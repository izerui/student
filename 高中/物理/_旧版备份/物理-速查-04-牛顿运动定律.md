Section ① "牛顿三大定律——力学的基石" (top, full width hero module, orange-gold header):

定律一（惯性定律）：
"一切物体总保持匀速直线运动状态或静止状态，除非作用在它上面的力迫使它改变这种状态。"
- 力不是维持运动的原因，而是改变运动状态的原因
- 惯性：物体保持原来运动状态的性质。质量是惯性大小的唯一量度

定律二（核心定律）：F = ma
- 矢量方程：加速度方向与合外力方向始终一致
- 瞬时性：力与加速度同时产生、同时变化、同时消失
- 独立性：每个方向上的力独立产生该方向的加速度
- 适用条件：惯性参考系（恒力变力均适用，F=ma是瞬时关系）
- 单位制：1 N = 1 kg·m/s²

定律三（作用力与反作用力）：
大小相等、方向相反、同一直线、作用在不同物体上。同时产生消失，不需任何条件

辨析框：作用力反作用力 vs 平衡力
| 对比项 | 作用力与反作用力 | 一对平衡力 |
| 作用对象 | 两个不同物体 | 同一个物体 |
| 是否同时 | 同时产生消失 | 不一定 |
| 性质 | 一定同性质 | 不一定同性质 |

Section ② "实验：探究加速度与力、质量的关系" (middle-left, medium module, grey header):
- 装置：长木板 + 小车 + 打点计时器 + 纸带 + 定滑轮 + 细线 + 砝码盘和砝码 + 刻度尺 + 天平
- 操作：①先补偿摩擦力：不挂砝码，将木板一端微微抬高，轻推小车使其恰好匀速运动（纸带上点迹等间距）②探究a与F：保持小车质量M不变，改变砝码盘中砝码质量m₀（m₀g近似为拉力F），用纸带测出对应加速度a ③探究a与m：保持砝码质量不变（F不变），在小车上增减砝码改变总质量M，测对应加速度a
- 数据处理：作a-F图像（应为过原点直线）；作a-1/M图像（应为过原点直线）
- 前提条件：砝码质量m₀ << 小车质量M（否则绳上拉力≠m₀g，而是m₀Mg/(M+m₀)）
- 误差控制：①未补偿摩擦→a=(F-f)/M，a-F图像在F轴有正截距f（即F<f时a=0），等价于a轴截距为负值-f/M②m₀过大→a-F图像在大F端向下弯曲 ③每次改变条件后都要重新打纸带测a ④加速度由纸带用逐差法求得，不能直接用公式a=F/m计算（那是待验证的结论）

Section ③ "牛顿定律的应用" (middle-right, medium module, coral header):
核心解题流程：确定研究对象 → 受力分析 → 建坐标系 → 列方程F合=ma → 结合运动学公式
两类问题：已知力求运动（F→a→v,x）/ 已知运动求力（v,x→a→F）
整体法 vs 隔离法：先整体求a，再隔离求内力

Section ④ "超重与失重" (bottom-left, medium module, violet header):
本质：物体对支持物的压力与重力的关系，不是重力的变化
| 状态 | 条件 | 视重 |
| 超重 | a向上（加速上升或减速下降） | N > mg |
| 失重 | a向下（加速下降或减速上升） | N < mg |
| 完全失重 | a = g | N = 0 |
太空站中宇航员"飘浮"——不是没有重力，而是重力全部充当向心力，视重为零

Section ⑤ "深层洞察" (bottom-right, golden border card):
• 第一定律定义"惯性"和"力的作用"，第二定律给出定量关系，第三定律揭示"力总是成对出现"
• 运动学只能描述"怎么动"，牛顿定律才能回答"为什么这么动"——物理学的第一次大统一
• 后续所有章节（圆周运动、万有引力、电磁力）都是F=ma在不同情境中的应用
