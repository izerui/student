Section ① "功——能量转化的量度" (top, large module, teal header):

定义：W = Flcosα（F为力的大小，l为位移大小，α为F与l的夹角）
- α < 90°：正功（力促进运动）
- α = 90°：不做功（如向心力、光滑面支持力）
- α > 90°：负功（力阻碍运动）

功的本质："功 = 力在空间中的累积效果。正功→输入能量；负功→提取能量。"

合力做的功 = 各力分别做功的代数和：W合 = W₁ + W₂ + W₃ + ...

变力做功的处理：
- 图像法：F-x图像下的面积 = 功
- 微元法：将过程分成小段，每段近似恒力
- 用动能定理反求：W合 = ΔEk

功率：P平均 = W/Δt；P瞬时 = Fvcosα（v为瞬时速度大小，α为力与速度夹角）；两者一般不相等

汽车启动问题（两种模式）：
模式1 恒定功率启动：P不变 → F = P/v → v↑则F↓ → a↓ → 直到F=f时匀速，v_max = P/f
模式2 恒定加速度启动：a不变 → v↑则P↑ → 直到P = P额定，此后转为模式1

Section ② "动能定理" (middle, large module, green header):

核心公式（黄色高亮框）：
W合 = ΔEk = ½mv₂² - ½mv₁²

动能定理的三大优势（对比牛顿定律）：
| 对比项 | 牛顿定律F=ma | 动能定理W=ΔEk |
|--------|-------------|--------------|
| 处理变力 | 很困难 | 可以 |
| 处理曲线运动 | 需分解为两个方向 | 直接用（标量） |
| 适用范围 | 惯性系中、质量不变的经典力学过程 | 本表采用Ek=½mv²：惯性系中、质量不变的非相对论过程 |

解题步骤：确定研究对象和过程 → 分析所有力并计算各力做功 → 列方程 W₁+W₂+...= ½mv₂² - ½mv₁² → 求解

Section ③ "深层洞察" (bottom, golden border card):
• 牛顿定律关注瞬时（力→加速度），动能定理关注过程（功→动能变化）——同一物理世界的两种视角
• 动量定理和动能定理都来自F=ma：前者对时间积分（恒力时为FΔt，变力时用平均力×Δt），后者对位移积分（力在空间上的累积）
