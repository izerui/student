Section ① "光的折射与全反射" (top, large module, teal header):

折射定律：n₁sinθ₁ = n₂sinθ₂ → sinθ₁/sinθ₂ = n₂/n₁ = v₁/v₂（光从介质1射入介质2）
折射率：n = c/v（v为光在介质中的速度，n≥1）
光密介质：n大v小；光疏介质：n小v大

全反射条件：①光从光密→光疏 ②入射角 > 临界角C（=C时折射角恰好90°，是临界态）
临界角：sinC = n疏/n密（光疏为真空/空气时sinC ≈ 1/n密）
应用：光导纤维（光纤通信）、全反射棱镜

Section ② "光的干涉" (middle-left, large module, green header):

杨氏双缝干涉（1801年，证明光是波）：
条纹间距：Δx = lλ/d（l=缝到屏距离，d=缝间距）
明纹：路程差 = nλ（n=0,1,2...）；暗纹：路程差 = (2n+1)λ/2
白光实验：中央白色亮纹，两侧彩色条纹（红最宽紫最窄）
薄膜干涉：肥皂泡/油膜的彩色条纹

实验：用双缝干涉测量光的波长
- 装置：光源→滤光片（选单色光）→单缝（线光源）→双缝（相干光源）→光屏
- 操作：①各元件共轴等高 ②先用白光调出彩色条纹确认装置正确 ③换单色滤光片 ④用测量头逐条测多条亮纹位置
- 数据处理：测n条亮纹间距，Δx = 总间距/(n-1)，λ = dΔx/l
- 误差控制：多测取平均；d为已知值；l越大条纹越宽越易精确测量
- 验证：红光波长>紫光波长（红光条纹更宽）

Section ③ "光的衍射、偏振与激光" (middle-right, medium module, orange header):

衍射：障碍物/缝尺寸与波长相当时，光偏离直线传播
单缝衍射（远场、小角度）：中央明纹最亮，宽度约为侧明纹的两倍；侧明纹宽度近似相等，向两侧亮度逐渐减弱
光的衍射不如声波明显的原因：光的波长极短（~10⁻⁷ m）

偏振：
自然光：各方向振动等概率；偏振光：只沿特定方向振动
偏振片：只让特定振动方向通过
偏振证明光是横波（纵波不能偏振）

激光：受激辐射实现光放大；原子能级跃迁见24表。
- 特点→应用：相干性好→全息成像；单色性好→精密光谱测量；方向性好→测距；聚焦后能量集中→切割加工。

Section ④ "波的统一性——从机械波到光波" (bottom, full width module, gold header):

| 性质 | 机械波 | 电磁波/光波 |
|------|--------|-----------|
| 介质 | 需要 | 不需要 |
| 反射/折射/衍射/干涉 | 都有 | 都有 |
| 偏振 | 仅横波 | 有（光是横波） |
| 多普勒效应 | 有 | 有（红移/蓝移→宇宙膨胀证据） |
| 波速 | 由介质决定 | 真空中c=3×10⁸m/s |
| 频率 | 由波源决定 | 由波源决定 |

洞察框："衍射和干涉是波特有的'指纹'——凡能衍射干涉的就是波。电子也能衍射→电子也是波！"

• 多普勒效应的宇宙学意义：几乎所有星系光谱都呈红移→宇宙在膨胀（哈勃发现）
• 光的波动性与粒子性并存→波粒二象性（密码表24）
