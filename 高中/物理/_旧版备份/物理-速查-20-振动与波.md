Section ① "简谐运动——振动的数学描述" (top-left, large module, teal header):

定义与判据：
- 简谐运动：位移随时间做正弦变化的运动
- 判据（充要条件）：回复力 F = -kx（回复力与位移成正比、方向相反）
- 注意：回复力不是新的力，是合力在振动方向上的分量

位移公式：x = Asin(ωt + φ)
- A：振幅（最大位移）；ω = 2π/T = 2πf：圆频率；φ：初相位

运动学特征对照表（关键！）：
| 位置 | 位移x | 速度v | 加速度a | 回复力F | 动能Ek | 势能Ep |
|------|-------|-------|---------|---------|--------|--------|
| 平衡位置O | 0 | 最大v_max | 0 | 0 | 最大 | 最小 |
| 最大位移±A | ±A | 0 | 最大a_max | 最大 | 0 | 最大 |

能量：机械能守恒（Ek+Ep=常量）；周期与振幅无关（等时性）；振幅越大→总能量越大

单摆：
- 条件：线不伸长质量忽略；球径<<线长；摆角<5°
- 回复力 F ≈ -(mg/l)x → 简谐运动
- 周期：T = 2π√(l/g)（只与l和g有关，与质量振幅无关）

实验：用单摆测量重力加速度
- 原理：由T = 2π√(l/g)得 g = 4π²l/T²
- 装置：细线+小钢球+铁架台+刻度尺+秒表（或光电门）
- 操作：①线长>1m，球用密度大的小钢球 ②摆长l = 悬点到球心的距离（线长+球半径）③拉开小角度(<5°)释放 ④从平衡位置开始计时，记录30~50次全振动的总时间，T = 总时间/次数
- 数据处理：改变摆长，测多组(l, T)数据；作T²-l图像，斜率k = 4π²/g → g = 4π²/k
- 误差控制：①从平衡位置（而非最大位移处）开始计时更准确 ②计多次全振动取平均减小偶然误差 ③摆长测量要精确（用刻度尺量线长+游标卡尺量球径） ④保持小角度振动（否则不是简谐运动）

受迫振动与共振：
- 固有频率f₀由系统决定；受迫振动频率 = 驱动力频率
- 共振：驱动力频率 = 固有频率 → 振幅最大

Section ② "机械波——振动的传播" (middle, large module, green header):

定义：机械振动在介质中的传播。条件：①波源 ②弹性介质

两类波：横波（振动⊥传播，波峰波谷）；纵波（振动∥传播，密部疏部）

核心公式：v = λf = λ/T
- 波速由介质决定；频率由波源决定；进入新介质时f不变、v变、λ变

波的两种图像：
| | 波形图（y-x） | 振动图（y-t） |
|--|---------|---------|
| 含义 | 某时刻所有质点位移快照 | 某质点各时刻位移记录 |
| 可读取 | 波长λ、振幅A | 周期T、振幅A |

波的特有现象：
| 现象 | 条件 | 本质 |
|------|------|------|
| 反射 | 遇障碍物 | 反射角=入射角 |
| 折射 | 进入不同介质 | 波速改变→方向改变 |
| 衍射 | 缝/障碍物尺寸与λ相当或更小 | 波绕过障碍物传播 |
| 干涉 | 频率相同、相位差恒定的两列波叠加 | 稳定加强/减弱区域 |
| 多普勒效应 | 波源与观察者相对运动 | 接近→f升高；远离→f降低 |

干涉三条件：①频率相同 ②相位差恒定 ③振动方向相同
叠加独立性：两列波相遇互不影响，穿过后恢复原状
波传能量不传物质：质点在平衡位置附近振动，不随波迁移
