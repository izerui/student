Section ① "基本物理量" (top, large module, orange header):

| 物理量 | 符号 | 定义 | 单位 | 关系 |
|--------|------|------|------|------|
| 线速度 | v | 弧长/时间 = Δs/Δt | m/s | v = 2πr/T = ωr |
| 角速度 | ω | 转过角度/时间 = Δθ/Δt | rad/s | ω = 2π/T = 2πf |
| 周期 | T | 转一圈所需时间 | s | T = 1/f = 2π/ω |
| 频率 | f | 单位时间转过的圈数 | Hz | f = 1/T |
| 转速 | n | 单位时间转过的圈数 | r/s 或 r/min | f以Hz计：n以r/s计时f=n；n以r/min计时f=n/60（数值关系） |

传动关系：
- 皮带传动/齿轮啮合（接触点线速度相等）：v₁ = v₂ → ω₁/ω₂ = r₂/r₁
- 同轴转动（固定在同一根轴上）：ω₁ = ω₂ → v₁/v₂ = r₁/r₂

向心加速度与向心力：
- a = v²/r = ω²r = 4π²r/T²（方向始终指向圆心）
- F向 = mv²/r = mω²r = 4π²mr/T²
- 向心力不是新的力！它是合外力沿半径方向的效果

Section ② "四大典型模型" (middle-bottom, full width hero module, coral header):

模型1 水平面内圆锥摆：
- Tsinθ = mv²/r, Tcosθ = mg → tanθ = v²/(rg)

模型2 竖直面内圆周运动（绳/杆模型）：
- 最高点（绳模型）：mg + T = mv²/r → 临界T=0时v_min = √(gr)
  · 若v < √(gr)，绳松弛，脱离圆周轨道
- 最高点（杆模型）：杆可拉可推 → v可以为0（此时杆推力 = mg）
- 最低点（通用）：N - mg = mv²/r

模型3 汽车过拱桥/凹桥：
- 凸形桥顶：mg - N = mv²/r（N < mg，变轻）
- 凹形桥底：N - mg = mv²/r（N > mg，变重）

模型4 火车转弯（倾斜轨道）：
- 重力和支持力的合力提供向心力
- 设计速率：v₀ = √(grtanθ)

Section ③ "深层洞察" (bottom, golden border card):
• 向心力公式有两种形式：知道v用v²/r，知道ω用ω²r。v一定时a∝1/r，ω一定时a∝r——不矛盾，是不同约束条件
• 一般曲线运动中任一小段都可近似为圆弧，用圆周运动方法分析
