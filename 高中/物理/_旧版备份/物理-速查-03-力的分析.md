Section ① "力的本质与分类" (top, large module, teal header):

核心定义框：力是物体之间的相互作用。力的三要素：大小、方向、作用点。力是矢量。

力的分类树状图：
├── 按性质分（本质分类）
│   ├── 重力 G = mg（方向竖直向下，重心为等效作用点）
│   │   · g = 9.8 m/s²（随纬度和海拔变化）
│   ├── 弹力 F = kx（胡克定律，仅在弹性限度内成立）
│   │   · 产生条件：①直接接触 ②发生弹性形变
│   │   · 方向：与形变方向相反（绳沿绳方向，面垂直接触面）
│   │   · 弹簧劲度系数k：由弹簧材料和结构决定，与形变量无关
│   ├── 摩擦力
│   │   ├── 静摩擦力：0 ≤ f静 ≤ f静max（大小随外力变化，方向阻碍相对运动趋势）
│   │   └── 滑动摩擦力：f = μN（μ为动摩擦因数，N为正压力）
│   │   · 关键：N ≠ mg（只有水平面且无其他竖直力时才等于mg）
│   │   · 方向：与相对运动方向（或趋势）相反，不一定与运动方向相反！
│   └── （电磁力、核力——后续章节展开）
└── 按效果分
    └── 向心力、回复力等不是新的力，是合力的效果名称

重要提醒框（红色边框）：
"向心力、回复力不是新的力种类！受力分析时绝不能凭空多画一个'向心力'。"

Section ② "力的合成与分解——矢量运算法则" (middle, large module, green header):

核心法则：平行四边形定则——以两个力为邻边作平行四边形，对角线即为合力
- 同方向：F合 = F₁ + F₂（最大值）
- 反方向：F合 = |F₁ - F₂|（最小值）
- 夹角θ：F合 = √(F₁² + F₂² + 2F₁F₂cosθ)
- 垂直时（θ=90°）：F合 = √(F₁² + F₂²)
- 合力范围：|F₁-F₂| ≤ F合 ≤ F₁+F₂

力的分解：按实际效果或按坐标轴分解。Fx = Fcosθ, Fy = Fsinθ

正交分解法步骤：受力分析 → 建坐标系（取a方向为x轴）→ 分解各力 → 列方程 ΣFx = max, ΣFy = may

Section ③ "共点力的平衡" (bottom, large module, blue header):

平衡条件：ΣF = 0（合外力为零）
- 二力平衡：等大反向共线
- 三力平衡：矢量构成封闭三角形，任意两力合力与第三力等大反向
- 多力平衡：正交分解后 ΣFx = 0, ΣFy = 0

| 情况 | 推荐方法 |
|------|---------|
| 三个力 | 合成法或三角形法 |
| 三个以上力 | 正交分解法 |
| 涉及角度变化 | 图解法（力三角形） |
