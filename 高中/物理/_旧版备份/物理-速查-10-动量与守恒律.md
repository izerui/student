Section ① "动量与动量定理" (top-left, medium module, coral header):

动量：p = mv（矢量，方向与v相同），单位：kg·m/s
动量变化：Δp = p₂ - p₁（矢量减法）
动量定理：F合平均Δt = Δp = mv₂ - mv₁ "合力的冲量 = 动量的变化量"（F合平均为该时段的时间平均合力，恒力时即合力本身）
冲量 I = F平均Δt（矢量，方向与时间平均力相同；变力不能直接代入某一时刻的力或峰值力）

动量定理 vs 动能定理——平行对比：
| | 动量定理 | 动能定理 |
| 公式 | F合平均Δt = Δp | W合 = ΔEk |
| 累积维度 | 时间平均合力 × 时间 | 合力的功 |
| 物理量 | 矢量方程 | 标量方程 |
| 来源 | F=ma两边对时间积分 | F=ma两边对位移积分 |
启示：它们是F=ma在时间和空间两个维度上的积分形式

Section ② "动量守恒与碰撞" (top-right, large module, green header):

动量守恒定律：条件为系统所受合外力为零（或内力远大于外力）
m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'
"动量守恒定律在牛顿力学失效的领域仍然成立——比牛顿定律更基本"

碰撞分类：
| 类型 | 动能变化 | 特征 |
| 弹性碰撞 | 动能守恒 | 动量+动能双守恒 |
| 非弹性碰撞 | 动能减少 | 只有动量守恒 |
| 完全非弹性碰撞 | 动能损失最大 | 碰后粘合共速 |

弹性碰撞特殊结论（m₁碰静止m₂）：
- m₁ = m₂：速度交换 | m₁ >> m₂：小飞走 | m₁ << m₂：弹回来

反冲与火箭：0 = m气v气 + m箭v箭。喷出气体速度越快、质量越大→箭体速度越大

实验：验证动量守恒定律

方法1 气垫导轨法：
- 装置：气垫导轨 + 两个滑块（可加不同质量砝码）+ 两个光电门 + 数字计时器 + 弹簧/尼龙搭扣（实现弹性/完全非弹性碰撞）
- 操作：①调节导轨水平（轻推滑块能匀速运动）②记录两滑块质量 ③让滑块1以一定速度碰撞静止的滑块2 ④光电门分别测碰前碰后各滑块速度（v = 挡光片宽度/遮光时间）
- 数据处理：验证 m₁v₁ = m₁v₁' + m₂v₂'（注意方向用正负号）

方法2 斜面小球法：
- 装置：斜面 + 两个大小相同但质量不同的小球 + 白纸 + 复写纸 + 刻度尺 + 重锤线
- 操作：①入射球从斜面同一高度由静止释放，飞出桌面做平抛 ②先不放被碰球，记录入射球落点P ③放上被碰球（在斜面末端），再次释放入射球，记录碰后两球落点M和N ④重复多次
- 数据处理：三个落点到桌面边缘正下方O点的水平距离分别为 OP=x₁（碰前入射球）、OM=x₁'（碰后入射球）、ON=x₂'（碰后被碰球）。由于所有球从同一高度桌面飞出→飞行时间相同→水平距离∝水平速度。验证：m₁·OP = m₁·OM + m₂·ON
- 误差控制：①每次从同一高度释放 ②两球等大（碰撞为正碰）③多次实验取落点平均位置 ④入射球质量应大于被碰球（否则碰后入射球反弹，无法测量）

Section ③ "三大守恒律" (bottom-left, large module, deep gold header):

| 守恒律 | 守恒量 | 条件 | 数学表达 |
| 动量守恒 | 总动量p | 合外力为零 | Σp₁ = Σp₂ |
| 机械能守恒 | 机械能E | 只有重力/弹力做功 | Ek₁+Ep₁ = Ek₂+Ep₂ |
| 能量守恒 | 总能量 | 无条件（永远成立） | 能量只转化不消灭 |

"三个守恒律对应三种对称性（诺特定理）：动量守恒↔空间平移对称性；能量守恒↔时间平移对称性；角动量守恒↔空间旋转对称性"
