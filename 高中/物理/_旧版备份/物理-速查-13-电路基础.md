Section ① "电流的本质" (top-left, medium module, teal header):

电流定义：I = q/t，单位安培（A），1A = 1C/s。方向：规定为正电荷运动方向。

微观本质：
- 自由电子在电场作用下定向漂移，漂移速度 v ≈ 10⁻⁴ m/s（极慢！）
- 但电场建立接近光速→开关一合整条电路几乎同时有电流
- I = nqvS（n单位体积自由电荷数，q单个电荷量，v漂移速度，S截面积）

Section ② "电阻与欧姆定律" (top-right, medium module, green header):

电阻 R = U/I，单位欧姆（Ω）。电阻是导体本身属性。

决定因素：R = ρl/S（ρ电阻率，l长度，S截面积）
- 金属：温度↑→ρ↑→R↑ | 半导体：温度↑→ρ↓→R↓ | 超导体：低于临界温度ρ→0

欧姆定律（部分电路）：I = U/R。适用于线性元件（I-U图为直线）。
非线性元件（灯泡、二极管）：R随U变化，I-U图为曲线。

Section ③ "串联与并联" (middle, full width module, orange header):

| 对比项 | 串联电路 | 并联电路 |
|--------|---------|---------|
| 电流 | I = I₁ = I₂（处处相等） | I = I₁ + I₂（分流） |
| 电压 | U = U₁ + U₂（分压） | U = U₁ = U₂（处处相等） |
| 电阻 | R = R₁ + R₂（越串越大） | 1/R = 1/R₁ + 1/R₂（越并越小） |
| 功率 | P = P₁ + P₂ | P = P₁ + P₂ |
| 分配 | U₁/U₂ = R₁/R₂ | I₁/I₂ = R₂/R₁ |

口诀："串联分压，并联分流"
电压表 = 大电阻（并联），电流表 = 小电阻（串联）

Section ④ "闭合电路欧姆定律" (bottom, large module, coral header):

核心公式（黄色高亮框）：
ε = IR + Ir = U外 + U内，变形 I = ε/(R + r)

- 电动势 ε = W/q（非静电力做功/电荷量），电源固有属性
- 内阻 r：电源内部电阻
- U外 = IR，U内 = Ir

U-I图：U = ε - Ir → 斜率 = -r，纵截距 = ε
- 短路（R=0）：I = ε/r（危险！），U = 0
- 断路（R=∞）：I = 0，U = ε
