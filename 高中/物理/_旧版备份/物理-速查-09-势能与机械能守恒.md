Section ① "势能" (top, large module, orange header):

重力势能：Ep = mgh
- h是质心相对于参考平面的高度
- 重力做功与路径无关：WG = mgh₁ - mgh₂ = -(Ep₂ - Ep₁)
- "路径无关"是定义势能的前提条件——只有保守力才能定义势能
- 重力做正功 → 势能减少；重力做负功 → 势能增加

弹性势能：Ep = ½kx²（x为弹簧形变量）
- 弹力做正功 → 弹性势能减少

Section ② "机械能守恒定律" (middle, large module, blue header):

条件：只有重力和弹力做功（其他力不做功或不存在）
Ek₁ + Ep₁ = Ek₂ + Ep₂ 即 ½mv₁² + mgh₁ = ½mv₂² + mgh₂
等价表述：ΔEk = -ΔEp（动能增加量 = 势能减少量）

判断条件的三种方法：
方法1：看是否只有重力/弹力做功
方法2：看是否存在做功的非保守力
方法3：计算非保守力做功之和是否为零

功能关系总表（核心关联图）：
| 做功的力 | 对应的能量变化 |
|---------|-------------|
| 合力做功 W合 | = ΔEk（动能定理） |
| 重力做功 WG | = -ΔEp重 |
| 弹力做功 W弹 | = -ΔEp弹 |
| 一对滑动摩擦力做功之和 Wf₁+Wf₂ | = -Q，Q=f·s相对（f恒定，Q为摩擦生热）；单个物体的摩擦力做功可正可负，不一定等于-Q |
| 除重力弹力外其他力做功 W其他 | = ΔE机械能 |

Section ③ "实验：验证机械能守恒定律" (bottom-left, medium module, grey header):
- 装置：铁架台 + 电磁打点计时器（竖直安装）+ 纸带 + 重锤（质量较大以减小摩擦影响）+ 刻度尺 + 导线和电源
- 操作：①将打点计时器竖直固定在铁架台上 ②纸带穿过计时器，下端夹住重锤 ③先接通电源，再松手释放重锤 ④选取前两点间距接近½gT²≈2mm的纸带，将首个清晰点作为近似静止起点O（释放时刻无法与打点精确同步，这是近似处理）
- 数据处理：①选取第一个清晰点为起始点O ②用刻度尺测量O到后续各点的距离h₁、h₂、h₃... ③用中间时刻速度公式求各点瞬时速度：vₙ = (hₙ₊₁-hₙ₋₁)/(2T) ④比较 ½vₙ² 与 ghₙ（已消去质量m），若二者近似相等则验证成功
- 误差控制：①重锤要足够重（减小摩擦和空气阻力的相对影响）②先接电源再释放 ③选前两点间距≈2mm的纸带（首点近似静止，初速度足够小可视为零）④测量h时从同一起始点O量起（减小累积误差）
- 系统误差方向：空气阻力和纸带摩擦消耗机械能→实测 ½v² 略小于 gh（动能增量 < 势能减量，合理）

Section ④ "深层洞察" (bottom-right, golden border card):
• 重力做功与路径无关→可以定义重力势能。摩擦力做功与路径有关→不能定义"摩擦势能"。保守力vs非保守力的本质区别
• 机械能守恒是更深层的自然规律——关注始末状态，不需要知道过程细节
