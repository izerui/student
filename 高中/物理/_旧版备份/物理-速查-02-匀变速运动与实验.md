Section ① "匀变速直线运动——完整公式体系" (top, large module, orange header):
核心条件框："a = 常量，直线运动"

三大基本公式（黄色高亮框）：
公式1: v = v₀ + at         （速度-时间关系，由a的定义直接得出）
公式2: x = v₀t + ½at²      （位移-时间关系，v-t图像下面积）
公式3: v² - v₀² = 2ax      （速度-位移关系，消去t得到）

两大推论（绿色框）：
推论1: x = v̄·t = [(v₀+v)/2]·t    （平均速度公式，匀变速特有）
推论2: Δx = aT²                   （连续相等时间T内位移之差恒定）

中间时刻速度：v(t/2) = (v₀+v)/2 = v̄  （等于平均速度！）
中间位移速度：v(x/2) = √[(v₀²+v²)/2]  （不等于平均速度）

公式选择策略（决策树）：缺x→公式1；缺t→公式3；缺v→公式2；缺a→推论1

Section ② "实验：探究小车速度随时间变化的规律" (middle-left, medium module, grey header):
- 装置：电磁/电火花打点计时器（均50Hz，周期0.02s）+ 纸带 + 小车 + 一端抬高的长木板 + 钩码（提供拉力）
- 操作：①将计时器固定在木板高端，纸带穿过计时器连接小车 ②先接通电源再释放小车 ③取点迹清晰、间距递增的纸带
- 纸带处理：每隔相等时间T取一个计数点（通常每5个点取一个，T=0.02×5=0.1s）
- 符号约定：x_n 为第n个计数点位置坐标，s_n 为第n个时间间隔位移（s_n = x_n - x_{n-1}）
- 求瞬时速度：v_n = (x_{n+1} - x_{n-1})/(2T)（中间时刻速度公式）
- 验证匀变速：s₂-s₁ = s₃-s₂ = ... = aT²（恒定则为匀变速）
- 求加速度：逐差法 a = (s₄+s₅+s₆-s₁-s₂-s₃)/(9T²)（6段数据分两组对应相减再取平均）
- 误差控制：①先接电源再释放（避免开头点迹过密无法分辨）②选取间距均匀递增的纸带③多测几组取平均 ④计时器与纸带间摩擦→实际加速度略小于理论值（系统误差方向）

Section ③ "v-t图像——运动的可视化语言" (middle-right, medium module, purple header):
| 图像特征 | 物理含义 |
|---------|---------|
| 横轴上方/下方 | v>0正方向运动 / v<0反方向运动 |
| 斜率 | 加速度a（斜率正负表示a的方向；a与v同号加速，异号减速） |
| 面积 | 位移x（上方为正位移，下方为负位移） |

典型图线：水平线→匀速(a=0)；过原点斜线→从静止匀加速；斜率为负穿过横轴→减速后反向

Section ④ "自由落体与竖直上抛" (bottom, large module, red header):

自由落体运动（特殊的匀加速，v₀=0, a=g）：
- 条件：仅受重力（忽略空气阻力），从静止开始
- g ≈ 9.8 m/s²（可取10 m/s²），g值随纬度和海拔略有变化，同一地点视为常量
- 公式：v = gt，h = ½gt²，v² = 2gh
- 伽利略：用斜面实验证明"同一地点、忽略空气阻力时，所有物体下落加速度相同"

竖直上抛运动：
- v₀向上，a = g向下（取向上为正则a = -g）
- 对称性：上升和下降经过同一位置的速度大小相等
- 最高点：H = v₀²/(2g)，上升时间 t上 = v₀/g，返回抛出高度的总时间 t总 = 2v₀/g（仅受重力，g视为常量）

Section ⑤ "总结" (bottom-right, golden border card):
• 所有匀变速公式的"密码"：只需记住"a恒定"这一个条件，三大公式都可由v-t图推出
• 从伽利略到牛顿：伽利略发现"怎么落"，牛顿解释"为什么落"（万有引力）
