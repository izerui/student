Section ① "变化率——贯穿物理学的核心思维" (top, full width hero module, gold header):

一条递进链（水平流程图，大号箭头连接）：
位置 x → 对时间求变化率(Δt→0) → 瞬时速度 v = dx/dt → 对时间求变化率(Δt→0) → 瞬时加速度 a = dv/dt
（有限Δt时为平均速度v̄=Δx/Δt、平均加速度ā=Δv/Δt）

标注框："同一个'变化率'思维在整个物理学中反复出现：
· 电流 I = ΔQ/Δt（电荷的变化率）
· 感应电动势 E = ΔΦ/Δt（磁通量的变化率）
· 功率 P = ΔW/Δt（能量的变化率）
掌握'变化率'，就掌握了物理学最常用的数学语言。"

Section ② "描述运动的基本量" (middle-left, large module, teal header):

四个概念的精确定义与关系：

质点：不是"小"，而是"简化"。地球绕太阳时可视为质点，研究自转时不行。判断标准：形状大小对所研究问题的影响是否可忽略。

参考系→坐标系→正方向：选定参照物→建立坐标→选定正方向。运动是相对的，选不同参考系描述不同。

时刻（点）vs 时间（段）：数轴上的点 vs 两点之间的线段。"第3秒末"是时刻，"第3秒内"是1秒的时间段。
（绘图：画一条标有0、1、2、3、4的t轴。"第3秒末"用红点标在t=3处；"第3秒内"用高亮线段标在t=2到t=3之间，不要标在t=3到t=4之间。）

位移（矢量）vs 路程（标量）：起点到终点的有向线段 vs 轨迹实际长度。往返运动时位移可为零而路程不为零。

速度体系（三层递进框）：
平均速度 v̄ = Δx/Δt（一段过程的快慢，矢量）
→ Δt极短时 → 瞬时速度 v（某一时刻的快慢，矢量）
→ 取大小 → 速率 |v|（标量，速度表显示的就是这个）
注意：平均速度 ≠ 平均速率（除单方向运动外）

加速度：瞬时加速度 a = dv/dt；有限时间段的平均加速度 ā = Δv/Δt。描述速度变化的快慢（矢量）
· a与v同向→加速；a与v反向→减速
· 关键洞察：加速度大 ≠ 速度大（火箭启动瞬间a大v小；匀速飞行v大a=0）

Section ③ "匀变速直线运动——'a恒定'的全部推论" (middle-right, large module, orange header):

核心条件框（黄色高亮）："以下所有公式只需一个前提：a = 常量"

三大公式的逻辑来源（不是三个独立公式，而是一个条件的三种推论）：
公式1: v = v₀ + at         ← 直接由a的定义得到
公式2: x = v₀t + ½at²      ← v-t图下面积
公式3: v² - v₀² = 2ax      ← 消去t得到
推论: x = [(v₀+v)/2]·t      ← 匀变速的平均速度 = 首末速度平均

公式选择策略（环形导航图，画成圆环，五个量排在环上、五条公式（含缺v₀的补充式）各连接四个量，学生找到缺的量就知道该用哪个公式）：
题目中缺哪个量→用不含它的公式：
缺 x → 公式1 (v=v₀+at)
缺 t → 公式3 (v²-v₀²=2ax)
缺 v → 公式2 (x=v₀t+½at²)
缺 a → 推论 (x=[(v₀+v)/2]·t)
缺 v₀ → 由公式1和公式2联立，或用 x=vt-½at²
（绘图：五个量 v、v₀、a、t、x 排成圆环，每条公式连接其中四个量，缺的那个量标红并指向对应公式。学生找到缺的量，箭头直接告诉用哪个公式。）

v-t图像的物理意义（图示）：
斜率 = 加速度a | 面积 = 位移x | 横轴上方v>0 | 横轴下方v<0
（绘图：画一条从v₀>0出发、斜向上的直线；只在图线与t轴之间（横轴上方）涂阴影，标"面积=位移x"；横轴下方不涂阴影。"横轴下方v<0"只用文字说明。）

连续等时间段位移差：Δs = aT²（恒定→判断匀变速的实验依据）
逐差法求a：a = (s₄+s₅+s₆-s₁-s₂-s₃)/(9T²)

Section ④ "自由落体——伽利略的突破" (bottom-left, medium module, red header):

自由落体 = 匀变速的特例（v₀=0, a=g）：
v = gt, h = ½gt², v² = 2gh
条件：仅受重力（忽略空气阻力），同一地点g ≈ 9.8 m/s²

竖直上抛 = 匀减速+匀加速（对称性）：
H最高 = v₀²/(2g), t上 = v₀/g, 上下经过同一高度速度大小相等

伽利略的方法论意义框（蓝色边框）：
"直觉说'重物先落'，伽利略用实验+逻辑证伪。这是科学方法的范例——不信直觉，信实验和推理。"

Section ⑤ "实验：打点计时器与纸带" (bottom-center, medium module, grey header):
装置：电磁/电火花打点计时器（50Hz, T₀=0.02s）+ 纸带 + 小车
操作：先通电再释放，取间距递增的清晰纸带
数据处理：每5点取一计数点(T=0.1s)，x_n为位置，s_n为相邻位移
求瞬时速度：v_n = (x_{n+1}-x_{n-1})/(2T)
验证匀变速：s₂-s₁ = s₃-s₂ = ... = aT²
误差控制：先通电再释放 | 选点迹清晰的纸带 | 各计数点位置从同一起点量出再相减，减小读数误差 | 用逐差法充分利用数据
