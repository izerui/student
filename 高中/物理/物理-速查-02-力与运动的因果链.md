Section ② "力的三种基本类型" (middle-left, medium module, teal header):

重力 G = mg（方向竖直向下，作用于重心）
· g ≈ 9.8 m/s²，重心在均匀物体几何中心，可在物体外

弹力：接触+形变才有。方向与形变方向相反
· 胡克定律 F = kx（x为弹簧形变量，非位置坐标；弹性限度内，k由弹簧决定，与x无关）
· 绳沿绳方向，面垂直接触面

摩擦力：
· 滑动摩擦 f = μN（μ为动摩擦因数，N为正压力，由受力分析确定，不一定等于mg）
· 静摩擦 0 ≤ f ≤ f_max（大小随外力变化，方向与相对运动趋势反）
· 关键：方向与"相对运动方向"反，不一定与运动方向反（传送带上摩擦力可与运动同向）

红色警告框："向心力、回复力不是新的力！它们按作用效果命名，可由实际力的合力或分力提供，受力分析时不要凭空多画。"

Section ③ "牛顿三定律——不是三个独立命题" (middle-right, large module, orange header):

三定律的逻辑关系（递进结构）：
第一定律（定义层）：定义了"惯性"和"力的作用"→ 没有力则匀速/静止
· 惯性：保持原来运动状态的性质。质量是惯性的唯一量度
第二定律（定量层）：F合 = ma（矢量方程，a与F合同时产生、同时变化、同向）
· 1 N = 1 kg·m/s²。适用于惯性参考系
第三定律（对称层）：作用力与反作用力等大反向、同时、同线、同性质、在不同物体上
辨析表：
| | 作用力与反作用力 | 一对平衡力 |
| 作用对象 | 两个不同物体 | 同一物体 |
| 能否抵消 | 不能 | 可以 |

Section ④ "受力分析与平衡" (bottom-left, medium module, blue header):

解题双向导航（画成左右双箭头流程图，学生看到题目立即判断走哪条路）：
路径A "已知力→求运动"：受力分析→求F合→a=F合/m→代入运动学公式求v、x
路径B "已知运动→求力"：由运动学公式求a→F=ma→反推未知力
桥梁：a（加速度）是牛顿定律两类问题中连接受力与运动的纽带

受力分析流程：隔离物体→画重力→找接触面画弹力摩擦力→检查有无遗漏多画
力的合成与分解：平行四边形定则（两力为邻边，对角线为合力）；合力范围 |F₁-F₂| ≤ F合 ≤ F₁+F₂；分解是合成的逆运算
正交分解：取加速度方向为x轴 → ΣFx = max, ΣFy = may
平衡条件：ΣF = 0 → a = 0 → 静止或匀速
三力平衡：任意两力合力与第三力等大反向（矢量三角形法）

超重与失重（验证F=ma的理解）：
| 状态 | 条件 | 视重N |
| 超重 | a有向上分量 | N > mg |
| 失重 | a有向下分量 | N < mg |
| 完全失重 | a = g | N = 0（太空站宇航员"飘浮"）|
本质：不是重力变了，是支持力变了
