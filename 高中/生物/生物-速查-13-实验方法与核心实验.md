Section ① "实验设计方法论" (top, full width hero module, teal header):

Three principle boxes side by side:
Box 1 "对照原则":
- 实验组：施加自变量处理 / 对照组：不施加或施加标准处理
- 四种对照：空白对照(无处理) / 自身对照(处理前后) / 条件对照(已知标准) / 相互对照(不同实验组间)

Box 2 "单一变量原则":
- 自变量：主动操作改变的变量(如温度、pH、光照)
- 因变量：随自变量变化的观测指标(如反应速率、产物量)
- 无关变量：除自变量外所有可能影响结果的因素 → 必须相同且适宜

Box 3 "可重复性原则":
- 每组≥3个平行重复 → 取平均值减少误差
- 整个实验可被他人重复验证

Bottom callout: "结论表述：探究性用'该实验表明……'；验证性用'该实验证明……'"

解题导航——实验设计题通用路径(decision-tree mini-block, 用分支箭头绘制):
第一步: 明确实验目的 → 探究还是验证?
├→ 探究性实验: 结果未知, 预期写多种可能("若...则说明...; 若...则说明...")
└→ 验证性实验: 结果已知, 预期写唯一结论
第二步: 确定变量
├→ 自变量: 你主动改变的因素(唯一不同的条件)
├→ 因变量: 随自变量变化而变化的观测指标
└→ 无关变量: 其他所有条件(必须相同且适宜)
第三步: 设计对照
├→ 空白对照: 不做处理(如加等量蒸馏水)
├→ 自身对照: 处理前后比较(如质壁分离与复原)
└→ 相互对照: 不同实验组之间比较
第四步: 描述步骤 → 取材分组(随机等量) → 施加处理(只改自变量) → 观察记录 → 统计分析
第五步: 预期结果与结论

Section ③ "显微观察与形态技术" (middle-right, medium module, blue header):

Mini-block A "显微镜操作":
①低倍找目标 → ②移至视野中央(偏左向左移) → ③转换器换高倍(不动粗准焦!) → ④细准焦螺旋调清 → ⑤调大光圈/凹面镜
放大倍数 = 目镜 × 物镜；倍数↑ → 视野↓亮度↓

Mini-block B "有丝分裂观察"(→验证于04表):
取材(根尖2-3mm) → 解离(15%HCl+95%酒精1:1, 3-5min) → 漂洗(清水~10min) → 染色(龙胆紫/醋酸洋红) → 压片 → 镜检
Note: 解离后细胞已死亡，不能观察动态分裂过程

Mini-block C "质壁分离与复原"(→验证于02表):
紫色洋葱外表皮 → 0.3g/mL蔗糖 → 原生质层与细胞壁分离(液泡缩小、颜色变深) → 清水 → 复原
"壁"=细胞壁，"质"=原生质层(细胞膜+液泡膜+两层间细胞质)

Mini-block D "叶绿体与细胞质流动"(→验证于02表):
黑藻小叶制临时装片→低倍→高倍→叶绿体椭球形(绿色)随细胞质沿细胞壁环形流动。光照和适温加速流动

Mini-block E "减数分裂装片观察"(→验证于04表):
蝗虫精巢永久装片→低倍找精母细胞→高倍辨认各期
判断口诀(适用于正常二倍体生物的典型分裂图): "有同源看联会→减I; 无同源→减II"(单倍体有丝分裂也无同源, 须结合其他信息区分)

Mini-block F "色素提取与分离"(→验证于03表):
提取: 绿叶+SiO₂(研磨)+CaCO₃(防酸破坏)+无水乙醇(溶解色素)→研磨→过滤
层析: 滤纸条距底端2cm画线→毛细管划滤液(干后重复2-3次)→插入层析液(液面必须低于滤液线!)
四带(上→下): 胡萝卜素(橙黄) → 叶黄素(黄) → 叶绿素a(蓝绿，最宽) → 叶绿素b(黄绿)

Section ④ "经典探究与验证实验" (bottom-left, large module, green header):

Experiment A "酶的专一性"(→验证于03表):
1号: 淀粉液+唾液淀粉酶→37°C水浴→加现配斐林试剂→50-65°C水浴加热→出现砖红色沉淀(水解为麦芽糖, 阳性)
2号: 蔗糖液+唾液淀粉酶→37°C水浴→加现配斐林试剂→50-65°C水浴加热→不出现砖红色沉淀(未水解, 阴性)

Experiment B "酶最适温度/pH"(→验证于03表):
温度: 设5组梯度→酶液和底物分别保温→混合→记录速率→画曲线→峰值对应的温度为已测条件中的近似最适温度(需缩小梯度范围进一步确定)。不能用H₂O₂做底物(受热自行分解)
pH: 设5组梯度→先调底物pH→加酶→记录→画曲线。温度控制在最适(控制变量)

Experiment C "H₂O₂分解对比"(→验证于03表):
空白(无处理): 极少气泡 / FeCl₃: 少量气泡 / 肝脏研磨液: 大量气泡+木条复燃 → 酶高效性
自变量=催化剂种类; 因变量=产气速度

Experiment D "酵母菌呼吸方式"(→验证于03表):
有氧组: 连续通空气(NaOH除CO₂)→石灰水快速变浑浊+酸性重铬酸钾不变色(无酒精)
无氧组: 密封→石灰水缓慢变浑浊+酸性重铬酸钾变灰绿色(有酒精)
结论: 兼性厌氧——有氧彻底氧化产CO₂+H₂O; 无氧产酒精+CO₂
总光合 = 净光合 + 呼吸(→验证于03表)

Experiment E "打孔叶片浮沉法"(→验证于03表):
原理: 光合产O₂→叶肉间隙充气→浮力增→叶片上浮; 上浮速度∝光合速率
操作: 打孔→注射器抽气(沉底)→不同光照距离的NaHCO₃液→记录上浮数/时间

Experiment F "低温诱导染色体加倍"(→验证于04表):
原理: 低温抑制纺锤体→着丝粒分裂后染色体不能移向两极→加倍(类似秋水仙素)
操作: 根尖→4°C 24h→卡诺固定液(酒精:冰醋酸3:1)→95%酒精冲洗→解离→漂洗→龙胆紫染色→压片→镜检

Experiment G "2,4-D促进生根"(→验证于10表):
设浓度梯度(0/10/50/100/200 mg/L)+空白对照(清水)→等长枝条浸泡→扦插→记录根数根长→依据各浓度组与清水对照组的比较判断促进或抑制→若低浓度组根数多于对照而高浓度组少于对照, 则支持两重性

Section ⑤ "微生物培养与分子操作" (bottom-middle, large module, dark blue header):

Mini-block A "传统发酵三联"(→验证于12表):
果酒: 葡萄(不去皮!)→榨汁→装瓶留1/3空间→水封排气→18-25°C→7-10天
果醋: 在果酒基础上→接种醋酸菌→30-35°C→持续通气(好氧!)。C₂H₅OH+O₂→CH₃COOH+H₂O
泡菜: 洗净切块→装入泡菜坛→倒入煮沸冷却的盐水(质量分数4%-6%)至没过菜料→坛口水封(厌氧)。亚硝酸盐先升后降(3-4天最高)
核心区别: 果酒=无氧+低温; 果醋=有氧+高温; 泡菜=无氧

Mini-block B "微生物纯培养"(→验证于12表):
以酵母菌为例：①配培养基(酵母菌常用PDA或麦芽汁琼脂; 细菌常用牛肉膏蛋白胨/LB培养基; 霉菌常用PDA——按目标微生物选择) → ②高压蒸汽灭菌(121°C, 15-20min) → ③冷至50°C倒平板 → ④接种: 平板划线法(分离单菌落)或稀释涂布法(可计数) → ⑤倒置培养(防冷凝水)→28-30°C
灭菌 vs 消毒: 灭菌杀全部(高压/灼烧); 消毒杀大部分(酒精/煮沸)。培养基要灭菌，手和外植体要消毒

Mini-block C "分解尿素菌分离计数"(→验证于12表):
选择培养基: 尿素为唯一氮源+酚红指示剂 → 梯度稀释(10⁻¹→10⁻⁶) → 取10⁻⁴/10⁻⁵/10⁻⁶各0.1mL涂布(每浓度3重复) → 选30-300菌落的平板计数
鉴定: 菌落周围酚红变红(脲酶分解尿素→NH₃→pH↑)
稀释涂布 vs 平板划线: 前者可计数，后者只能分离

Mini-block D "PCR与电泳"(→验证于12表):
PCR体系: 模板DNA + 引物对 + 4种dNTP + Taq聚合酶 + Mg²⁺缓冲液
三步循环: 变性95°C(氢键断, 非磷酸二酯键) → 退火55-60°C(引物配对) → 延伸72°C(Taq合成) → 循环25-30次, 产物2ⁿ倍
电泳: DNA带负电→负极向正极→小片段跑快→紫外下EB荧光→比marker判断大小

Mini-block E "DNA粗提取与鉴定"(→验证于05表):
材料: 鸡血细胞(哺乳动物成熟红细胞无核不可用!)
步骤: 加蒸馏水涨破细胞→过滤→加NaCl至2mol/L溶解DNA→过滤去不溶蛋白→加蒸馏水稀释NaCl至约0.14mol/L(此浓度DNA溶解度最低)→DNA析出丝状物→再溶于2mol/L NaCl→加95%冷酒精→白色丝状沉淀
鉴定: +二苯胺→沸水浴5min→蓝色

Mini-block F "菊花组织培养"(→验证于12表):
取外植体(幼嫩茎段) → 流水充分冲洗 → 消毒(70%酒精消毒30s→无菌水清洗2-3次→5%次氯酸钠溶液处理30min→无菌水清洗2-3次) → 脱分化(生长素与细胞分裂素比值适中或偏高→暗培养→愈伤组织) → 再分化-生芽(转接至高CK/低生长素培养基→光照→丛芽) → 转接生根(高生长素/低CK培养基→不定根) → 炼苗移栽
激素比值三阶段: 脱分化=生长素/CK适中偏高→诱导愈伤; 生芽=CK/生长素↑→丛芽分化; 生根=生长素/CK↑→不定根形成。三个阶段须分别转接到不同配比的培养基上

Section ⑥ "生态调查与种群统计" (bottom-right, medium module, forest green header):

Mini-block A "酵母菌种群计数"(→验证于11表):
操作: 液体培养基→接种→28°C→每天同时取样(先摇匀!)→血球计数板计数→连续7天
计数方法: 先盖盖玻片再滴入→计数5个中方格(共80个小方格)内菌数→压线计上左不计下右
公式: 密度(个/mL) = (5个中方格总菌数 ÷ 80) × 400 × 10⁴ × 稀释倍数
结果: 先J型增长→S型→K值→营养耗尽后下降

Mini-block B "样方法与标记重捕法"(→验证于11表):
样方法(植物): 随机取样(五点/等距)→划1m×1m→计数(压线计上左不计下右)→密度=总数/总面积→多样方取均值
标记重捕法(动物): N(总量) = 首次标记数M × 重捕数n ÷ 重捕中标记数m

Mini-block C "土壤小动物丰富度"(→验证于11表):
取样器取样(非样方——动物会跑) → 诱虫器收集(趋暗避热→下爬入瓶) → 放大镜/体视镜鉴定 → 记名计算法(种类少)或目测估计法

Mini-block D "生态缸设计"(→验证于11表):
密封+透光(物质不进出, 只有光能输入) → 含生产者(水草)+消费者(小鱼/螺)+分解者(微生物)+非生物环境(水/沙/光) → 避免直射(防高温) → 能否长期维持取决于: ①持续光能输入; ②物质循环完整(生产者/消费者/分解者比例合理); ③初始组分平衡。生态缸的稳定性有条件, 能否维持及维持多久由组成、环境条件和实际观察结果判断

Mini-block E "调查类速记":
遗传病调查(→验证于06表): 选单基因高发病→自然人群随机抽样→足够样本量
自然选择模拟(→验证于07表): 不同色纸片+特定背景→"捕食"→统计存活基因频率→逐代定向变化
抗生素选择(→验证于07表): 含抗生素培养基→涂布→存活菌落转接→逐代耐药性增强→选择已有变异, 非诱导变异

模型与模拟类实验速查:
· 性状分离比模拟(→验证于06表): 单因子(模拟3:1)——两个小桶各含两种彩球(如D和d, 比例1:1, 代表一对等位基因的配子)→每次每桶随机抽1个→记录组合→放回并充分混匀→重复50-100次→统计比例是否接近1:2:1(基因型)或3:1(表现型)。双因子(模拟9:3:3:1)——两个小桶各含四类配子球(YR/Yr/yR/yr各等量, 分别代表父本和母本的配子)→每次从两桶各抽1个配子球→记录子代基因型→放回并充分混匀→重复统计是否接近9:3:3:1
· 减数分裂染色体模型(→验证于04表): 用不同颜色/长度的橡皮泥代表同源染色体→模拟联会、交叉互换、独立分配→理解重组来源
· DNA双螺旋模型(→验证于05表): 用零件拼接碱基对→遵守A-T/G-C配对→直观理解反向平行与螺旋结构
· 真核细胞模型(→验证于02表): 选择材料模拟各细胞器→按实际比例和位置关系组装→理解细胞器分工

其他调查与验证实验速查:
· pH稳定模拟(→验证于08表): 向缓冲液与蒸馏水中分别滴加等量HCl/NaOH→测pH变化→对比: 缓冲液变化小→模拟内环境pH稳态
· 土壤微生物分解实验(→验证于11表): 设灭菌土vs自然土对照→各加等量落叶→相同条件培养→定期比较落叶分解速度→有微生物的自然土分解显著更快
· 能量流动调查(→验证于11表): 选定简单生态系统(如农田)→调查相邻两个营养级在同一时间范围内的同化量(用能量单位)→计算传递效率(10%-20%)→验证能量逐级递减。注意: 单次生物量调查≠同化量, 若仅调查生物量则用于绘制生物量金字塔, 不能直接计算能量传递效率
· 环境状况调查(→验证于11表): 选定区域→用指示生物法(如水中指示生物判断水质等级)或理化检测法(pH/溶解氧/重金属)→评估环境质量→提出保护建议
