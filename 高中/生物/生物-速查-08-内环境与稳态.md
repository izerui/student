Section ① "体液的组成" (top, large hero card, blue header):
Hierarchical diagram:
体液 → 细胞内液(约2/3) + 细胞外液(约1/3)
细胞外液 → 血浆 + 组织液 + 淋巴
三者关系循环图:
- 血浆 ⇌ 组织液(通过毛细血管壁)
- 组织液 → 淋巴(通过毛细淋巴管壁, 单向)
- 淋巴 → 血浆(通过淋巴循环汇入锁骨下静脉)
- 内环境 = 细胞外液 = 细胞直接生活的环境
- 各类细胞的内环境按所在部位判断: 血液中的细胞→血浆; 组织中的细胞→组织液; 淋巴液中的细胞→淋巴。同一种细胞(如淋巴细胞)可随循环出现在不同体液中, 其直接内环境随所在部位而变

Section ② "内环境的理化性质" (middle-left, medium card, teal header):
Three key properties with reference ranges:
- 渗透压: 约770kPa(37°C), 主要由Na⁺/Cl⁻和蛋白质维持
- pH: 血浆7.35~7.45(弱碱性), 缓冲物质: H₂CO₃/NaHCO₃, NaH₂PO₄/Na₂HPO₄
- 温度: 约37°C, 一日内波动不超过1°C

Section ③ "稳态的调节机制" (middle-right, large card, dark green header):
Central concept diagram:
稳态 = 内环境的各种化学成分和理化性质保持相对稳定的状态
调节机制: 神经—体液—免疫 调节网络
- 神经调节: 速度快/精确/持续时间短 (通过反射弧)
- 体液调节: 速度较慢/持续时间长/作用范围广 (通过激素等)
- 免疫调节: 清除异物/病原微生物, 监控自身细胞
三者关系: 神经系统可影响内分泌系统→激素可影响神经系统→免疫细胞可分泌淋巴因子→三者相互协调

Section ④ "组织水肿原因分析" (bottom-left, medium card, crimson header):
组织水肿 = 组织液过多积聚. 四种常见原因:
① 营养不良 → 血浆蛋白合成减少 → 血浆渗透压降低 → 血浆中水分渗出到组织间隙 → 组织液增多
② 花粉过敏 → 毛细血管通透性增大 → 血浆蛋白渗出到组织间隙 → 组织液蛋白质浓度升高, 渗透压升高 → 吸水增多
③ 淋巴回流受阻(如丝虫病/肿瘤压迫) → 组织液不能通过淋巴回收进入血液 → 组织液积聚
④ 肾小球肾炎 → 肾小球滤过蛋白质(蛋白尿) → 血浆蛋白减少 → 同①
共同框架: 组织水肿的本质是组织液生成与回流失衡——①②④通过渗透压变化使组织液生成增多, ③则是回流通路受阻使组织液不能正常回收, 与渗透压无直接关系

Section ⑤ "内环境与外界环境的物质交换" (bottom-right, medium card, orange header):
System integration diagram showing:
外界环境 ↔ 消化系统(营养物质) ↔ 内环境 ↔ 细胞
外界环境 ↔ 呼吸系统(O₂/CO₂) ↔ 内环境
内环境 ↔ 泌尿系统(代谢废物) ↔ 外界环境
内环境 ↔ 循环系统(物质运输) ↔ 全身
Each system has a brief function note.

Section ⑥ "规律" (footer):
• 稳态不是恒定不变, 而是在一定范围内波动(动态平衡)
• 稳态的维持有一定限度, 超过调节能力→稳态失调→疾病
• 内环境稳态是机体进行正常生命活动的必要条件
