Section ① "神经系统与反射弧" (top-left, large card, deep blue header):
神经系统组成:
- 中枢神经系统: 脑(大脑/小脑/脑干) + 脊髓 — 分析综合信息、发出指令
- 外周神经系统: 脑神经(12对) + 脊神经(31对) — 传导信息
神经元(神经细胞)结构:
- 胞体: 含细胞核，是代谢和营养中心
- 树突: 短而多分支，接收信息
- 轴突: 长而少分支(可达1m+)，传出信息，外包髓鞘(绝缘加速传导)
- 突触小体: 轴突末梢膨大部分，含突触小泡(递质)
神经胶质细胞: 数量为神经元的10~50倍，功能: 支持/保护/营养/绝缘(形成髓鞘)，不传导神经冲动

Reflex arc diagram with labels:
感受器 → 传入神经(有神经节) → 神经中枢 → 传出神经 → 效应器
- 反射: 在中枢神经系统参与下, 对刺激做出的规律性应答
- 非条件反射: 先天性/低级中枢(如缩手反射/膝跳反射)
- 条件反射: 后天学习/高级中枢大脑皮层(如望梅止渴/谈虎色变)
- 反射弧是反射的结构基础, 反射弧不完整则反射不能完成

Section ② "兴奋传导与膜电位" (top-right, large card, violet header):
a) 膜电位变化:
- 静息电位: 外正内负 → K⁺通道开放, K⁺顺浓度梯度外流(细胞内K⁺浓度 > 细胞外)
- 动作电位: 外负内正 → 受刺激后Na⁺通道开放, Na⁺顺浓度梯度内流(细胞外Na⁺浓度 > 细胞内)
- 复极化: Na⁺通道关闭, K⁺通道再次开放, K⁺外流, 恢复静息电位

b) 神经纤维上传导:
- 局部电流: 膜外由未兴奋区→兴奋区, 膜内由兴奋区→未兴奋区
- 兴奋传导方向与膜内电流方向一致
- 传导特点: 双向传导(但在反射弧中单向)

c) 突触传递:
突触结构: 突触前膜→突触间隙→突触后膜
- 突触小泡→神经递质(如乙酰胆碱)→突触间隙→与后膜受体结合→兴奋或抑制
- 特点: 单向传递(突触前膜→突触后膜, 因为递质只能由前膜释放、后膜上有受体)
- 神经递质的效应取决于受体和靶细胞类型, 不能仅按递质名称判断兴奋或抑制。如乙酰胆碱: 在骨骼肌神经肌肉接头→兴奋(肌肉收缩), 在心脏→抑制(心率减慢); GABA→中枢抑制性递质

解题导航——兴奋传导方向判断(decision-tree mini-block, 用分支箭头绘制):
刺激某一点后, 哪些部位能检测到电位变化?
├→ 同一条神经纤维上(无突触):
│  └→ 可双向传导 → 刺激点两侧都能检测到
├→ 经过突触:
│  └→ 只能单向传递(突触前膜→突触间隙→突触后膜)
│     ├→ 刺激点在突触前膜侧 → 前后方都能检测到(纤维上双向+突触单向)
│     └→ 刺激点在突触后膜侧 → 只能向后方传导, 不能逆向过突触
└→ 反射弧上:
   ├→ 刺激感受器 → 沿反射弧单向传到效应器(完整反射弧才有反射)
   └→ 刺激传出神经 → 效应器有反应, 但不是反射(不完整弧)

激素调节特点: 微量高效/通过体液运输/作用于靶器官靶细胞

分级调节:
- 大脑皮层: 最高级中枢(语言/思维/感觉/运动)
- 下丘脑: 体温/水盐平衡/血糖等调节中枢; 也是内分泌枢纽(既是神经中枢又能分泌激素)
- 脑干: 呼吸中枢等维持基本生命活动
- 小脑: 维持身体平衡协调运动
- 脊髓: 低级中枢(缩手/排尿/排便等反射)
- 分级调节实例——排尿反射: 婴儿大脑皮层发育不完善→不能控制排尿反射→排尿次数多; 成人大脑皮层控制脊髓排尿中枢→可有意识控制排尿; 高位截瘫患者大脑与脊髓联系中断→排尿再次失控

Section ⑤ "调节实例整合：血糖·体温·水盐" (bottom, wide card, red header):
Three sub-panels side by side:

a) 血糖调节:
- 血糖升高→胰岛B细胞→胰岛素→(促进组织摄取利用+合成糖原+抑制分解)→血糖降低
- 血糖降低→胰岛A细胞→胰高血糖素→(促进糖原分解+非糖物质转化)→血糖升高
- 正常血糖: 3.9~6.1 mmol/L (≈0.70~1.10 g/L; 换算: mmol/L × 0.18 = g/L, 葡萄糖分子量180)
- 拮抗: 胰岛素↔胰高血糖素; 协同: 胰高血糖素+肾上腺素

b) 体温调节: 产热=散热(动态平衡)
- 寒冷→皮肤冷觉感受器→下丘脑体温调节中枢→(皮肤血管收缩+汗腺分泌减少+骨骼肌战栗+甲状腺激素/肾上腺素分泌增多→代谢增强产热增加)
- 炎热→反向调节(血管舒张+汗腺分泌增多→散热增加)

c) 水盐平衡调节:
饮水不足/出汗多/吃咸食 → 血浆渗透压升高 → 下丘脑渗透压感受器兴奋 →
  ① 下丘脑合成, 垂体释放ADH(抗利尿激素)→ 促进肾小管和集合管重吸收水 → 尿量减少 → 血浆渗透压降低(负反馈)
  ② 大脑皮层产生渴觉 → 主动饮水 → 补充水分
饮水过多 → 血浆渗透压降低 → ADH分泌减少 → 尿量增多
Na⁺平衡: 失钠过多 → 醛固酮增多 → 促进肾小管重吸收Na⁺ → 水随Na⁺被动重吸收
注意: ADH是下丘脑合成、垂体释放的; 下丘脑是水盐平衡调节中枢, 大脑皮层产生渴觉(感觉)
