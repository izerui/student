A professional, ultra-dense Chinese educational biology cheat sheet poster titled "生物密码表⑪：种群·群落·生态系统" (Cheat Sheet 11: Population · Community · Ecosystem). Portrait orientation, 3:4 ratio. Scientific illustration style with warm cream background. Central logic: from population to community to ecosystem — local to global, structure to function.

Layout: 7 sections in bento-grid. Top row = population (2 cards side by side). Second row = community (1 wide card). Third row = ecosystem structure + energy/matter/info (2 cards). Fourth row = stability + biodiversity (2 cards). Footer = cross-sheet links.

Section ① "种群的特征与调查" (top-left, medium card, forest green header):
Key characteristics diagram — arrows showing causal links:
- 种群密度(最基本特征)
  调查方法: 样方法(植物/活动能力弱的动物) | 标记重捕法(活动能力强的动物)
  标记重捕法公式: N = (M×n)/m
  (N=总数量, M=标记后放回数, n=第二次捕获总数, m=第二次捕获中标记数)
- 直接决定密度的因素: 出生率与死亡率 / 迁入率与迁出率
- 年龄结构 → 预测未来趋势:
  增长型(金字塔) | 稳定型(柱状) | 衰退型(倒金字塔)
- 性别比例 → 间接影响出生率

Section ② "种群数量变化模型" (top-right, medium card, blue header):
Two growth curves plotted on same axes for comparison:
J型增长: Nₜ = N₀λᵗ (λ>1)
- 条件: 食物充裕 / 空间无限 / 无天敌 / 无疾病 → 理想状态
S型增长: 有K值(环境容纳量)
- K值: 一定环境条件所能维持的种群最大数量, 非固定值(环境变→K变), 不等于某次观测到的最高种群数
- K/2处: 增长速率最大 → 渔业捕捞后维持在K/2, 有害生物防治降低K值
- 种群数量在K值附近波动
影响因素分类:
- 密度制约: 食物/天敌/传染病 → 密度越大影响越强
- 非密度制约: 气候/自然灾害/人类活动 → 与密度无关

Left sub-panel — 群落结构:
- 垂直结构: 分层现象(森林: 乔木层→灌木层→草本层→地被层; 水体: 浮游→中层→底层)
- 水平结构: 镶嵌分布(不同地段种群分布不均匀)
- 种间关系对比mini-table:
  | 关系 | 符号 | 典型例子 |
  | 竞争 | (−/−) | 牛与羊争夺牧草 |
  | 捕食 | (+/−) | 狼与兔 |
  | 互利共生 | (+/+) | 豆科植物与根瘤菌 |
  | 寄生 | (+/−) | 蛔虫与人体 |

Right sub-panel — 群落演替:
- 初生演替(气候条件适宜时的典型过程): 裸岩→地衣→苔藓→草本→灌木→乔木(森林), 时间长; 终态受气候和环境约束, 并非所有群落都必然演替为森林
- 次生演替: 火灾/弃耕后→保留土壤和种子库→演替快
- 人类活动可改变演替方向和速度
- 群落类型与气候:
  赤道→两极: 热带雨林→温带落叶林→针叶林→苔原→冰原(温度递减)
  沿海→内陆: 森林→草原→荒漠(降水递减)

Section ④ "生态系统的结构" (third row left, medium card, teal header):
组成成分:
- 非生物的物质和能量(光/热/水/无机盐)
- 生产者(自养, 植物/化能自养细菌) → 第一营养级
- 消费者(异养) → 第二营养级起
- 分解者(异养, 细菌/真菌) → 不占营养级
营养结构 = 食物链 + 食物网
- 食物链写法: 起点必须是生产者, 不含分解者和非生物
- 营养级: 按食物链位置确定, 同一物种可占不同营养级

Section ⑤ "能量流动·物质循环·信息传递" (third row right, large card, dark green header):
Three parallel sub-panels:

a) 能量流动:
- 起点: 生产者固定的太阳能(总初级生产量)
- 每营养级去向: 呼吸消耗 + 流向下一营养级 + 流向分解者 + 未利用
- 传递效率 = 下一营养级同化量 / 本营养级同化量 × 100% = 10%~20%
- 特点: 单向流动 / 逐级递减 → 能量金字塔永远正立
- 同化量 = 摄入量 − 粪便量 (粪便中能量属上一营养级!)
计算速查(假设各营养级同化量能量密度相同——等能值假设, 实际常用干重或能量值):
- "至少需要多少?" → 最短链 + 最大效率20% (适用于题目允许选择食物链的情况)
- "最多消耗多少?" → 最长链 + 最小效率10% (适用于题目允许选择食物链的情况)
- 若题目已给出各食物来源的比例, 则按比例分别计算再求和
- 例: 草→兔→狐, 狐增重1kg → 至少需草 1÷20%÷20%=25kg, 最多需草 1÷10%÷10%=100kg

解题导航——能量流动计算(decision-tree mini-block, 用分支箭头绘制):
题目问什么?
├→ "至少需要多少生产者" → 选最短食物链 + 最大传递效率(20%)
├→ "最多消耗多少生产者" → 选最长食物链 + 最小传递效率(10%)
├→ 题目已给各食物来源比例 → 按比例分段计算再求和, 不能直接用最短/最长链
└→ 同化量去向分析:
   ├→ 同化量 = 摄入量 − 粪便量(粪便属上一营养级)
   ├→ 同化量 = 呼吸散失 + 流向下一营养级 + 流向分解者 + 未利用
   └→ 传递效率 = 下一营养级同化量 ÷ 本营养级同化量 × 100%

b) 物质循环(以碳循环为例):
- 碳循环完整路径(箭头图):
  CO₂库(大气) →(光合作用)→ 生产者 →(捕食)→ 消费者
  生产者 →(遗体/枯枝落叶)→ 分解者 (直接进入, 不经消费者)
  消费者 →(粪便/遗体)→ 分解者
  生产者 →(呼吸作用)→ CO₂库
  消费者 →(呼吸作用)→ CO₂库
  分解者 →(分解作用/呼吸)→ CO₂库
  化石燃料 →(燃烧)→ CO₂库 → 温室效应
  注: 所有呼吸/分解箭头终点均指向CO₂库(无机环境), 碳在生物群落内以有机物形式传递, 在生物群落与无机环境之间以CO₂形式循环
- 特点: 全球性 / 循环往复(物质可反复利用)
- 能量流动与物质循环: 同时进行 / 相互依存 / 能量驱动物质循环

c) 信息传递:
- 物理信息: 光/声/温度/电(萤火虫发光)
- 化学信息: 信息素/气味(昆虫性外激素)
- 行为信息: 蜜蜂舞蹈/孔雀开屏
- 作用: 调节种间关系 / 维持生态系统稳定

Section ⑥ "稳定性与调节" (bottom-left, medium card, dark brown header):
- 抵抗力稳定性: 抵抗外界干扰保持原状 → 营养结构越复杂越强
- 恢复力稳定性: 被破坏后恢复原状 → 一般与抵抗力负相关(非绝对)
- 自我调节基础: 负反馈调节(草↑→兔↑→草↓→兔↓→草↑…)
- 调节有限度 → 超过自我调节能力→稳定性下降、生态平衡破坏; 严重时恢复困难或耗时很长
- 提高措施: 控制干扰强度 / 适当投入物质能量

Section ⑦ "生物多样性与环境保护" (bottom-right, medium card, amber header):
全球性问题mini-table:
| 问题 | 原因 | 后果 |
| 温室效应 | 化石燃料燃烧→CO₂↑ | 全球变暖/海平面上升 |
| 水体富营养化 | N/P废水 | 水华(淡水)/赤潮(海水) |
| 酸雨 | SO₂/NOₓ | pH<5.6, 腐蚀建筑伤害植物 |
| 臭氧层破坏 | CFCs | 紫外线增强 |
| 生物入侵 | 外来物种缺天敌 | 破坏生态平衡(水葫芦/澳洲兔) |

生物多样性三个层次(并列, 相互联系):
  · 基因多样性(根本基础: 基因突变和重组提供多样性的来源)
  · 物种多样性(最直观的体现, 是保护的关键层次)
  · 生态系统多样性(外在表现: 不同生态系统中生物与环境的组合)
保护措施:
- 就地保护(最有效): 自然保护区
- 迁地保护: 动物园/植物园/种子库
- 法律法规 + 可持续利用
