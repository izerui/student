Section ① "分离定律" (top-left, medium card, green header):
- Pea cross diagram: DD(高茎)×dd(矮茎) → F₁ Dd(高茎) → F₁自交 → F₂ DD:Dd:dd = 1:2:1 (基因型), 高茎:矮茎 = 3:1(表现型)
- 核心内容: 控制同一性状的成对遗传因子在形成配子时彼此分离
- 测交验证: Dd×dd → Dd:dd = 1:1
- 概念框: 显性/隐性/纯合子/杂合子/等位基因
- 判断显隐性四法(小字):
  ① 性状分离法: 相同亲本→后代新性状出现→亲本性状为显性
  ② 杂交法: 不同亲本杂交→F₁只一种性状→该性状为显性
  ③ 自交法: 后代3:1分离→亲本性状为显性，亲本为Aa
  ④ 测交法: Aa×aa→1:1; AA×aa→全显性

Section ③ "伴性遗传" (middle-left, medium card, coral header):
Three genetic modes in parallel columns:
X染色体隐性遗传(X^aX^a / X^aY):
- 典型: 色盲、血友病
- 特征: 男患多于女患, 交叉遗传(母传子), 女患者父必患+儿必患
- 图解: X^BX^b(携带者母) × X^BY(正常父) → X^BX^B : X^BX^b : X^BY : X^bY = 1:1:1:1

X染色体显性遗传(X^AX^A / X^AX^a / X^AY):
- 典型: 抗维生素D佝偻病
- 特征: 女患多于男患; 父亲的致病X必传给女儿(父→女), 儿子的X来自母亲(母→子); 单基因完全外显模型中: 男患者母亲必患, 父亲患病则女儿必患

伴Y遗传:
- 特征: 父→所有儿子→所有孙子，女性永不患病

Section ④ "系谱图判读决策流程" (middle-right, large card, dark red header):
Three-step decision flowchart (核心解题思维链!):

STEP 1 — 判断显隐性:
Decision diamond: "双亲正常→子代患病？"
→ YES → "无中生有为隐性"
→ NO → "双亲患病→子代正常？"
  → YES → "有中生无为显性"
  → NO → 需假设法(先假设显性推导验证，再假设隐性验证)

STEP 2A — 隐性遗传定位(常 vs X):
口诀"隐性看女病"——
Decision diamond: "父亲正常但女儿患病？"
→ YES → 常染色体隐性 [reason: 若X隐，父X^AY正常，女儿必获X^A不可能患病→矛盾]
→ NO → "母亲患病但儿子正常？"
  → YES → 常染色体隐性 [reason: 若X隐，母X^aX^a，儿子必获X^a必患→矛盾]
  → NO → 可能X隐性，也可能常隐性——需更多家系数据或统计分析(不能仅凭一个家系确定)

STEP 2B — 显性遗传定位(常 vs X):
口诀"显性看男病"——
Decision diamond: "父亲患病但女儿正常？"
→ YES → 常染色体显性 [reason: 若X显，父X^AY，女儿必获X^A必患→矛盾]
→ NO → "母亲正常但儿子患病？"
  → YES → 常染色体显性
  → NO → 可能X显性，也可能常显性——需更多数据

Side note — 伴Y遗传判断: 若家系中父→子100%传递且女性无患者→考虑伴Y遗传；若有女性患者或父→子未必传递→排除伴Y。高考常见题型通常限定常染色体或X染色体遗传，伴Y需根据题目条件判断

STEP 3 — 写基因型→算概率:
确定遗传方式 → 标出已知个体基因型 → 用分离定律计算后代概率

Section ⑤ "概率计算技巧" (bottom-left, medium card, orange header):
Four techniques:

技巧一 "分解法(乘法原理)":
适用: 两对或多对基因独立遗传
方法: 分别算每对基因概率 → 相乘
例: AaBb×AaBb → P(A_B_) = 3/4 × 3/4 = 9/16
例: AaBbCc×AaBbCc → P(A_B_cc) = 3/4 × 3/4 × 1/4 = 9/64

技巧二 "条件概率":
问题类型: "已知表现型为XX，求基因型为YY的概率"
公式: P(基因型|表现型) = P(该基因型) / P(该表现型)
例: Aa×Aa后代中，显性个体是杂合子的概率 = (2/4)/(3/4) = 2/3

技巧三 "逆推法":
后代 显:隐=3:1 → 亲本 Aa×Aa
后代 显:隐=1:1 → 亲本 Aa×aa
后代 全显性(样本足够大) → 至少一方AA；若后代数少(如<20)，不能排除Aa×Aa偶然未分离
后代 全隐性 → 双方aa

技巧四 "配子法":
写亲本配子种类及比例 → Punnett square组合 → 统计基因型与表现型比例

Section ⑥ "实验设计方法" (bottom-right, medium card, teal header):
Three experiment design boxes:

实验一 "正反交法——判基因在常染色体还是X非同源区"(候选须已限定为常染色体或X非同源区):
正交: ♀显性纯合 × ♂隐性 → 观察F₁雌雄表型
反交: ♀隐性 × ♂显性(常染色体假设下为纯合子, X染色体假设下为半合子) → 观察F₁雌雄表型
结果相同(F₁雌雄表型一致) → 常染色体; 结果不同(尤其F₁雌雄表现不同) → X染色体
经典: 摩尔根果蝇眼色正反交

实验二 "测交法——判纯合/杂合 & 基因连锁":
· 判纯杂: 待测×隐性纯合 → 后代全显(样本足够大)=纯合(AA); 后代显:隐≈1:1=杂合(Aa)
· 判连锁: F₁(AaBb)×aabb →
  4种≈1:1:1:1 → 两对基因独立遗传(多数位于非同源染色体；但同一染色体上距离很远的基因因交换频率高也可接近独立分配，需结合重组频率进一步判断)
  仅2种亲本型 → 完全连锁(同一对同源染色体)
  4种但亲本型多重组型少 → 不完全连锁(交换率=重组型/总数×100%)
Note: 单次测交比例受样本量影响，需足够大的后代数量才能可靠判断连锁关系

实验三 "自交法——判显隐与基因型":
待测自交 → 后代3:1分离 → 待测为杂合显性(Aa)
待测自交 → 后代无分离(样本足够大) → 待测为纯合(AA或aa)；若后代数少，不能排除杂合偶然未分离
