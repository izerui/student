Section ① "变异三类型" (top-left, large card, red-orange header):
Three sub-panels side by side:

a) 基因突变:
- 概念: DNA分子中碱基的增添/缺失/替换→基因结构改变
- 特点: 普遍性/随机性/不定向性/低频性/大多数有害
- 意义: 新基因产生的唯一途径, 生物变异的根本来源, 为进化提供原材料
- 可遗传变异 vs 不可遗传变异: 遗传物质或其表达状态发生可遗传的改变→可遗传变异; 环境引起的表型变化, 未伴随遗传物质或基因表达状态的可遗传改变→不可遗传变异

b) 基因重组:
- 自由组合型: 减数分裂后期I, 非同源染色体自由组合
- 交叉互换型: 减数分裂前期I, 同源染色体非姐妹染色单体交叉互换
- 意义: 提供极丰富的变异来源(重新组合已有基因, 不产生新基因)
- 基因工程也属于基因重组(人为的)

c) 染色体变异:
- 结构变异: 缺失/重复/倒位/易位 (图示4种类型)
- 数目变异——个别增减: 如21三体综合征(多1条21号)
- 数目变异——成倍增减: 多倍体(秋水仙素处理→抑制纺锤体形成→染色体加倍); 单倍体(含本物种配子染色体数, 花药离体培养获得)
- 多倍体特点: 果实大/营养物质含量高; 单倍体: 二倍体植物产生的单倍体植株通常矮小、高度不育(染色体组减半无法正常联会), 但单倍体生物并非都不育(如雄蜂是正常繁殖的单倍体); 单倍体育种优势: 明显缩短育种年限

解题导航——判断变异类型(decision-tree mini-block, 用分支箭头绘制):
该变异是否可遗传?
├→ 环境引起的表型变化, 未伴随遗传物质或基因表达状态的可遗传改变 → 不可遗传变异(如水肥充足导致植株高大)
└→ 可遗传 → 属于以下哪种?
   ├→ 基因层面——DNA碱基序列改变(增添/缺失/替换, 产生新基因) → 基因突变
   ├→ 染色体层面——结构或数目改变(显微镜可观察):
   │  ├→ 结构改变(缺失/重复/倒位/易位) → 染色体结构变异
   │  └→ 数目改变(整倍/非整倍, 不要求单条DNA序列改变) → 染色体数目变异
   ├→ 已有基因重新组合(各基因碱基序列不变, 组合方式改变):
   │  └→ 减数分裂自由组合(非同源染色体随机分配)/交叉互换/基因工程 → 基因重组
   └→ DNA序列未变但基因表达状态发生可遗传变化 → 表观遗传

Section ② "人类遗传病" (top-right, compact card, purple header):
- 分类: 单基因遗传病(常显/常隐/X显/X隐) / 多基因遗传病(糖尿病/高血压等) / 染色体异常遗传病(21三体/猫叫综合征)
- 调查方法: ①在自然人群中随机调查→统计发病率(选发病率较高的单基因遗传病) ②在患者家系中调查→分析遗传方式(画系谱图→判显隐/判常X)
- 遗传咨询步骤: 确定遗传病类型→分析遗传方式→推算后代患病概率→向咨询者提出建议
- 产前诊断: 羊膜穿刺/B超/基因检测→降低遗传病患儿出生率
- 优生措施: 禁止近亲结婚(提高纯合概率→隐性遗传病发病增加)、遗传咨询、产前诊断

Section ③ "进化证据与自然选择" (middle-left, medium card, deep green header):
Two sub-panels:

a) 进化证据:
- 化石(最直接的证据)
- 比较解剖学(同源器官: 结构相似→共同祖先)
- 胚胎学(早期胚胎相似→亲缘关系)
- 分子生物学(DNA和蛋白质序列比较→越相似亲缘越近)

b) 达尔文自然选择学说 (flow diagram, two inputs converging):
左输入: 遗传变异(已存在的可遗传差异, 突变和重组提供原材料, 不定向)
右输入: 过度繁殖(后代数远超环境容纳量) + 资源空间有限
两组输入并列汇入→ 生存斗争/差异性生存与繁殖(适者生存, 不适者被淘汰) → 种群中有利变异积累
- 变异在先, 选择在后: 变异提供原材料(不定向), 自然选择决定方向(定向)
- 适应是自然选择的结果, 不是生物主动选择的结果

Section ④ "现代进化理论与物种形成" (middle-right, large card, teal header):
A concept map with flow arrows:

核心要点:
- 种群是进化的基本单位(不是个体!)
- 基因频率改变 = 进化(突变和基因重组提供原材料, 自然选择导致基因频率定向改变)
- 隔离导致物种形成

物种形成三环节 (flow diagram):
突变(基因突变+染色体变异) + 基因重组 → 提供进化的原材料(不定向)
↓
自然选择 → 定向改变种群基因频率 → 决定进化方向
↓
隔离 → 物种形成的必要条件

两种隔离:
地理隔离: 同一物种的不同种群被地理障碍分开→基因不能交流→各自独立进化
↓ (长期积累)
生殖隔离: 不同种群间不能自然交配或交配后不能产生可育后代→形成新物种

共同进化(协同进化):
- 不同物种之间/生物与环境之间在相互影响中不断进化和发展
- 实例: 兰花花距与蛾类口器协同加长; 猎豹与羚羊奔跑速度的"军备竞赛"
- 共同进化→导致生物多样性(三个层次, 并列关系): 基因多样性(根本基础)·物种多样性(关键)·生态系统多样性(外在体现)。三者相互联系, 不是单向生成链

Key distinction callout: "进化≠物种形成：基因频率改变即进化，但只有生殖隔离才标志新物种产生"

Section ⑤ "基因频率计算" (bottom-left, medium card, orange header):
Core concept box: "基因频率 = 某基因在种群中出现的次数 / 该基因位点全部等位基因的总次数"

Formula 1 — 直接计算法:
p(A) = (2×AA个体数 + Aa个体数) / (2×种群总个体数)
q(a) = (2×aa个体数 + Aa个体数) / (2×种群总个体数)
恒等式: p + q = 1

Formula 2 — Hardy-Weinberg平衡公式(理想种群):
基因型频率: p²(AA) + 2pq(Aa) + q²(aa) = 1
适用条件(五个): 种群足够大 / 随机交配 / 无突变 / 无自然选择 / 无迁移

Worked example:
"种群中aa个体占16%，求A和a的基因频率及Aa基因型频率"
q² = 0.16 → q(a) = 0.4 → p(A) = 1−0.4 = 0.6
Aa频率 = 2pq = 2×0.6×0.4 = 0.48 = 48%

X染色体基因频率: 男性只有一个X, 直接计基因型频率; 女性两个X, 按常染色体方法

Section ⑥ "育种方法对比与决策" (bottom-right, large card, blue-green header):
Three sub-panels:

a) 五大育种方法对比表:
| | 杂交育种 | 诱变育种 | 单倍体育种 | 多倍体育种 | 基因工程育种 |
|---|---|---|---|---|---|
| 原理 | 基因重组 | 基因突变 | 染色体数目变异 | 染色体数目变异 | 基因重组(定向转移) |
| 方法 | 杂交→自交→选择→纯化(6-7代) | 物理(射线/太空)/化学(亚硝酸)诱变→筛选 | 花药离体培养→秋水仙素加倍(1-2年) | 秋水仙素处理萌发种子或幼苗 | 获取目的基因→构建载体→导入→检测 |
| 优点 | 集中多个优良性状 | 创造新基因新性状 | 明显缩短育种年限 | 器官增大/营养提高 | 定向改造/可跨物种 |
| 缺点 | 周期长(6-7年) | 不定向/有利变异少 | 技术难度大 | 发育延迟/结实率低 | 技术难/费用高/安全争议 |

b) 育种决策树 (flowchart):
"集中已有优良性状" → 是否缩短年限? → NO: 杂交育种 / YES: 单倍体育种
"创造新基因新性状" → 诱变育种
"获取其他物种基因" → 基因工程育种
"增大果实/提高营养" → 多倍体育种

c) 三倍体无籽西瓜 (4-step flow):
①秋水仙素处理二倍体(2n=22)→四倍体(4n=44)
②♀四倍体 × ♂二倍体→种子(胚为3n=33) [必须四倍体作母本]
③种植三倍体→开花(减数分裂联会紊乱→不能形成正常配子→高度不育)
④用二倍体花粉授粉→刺激子房发育→果实无种子
Warning: "二倍体花粉只起刺激作用, 不发生受精!"
Distinction: "无籽西瓜(3n, 染色体变异) ≠ 无籽番茄(2n, 生长素处理, 不是变异)"
