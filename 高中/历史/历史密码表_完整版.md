# 中外历史纲要 · 密码表（一周精通版）

> 核心方法论：历史的底层逻辑是**生产力决定生产关系，经济基础决定上层建筑**。
> 每个朝代/时期的兴衰都围绕三条主线：**制度演进、经济变迁、思想文化**。

---

## 元规律：贯穿全书的六大历史规律

| 规律 | 表现 | 实例 |
|------|------|------|
| **集权-分裂钟摆** | 集权过度→腐败→起义→分裂→再统一 | 秦→汉、隋→唐、元→明 |
| **土地兼并周期律** | 均田/授田→豪强兼并→流民起义→重新洗牌 | 北魏至隋唐均田制最典型；其他朝代中后期土地集中亦常见 |
| **技术-制度耦合** | 新生产力要求新制度匹配，否则社会崩溃 | 铁器→郡县制；工业革命→工厂制度与社会变革 |
| **边疆-中原互动** | 游牧压力推动中原改革，交融促进统一 | 北魏孝文帝、清朝多民族国家 |
| **外力冲击-自救循环** | 外部入侵→被动应对→模仿学习→自主创新 | 鸦片战争→洋务→维新→革命→改革开放 |
| **思想解放先于制度变革** | 每次大变革前必有思想启蒙 | 百家争鸣→秦统一；新文化运动→新民主主义 |

### 【密码表1】先秦：从文明起源到大一统

```
时间轴：170万年前(元谋人) → 1万年前(新石器) → 前2070(夏) → 前1600(商) → 前1046(西周) → 前770(东周=春秋+战国) → 前221(秦统一)
```

| 阶段 | 政治制度 | 经济 | 文化思想 | 底层逻辑 |
|------|---------|------|---------|---------|
| **旧石器** | 原始人群→母系氏族 | 采集渔猎 | 元谋人170万年/北京人70-20万年 | 生产力极低→群居合作 |
| **新石器** | 母系→父系氏族→部落联盟 | 农业/畜牧/陶器 | 仰韶(彩陶/粟)→龙山(黑陶)→良渚(玉器/城墙) | 农业剩余→私有制→阶级分化 |
| **夏**(前2070) | 世袭制取代禅让→最早奴隶制国家 | 农业+手工业 | 二里头遗址 | **公→私的转折点** |
| **商**(前1600) | 内外服制/商王至高 | 青铜文明鼎盛 | **甲骨文**(成熟文字) | 国家机构完善 |
| **西周**(前1046) | **分封制+宗法制** | 井田制(土地国有) | 礼乐文化/青铜铭文 | 血缘纽带维持统治 |
| **春秋**(前770) | 王室衰微/霸主政治/五霸 | 铁器牛耕→生产力革命 | 孔子(仁/礼)/老子(道/无为) | **铁器瓦解井田制→旧制度崩溃** |
| **战国** | 七雄并立/兼并战争 | 土地私有/商品经济繁荣 | **百家争鸣**(儒墨道法) | 新阶级要求新秩序→变法潮流 |

**深层规律**：分封制靠血缘，适用于小规模→铁器使生产力跃升→新兴地主阶级崛起→需要郡县制直接管理→商鞅变法→秦统一

#### 百家争鸣·速查表

| 学派 | 创始人 | 核心主张 | 代表谁的利益 |
|------|--------|--------|-----------|
| **儒家** | 孔子→孟子(仁政/性善)/荀子(性恶/隆礼重法) | 仁/礼/德治/有教无类 | 没落贵族→后被统治者改造 |
| **道家** | 老子→庄子 | 道/无为/辩证法/逍遥 | 隐士/小农 |
| **墨家** | 墨子 | 兼爱/非攻/尚贤/节俭 | 小生产者/下层平民 |
| **法家** | 韩非(集大成者) | 以法为工具管理国家/中央集权 | **新兴地主阶级**→秦采用(商鞅为法家实践者) |

### 【密码表2】秦汉：大一统的建立与巩固

```
秦(前221-前207) → 西汉(前202-9) → 新(9-23) → 东汉(25-220)
```

| 维度 | 秦朝 | 西汉(武帝巅峰) | 东汉 |
|------|------|-------------|------|
| **中央** | 皇帝制+三公九卿 | 设中朝削弱丞相权力，加强皇权 | 尚书台掌权 |
| **地方** | **郡县制**(废分封) | **推恩令**+刺史监察 | 州牧掌军政→军阀 |
| **选官** | 军功爵制 | **察举制** | 察举→门第化 |
| **经济** | 统一度量衡/货币/车轨 | 盐铁官营/均输平准 | 豪强地主庄园 |
| **思想** | 法家+焚书坑儒 | **"罢黜百家，尊崇儒术"** | 经学→谶纬迷信 |
| **对外** | 修长城/北击匈奴/南征百越 | 卫青霍去病破匈奴/**丝绸之路**/西域都护府 | 班超经营西域 |
| **灭亡原因** | 暴政→陈胜吴广起义(前209) | 王莽篡汉(9年) | 外戚宦官交替专权→黄巾起义(184) |

**秦亡教训**：`徭役过重 + 法律严苛 + 焚书坑儒 = 民心尽失` → 汉初吸取教训 → "与民休息"/黄老无为 → 文景之治

**两汉文化速记**：
- 史学：司马迁《史记》(纪传体**通史**鼻祖) / 班固《汉书》(断代史)
- 科技：105年蔡伦改进造纸术 / 《九章算术》/ 《黄帝内经》

### 【密码表4】隋唐：制度创新与盛世巅峰

```
隋(581-618) → 唐(618-907) → 五代十国(907-960)
```

| 维度 | 隋 | 唐(前期盛世) | 唐(后期衰落) |
|------|-----|-----------|-----------|
| **政治** | 统一/隋文帝正式确立三省六部制 | **三省六部制**(中书起草→门下审核→尚书执行) | 宦官专权/藩镇割据 |
| **选官** | 废九品中正/**科举制始** | 科举完善(进士/明经/武举/殿试) | 科举门第之争 |
| **地方** | 大运河(连五水系) | 道→州→县 | **藩镇**尾大不掉 |
| **赋税** | 租调制 | **租庸调制**(庸=以绢布代役) → 780年**两税法**(按资产/夏秋两征) | 两税法破坏 |
| **民族** | 灭陈统一 | "天可汗"/安西北庭都护府/唐蕃和亲 | 安史之乱后内缩 |
| **关键事件** | 大运河/三征高句丽→亡 | 贞观之治/武则天/开元盛世 | **安史之乱**(755) → 黄巢起义 → 907年亡 |

#### 隋唐制度创新·核心对比

| 制度 | 旧制度 | 新制度 | 革命性意义 |
|------|--------|--------|---------|
| 选官 | 九品中正(看门第) | **科举制**(看考试) | 打破门阀垄断，扩大统治基础 |
| 行政 | 三公九卿(职能模糊) | **三省六部**(分权制衡) | 决策-审核-执行分离，效率↑ |
| 赋税 | 租调(按人头) | **两税法**(按资产) | "惟以资产为宗"→减轻人身控制 |

**隋唐文化速记**：
- 诗歌：李白"诗仙"/杜甫"诗圣"/白居易
- 书法：颜真卿/柳公权 ｜ 绘画：吴道子"画圣"

## ═══ Day 2：古代中国·下篇 + 古代世界 ═══

### 【密码表5】宋元：从多政权并立到大一统

```
北宋(960-1127) → 南宋(1127-1279) ‖ 辽(916-1125) / 西夏(1038-1227) / 金(1115-1234) → 元(1271-1368)
```

#### 宋朝制度·核心密码："强干弱枝，崇文抑武"

| 维度 | 措施 | 效果 | 副作用 |
|------|------|------|--------|
| 军权 | 枢密院调兵≠三衙统兵 | 防武将叛乱 | **兵不识将→战斗力差** |
| 行政 | 文官知州/通判监督 | 防地方割据 | 效率低下 |
| 财政 | 转运司收财归中央 | 中央富裕 | 地方无力/冗费 |
| 科举 | 扩大录取/糊名誊录 | 公平选才 | 冗官 |

**结果**：`冗兵+冗官+冗费 → 积贫积弱 → 王安石变法(1069)取得富国成效但强兵效果不明显，未能挽救北宋衰亡 → 靖康之变(1127)`

#### 少数民族政权·制度比较

| 政权 | 民族 | 制度特色 | 与宋关系 |
|------|------|--------|--------|
| **辽** | 契丹/耶律阿保机 | **南北面官制**(南治汉/北治契丹) | 澶渊之盟(兄弟/岁币) |
| **西夏** | 党项/元昊 | 模仿宋制+本族官称 | 称臣/岁赐 |
| **金** | 女真/完颜阿骨打 | **猛安谋克制**(兵农合一) | 灭辽灭北宋 |
| **元** | 蒙古/忽必烈 | **行省制**/宣政院管吐蕃 | 灭南宋统一 |

**元朝密码**：
- 行省制 = 中国**省制的开端**（全国10行省）
- 四等人制 = 蒙古人 > 色目人 > 汉人 > 南人（民族歧视和压迫；元末阶级矛盾日益严重→农民起义→元朝灭亡）
- 澎湖巡检司 = 管辖台湾

#### 宋元经济文化·黄金时代

| 领域 | 突破 |
|------|------|
| **经济重心南移** | **完成**！"苏湖熟，天下足"；南方成赋税重心 |
| 商业革命 | 打破坊市制→夜市/早市；北宋**交子**(世界最早纸币)；海外贸易繁荣(泉州/广州) |
| 理学 | 程颢程颐→**朱熹**集大成 → "存天理灭人欲"/"格物致知" → 1313年定为科举标准 |
| 文学 | **宋词**(苏轼豪放/李清照婉约) → **元曲**(关汉卿/戏曲成熟) |
| 三大发明成熟 | **活字印刷**(毕昇) / **火药**军事化 / **指南针**航海 |
| 科技 | 沈括《梦溪笔谈》/ 郭守敬《授时历》 |
| 社会变化 | 门第观念淡化→"取士不问家世"→平民社会 |
