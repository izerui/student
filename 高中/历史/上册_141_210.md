## 第八单元 中华民族的抗日战争和人民解放战争

### 第22课 从局部抗战到全国抗战

**日本侵华背景**
- 1927年，日本"东方会议"确立侵略中国总方针，把满洲从中国分裂出去
- 1929年世界经济危机→日本急于对外侵略转嫁矛盾

**局部抗战（1931-1937）**
- 1931.9.18：九一八事变，日军占领东北，中国局部抗战开始
- 1932.1.28：一·二八事变，十九路军抗战
- 1932.3：日本扶植溥仪建"伪满洲国"
- 国民政府"攘外必先安内"→不抵抗政策
- 东北人民革命军/抗日联军在白山黑水坚持抗战
- 1935年华北事变→一二·九运动（北平学生），宣传"停止内战，一致抗日"
- 1935.8.1：中共"八一宣言"号召抗日民族统一战线
- 瓦窑堡会议确定建立抗日民族统一战线方针

**西安事变（1936.12.12）**
- 张学良、杨虎城扣留蒋介石，逼蒋抗日
- 中共主张和平解决，周恩来赴西安谈判
- 结果：十年内战基本结束，全国团结抗战局面初步形成

**全国抗战开始（1937）**
- 1937.7.7：卢沟桥事变（七七事变），全国抗战开始
- 洛川会议→中共全面抗战路线
- 红军改编为八路军（朱德、彭德怀）、新四军（叶挺）
- 1937.9.22：国民党发表中共合作抗战宣言→国共第二次合作，抗日民族统一战线正式形成

**日军侵华暴行**
- 1937.12.13：南京大屠杀（屠杀30万人以上）
- 重庆大轰炸（1938-1943）
- 731部队细菌战
- "慰安妇"制度
- 政治："以华制华"→1940汪精卫伪国民政府
- 经济："以战养战"→掠夺资源
- 军事："三光"政策、"治安强化运动"

### 第23课 全民族浴血奋战与抗日战争的胜利

**正面战场**
- 1937.8-11：淞沪会战→粉碎日军"三个月亡华"企图
- 1937.9：平型关大捷（八路军115师，林彪）→全国抗战首胜，打破日军不可战胜神话
- 忻口会战（华北战场规模最大、最激烈）
- 1938.1-5：徐州会战→台儿庄大捷（李宗仁），正面战场最大胜利
- 1938.6-10：武汉会战→抗战以来规模最大，抗战进入战略相持阶段
- 毛泽东发表《论持久战》→科学论证持久作战必胜
- 1941.12：第三次长沙会战胜利（国内外积极影响）

**敌后战场**
- 八路军、新四军建立多个敌后抗日根据地
- 游击战争：地道战、地雷战、夜袭战、麻雀战
- 1940.8-1941.1：百团大战（彭德怀），破袭日军华北交通线，打破日军"囚笼"
- 敌后战场牵制在华日军一半以上兵力，逐渐成为全国抗战主战场

**中共根据地建设**
- 减租减息政策
- 大生产运动
- 精兵简政
- "三三制"选举制度

**皖南事变（1941.1）**
- 国民党顽固派突袭新四军，反共高潮
- 中共坚持抗战、团结、进步方针

**东方主战场**
- 中国战场是世界反法西斯战争东方主战场
- 1942年：中国远征军入缅作战（戴安澜200师）
- 1942初：26国签署《联合国家宣言》
- 1943.11：中美英开罗会议→《开罗宣言》（日本窃取中国领土须归还）
- 中国废除不平等条约，签订新约

**抗日战争的胜利**
- 1945.4-6：中共七大（延安）
  - 政治路线：放手发动群众，壮大人民力量，打败日本侵略者，建立新民主主义中国
  - 确立毛泽东思想为党的指导思想
- 1945.8.6/9：美国投原子弹（广岛、长崎）
- 1945.8.8：苏联对日宣战
- 1945.8.15：日本宣布无条件投降
- 1945.9.2：日本签署投降书→抗战胜利
- 1945.10.25：台湾光复

**抗战胜利意义**
- 近代以来中国抗击外敌入侵的第一次完全胜利
- 重新确立中国大国地位
- 开辟中华民族伟大复兴的光明前景

### 第24课 人民解放战争

**争取和平民主**
- 两种建国方针：中共→联合政府/新民主主义；国民党→独裁/内战
- 1945.8-10：重庆谈判（毛泽东赴重庆）→"双十协定"（坚决避免内战）
- 1946.1.10：政治协商会议（重庆）→通过和平建国纲领等，但国民党六届二中全会否决

**全面内战爆发（1946.6）**
- 国民党围攻中原解放区→全面内战爆发
- 1946.7-10：人民解放军歼敌30万→粉碎全面进攻
- 1947.3：国民党重点进攻陕北、山东→撤出延安转战陕北
- 彭德怀：西北野战军→青化砭、沙家店等战役
- 粟裕/华东野战军→孟良崮歼灭74师

**国民党统治危机**
- 恶性通货膨胀（1948年纸币发行量47万倍于1937年）
- 官僚资本掠夺→民不聊生
- 第二条战线：学生运动（反饥饿、反内战、反迫害）
- 1946.11："国民大会"→《中华民国宪法》（国民党独裁装饰品）

**新民主主义革命的胜利**
- 1947年夏：全国土地会议→《中国土地法大纲》→土地改革→亿万农民翻身解放
- 1947.6：刘邓大军千里跃进大别山→揭开战略进攻序幕

**三大战役（1948.9-1949.1）**
- 辽沈战役（1948.9-11）：歼敌47万→东北全境解放
- 淮海战役（1948.11-1949.1）：歼敌55万→长江中下游以北解放
- 平津战役（1948.11-1949.1）：歼灭改编52万→华北基本解放
- 三大战役共歼灭改编154万→基本摧毁国民党主要军事力量

**七届二中全会（1949.3西柏坡）**
- 工作重心由乡村转向城市
- 毛泽东：保持"两个务必"

**渡江战役（1949.4.21）**
- 百万雄师渡长江→4.23占领南京
- 国民党蒋介石集团反动统治覆灭

**胜利原因**
- 中共代表最广大人民根本利益→群众支持
- 马克思主义普遍原理与中国革命实践相结合
- 毛泽东思想的指导
- 国民党不能解决社会主要矛盾→失去民心

## 第九单元 中华人民共和国成立和社会主义革命与建设

### 第25课 中华人民共和国成立和向社会主义的过渡

**新中国成立**
- 1949.9.21：中国人民政治协商会议第一届全体会议（北平）
  - 通过《中国人民政治协商会议共同纲领》（临时宪法）
  - 国名：中华人民共和国
  - 性质：新民主主义即人民民主主义国家
  - 选举中央人民政府委员会（毛泽东为主席）
- 1949.10.1：开国大典，中华人民共和国成立
- 意义：结束帝国主义、封建主义和官僚资本主义压迫→人民当家作主→开辟新纪元

**巩固人民政权**
- 土地改革：1950年《土地改革法》→到1952年底基本完成→3亿农民获七亿亩土地
- 稳定物价："银元之战""米棉之战"→1950年春物价稳定
- 统一全国财政经济→到1952年国民经济全面恢复
- 抗美援朝（1950.10-1953.7）：
  - 彭德怀率志愿军入朝
  - 英雄：杨根思、黄继光、邱少云、罗盛教
  - 意义：打出国威军威，提高新中国国际地位

**独立自主的和平外交**
- 三大外交方针："另起炉灶""打扫干净屋子再请客""一边倒"
- 1953.12：周恩来提出和平共处五项原则（互相尊重主权和领土完整、互不侵犯、互不干涉内政、平等互利、和平共处）
- 1954.4：日内瓦会议（新中国首次以五大国身份参加）
- 1955.4：万隆会议（亚非会议）→"求同存异"方针

**社会主义基本制度建立**
- 1953年：过渡时期总路线→"一化三改"
- 一五计划（1953-1957）→工业化起步
- 三大改造（农业、手工业、资本主义工商业）→1956年基本完成→社会主义经济制度确立
- 1954.9：一届全国人大→通过《中华人民共和国宪法》（第一部社会主义类型宪法）
  - 根本政治制度：人民代表大会制度
  - 基本政治制度：中共领导的多党合作和政治协商制度、民族区域自治制度

### 第26课 社会主义建设在探索中曲折发展

**全面建设社会主义**
- 1956年：中共八大
  - 主要矛盾：人民对于建立先进工业国的要求同落后农业国现实之间的矛盾
  - 主要任务：集中力量把农业国变为先进工业国
  - 成功探索
- 1956年："百花齐放、百家争鸣"方针
- 1957年：毛泽东提出正确处理人民内部矛盾
- 1964年：三届人大提出"四个现代化"

**"大跃进"和人民公社化运动（1958）**
- "鼓足干劲、力争上游、多快好省"总路线
- 片面追求高速度，忽视客观经济规律
- 1959-1961年：严重经济困难

**调整与恢复**
- 1961年："调整、巩固、充实、提高"八字方针
- 1962年：七千人大会总结经验
- 1962年下半年-1965年：国民经济稳步增长

**"文化大革命"（1966-1976）**
- 毛泽东认为存在资本主义复辟危险→"以阶级斗争为纲"
- 1966年夏全面发动→打、砸、抢
- 1967年"一月风暴"→全面夺权
- 1971.9：林彪反革命集团覆灭
- 1972年：周恩来主持日常工作→批判极左思潮→各项工作转机
- 1975年：邓小平主持整顿→经济好转
- 1976.9：毛泽东逝世
- 1976.10：粉碎"四人帮"→"文化大革命"结束
- 性质：由领导者错误发动、被反革命集团利用的内乱

**伟大建设成就（1949-1978）**
- 工业：建立独立的、比较完整的工业体系和国民经济体系
- 三线建设：改善工业布局、增强国防
- 国防科技：原子弹、氢弹、中远程弹道导弹、人造卫星
- 农业：兴修水利、推广良种→粮食生产水平大幅提高
- 外交：
  - 1971年：恢复联合国合法权利
  - 1972年：中美关系正常化；中日建交
- 英雄模范：雷锋、王进喜、焦裕禄、邓稼先、钱学森、李四光

## 第十单元 改革开放和社会主义现代化建设新时期

### 第27课 中国特色社会主义的开创与发展

**思想准备**
- 1978.5：真理标准问题大讨论→"实践是检验真理的唯一标准"→否定"两个凡是"

**伟大的历史转折——十一届三中全会（1978.12）**
- 停止使用"以阶级斗争为纲"
- 工作重心转移到社会主义现代化建设
- 实行改革开放
- 重新确立思想路线、政治路线、组织路线
- 恢复民主集中制
- 意义：新中国成立以来党的历史上最深远意义的伟大转折

**拨乱反正**
- 平反冤假错案（1980年刘少奇平反）
- 1981.6：十一届六中全会→《关于建国以来党的若干历史问题的决议》
- 1982年：新修改《宪法》

**改革开放进程**
- 农村：家庭联产承包责任制
- 城市：1984年城市经济体制改革全面展开→扩大企业自主权
- 对外开放：
  - 1980年：深圳、珠海、汕头、厦门经济特区
  - 沿海港口城市→沿海经济开放区→上海浦东新区
- 1982年十二大：建设有中国特色的社会主义
- 1987年十三大：社会主义初级阶段理论→"一个中心、两个基本点"→"三步走"战略
- 1992年：邓小平南方谈话→社会主义的本质、计划与市场
- 1992年十四大：建立社会主义市场经济体制
- 1997年十五大：公有制为主体、多种所有制经济共同发展
- 2001年：加入WTO

**中国特色社会主义理论体系**
- 邓小平理论（1997年十五大写入党章→指导思想）
- "三个代表"重要思想（江泽民→2002年十六大确立为指导思想）
- 科学发展观（胡锦涛→2012年十八大确立为指导思想）

### 第28课 改革开放和社会主义现代化建设的巨大成就

**综合国力不断提升**
- 1984-1988：GDP年均增长12.1%
- 1990年"七五"计划超额完成→解决温饱
- 科技：1983年"银河-I"巨型计算机；1988年北京正负电子对撞机
- 1991年：秦山核电站并网发电
- 1999年："神舟一号"→载人航天突破
- 1999年："神威"计算机→打破西方封锁
- 2000年：GDP超10万亿元→"九五"计划超额完成
- 2006年：取消农业税
- 2010年：GDP超40万亿元→世界第二
- 2011年：世界第一电子信息产品制造大国

**重大工程**
- 长江三峡水利枢纽、西电东送、青藏铁路、西气东输
- 863计划（1986年→7个高技术领域）

**"一国两制"与祖国统一**
- 20世纪80年代：邓小平提出"一个国家，两种制度"
- 1984.12 / 1987.4：中英、中葡联合声明
- 1997.7.1：香港回归
- 1999.12.20：澳门回归
- 台湾问题：
  - 1979年：《告台湾同胞书》
  - 1992年："九二共识"（海峡两岸均坚持一个中国）
  - 1993年：汪辜会谈
  - 2005年：《反分裂国家法》
  - 2008年：两岸"三通"
  - 2015年：习近平与马英九新加坡会面（1949年以来首次）

**国际影响力扩大**
- 1978年：《中日和平友好条约》
- 1979年：中美正式建交
- 1989年：中苏关系正常化
- 全方位多层次对外关系新格局
- 上海合作组织
- 中国—东盟自由贸易区
- 金砖国家合作
- 坚决捍卫钓鱼岛主权

## 第十一单元 中国特色社会主义新时代

### 第29课 中国特色社会主义进入新时代

**中共十八大（2012.11）**
- 主线：坚持和发展中国特色社会主义
- "五位一体"总体布局
- "两个一百年"奋斗目标
- 习近平当选总书记，2013.3当选国家主席
- 中国梦：实现中华民族伟大复兴

**"四个全面"战略布局**
- 全面建成小康社会
- 全面深化改革
- 全面依法治国
- 全面从严治党

**中共十九大（2017.10）**
- 主要矛盾转化：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾
- 确立习近平新时代中国特色社会主义思想为指导思想→写入党章
- 2018.3：载入宪法
- 两阶段战略安排：2020-2035基本实现现代化；2035-本世纪中叶建成现代化强国

**2021.11：十九届六中全会**
- 《中共中央关于党的百年奋斗重大成就和历史经验的决议》
- 确立习近平党中央核心地位、习近平新时代中国特色社会主义思想指导地位

**中共二十大（2022.10）**
- 主题：全面建设社会主义现代化国家
- 向第二个百年奋斗目标进军
- 2023.3：习近平当选国家主席

### 第30课 新时代中国特色社会主义的伟大成就

**全面建成小康社会**
- 2013年：提出"精准扶贫"
- 2020.11：最后九个贫困县脱贫→832个贫困县全部摘帽
- 2021.2：全国脱贫攻坚总结表彰大会→全面胜利
- 实现第一个百年奋斗目标

**综合国力显著提升**
- 2021年GDP达114万亿元→世界第二（占世界18.5%）
- 高铁运营4.2万千米→世界首位
- 高速公路17万千米→世界首位
- 科技：载人航天、探月探火、深海深地探测、超级计算机
- 全社会研发经费2.8万亿元→世界第二
- 国防：国产航母、核潜艇、歼-20、运-20
- 人均预期寿命78.2岁
- 世界规模最大社会保障体系和医疗卫生体系

**全面依法治国**
- 2020.5：《中华人民共和国民法典》（新中国第一部法典化法律）

**应对风险挑战**
- 2018年以来：中美经贸摩擦→坚定维护自身合法利益
- 2019年：香港"修例风波"→2020《港区国安法》→由乱到治
- 台湾问题：坚决反对"台独"，2015年"习马会"
- 2020年：新冠疫情→人民至上、生命至上→抗疫精神

**中国特色大国外交**
- 2013年：习近平提出人类命运共同体理念
- "一带一路"倡议→150多个国家签署合作文件
- 全球发展倡议、全球安全倡议、全球文明倡议
- 2023.3：与182个国家建交

## 活动课 家国情怀与统一多民族国家的演进

- 核心主题：多民族共存、共同发展→中华民族多元一体格局
