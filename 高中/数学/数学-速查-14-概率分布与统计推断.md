Section ① "概率基础" (top-left, medium module, dark blue header):
Core concepts with compact notation:

样本空间与事件:
  Ω = 所有可能结果的集合（样本空间）
  A ⊆ Ω 是一个事件
  ∅ = 不可能事件, Ω = 必然事件

Two model boxes side by side:
  古典概型 box (blue border):
    条件: ①Ω有限 ②等可能
    P(A) = |A| / |Ω| = 事件A包含的基本事件数 / 总基本事件数

  几何概型 box (green border):
    条件: ①Ω可度量(长度/面积/体积) ②等可能(均匀分布)
    P(A) = μ(A) / μ(Ω) （μ表示度量）

事件关系矩阵 (4 rows):
  互斥: A∩B=∅ → P(A∪B)=P(A)+P(B)
  对立: Ā=Ω\A → P(Ā)=1−P(A) ← 对立必互斥，互斥未必对立
  独立: P(A∩B)=P(A)·P(B) ← A发生不影响B的概率
  一般: P(A∪B)=P(A)+P(B)−P(A∩B)

⚠️ 易错: "互斥"与"独立"不同! 互斥是A∩B=∅(不能同时发生, 推出P(AB)=0; ⚠️在连续分布中P(AB)=0不等于互斥, 因为非空交集也可能概率为0)；独立是P(AB)=P(A)P(B)(互不影响)。两事件既互斥又独立 ⟹ 至少一个概率为0。

Section ② "条件概率与全概率" (top-right, medium module, teal header):
条件概率 definition in box:
  P(B|A) = P(AB) / P(A), 其中P(A)>0
  含义: "已知A发生的条件下B发生的概率"

乘法公式:
  P(AB) = P(A) · P(B|A) = P(B) · P(A|B)

全概率公式 (with visual tree diagram):
  若 A₁, A₂, …, Aₙ 是Ω的一个完备事件组(两两互斥且并为Ω), 则:
  P(B) = Σᵢ P(Aᵢ) · P(B|Aᵢ)

  Draw a probability tree diagram showing:
    Root node → Branch A₁ (prob P(A₁)) → Branch B|A₁ (prob P(B|A₁)) → Leaf: P(A₁)·P(B|A₁)
    Root node → Branch A₂ (prob P(A₂)) → Branch B|A₂ (prob P(B|A₂)) → Leaf: P(A₂)·P(B|A₂)
    Root node → Branch A₃ (prob P(A₃)) → ... → ...
    Sum of all leaves = P(B)

独立性与条件概率:
  若A,B独立 → P(B|A)=P(B), P(A|B)=P(A)
  独立性传递: 若A,B独立 → A与B̄独立, Ā与B独立, Ā与B̄独立

Section ②b "概率与统计审题导航" (compact sub-module between Sections ② and ③, full width, yellow-green header bar labeled "拿到概率统计题第一步: 识别模型"):

概率题型导航 → 第一步: 识别概率模型
├─ 有限等可能 → 古典概型: P=有利/全部 → 关键是正确计数(→链接密码表13)
├─ 几何区域(长度/面积/体积) → 几何概型: P=目标区域/总区域
├─ n次独立重复试验 → 二项分布 B(n,p): 直接套公式
├─ 不放回抽样 → 超几何分布: 用组合数公式
├─ 多阶段/分步进行 → 画概率树: 每个分支标概率, 路径概率=各段相乘, 总概率=各路径相加
├─ "至少一个"/"至多" → 补集法: P(至少1个)=1−P(一个都没有)
├─ "已知A发生求B" → 条件概率: P(B|A)=P(AB)/P(A)
│    ⚠️ 先分清谁是条件(A)谁是目标事件(B), 别搞反!
├─ 互斥 vs 独立 → ⚠️ 最易混淆!
│    互斥: A,B不能同时发生 → P(A∪B)=P(A)+P(B), 但P(AB)=0
│    独立: A,B互不影响 → P(AB)=P(A)·P(B)
│    ⚠️ 互斥(P>0)的两个事件一定不独立! (独立要求P(AB)=P(A)P(B)>0, 但互斥P(AB)=0)
└─ 求E(X)/D(X) → 先列完整分布列(检查ΣP=1), 再套公式; 或识别出已知分布直接用公式

统计题导航:
├─ 看图读数据 → 频率分布直方图: 纵轴是频率/组距, 面积=频率! | 茎叶图: 直接读数
├─ 估计参数 → 用样本均值x̄估计总体均值μ, 用样本方差s²估计总体方差σ²
├─ 线性回归 → 四步: ①算x̄,ȳ ②算b̂ ③â=ȳ−b̂x̄ ④写ŷ=b̂x+â ⚠️回归直线必过(x̄,ȳ)
├─ 独立性检验 → 列四格表 → 算χ² → 比临界值(3.841/6.635/10.828) → 判断关联
└─ ⚠️ 统计结论是概率性的! "有95%把握认为有关联" ≠ "确定有关联"

    意义: 衡量X取值的离散(波动)程度

  标准差: σ(X) = √D(X)

  BOTTOM sub-row — 线性变换性质 (compact, boxed):

Section ④ "重要分布" (below Section③, two columns side by side):

LEFT COLUMN "离散型分布" (medium module, blue header):
  Sub-block ④a "二项分布 X~B(n,p)" with light blue background:
    场景: n次独立重复试验(伯努利试验)，每次成功概率p
    P(X=k) = Cₙᵏ pᵏ (1−p)ⁿ⁻ᵏ, k=0,1,…,n
    E(X) = np
    D(X) = np(1−p)
    特例: n=1 → 0-1分布(伯努利分布)

  Sub-block ④b "超几何分布" with light green background:
    场景: N件产品中M件次品，不放回取n件，X=取到的次品数
    P(X=k) = C_M^k · C_{N-M}^{n-k} / C_N^n
    E(X) = nM/N
    ⚠️ 超几何vs二项: 不放回→超几何 / 放回(或独立)→二项
    当N≫n时: 超几何分布 ≈ 二项分布(取走的比例可忽略)

RIGHT COLUMN "连续型分布" (medium module, red header):
  Sub-block ④c "正态分布 X~N(μ, σ²)" with light pink background:
    Draw a bell curve (normal distribution curve) centered at x=μ:
    - The curve is symmetric about x=μ (draw a vertical dashed line at μ)
    - Mark μ−3σ, μ−2σ, μ−σ, μ, μ+σ, μ+2σ, μ+3σ on the x-axis
    - Shade regions with labels:
      P(μ−σ < X < μ+σ) ≈ 68.27%
      P(μ−2σ < X < μ+2σ) ≈ 95.45%
      P(μ−3σ < X < μ+3σ) ≈ 99.73%
    - Note: σ越小 → 曲线越尖瘦(数据越集中) / σ越大 → 曲线越矮胖(数据越分散)
    标准化: Z = (X−μ)/σ ~ N(0,1)
    Symmetry: P(X<μ−a) = P(X>μ+a) = 1−Φ((μ+a−μ)/σ)

  Deep insight box (老教材扩展·概率论基础):
    大数定律(伯努利): 频率→概率(n→∞时频率收敛于概率)
    中心极限定理: 独立同分布, 均值μ, 方差0<σ²<∞时, (ΣXᵢ−nμ)/(σ√n) → N(0,1) (n→∞)
    Why正态分布无处不在? 因为现实中的随机量往往是大量微小独立因素叠加的结果

Section ⑤ "统计推断" (bottom, full-width module, dark green header):

Sub-area ⑤a "抽样与数据描述" (left third):
  抽样方法三种:
    简单随机抽样: 抽签法/随机数法，总体N不太大

    均值 x̄ = (Σxᵢ)/n
    中位数: 排序后中间值(偶数取中间两个平均)
    众数: 出现次数最多的值
    方差 s² = Σ(xᵢ−x̄)²/n
    标准差 s = √s²
    极差 = max−min

Sub-area ⑤b "一元线性回归" (middle third):
  Model: ŷ = b̂x + â
  Formulas in box:
    b̂ = [Σᵢxᵢyᵢ − nx̄ȳ] / [Σᵢxᵢ² − nx̄²] = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
    â = ȳ − b̂x̄
  Key property: 回归直线必过样本中心点 (x̄, ȳ)
  相关系数:
    r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)² · Σ(yᵢ−ȳ)²]
    |r| 越接近1 → 线性相关性越强
    |r| > 0.75 通常认为强相关
  残差分析: 残差 eᵢ = yᵢ − ŷᵢ，残差图中点应随机分布

Sub-area ⑤c "独立性检验" (right third):
  四格表 (2×2 contingency table):
  |        | 类别1 | 类别2 | 合计   |
  |--------|-------|-------|--------|
  | 条件1  |   a   |   b   | a+b    |
  | 条件2  |   c   |   d   | c+d    |
  | 合计   |  a+c  |  b+d  | n=a+b+c+d |

  χ² statistic formula:
    χ² = n(ad−bc)² / [(a+b)(c+d)(a+c)(b+d)]

  Decision: χ² > 临界值 → 拒绝"两变量独立"的假设 → 认为两变量有关联

  临界值表:
    α=0.05 → χ₀² = 3.841 (95%置信度)
    α=0.01 → χ₀² = 6.635 (99%置信度)
    α=0.001 → χ₀² = 10.828 (99.9%置信度)

  ⚠️ 注意: 独立性检验只能给出统计上的关联证据，不能证明因果关系
