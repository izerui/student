排列组合题型导航 → 审题关键词决定方法:

Section ② "排列与组合" (middle-left, large module, green header):
Two sub-blocks stacked vertically:

Sub-block "排列（有序选取）" with teal background:
  Definition: 从n个不同元素中取出m个(m≤n)，按一定顺序排成一列
  Formula: Aₙᵐ = n!/(n−m)! = n(n−1)(n−2)⋯(n−m+1)
  Special case: 全排列 Aₙⁿ = n!
  Convention: 0! = 1

Sub-block "组合（无序选取）" with olive background:
  Definition: 从n个不同元素中取出m个(m≤n)，组成一组(不论顺序)
  Formula: Cₙᵐ = Aₙᵐ / m! = n! / [m!(n−m)!]

Decision box with bold border:
  "是否关心取出顺序？" → 是 → 排列 Aₙᵐ / 否 → 组合 Cₙᵐ

组合数重要性质 (numbered list):
  ① Cₙᵐ = Cₙⁿ⁻ᵐ （对称性：取m个 ↔ 留n−m个）
  ② Cₙᵐ = Cₙ₋₁ᵐ⁻¹ + Cₙ₋₁ᵐ （帕斯卡/杨辉递推：取或不取某特定元素）
  ③ Cₙ⁰ + Cₙ¹ + ⋯ + Cₙⁿ = 2ⁿ （n元素集合的子集总数）
  ④ Cₙ¹ + Cₙ³ + ⋯ = Cₙ⁰ + Cₙ² + ⋯ = 2ⁿ⁻¹ （奇偶项之和相等）

Section ③ "经典计数模型" (middle-right, medium module, orange header):
Six models listed with icon + one-line description + formula/method:

🔗 捆绑法（相邻问题）：
  要求某些元素相邻 → 将相邻元素捆绑为一个"超元素" → 整体排列 × 内部排列
  Example: 5人站一排，甲乙必须相邻 → 把甲乙捆绑 → A₄⁴ × A₂² = 48

🪟 插空法（不相邻问题）：
  要求某些元素不相邻 → 先排其余元素 → 在形成的空隙中选位插入
  Example: 5人站一排，甲乙不相邻 → 先排其余3人A₃³ → 4个空隙中选2个插入A₄² → 3!×A₄²=72

📏 隔板法（相同球分盒）：
  n个相同球放入k个不同盒，每盒至少1个
  方法：n个球排成一排形成n−1个间隙 → 插入k−1块隔板
  Formula: Cₙ₋₁ᵏ⁻¹

🔄 容斥原理：
  |A∪B| = |A| + |B| − |A∩B|
  三集合: |A∪B∪C| = |A|+|B|+|C|−|A∩B|−|A∩C|−|B∩C|+|A∩B∩C|

🎭 错位排列（老教材·代数甲种本第三册）：
  n个元素的全排列中，每个元素都不在原来位置上的排列数
  Dₙ = n! × [1 − 1/1! + 1/2! − 1/3! + ⋯ + (−1)ⁿ/n!]
  D₁=0, D₂=1, D₃=2, D₄=9, D₅=44
  递推: Dₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂)
  When n→∞: Dₙ/n! → 1/e ≈ 0.3679（与自然常数e的深刻联系）

🏷️ 多重集排列（老教材扩展）：
  n个元素中有n₁个相同的，n₂个相同的，…，nₖ个相同的
  排列数 = n! / (n₁!·n₂!·⋯·nₖ!)
  Example: MISSISSIPPI 的排列数 = 11!/(4!·4!·2!·1!) = 34650
