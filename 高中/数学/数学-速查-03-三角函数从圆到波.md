Part B — "诱导公式" with a highlighted rule box:
Core rule in a colored callout box: "奇变偶不变，符号看象限"
Meaning: for functions of kπ/2 ± α — if k is odd, sin↔cos swap; if k is even, function name unchanged. The sign is determined by treating α as an acute angle and checking the sign of the ORIGINAL function in that quadrant.

Concrete formulas listed in two columns:
Left column (偶数k, function unchanged):
sin(π − α) = sinα          cos(π − α) = −cosα
sin(π + α) = −sinα         cos(π + α) = −cosα
sin(−α) = −sinα            cos(−α) = cosα
sin(2π − α) = −sinα        cos(2π − α) = cosα

Right column (奇数k, sin↔cos swap):
sin(π/2 − α) = cosα        cos(π/2 − α) = sinα
sin(π/2 + α) = cosα        cos(π/2 + α) = −sinα
sin(3π/2 − α) = −cosα      cos(3π/2 − α) = −sinα

Section ④b "三角函数题型导航" (inside Section ④ right side or as a sub-block, highlighted with yellow-green background):
A DECISION TREE titled "拿到三角函数题 → 先看要求什么":

Branch A — 化简/求值:
  ├─ 含 sin²α, cos²α, sinαcosα → 用sin²+cos²=1 或 倍角降幂(cos2α=1−2sin²α)
  ├─ 含 sin(α±β), cos(α±β) → 展开或逆用合并 (→链接04表公式网络)
  ├─ 含 asinx+bcosx → 辅助角公式 = √(a²+b²)sin(x+φ) (→链接04表)
  ├─ 含 sinα+cosα 与 sinαcosα → 设t=sinα+cosα → sinαcosα=(t²−1)/2, t∈[−√2,√2]
  └─ 已知一个三角函数值求其余 → sin²+cos²=1 联合 tanα=sinα/cosα, ⚠️注意象限定正负

Branch B — 图象与性质:
  ├─ 求值域/最值 → 先化成 y=Asin(ωx+φ)+k → 完整周期时值域 [k−|A|, k+|A|]; ⚠️受限区间须求sin在该区间的实际值域, 如sinx在[0,π/6]上值域为[0,1/2]
  ├─ 求周期 → 找ω → T=2π/ω
  ├─ 求单调区间 → 对sinx递增: 解 −π/2+2kπ ≤ ωx+φ ≤ π/2+2kπ 得x范围
  ├─ 由图象求参数(反推) →
  │    A = (最大值−最小值)/2
  │    k = (最大值+最小值)/2
  │    ω: 从图上读周期T → ω=2π/T
  │    φ: 代入一个已知点(最高点/零点等)解方程, ⚠️注意φ范围约束(如|φ|<π)
  └─ 比较大小 → 用诱导公式统一成同名同角函数 → 用单调性比较
