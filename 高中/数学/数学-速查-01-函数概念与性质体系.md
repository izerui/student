Section ② "四性质判定体系" (middle, core module spanning full width, emerald green header, occupying ~30% height):
This is the CENTRAL THINKING MODEL — a four-column comparison matrix with a relationship diagram.

The matrix (4 columns, each a colored vertical card):

Column 1 (blue card) — "单调性":
  定义: "在区间D上, ∀x₁<x₂, f(x₁)<f(x₂) → f在D上递增"
  判定方法:
    ① 定义法: 取x₁<x₂ → 算f(x₁)-f(x₂) → 判符号
    ② 导数法: f'(x)>0 ⟹ 递增; f'(x)<0 ⟹ 递减 (→ 详见密码表05)
    ③ 复合函数: "同增异减" (内外层同调→增, 异调→减)
  图象: Small sketch of an increasing curve with upward arrow, and a decreasing curve with downward arrow

Column 2 (red card) — "奇偶性":
  定义: "奇函数 f(-x) = -f(x); 偶函数 f(-x) = f(x)"
  判定方法:
    前提: 定义域必须关于原点对称! (否则非奇非偶)
    ① 验证 f(-x) 与 f(x) 的关系
    ② f(-x)+f(x)=0 → 奇; f(-x)-f(x)=0 → 偶
  图象: 奇函数 → 关于原点中心对称; 偶函数 → 关于y轴轴对称
  Important properties:
    • 奇函数若x=0在定义域内 → f(0)=0 (必过原点)
    • 奇×奇=偶; 偶×偶=偶; 奇×偶=奇

Column 3 (purple card) — "周期性":
  定义: "∃T>0, ∀x∈D, f(x+T)=f(x) → f以T为周期"
  最小正周期: 满足条件的最小T
  常见推导 (以下均要求 a≠0, T取正值):
    f(x+a) = -f(x) → T=2|a|
    f(x+a) = 1/f(x) → T=2|a| (需f(x)≠0)
    f(x+a) = f(x+b) → T=|b-a| (当a≠b)
  ⚠️ 偶函数关于x=0对称, 但不产生周期性(如x²); 只有关于x=a(a≠0)对称才可能推出周期
  图象: 图象每隔T重复

Column 4 (orange card) — "对称性":
  轴对称: f(a+x) = f(a-x) → 图象关于直线x=a对称
  中心对称: f(a+x) + f(a-x) = 2b → 图象关于点(a,b)中心对称
  特殊情形:
    f(x) = f(-x) 即 偶函数 → 关于x=0(y轴)对称
    f(x) + f(-x) = 0 即 奇函数 → 关于原点(0,0)中心对称

Below the four columns, a horizontal "性质联系网" strip:
  Connecting arrows between columns:
  奇函数 + 偶函数 → f(x)≡0 (恒为零)
  奇函数 + 关于x=a对称 → 周期T=4|a| (a≠0)
  偶函数 + 关于x=a对称 → 周期T=2|a| (a≠0; a=0时是原有对称性, 不产生周期)
  单调性 + 奇偶性 → 奇函数在对称区间上单调性相同; 偶函数在对称区间上单调性相反

Section ③ "值域求法——解题导航" (bottom-left, medium module occupying ~20% height and 45% width, teal header):

A DECISION TREE flowchart titled "求f(x)的值域 → 先看函数类型" with branches:
  ├─ 一次函数/反比例 → 直接由定义域确定(端点代入, 注意开闭)
  ├─ 二次函数 → 配方法: y=a(x−h)²+k
  │    ├─ 定义域为ℝ → 只有最小值k(a>0)或最大值k(a<0), 值域半无穷
  │    ├─ 定义域为有限闭区间[m,n] → ⚠️ 先判断顶点x=−b/(2a)是否落在[m,n]内: 在内则比较顶点值与端点值f(m),f(n); 不在内则函数在[m,n]上单调, 只比较两端点值
  │    └─ 开区间或半无穷 → ⚠️ 端点处函数值可能取不到, 须用开/闭区间写值域
  ├─ 一次分式 y=(ax+b)/(cx+d) → 反解法: 解x=(dy−b)/(a−cy), 令分母a−cy≠0 → 排除y=a/c
  │    ⚠️ 前提: c≠0 且 ad−bc≠0(否则分式可约, 如(x+1)/(x+1)值域为{1}, 恰好是被"排除"的值); 还须确认所得x在原定义域内
  ├─ 二次分式 → 判别式法: 交叉相乘整理为关于x的方程, Δ≥0 求y范围
  │    ⚠️ 须检查: ①交叉相乘后是否降次(二次项系数为0时另行处理) ②所得x是否在原定义域内(排除增根)
  ├─ 含根号 → 换元法: 令t=√(...)≥0, 化为t的函数再求值域
  ├─ 含三角函数(可化成正弦型) → 化成 Asin(ωx+φ)+k → 值域 [k−|A|, k+|A|] (→链接03表)
  │    ⚠️ 定义域覆盖完整周期时值域为[k−|A|, k+|A|](充分条件); 未覆盖完整周期时须求sin(ωx+φ)在受限区间上的实际值域(如sinx在[−π/2,π/2]上取遍[−1,1], 只有半个周期). 不可化成正弦型的(如tanx, sinx+sin2x)须另行分析
  ├─ 复合函数 → 由内层到外层逐层传递值域
  └─ 以上都不适合 → 导数法: 求f'(x)=0找极值, 比较极值与端点值 (→链接05表)

Worked example box at bottom (light blue):
  例: 求 y = (x²+1)/(x²-1) 的值域 (x≠±1) → 属于"二次分式" → 走判别式法
  设 y = (x²+1)/(x²-1), 则 yx²-y = x²+1, (y-1)x² = y+1
  当y≠1: x² = (y+1)/(y-1) ≥ 0 → (y+1)/(y-1) ≥ 0 → y>1 或 y≤-1
  验证y=1: 代入得0=2矛盾, y≠1
  ∴ 值域为 (-∞, -1] ∪ (1, +∞)

Section ④ "函数与方程·零点——解题导航" (bottom-middle, medium module occupying ~20% height and 30% width, dark red header):

A DECISION TREE at the top of this section titled "零点/交点问题 → 先判断类型":
  ├─ 求具体零点 → 令f(x)=0, 直接解方程(因式分解/公式/换元)
  ├─ 判断零点个数 → 数形结合: 画y=f(x)图象, 数与x轴交点
  │    (或化为 y=g(x) 与 y=h(x) 的交点个数)
  ├─ 证明零点存在 → 零点存在定理: 找a,b使f(a)·f(b)<0
  ├─ 求零点所在区间 → 逐段检验符号变化(代入整数点试探)
  └─ 含参问题(零点个数随参数变化) → 画含参函数图象, 观察临界值
      (→ 链接05表导数分析)

Below the decision tree:
Key definitions:
  零点: 使f(x₀)=0的x₀ ⟺ y=f(x)图象与x轴的交点横坐标
  ⟺ 方程f(x)=0的实数根

零点存在定理 (boxed, important):
  "若f(x)在[a,b]上连续, 且f(a)·f(b)<0, 则∃ξ∈(a,b)使f(ξ)=0"
  Small diagram: a curve crossing x-axis between a and b, with f(a)>0 and f(b)<0 marked

二分法步骤:
  ① 确认f(a)·f(b)<0
  ② 取中点m=(a+b)/2, 算f(m)
  ③ f(m)=0 → 找到零点; f(a)·f(m)<0 → 零点在(a,m); f(m)·f(b)<0 → 零点在(m,b)
  ④ 重复直到精度满足

Old textbook callout: "老教材·连续函数中间值定理: 若f连续且f(a)≠f(b), 则f取遍f(a)与f(b)之间的一切值——零点存在定理是其特例"

零点个数判断: "数形结合: 画y=f(x)图象, 数与x轴交点个数; 或化为y=g(x)与y=h(x)的交点个数"

Section ⑤ "函数图象变换" (bottom-right, medium module occupying ~18% height and 25% width, violet header):

Three transformation types, each with a before→after description:

平移变换:
  y=f(x) → y=f(x-h): 图象向右平移h个单位 (h>0)
  y=f(x) → y=f(x)+k: 图象向上平移k个单位 (k>0)
  口诀: "左加右减, 上加下减"

对称变换:
  y=f(-x): 关于y轴对称 (x换-x)
  y=-f(x): 关于x轴对称 (y换-y)
  y=f(|x|): 保留x≥0部分, 关于y轴对称翻折 (偶化)
  y=|f(x)|: x轴下方部分翻折到上方

伸缩变换:
  y=f(ωx): 横坐标÷ω (ω>1压缩, 0<ω<1拉伸)
  y=Af(x): 纵坐标×A (A>1拉伸, 0<A<1压缩)

Note: "变换顺序影响结果! 一般先平移后伸缩, 或统一用'先化为标准形式'再读参数"
