  TOP node (red box):      a² + b²    (平方和)
  LEFT node (blue box):    a + b      (和)
  RIGHT node (green box):  ab         (积)
  BOTTOM node (orange box): 1/a + 1/b (倒数和)
  CENTER-LEFT (gray box):  (a − b)²   (差的平方)

Edges (arrows with formulas — each edge is a labeled directed arrow or double arrow):

  a+b ←→ a²+b²:  恒等式 a²+b² = (a+b)² − 2ab
                   不等式 a²+b² ≥ (a+b)²/2, 等号a=b

  a+b ←→ ab:     核心! a+b ≥ 2√(ab), 等号a=b
                   即: 知和求积(↓) ab ≤ (a+b)²/4 → 积最大
                       知积求和(↑) a+b ≥ 2√(ab) → 和最小

  a²+b² ←→ ab:   a²+b² ≥ 2ab, 等号a=b

  a+b ←→ 1/a+1/b: 恒等式 1/a+1/b = (a+b)/(ab)
                    不等式 (a+b)(1/a+1/b) ≥ 4, 等号a=b

  ab ←→ 1/a+1/b:  1/a+1/b = (a+b)/(ab) ≥ 2√(ab)/(ab) = 2/√(ab)

  a+b ←→ (a−b)²:  恒等式 (a−b)² = (a+b)² − 4ab

A prominent callout box next to the network labeled "导航规则":
  和固定 → 积有上界(积最大): ab ≤ (a+b)²/4, 等号a=b
  积固定 → 和有下界(和最小): a+b ≥ 2√(ab), 等号a=b
  解题第一步: ①识别哪个量是定值(和定还是积定?) ②目标量是什么? ③沿网络找对应的不等式 ④检验等号能否取到

Below the network, a highlighted box "使用三条件 一正二定三相等":
① 正: a, b 同号为正 (保证√(ab)有意义)
② 定: 和(a+b)或积(ab)有一个为定值 (才能用不等式求另一个的界)
③ 等: 等号可以取到 (存在使 a=b 的取值, 否则只有界没有最值)

Left bottom of this section, a compact table of 8 basic properties of inequalities:
① 对称性: a > b ⟺ b < a
② 传递性: a > b, b > c → a > c
③ 可加性: a > b → a + c > b + c
④ 同向可加: a > b, c > d → a + c > b + d
⑤ 正数可乘: a > b, c > 0 → ac > bc; c < 0 → ac < bc (变号!)
⑥ 同向正数可乘: a > b > 0, c > d > 0 → ac > bd
⑦ 正数乘方: a > b > 0 → aⁿ > bⁿ (n∈ℕ, n≥2)
⑧ 正数开方: a > b > 0 → ⁿ√a > ⁿ√b (n∈ℕ, n≥2)

Section ② "基本不等式变形技巧——网络导航实战" (middle, full width, large module, green header):
A numbered grid of 9 technique cards arranged in a 3×3 layout. Each card shows: technique name, which NETWORK PATH it uses (in a small colored tag matching the edge color in Section ①), core idea in one line, and a worked mini-example.

Card ① 基础型 [路径: 积定→和的下界]: 展开后出现 u + k/u 形式(积 u·k/u=k 为定值), 套 u+k/u ≥ 2√k
例: a,b>0, (1+b/a)(1+4a/b) = 5 + b/a+4a/b ≥ 5+2√4 = 9, 当b/a=4a/b即b=2a取等

Card ② 配凑法 [路径: 积定→和的下界]: 变量有偏移时, 拆项凑出 (x−c)+k/(x−c) 形式(积为定值k)
例: x>2, x+4/(x−2) = (x−2)+4/(x−2)+2 ≥ 2√4+2 = 6, 当x−2=2即x=4取等

Card ③ 1的代换 [路径: 和×倒数和 ≥ 4]: 约束=1, 乘入目标式, 展开出交叉项
例: a,b>0, 3/b+2/a=1, 求min(2a+3b) → (2a+3b)·1 = (2a+3b)(2/a+3/b) = 13+6b/a+6a/b ≥ 25

Card ④ 常数代换 [路径: 和定→积的上界 或 积定→和的下界]: 约束=常数k, 变形后代入目标式
例: x+y=1, x,y>0, 求min(1/x+4/y): (1/x+4/y)·(x+y) = 5+y/x+4x/y ≥ 5+4 = 9

Card ⑤ 同除法 [路径: 积→倒数和]: 两边同除以积ab, 把积的约束转化为倒数和
例: a+2b=3ab, a,b>0 → ÷ab得 1/b+2/a=3, 转为倒数和已知, 求积的最值

Card ⑥ 和积互消 [路径: 和↔积↔差]: 约束同时含和与积时, 换元t=√(xy)统一
例: x+2y+xy=30, x,y>0, 由x+2y≥2√(2xy)=2√2·t, 得2√2·t+t²≤30, 解t的范围

Card ⑦ 构造分母 [路径: 和×倒数和 ≥ 4]: 目标是倒数和, 乘以已知的和, 展开后用AM-GM
例: 4x+3y=4, x,y>0, 求min(1/(2x+1)+1/(3y+2)), 令a=2x+1,b=3y+2则2a+b=8

Card ⑧ 分离分子型: 分子拆分后各项化简
例: 4x>y>0, y/(4x−y) + x/y = y/(4x−y) + (4x−y)/y·¼ + ¼ ≥ 2·½ + ¼ = 5/4

Card ⑨ 反解代入消元法: 从约束解出一变量代入目标函数
例: a,b>0, 1/a+1/b=2, 求 max(3/(b+1)−a): 由 1/b=2−1/a 解 b=a/(2a−1), 代入化简

Section ④ "恒成立/存在性/参数范围" (bottom-center, medium module, purple header):
A decision tree with diamond nodes:

问题类型 (D非空) →
├─ "f(x) ≥ a 对所有 x∈D 恒成立" → 先判断f(x)在D上是否有下界:
│    ├─ f(x)下方无界(inf f = −∞) → 不存在实数a使恒成立(任取a总有x使f(x)<a)
│    ├─ f(x)有最小值m(取得到) → a ≤ m
│    └─ f(x)无最小值但下确界m₀有限(取不到) → 同样 a ≤ m₀ (无需函数取到下确界)
│    验证: f(x)=x, D=(0,1), a=0 → inf=0, a≤0 ✓, ∀x∈(0,1): x≥0 ✓
├─ "存在 x∈D 使 f(x) ≥ a" → 先判断f(x)在D上是否有上界:
│    ├─ f(x)上方无界(sup f = +∞) → 任意实数a都满足(总能找到足够大的f(x))
│    ├─ f(x)有最大值M(取得到) → a ≤ M
│    └─ f(x)无最大值但上确界M₀有限(取不到) → a < M₀ (严格! 等号处取不到)
│    验证: f(x)=x, D=(0,1), a=1 → sup=1取不到, a<1才正确;
│    f(x)=x, D=ℝ → 上方无界, 任意a都存在x≥a ✓
├─ "f(x) > g(x) 对所有 x∈D 恒成立" → 两种策略:
│   ├─ 策略1: 分离参数: a > h(x) 恒成立 → 先判断h(x)在D上是否有上界:
│   │    ├─ h(x)上方无界(sup h = +∞) → 不存在实数a使a>h(x)恒成立
│   │    ├─ h(x)有最大值M(有限,取得到) → a > M (严格! 不能写≥)
│   │    └─ h(x)无最大值但上确界M₀有限(取不到) → a ≥ M₀
│   │    验证: h(x)=x, D=ℝ → 上方无界, 不存在a使a>x恒成立 ✓
│   │    验证: h(x)=0(常函数), a=0 → 有最大值0, 需a>0, 而非a≥0 ✓
│   └─ 策略2: 令 F(x)=f(x)−g(x), 转化为 F(x) > 0 在D上恒成立 → 先判断F(x)下界:
│        ├─ F(x)下方无界(inf F = −∞) → F(x)>0 不恒成立
│        ├─ F(x)有最小值m(有限,取得到) → 需 m > 0
│        └─ F(x)无最小值但下确界m₀有限(取不到) → 需 m₀ ≥ 0
│        验证: F(x)=x, D=ℝ → 下方无界, F>0不恒成立(x=-1时F=-1<0) ✓
│        验证: F(x)=x, D=(0,1) → inf=0取不到, m₀=0≥0 ✓, F>0恒成立 ✓
└─ "恰好有n个解" → 数形结合: 画f(x)和g(x)图象，数交点个数

Section ⑤ "不等式证明方法" (bottom-right, medium module, red header):
A method hierarchy showing five approaches in order of common usage (老教材代数二核心体系):

① 比较法 (最基本):
  作差法: 证A≥B → 证A−B≥0, 对差式因式分解或配方
  作商法: 证A≥B(B>0) → 证A/B≥1

② 综合法 (顺推): 从已知条件出发，利用已知不等式逐步推出目标
  常用已知不等式: a²+b²≥2ab, |a+b|≤|a|+|b|, AM≥GM

③ 分析法 (逆推): 从待证结论出发，寻找使之成立的充分条件，回溯到已知
  书写格式: "要证...只需证...只需证...而这由已知成立"

④ 放缩法: 适当放大或缩小，化繁为简
  常用放缩:
  n! > 2ⁿ⁻¹ (n≥3)
  (1+1/n)ⁿ < e < (1+1/n)ⁿ⁺¹
  1/(n²) < 1/[n(n−1)] = 1/(n−1) − 1/n (n≥2)
  ln(1+x) < x (x>0)
