Method ① 累加法:
递推型: aₙ₊₁ = aₙ + f(n)
操作: a₂−a₁=f(1), a₃−a₂=f(2), ..., aₙ−aₙ₋₁=f(n−1) → 逐项相加消去中间项
结果: aₙ = a₁ + Σₖ₌₁ⁿ⁻¹ f(k)

Method ② 累乘法:
递推型: aₙ₊₁ = aₙ · f(n), aₙ≠0
操作: a₂/a₁=f(1), a₃/a₂=f(2), ..., aₙ/aₙ₋₁=f(n−1) → 逐项相乘消去
结果: aₙ = a₁ · Πₖ₌₁ⁿ⁻¹ f(k)

Method ③ 构造等比(待定常数法):
递推型: aₙ₊₁ = paₙ + q (p≠0, p≠1)
操作: 设 aₙ₊₁ + t = p(aₙ + t) → 解得 t = q/(p−1)
结果: {aₙ + t} 是公比为p的等比数列 → aₙ = (a₁+t)·pⁿ⁻¹ − t
⚠️ 若 a₁+t=0 (即 a₁ 恰为不动点 q/(1−p)), 则 aₙ 为常数列 aₙ=a₁, 通项公式仍成立但构造出的是零数列而非等比数列
老教材深度 — 特征方程法: 特征方程 x = px + q → 不动点 x₀ = q/(1−p) → aₙ − x₀ = (a₁ − x₀)·pⁿ⁻¹

Method ④ 除以指数项:
递推型: aₙ₊₁ = paₙ + rⁿ (r≠0)
操作: 两边÷rⁿ⁺¹ → aₙ₊₁/rⁿ⁺¹ = (p/r)·(aₙ/rⁿ) + 1/r → 换元 bₙ = aₙ/rⁿ → 化为Method③
⚠️ 若 p=r, 则新递推公比=1, 退化为等差型, 改用 Method ① (累加法)

Method ⑤ 取倒数/取对数:
递推型: aₙ₊₁ = aₙ/(paₙ+q) → 取倒数 1/aₙ₊₁ = p + q/aₙ → 化为线性递推 (⚠️ 取倒数须aₙ≠0; 原递推在aₙ=0时可能仍有意义, 如aₙ₊₁=aₙ/(aₙ+1)在a₁=0时给出零数列, 但取倒数这一变换步骤不适用)
递推型: aₙ₊₁ = aₙᵖ → 取对数 ln aₙ₊₁ = p·ln aₙ → {ln aₙ} 是公比p的等比数列 (⚠️ 需aₙ>0且p≠0; p=0时从第2项起aₙ=1, 对数列为ln a₁,0,0,…须单独处理(a₁=1时才是全零列); aₙ≡1时lnaₙ≡0, 也不构成等比数列)

Method ① 公式法:
适用: 等差或等比数列
等差: Sₙ = n(a₁+aₙ)/2
等比: Sₙ = a₁(1−qⁿ)/(1−q), q≠1
⚠️ 等比求和必须讨论 q=1 的情况!

Method ② 错位相减法:
适用: cₙ = aₙ·bₙ (aₙ等差, bₙ等比)
操作: Sₙ = a₁b₁ + a₂b₂ + ... + aₙbₙ
     qSₙ = a₁b₂ + a₂b₃ + ... + aₙbₙ₊₁
     (1−q)Sₙ = a₁b₁ + d(b₂+b₃+...+bₙ) − aₙbₙ₊₁

Method ③ 裂项相消法:
适用: 通项可拆为两项之差
常用裂项: 1/[n(n+1)] = 1/n − 1/(n+1)
         1/[n(n+2)] = ½[1/n − 1/(n+2)]
         1/(√n+√(n+1)) = √(n+1) − √n
→ 求和后中间项消去，首尾相残

Method ④ 分组求和法:
适用: 通项由几个不同类型部分组成
例: aₙ = 2ⁿ + 3n → Sₙ = Σ2ⁿ + 3·Σn = (2ⁿ⁺¹−2) + 3n(n+1)/2

Method ⑤ 倒序相加法:
适用: 首尾对应项之和为常数 (aₖ + aₙ₊₁₋ₖ 不随k变化)
例: Sₙ = 1+2+3+...+n, 倒序Sₙ = n+(n-1)+...+1, 对应项相加每对=n+1 → 2Sₙ=n(n+1) → Sₙ=n(n+1)/2
⚠️ Σₖ₌₀ⁿ Cₙᵏ=2ⁿ 由二项式定理(a=b=1)得到(→见13表), 不是倒序相加的结论(倒序只得 S=S, 不能定值)
⚠️ Σ Cₙᵏ·2ᵏ 也不适用倒序相加(首尾和不固定), 应走二项式定理 (1+2)ⁿ=3ⁿ

Method ⑥ 并项法/周期法:
适用: 数列有周期性或相邻项可合并
例: aₙ = (−1)ⁿ·n → 相邻两项合并: (−1+2)+(−3+4)+... = 1+1+... (偶数项时)

Section ④ "数学归纳法" (bottom-left, medium module, red header):
Title with analogy: 多米诺骨牌原理

Two-step standard format shown as two connected boxes:
Step 1 (基础步): 验证 n = n₀ (通常 n₀=1) 时命题成立 → "推倒第一块"
↓ (连接箭头)
Step 2 (归纳步): 假设 n = k (k ≥ n₀) 时命题成立 → 证明 n = k+1 时命题也成立 → "每块倒了, 下一块也倒"
↓
结论: 命题对所有 n ≥ n₀ 成立

⚠️ 三个易错点 (red warning box):
① 基础步不能省略 (缺第一块则无法启动)
② 归纳步中必须用到 "n=k时成立" 这个假设 (否则不是归纳法)
③ 注意起始值 n₀ 不一定是1

老教材扩展 — 第二数学归纳法(强归纳法):
假设 n ≤ k 时命题全部成立 → 证 n = k+1 成立
适用: 当 n=k+1 的证明需要用到 n=k 之前多步的结论 (如斐波那契数列性质)

常见证明类型: 恒等式证明 | 不等式证明 | 整除性证明 | 几何命题
