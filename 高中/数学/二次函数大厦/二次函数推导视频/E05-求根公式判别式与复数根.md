# E05｜求根公式与判别式；Δ<0 时的复数根

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：x² + (b/a)x + c/a = 0；x² + (b/a)x = −c/a；(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)；求根公式与判别式；Δ<0 时开平方；复数范围内的一元二次方程

## 这一集要讲明白的一件事
配方把 ax²+bx+c=0 化成 (x+b/2a)²=Δ/(4a²)，右边的符号只由 Δ 决定：Δ>0 两根、Δ=0 两个相等的根、Δ<0 没有实根；在复数范围内 Δ<0 也有两个共轭虚根，根与系数的关系仍成立。

## 开场问题（不依赖其他集）
判别式为什么恰好是 b²−4ac？x²+2x+5=0 真的“无解”吗？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **一元二次方程的解法**
  - 直接开平方：x²=p（p≥0）⇒ x=±√p
  - 因式分解：(x−x₁)(x−x₂)=0 ⇒ x=x₁ 或 x₂
  - 配方法：化成 (x+m)²=p 再开平方
  - 由来（简短复习）：由“【公理】实数运算与大小”：【因式分解】乘积为 0 ⟺ 某个因式为 0（uv=0 ⟺ u=0 或 v=0）；例：x²−5x+6=(x−2)(x−3)=0 ⇒ x=2 或 x=3；【开平方】x²=p（p≥0）⇒ x=±√p；(x+m)²=p 同理 ⇒ x=−m±√p。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **一元二次方程的解法 → x² + (b/a)x + c/a = 0**（推导）
   - 【同除】ax²+bx+c=0 两边除以 a（a≠0）
2. **x² + (b/a)x + c/a = 0 → x² + (b/a)x = −c/a**（推导）
   - 【移项】常数项 c/a 移到右边
3. **x² + (b/a)x = −c/a → (x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)**（推导）
   - 【配凑】两边加上一次项系数一半的平方 (b/2a)²
   - 左边凑成完全平方，右边通分：(b²−4ac)/(4a²)
4. **(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²) → 求根公式与判别式**（推导；含 2 个小步骤，逐个展开）
   - 【分类讨论】右边分母 4a²>0，正负只看 Δ
   - Δ<0：右边为负，「平方非负」⇒ 无实根
   - Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)
5. **(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²) → Δ<0 时开平方**（推导）
   - ▼ 加条件：Δ<0，在复数范围内求根（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - Δ<0：右边为负，实数范围内开不了平方
   - 「复数」i²=−1 ⇒ Δ/(4a²) = (√(−Δ)·i/(2a))²
   - 【开平方】x + b/2a = ±√(−Δ)·i/(2a)
6. **Δ<0 时开平方 → 复数范围内的一元二次方程**（推导）
   - 【代入】两根相加：虚部抵消，得 −b/a
   - 两根相乘：(b² + (−Δ))/(4a²) = 4ac/(4a²) = c/a
7. **【定义】二次函数 → x² + (b/a)x + c/a = 0**（提供前提）
   - 【前提】a≠0，才能两边除以 a
8. **【定义】虚数单位与复数 → 复数范围内的一元二次方程**（提供前提）
   - 【前提】i²=−1

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### x² + (b/a)x + c/a = 0

#### x² + (b/a)x = −c/a

#### (x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)

#### 求根公式与判别式
- Δ = b²−4ac
- Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
- Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根

#### 【定义】虚数单位与复数
- i² = −1；复数 α+βi（α、β 为实数）
- 四则运算按多项式运算，遇 i² 换成 −1

#### Δ<0 时开平方
- 条件：Δ<0（复数范围）
- x + b/2a = ±√(−Δ)·i/(2a)
- 两根 x = (−b ± √(−Δ)·i)/(2a)

#### 复数范围内的一元二次方程
- 条件：实系数；Δ<0（复数范围）
- 实系数，Δ<0：两个共轭虚根 x = (−b ± √(−Δ)·i)/(2a)
- 根与系数的关系仍成立：x₁+x₂=−b/a，x₁x₂=c/a
- 例：x²+2x+5=0：x=−1±2i
- 虚根成对：已知一根 α+βi（β≠0），另一根是 α−βi，再用韦达求系数；例：1+i 是 x²−ax+2=0 的根 ⇒ a=(1+i)+(1−i)=2

## 着重标注（本集必须突出的地方）
- 两边除以 a 需要 a≠0。
- 4a²>0，所以右边的正负只看 Δ。
- i²=−1 那一步单独框出。

## 解题思维导向（片尾一句话）
看到一元二次方程 → 先算 Δ 判断根的个数，再用求根公式；在复数范围内 Δ<0 → 两个共轭虚根。

## 易错点与边界（必须讲到）
- Δ=0 说“两个相等的实根”（重根算两个）。
- Δ<0 是“没有实根”，在复数范围内有解。
- 求根公式的分母是 2a，不是 2。
