# E09｜抛物线的焦点与准线：二次函数图像就是解析几何里的抛物线

- 建议时长：3–4 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：抛物线的几何定义（选择性必修衔接）

## 这一集要讲明白的一件事
y=ax² 上每个点到点 (0,1/(4a)) 的距离，等于到直线 y=−1/(4a) 的距离——二次函数的图像就是选择性必修里“到定点与定直线距离相等”的抛物线。

## 开场问题（不依赖其他集）
二次函数的图像叫“抛物线”，它和“到一个定点与一条定直线距离相等的点”组成的曲线是同一种曲线吗？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **两点距离与点到水平直线的距离**：点 (x,y) 到 (0,d) 的距离为 √(x²+(y−d)²)；到直线 y=−d 的距离为 |y+d|。
- **y = ax² 的图像（a≠0）**
  - a>0 开口向上，a<0 开口向下
  - |a| 越大，开口越小
  - 关于 y 轴对称，顶点 (0,0)（a>0 最低点，a<0 最高点）
  - 由来（简短复习）：由“y = x² 的图像”：【伸缩】同一个 x，纵坐标乘 a；a<0 时翻到 x 轴下方；|a| 越大，同一 x 处离 x 轴越远，开口越窄；x 与 −x 的纵坐标同乘 a 仍相等：对称性不变，顶点仍是 (0,0)。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **y = ax² 的图像（a≠0） → 抛物线的几何定义（选择性必修衔接）**（推导；含 2 个小步骤，逐个展开）
   - 【前提】两点距离公式、点到直线的距离（课本）
   - 【距离验证】令 q=1/(4a)，点 (x,y) 满足 y=ax² 时：
   - x²+(y−q)² = (y+q)²（两边相减得 x² − 4qy = x² − y/a = 0）
   - 即到 (0,q) 的距离 = 到直线 y=−q 的距离；反过来展开即得 y=ax²（a<0 时同样成立）

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 抛物线的几何定义（选择性必修衔接）
- 定义：到定点 F（焦点）与到定直线 l（准线，F 不在 l 上）距离相等的点的轨迹
- y = ax² 即 x² = (1/a)y
- 焦点 (0, 1/(4a))，准线 y = −1/(4a)
- 焦半径：点 (x₀, y₀) 在 y=ax² 上，到焦点的距离 = 到准线的距离 = |y₀ + 1/(4a)|

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- y=x²（a=1）：焦点 (0,1/4)，准线 y=−1/4；图上取 P(1,1)，PF=√(1²+(3/4)²)=5/4，P 到准线的距离 1+1/4=5/4。

## 着重标注（本集必须突出的地方）
- 两边平方后相减，得到 x²−4dy=0，即 x²=y/a 那一步。
- a<0 时开口向下，结论同样成立。

## 解题思维导向（片尾一句话）
看到 y=ax² 求焦点、准线 → 化成 x²=(1/a)y，焦点 (0,1/(4a))，准线 y=−1/(4a)。

## 易错点与边界（必须讲到）
- 焦点纵坐标是 1/(4a)，不是 a/4。
- a<0 时焦点在原点下方，准线在上方。
