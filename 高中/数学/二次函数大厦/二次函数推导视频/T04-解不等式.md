# T04｜题型串讲：解不等式

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **解一元二次不等式**
  - ① 二次项系数化为正（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写解集
  - 解集用集合（或区间）写：{x | x<x₁ 或 x>x₂}、{x | x₁<x<x₂}；无解写 ∅，对一切 x 成立写 ℝ
  - 也可先因式分解：(x−x₁)(x−x₂)>0 ⟺ 两个因式同号，化成两个一元一次不等式组
  - 例（实际情境，s 为刹车距离，单位米；v 为车速，单位千米每小时）：s=v²/100−v/10>6（v>0）⇒ (v−30)(v+20)>0 ⇒ v>30
  - 由来（简短复习）：由“三个二次的关系”：【同乘法】a<0 时两边乘 −1：系数化正，不等号反向；化成 a>0 后：求 Δ 和两根，按三个二次的关系读出解集；例：−x²+x+2>0 ⟺ x²−x−2<0 ⟺ (x−2)(x+1)<0 ⟺ −1<x<2。由“一元二次方程的解法”：【因式分解】(x−x₁)(x−x₂)>0 ⟺ 两个因式同号；⟺ x−x₁、x−x₂ 同正，或同负：两个一元一次不等式组。
- **含参二次不等式**
  - ① 先看二次项系数：=0 时不是二次不等式（b≠0 按一次解，b=0 看常数 c）
  - ② 系数 ≠0：化为正，再看 Δ
  - ③ 有两根时比较两根大小
  - 由来（简短复习）：由“解一元二次不等式”：【分类讨论】第一层：二次项系数是否为 0？为 0 时不是二次不等式，按一次处理；第二层：系数不为 0 时化正，看 Δ<0、Δ=0、Δ>0；第三层：有两根时比较两根大小；例 (x−1)(x−m)<0：m>1 时 1<x<m，m=1 时无解，m<1 时 m<x<1。
- **三个二次的关系**
  - 条件：a>0
  - Δ>0：f(x)>0 ⟺ x<x₁ 或 x>x₂
  - f(x)<0 ⟺ x₁<x<x₂
  - Δ=0：f(x)>0 ⟺ x≠x₁；f(x)<0 无解
  - Δ<0：f(x)>0 对一切 x 成立
  - ≥、≤：把根并进去；Δ=0 时 f(x)≤0 ⟺ x=x₁；Δ<0 时 f(x)≤0 无解
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方；Δ<0：最小值 −Δ/(4a)>0，整条在上方。
- **配方法解二次不等式**
  - 条件：a>0
  - ax²+bx+c>0 ⟺ (x−h)² > Δ/(4a²)
  - Δ<0：恒成立；Δ=0：x≠h
  - Δ>0：|x−h| > √Δ/(2a)，即 x 到 h 的距离大于 √Δ/(2a)
  - 例：x²−4x+1<0 ⟺ (x−2)²<3 ⟺ 2−√3 < x < 2+√3
  - 由来（简短复习）：由“f(x)>0 ⟺ (x−h)² > Δ/(4a²)”：【开平方】两边非负：(x−h)² > r² ⟺ |x−h| > r（r=√Δ/(2a)）；即 x<h−r 或 x>h+r。
- **分式不等式化为二次**
  - f(x)/g(x) > 0 ⟺ f(x)·g(x) > 0
  - f(x)/g(x) ≥ 0 ⟺ f(x)·g(x) ≥ 0 且 g(x)≠0
  - 例：(2x+1)/(x−2) ≥ 1 ⟺ (x+3)/(x−2) ≥ 0 ⟺ x ≤ −3 或 x > 2
  - 由来（简短复习）：由“f(x)/g(x) 与 0 比较”：【同乘法】g(x)≠0 时 g(x)²>0，两边乘 g(x)² 方向不变：f/g>0 ⟺ f·g>0；≥0 时 f/g=0 ⟺ f=0 且 g≠0，所以要单独保证 g≠0。
- **高次不等式（穿根法）**
  - (x−x₁)(x−x₂)…(x−xₙ)>0（x₁<…<xₙ，各因式 x 的系数为正）
  - 最右侧全为正，往左每过一个根变一次号；偶次重根不变号
  - 例：(x+2)(x+1)(x−1)>0 ⟺ −2<x<−1 或 x>1
  - ≥0（≤0）时再并上所有根；偶次重根可能是孤立点，例：(x−1)²(x−3)≥0 ⟺ x≥3 或 x=1
  - 由来（简短复习）：由“【公理】实数运算与大小”：【符号规则】x−xᵢ 在 xᵢ 右边为正、左边为负；乘积的正负由负因式的个数决定：从最右（全为正）往左，每过一个根多一个负因式。
- **已知解集反求系数**
  - ax²+bx+c<0 的解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是方程的两根
  - ax²+bx+c>0 的解集为 (x₁,x₂) ⇒ a<0（两边乘 −1 化成上一条）；>0 的解集为 x<x₁ 或 x>x₂ ⇒ a>0
  - 由韦达：b=−a(x₁+x₂)，c=a·x₁x₂
  - 例：x²+bx+c<0 解集 (−3,−1) ⇒ b=4，c=3
  - 由来（简短复习）：由“解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是 ax²+bx+c=0 的两根”：「韦达」x₁+x₂=−b/a，x₁x₂=c/a，解出 b、c（用 a 表示）。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。
- **恒成立（全体实数）**
  - 条件：对一切 x∈ℝ
  - ax²+bx+c>0 恒成立 ⟺ a>0 且 Δ<0，或 a=b=0 且 c>0
  - （a=0、b≠0 时取遍全体实数，不可能恒正）
  - ≥0：Δ<0 改为 Δ≤0，c>0 改为 c≥0
  - 由来（简短复习）：由“最值”：【等价变形】a>0：恒 >0 ⟺ 最小值 >0 ⟺ −Δ/(4a)>0 ⟺ Δ<0；a<0：f 可以任意小（没有最小值），不可能恒正。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **零点 ⟺ 根 ⟺ 交点**
  - f 的零点 = 方程 f(x)=0 的实根
  - = 图像与 x 轴交点的横坐标
  - 个数：Δ>0 两个，Δ=0 一个，Δ<0 没有
  - 由来（简短复习）：由“【定义】零点”：【定义】零点 = 方程的根；【数形结合】= 图像与 x 轴交点（y=0）。
- **【公理】实数运算与大小**
  - u>v ⟺ u−v>0；正数×正数=正数
  - 两边同加不变向；乘正数不变向，乘负数变向
  - uv=0 ⟺ u=0 或 v=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **含绝对值的图像**
  - y=|f(x)|：x 轴下方部分翻到上方
  - y=f(|x|)：保留 y 轴右侧，再关于 y 轴对称
  - 由来（简短复习）：由“【约定】点在图像上”：【分类讨论】y=|f(x)|：f(x)≥0 的部分不变，f(x)<0 的部分取相反数 ⇒ x 轴下方的部分翻到上方；y=f(|x|)：x≥0 时就是 f(x)；x<0 时 f(|x|)=f(−x)，与 x>0 处的值相同 ⇒ 保留右侧，再关于 y 轴对称。
- **【定义】集合与区间**
  - 交集：同时满足；并集：满足其一
  - [m,n] 含端点，(m,n) 不含端点
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 题型（按顺序讲）
### 1. 看到：解一元二次不等式（含参）
- 反推：化正 → Δ → 两根大小；也可配方化成 |x−h| 与常数比较
- 先查：二次项系数是否可能为 0
- 用到的结论：解一元二次不等式、含参二次不等式、三个二次的关系、配方法解二次不等式
- 例题：解关于 x 的不等式 ax²−(a+1)x+1<0。
  - 分解：ax²−(a+1)x+1=(ax−1)(x−1)。
  - a=0：−x+1<0，x>1。a<0：化正得 (x−1/a)(x−1)>0，x<1/a 或 x>1。
  - a>0：两根 1/a 与 1 比大小——0<a<1 时 1<x<1/a；a=1 时无解；a>1 时 1/a<x<1。
  - 答案：按 a=0、a<0、0<a<1、a=1、a>1 分五种情况写出

### 2. 看到：分式不等式
- 反推：移项通分 → 化成 f·g 与 0 比较 → 按二次（或高次）不等式解
- 先查：分母 ≠ 0；≥ 时等号只来自分子
- 用到的结论：分式不等式化为二次、解一元二次不等式
- 例题：解 (x+1)/(x−2)≤2。
  - 移项通分：(x+1)/(x−2)−2=(5−x)/(x−2)≤0，两边乘 −1：(x−5)/(x−2)≥0。
  - 化为 (x−5)(x−2)≥0 且 x≠2。
  - 答案：x<2 或 x≥5

### 3. 看到：高次不等式
- 反推：化成一次因式乘积（x 的系数为正），标根后从右往左穿线
- 先查：无实根的二次因式恒正可约去；重根
- 用到的结论：高次不等式（穿根法）、三个二次的关系
- 例题：解 (x−1)²(x−3)≥0。
  - 根 1（二重）、3。从最右侧开始：x>3 为正；过 3 变号；过二重根 1 不变号，所以 x<3 且 x≠1 时为负。
  - ≥0 还要并上所有根：x=1、x=3。
  - 答案：x≥3 或 x=1

### 4. 看到：已知解集，求系数
- 反推：<0 的解集是两根之间 → 开口向上；>0 的解集是两根之间 → 开口向下；两端是方程的根 → 韦达
- 先查：解集形式决定 a 的符号
- 用到的结论：已知解集反求系数、三个二次的关系、韦达定理
- 例题：ax²+bx+2>0 的解集是 (−1/2, 1/3)，求 a+b。
  - >0 的解集是两根之间 ⇒ 开口向下，a<0；−1/2、1/3 是方程的两根。
  - 韦达：−b/a=−1/2+1/3=−1/6，2/a=(−1/2)(1/3)=−1/6 ⇒ a=−12，b=−2。
  - 答案：a+b=−14

### 5. 看到：求定义域：根号、对数里的二次
- 反推：根号下的二次式 ≥0；对数真数里的二次式 >0；化成解一元二次不等式。定义域为 ℝ 求参数：化成恒成立
- 先查：二次项系数含参数时先看 =0；√ 要 ≥0，log 要 >0
- 用到的结论：解一元二次不等式、含参二次不等式、恒成立（全体实数）
- 例题：f(x)=√(ax²+2x+1) 的定义域为 ℝ，求 a 的范围。
  - a=0 时根号下是 2x+1，x<−1/2 时为负，不行。
  - a≠0：ax²+2x+1≥0 对一切 x 成立 ⟺ a>0 且 Δ=4−4a≤0 ⟺ a≥1。
  - 答案：a≥1

### 6. 看到：集合包含、交集并集里的二次，求参数
- 反推：先解出（或表示出）二次方程、不等式的解集，再按集合关系列条件
- 先查：解集可能是空集（Δ<0）；两根谁大；端点能否取等
- 用到的结论：求根公式与判别式、零点 ⟺ 根 ⟺ 交点、含参二次不等式、解一元二次不等式
- 例题：A={−2}，B={x | x²+2x+a−1=0}，A∩B=B，求 a。
  - A∩B=B ⟺ B⊆A：B=∅ 或 B={−2}。
  - B=∅：Δ=4−4(a−1)<0 ⇒ a>2；B={−2}：要 Δ=0 ⇒ a=2，此时根是 −1，不行。
  - 答案：a>2

### 7. 看到：无理不等式（根号）化成二次不等式
- 反推：√f(x) > g(x) ⟺ ① f(x)≥0 且 g(x)<0，或 ② g(x)≥0 且 f(x)>g(x)²；√f(x) < g(x) ⟺ f(x)≥0，g(x)>0，f(x)<g(x)²
- 先查：根号下 ≥0；两边平方前右边要非负，按 g(x) 的正负分情况
- 用到的结论：解一元二次不等式、三个二次的关系、【公理】实数运算与大小
- 例题：解 √(x+2) > x。
  - x<0 时右边为负，只要根号有意义：x+2≥0 ⇒ −2≤x<0。
  - x≥0 时两边平方：x+2>x² ⇒ x²−x−2<0 ⇒ −1<x<2，所以 0≤x<2。
  - 答案：−2≤x<2

### 8. 看到：含绝对值的二次不等式
- 反推：|f(x)| < a（a>0）⟺ −a < f(x) < a，两个二次不等式取交集；|f(x)| > a ⟺ f(x) > a 或 f(x) < −a，取并集
- 先查：a≤0 时单独看；也可画 |f(x)| 的翻折图像与直线 y=a 比较
- 用到的结论：解一元二次不等式、含绝对值的图像、【定义】集合与区间
- 例题：解 |x²−2x| < 3。
  - ⟺ −3 < x²−2x < 3。
  - x²−2x<3 ⇒ −1<x<3；x²−2x>−3 ⟺ (x−1)²+2>0 恒成立。
  - 答案：−1<x<3

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“Δ≥0”写成“Δ>0”，或省掉“a>0”“x∈ℝ”）。数值必须自己再算一遍。
- 同一字母在一集里只表示一个量：二次项系数用 a，题目里的参数改用 m、t、k 等。
- 叙述用高中生听得懂的说法，不用超纲术语。
