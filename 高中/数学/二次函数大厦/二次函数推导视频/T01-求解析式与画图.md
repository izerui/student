# T01｜题型串讲：求解析式与画图

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **待定系数法求解析式**
  - 已知三点 → 设一般式 ax²+bx+c
  - 已知顶点（或对称轴、最值）→ 设顶点式
  - 已知与 x 轴两交点 → 设交点式
  - 由来（简短复习）：由“【定义】二次函数”：【待定系数】设出含未知系数的式子，每个已知条件列一个方程；已知三点 → 设 y=ax²+bx+c，代入得三元一次方程组；已知顶点 (h,k) → 设 y=a(x−h)²+k，再代一点求 a；已知与 x 轴交点 x₁、x₂ → 设 y=a(x−x₁)(x−x₂)，再代一点求 a。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **交点式（两根式）**
  - 条件：Δ≥0
  - f(x) = a(x − x₁)(x − x₂)
  - x₁、x₂ 是 f(x)=0 的两根
  - 由来（简短复习）：由“韦达定理”：【因式分解】ax²+bx+c = a[x² − (x₁+x₂)x + x₁x₂]；= a(x−x₁)(x−x₂)。
- **平移：y = a(x−h)² + k**
  - 由 y=ax² 向右平移 h、向上平移 k
  - 顶点 (h, k)，对称轴 x=h
  - 口诀：左加右减（括号里）、上加下减（括号外）
  - 移轴（坐标变换）：令 x′=x−h，y′=y−k，方程化成 y′=ax′²
  - 由来（简短复习）：由“y = ax² 的图像（a≠0）”：【代换法】(x₀,y₀) 在 y=ax² 上；⟺ (x₀+h, y₀+k) 在 y=a(x−h)²+k 上。
- **系数的几何意义**
  - a：开口方向和大小
  - c = f(0)：与 y 轴交点 (0, c)
  - ab>0 对称轴在 y 轴左侧，ab<0 在右侧（左同右异）；b=0 时对称轴就是 y 轴
  - 由来（简短复习）：由“顶点式”：【代入特定值】x=0：f(0)=c，图像与 y 轴交于 (0,c)；对称轴 h=−b/(2a)：h<0 ⟺ b/(2a)>0 ⟺ a、b 同号（ab>0）；b=0 ⟺ h=0：对称轴就是 y 轴。
- **两点同高 ⇒ 对称轴**
  - f(x₁)=f(x₂)，x₁≠x₂ ⇒ 对称轴 x = (x₁+x₂)/2
  - 由来（简短复习）：由“作差恒等式”：【作差】f(x₁)=f(x₂) ⇒ 0 = a(x₁−x₂)(x₁+x₂−2h)；a≠0，x₁≠x₂ ⇒ 只能第三个因子为 0：x₁+x₂−2h=0 ⇒ h=(x₁+x₂)/2。
- **最值**
  - 条件：x∈ℝ；a>0
  - 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
  - a<0 时：最大值 −Δ/(4a)，没有最小值
  - 由来（简短复习）：由“顶点式”：【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0；⇒ f(x) ≥ k，x=h 取等；(x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值。

## 题型（按顺序讲）
### 1. 看到：求二次函数的解析式
- 反推：已知什么设什么：三点 → 一般式；顶点 → 顶点式；两零点 → 交点式
- 先查：a≠0
- 用到的结论：待定系数法求解析式、顶点式、交点式（两根式）
- 例题：已知 f(2)=f(−1)=−1，且 f 的最大值为 8，求 f(x)。
  - f(2)=f(−1)，两点同高 ⇒ 对称轴 x=(2+(−1))/2=1/2；最大值 8 ⇒ 设顶点式 f(x)=a(x−1/2)²+8。
  - 代入 f(2)=−1：a·(3/2)²+8=−1，得 a=−4。
  - 答案：f(x)=−4(x−1/2)²+8

### 2. 看到：画抛物线、图像平移
- 反推：化成顶点式 → 由 y=ax² 平移；开口看 a，与 y 轴交点看 c
- 先查：平移方向（括号里左加右减）
- 用到的结论：平移：y = a(x−h)² + k、顶点式、系数的几何意义
- 例题：画 y=−2x²+4x+1 的草图，并说明它由 y=−2x² 怎样平移得到。
  - 配方：y=−2(x−1)²+3，顶点 (1,3)，开口向下。
  - 与 y 轴交于 (0,1)；a、b 异号，对称轴在 y 轴右侧，与 h=1 一致。
  - 由 y=−2x² 向右平移 1、向上平移 3。
  - 答案：顶点 (1,3)，开口向下，过 (0,1)

## 着重标注
- 每个题型的“先查”用橙色框，讲到时停顿；按“先查”漏掉会错的地方，用反例或叉号标出。
- 例题的每个数值都写出计算过程，答案用粗框。

## 解题思维导向（片尾一句话）
看到题目先问：它在问函数、方程还是不等式？参数在哪里？再从对应的入口反推到结论。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“Δ≥0”写成“Δ>0”，或省掉“a>0”“x∈ℝ”）。数值必须自己再算一遍。
- 同一字母在一集里只表示一个量：二次项系数用 a，题目里的参数改用 m、t、k 等。
- 叙述用高中生听得懂的说法，不用超纲术语。
