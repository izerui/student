# E11｜作差恒等式与对称轴

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]；作差恒等式；对称轴；两点同高 ⇒ 对称轴；对称轴的一般形式

## 这一集要讲明白的一件事
由顶点式作差得 f(x₁)−f(x₂)=a(x₁−x₂)(x₁+x₂−2h)，这一个恒等式管住对称、单调、比较大小；本集先用它和顶点式得到对称轴的两种说法。

## 开场问题（不依赖其他集）
如果 f(1)=f(5)，这个二次函数的对称轴在哪里？为什么一定是 x=3？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **【约定】点在图像上**
  - 点 (x₀, y₀) 在 y=f(x) 的图像上 ⟺ y₀ = f(x₀)
  - 由来（简短复习）：这是课本的定义或约定，直接承认（数与形互相翻译的依据）。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **顶点式 → f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]**（推导）
   - 【作差】[a(x₁−h)²+k] − [a(x₂−h)²+k]，k 抵消
2. **f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²] → 作差恒等式**（推导）
   - 「平方差」(x₁−h)²−(x₂−h)² = (x₁−x₂)(x₁+x₂−2h)
   - 【同除】x₁≠x₂ 时两边除以 x₁−x₂，得平均变化率
3. **顶点式 → 对称轴**（推导）
   - 【代入】x=h+t：f(h+t)=a·t²+k；x=h−t：f(h−t)=a·(−t)²+k=at²+k
   - ⇒ f(h+t)=f(h−t)：点 (h+t, y) 与 (h−t, y) 同在图像上，关于直线 x=h 对称
4. **作差恒等式 → 两点同高 ⇒ 对称轴**（推导）
   - 【作差】f(x₁)=f(x₂) ⇒ 0 = a(x₁−x₂)(x₁+x₂−2h)
   - a≠0，x₁≠x₂ ⇒ 只能第三个因子为 0：x₁+x₂−2h=0 ⇒ h=(x₁+x₂)/2
5. **两点同高 ⇒ 对称轴 → 对称轴的一般形式**（推导）
   - 【代入】取 x≠(q−p)/2：x₁=p+x 与 x₂=q−x 不同且函数值相等
   - 二次函数由两点同高：h=(x₁+x₂)/2=(p+q)/2（一般函数的对称性由“点在图像上”证）
6. **【约定】点在图像上 → 对称轴**（提供前提）
   - 【前提】点在图像上 ⟺ 坐标满足解析式：(h+t, y)、(h−t, y) 同在图像上
7. **【约定】点在图像上 → 对称轴的一般形式**（提供前提）
   - 【前提】任取图像上一点 (x₀, y₀)，令 x=x₀−p：f(p+q−x₀)=f(x₀)=y₀，对称点 (p+q−x₀, y₀) 也在图像上

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]

#### 作差恒等式
- f(x₁) − f(x₂) = a(x₁ − x₂)(x₁ + x₂ − 2h)
- 平均变化率（x₁≠x₂）：(f(x₁)−f(x₂))/(x₁−x₂) = a(x₁+x₂−2h)

#### 对称轴
- f(h + t) = f(h − t)，图像关于 x=h 对称

#### 两点同高 ⇒ 对称轴
- f(x₁)=f(x₂)，x₁≠x₂ ⇒ 对称轴 x = (x₁+x₂)/2

#### 对称轴的一般形式
- f(p+x)=f(q−x) 对一切 x 成立（p、q 为常数）⇒ 图像关于 x=(p+q)/2 对称（任何函数都成立）
- 二次函数：对称轴唯一，所以 h=(p+q)/2
- 例：f(x)=x²+bx+c，f(1+x)=f(3−x) ⇒ h=2，b=−4

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 抛物线上两点等高，连一条水平线段，中点处的竖直线就是对称轴。
- h+t 与 h−t 两点关于 x=h 对称。

## 着重标注（本集必须突出的地方）
- 平方差那一步：(x₁−h)²−(x₂−h)²=(x₁−x₂)(x₁+x₂−2h)。
- x₁≠x₂ 时才能约去 x₁−x₂；a≠0。

## 解题思维导向（片尾一句话）
看到两个自变量的函数值相等 → 对称轴是它们的中点；比较大小、判断单调 → 想到作差恒等式。

## 易错点与边界（必须讲到）
- f(x₁)=f(x₂) 必须加上 x₁≠x₂ 才能得出对称轴。
- 平均变化率要求 x₁≠x₂。
