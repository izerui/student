# T05｜题型串讲：恒成立与根的分布

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- 字母说明：k 表示与两根比较的那个数；复习顶点式时，顶点纵坐标改记为 k₀，避免同屏出现两个 k。
- **恒成立（全体实数）**
  - 条件：对一切 x∈ℝ
  - ax²+bx+c>0 恒成立 ⟺ a>0 且 Δ<0，或 a=b=0 且 c>0
  - （a=0、b≠0 时取遍全体实数，不可能恒正）
  - ≥0：Δ<0 改为 Δ≤0，c>0 改为 c≥0
  - 由来（简短复习）：由“最值”：【等价变形】a>0：恒 >0 ⟺ 最小值 >0 ⟺ −Δ/(4a)>0 ⟺ Δ<0；a<0：f 可以任意小（没有最小值），不可能恒正。
- **区间上恒成立 / 能成立（参数记作 λ）**
  - 条件：x∈区间
  - 先求 g(x) 在区间上的取值范围：开还是闭、有没有无界、边界能否取到
  - λ ≥ g(x) 恒成立：g 有最大值 M ⟺ λ ≥ M
  - g 有上界、但取值范围的上边界 L 取不到 ⟺ λ ≥ L；g 向上无界 ⟹ 没有这样的 λ
  - λ ≥ g(x) 能成立（至少一个 x）：g 有最小值 m₀ ⟺ λ ≥ m₀
  - g 有下界、但取值范围的下边界 L′ 取不到 ⟺ λ > L′；g 向下无界 ⟹ 任意实数 λ 都行
  - λ ≤ g(x)：规则对称——恒成立用最小值（或下边界），能成立用最大值（或上边界）
  - 二次函数：a>0 时 f(x)≤0 在 [m,n] 上恒成立 ⟺ f(m)≤0 且 f(n)≤0（开口向上，最大值在端点）
  - 核对 g(x)=x：x∈(0,1) 时恒成立 ⟺ λ≥1，能成立 ⟺ λ>0；x∈ℝ 时恒成立无解，能成立 λ 任意
  - 由来（简短复习）：由“恒成立 ⟺ 最不利的值满足；能成立 ⟺ 最有利的值满足”：【分离参数】化成 λ 与 g(x) 比较，先求 g 的取值范围；有最值用最值；边界取不到看边界值（恒成立可取等，能成立不可取等）；无界单独判断；两边除以含 x 的式子时，先定它的正负（除以负数要变号）。
- **两根都大于 k**
  - 条件：a>0
  - Δ ≥ 0，对称轴 −b/(2a) > k，f(k) > 0
  - （重根算两个根；两根都小于 k 同理）
  - a<0：两边乘 −1 化为 a>0（根不变），即 f(k)>0 改为 a·f(k)>0
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】看三样：判别式、对称轴位置、f(k) 的符号；必要：有两根 ⇒ Δ≥0；两根都 >k ⇒ 中点 h>k；k 在两根之外 ⇒ f(k)>0；充分：f(k)>0 ⇒ k 在两根之外；若 k 在右侧则 h≤x₂<k，与 h>k 矛盾，所以 k<x₁。
- **一根大于 k、一根小于 k**
  - ⟺ a·f(k) < 0（不用再查 Δ）
  - 系数含参数时先确认 a≠0
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】a>0 时 f(k)<0 ⇒ 最小值 <0 ⇒ Δ>0，必有两根，且 k 在两根之间；反之亦然；a<0 时对 −f（开口向上）用同一结论：f(k)>0，即 a·f(k)<0。
- **两根都在 (m, n) 内**
  - 条件：a>0
  - Δ ≥ 0，m < −b/(2a) < n，f(m) > 0，f(n) > 0
  - 由来（简短复习）：由“两根都大于 k”：【同理】两根都 >m：Δ≥0，h>m，f(m)>0（上一条）；两根都 <n：对称地 Δ≥0，h<n，f(n)>0；两组同时成立 ⇒ Δ≥0，m<h<n，f(m)>0，f(n)>0。
- **恰有一根在 (m, n) 内**
  - 条件：只看 (m,n) 内的根
  - f(m)·f(n) < 0 时成立
  - f(m)·f(n)=0（端点是根）或 Δ=0（重根）时单独检验
  - 由来（简短复习）：由“f(m)·f(n)<0 ⇒ (m,n) 内至少一个根”：【反证法】若两个不同实根都在 (m,n) 内：由交点式，f(m)、f(n) 都与 a 同号，与 f(m)f(n)<0 矛盾；重根 x₀ 在 (m,n) 内：f=a(x−x₀)² 不变号，同样矛盾 ⇒ 恰有一个；【分类讨论】f(m)f(n)=0（端点是根）时单独检验。
- **根的符号：用韦达**
  - 两正根 ⟺ Δ≥0，x₁+x₂>0，x₁x₂>0
  - 两负根 ⟺ Δ≥0，x₁+x₂<0，x₁x₂>0
  - 一正一负 ⟺ x₁x₂<0（即 c/a<0）
  - 由来（简短复习）：由“韦达定理”：【韦达】两根同号 ⟺ x₁x₂>0；同正再要 x₁+x₂>0；一正一负：c/a<0 ⇒ ac<0 ⇒ Δ=b²−4ac>0，自动有两个实根。
- **两根分属两个区间**
  - 条件：a>0
  - 一根在 (m,n)、另一根在 (n,p) ⟺ f(m)>0，f(n)<0，f(p)>0
  - 两区间不相邻：一根在 (m,n)、另一根在 (p,q)（n≤p）⟺ f(m)>0，f(n)<0，f(p)<0，f(q)>0
  - 由来（简短复习）：由“一根大于 k、一根小于 k”：【数形结合】f(n)<0 ⇒ n 在两根之间（a·f(n)<0）；f(m)>0 且 m<n ⇒ m 在两根之外的左侧，x₁∈(m,n)；同理 x₂∈(n,p)；反之两根如此分布，三处函数值符号必如上。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 题型（按顺序讲）
### 1. 看到：恒成立 / 能成立
- 反推：全体实数：看 a 和 Δ；区间上：化为最值或分离参数
- 先查：a=0 的情形；分离参数时除数的正负；g 的取值范围有没有最值、边界能否取到、是否无界（λ≥g 恒成立遇向上无界无解；λ≤g 恒成立遇向下无界无解）；g 不是二次函数时换用对应工具，如 x+1/x
- 用到的结论：恒成立（全体实数）、区间上恒成立 / 能成立（参数记作 λ）
- 例题：x²−sx+1≥0 对 x∈[1,2] 恒成立，求 s 的范围。
  - x∈[1,2] 时 x>0，两边除以 x 方向不变：s≤x+1/x。
  - 方向是 s≤g(x)，恒成立用 g 的最小值：x+1/x−2=(x−1)²/x≥0，x=1 时取等，最小值 2。
  - 答案：s≤2

### 2. 看到：方程根的分布
- 反推：判别式、对称轴、端点值三样；或用韦达看符号
- 先查：二次项系数不为 0，a<0 先化正；重根怎么算
- 用到的结论：两根都大于 k、一根大于 k、一根小于 k、两根都在 (m, n) 内、恰有一根在 (m, n) 内、根的符号：用韦达
- 例题：x²−2tx+t+2=0 的两根都大于 1，求 t 的范围。
  - 二次项系数 1>0。查三样：Δ=4t²−4(t+2)≥0 ⇒ t≤−1 或 t≥2；对称轴 t>1；f(1)=3−t>0 ⇒ t<3。
  - 三个条件取交集。
  - 答案：2≤t<3

### 3. 看到：两根分别在两个区间内
- 反推：端点函数值符号：f(m)>0，f(n)<0，f(p)>0（a>0）
- 先查：开口方向；两区间不相邻时四个端点都要查
- 用到的结论：两根分属两个区间、一根大于 k、一根小于 k、恰有一根在 (m, n) 内
- 例题：x²+2λx+2λ+1=0 的一根在 (−1,0) 内，另一根在 (1,2) 内，求 λ。
  - 二次项系数 1>0，两区间不相邻，四个端点都查：f(−1)=2>0，f(0)=2λ+1<0，f(1)=4λ+2<0，f(2)=6λ+5>0。
  - 解得 λ<−1/2 且 λ>−5/6。
  - 答案：−5/6<λ<−1/2

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“Δ≥0”写成“Δ>0”，或省掉“a>0”“x∈ℝ”）。数值必须自己再算一遍。
- 同一字母在一集里只表示一个量：二次项系数用 a，题目里的参数改用 m、t、k 等。
- 叙述用高中生听得懂的说法，不用超纲术语。
