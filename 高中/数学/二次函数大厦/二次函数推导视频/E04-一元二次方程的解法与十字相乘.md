# E04｜一元二次方程的解法：开平方、因式分解、十字相乘

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：一元二次方程的解法；(a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂；十字相乘

## 这一集要讲明白的一件事
解一元二次方程只有两条依据：“平方等于 p（p≥0）就开平方”和“乘积为 0 ⟺ 至少一个因式为 0”；十字相乘是因式分解的一种找法。

## 开场问题（不依赖其他集）
x²=9、(x−1)(x+3)=0、2x²−7x+3=0 各怎么解？它们背后只用到两条依据。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **【公理】实数运算与大小**
  - u>v ⟺ u−v>0；正数×正数=正数
  - 两边同加不变向；乘正数不变向，乘负数变向
  - uv=0 ⟺ u=0 或 v=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【公理】实数运算与大小 → 一元二次方程的解法**（推导；含 2 个小步骤，逐个展开）
   - 【因式分解】乘积为 0 ⟺ 某个因式为 0（uv=0 ⟺ u=0 或 v=0）
   - 例：x²−5x+6=(x−2)(x−3)=0 ⇒ x=2 或 x=3
   - 【开平方】x²=p（p≥0）⇒ x=±√p；(x+m)²=p 同理 ⇒ x=−m±√p
2. **一元二次方程的解法 → (a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂**（推导）
   - 【展开】(a₁x+c₁)(a₂x+c₂) 逐项相乘，合并同类项
3. **(a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂ → 十字相乘**（推导）
   - 【比较系数】与 ax²+bx+c 对照：a=a₁a₂，c=c₁c₂，b=a₁c₂+a₂c₁
   - 能找到这样的 a₁、a₂、c₁、c₂ 就能分解；交叉相乘再相加等于 b

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 一元二次方程的解法
- 直接开平方：x²=p（p≥0）⇒ x=±√p
- 因式分解：(x−x₁)(x−x₂)=0 ⇒ x=x₁ 或 x₂
- 配方法：化成 (x+m)²=p 再开平方

#### (a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂

#### 十字相乘
- 若 a=a₁a₂，c=c₁c₂，且 a₁c₂+a₂c₁=b，则 ax²+bx+c=(a₁x+c₁)(a₂x+c₂)
- 例：2x²−7x+3=(2x−1)(x−3)

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 十字相乘的十字格：左列 2、1，右列 −1、−3，交叉相乘 2×(−3)+1×(−1)=−7。
- 数轴上 ±√p 两点关于 0 对称。

## 着重标注（本集必须突出的地方）
- x²=p 要求 p≥0；p<0 时方程没有实数根——这是“没有实数满足”，不是“运算被禁止”。
- 十字相乘找到后要展开验证中间项。

## 解题思维导向（片尾一句话）
方程能拆成两个一次因式 → 因式分解（十字相乘）；拆不动 → 配方或用求根公式。

## 易错点与边界（必须讲到）
- 开平方别漏负根：x²=9 ⇒ x=±3。
- (x−1)(x+3)=5 不能令每个因式等于 5；只有右边是 0 才能用“乘积为 0”。

## 本集练到的方法
因式分解（1 次）、开平方（1 次）、展开（1 次）、比较系数（1 次）
