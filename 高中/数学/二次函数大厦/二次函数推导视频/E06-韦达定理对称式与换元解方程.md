# E06｜韦达定理、两根的对称式与换元解方程

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：韦达定理；两根的对称式求值；换元后的方程；换元解方程（舍根）

## 这一集要讲明白的一件事
两根相加、相乘时 √Δ 恰好消掉，得到 x₁+x₂=−b/a、x₁x₂=c/a；用它不解方程就能算对称式。换元化成二次方程时，新变量的范围决定哪个根要舍。

## 开场问题（不依赖其他集）
不解 x²−3x+1=0，能求出两根的平方和吗？x−2√x−1=0 怎么解，为什么有一个根要扔掉？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **求根公式与判别式 → 韦达定理**（推导）
   - ▼ 加条件：Δ≥0（有实根）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【代入】两根相加、相乘：
   - (−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a
2. **韦达定理 → 两根的对称式求值**（推导；含 2 个小步骤，逐个展开）
   - 【配凑】x₁²+x₂²=(x₁+x₂)²−2x₁x₂，代入韦达
   - 【通分】1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)
3. **求根公式与判别式 → 换元后的方程**（推导）
   - ▼ 加条件：新变量 t 的取值范围（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【换元法】令 t=√x 或 t=x²，原方程变成 t 的一元二次方程
4. **换元后的方程 → 换元解方程（舍根）**（推导）
   - 「求根公式」解出 t
   - 【检验】舍去不在 t 范围内的根，再由 t 还原 x

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 韦达定理
- 条件：Δ≥0
- x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
- 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)

#### 两根的对称式求值
- 条件：Δ≥0（实根）
- x₁²+x₂²=(x₁+x₂)²−2x₁x₂
- 1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)（x₁x₂≠0）
- 例：x²−3x+1=0：x₁²+x₂²=9−2=7
- 两交点 P(x₁,y₁)、Q(x₂,y₂) 在 y=kx+m 上：x₁x₂+y₁y₂ 代入直线化成 x₁+x₂、x₁x₂；OP⊥OQ ⟺ x₁x₂+y₁y₂=0（P、Q 不是原点）
- 非对称式：先用“根满足原方程”降次；例：x₁、x₂ 是 x²+2x−5=0 的两根，x₁²+x₁x₂+2x₁=5+(−5)=0
- 倒数根：ac≠0 时，cx²+bx+a=0 的两根是 ax²+bx+c=0 两根的倒数

#### 换元后的方程
- 条件：新变量的范围
- t 的一元二次方程，t≥0（t=√x 或 t=x²）
- 例：x−2√x−1=0 ⇒ t²−2t−1=0

#### 换元解方程（舍根）
- 条件：新变量的范围
- 令 t=√x 或 t=x²，化成 t 的一元二次方程，再按 t 的范围舍根
- 例：x−2√x−1=0：t=√x≥0，t²−2t−1=0
- t=1+√2（1−√2<0 舍），x=3+2√2
- 例：2x⁴−7x²+3=0：t=x²≥0，t=3 或 1/2，x=±√3、±√2/2
- 对数合并、两边平方会扩大定义域：解出后回原方程检验；例：lg x+lg(x−3)=1 ⇒ x²−3x−10=0 ⇒ x=5（x=−2 不满足 x>3，舍）

## 着重标注（本集必须突出的地方）
- ▼ Δ≥0：有实根才谈两根之和、积。反例：x²+x+1=0 的 Δ<0，−b/a=−1 仍能算出，但说“两实根之和为 −1”是错的。
- ▼ 新变量 t 的范围：t=√x≥0、t=x²≥0。

## 解题思维导向（片尾一句话）
已知方程求两根的对称式 → 韦达 + 配凑；方程里有 √x、x⁴、2ˣ → 换元，解完按新变量的范围舍根。

## 易错点与边界（必须讲到）
- 含参数时先保证 Δ≥0，再用韦达。
- 1/x₁+1/x₂ 要求 x₁x₂≠0。
- t=x² 还原时 x=±√t，两个都要。
