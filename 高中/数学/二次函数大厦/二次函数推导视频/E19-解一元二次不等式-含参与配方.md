# E19｜解一元二次不等式：程序、含参分类与配方法

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：解一元二次不等式；含参二次不等式；f(x)>0 ⟺ (x−h)² > Δ/(4a²)；配方法解二次不等式

## 这一集要讲明白的一件事
解二次不等式的固定程序：系数化正 → 算 Δ、求根 → 按三个二次的关系写解集；系数含参数时先看二次项系数是否为 0，再看 Δ，再比较两根；配方法给出另一种看法：x 到 h 的距离。

## 开场问题（不依赖其他集）
解 −x²+x+6>0；再解 x²−(m+1)x+m<0（m 是参数）。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **三个二次的关系**
  - 条件：a>0
  - Δ>0：f(x)>0 ⟺ x<x₁ 或 x>x₂
  - f(x)<0 ⟺ x₁<x<x₂
  - Δ=0：f(x)>0 ⟺ x≠x₁；f(x)<0 无解
  - Δ<0：f(x)>0 对一切 x 成立
  - ≥、≤：把根并进去；Δ=0 时 f(x)≤0 ⟺ x=x₁；Δ<0 时 f(x)≤0 无解
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方；Δ<0：最小值 −Δ/(4a)>0，整条在上方。
- **一元二次方程的解法**
  - 直接开平方：x²=p（p≥0）⇒ x=±√p
  - 因式分解：(x−x₁)(x−x₂)=0 ⇒ x=x₁ 或 x₂
  - 配方法：化成 (x+m)²=p 再开平方
  - 由来（简短复习）：由“【公理】实数运算与大小”：【因式分解】乘积为 0 ⟺ 某个因式为 0（uv=0 ⟺ u=0 或 v=0）；例：x²−5x+6=(x−2)(x−3)=0 ⇒ x=2 或 x=3；【开平方】x²=p（p≥0）⇒ x=±√p；(x+m)²=p 同理 ⇒ x=−m±√p。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **【公理】实数运算与大小**
  - u>v ⟺ u−v>0；正数×正数=正数
  - 两边同加不变向；乘正数不变向，乘负数变向
  - uv=0 ⟺ u=0 或 v=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **【定义】集合与区间**
  - 交集：同时满足；并集：满足其一
  - [m,n] 含端点，(m,n) 不含端点
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **十字相乘**
  - 若 a=a₁a₂，c=c₁c₂，且 a₁c₂+a₂c₁=b，则 ax²+bx+c=(a₁x+c₁)(a₂x+c₂)
  - 例：2x²−7x+3=(2x−1)(x−3)
  - 由来（简短复习）：由“(a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂”：【比较系数】与 ax²+bx+c 对照：a=a₁a₂，c=c₁c₂，b=a₁c₂+a₂c₁；能找到这样的 a₁、a₂、c₁、c₂ 就能分解；交叉相乘再相加等于 b。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **三个二次的关系 → 解一元二次不等式**（推导）
   - 【同乘法】a<0 时两边乘 −1：系数化正，不等号反向
   - 化成 a>0 后：求 Δ 和两根，按三个二次的关系读出解集
   - 例：−x²+x+2>0 ⟺ x²−x−2<0 ⟺ (x−2)(x+1)<0 ⟺ −1<x<2
2. **一元二次方程的解法 → 解一元二次不等式**（推导）
   - 【因式分解】(x−x₁)(x−x₂)>0 ⟺ 两个因式同号
   - ⟺ x−x₁、x−x₂ 同正，或同负：两个一元一次不等式组
3. **解一元二次不等式 → 含参二次不等式**（推导）
   - 【分类讨论】第一层：二次项系数是否为 0？为 0 时不是二次不等式，按一次处理
   - 第二层：系数不为 0 时化正，看 Δ<0、Δ=0、Δ>0
   - 第三层：有两根时比较两根大小；例 (x−1)(x−m)<0：m>1 时 1<x<m，m=1 时无解，m<1 时 m<x<1
4. **顶点式 → f(x)>0 ⟺ (x−h)² > Δ/(4a²)**（推导）
   - ▼ 加条件：a>0（a<0 先乘 −1 化正）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【同除】f(x)=a(x−h)²−Δ/(4a)>0，两边除以正数 a
   - ⟺ (x−h)² > Δ/(4a²)
5. **f(x)>0 ⟺ (x−h)² > Δ/(4a²) → 配方法解二次不等式**（推导）
   - 【开平方】两边非负：(x−h)² > r² ⟺ |x−h| > r（r=√Δ/(2a)）
   - 即 x<h−r 或 x>h+r
6. **【公理】实数运算与大小 → 解一元二次不等式**（提供前提）
   - 【前提】乘负数，不等号反向
7. **【定义】集合与区间 → 解一元二次不等式**（提供前提）
   - 【前提】解集用集合、区间表示：并集、交集
8. **【定义】二次函数 → 含参二次不等式**（提供前提）
   - 【前提】a=0 时不是二次函数

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 解一元二次不等式
- ① 二次项系数化为正（两边乘 −1，不等号反向）
- ② 算 Δ、求根；③ 按三个二次的关系写解集
- 解集用集合（或区间）写：{x | x<x₁ 或 x>x₂}、{x | x₁<x<x₂}；无解写 ∅，对一切 x 成立写 ℝ
- 也可先因式分解：(x−x₁)(x−x₂)>0 ⟺ 两个因式同号，化成两个一元一次不等式组
- 例（实际情境，s 为刹车距离，单位米；v 为车速，单位千米每小时）：s=v²/100−v/10>6（v>0）⇒ (v−30)(v+20)>0 ⇒ v>30

#### 含参二次不等式
- ① 先看二次项系数：=0 时不是二次不等式（b≠0 按一次解，b=0 看常数 c）
- ② 系数 ≠0：化为正，再看 Δ
- ③ 有两根时比较两根大小

#### f(x)>0 ⟺ (x−h)² > Δ/(4a²)
- 条件：a>0

#### 配方法解二次不等式
- 条件：a>0
- ax²+bx+c>0 ⟺ (x−h)² > Δ/(4a²)
- Δ<0：恒成立；Δ=0：x≠h
- Δ>0：|x−h| > √Δ/(2a)，即 x 到 h 的距离大于 √Δ/(2a)
- 例：x²−4x+1<0 ⟺ (x−2)²<3 ⟺ 2−√3 < x < 2+√3

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- −x²+x+6>0 ⟺ x²−x−6<0 ⟺ −2<x<3。
- x²−(m+1)x+m=(x−1)(x−m)：数轴上两根 1 与 m，m 从左滑到右越过 1，解集随之变化。
- 配方法：数轴上以 h 为中心、距离 d 的两点，>0 的解集在两点外侧。

- 两边乘 −1 时不等号反向。
- 含参三层分类：二次项系数是否为 0 → Δ → 两根大小。
- 例题答案：m>1 时 1<x<m；m=1 时无解；m<1 时 m<x<1。
- ▼ a>0（配方法）。

## 解题思维导向（片尾一句话）
解二次不等式 → 化正、求根、画图写解集；含参 → 先看二次项系数，再看 Δ，再比较两根。

## 易错点与边界（必须讲到）
- 乘负数忘记变号。
- 两根相等时：<0 无解，>0 要挖去一个点。
- 二次项系数含参数时可能为 0，要单独讨论。
