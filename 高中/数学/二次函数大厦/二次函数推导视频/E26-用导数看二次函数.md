# E26｜用导数看二次函数；三次函数的单调性；牛顿法

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：用导数看二次函数；F′(x) = 3Ax² + 2Bx + C 是二次函数；与导数衔接；牛顿法求根

## 这一集要讲明白的一件事
二次函数的导数 2ax+b 的零点正好是顶点横坐标，导数的正负与作差得到的单调性一致；反过来，三次函数的导数是二次函数，它的单调区间由一个二次不等式决定。拓展：牛顿法用切线一步步逼近方程的根。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **导数工具（课本承认）**：(xⁿ)′=nxⁿ⁻¹，常数的导数为 0；在某区间上 f′>0 则递增、f′<0 则递减；f′≥0 且只在个别点为 0 时仍递增；f′(x₀) 是曲线在 x₀ 处切线的斜率。
- **作差恒等式**
  - f(x₁) − f(x₂) = a(x₁ − x₂)(x₁ + x₂ − 2h)
  - 平均变化率（x₁≠x₂）：(f(x₁)−f(x₂))/(x₁−x₂) = a(x₁+x₂−2h)
  - 由来（简短复习）：由“f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]”：「平方差」(x₁−h)²−(x₂−h)² = (x₁−x₂)(x₁+x₂−2h)；【同除】x₁≠x₂ 时两边除以 x₁−x₂，得平均变化率。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。
- **解一元二次不等式**
  - ① 二次项系数化为正（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写解集
  - 解集用集合（或区间）写：{x | x<x₁ 或 x>x₂}、{x | x₁<x<x₂}；无解写 ∅，对一切 x 成立写 ℝ
  - 也可先因式分解：(x−x₁)(x−x₂)>0 ⟺ 两个因式同号，化成两个一元一次不等式组
  - 例（实际情境，s 为刹车距离，单位米；v 为车速，单位千米每小时）：s=v²/100−v/10>6（v>0）⇒ (v−30)(v+20)>0 ⇒ v>30
  - 由来（简短复习）：由“三个二次的关系”：【同乘法】a<0 时两边乘 −1：系数化正，不等号反向；化成 a>0 后：求 Δ 和两根，按三个二次的关系读出解集；例：−x²+x+2>0 ⟺ x²−x−2<0 ⟺ (x−2)(x+1)<0 ⟺ −1<x<2。由“一元二次方程的解法”：【因式分解】(x−x₁)(x−x₂)>0 ⟺ 两个因式同号；⟺ x−x₁、x−x₂ 同正，或同负：两个一元一次不等式组。
- **三个二次的关系**
  - 条件：a>0
  - Δ>0：f(x)>0 ⟺ x<x₁ 或 x>x₂
  - f(x)<0 ⟺ x₁<x<x₂
  - Δ=0：f(x)>0 ⟺ x≠x₁；f(x)<0 无解
  - Δ<0：f(x)>0 对一切 x 成立
  - ≥、≤：把根并进去；Δ=0 时 f(x)≤0 ⟺ x=x₁；Δ<0 时 f(x)≤0 无解
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方；Δ<0：最小值 −Δ/(4a)>0，整条在上方。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **作差恒等式 → 用导数看二次函数**（推导）
   - 【取极限】x₂=x₁+Δx：平均变化率 = a(2x₁+Δx−2h)
   - Δx→0 得 f′(x₁)=2a(x₁−h)=2ax₁+b（由导数的定义，课本）
2. **【定义】二次函数 → 用导数看二次函数**（推导；含 2 个小步骤，逐个展开）
   - 【求导】(ax²+bx+c)′ = 2ax+b（工具：(xⁿ)′=nxⁿ⁻¹，和差、常数倍的求导法则）
   - 【前提】导数判单调：f′<0 递减，f′>0 递增
3. **用导数看二次函数 → F′(x) = 3Ax² + 2Bx + C 是二次函数**（推导）
   - 【求导】F(x)=Ax³+Bx²+Cx+D（A≠0），用求导法则⑤：F′(x)=3Ax²+2Bx+C
4. **F′(x) = 3Ax² + 2Bx + C 是二次函数 → 与导数衔接**（推导）
   - 「三个二次的关系」读出 F′ 的正负区间（3A<0 时先乘 −1 化正）
   - 【前提】F′>0 的区间递增，F′<0 的区间递减；导数为 0 且左右变号的点是极值点（课本）
5. **用导数看二次函数 → 牛顿法求根**（推导；含 2 个小步骤，逐个展开）
   - 【切线】在 (xₖ, f(xₖ)) 处切线 y=f(xₖ)+f′(xₖ)(x−xₖ)，令 y=0 得 xₖ₊₁
   - 需 f′(xₖ)≠0
   - 【前提】导数的几何意义：f′(xₖ) 是切线斜率（选择性必修 6.1.2，由切线的定义得到）
6. **解一元二次不等式 → 与导数衔接**（提供前提）
   - 【前提】二次项系数为负时先化正
7. **三个二次的关系 → 与导数衔接**（提供前提）
   - 【前提】三个二次的关系：读出导函数的正负区间

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 用导数看二次函数
- f′(x) = 2ax + b，f′(x)=0 ⟺ x = −b/(2a)（顶点横坐标）
- a>0：x<h 时 f′<0 递减，x>h 时 f′>0 递增，与作差得到的单调性一致
- 平均变化率 = 区间中点处的导数：抛物线的割线平行于区间中点处的切线
- 切线：y=f(x₀)+(2ax₀+b)(x−x₀)；例 y=x² 在 (1,1) 处：y=2x−1
- f(x)−切线=a(x−x₀)²：联立得重根、Δ=0，与“直线与抛物线相切”的判定一致

#### F′(x) = 3Ax² + 2Bx + C 是二次函数

#### 与导数衔接
- 三次函数的导数是二次函数
- 导函数（二次）为正的区间上递增，为负的区间上递减
- 导函数 Δ>0：两个变号零点，一个极大值点、一个极小值点
- 导函数 Δ≤0：不变号（重根处为 0 也不变号，如 y=x³），没有极值，单调性不变
- F′(x₀)=0 是 x₀ 为极值点的必要不充分条件（F 在 x₀ 处可导）
- 三次函数（三次项系数为正）有三个零点 ⟺ 导函数 Δ>0，且极大值 >0> 极小值
- 导函数 = 恒正因子 × 二次式（如 eˣ·(x²−x−2)，或 x>0 时 ((x−1)(x−λ))/x）：单调性只看二次因式的符号，含参时比较两根大小

#### 牛顿法求根
- 从 x₀ 出发，用切线与 x 轴的交点逼近：xₖ₊₁ = xₖ − f(xₖ)/f′(xₖ)
- 例：x²+x−1=0，x₀=1：x₁=2/3，x₂≈0.619，真根 (√5−1)/2≈0.618
