- 本集结论：y 变成 t 的二次函数，t 取 g(x) 的值域；二次型复合：换元

## 这一集要讲明白的一件事
指数、三角、对数式里藏着二次函数时，令 t 等于里层的式子，先求 t 的范围，再在这个范围上求二次函数的最值；范围是开区间或无界时，看端点能否取到。

## 开场问题（不依赖其他集）
4ˣ−2ˣ⁺¹ 的最小值是多少？有最大值吗？sin²x+cos x 的最大值、最小值呢？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **指数、三角、对数的基本事实**：2ˣ>0 且取遍全体正数，y=2ˣ 在 ℝ 上递增；4ˣ=(2ˣ)²，2ˣ⁺¹=2·2ˣ；sin²x=1−cos²x，cos x 取遍 [−1,1]；y=log₂u 在 u>0 上递增。
- **闭区间上的最值**
  - 条件：x∈[m,n]
  - h<m：在 [m,n] 上递增，最小 f(m)，最大 f(n)
  - h>n：递减，最小 f(n)，最大 f(m)
  - m≤h≤n：最小 f(h)；最大取 f(m)、f(n) 中离轴远的
  - （以上 a>0；a<0 时最大、最小对调）
  - 由来（简短复习）：由“单调性”：【分类讨论】按对称轴 h 与 [m,n] 的位置分三类（a>0）；h<m：区间在轴右侧，递增 ⇒ 最小 f(m)，最大 f(n)；h>n：区间在轴左侧，递减 ⇒ 最小 f(n)，最大 f(m)；m≤h≤n：左减右增 ⇒ 最小 f(h)；最大在离轴远的端点（远近规律）。
- **值域**
  - 条件：x∈ℝ
  - a>0：[−Δ/(4a), +∞)
  - a<0：(−∞, −Δ/(4a)]
  - 由来（简短复习）：由“最值”：【代入】任给 u≥0，取 x=h+√u，就有 (x−h)²=u；所以 (x−h)² 取遍 [0,+∞)。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

#### 二次型复合：换元
- 条件：新变量 t 的范围
- y=f(g(x))：令 t=g(x)，先求 t 的范围（可能是开区间、可能无界）
- 再在 t 的范围上求最值：闭区间用闭区间最值表；开区间、无界看端点能否取到
- 例：4ˣ − 2ˣ⁺¹ = t² − 2t（t=2ˣ>0）：
- 最小值 −1（t=1），没有最大值
- 例：sin²x + cos x = −t² + t + 1（t=cos x∈[−1,1]）：
- 最大 5/4，最小 −1
- 二次函数在里层：y=log₂(x²+x+1)，先求 u=x²+x+1≥3/4
- log₂ 递增，值域 [log₂(3/4), +∞)
- 正态密度的指数 −(x−μ)²/(2σ²)：二次在里层，曲线关于 x=μ 对称，x=μ 处最高
- 比较 g(二次式) 与 g(常数)：先求内层范围，再看外层单调；例：a²+2≥2，ln 递增 ⇒ ln(a²+2) ≥ ln 2
- 指数不等式化成二次不等式：(√3−√2)^(m²−m)>(√3−√2)²，底数在 0 与 1 之间，指数函数递减 ⇒ m²−m<2 ⇒ −1<m<2
