# T02｜题型串讲：最值与值域

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **y=2ˣ 的单调性**：y=2ˣ 在 ℝ 上递增，所以 x∈[−1,2] 时 2ˣ∈[1/2,4]。
- **闭区间上的最值**
  - 条件：x∈[m,n]
  - h<m：在 [m,n] 上递增，最小 f(m)，最大 f(n)
  - h>n：递减，最小 f(n)，最大 f(m)
  - m≤h≤n：最小 f(h)；最大取 f(m)、f(n) 中离轴远的
  - （以上 a>0；a<0 时最大、最小对调）
  - 由来（简短复习）：由“单调性”：【分类讨论】按对称轴 h 与 [m,n] 的位置分三类（a>0）；h<m：区间在轴右侧，递增 ⇒ 最小 f(m)，最大 f(n)；h>n：区间在轴左侧，递减 ⇒ 最小 f(n)，最大 f(m)；m≤h≤n：左减右增 ⇒ 最小 f(h)；最大在离轴远的端点（远近规律）。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。
- **最值**
  - 条件：x∈ℝ；a>0
  - 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
  - a<0 时：最大值 −Δ/(4a)，没有最小值
  - 由来（简短复习）：由“顶点式”：【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0；⇒ f(x) ≥ k，x=h 取等；(x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值。
- **含参最值**
  - 条件：参数在 h 或区间里
  - 轴动区间定：按 h 在区间左、内、右分类
  - 区间动轴定：按区间在轴左、跨轴、在轴右分类
  - a>0 求最大值、a<0 求最小值：比较 h 与区间中点 (m+n)/2，取离轴远的端点
  - 另一种最值：看顶点 h 是否落在区间内（在内取 f(h)，不在内看单调性）
  - 由来（简短复习）：由“闭区间上的最值”：【分类讨论】参数在对称轴里：轴动区间定；参数在区间里：区间动轴定；另一种最值看顶点是否落在区间内。由“f(n) − f(m) = a(n−m)(m+n−2h)”：【分类讨论】a>0：h<(m+n)/2 时 f(n) 大，h>(m+n)/2 时 f(m) 大，相等时一样大；所以 a>0 的最大值、a<0 的最小值取离轴远的端点。
- **作差恒等式**
  - f(x₁) − f(x₂) = a(x₁ − x₂)(x₁ + x₂ − 2h)
  - 平均变化率（x₁≠x₂）：(f(x₁)−f(x₂))/(x₁−x₂) = a(x₁+x₂−2h)
  - 由来（简短复习）：由“f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]”：「平方差」(x₁−h)²−(x₂−h)² = (x₁−x₂)(x₁+x₂−2h)；【同除】x₁≠x₂ 时两边除以 x₁−x₂，得平均变化率。
- **值域**
  - 条件：x∈ℝ
  - a>0：[−Δ/(4a), +∞)
  - a<0：(−∞, −Δ/(4a)]
  - 由来（简短复习）：由“最值”：【代入】任给 u≥0，取 x=h+√u，就有 (x−h)²=u；所以 (x−h)² 取遍 [0,+∞)。
- **二次型复合：换元**
  - 条件：新变量 t 的范围
  - y=f(g(x))：令 t=g(x)，先求 t 的范围（可能是开区间、可能无界）
  - 再在 t 的范围上求最值：闭区间用闭区间最值表；开区间、无界看端点能否取到
  - 例：4ˣ − 2ˣ⁺¹ = t² − 2t（t=2ˣ>0）：
  - 最小值 −1（t=1），没有最大值
  - 例：sin²x + cos x = −t² + t + 1（t=cos x∈[−1,1]）：
  - 最大 5/4，最小 −1
  - 二次函数在里层：y=log₂(x²+x+1)，先求 u=x²+x+1≥3/4
  - log₂ 递增，值域 [log₂(3/4), +∞)
  - 正态密度的指数 −(x−μ)²/(2σ²)：二次在里层，曲线关于 x=μ 对称，x=μ 处最高
  - 比较 g(二次式) 与 g(常数)：先求内层范围，再看外层单调；例：a²+2≥2，ln 递增 ⇒ ln(a²+2) ≥ ln 2
  - 指数不等式化成二次不等式：(√3−√2)^(m²−m)>(√3−√2)²，底数在 0 与 1 之间，指数函数递减 ⇒ m²−m<2 ⇒ −1<m<2
  - 由来（简短复习）：由“y 变成 t 的二次函数，t 取 g(x) 的值域”：在 t 的范围上求最值：闭区间用闭区间最值；开区间、无界时看端点能否取到。
- **判别式法求值域**
  - y = f(x)/g(x) 化为关于 x 的方程 → 二次项系数含 y：为 0 时单独判断；不为 0 时 Δ≥0
  - Δ≥0 只给出候选：每个候选 y 都要有 x 满足原定义域、且分母 g(x)≠0，不能只检验端点；定义域是区间时，化为“方程在该区间内有根”，用根的分布
  - 例：y=(x²−x)/(x²−1)：Δ=(2y−1)²≥0 恒成立，但 y=1/2 时根只有 x=1（被排除），y=1 时也只有 x=1，值域是 y≠1 且 y≠1/2
  - 由来（简短复习）：由“x 有实根 ⟹ Δ≥0：得到候选 y”：【检验】候选 y 回代：对应的 x 要在定义域内、分母 ≠0。
- **二次函数模型（实际应用）**
  - 条件：实际意义的定义域
  - 按题意列出二次函数，先写出定义域（长度为正、件数为整数等）
  - 再在定义域上求最值：区间上看对称轴位置，整数自变量：a>0 的最小值、a<0 的最大值取定义域内离轴最近的整数
  - 例：20 m 篱笆围靠墙矩形（墙足够长），垂直墙的边长 x：
  - S=x(20−2x)，0<x<10，x=5 时最大 50
  - 由来（简短复习）：由“闭区间上的最值”：【建模】设自变量 x，按题意列函数，如靠墙矩形面积 S=x(20−2x)；由实际意义写定义域：长度为正 ⇒ 0<x<10；在定义域上求最值：对称轴 x=5 在区间内，a<0 ⇒ x=5 时最大 50；整数自变量见整数最值。
- **整数自变量上的最值**
  - 条件：自变量取整数；a>0
  - a>0：最小值在定义域内离对称轴 h 最近的整数处取到（两个一样近则都取到）
  - a<0 的最大值同理
  - 例：Sₙ=2n²−30n，h=7.5，n=7 或 8 时最小，S=−112
  - 等差数列（a₁ 首项，d 公差）：由 Sₙ=na₁+n(n−1)d/2 展开得 Sₙ=(d/2)n²+(a₁−d/2)n，d≠0 时是 n 的二次函数，常数项为 0
  - 反过来：Sₙ=An²+Bn+C 是等差数列的前 n 项和 ⟺ C=0（C≠0 时从第 2 项起等差）
  - 另一种判法：a₁<0、d>0 时，Sₙ 在 aₙ≤0≤aₙ₊₁ 处最小，与离轴最近的整数一致；S_k=0（k≠0）⇒ 对称轴 h=k/2
  - 等比数列前 n 项积：a₁=4，q=1/2 ⇒ Tₙ=2^((5n−n²)/2)，指数是 n 的二次式，n=2 或 3 时最大 8
  - 由来（简短复习）：由“远近规律”：【远近规律】a>0：|x−h| 越小，f(x) 越小；自变量只取整数 ⇒ 只需比较 h 左右最近的两个整数；两个一样近（h 是某整数加 0.5）时都取到；例 h=7.5 ⇒ n=7、8。
- **统计与概率中的二次：方差、最小二乘**
  - Q(t)=[(x₁−t)²+(x₂−t)²+…+(xₙ−t)²]/n 展开是 t 的二次函数（二次项系数 1）
  - 对称轴 t=(x₁+x₂+…+xₙ)/n：取平均数时偏差平方和最小，Q 的最小值就是方差
  - 配方成顶点式：Q(t) = 方差 + (t − 平均数)²；t=0 得 方差 = 平方的平均数 − 平均数²；分层合并的方差公式也由此得到
  - 已知方差反求某个数据：方差是这个数据的二次函数，列二次方程（可能两解）；例：12、13、15、16、17、14、a 的方差为 4 ⇒ a=11 或 18
  - 随机变量：Σ(xᵢ−t)²pᵢ = D(X) + (t−E(X))²，t=E(X) 时最小
  - 单个数据的范围：(xₖ − 平均数)² ≤ n·方差（其余偏差的平方都 ≥0）；例：10 个整数平均 2、方差 3 ⇒ (xₖ−2)² ≤ 30 ⇒ xₖ ≤ 7
  - 数据和固定且都非负，求方差最大：平均数固定，只看平方和；两数之和 S 固定、x∈[0,S] 时 x²+(S−x)² 开口向上，最大值在端点 x=0 或 S，所以数据往一个上集中；例：a+b+c=600（非负）⇒ a=600、b=c=0 时方差最大 80000
  - 概率：两点分布方差 p(1−p)、二项分布方差 np(1−p)，p=1/2 时最大；A、B 独立，P(A)=p，P(B)=1−p：P(AB)=p(1−p) 最大 1/4
  - 回归直线（斜率记 k，截距记 d）：固定 k，各点竖直偏差的平方和是 d 的二次函数（二次项系数为数据个数 n>0），最小处 d = y 的平均数 − k·x 的平均数，所以回归直线过样本中心点
  - 教材的回归直线记号：斜率、截距的字母上加“^”，表示估计值
  - 由来（简短复习）：由“最值”：【配方法】Q(t)=[(x₁−t)²+…+(xₙ−t)²]/n 展开：Q(t)=t² − 2·(平均数)·t + (平方的平均数)；二次项系数 1>0，对称轴 t=平均数 ⇒ 在平均数处最小；最小值 = 平方的平均数 − 平均数² = 方差。
- **直线截抛物线的弦长**
  - 条件：Δ′>0（两个交点）
  - y=kx+m 代入得 a′x²+b′x+c′=0（与抛物线 a′=a；与圆、椭圆等联立时 a′ 另算），Δ′=b′²−4a′c′
  - 弦的两端 P、Q：|PQ| = √(1+k²)·|x₁−x₂| = √(1+k²)·√(Δ′)/|a′|
  - 对 y 消元时：|PQ| = √(1+1/k²)·|y₁−y₂|（k≠0）
  - 例：y=x² 与 y=x：|PQ| = √2
  - 由来（简短复习）：由“|PQ| = √(1+k²)·|x₁−x₂|”：「韦达」用于联立后的方程：(x₁−x₂)²=(x₁+x₂)²−4x₁x₂=Δ′/a′²；⇒ |x₁−x₂|=√(Δ′)/|a′|。
- **对称轴**
  - f(h + t) = f(h − t)，图像关于 x=h 对称
  - 由来（简短复习）：由“顶点式”：【代入】x=h+t：f(h+t)=a·t²+k；x=h−t：f(h−t)=a·(−t)²+k=at²+k；⇒ f(h+t)=f(h−t)：点 (h+t, y) 与 (h−t, y) 同在图像上，关于直线 x=h 对称。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 题型（按顺序讲）
### 1. 看到：二次函数在给定区间上求最值
- 反推：先求对称轴 x=h，再看 h 与区间的位置
- 先查：开口方向 a；区间开闭、是否无界、端点能否取到
- 用到的结论：闭区间上的最值、单调性、最值
- 例题：求 f(x)=−x²+4x 在 [0,3] 上、在 [1,5) 上的最值。
  - a=−1<0，h=2。[0,3]：轴在区间内，最大 f(2)=4；离轴远的端点是 0，最小 f(0)=0。
  - [1,5)：最大仍是 f(2)=4；最小本应在离轴远的端点 5，但 5 取不到（函数值趋近 −5），所以没有最小值，值域 (−5,4]。
  - 答案：[0,3] 上最大 4、最小 0；[1,5) 上最大 4、没有最小值

### 2. 看到：含参数的最值（轴动 / 区间动）
- 反推：按对称轴与区间的相对位置分类；a>0 求最大值、a<0 求最小值时，用区间中点判断取哪个端点；另一种最值按顶点是否落在区间内判断
- 先查：a 的正负；参数在轴里还是在区间里
- 用到的结论：含参最值、闭区间上的最值、作差恒等式
- 例题：求 f(x)=x²−2tx+3 在 [0,2] 上的最小值 g(t)。
  - h=t，a=1>0。按轴与区间的位置分三类：t<0 时递增，最小 f(0)=3；0≤t≤2 时最小 f(t)=3−t²；t>2 时递减，最小 f(2)=7−4t。
  - 答案：g(t)=3（t<0）；3−t²（0≤t≤2）；7−4t（t>2）

### 3. 看到：求值域（二次、换元、分式）
- 反推：二次（x∈ℝ）：看开口和顶点；限定区间：查闭区间最值；换元：先求新变量范围；分式：判别式法
- 先查：定义域；区间开闭与端点；分式要逐个检验候选值
- 用到的结论：值域、闭区间上的最值、二次型复合：换元、判别式法求值域
- 例题：(1) 求 y=x²−2x（x∈[2,4]）的值域；(2) 求 y=x+√(1−x) 的值域。
  - (1) h=1 在区间左侧，函数在 [2,4] 上递增：值域 [f(2),f(4)]=[0,8]。不能直接写成 x∈ℝ 时的 [−1,+∞)。
  - (2) 令 t=√(1−x)≥0，x=1−t²，y=−t²+t+1，t=1/2 时最大 5/4，t 无上界时 y 无下界。
  - 答案：(1) [0,8]；(2) (−∞, 5/4]

### 4. 看到：分式函数求值域
- 反推：化为关于 x 的方程，Δ≥0 得到候选 y
- 先查：二次项系数为 0 的 y；每个候选 y 都要对应定义域内、分母≠0 的 x（不只查端点）
- 用到的结论：判别式法求值域
- 例题：求 y=(x²−x+1)/(x²+x+1) 的值域。
  - 分母恒正，化为 (y−1)x²+(y+1)x+(y−1)=0。
  - y=1 时 2x=0，x=0，可以取到；y≠1 时 Δ=(y+1)²−4(y−1)²≥0 ⇒ (3−y)(3y−1)≥0 ⇒ 1/3≤y≤3。
  - 分母 x²+x+1 恒正、定义域是全体实数，所以 Δ≥0 的每个 y 都有可用的 x，不会有候选被排除（y=3 时 x=−1，y=1/3 时 x=1，可以验证）。
  - 答案：[1/3, 3]

### 5. 看到：指数、三角式里藏着二次
- 反推：换元 t，先求 t 的范围
- 先查：t 的范围是开是闭、端点能否取到
- 用到的结论：二次型复合：换元
- 例题：求 y=4ˣ−2ˣ⁺¹+3（x∈[−1,2]）的最值。
  - 令 t=2ˣ，x∈[−1,2] ⇒ t∈[1/2,4]；y=t²−2t+3。
  - 对称轴 t=1 在区间内：最小 y(1)=2；离轴远的端点是 4：最大 y(4)=11。
  - 答案：最小 2（x=0），最大 11（x=2）

### 6. 看到：实际应用：利润、面积的最值（刹车距离类是解不等式，见解一元二次不等式）
- 反推：列出二次函数 → 写出实际意义的定义域 → 在定义域上求最值
- 先查：自变量是否只能取整数；端点能否取到
- 用到的结论：二次函数模型（实际应用）、闭区间上的最值、整数自变量上的最值
- 例题：20 m 篱笆一边靠墙围矩形，墙长 8 m，求最大面积。
  - 设垂直墙的边长 x，S=x(20−2x)。平行墙的边 20−2x≤8 且 >0 ⇒ 6≤x<10。
  - 对称轴 x=5 在区间左侧，a<0，S 在 [6,10) 上递减，最大 S(6)=48。
  - 答案：48 m²（x=6）

### 7. 看到：圆锥曲线上的点到定点距离的最值
- 反推：定点在曲线的对称轴上时，用曲线方程消去一个变量，把距离的平方 d² 化成 x（或 y）的二次函数 → 在变量范围上求最值
- 先查：变量范围（椭圆：x 在长轴两端点的横坐标之间；抛物线 y²=2px（p>0）：x≥0，范围无界时看端点能否取到；双曲线：x≤−a 或 x≥a 两段，分段求最值）
- 用到的结论：闭区间上的最值、含参最值、二次型复合：换元
- 例题：求椭圆 x²/4+y²=1 上的点到 (1,0) 距离的最小值和最大值。
  - y²=1−x²/4，d²=(x−1)²+1−x²/4=(3/4)x²−2x+2，x∈[−2,2]。
  - 对称轴 x=4/3 在区间内：最小 d²=2/3；离轴远的端点 x=−2：最大 d²=9。
  - 答案：最小 √6/3（x=4/3），最大 3（点 (−2,0)）

### 8. 看到：为什么方差、回归直线用平均数
- 反推：偏差平方和是二次函数，在对称轴处最小
- 先查：二次项系数为正
- 用到的结论：统计与概率中的二次：方差、最小二乘、最值
- 例题：数据 1、2、6，求使 Q(t)=[(1−t)²+(2−t)²+(6−t)²]/3 最小的 t 及最小值。
  - 展开：Q(t)=t²−6t+41/3，二次项系数 1>0。
  - 对称轴 t=3（正是平均数），最小值 Q(3)=(4+1+9)/3=14/3，就是这组数据的方差。
  - 答案：t=3，最小值 14/3

### 9. 看到：弦长、面积的最值
- 反推：弦长或面积写成参数的式子（常是二次式或其平方根）→ 参数范围由 Δ>0 给出 → 求最值
- 先查：参数范围是开区间（Δ>0），端点取不到
- 用到的结论：直线截抛物线的弦长、闭区间上的最值、二次型复合：换元
- 例题：直线 y=x+m 与椭圆 x²/4+y²=1 交于 A、B，求 |AB| 的最大值。
  - 联立：5x²+8mx+4m²−4=0，Δ=80−16m²>0 ⇒ m²<5。
  - |AB|=√2·√Δ/5=(4√2/5)·√(5−m²)，m=0 时最大。
  - 答案：4√10/5

### 10. 看到：向量模长含参数：求最值或恒成立
- 反推：向量 p、q（q≠0）：|p−tq|² = |q|²t² − 2(p·q)t + |p|² 是 t 的二次函数，对称轴 t=(p·q)/|q|²
- 先查：先平方再看二次函数；“恒有 |p−tq| ≥ |p−t₀q|” ⟺ t₀ 是最小值点
- 用到的结论：最值、对称轴、顶点式
- 例题：向量 p、q 满足 |p|=2，|q|=1，p·q=1，求 |p−tq| 的最小值。
  - |p−tq|²=t²−2t+4=(t−1)²+3。
  - t=1 时最小，|p−tq| 最小为 √3。
  - 答案：√3

### 11. 看到：两种方案的方差和最小
- 反推：D(aX)=a²D(X)：方差和化成投入量 x 的二次函数，在 x 的范围上求最小值
- 先查：x 的实际范围（如 0≤x≤总额）
- 用到的结论：统计与概率中的二次：方差、最小二乘、闭区间上的最值
- 例题：甲、乙两项目利润相互独立，每投 1 万元利润的方差分别为 1、3。共投 100 万元，甲投 x 万元，求总利润方差的最小值。
  - D(aX)=a²D(X)：总方差 f(x)=x²+3(100−x)²=4x²−600x+30000，x∈[0,100]。
  - 对称轴 x=75 在区间内，f(75)=7500。
  - 答案：x=75 时最小 7500

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“Δ≥0”写成“Δ>0”，或省掉“a>0”“x∈ℝ”）。数值必须自己再算一遍。
- 同一字母在一集里只表示一个量：二次项系数用 a，题目里的参数改用 m、t、k 等。
