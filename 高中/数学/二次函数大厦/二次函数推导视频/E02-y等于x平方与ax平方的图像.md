# E02｜y=x² 与 y=ax² 的图像：a 管开口方向和大小

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：y = x² 的图像；y = ax² 的图像（a≠0）

## 这一集要讲明白的一件事
从 y=x² 描点出发，用“同一个 x，纵坐标乘 a”得到 y=ax² 的全部特征：a 的符号定开口方向，|a| 定开口大小，对称轴和顶点不变。

## 开场问题（不依赖其他集）
y=x²、y=2x²、y=−½x² 的图像有什么相同、有什么不同？a 到底管了图像的哪几件事？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **【约定】点在图像上**
  - 点 (x₀, y₀) 在 y=f(x) 的图像上 ⟺ y₀ = f(x₀)
  - 由来（简短复习）：这是课本的定义或约定，直接承认（数与形互相翻译的依据）。
- **【公理推论】平方非负**
  - x² ≥ 0，等号 ⟺ x=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【约定】点在图像上 → y = x² 的图像**（推导；含 2 个小步骤，逐个展开）
   - 【列表描点】x=0,±1,±2 代入 y=x²，描点连线
   - 【代入】(−x)²=x²：(x,y) 在图像上 ⟺ (−x,y) 也在，关于 y 轴对称
2. **y = x² 的图像 → y = ax² 的图像（a≠0）**（推导）
   - 【伸缩】同一个 x，纵坐标乘 a
   - a<0 时翻到 x 轴下方；|a| 越大，同一 x 处离 x 轴越远，开口越窄
   - x 与 −x 的纵坐标同乘 a 仍相等：对称性不变，顶点仍是 (0,0)
3. **【公理推论】平方非负 → y = x² 的图像**（提供前提）
   - 【前提】x²≥0：图像在 x 轴上方，最低点 (0,0)

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### y = x² 的图像
- 过原点，开口向上
- 关于 y 轴对称；最低点 (0,0)
- 也是幂函数 y=x^α 中 α=2 的情形：偶函数，在 [0,+∞) 上递增

#### y = ax² 的图像（a≠0）
- a>0 开口向上，a<0 开口向下
- |a| 越大，开口越小
- 关于 y 轴对称，顶点 (0,0)（a>0 最低点，a<0 最高点）

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 同一坐标系画 y=x²、y=2x²、y=½x²、y=−x²；在 x=1 处画竖线，标出纵坐标 1、2、½、−1。
- (x,y) 与 (−x,y) 两点用水平虚线连起来，显示关于 y 轴对称。

## 着重标注（本集必须突出的地方）
- (−x)²=x² ⇒ 关于 y 轴对称；x²≥0 ⇒ 最低点 (0,0)：这两句是说理，描点只是看形状。
- a<0 时整条图像翻到 x 轴下方，顶点变成最高点。

## 解题思维导向（片尾一句话）
看到 y=ax² → 先看 a 的符号定开口，再看 |a| 定胖瘦。

## 易错点与边界（必须讲到）
- 是 |a| 越大开口越小，不是 a 越大开口越小（比较 y=−3x² 和 y=x²）。
- a<0 时顶点 (0,0) 是最高点。
