# E10｜配方得顶点式：一般式、顶点式、交点式

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：a[x² + (b/a)x] + c；a[(x + b/2a)² − b²/(4a²)] + c；顶点式；交点式（两根式）；待定系数法求解析式；系数的几何意义

## 这一集要讲明白的一件事
一般式配方得到顶点式；有实根时由韦达得到交点式。三种式子描述同一条抛物线：题目给什么条件就选哪种式子求解析式，系数 a、b、c 也能在图上读出来。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。
- **平移：y = a(x−h)² + k**
  - 由 y=ax² 向右平移 h、向上平移 k
  - 顶点 (h, k)，对称轴 x=h
  - 口诀：左加右减（括号里）、上加下减（括号外）
  - 移轴（坐标变换）：令 x′=x−h，y′=y−k，方程化成 y′=ax′²
  - 由来（简短复习）：由“y = ax² 的图像（a≠0）”：【代换法】(x₀,y₀) 在 y=ax² 上；⟺ (x₀+h, y₀+k) 在 y=a(x−h)²+k 上。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。
- **y = ax² 的图像（a≠0）**
  - a>0 开口向上，a<0 开口向下
  - |a| 越大，开口越小
  - 关于 y 轴对称，顶点 (0,0)（a>0 最低点，a<0 最高点）
  - 由来（简短复习）：由“y = x² 的图像”：【伸缩】同一个 x，纵坐标乘 a；a<0 时翻到 x 轴下方；|a| 越大，同一 x 处离 x 轴越远，开口越窄；x 与 −x 的纵坐标同乘 a 仍相等：对称性不变，顶点仍是 (0,0)。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】二次函数 → a[x² + (b/a)x] + c**（推导）
   - 【提取公因式】前两项提出 a（a≠0）
2. **a[x² + (b/a)x] + c → a[(x + b/2a)² − b²/(4a²)] + c**（推导）
   - 【配凑】括号内加上再减去 (b/2a)²
   - 前三项凑成「完全平方公式」(x + b/2a)²
3. **a[(x + b/2a)² − b²/(4a²)] + c → 顶点式**（推导）
   - 【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)
   - 记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)
4. **平移：y = a(x−h)² + k → 顶点式**（推导）
   - 【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式
   - ⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h
5. **韦达定理 → 交点式（两根式）**（推导）
   - 【因式分解】ax²+bx+c = a[x² − (x₁+x₂)x + x₁x₂]
   - = a(x−x₁)(x−x₂)
6. **【定义】二次函数 → 待定系数法求解析式**（推导）
   - 【待定系数】设出含未知系数的式子，每个已知条件列一个方程
   - 已知三点 → 设 y=ax²+bx+c，代入得三元一次方程组
   - 已知顶点 (h,k) → 设 y=a(x−h)²+k，再代一点求 a
   - 已知与 x 轴交点 x₁、x₂ → 设 y=a(x−x₁)(x−x₂)，再代一点求 a
7. **顶点式 → 系数的几何意义**（推导）
   - 【代入特定值】x=0：f(0)=c，图像与 y 轴交于 (0,c)
   - 对称轴 h=−b/(2a)：h<0 ⟺ b/(2a)>0 ⟺ a、b 同号（ab>0）
   - b=0 ⟺ h=0：对称轴就是 y 轴
8. **顶点式 → 待定系数法求解析式**（提供前提）
   - 【前提】顶点式
9. **交点式（两根式） → 待定系数法求解析式**（提供前提）
   - 【前提】交点式
10. **y = ax² 的图像（a≠0） → 系数的几何意义**（提供前提）
   - 【前提】a 定开口方向和大小

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### a[x² + (b/a)x] + c

#### a[(x + b/2a)² − b²/(4a²)] + c

#### 顶点式
- f(x) = a(x − h)² + k
- h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)

#### 交点式（两根式）
- 条件：Δ≥0
- f(x) = a(x − x₁)(x − x₂)
- x₁、x₂ 是 f(x)=0 的两根

#### 待定系数法求解析式
- 已知三点 → 设一般式 ax²+bx+c
- 已知顶点（或对称轴、最值）→ 设顶点式
- 已知与 x 轴两交点 → 设交点式

#### 系数的几何意义
- a：开口方向和大小
- c = f(0)：与 y 轴交点 (0, c)
- ab>0 对称轴在 y 轴左侧，ab<0 在右侧（左同右异）；b=0 时对称轴就是 y 轴

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 同一条抛物线 y=2x²−8x+6 上标出顶点 (2,−2)、与 x 轴交点 1 和 3、与 y 轴交点 (0,6)，分别对应三种式子。
- 对称轴位置与 a、b 符号的关系：左同右异。

## 着重标注（本集必须突出的地方）
- 配方三步（提出 a、括号内补 (b/2a)²、括号外减 b²/(4a)）分开写。
- ▼ Δ≥0 才有交点式（Δ<0 时与 x 轴没有交点）。
- 对称轴 −b/(2a)<0 ⟺ ab>0。

## 解题思维导向（片尾一句话）
求解析式 → 给三点用一般式；给顶点、对称轴或最值用顶点式；给与 x 轴两个交点用交点式。

## 易错点与边界（必须讲到）
- 配方时括号外的常数要算对：减去的是 b²/(4a)。
- Δ<0 时没有实数范围的交点式。
- “左同右异”说的是 a、b 同号时对称轴在 y 轴左侧。
