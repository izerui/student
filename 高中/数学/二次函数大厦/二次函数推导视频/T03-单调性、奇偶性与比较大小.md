# T03｜题型串讲：单调性、奇偶性与比较大小

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。
- **对称轴**
  - f(h + t) = f(h − t)，图像关于 x=h 对称
  - 由来（简短复习）：由“顶点式”：【代入】x=h+t：f(h+t)=a·t²+k；x=h−t：f(h−t)=a·(−t)²+k=at²+k；⇒ f(h+t)=f(h−t)：点 (h+t, y) 与 (h−t, y) 同在图像上，关于直线 x=h 对称。
- **远近规律**
  - 条件：a>0
  - |x − h| 越大，f(x) 越大
  - 比较函数值：看谁离对称轴远；a<0 时反过来
  - 由来（简短复习）：由“f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]”：「平方保序」0≤|x₂−h|<|x₁−h| ⇒ (x₂−h)²<(x₁−h)²；a>0：差 f(x₁)−f(x₂) >0，离轴远的函数值大。
- **两点同高 ⇒ 对称轴**
  - f(x₁)=f(x₂)，x₁≠x₂ ⇒ 对称轴 x = (x₁+x₂)/2
  - 由来（简短复习）：由“作差恒等式”：【作差】f(x₁)=f(x₂) ⇒ 0 = a(x₁−x₂)(x₁+x₂−2h)；a≠0，x₁≠x₂ ⇒ 只能第三个因子为 0：x₁+x₂−2h=0 ⇒ h=(x₁+x₂)/2。
- **奇偶性**
  - 条件：定义域关于原点对称
  - 定义域为 ℝ（或关于原点对称）时：b=0 ⟺ f 是偶函数
  - 定义域是区间时，二次函数不可能是奇函数
  - 例：y=x²，x∈[−1,3] 定义域不对称，非奇非偶
  - 由来（简短复习）：由“【定义】单调性、最值、奇偶性”：【代入】f(−x)=f(x) ⟺ 2bx=0 对定义域内一切 x ⟺ b=0（定义域含非零的 x）；奇函数需 2ax²+2c=0 对定义域内一切 x；定义域含两个 x² 不同的 x（如区间）时得 a=c=0，与 a≠0 矛盾。
- **【定义】单调性、最值、奇偶性**
  - 在区间 D 上递增：对 D 内任意 x₁<x₂，都有 f(x₁)<f(x₂)；递减反之（取几个点验证不够）
  - 最小值：f(x₀)≤f(x) 对定义域内一切 x 成立，且取得到
  - 定义域关于原点对称时：偶函数 f(−x)=f(x)；奇函数 f(−x)=−f(x)
  - 定义域不关于原点对称：既不是奇函数也不是偶函数
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **与导数衔接**
  - 三次函数的导数是二次函数
  - 导函数（二次）为正的区间上递增，为负的区间上递减
  - 导函数 Δ>0：两个变号零点，一个极大值点、一个极小值点
  - 导函数 Δ≤0：不变号（重根处为 0 也不变号，如 y=x³），没有极值，单调性不变
  - F′(x₀)=0 是 x₀ 为极值点的必要不充分条件（F 在 x₀ 处可导）
  - 三次函数（三次项系数为正）有三个零点 ⟺ 导函数 Δ>0，且极大值 >0> 极小值
  - 导函数 = 恒正因子 × 二次式（如 eˣ·(x²−x−2)，或 x>0 时 ((x−1)(x−λ))/x）：单调性只看二次因式的符号，含参时比较两根大小
  - 由来（简短复习）：由“F′(x) = 3Ax² + 2Bx + C 是二次函数”：「三个二次的关系」读出 F′ 的正负区间（3A<0 时先乘 −1 化正）；【前提】F′>0 的区间递增，F′<0 的区间递减；导数为 0 且左右变号的点是极值点（课本）。
- **解一元二次不等式**
  - ① 二次项系数化为正（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写解集
  - 解集用集合（或区间）写：{x | x<x₁ 或 x>x₂}、{x | x₁<x<x₂}；无解写 ∅，对一切 x 成立写 ℝ
  - 也可先因式分解：(x−x₁)(x−x₂)>0 ⟺ 两个因式同号，化成两个一元一次不等式组
  - 例（实际情境，s 为刹车距离，单位米；v 为车速，单位千米每小时）：s=v²/100−v/10>6（v>0）⇒ (v−30)(v+20)>0 ⇒ v>30
  - 由来（简短复习）：由“三个二次的关系”：【同乘法】a<0 时两边乘 −1：系数化正，不等号反向；化成 a>0 后：求 Δ 和两根，按三个二次的关系读出解集；例：−x²+x+2>0 ⟺ x²−x−2<0 ⟺ (x−2)(x+1)<0 ⟺ −1<x<2。由“一元二次方程的解法”：【因式分解】(x−x₁)(x−x₂)>0 ⟺ 两个因式同号；⟺ x−x₁、x−x₂ 同正，或同负：两个一元一次不等式组。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **凸性：中点不等式**
  - 条件：a>0
  - a>0：f((x₁+x₂)/2) ≤ (f(x₁)+f(x₂))/2，等号 ⟺ x₁=x₂；a<0 时反向
  - 几何意义：a>0 时，弦的中点在抛物线上方（整条弦都在上方）
  - 例：f(x)=x²，x₁=0，x₂=2：f(1)=1 < (0+4)/2=2
  - 由来（简短复习）：由“顶点式”：【作差】记 u=x₁−h，v=x₂−h：；(f(x₁)+f(x₂))/2 − f((x₁+x₂)/2) = a(u²+v²)/2 − a((u+v)/2)²；= a(u−v)²/4 = a(x₁−x₂)²/4。
- **作差恒等式**
  - f(x₁) − f(x₂) = a(x₁ − x₂)(x₁ + x₂ − 2h)
  - 平均变化率（x₁≠x₂）：(f(x₁)−f(x₂))/(x₁−x₂) = a(x₁+x₂−2h)
  - 由来（简短复习）：由“f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]”：「平方差」(x₁−h)²−(x₂−h)² = (x₁−x₂)(x₁+x₂−2h)；【同除】x₁≠x₂ 时两边除以 x₁−x₂，得平均变化率。
- **对称轴的一般形式**
  - f(p+x)=f(q−x) 对一切 x 成立（p、q 为常数）⇒ 图像关于 x=(p+q)/2 对称（任何函数都成立）
  - 二次函数：对称轴唯一，所以 h=(p+q)/2
  - 例：f(x)=x²+bx+c，f(1+x)=f(3−x) ⇒ h=2，b=−4
  - 由来（简短复习）：由“两点同高 ⇒ 对称轴”：【代入】取 x≠(q−p)/2：x₁=p+x 与 x₂=q−x 不同且函数值相等；二次函数由两点同高：h=(x₁+x₂)/2=(p+q)/2（一般函数的对称性由“点在图像上”证）。
- **区间上恒成立 / 能成立（参数记作 λ）**
  - 条件：x∈区间
  - 先求 g(x) 在区间上的取值范围：开还是闭、有没有无界、边界能否取到
  - λ ≥ g(x) 恒成立：g 有最大值 M ⟺ λ ≥ M
  - g 有上界、但取值范围的上边界 L 取不到 ⟺ λ ≥ L；g 向上无界 ⟹ 没有这样的 λ
  - λ ≥ g(x) 能成立（至少一个 x）：g 有最小值 m₀ ⟺ λ ≥ m₀
  - g 有下界、但取值范围的下边界 L′ 取不到 ⟺ λ > L′；g 向下无界 ⟹ 任意实数 λ 都行
  - λ ≤ g(x)：规则对称——恒成立用最小值（或下边界），能成立用最大值（或上边界）
  - 二次函数：a>0 时 f(x)≤0 在 [m,n] 上恒成立 ⟺ f(m)≤0 且 f(n)≤0（开口向上，最大值在端点）
  - 核对 g(x)=x：x∈(0,1) 时恒成立 ⟺ λ≥1，能成立 ⟺ λ>0；x∈ℝ 时恒成立无解，能成立 λ 任意
  - 由来（简短复习）：由“恒成立 ⟺ 最不利的值满足；能成立 ⟺ 最有利的值满足”：【分离参数】化成 λ 与 g(x) 比较，先求 g 的取值范围；有最值用最值；边界取不到看边界值（恒成立可取等，能成立不可取等）；无界单独判断；两边除以含 x 的式子时，先定它的正负（除以负数要变号）。
- **闭区间上的最值**
  - 条件：x∈[m,n]
  - h<m：在 [m,n] 上递增，最小 f(m)，最大 f(n)
  - h>n：递减，最小 f(n)，最大 f(m)
  - m≤h≤n：最小 f(h)；最大取 f(m)、f(n) 中离轴远的
  - （以上 a>0；a<0 时最大、最小对调）
  - 由来（简短复习）：由“单调性”：【分类讨论】按对称轴 h 与 [m,n] 的位置分三类（a>0）；h<m：区间在轴右侧，递增 ⇒ 最小 f(m)，最大 f(n)；h>n：区间在轴左侧，递减 ⇒ 最小 f(n)，最大 f(m)；m≤h≤n：左减右增 ⇒ 最小 f(h)；最大在离轴远的端点（远近规律）。
- **恰有一根在 (m, n) 内**
  - 条件：只看 (m,n) 内的根
  - f(m)·f(n) < 0 时成立
  - f(m)·f(n)=0（端点是根）或 Δ=0（重根）时单独检验
  - 由来（简短复习）：由“f(m)·f(n)<0 ⇒ (m,n) 内至少一个根”：【反证法】若两个不同实根都在 (m,n) 内：由交点式，f(m)、f(n) 都与 a 同号，与 f(m)f(n)<0 矛盾；重根 x₀ 在 (m,n) 内：f=a(x−x₀)² 不变号，同样矛盾 ⇒ 恰有一个；【分类讨论】f(m)f(n)=0（端点是根）时单独检验。
- **含参二次不等式**
  - ① 先看二次项系数：=0 时不是二次不等式（b≠0 按一次解，b=0 看常数 c）
  - ② 系数 ≠0：化为正，再看 Δ
  - ③ 有两根时比较两根大小
  - 由来（简短复习）：由“解一元二次不等式”：【分类讨论】第一层：二次项系数是否为 0？为 0 时不是二次不等式，按一次处理；第二层：系数不为 0 时化正，看 Δ<0、Δ=0、Δ>0；第三层：有两根时比较两根大小；例 (x−1)(x−m)<0：m>1 时 1<x<m，m=1 时无解，m<1 时 m<x<1。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。

## 题型（按顺序讲）
### 1. 看到：已知单调区间，求参数
- 反推：“在 D 上单调”：D 整个落在对称轴同一侧；“单调区间是 D”：D 的端点就是 h
- 先查：开口方向；二次项系数含参数时先看 =0（一次函数看 b 的符号）
- 用到的结论：单调性、对称轴
- 例题：(1) f(x)=x²+2(m−1)x+2 的单调递减区间是 (−∞,4]，求 m；(2) 若只说 f 在 (−∞,4] 上递减，求 m；(3) f(x)=ax²+2x+1 在 (−∞,1] 上递增，求 a。
  - (1) 单调递减区间是 (−∞,4] ⇒ 区间端点就是对称轴：h=1−m=4，m=−3。
  - (2) 在 (−∞,4] 上递减 ⇒ 区间整个落在轴左侧：4≤1−m，m≤−3。
  - (3) a=0 时 f=2x+1 递增，符合；a>0 时在 x 很小处递减，不行；a<0 时需 1≤−1/a，得 −1≤a<0。合起来 −1≤a≤0。
  - 答案：(1) m=−3；(2) m≤−3；(3) −1≤a≤0

### 2. 看到：比较 f(x₁)、f(x₂) 的大小
- 反推：看谁离对称轴远
- 先查：a>0 远的大，a<0 远的小
- 用到的结论：远近规律、两点同高 ⇒ 对称轴
- 例题：a<0，二次函数 f 满足 f(1+x)=f(3−x)，比较 f(−1) 与 f(4)。
  - (1+x)+(3−x)=4，两点同高 ⇒ 对称轴 x=2。
  - −1 离轴 3，4 离轴 2；a<0 时离轴远的函数值小。
  - 答案：f(−1)<f(4)

### 3. 看到：已知函数是偶函数，求参数
- 反推：定义域关于原点对称时：二次函数是偶函数 ⟺ 一次项系数 b=0
- 先查：定义域是否关于原点对称；先展开成一般式
- 用到的结论：奇偶性、【定义】单调性、最值、奇偶性
- 例题：f(x)=(x−1)²+mx+2（x∈ℝ）是偶函数，求 m。
  - 定义域 ℝ 关于原点对称；展开：f(x)=x²+(m−2)x+3。
  - 偶函数 ⟺ 一次项系数为 0：m−2=0。
  - 答案：m=2

### 4. 看到：三次函数的单调区间
- 反推：求导得二次函数，解导函数 >0、<0 的二次不等式
- 先查：导函数二次项系数为负先化正；导函数的重根处单调性不变
- 用到的结论：与导数衔接、解一元二次不等式
- 例题：求 f(x)=x³−3x 的单调区间。
  - f′(x)=3x²−3=3(x+1)(x−1)。
  - f′>0 ⟺ x<−1 或 x>1，递增；f′<0 ⟺ −1<x<1，递减。
  - 答案：增区间 (−∞,−1)、(1,+∞)，减区间 (−1,1)

### 5. 看到：三次函数的极值、有无极值求参数
- 反推：求导得二次函数：Δ>0 时有两个变号零点，才有极值
- 先查：三次项系数含参数时先看是否为 0；导函数的重根不是极值点
- 用到的结论：与导数衔接、求根公式与判别式
- 例题：f(x)=ax³+3x+2 有极值，求 a 的范围。
  - a=0 时 f=3x+2 单调，没有极值。
  - a≠0：f′(x)=3ax²+3，要有两个变号零点：Δ=0−36a>0 ⇒ a<0。
  - 答案：a<0

### 6. 看到：比较 f(两点中点) 与两端函数值的平均
- 反推：作差：两者之差 = a(x₁−x₂)²/4；a>0 且 x₁≠x₂ 时，中点的函数值更小（x₁=x₂ 时相等）
- 先查：开口方向 a
- 用到的结论：凸性：中点不等式、作差恒等式
- 例题：f(x)=x²−2x，x₁≠x₂，比较 f((x₁+x₂)/2) 与 (f(x₁)+f(x₂))/2。
  - h=1，记 u=x₁−1，v=x₂−1：(f(x₁)+f(x₂))/2 − f((x₁+x₂)/2) = (u−v)²/4 = (x₁−x₂)²/4。
  - x₁≠x₂ ⇒ 差 >0。
  - 答案：f((x₁+x₂)/2) < (f(x₁)+f(x₂))/2

### 7. 看到：抽象函数：已知 f(p+x)=f(q−x)，求对称轴
- 反推：两个自变量之和 p+q 是常数 ⇒ 对称轴 x=(p+q)/2；再用对称轴比大小、求参数
- 先查：等式对一切 x 成立；是 q−x 不是 q+x（q+x 是周期，不是对称）；比大小还要看开口方向 a（抽象函数要已知一侧的单调性）
- 用到的结论：对称轴的一般形式、两点同高 ⇒ 对称轴、远近规律
- 例题：f(x)=x²+bx+c 对一切 x 满足 f(1+x)=f(3−x)，求 b，并比较 f(0) 与 f(5)。
  - 1+x 与 3−x 之和恒为 4 ⇒ 对称轴 x=2 ⇒ −b/2=2，b=−4。
  - a=1>0，离轴远的大：|0−2|=2<|5−2|=3。
  - 答案：b=−4，f(0)<f(5)

### 8. 看到：分段函数（含二次段）在 ℝ 上单调，求参数
- 反推：每一段都单调（二次段：区间落在对称轴同一侧）+ 分界点处衔接（递增时左段在分界点的值 ≤ 右段的值）
- 先查：只看每段单调不够，分界点处的大小也要查
- 用到的结论：单调性、对称轴、【定义】单调性、最值、奇偶性
- 例题：f(x)=−x²+2ax（x≤1），f(x)=x+a（x>1）在 ℝ 上递增，求 a。
  - 二次段开口向下，对称轴 x=a，要在 (−∞,1] 上递增 ⇒ a≥1。
  - 分界点：左段 f(1)=2a−1 不超过右段在 1 处的值 1+a ⇒ a≤2。
  - 答案：1≤a≤2

### 9. 看到：已知奇（偶）函数一侧的二次解析式，求另一侧
- 反推：x<0 时 −x>0，把 −x 代入已知一侧，再用 f(x)=−f(−x)（奇）或 f(x)=f(−x)（偶）
- 先查：奇函数在 x=0 处有定义时 f(0)=0
- 用到的结论：【定义】单调性、最值、奇偶性、奇偶性
- 例题：f 是 ℝ 上的奇函数，x≥0 时 f(x)=x²+2x，求 x<0 时的解析式。
  - x<0 时 −x>0：f(−x)=x²−2x。
  - 奇函数：f(x)=−f(−x)=−x²+2x。
  - 答案：f(x)=−x²+2x（x<0）

### 10. 看到：已知函数在区间上单调（或有极值），求参数（导函数是二次）
- 反推：单调递减 ⟺ 导函数在区间上 ≤0 恒成立：开口向上时只查两个端点；有极值 ⟺ 导函数在区间内有变号零点
- 先查：导函数的开口方向；端点能否取等；变号零点不是重根
- 用到的结论：与导数衔接、区间上恒成立 / 能成立（参数记作 λ）、闭区间上的最值、恰有一根在 (m, n) 内
- 例题：y=x³−tx²−t²x+t³ 在 (−1,3) 上递减，求 t。
  - y′=3x²−2tx−t²=(3x+t)(x−t)，开口向上，要在 (−1,3) 上 ≤0 ⟺ 两端 ≤0。
  - y′(−1)=3+2t−t²≤0 ⇒ t≥3 或 t≤−1；y′(3)=27−6t−t²≤0 ⇒ t≥3 或 t≤−9。
  - 答案：t≥3 或 t≤−9

### 11. 看到：导函数含二次因式：单调区间、极值（含 eˣ、ln x）
- 反推：提出恒正因子（eˣ，或 x>0 时的 1/x），单调性只看剩下的二次式；含参时按两根的大小分类
- 先查：定义域（ln x 要 x>0）；两根是否在定义域内
- 用到的结论：与导数衔接、含参二次不等式、解一元二次不等式
- 例题：求 f(x)=(x²−3x+1)eˣ 的单调区间。
  - f′(x)=(x²−x−2)eˣ=(x−2)(x+1)eˣ，eˣ>0。
  - x<−1 或 x>2 时 f′>0；−1<x<2 时 f′<0。
  - 答案：增区间 (−∞,−1)、(2,+∞)，减区间 (−1,2)

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
### 解题导向与内容依据

- 叙述用高中生听得懂的说法，不用超纲术语。
