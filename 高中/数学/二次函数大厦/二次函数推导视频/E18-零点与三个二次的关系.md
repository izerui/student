# E18｜零点与三个二次：函数、方程、不等式

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：零点 ⟺ 根 ⟺ 交点；三个二次的关系

## 这一集要讲明白的一件事
零点、方程的根、图像与 x 轴交点的横坐标是同一组数；a>0 时开口向上，两根之外函数值为正、两根之间为负——一张图同时回答函数、方程、不等式三个问题。

## 开场问题（不依赖其他集）
画出 y=x²−x−6 的图像，能不能一眼读出 x²−x−6=0 的根、x²−x−6>0 和 <0 的解集？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **交点式（两根式）**
  - 条件：Δ≥0
  - f(x) = a(x − x₁)(x − x₂)
  - x₁、x₂ 是 f(x)=0 的两根
  - 由来（简短复习）：由“韦达定理”：【因式分解】ax²+bx+c = a[x² − (x₁+x₂)x + x₁x₂]；= a(x−x₁)(x−x₂)。
- **最值**
  - 条件：x∈ℝ；a>0
  - 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
  - a<0 时：最大值 −Δ/(4a)，没有最小值
  - 由来（简短复习）：由“顶点式”：【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0；⇒ f(x) ≥ k，x=h 取等；(x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】零点 → 零点 ⟺ 根 ⟺ 交点**（推导；含 2 个小步骤，逐个展开）
   - 【定义】零点 = 方程的根
   - 【数形结合】= 图像与 x 轴交点（y=0）
2. **零点 ⟺ 根 ⟺ 交点 → 三个二次的关系**（推导）
   - ▼ 加条件：a>0（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方
   - Δ<0：最小值 −Δ/(4a)>0，整条在上方
3. **求根公式与判别式 → 零点 ⟺ 根 ⟺ 交点**（提供前提）
   - 【前提】根的个数由 Δ 决定
4. **交点式（两根式） → 三个二次的关系**（提供前提）
   - 【前提】交点式：两根之外两个因式同号，之间异号
5. **最值 → 三个二次的关系**（提供前提）
   - 【前提】最小值 −Δ/(4a)

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【定义】零点
- 使 f(x)=0 的实数 x 叫 f 的零点

#### 零点 ⟺ 根 ⟺ 交点
- f 的零点 = 方程 f(x)=0 的实根
- = 图像与 x 轴交点的横坐标
- 个数：Δ>0 两个，Δ=0 一个，Δ<0 没有

#### 三个二次的关系
- 条件：a>0
- Δ>0：f(x)>0 ⟺ x<x₁ 或 x>x₂
- f(x)<0 ⟺ x₁<x<x₂
- Δ=0：f(x)>0 ⟺ x≠x₁；f(x)<0 无解
- Δ<0：f(x)>0 对一切 x 成立
- ≥、≤：把根并进去；Δ=0 时 f(x)≤0 ⟺ x=x₁；Δ<0 时 f(x)≤0 无解

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- Δ>0、=0、<0 三条开口向上的抛物线并排；x 轴上方部分涂一种颜色，下方涂另一种。
- 例子 y=x²−x−6：两根 −2、3；>0 时 x<−2 或 x>3；<0 时 −2<x<3。

## 着重标注（本集必须突出的地方）
- ▼ a>0。反例：a<0 时两根之外为负。
- Δ=0 时 f(x)>0 ⟺ x≠x₁（要挖去根）。
- 交点式的符号：两根之外两个因式同号，之间异号。

## 解题思维导向（片尾一句话）
二次方程、二次不等式 → 先把二次项系数化正，画开口向上的抛物线，看它与 x 轴的交点。

## 易错点与边界（必须讲到）

- a<0 先两边乘 −1 化正。
