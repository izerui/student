# E03｜平移：y=a(x−h)²+k 的顶点与对称轴

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：平移：y = a(x−h)² + k

## 这一集要讲明白的一件事
把 y=ax² 的每个点向右移 h、向上移 k，就得到 y=a(x−h)²+k：顶点 (h,k)，对称轴 x=h；“左加右减、上加下减”由代入坐标说明，不靠死记。

## 开场问题（不依赖其他集）
y=(x−2)²+1 的图像在哪里？为什么括号里是 x−2，图像却向右移？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **y = ax² 的图像（a≠0）**
  - a>0 开口向上，a<0 开口向下
  - |a| 越大，开口越小
  - 关于 y 轴对称，顶点 (0,0)（a>0 最低点，a<0 最高点）
  - 由来（简短复习）：由“y = x² 的图像”：【伸缩】同一个 x，纵坐标乘 a；a<0 时翻到 x 轴下方；|a| 越大，同一 x 处离 x 轴越远，开口越窄；x 与 −x 的纵坐标同乘 a 仍相等：对称性不变，顶点仍是 (0,0)。
- **【约定】点在图像上**
  - 点 (x₀, y₀) 在 y=f(x) 的图像上 ⟺ y₀ = f(x₀)
  - 由来（简短复习）：这是课本的定义或约定，直接承认（数与形互相翻译的依据）。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **y = ax² 的图像（a≠0） → 平移：y = a(x−h)² + k**（推导）
   - 【代换法】(x₀,y₀) 在 y=ax² 上
   - ⟺ (x₀+h, y₀+k) 在 y=a(x−h)²+k 上
2. **【约定】点在图像上 → 平移：y = a(x−h)² + k**（提供前提）
   - 【前提】点在图像上 ⟺ 坐标满足解析式

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 平移：y = a(x−h)² + k
- 由 y=ax² 向右平移 h、向上平移 k
- 顶点 (h, k)，对称轴 x=h
- 口诀：左加右减（括号里）、上加下减（括号外）
- 移轴（坐标变换）：令 x′=x−h，y′=y−k，方程化成 y′=ax′²

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- y=x² 上取点 (1,1)，平移后到 (3,2)，代入 y=(x−2)²+1 验证 2=(3−2)²+1。
- 顶点 (0,0) → (2,1) 用箭头连起来；括号里的“−2”与“向右 2”用同一种颜色对应。

## 着重标注（本集必须突出的地方）
- 代换的一步：(x₀,y₀) 在 y=ax² 上，则 a((x₀+h)−h)²+k=ax₀²+k=y₀+k，所以 (x₀+h, y₀+k) 在新图像上。
- 反方向也要说：(X,Y) 在新图像上，则 Y−k=a(X−h)²，即 (X−h, Y−k) 在 y=ax² 上——新图像上的每个点都由旧图像平移而来。
- “括号里减 h 反而向右”的地方停顿，用上面的代入说明。

## 解题思维导向（片尾一句话）
看到 a(x−h)²+k → 顶点 (h,k) 直接读出，图像由 y=ax² 平移得到。

## 易错点与边界（必须讲到）
- y=(x+2)² 的顶点横坐标是 −2，不是 2。
- 平移不改变 a：开口方向和大小都不变。
