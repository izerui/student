# T06｜题型串讲：方程、零点与韦达

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- 字母说明：例题里的 k 是水平直线 y=k 的高度；复习顶点式时，顶点纵坐标改记为 k₀，避免同屏出现两个 k。
- **指数与对数**：2ˣ>0 且取遍全体正数；2ˣ=3 ⟺ x=log₂3（对数的定义）。
- **零点 ⟺ 根 ⟺ 交点**
  - f 的零点 = 方程 f(x)=0 的实根
  - = 图像与 x 轴交点的横坐标
  - 个数：Δ>0 两个，Δ=0 一个，Δ<0 没有
  - 由来（简短复习）：由“【定义】零点”：【定义】零点 = 方程的根；【数形结合】= 图像与 x 轴交点（y=0）。
- **含绝对值的图像**
  - y=|f(x)|：x 轴下方部分翻到上方
  - y=f(|x|)：保留 y 轴右侧，再关于 y 轴对称
  - 由来（简短复习）：由“【约定】点在图像上”：【分类讨论】y=|f(x)|：f(x)≥0 的部分不变，f(x)<0 的部分取相反数 ⇒ x 轴下方的部分翻到上方；y=f(|x|)：x≥0 时就是 f(x)；x<0 时 f(|x|)=f(−x)，与 x>0 处的值相同 ⇒ 保留右侧，再关于 y 轴对称。
- **恰有一根在 (m, n) 内**
  - 条件：只看 (m,n) 内的根
  - f(m)·f(n) < 0 时成立
  - f(m)·f(n)=0（端点是根）或 Δ=0（重根）时单独检验
  - 由来（简短复习）：由“f(m)·f(n)<0 ⇒ (m,n) 内至少一个根”：【反证法】若两个不同实根都在 (m,n) 内：由交点式，f(m)、f(n) 都与 a 同号，与 f(m)f(n)<0 矛盾；重根 x₀ 在 (m,n) 内：f=a(x−x₀)² 不变号，同样矛盾 ⇒ 恰有一个；【分类讨论】f(m)f(n)=0（端点是根）时单独检验。
- **均值代换**
  - 两数 x₁、x₂：x₁+x₂=s，x₁x₂=p ⇒
  - x₁、x₂ 是 t²−st+p=0 的两根
  - ⇒ s² − 4p ≥ 0
  - sinα、cosα：sinα+cosα=s ⇒ sinα·cosα=(s²−1)/2，两者是 t²−st+(s²−1)/2=0 的两根，再按 t∈[−1,1] 和象限取舍
  - 由来（简短复习）：由“韦达定理”：【展开】(t−x₁)(t−x₂) = t² − st + p，所以 x₁、x₂ 是 t²−st+p=0 的两根；x₁、x₂ 是实数 ⇒ 判别式 s²−4p = (x₁+x₂)²−4x₁x₂ = (x₁−x₂)² ≥ 0。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。
- **根的符号：用韦达**
  - 两正根 ⟺ Δ≥0，x₁+x₂>0，x₁x₂>0
  - 两负根 ⟺ Δ≥0，x₁+x₂<0，x₁x₂>0
  - 一正一负 ⟺ x₁x₂<0（即 c/a<0）
  - 由来（简短复习）：由“韦达定理”：【韦达】两根同号 ⟺ x₁x₂>0；同正再要 x₁+x₂>0；一正一负：c/a<0 ⇒ ac<0 ⇒ Δ=b²−4ac>0，自动有两个实根。
- **复数范围内的一元二次方程**
  - 条件：实系数；Δ<0（复数范围）
  - 实系数，Δ<0：两个共轭虚根 x = (−b ± √(−Δ)·i)/(2a)
  - 根与系数的关系仍成立：x₁+x₂=−b/a，x₁x₂=c/a
  - 例：x²+2x+5=0：x=−1±2i
  - 虚根成对：已知一根 α+βi（β≠0），另一根是 α−βi，再用韦达求系数；例：1+i 是 x²−ax+2=0 的根 ⇒ a=(1+i)+(1−i)=2
  - 由来（简短复习）：由“Δ<0 时开平方”：【代入】两根相加：虚部抵消，得 −b/a；两根相乘：(b² + (−Δ))/(4a²) = 4ac/(4a²) = c/a。
- **换元解方程（舍根）**
  - 条件：新变量的范围
  - 令 t=√x 或 t=x²，化成 t 的一元二次方程，再按 t 的范围舍根
  - 例：x−2√x−1=0：t=√x≥0，t²−2t−1=0
  - t=1+√2（1−√2<0 舍），x=3+2√2
  - 例：2x⁴−7x²+3=0：t=x²≥0，t=3 或 1/2，x=±√3、±√2/2
  - 对数合并、两边平方会扩大定义域：解出后回原方程检验；例：lg x+lg(x−3)=1 ⇒ x²−3x−10=0 ⇒ x=5（x=−2 不满足 x>3，舍）
  - 由来（简短复习）：由“换元后的方程”：「求根公式」解出 t；【检验】舍去不在 t 范围内的根，再由 t 还原 x。
- **二次型复合：换元**
  - 条件：新变量 t 的范围
  - y=f(g(x))：令 t=g(x)，先求 t 的范围（可能是开区间、可能无界）
  - 再在 t 的范围上求最值：闭区间用闭区间最值表；开区间、无界看端点能否取到
  - 例：4ˣ − 2ˣ⁺¹ = t² − 2t（t=2ˣ>0）：
  - 最小值 −1（t=1），没有最大值
  - 例：sin²x + cos x = −t² + t + 1（t=cos x∈[−1,1]）：
  - 最大 5/4，最小 −1
  - 二次函数在里层：y=log₂(x²+x+1)，先求 u=x²+x+1≥3/4
  - log₂ 递增，值域 [log₂(3/4), +∞)
  - 正态密度的指数 −(x−μ)²/(2σ²)：二次在里层，曲线关于 x=μ 对称，x=μ 处最高
  - 比较 g(二次式) 与 g(常数)：先求内层范围，再看外层单调；例：a²+2≥2，ln 递增 ⇒ ln(a²+2) ≥ ln 2
  - 指数不等式化成二次不等式：(√3−√2)^(m²−m)>(√3−√2)²，底数在 0 与 1 之间，指数函数递减 ⇒ m²−m<2 ⇒ −1<m<2
  - 由来（简短复习）：由“y 变成 t 的二次函数，t 取 g(x) 的值域”：在 t 的范围上求最值：闭区间用闭区间最值；开区间、无界时看端点能否取到。
- **两根的对称式求值**
  - 条件：Δ≥0（实根）
  - x₁²+x₂²=(x₁+x₂)²−2x₁x₂
  - 1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)（x₁x₂≠0）
  - 例：x²−3x+1=0：x₁²+x₂²=9−2=7
  - 两交点 P(x₁,y₁)、Q(x₂,y₂) 在 y=kx+m 上：x₁x₂+y₁y₂ 代入直线化成 x₁+x₂、x₁x₂；OP⊥OQ ⟺ x₁x₂+y₁y₂=0（P、Q 不是原点）
  - 非对称式：先用“根满足原方程”降次；例：x₁、x₂ 是 x²+2x−5=0 的两根，x₁²+x₁x₂+2x₁=5+(−5)=0
  - 倒数根：ac≠0 时，cx²+bx+a=0 的两根是 ax²+bx+c=0 两根的倒数
  - 由来（简短复习）：由“韦达定理”：【配凑】x₁²+x₂²=(x₁+x₂)²−2x₁x₂，代入韦达；【通分】1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)。
- **二分法求零点近似值**
  - f 在 [m,n] 上连续，f(m)f(n)<0：取中点 c，算 f(c)
  - f(c)=0 即为零点；否则保留端点值异号的那一半，重复到区间长度小于精确度 ε，区间内任一点（如端点）即为近似值
  - 每次区间长度减半：算 k 次后长度为 (n−m)/2ᵏ，用它估计至少算几次；B 版教材写法：区间长度 ≤ 2ε 时取中点
  - 例：x²−2 在 [1,2]：f(1.5)>0，f(1.25)<0，√2∈[1.25,1.5]
  - 由来（简短复习）：由“【定理】零点存在定理”：【零点存在定理】f(m)·f(n)<0 ⇒ (m,n) 内有零点；取中点 c：f(c)=0 即找到；否则 f(m)·f(c)<0 与 f(c)·f(n)<0 必有一个成立；保留端点值异号的一半，零点仍在其中；区间长度每次减半，k 次后为 (n−m)/2ᵏ，可以小于任意精确度。
- **【定理】零点存在定理**
  - f 在 [m,n] 上连续，f(m)·f(n)<0
  - ⇒ f 在 (m,n) 内至少有一个零点
  - 由来（简短复习）：这是课本的定理（直接承认，不证），直接承认（课本承认，不证）。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **一元二次方程的解法**
  - 直接开平方：x²=p（p≥0）⇒ x=±√p
  - 因式分解：(x−x₁)(x−x₂)=0 ⇒ x=x₁ 或 x₂
  - 配方法：化成 (x+m)²=p 再开平方
  - 由来（简短复习）：由“【公理】实数运算与大小”：【因式分解】乘积为 0 ⟺ 某个因式为 0（uv=0 ⟺ u=0 或 v=0）；例：x²−5x+6=(x−2)(x−3)=0 ⇒ x=2 或 x=3；【开平方】x²=p（p≥0）⇒ x=±√p；(x+m)²=p 同理 ⇒ x=−m±√p。
- **整数自变量上的最值**
  - 条件：自变量取整数；a>0
  - a>0：最小值在定义域内离对称轴 h 最近的整数处取到（两个一样近则都取到）
  - a<0 的最大值同理
  - 例：Sₙ=2n²−30n，h=7.5，n=7 或 8 时最小，S=−112
  - 等差数列（a₁ 首项，d 公差）：由 Sₙ=na₁+n(n−1)d/2 展开得 Sₙ=(d/2)n²+(a₁−d/2)n，d≠0 时是 n 的二次函数，常数项为 0
  - 反过来：Sₙ=An²+Bn+C 是等差数列的前 n 项和 ⟺ C=0（C≠0 时从第 2 项起等差）
  - 另一种判法：a₁<0、d>0 时，Sₙ 在 aₙ≤0≤aₙ₊₁ 处最小，与离轴最近的整数一致；S_k=0（k≠0）⇒ 对称轴 h=k/2
  - 等比数列前 n 项积：a₁=4，q=1/2 ⇒ Tₙ=2^((5n−n²)/2)，指数是 n 的二次式，n=2 或 3 时最大 8
  - 由来（简短复习）：由“远近规律”：【远近规律】a>0：|x−h| 越小，f(x) 越小；自变量只取整数 ⇒ 只需比较 h 左右最近的两个整数；两个一样近（h 是某整数加 0.5）时都取到；例 h=7.5 ⇒ n=7、8。
- **解一元二次不等式**
  - ① 二次项系数化为正（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写解集
  - 解集用集合（或区间）写：{x | x<x₁ 或 x>x₂}、{x | x₁<x<x₂}；无解写 ∅，对一切 x 成立写 ℝ
  - 也可先因式分解：(x−x₁)(x−x₂)>0 ⟺ 两个因式同号，化成两个一元一次不等式组
  - 例（实际情境，s 为刹车距离，单位米；v 为车速，单位千米每小时）：s=v²/100−v/10>6（v>0）⇒ (v−30)(v+20)>0 ⇒ v>30
  - 由来（简短复习）：由“三个二次的关系”：【同乘法】a<0 时两边乘 −1：系数化正，不等号反向；化成 a>0 后：求 Δ 和两根，按三个二次的关系读出解集；例：−x²+x+2>0 ⟺ x²−x−2<0 ⟺ (x−2)(x+1)<0 ⟺ −1<x<2。由“一元二次方程的解法”：【因式分解】(x−x₁)(x−x₂)>0 ⟺ 两个因式同号；⟺ x−x₁、x−x₂ 同正，或同负：两个一元一次不等式组。
- **与导数衔接**
  - 三次函数的导数是二次函数
  - 导函数（二次）为正的区间上递增，为负的区间上递减
  - 导函数 Δ>0：两个变号零点，一个极大值点、一个极小值点
  - 导函数 Δ≤0：不变号（重根处为 0 也不变号，如 y=x³），没有极值，单调性不变
  - F′(x₀)=0 是 x₀ 为极值点的必要不充分条件（F 在 x₀ 处可导）
  - 三次函数（三次项系数为正）有三个零点 ⟺ 导函数 Δ>0，且极大值 >0> 极小值
  - 导函数 = 恒正因子 × 二次式（如 eˣ·(x²−x−2)，或 x>0 时 ((x−1)(x−λ))/x）：单调性只看二次因式的符号，含参时比较两根大小
  - 由来（简短复习）：由“F′(x) = 3Ax² + 2Bx + C 是二次函数”：「三个二次的关系」读出 F′ 的正负区间（3A<0 时先乘 −1 化正）；【前提】F′>0 的区间递增，F′<0 的区间递减；导数为 0 且左右变号的点是极值点（课本）。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。

## 题型（按顺序讲）
### 1. 看到：零点个数、含绝对值的二次
- 反推：零点 = 与 x 轴交点：看 Δ；含绝对值先画翻折后的图像，再数交点
- 先查：二次项系数含参数时先看 =0（一次函数 b≠0 时恰有一个零点）；|f(x)| 与 f(|x|) 的区别
- 用到的结论：零点 ⟺ 根 ⟺ 交点、含绝对值的图像、恰有一根在 (m, n) 内
- 例题：(1) f(x)=ax²+2x+1 恰有一个零点，求 a；(2) |x²−4x+3|=k 有 4 个实数解，求 k。
  - (1) a=0 时 f=2x+1，零点 −1/2，符合；a≠0 时要 Δ=4−4a=0，a=1。
  - (2) 把 y=x²−4x+3 在 x 轴下方的部分翻上去，顶点 (2,−1) 变成 (2,1)；水平线 y=k 与图像有 4 个交点 ⟺ 0<k<1。
  - 答案：(1) a=0 或 a=1；(2) 0<k<1

### 2. 看到：已知两数的和与积，求范围
- 反推：均值代换：两数是 t²−st+p=0 的两根
- 先查：隐含条件 s²−4p≥0；两数限正（负）时，再用韦达看根的符号
- 用到的结论：均值代换、韦达定理、根的符号：用韦达
- 例题：正数 u、v 满足 uv=u+v+3，求 uv 的范围。
  - 设 s=u+v，则 p=uv=s+3；u、v 是 t²−st+p=0 的两根：s²−4(s+3)≥0 ⇒ s≥6 或 s≤−2。
  - u、v 都是正数：两根同正 ⇒ s>0，所以 s≥6，uv=s+3≥9（u=v=3 时取等）。
  - 答案：uv≥9

### 3. 看到：Δ<0 的方程、复数根
- 反推：在复数范围内用求根公式，根与系数的关系仍成立；实系数时，已知一个虚根，另一根是它的共轭，用韦达求系数
- 先查：题目是在实数还是复数范围内；求 |x₁−x₂| 时 Δ<0 用 |a|·|x₁−x₂| = √(−Δ)
- 用到的结论：复数范围内的一元二次方程
- 例题：在复数范围内解 −x²+2x−5=0。
  - 两边乘 −1：x²−2x+5=0，Δ=4−20=−16<0。
  - x=(2±4i)/2=1±2i；验证：两根之和 2=−b/a，积 1+4=5=c/a。
  - 答案：x=1±2i

### 4. 看到：换元后化成一元二次方程
- 反推：令 t=√x、x²、aˣ、lg x 等，解 t 的方程，再按 t 的范围舍根
- 先查：t 的取值范围；对数合并、两边平方后回原方程的定义域检验
- 用到的结论：换元解方程（舍根）、二次型复合：换元
- 例题：解 4ˣ−2ˣ⁺¹−3=0。
  - 令 t=2ˣ>0，t²−2t−3=0，t=3 或 t=−1。
  - t=−1<0，舍去；2ˣ=3。
  - 答案：x=log₂3

### 5. 看到：已知方程，求两根的对称式的值
- 反推：用韦达把 x₁²+x₂²、1/x₁+1/x₂ 等化成 x₁+x₂、x₁x₂；非对称式先用“根满足原方程”降次
- 先查：Δ≥0（有实根）；复数范围韦达仍成立，但模 |x₁−x₂| 要另算
- 用到的结论：两根的对称式求值、韦达定理
- 例题：x²−2λx+λ+6=0 有两个实根 x₁、x₂，求 (x₁−1)²+(x₂−1)² 的最小值。
  - 先查 Δ=4λ²−4(λ+6)≥0 ⇒ λ≤−2 或 λ≥3。
  - 原式 =(x₁+x₂)²−2x₁x₂−2(x₁+x₂)+2=4λ²−6λ−10。
  - 对称轴 λ=3/4 不在可取范围内：λ≥3 时递增，最小 8；λ≤−2 时递减，最小 18。
  - 答案：最小值 8（λ=3）；漏查 Δ 会误得 −49/4

### 6. 看到：求零点的近似值
- 反推：二分法：保留端点值异号的半区间
- 先查：区间端点值异号、函数连续
- 用到的结论：二分法求零点近似值、【定理】零点存在定理
- 例题：用二分法求 x²−3=0 在 [1,2] 内的近似解（精确度 0.1）。
  - f(1)=−2<0，f(2)=1>0。中点 1.5：f<0，取 [1.5,2]；1.75：f=0.0625>0，取 [1.5,1.75]；1.625：f<0，取 [1.625,1.75]；1.6875：f<0，取 [1.6875,1.75]。
  - 区间长度 0.0625<0.1，停止，取端点 1.75 或 1.6875 为近似值（真值 √3≈1.732）。
  - 答案：约 1.7

### 7. 看到：分式方程化成一元二次方程
- 反推：去分母化成一元二次方程，解出后验增根（使分母为 0 的根舍去）；“解集只有一个元素”：Δ=0，或两根中有一个是增根
- 先查：去分母前写出分母 ≠0 的条件；能换元先换元
- 用到的结论：换元解方程（舍根）、求根公式与判别式
- 例题：x/(x−1)=(k−2x)/(x²−x) 的解集只有一个元素，求 k。
  - 去分母（x≠0、1）：x²+2x−k=0。
  - Δ=0：k=−1，根 −1 可取；一根是增根：x=0 ⇒ k=0，另一根 −2；x=1 ⇒ k=3，另一根 −3。
  - 答案：k=−1、0 或 3

### 8. 看到：已知 sinα±cosα 或 sinα·cosα，求值
- 反推：平方得 sinα·cosα；sinα、cosα 是一个一元二次方程的两根，解出后按象限取舍
- 先查：α 的范围决定 sinα、cosα 的符号；t∈[−1,1]
- 用到的结论：均值代换、换元解方程（舍根）、韦达定理
- 例题：sinα+cosα=1/5，α∈(0,π)，求 tanα。
  - 平方：sinα·cosα=(1/25−1)/2=−12/25，sinα、cosα 是 25t²−5t−12=0 的两根：t=4/5 或 −3/5。
  - α∈(0,π) ⇒ sinα>0：sinα=4/5，cosα=−3/5。
  - 答案：tanα=−4/3

### 9. 看到：解三角形：已知两边和其中一边的对角
- 反推：余弦定理 a²=b²+c²−2bc·cosA 化成第三边 c 的二次方程：c² − (2b·cosA)c + (b²−a²) = 0；正根个数 = 三角形个数
- 先查：只取正根；用 Δ 和两根之积 b²−a² 的符号判断正根个数
- 用到的结论：根的符号：用韦达、求根公式与判别式、韦达定理
- 例题：△ABC 中 a=2，c=√6，A=45°，求 b。
  - 余弦定理：4=b²+6−2√6·b·(√2/2) ⇒ b²−2√3b+2=0。
  - 两根之积 2>0、之和 2√3>0：两个正根，b=√3+1 或 √3−1，两个三角形。
  - 答案：b=√3+1 或 √3−1

### 10. 看到：数列通项 aₙ 是 n 的二次式
- 反推：是不是数列的项：解 n 的一元二次方程，只取正整数根；最大（小）项：取离对称轴最近的正整数；单调：aₙ₊₁−aₙ 的符号
- 先查：n 只取正整数；aₙ=an²+bn（a>0）递增 ⟺ 对称轴 <3/2，不是 ≤1
- 用到的结论：一元二次方程的解法、整数自变量上的最值、解一元二次不等式
- 例题：aₙ=n²+2n，168 是不是数列的项？
  - n²+2n=168 ⇒ n²+2n−168=0 ⇒ (n−12)(n+14)=0。
  - n 取正整数：n=12。
  - 答案：是第 12 项

### 11. 看到：排列组合数、概率方程化成一元二次方程
- 反推：按公式展开或列方程组消元，化成一元二次方程，只取符合要求的根；例：独立事件列方程组消元得 32b²+4b−3=0，b=1/4（−3/8 舍）
- 先查：n 是正整数且不小于下标要求；概率要在 [0,1] 内
- 用到的结论：一元二次方程的解法、换元解方程（舍根）
- 例题：解方程 Aₙ²=7Aₙ₋₄²。
  - n(n−1)=7(n−4)(n−5) ⇒ 3n²−31n+70=0 ⇒ n=7 或 10/3。
  - n 是正整数且 n−4≥2：n=7。
  - 答案：n=7

### 12. 看到：三次函数的零点个数、与水平线的交点个数
- 反推：求导得二次函数：Δ≤0 时单调，只有一个零点；Δ>0 时看极大值、极小值的符号
- 先查：三次项系数的正负；极值点处的函数值
- 用到的结论：与导数衔接、求根公式与判别式
- 例题：f(x)=x³−3x+c 有三个零点，求 c。
  - f′=3x²−3，Δ>0，极大值 f(−1)=2+c，极小值 f(1)=c−2。
  - 三个零点 ⟺ 2+c>0 且 c−2<0。
  - 答案：−2<c<2

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
