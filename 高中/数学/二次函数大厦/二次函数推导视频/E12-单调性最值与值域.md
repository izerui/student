# E12｜单调性、最值与值域

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：单调性；最值；值域

## 这一集要讲明白的一件事
用作差恒等式判断符号得到单调区间，用平方非负得到最值，再说明 (x−h)² 能取遍 [0,+∞)，得到值域。全部按 a>0 讲，a<0 上下翻过来。

## 开场问题（不依赖其他集）
y=x²−4x+3 在哪里递减、哪里递增？最小值是多少？它能取到 100 吗？能取到 −2 吗？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **作差恒等式**
  - f(x₁) − f(x₂) = a(x₁ − x₂)(x₁ + x₂ − 2h)
  - 平均变化率（x₁≠x₂）：(f(x₁)−f(x₂))/(x₁−x₂) = a(x₁+x₂−2h)
  - 由来（简短复习）：由“f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]”：「平方差」(x₁−h)²−(x₂−h)² = (x₁−x₂)(x₁+x₂−2h)；【同除】x₁≠x₂ 时两边除以 x₁−x₂，得平均变化率。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **【公理推论】平方非负**
  - x² ≥ 0，等号 ⟺ x=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **【定义】函数**
  - 每个 x（定义域内）对应唯一的 y
  - 定义域、值域；图像 = 所有点 (x, f(x))
  - 由来（简短复习）：这是课本的定义或约定，直接承认（函数的定义）。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **作差恒等式 → 单调性**（推导）
   - ▼ 加条件：a>0（a<0 时反向）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0
   - ⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增
2. **顶点式 → 最值**（推导）
   - ▼ 加条件：a>0（a<0 时反向）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0
   - ⇒ f(x) ≥ k，x=h 取等
   - (x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值
3. **最值 → 值域**（推导）
   - 【代入】任给 u≥0，取 x=h+√u，就有 (x−h)²=u
   - 所以 (x−h)² 取遍 [0,+∞)
4. **【定义】单调性、最值、奇偶性 → 单调性**（提供前提）
   - 【前提】单调性的定义
5. **【公理推论】平方非负 → 最值**（提供前提）
   - 【前提】平方非负
6. **【定义】函数 → 值域**（提供前提）
   - 【前提】值域 = 所有函数值组成的集合

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【定义】单调性、最值、奇偶性
- 在区间 D 上递增：对 D 内任意 x₁<x₂，都有 f(x₁)<f(x₂)；递减反之（取几个点验证不够）
- 最小值：f(x₀)≤f(x) 对定义域内一切 x 成立，且取得到
- 定义域关于原点对称时：偶函数 f(−x)=f(x)；奇函数 f(−x)=−f(x)
- 定义域不关于原点对称：既不是奇函数也不是偶函数

#### 单调性
- 条件：a>0
- (−∞, h] 上递减，[h, +∞) 上递增
- a<0 时反过来

#### 最值
- 条件：x∈ℝ；a>0
- 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
- a<0 时：最大值 −Δ/(4a)，没有最小值

#### 值域
- 条件：x∈ℝ
- a>0：[−Δ/(4a), +∞)
- a<0：(−∞, −Δ/(4a)]

## 着重标注（本集必须突出的地方）
- ▼ a>0（a<0 时反向）。反例：y=−x² 在 [0,+∞) 上递减。
- x₁<x₂≤h 时 x₁−x₂<0、x₁+x₂−2h<0，两个负数相乘为正——这一步写出来。
- 没有最大值的理由：(x−h)² 可以任意大；值域取遍的理由：任给 u≥0，取 x=h+√u。

## 解题思维导向（片尾一句话）
求二次函数的单调区间、最值、值域 → 先配方找 h、k，再看 a 的符号。

## 易错点与边界（必须讲到）
- 最值要说出在哪里取到：x=h。
- a>0 时没有最大值。
- 这里的值域是 x 取全体实数的结果；限定区间时要另算。
