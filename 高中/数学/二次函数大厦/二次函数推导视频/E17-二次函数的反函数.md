# E17｜二次函数的反函数

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：二次函数的反函数

## 这一集要讲明白的一件事
二次函数在 ℝ 上一个 y 对应两个 x，没有反函数；限制在一个单调区间上才有。求法是解出 x、交换字母，开平方取哪个符号由原定义域决定，反函数的定义域是原函数的值域。

## 开场问题（不依赖其他集）
y=x² 有反函数吗？y=x²（x≥0）呢？y=x²（x≤0）呢？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **对称轴**
  - f(h + t) = f(h − t)，图像关于 x=h 对称
  - 由来（简短复习）：由“顶点式”：【代入】x=h+t：f(h+t)=a·t²+k；x=h−t：f(h−t)=a·(−t)²+k=at²+k；⇒ f(h+t)=f(h−t)：点 (h+t, y) 与 (h−t, y) 同在图像上，关于直线 x=h 对称。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】反函数 → 二次函数的反函数**（推导）
   - ▼ 加条件：限制在一个单调区间上（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【定义】反函数要求每个 y 只对应一个 x
   - f(x)=f(2h−x)：轴两侧成对的 x 对应同一个 y ⇒ 在 ℝ 上没有反函数
   - 限制在 x≥h（或 x≤h）上，函数单调，每个 y 只对应一个 x ⇒ 有反函数；解 x 时开平方按这一侧取符号
2. **对称轴 → 二次函数的反函数**（提供前提）
   - 【前提】f(h+t)=f(h−t)
3. **单调性 → 二次函数的反函数**（提供前提）
   - 【前提】单调区间上不同的 x 对应不同的 y

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【定义】反函数
- y=f(x) 中每个 y 只对应一个 x 时，把 x 用 y 表示，再交换字母，得 f 的反函数
- 反函数的定义域 = 原函数的值域

#### 二次函数的反函数
- 条件：限制在单调区间
- 在 ℝ 上：x 与 2h−x 对应同一个 y，没有反函数
- 定义域是区间时：限制在一个单调区间上才有反函数
- 例：y=x²（x≥0）的反函数是 y=√x（x≥0）
- 开平方时按原定义域取符号：y=x²（x≤0）的反函数是 y=−√x（x≥0）

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 水平线 y=4 与 y=x² 交于 x=±2 两点，打叉。
- 只保留右半支，与 y=√x 关于直线 y=x 对称；只保留左半支，对应 y=−√x。

## 着重标注（本集必须突出的地方）
- ▼ 限制在一个单调区间上。
- 开平方时按原定义域取符号。
- 反函数的定义域 = 原函数的值域。

## 解题思维导向（片尾一句话）
求二次函数的反函数 → 确认限制在单调区间，解出 x（按原定义域取符号），交换字母，写出定义域。
