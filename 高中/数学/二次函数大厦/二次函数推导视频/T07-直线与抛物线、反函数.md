# T07｜题型串讲：直线与抛物线、反函数

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 manim-video 的 story-models.md）
- 讲法：每个题型按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按“本集先补齐的基础”写出公式、条件和理由。

## 本集先补齐的基础（用到时写出公式和条件，一两句话讲清由来）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- 字母说明：k 是直线的斜率；弦的两端记作 P、Q，联立后方程的系数记作 a′、b′、c′；复习顶点式时，顶点纵坐标改记为 k₀，避免同屏出现两个 k。
- **直线与抛物线的交点**
  - 竖直直线 x=t：恰有一个交点
  - y=kx+m：代入得 ax²+(b−k)x+c−m=0，看 Δ
  - y=kx+m 时 Δ=0：只有一个公共点，即相切（教材定义）
  - x=t 虽只有一个交点，但与对称轴平行，不算相切
  - 直线与圆联立：Δ>0、Δ=0、Δ<0 ⟺ d<r、d=r、d>r（d 是圆心到直线的距离）
  - 哪一段抛物线在直线上方：解二次不等式 f(x)−(kx+m)>0
  - 一次、二次方程组：代入消元化成一元二次方程，解出一个未知数，再回代求另一个；两个二次方程的二次项相同时（如两个圆），两式相减消去二次项，得一次方程
  - 与一般圆锥曲线联立：先看二次项系数，为 0 时化成一次方程，至多一个公共点（如双曲线与它的渐近线没有公共点），有也不算相切
  - 由来（简短复习）：由“求根公式与判别式”：【定义】函数每个 x 只对应一个 y：竖直直线 x=t 与图像恰有一个交点；【代入消元】y=kx+m 代入，得关于 x 的二次方程，交点个数 = 实根个数。
- **直线截抛物线的弦长**
  - 条件：Δ′>0（两个交点）
  - y=kx+m 代入得 a′x²+b′x+c′=0（与抛物线 a′=a；与圆、椭圆等联立时 a′ 另算），Δ′=b′²−4a′c′
  - 弦的两端 P、Q：|PQ| = √(1+k²)·|x₁−x₂| = √(1+k²)·√(Δ′)/|a′|
  - 对 y 消元时：|PQ| = √(1+1/k²)·|y₁−y₂|（k≠0）
  - 例：y=x² 与 y=x：|PQ| = √2
  - 由来（简短复习）：由“|PQ| = √(1+k²)·|x₁−x₂|”：「韦达」用于联立后的方程：(x₁−x₂)²=(x₁+x₂)²−4x₁x₂=Δ′/a′²；⇒ |x₁−x₂|=√(Δ′)/|a′|。
- **用导数看二次函数**
  - f′(x) = 2ax + b，f′(x)=0 ⟺ x = −b/(2a)（顶点横坐标）
  - a>0：x<h 时 f′<0 递减，x>h 时 f′>0 递增，与作差得到的单调性一致
  - 平均变化率 = 区间中点处的导数：抛物线的割线平行于区间中点处的切线
  - 切线：y=f(x₀)+(2ax₀+b)(x−x₀)；例 y=x² 在 (1,1) 处：y=2x−1
  - f(x)−切线=a(x−x₀)²：联立得重根、Δ=0，与“直线与抛物线相切”的判定一致
  - 由来（简短复习）：由“作差恒等式”：【取极限】x₂=x₁+Δx：平均变化率 = a(2x₁+Δx−2h)；Δx→0 得 f′(x₁)=2a(x₁−h)=2ax₁+b（由导数的定义，课本）。由“【定义】二次函数”：【求导】(ax²+bx+c)′ = 2ax+b（工具：(xⁿ)′=nxⁿ⁻¹，和差、常数倍的求导法则）；【前提】导数判单调：f′<0 递减，f′>0 递增。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **最值**
  - 条件：x∈ℝ；a>0
  - 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
  - a<0 时：最大值 −Δ/(4a)，没有最小值
  - 由来（简短复习）：由“顶点式”：【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0；⇒ f(x) ≥ k，x=h 取等；(x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值。
- **二次函数的反函数**
  - 条件：限制在单调区间
  - 在 ℝ 上：x 与 2h−x 对应同一个 y，没有反函数
  - 定义域是区间时：限制在一个单调区间上才有反函数
  - 例：y=x²（x≥0）的反函数是 y=√x（x≥0）
  - 开平方时按原定义域取符号：y=x²（x≤0）的反函数是 y=−√x（x≥0）
  - 由来（简短复习）：由“【定义】反函数”：【定义】反函数要求每个 y 只对应一个 x；f(x)=f(2h−x)：轴两侧成对的 x 对应同一个 y ⇒ 在 ℝ 上没有反函数；限制在 x≥h（或 x≤h）上，函数单调，每个 y 只对应一个 x ⇒ 有反函数；解 x 时开平方按这一侧取符号。
- **【定义】反函数**
  - y=f(x) 中每个 y 只对应一个 x 时，把 x 用 y 表示，再交换字母，得 f 的反函数
  - 反函数的定义域 = 原函数的值域
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **中点弦**
  - 条件：Δ′>0（两个交点）
  - 弦 PQ 的中点横坐标 x₀=(x₁+x₂)/2=−b′/(2a′)，纵坐标代回直线 y₀=kx₀+m
  - 已知中点求直线：由 x₁+x₂=2x₀ 和中点在直线上，解出 k、m，再验 Δ′>0（圆、椭圆另验斜率不存在的弦）
  - 例：y=x² 被 y=2x+1 截得的弦：x²−2x−1=0，中点 (1, 3)
  - 由来（简短复习）：由“韦达定理”：【韦达】x₁+x₂=−b′/a′，不用求出两根；中点 x₀=(x₁+x₂)/2，再代入直线得 y₀。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。
- **两根的对称式求值**
  - 条件：Δ≥0（实根）
  - x₁²+x₂²=(x₁+x₂)²−2x₁x₂
  - 1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)（x₁x₂≠0）
  - 例：x²−3x+1=0：x₁²+x₂²=9−2=7
  - 两交点 P(x₁,y₁)、Q(x₂,y₂) 在 y=kx+m 上：x₁x₂+y₁y₂ 代入直线化成 x₁+x₂、x₁x₂；OP⊥OQ ⟺ x₁x₂+y₁y₂=0（P、Q 不是原点）
  - 非对称式：先用“根满足原方程”降次；例：x₁、x₂ 是 x²+2x−5=0 的两根，x₁²+x₁x₂+2x₁=5+(−5)=0
  - 倒数根：ac≠0 时，cx²+bx+a=0 的两根是 ax²+bx+c=0 两根的倒数
  - 由来（简短复习）：由“韦达定理”：【配凑】x₁²+x₂²=(x₁+x₂)²−2x₁x₂，代入韦达；【通分】1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。

## 题型（按顺序讲）
### 1. 看到：直线与抛物线：相切、弦长
- 反推：联立消元得 a′x²+b′x+c′=0，Δ′=b′²−4a′c′：Δ′=0 相切；弦长 √(1+k²)·√(Δ′)/|a′|
- 先查：竖直直线单独处理
- 用到的结论：直线与抛物线的交点、直线截抛物线的弦长
- 例题：(1) y=kx−1 与 y=x² 相切，求 k；(2) 求直线 y=x+2 被 y=x² 截得的弦长。
  - (1) 联立 x²−kx+1=0，Δ′=k²−4=0，k=±2。
  - (2) 联立 x²−x−2=0，Δ′=9>0，|x₁−x₂|=√9/1=3，|PQ|=√(1+1²)·3=3√2；验证：交点 (2,4)、(−1,1) 的距离为 3√2。
  - 答案：(1) k=±2；(2) 3√2

### 2. 看到：直线与抛物线、圆、圆锥曲线有几个交点
- 反推：联立消元，看 Δ（圆也可比较 d 与 r）
- 先查：竖直直线单独处理；参数范围 = Δ 的条件 ∩ 二次项系数 ≠0 的条件（二次项系数为 0 时单独看）
- 用到的结论：直线与抛物线的交点
- 例题：直线 y=kx+2 与 y=x²−2x+3 有几个交点？
  - 直线不是竖直的，联立：x²−(k+2)x+1=0，Δ′=(k+2)²−4=k(k+4)。
  - 答案：k<−4 或 k>0：两个；k=0 或 k=−4：一个（相切）；−4<k<0：没有

### 3. 看到：过一点作抛物线的切线
- 反推：设切点 x₀，切线 y=f(x₀)+f′(x₀)(x−x₀) 过该点 ⇒ x₀ 的二次方程；或设直线联立，令 Δ=0
- 先查：点在不在抛物线上（在上面时它就是切点；在外面时有两条）；对 y²=2px 这类开口向右的抛物线，斜率不存在的直线也可能是切线；问“只有一个公共点”时还要加上与对称轴平行的直线（它不是切线）
- 用到的结论：用导数看二次函数、直线与抛物线的交点、求根公式与判别式
- 例题：过点 (2,3) 作抛物线 y=x² 的切线，求切线方程。
  - (2,3) 不在抛物线上（2²=4≠3）。设切点 (x₀, x₀²)，切线 y=2x₀x−x₀²。
  - 过 (2,3)：3=4x₀−x₀² ⇒ x₀²−4x₀+3=0 ⇒ x₀=1 或 3。
  - 答案：y=2x−1 或 y=6x−9

### 4. 看到：抛物线上的点到直线的最短距离
- 反推：距离 =|f(x)−(kx+m)|/√(1+k²)，绝对值里是二次式，配方求最小值
- 先查：直线与抛物线没有公共点（绝对值里不变号）；最近点是切线与该直线平行的切点
- 用到的结论：最值、直线与抛物线的交点、用导数看二次函数
- 例题：求抛物线 y=4x² 上的点到直线 y=8x−6 的最短距离。
  - 距离 =|4x²−8x+6|/√(8²+1)=|4x²−8x+6|/√65。
  - 4x²−8x+6=4(x−1)²+2≥2，绝对值里恒正，x=1 时最小。
  - 答案：最短距离 2/√65，最近点 (1,4)

### 5. 看到：二次函数的反函数
- 反推：先限制在一个单调区间，再把 x 用 y 表示、交换字母
- 先查：原函数的值域就是反函数的定义域
- 用到的结论：二次函数的反函数、【定义】反函数
- 例题：求 y=x²−2x（x≤0）的反函数。
  - 对称轴 x=1，x≤0 落在递减段，有反函数；原函数的值域 [0,+∞)。
  - (x−1)²=y+1，x≤0 ⇒ x−1<0，取负号：x=1−√(y+1)。交换字母。
  - 答案：y=1−√(x+1)（x≥0）

### 6. 看到：已知弦的中点，求弦所在直线
- 反推：设直线联立，用韦达：x₁+x₂=2x₀，解出斜率或截距
- 先查：求出直线后验 Δ′>0（弦真的存在）；圆、椭圆要另看斜率不存在的弦
- 用到的结论：中点弦、韦达定理、直线与抛物线的交点
- 例题：抛物线 y=x² 的弦 PQ 的中点是 (1,3)，求直线 PQ。
  - 设 y=kx+m，联立：x²−kx−m=0，x₁+x₂=k=2。
  - 中点在直线上：3=2·1+m ⇒ m=1；验 Δ=4+4=8>0。
  - 答案：y=2x+1

### 7. 看到：OA⊥OB、向量数量积：求值或求参数
- 反推：联立 → 韦达 → x₁x₂+y₁y₂ 代入直线化成 x₁+x₂、x₁x₂
- 先查：Δ>0；交点不能与原点重合
- 用到的结论：两根的对称式求值、韦达定理、直线与抛物线的交点
- 例题：直线 y=x+m 与 y=x² 交于 A、B，OA⊥OB，求 m。
  - 联立：x²−x−m=0，x₁+x₂=1，x₁x₂=−m；y₁y₂=x₁²x₂²=m²。
  - x₁x₂+y₁y₂=m²−m=0 ⇒ m=0 或 1；m=0 时有一个交点是原点，舍；m=1 时 Δ=5>0。
  - 答案：m=1

### 8. 看到：定点、定值
- 反推：联立 → 韦达 → 化简后与参数无关（定值）；或直线方程整理成参数乘某式 + 某式，令两式为 0（定点）
- 先查：斜率不存在的直线单独验证；Δ>0
- 用到的结论：韦达定理、两根的对称式求值、直线与抛物线的交点
- 例题：过 y²=4x 的焦点 F(1,0) 的直线 x=ty+1 交抛物线于 A、B，证明 y₁y₂ 是定值。
  - 对 y 消元：y²−4ty−4=0，Δ=16t²+16>0。
  - 韦达：y₁y₂=−4，与 t 无关。
  - 答案：y₁y₂=−4

## 着重标注
- 每个题型的“先查”用橙色框，讲到时停顿；按“先查”漏掉会错的地方，用反例或叉号标出。
- 例题的每个数值都写出计算过程，答案用粗框。

## 解题思维导向（片尾一句话）
看到题目先问：它在问函数、方程还是不等式？参数在哪里？再从对应的入口反推到结论。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机，再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（a≠0、a>0、Δ 的符号、区间、参数范围）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“结论成不成立”：例如 Δ<0 时方程没有实数根，是“没有实数满足”，不是“运算被禁止”；乘负数后不等号反向，是比较规则变了，不是不能乘。
- 等号成立条件、端点能否取到单独一行框出；关键变形（配方、代换、作差、换元）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），先出图、再从图里“读出”结论，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”。
### 解题导向与内容依据
