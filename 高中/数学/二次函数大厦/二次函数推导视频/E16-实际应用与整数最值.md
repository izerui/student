## 这一集要讲明白的一件事

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **闭区间上的最值**
  - 条件：x∈[m,n]
  - h<m：在 [m,n] 上递增，最小 f(m)，最大 f(n)
  - h>n：递减，最小 f(n)，最大 f(m)
  - m≤h≤n：最小 f(h)；最大取 f(m)、f(n) 中离轴远的
  - （以上 a>0；a<0 时最大、最小对调）
  - 由来（简短复习）：由“单调性”：【分类讨论】按对称轴 h 与 [m,n] 的位置分三类（a>0）；h<m：区间在轴右侧，递增 ⇒ 最小 f(m)，最大 f(n)；h>n：区间在轴左侧，递减 ⇒ 最小 f(n)，最大 f(m)；m≤h≤n：左减右增 ⇒ 最小 f(h)；最大在离轴远的端点（远近规律）。
- **远近规律**
  - 条件：a>0
  - |x − h| 越大，f(x) 越大
  - 比较函数值：看谁离对称轴远；a<0 时反过来
  - 由来（简短复习）：由“f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]”：「平方保序」0≤|x₂−h|<|x₁−h| ⇒ (x₂−h)²<(x₁−h)²；a>0：差 f(x₁)−f(x₂) >0，离轴远的函数值大。
- **最值**
  - 条件：x∈ℝ；a>0
  - 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
  - a<0 时：最大值 −Δ/(4a)，没有最小值
  - 由来（简短复习）：由“顶点式”：【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0；⇒ f(x) ≥ k，x=h 取等；(x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值。
- **待定系数法求解析式**
  - 已知三点 → 设一般式 ax²+bx+c
  - 已知顶点（或对称轴、最值）→ 设顶点式
  - 已知与 x 轴两交点 → 设交点式
  - 由来（简短复习）：由“【定义】二次函数”：【待定系数】设出含未知系数的式子，每个已知条件列一个方程；已知三点 → 设 y=ax²+bx+c，代入得三元一次方程组；已知顶点 (h,k) → 设 y=a(x−h)²+k，再代一点求 a；已知与 x 轴交点 x₁、x₂ → 设 y=a(x−x₁)(x−x₂)，再代一点求 a。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 二次函数模型（实际应用）
- 条件：实际意义的定义域
- 按题意列出二次函数，先写出定义域（长度为正、件数为整数等）
- 再在定义域上求最值：区间上看对称轴位置，整数自变量：a>0 的最小值、a<0 的最大值取定义域内离轴最近的整数
- 例：20 m 篱笆围靠墙矩形（墙足够长），垂直墙的边长 x：
- S=x(20−2x)，0<x<10，x=5 时最大 50

#### 整数自变量上的最值
- 条件：自变量取整数；a>0
- a>0：最小值在定义域内离对称轴 h 最近的整数处取到（两个一样近则都取到）
- a<0 的最大值同理
- 例：Sₙ=2n²−30n，h=7.5，n=7 或 8 时最小，S=−112
- 等差数列（a₁ 首项，d 公差）：由 Sₙ=na₁+n(n−1)d/2 展开得 Sₙ=(d/2)n²+(a₁−d/2)n，d≠0 时是 n 的二次函数，常数项为 0
- 反过来：Sₙ=An²+Bn+C 是等差数列的前 n 项和 ⟺ C=0（C≠0 时从第 2 项起等差）
- 另一种判法：a₁<0、d>0 时，Sₙ 在 aₙ≤0≤aₙ₊₁ 处最小，与离轴最近的整数一致；S_k=0（k≠0）⇒ 对称轴 h=k/2
- 等比数列前 n 项积：a₁=4，q=1/2 ⇒ Tₙ=2^((5n−n²)/2)，指数是 n 的二次式，n=2 或 3 时最大 8

#### 统计与概率中的二次：方差、最小二乘
- Q(t)=[(x₁−t)²+(x₂−t)²+…+(xₙ−t)²]/n 展开是 t 的二次函数（二次项系数 1）
- 对称轴 t=(x₁+x₂+…+xₙ)/n：取平均数时偏差平方和最小，Q 的最小值就是方差
- 配方成顶点式：Q(t) = 方差 + (t − 平均数)²；t=0 得 方差 = 平方的平均数 − 平均数²；分层合并的方差公式也由此得到
- 已知方差反求某个数据：方差是这个数据的二次函数，列二次方程（可能两解）；例：12、13、15、16、17、14、a 的方差为 4 ⇒ a=11 或 18
- 随机变量：Σ(xᵢ−t)²pᵢ = D(X) + (t−E(X))²，t=E(X) 时最小
- 单个数据的范围：(xₖ − 平均数)² ≤ n·方差（其余偏差的平方都 ≥0）；例：10 个整数平均 2、方差 3 ⇒ (xₖ−2)² ≤ 30 ⇒ xₖ ≤ 7
- 数据和固定且都非负，求方差最大：平均数固定，只看平方和；两数之和 S 固定、x∈[0,S] 时 x²+(S−x)² 开口向上，最大值在端点 x=0 或 S，所以数据往一个上集中；例：a+b+c=600（非负）⇒ a=600、b=c=0 时方差最大 80000
- 概率：两点分布方差 p(1−p)、二项分布方差 np(1−p)，p=1/2 时最大；A、B 独立，P(A)=p，P(B)=1−p：P(AB)=p(1−p) 最大 1/4
- 回归直线（斜率记 k，截距记 d）：固定 k，各点竖直偏差的平方和是 d 的二次函数（二次项系数为数据个数 n>0），最小处 d = y 的平均数 − k·x 的平均数，所以回归直线过样本中心点
- 教材的回归直线记号：斜率、截距的字母上加“^”，表示估计值

## 解题思维导向（片尾一句话）
应用题求最值 → 列式、写定义域、找对称轴；自变量是整数 → 找离对称轴最近的整数。

## 易错点与边界（必须讲到）
- 漏写定义域。
- 墙长有限时定义域变小，最大值可能不在顶点（如墙长 8 m 时 6≤x<10，最大值 f(6)=48）。
- 对称轴不是整数时，不能直接把 h 代进去。
