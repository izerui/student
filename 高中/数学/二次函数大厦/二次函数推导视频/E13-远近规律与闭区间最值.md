# E13｜远近规律与闭区间上的最值

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：远近规律；凸性：中点不等式；闭区间上的最值

## 这一集要讲明白的一件事
a>0 时离对称轴越远，函数值越大；把这个规律和单调性用到闭区间 [m,n] 上，按对称轴在区间左、内、右三种情况读出最值。

## 开场问题（不依赖其他集）
f(x)=x²−2x 在 [−1,2] 上的最大值、最小值各是多少？在 [2,3] 上呢？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²]**
  - 由来（简短复习）：由“顶点式”：【作差】[a(x₁−h)²+k] − [a(x₂−h)²+k]，k 抵消。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **单调性**
  - 条件：a>0
  - (−∞, h] 上递减，[h, +∞) 上递增
  - a<0 时反过来
  - 由来（简短复习）：由“作差恒等式”：【作差】x₁<x₂≤h：x₁−x₂<0，x₁+x₂−2h<0；⇒ f(x₁)−f(x₂)>0，递减；[h,+∞) 同理递增。
- **【公理推论】平方非负**
  - x² ≥ 0，等号 ⟺ x=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **【定义】集合与区间**
  - 交集：同时满足；并集：满足其一
  - [m,n] 含端点，(m,n) 不含端点
  - 由来（简短复习）：这是课本的定义或约定，直接承认。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **f(x₁) − f(x₂) = a[(x₁−h)² − (x₂−h)²] → 远近规律**（推导）
   - ▼ 加条件：a>0（a<0 时反向）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 「平方保序」0≤|x₂−h|<|x₁−h| ⇒ (x₂−h)²<(x₁−h)²
   - a>0：差 f(x₁)−f(x₂) >0，离轴远的函数值大
2. **顶点式 → 凸性：中点不等式**（推导）
   - ▼ 加条件：a>0（a<0 时反向）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【作差】记 u=x₁−h，v=x₂−h：
   - (f(x₁)+f(x₂))/2 − f((x₁+x₂)/2) = a(u²+v²)/2 − a((u+v)/2)²
   - = a(u−v)²/4 = a(x₁−x₂)²/4
3. **单调性 → 闭区间上的最值**（推导）
   - ▼ 加条件：x∈[m,n]（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【分类讨论】按对称轴 h 与 [m,n] 的位置分三类（a>0）
   - h<m：区间在轴右侧，递增 ⇒ 最小 f(m)，最大 f(n)
   - h>n：区间在轴左侧，递减 ⇒ 最小 f(n)，最大 f(m)
   - m≤h≤n：左减右增 ⇒ 最小 f(h)；最大在离轴远的端点（远近规律）
4. **【公理推论】平方非负 → 凸性：中点不等式**（提供前提）
   - 【前提】平方非负：(x₁−x₂)²≥0
5. **远近规律 → 闭区间上的最值**（提供前提）
   - 【前提】最大值看离轴远的端点
6. **【定义】集合与区间 → 闭区间上的最值**（提供前提）
   - 【前提】闭区间含端点

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 远近规律
- 条件：a>0
- |x − h| 越大，f(x) 越大
- 比较函数值：看谁离对称轴远；a<0 时反过来

#### 凸性：中点不等式
- 条件：a>0
- a>0：f((x₁+x₂)/2) ≤ (f(x₁)+f(x₂))/2，等号 ⟺ x₁=x₂；a<0 时反向
- 几何意义：a>0 时，弦的中点在抛物线上方（整条弦都在上方）
- 例：f(x)=x²，x₁=0，x₂=2：f(1)=1 < (0+4)/2=2

#### 闭区间上的最值
- 条件：x∈[m,n]
- h<m：在 [m,n] 上递增，最小 f(m)，最大 f(n)
- h>n：递减，最小 f(n)，最大 f(m)
- m≤h≤n：最小 f(h)；最大取 f(m)、f(n) 中离轴远的
- （以上 a>0；a<0 时最大、最小对调）

## 着重标注（本集必须突出的地方）
- ▼ a>0（远近规律）；▼ x∈[m,n]（闭区间含端点，最值才取得到）。
- 平方保序：两边都非负时，|u|<|v| ⇒ u²<v²。
- 例题答案：[−1,2] 上最小 f(1)=−1、最大 f(−1)=3；[2,3] 上递增，最小 f(2)=0、最大 f(3)=3。

## 解题思维导向（片尾一句话）
求二次函数在区间上的最值 → 先找对称轴，再看轴与区间的位置：最小值看顶点在不在区间内，最大值看离轴远的端点（a>0）。

## 易错点与边界（必须讲到）
- 开区间端点取不到时可能没有最值。
- a<0 时最大、最小对调。
- 比较远近用 |x−h|，不是比较 x 本身的大小。
