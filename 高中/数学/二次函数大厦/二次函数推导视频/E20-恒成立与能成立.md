# E20｜恒成立与能成立

- 建议时长：7–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：恒成立（全体实数）；恒成立 ⟺ 最不利的值满足；能成立 ⟺ 最有利的值满足；区间上恒成立 / 能成立（参数记作 λ）；相关系数 |r| ≤ 1（判别式）

## 这一集要讲明白的一件事
对一切实数恒成立：看 a 和 Δ，并单独讨论 a=0。在区间上恒成立或能成立：化为最值或分离参数，看 g 的取值范围——有没有最值、边界能否取到、是否无界，按比较方向选最大值或最小值。

## 开场问题（不依赖其他集）
sx²−sx+1>0 对一切实数 x 成立，s 取什么范围？x²−tx+1≥0 对 x∈[1,2] 恒成立，t 取什么范围？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **x+1/x 在 x>0 时的最小值**：x+1/x−2=(x²−2x+1)/x=(x−1)²/x≥0（x>0），x=1 时取等，所以 x+1/x≥2。
- **最值**
  - 条件：x∈ℝ；a>0
  - 最小值 k = −Δ/(4a)，在 x=h 取到；没有最大值
  - a<0 时：最大值 −Δ/(4a)，没有最小值
  - 由来（简短复习）：由“顶点式”：【平方非负】a>0，(x−h)²≥0 ⇒ a(x−h)²≥0；⇒ f(x) ≥ k，x=h 取等；(x−h)² 可以任意大：a>0 时没有最大值；a<0 时 f 可以任意小，没有最小值。
- **闭区间上的最值**
  - 条件：x∈[m,n]
  - h<m：在 [m,n] 上递增，最小 f(m)，最大 f(n)
  - h>n：递减，最小 f(n)，最大 f(m)
  - m≤h≤n：最小 f(h)；最大取 f(m)、f(n) 中离轴远的
  - （以上 a>0；a<0 时最大、最小对调）
  - 由来（简短复习）：由“单调性”：【分类讨论】按对称轴 h 与 [m,n] 的位置分三类（a>0）；h<m：区间在轴右侧，递增 ⇒ 最小 f(m)，最大 f(n)；h>n：区间在轴左侧，递减 ⇒ 最小 f(n)，最大 f(m)；m≤h≤n：左减右增 ⇒ 最小 f(h)；最大在离轴远的端点（远近规律）。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。
- **统计与概率中的二次：方差、最小二乘**
  - Q(t)=[(x₁−t)²+(x₂−t)²+…+(xₙ−t)²]/n 展开是 t 的二次函数（二次项系数 1）
  - 对称轴 t=(x₁+x₂+…+xₙ)/n：取平均数时偏差平方和最小，Q 的最小值就是方差
  - 配方成顶点式：Q(t) = 方差 + (t − 平均数)²；t=0 得 方差 = 平方的平均数 − 平均数²；分层合并的方差公式也由此得到
  - 已知方差反求某个数据：方差是这个数据的二次函数，列二次方程（可能两解）；例：12、13、15、16、17、14、a 的方差为 4 ⇒ a=11 或 18
  - 随机变量：Σ(xᵢ−t)²pᵢ = D(X) + (t−E(X))²，t=E(X) 时最小
  - 单个数据的范围：(xₖ − 平均数)² ≤ n·方差（其余偏差的平方都 ≥0）；例：10 个整数平均 2、方差 3 ⇒ (xₖ−2)² ≤ 30 ⇒ xₖ ≤ 7
  - 数据和固定且都非负，求方差最大：平均数固定，只看平方和；两数之和 S 固定、x∈[0,S] 时 x²+(S−x)² 开口向上，最大值在端点 x=0 或 S，所以数据往一个上集中；例：a+b+c=600（非负）⇒ a=600、b=c=0 时方差最大 80000
  - 概率：两点分布方差 p(1−p)、二项分布方差 np(1−p)，p=1/2 时最大；A、B 独立，P(A)=p，P(B)=1−p：P(AB)=p(1−p) 最大 1/4
  - 回归直线（斜率记 k，截距记 d）：固定 k，各点竖直偏差的平方和是 d 的二次函数（二次项系数为数据个数 n>0），最小处 d = y 的平均数 − k·x 的平均数，所以回归直线过样本中心点
  - 教材的回归直线记号：斜率、截距的字母上加“^”，表示估计值
  - 由来（简短复习）：由“最值”：【配方法】Q(t)=[(x₁−t)²+…+(xₙ−t)²]/n 展开：Q(t)=t² − 2·(平均数)·t + (平方的平均数)；二次项系数 1>0，对称轴 t=平均数 ⇒ 在平均数处最小；最小值 = 平方的平均数 − 平均数² = 方差。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **最值 → 恒成立（全体实数）**（推导）
   - ▼ 加条件：对一切 x∈ℝ 恒成立（系数含参数时先分 a=0 与 a≠0）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【等价变形】a>0：恒 >0 ⟺ 最小值 >0 ⟺ −Δ/(4a)>0 ⟺ Δ<0
   - a<0：f 可以任意小（没有最小值），不可能恒正
2. **闭区间上的最值 → 恒成立 ⟺ 最不利的值满足；能成立 ⟺ 最有利的值满足**（推导）
   - ▼ 加条件：x 只在某个区间内（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【等价变形】恒成立 ⟺ 最不利的值也满足
   - 能成立 ⟺ 最有利的值满足
3. **恒成立 ⟺ 最不利的值满足；能成立 ⟺ 最有利的值满足 → 区间上恒成立 / 能成立（参数记作 λ）**（推导）
   - 【分离参数】化成 λ 与 g(x) 比较，先求 g 的取值范围
   - 有最值用最值；边界取不到看边界值（恒成立可取等，能成立不可取等）；无界单独判断
   - 两边除以含 x 的式子时，先定它的正负（除以负数要变号）
4. **恒成立（全体实数） → 相关系数 |r| ≤ 1（判别式）**（推导）
   - 【判别式法】二次项系数 >0 的二次式对一切 t 恒 ≥0 ⟺ Δ≤0
   - 4(Σuᵢvᵢ)² − 4Σuᵢ²·Σvᵢ² ≤ 0
5. **【定义】二次函数 → 恒成立（全体实数）**（提供前提）
   - 【前提】a=0 时退化为一次函数或常数
6. **统计与概率中的二次：方差、最小二乘 → 相关系数 |r| ≤ 1（判别式）**（提供前提）
   - 【前提】偏差平方和、最小二乘

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 恒成立（全体实数）
- 条件：对一切 x∈ℝ
- ax²+bx+c>0 恒成立 ⟺ a>0 且 Δ<0，或 a=b=0 且 c>0
- （a=0、b≠0 时取遍全体实数，不可能恒正）
- ≥0：Δ<0 改为 Δ≤0，c>0 改为 c≥0

#### 恒成立 ⟺ 最不利的值满足；能成立 ⟺ 最有利的值满足
- 条件：x∈区间

#### 区间上恒成立 / 能成立（参数记作 λ）
- 条件：x∈区间
- 先求 g(x) 在区间上的取值范围：开还是闭、有没有无界、边界能否取到
- λ ≥ g(x) 恒成立：g 有最大值 M ⟺ λ ≥ M
- g 有上界、但取值范围的上边界 L 取不到 ⟺ λ ≥ L；g 向上无界 ⟹ 没有这样的 λ
- λ ≥ g(x) 能成立（至少一个 x）：g 有最小值 m₀ ⟺ λ ≥ m₀
- g 有下界、但取值范围的下边界 L′ 取不到 ⟺ λ > L′；g 向下无界 ⟹ 任意实数 λ 都行
- λ ≤ g(x)：规则对称——恒成立用最小值（或下边界），能成立用最大值（或上边界）
- 二次函数：a>0 时 f(x)≤0 在 [m,n] 上恒成立 ⟺ f(m)≤0 且 f(n)≤0（开口向上，最大值在端点）
- 核对 g(x)=x：x∈(0,1) 时恒成立 ⟺ λ≥1，能成立 ⟺ λ>0；x∈ℝ 时恒成立无解，能成立 λ 任意

#### 相关系数 |r| ≤ 1（判别式）
- 记 uᵢ、vᵢ 为 xᵢ、yᵢ 各自减去平均数：g(t) = Σ(vᵢ − t·uᵢ)² ≥ 0 对一切 t 成立
- g(t) = (Σuᵢ²)t² − 2(Σuᵢvᵢ)t + Σvᵢ²，二次项系数 >0（x 不全相等；y 也不全相等，r 才有定义）⇒ Δ ≤ 0
- ⇒ (Σuᵢvᵢ)² ≤ Σuᵢ² · Σvᵢ²，即 |r| ≤ 1；|r| = 1 ⟺ Δ = 0 ⟺ 所有点在一条斜率不为 0 的直线上
- g(t) 的顶点 t = (Σuᵢvᵢ)/(Σuᵢ²) 就是回归直线的斜率（最小二乘）
- 同一证法用于任意实数 aᵢ、bᵢ：aᵢ 不全为 0 时，对 Σ(bᵢ−t·aᵢ)² 用 Δ≤0，得 (Σaᵢbᵢ)² ≤ Σaᵢ² · Σbᵢ²（柯西不等式）；aᵢ 全为 0 时两边都为 0

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- a>0、Δ<0 时整条抛物线在 x 轴上方。
- 区间 [1,2] 上画 y=x+1/x，再画水平线 y=t：t 不高于曲线最低点（t≤2）时恒成立，t=2 时在 x=1 处取等。

## 着重标注（本集必须突出的地方）
- ▼ 系数含参数时先分二次项系数为 0 与不为 0：s=0 时 1>0 成立，所以答案含 s=0；s≠0 时要 s>0 且 Δ=s²−4s<0。例题答案 0≤s<4。
- 分离参数时两边除以 x，要先确认 x>0。
- t≤x+1/x 恒成立用最小值：x+1/x−2=(x−1)²/x≥0，x=1 时取等，所以最小值 2，t≤2。
- 比较方向：A≥g 恒成立用最大值，A≤g 恒成立用最小值；能成立反过来。

## 解题思维导向（片尾一句话）
恒成立 → 全体实数看 a 与 Δ；区间上 → 求最值或分离参数，按比较方向用最大值或最小值，边界取不到、无界单独判断。

## 易错点与边界（必须讲到）
- 漏掉 a=0 的情形。
- 恒成立和能成立用到的最值相反。
- 边界取不到时：恒成立可以取等，能成立不能取等。
- A≥g 遇到 g 向上无界时恒成立无解；A≤g 遇到 g 向下无界时恒成立无解。
