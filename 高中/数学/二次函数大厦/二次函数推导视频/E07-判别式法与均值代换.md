# E07｜判别式法求值域；已知和与积的均值代换

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：x 有实根 ⟹ Δ≥0：得到候选 y；判别式法求值域；均值代换

## 这一集要讲明白的一件事
把 y 看成已知数，“x 有实数解”就给出 Δ≥0，这是判别式法；但 Δ≥0 只给候选，还要检验：被排除的 x（分母为 0、不在定义域内）会让哪些 y 失去合法的根。反过来，已知两数的和 s、积 p，把这两个数看成 t²−st+p=0 的两根，就得到 s²≥4p。

## 开场问题（不依赖其他集）
y=(x²−x)/(x²−1) 能取哪些值？两个实数的和为 s、积为 p，s 和 p 能随便取吗？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **求根公式与判别式 → x 有实根 ⟹ Δ≥0：得到候选 y**（推导；含 2 个小步骤，逐个展开）
   - 【判别式法】把 y 当已知数，化成关于 x 的方程
   - 二次项系数 ≠0 时：x 有实根 ⟹ Δ≥0，得到候选 y
   - 【分类讨论】二次项系数为 0 时单独判断
2. **x 有实根 ⟹ Δ≥0：得到候选 y → 判别式法求值域**（推导）
   - 【检验】候选 y 回代：对应的 x 要在定义域内、分母 ≠0
3. **韦达定理 → 均值代换**（推导）
   - 【展开】(t−x₁)(t−x₂) = t² − st + p，所以 x₁、x₂ 是 t²−st+p=0 的两根
   - x₁、x₂ 是实数 ⇒ 判别式 s²−4p = (x₁+x₂)²−4x₁x₂ = (x₁−x₂)² ≥ 0

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### x 有实根 ⟹ Δ≥0：得到候选 y

#### 判别式法求值域
- y = f(x)/g(x) 化为关于 x 的方程 → 二次项系数含 y：为 0 时单独判断；不为 0 时 Δ≥0
- Δ≥0 只给出候选：每个候选 y 都要有 x 满足原定义域、且分母 g(x)≠0，不能只检验端点；定义域是区间时，化为“方程在该区间内有根”，用根的分布
- 例：y=(x²−x)/(x²−1)：Δ=(2y−1)²≥0 恒成立，但 y=1/2 时根只有 x=1（被排除），y=1 时也只有 x=1，值域是 y≠1 且 y≠1/2

#### 均值代换
- 两数 x₁、x₂：x₁+x₂=s，x₁x₂=p ⇒
- x₁、x₂ 是 t²−st+p=0 的两根
- ⇒ s² − 4p ≥ 0
- sinα、cosα：sinα+cosα=s ⇒ sinα·cosα=(s²−1)/2，两者是 t²−st+(s²−1)/2=0 的两根，再按 t∈[−1,1] 和象限取舍

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 判别式法的流程：化成关于 x 的方程 → 二次项系数为 0？ → Δ≥0 得候选 → 检验被排除的 x 会让哪些 y 失去合法的根。
- 例子里方程是 (y−1)x²+x−y=0，Δ=(2y−1)²≥0 对每个 y 都成立，所以候选是全体实数，不能逐个回代。改为检验被排除的 x=±1：x=1 对所有 y 都是根（被分母排除），x=−1 永远不是根；另一根 x=y/(1−y)（y≠1）等于 1 时 y=1/2，这时两根都是 x=1，全被排除；y=1 时方程变成 x−1=0，也只有 x=1。所以去掉 y=1/2 和 y=1，打叉。

## 着重标注（本集必须突出的地方）
- 二次项系数含 y 时，为 0 的情形单独判断。
- 检验不能只查端点：看被排除的 x 会让哪些 y 只剩下不合法的根。
- s²−4p=(x₁−x₂)²≥0 那一步。

## 解题思维导向（片尾一句话）
分式函数求值域 → 化成关于 x 的方程，Δ≥0 得候选，再检验被排除的 x 让哪些 y 失去合法的根；已知两数的和与积求范围 → 构造 t²−st+p=0，用 Δ≥0。

## 易错点与边界（必须讲到）
- 漏掉二次项系数为 0 的情况。
- 回代时分母为 0 的 x 要排除。
- 定义域是区间时，要看方程在区间内有没有根（根的分布）。
