# E08｜直线与抛物线：交点、相切、弦长

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：直线与抛物线的交点；|PQ| = √(1+k²)·|x₁−x₂|；直线截抛物线的弦长；中点弦；两条抛物线的公切线

## 这一集要讲明白的一件事
联立消元，把“交点个数”变成“二次方程的实根个数”，用联立后方程的判别式 Δ′ 判断相交、相切、相离；竖直直线单独看；弦长等于 √(1+k²)·|x₁−x₂|。

## 开场问题（不依赖其他集）
直线 y=x+m 与 y=x² 什么时候相切？竖直直线 x=1 与抛物线只有一个交点，算不算相切？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- 字母说明：弦的两端记作 P、Q；联立后方程的系数记作 a′、b′、c′。
- **两点距离公式**：P(x₁,y₁)、Q(x₂,y₂) 的距离 |PQ|=√((x₁−x₂)²+(y₁−y₂)²)。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。
- **【定义】函数**
  - 每个 x（定义域内）对应唯一的 y
  - 定义域、值域；图像 = 所有点 (x, f(x))
  - 由来（简短复习）：这是课本的定义或约定，直接承认（函数的定义）。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **求根公式与判别式 → 直线与抛物线的交点**（推导；含 2 个小步骤，逐个展开）
   - 【定义】函数每个 x 只对应一个 y：竖直直线 x=t 与图像恰有一个交点
   - 【代入消元】y=kx+m 代入，得关于 x 的二次方程，交点个数 = 实根个数
2. **直线与抛物线的交点 → |PQ| = √(1+k²)·|x₁−x₂|**（推导）
   - ▼ 加条件：Δ′=b′²−4a′c′>0（有两个交点才有弦）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 「两点距离」|PQ|=√((x₁−x₂)²+(y₁−y₂)²)
   - y₁−y₂=k(x₁−x₂) ⇒ |PQ|=√(1+k²)·|x₁−x₂|
3. **|PQ| = √(1+k²)·|x₁−x₂| → 直线截抛物线的弦长**（推导）
   - 「韦达」用于联立后的方程：(x₁−x₂)²=(x₁+x₂)²−4x₁x₂=Δ′/a′²
   - ⇒ |x₁−x₂|=√(Δ′)/|a′|
4. **韦达定理 → 中点弦**（推导）
   - ▼ 加条件：Δ′>0（有两个交点才有弦）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【韦达】x₁+x₂=−b′/a′，不用求出两根
   - 中点 x₀=(x₁+x₂)/2，再代入直线得 y₀
5. **直线与抛物线的交点 → 两条抛物线的公切线**（推导）
   - 【相切】设公切线 y=kx+m，与第一条抛物线联立得二次方程，令 Δ₁=0
   - 与第二条抛物线联立，令 Δ₂=0
   - 两个关于 k、m 的方程联立求解；例 y=x² 与 y=−(x−2)²：k²+4m=0，k²−8k−4m=0 ⇒ k=0、m=0 或 k=4、m=−4
6. **【定义】函数 → 直线与抛物线的交点**（提供前提）
   - 【前提】函数定义：每个 x 对应唯一的 y
7. **韦达定理 → 直线截抛物线的弦长**（提供前提）
   - 【前提】韦达定理（用于联立后的方程）
8. **直线与抛物线的交点 → 中点弦**（提供前提）
   - 【前提】联立消元得 a′x²+b′x+c′=0

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 直线与抛物线的交点
- 竖直直线 x=t：恰有一个交点
- y=kx+m：代入得 ax²+(b−k)x+c−m=0，看 Δ
- y=kx+m 时 Δ=0：只有一个公共点，即相切（教材定义）
- x=t 虽只有一个交点，但与对称轴平行，不算相切
- 直线与圆联立：Δ>0、Δ=0、Δ<0 ⟺ d<r、d=r、d>r（d 是圆心到直线的距离）
- 哪一段抛物线在直线上方：解二次不等式 f(x)−(kx+m)>0
- 一次、二次方程组：代入消元化成一元二次方程，解出一个未知数，再回代求另一个；两个二次方程的二次项相同时（如两个圆），两式相减消去二次项，得一次方程
- 与一般圆锥曲线联立：先看二次项系数，为 0 时化成一次方程，至多一个公共点（如双曲线与它的渐近线没有公共点），有也不算相切

#### |PQ| = √(1+k²)·|x₁−x₂|
- 条件：Δ′>0（两个交点）

#### 直线截抛物线的弦长
- 条件：Δ′>0（两个交点）
- y=kx+m 代入得 a′x²+b′x+c′=0（与抛物线 a′=a；与圆、椭圆等联立时 a′ 另算），Δ′=b′²−4a′c′
- 弦的两端 P、Q：|PQ| = √(1+k²)·|x₁−x₂| = √(1+k²)·√(Δ′)/|a′|
- 对 y 消元时：|PQ| = √(1+1/k²)·|y₁−y₂|（k≠0）
- 例：y=x² 与 y=x：|PQ| = √2

#### 中点弦
- 条件：Δ′>0（两个交点）
- 弦 PQ 的中点横坐标 x₀=(x₁+x₂)/2=−b′/(2a′)，纵坐标代回直线 y₀=kx₀+m
- 已知中点求直线：由 x₁+x₂=2x₀ 和中点在直线上，解出 k、m，再验 Δ′>0（圆、椭圆另验斜率不存在的弦）
- 例：y=x² 被 y=2x+1 截得的弦：x²−2x−1=0，中点 (1, 3)

#### 两条抛物线的公切线
- 设切线 y=kx+m，分别与两条抛物线联立，两个 Δ 都等于 0
- 例：y=x² 与 y=−(x−2)²：
- k=0，m=0 或 k=4，m=−4，即 y=0 与 y=4x−4

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- y=x² 与一族平行直线 y=x+m：m 变化时交点从 2 个变 1 个再变 0 个（相切时 m=−1/4）。
- 竖直线 x=1 穿过抛物线，只有一个交点，但不是相切。
- 弦长三角形：水平边 |x₁−x₂|，竖直边 |k|·|x₁−x₂|，斜边就是弦 PQ。

## 着重标注（本集必须突出的地方）
- Δ′ 是联立后方程 a′x²+b′x+c′=0 的判别式 b′²−4a′c′，不是原二次函数的 Δ。
- ▼ Δ′>0 才有两个交点、才有弦。
- 竖直直线与对称轴平行，不算相切。

## 解题思维导向（片尾一句话）
直线与抛物线 → 先看直线是不是竖直的；不是就联立消 y，看 Δ′ 判交点，用韦达算弦长。

## 易错点与边界（必须讲到）
- 弦长公式里的 Δ′、A 都来自联立后的方程。
- 公切线：两个 Δ 都等于 0，联立解 k、m。
