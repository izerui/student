# E24｜根的分布（二）：区间里的根

- 建议时长：7–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：两根都在 (m, n) 内；f(m)·f(n)<0 ⇒ (m,n) 内至少一个根；恰有一根在 (m, n) 内；两根分属两个区间

## 这一集要讲明白的一件事
两根都在 (m,n) 内，是“都大于 m”与“都小于 n”的合并；恰有一根在 (m,n) 内，看 f(m)f(n)<0，端点是根或重根时单独检验；两根分属两个区间，看几个端点处函数值的符号。

## 开场问题（不依赖其他集）
x²+tx+1=0 的两根都在 (0,2) 内，t 取什么范围？x²−2x+t=0 恰有一根在 (2,3) 内呢？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- 字母说明：本集 k 表示与两根比较的那个数；复习顶点式时，顶点纵坐标改记为 k₀，避免同屏出现两个 k。
- **两根都大于 k**
  - 条件：a>0
  - Δ ≥ 0，对称轴 −b/(2a) > k，f(k) > 0
  - （重根算两个根；两根都小于 k 同理）
  - a<0：两边乘 −1 化为 a>0（根不变），即 f(k)>0 改为 a·f(k)>0
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】看三样：判别式、对称轴位置、f(k) 的符号；必要：有两根 ⇒ Δ≥0；两根都 >k ⇒ 中点 h>k；k 在两根之外 ⇒ f(k)>0；充分：f(k)>0 ⇒ k 在两根之外；若 k 在右侧则 h≤x₂<k，与 h>k 矛盾，所以 k<x₁。
- **【定理】零点存在定理**
  - f 在 [m,n] 上连续，f(m)·f(n)<0
  - ⇒ f 在 (m,n) 内至少有一个零点
  - 由来（简短复习）：这是课本的定理（直接承认，不证），直接承认（课本承认，不证）。
- **一根大于 k、一根小于 k**
  - ⟺ a·f(k) < 0（不用再查 Δ）
  - 系数含参数时先确认 a≠0
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】a>0 时 f(k)<0 ⇒ 最小值 <0 ⇒ Δ>0，必有两根，且 k 在两根之间；反之亦然；a<0 时对 −f（开口向上）用同一结论：f(k)>0，即 a·f(k)<0。
- **交点式（两根式）**
  - 条件：Δ≥0
  - f(x) = a(x − x₁)(x − x₂)
  - x₁、x₂ 是 f(x)=0 的两根
  - 由来（简短复习）：由“韦达定理”：【因式分解】ax²+bx+c = a[x² − (x₁+x₂)x + x₁x₂]；= a(x−x₁)(x−x₂)。
- **三个二次的关系**
  - 条件：a>0
  - Δ>0：f(x)>0 ⟺ x<x₁ 或 x>x₂
  - f(x)<0 ⟺ x₁<x<x₂
  - Δ=0：f(x)>0 ⟺ x≠x₁；f(x)<0 无解
  - Δ<0：f(x)>0 对一切 x 成立
  - ≥、≤：把根并进去；Δ=0 时 f(x)≤0 ⟺ x=x₁；Δ<0 时 f(x)≤0 无解
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方；Δ<0：最小值 −Δ/(4a)>0，整条在上方。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **两根都大于 k → 两根都在 (m, n) 内**（推导）
   - 【同理】两根都 >m：Δ≥0，h>m，f(m)>0（上一条）
   - 两根都 <n：对称地 Δ≥0，h<n，f(n)>0
   - 两组同时成立 ⇒ Δ≥0，m<h<n，f(m)>0，f(n)>0
2. **【定理】零点存在定理 → f(m)·f(n)<0 ⇒ (m,n) 内至少一个根**（推导）
   - ▼ 加条件：只看区间 (m,n) 内的根（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 「零点存在定理」二次函数处处连续，f(m)·f(n)<0 ⇒ (m,n) 内至少一个零点
3. **f(m)·f(n)<0 ⇒ (m,n) 内至少一个根 → 恰有一根在 (m, n) 内**（推导；含 2 个小步骤，逐个展开）
   - 【反证法】若两个不同实根都在 (m,n) 内：由交点式，f(m)、f(n) 都与 a 同号，与 f(m)f(n)<0 矛盾
   - 重根 x₀ 在 (m,n) 内：f=a(x−x₀)² 不变号，同样矛盾 ⇒ 恰有一个
   - 【分类讨论】f(m)f(n)=0（端点是根）时单独检验
4. **一根大于 k、一根小于 k → 两根分属两个区间**（推导）
   - ▼ 加条件：a>0（a<0 时三处符号全反）（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【数形结合】f(n)<0 ⇒ n 在两根之间（a·f(n)<0）
   - f(m)>0 且 m<n ⇒ m 在两根之外的左侧，x₁∈(m,n)；同理 x₂∈(n,p)
   - 反之两根如此分布，三处函数值符号必如上
5. **交点式（两根式） → 恰有一根在 (m, n) 内**（提供前提）
   - 【前提】交点式 f(x)=a(x−x₁)(x−x₂)
6. **三个二次的关系 → 两根分属两个区间**（提供前提）
   - 【前提】f(k)>0 ⟺ k 在两根之外（a>0）

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 两根都在 (m, n) 内
- 条件：a>0
- Δ ≥ 0，m < −b/(2a) < n，f(m) > 0，f(n) > 0

#### f(m)·f(n)<0 ⇒ (m,n) 内至少一个根
- 条件：只看 (m,n) 内的根

#### 恰有一根在 (m, n) 内
- 条件：只看 (m,n) 内的根
- f(m)·f(n) < 0 时成立
- f(m)·f(n)=0（端点是根）或 Δ=0（重根）时单独检验

#### 两根分属两个区间
- 条件：a>0
- 一根在 (m,n)、另一根在 (n,p) ⟺ f(m)>0，f(n)<0，f(p)>0
- 两区间不相邻：一根在 (m,n)、另一根在 (p,q)（n≤p）⟺ f(m)>0，f(n)<0，f(p)<0，f(q)>0

## 着重标注（本集必须突出的地方）
- 例题答案一：Δ=t²−4≥0、对称轴 −t/2∈(0,2)、f(0)=1>0、f(2)=5+2t>0 ⟹ −5/2<t≤−2（t=−2 时重根 x=1）。
- 例题答案二：f(2)f(3)=t(3+t)<0 ⟹ −3<t<0；再检验端点：t=0 时根为 0、2，t=−3 时根为 −1、3，都没有根在 (2,3) 内；Δ=0 时 t=1，根 x=1 不在区间内。所以 −3<t<0。
- ▼ a>0；▼ 只看 (m,n) 内的根。

## 解题思维导向（片尾一句话）
根在区间里 → 端点函数值的符号 + 对称轴 + Δ；只有一根在区间里 → 先看 f(m)f(n)<0，再单独查端点和重根。

## 易错点与边界（必须讲到）
- f(m)f(n)<0 能推出恰有一根，但恰有一根时不一定 f(m)f(n)<0（端点是根的情形）。
- 两区间不相邻时，四个端点都要查。
