# E15｜奇偶性与含绝对值的二次函数图像

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：奇偶性；含绝对值的图像

## 这一集要讲明白的一件事
定义域关于原点对称时，二次函数是偶函数 ⟺ b=0；定义域是区间时它不可能是奇函数。y=|f(x)| 与 y=f(|x|) 的图像都由“按定义去绝对值”分段画出。

## 开场问题（不依赖其他集）
f(x)=x²+bx 什么时候是偶函数？y=|x²−2x−3| 和 y=x²−2|x|−3 的图像各长什么样？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **【定义】单调性、最值、奇偶性**
  - 在区间 D 上递增：对 D 内任意 x₁<x₂，都有 f(x₁)<f(x₂)；递减反之（取几个点验证不够）
  - 最小值：f(x₀)≤f(x) 对定义域内一切 x 成立，且取得到
  - 定义域关于原点对称时：偶函数 f(−x)=f(x)；奇函数 f(−x)=−f(x)
  - 定义域不关于原点对称：既不是奇函数也不是偶函数
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **【约定】点在图像上**
  - 点 (x₀, y₀) 在 y=f(x) 的图像上 ⟺ y₀ = f(x₀)
  - 由来（简短复习）：这是课本的定义或约定，直接承认（数与形互相翻译的依据）。
- **【定义】二次函数**
  - y = ax² + bx + c（a≠0）
  - 系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
  - 由来（简短复习）：这是课本的定义或约定，直接承认（研究对象的定义）。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。
- **求根公式与判别式**
  - Δ = b²−4ac
  - Δ>0：两个不等实根 x = (−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
  - 由来（简短复习）：由“(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)”：【分类讨论】右边分母 4a²>0，正负只看 Δ；Δ<0：右边为负，「平方非负」⇒ 无实根；Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】单调性、最值、奇偶性 → 奇偶性**（推导）
   - ▼ 加条件：定义域关于原点对称（此处停顿，讲为什么要加条件，并给去掉条件的反例）
   - 【代入】f(−x)=f(x) ⟺ 2bx=0 对定义域内一切 x ⟺ b=0（定义域含非零的 x）
   - 奇函数需 2ax²+2c=0 对定义域内一切 x；定义域含两个 x² 不同的 x（如区间）时得 a=c=0，与 a≠0 矛盾
2. **【约定】点在图像上 → 含绝对值的图像**（推导）
   - 【分类讨论】y=|f(x)|：f(x)≥0 的部分不变，f(x)<0 的部分取相反数 ⇒ x 轴下方的部分翻到上方
   - y=f(|x|)：x≥0 时就是 f(x)；x<0 时 f(|x|)=f(−x)，与 x>0 处的值相同 ⇒ 保留右侧，再关于 y 轴对称
3. **【定义】二次函数 → 奇偶性**（提供前提）
   - 【前提】f(x)=ax²+bx+c，a≠0

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 奇偶性
- 条件：定义域关于原点对称
- 定义域为 ℝ（或关于原点对称）时：b=0 ⟺ f 是偶函数
- 定义域是区间时，二次函数不可能是奇函数
- 例：y=x²，x∈[−1,3] 定义域不对称，非奇非偶

#### 含绝对值的图像
- y=|f(x)|：x 轴下方部分翻到上方
- y=f(|x|)：保留 y 轴右侧，再关于 y 轴对称

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- y=x²−2x−3（与 x 轴交于 −1、3，顶点 (1,−4)）：把 x 轴下方部分翻上去得 y=|f(x)|，顶点变成 (1,4)。
- 保留 y 轴右侧，再关于 y 轴对称得 y=f(|x|)，两个最低点 (±1,−4)。

## 着重标注（本集必须突出的地方）
- ▼ 定义域关于原点对称。反例：y=x²，x∈[−1,3]，非奇非偶。
- f(−x)=f(x) ⟺ 2bx=0 对定义域内每个 x 成立。

## 解题思维导向（片尾一句话）
判断奇偶性 → 先看定义域是否关于原点对称，再比较 f(−x) 与 f(x)；含绝对值的二次函数 → 分段去绝对值，或用翻折、对称作图。

## 易错点与边界（必须讲到）
- |f(x)| 翻的是 x 轴下方的部分；f(|x|) 是关于 y 轴对称的偶函数。
