# E21｜分式不等式、高次不等式与已知解集求系数

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：f(x)/g(x) 与 0 比较；分式不等式化为二次；高次不等式（穿根法）；解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是 ax²+bx+c=0 的两根；已知解集反求系数

## 这一集要讲明白的一件事
分式不等式乘以分母的平方化成整式（≥0 时另外保证分母不为 0）；高次不等式按因式的符号从右往左穿根；已知二次不等式的解集，可以反推开口方向和两根，再用韦达求系数。

## 开场问题（不依赖其他集）
(2x+1)/(x−2)≥1 怎么解？已知 x²+bx+c<0 的解集是 (−3,−1)，b、c 是多少？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：一个数大于另一个数 ⟺ 两数之差为正；等式两边同加、同乘同一个数仍相等；不等式两边同加同一个数方向不变，同乘（除）正数方向不变，同乘（除）负数方向反向；正×正=正，负×负=正，正×负=负；平方非负：x²≥0，等号 ⟺ x=0。
- **解一元二次不等式**
  - ① 二次项系数化为正（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写解集
  - 解集用集合（或区间）写：{x | x<x₁ 或 x>x₂}、{x | x₁<x<x₂}；无解写 ∅，对一切 x 成立写 ℝ
  - 也可先因式分解：(x−x₁)(x−x₂)>0 ⟺ 两个因式同号，化成两个一元一次不等式组
  - 例（实际情境，s 为刹车距离，单位米；v 为车速，单位千米每小时）：s=v²/100−v/10>6（v>0）⇒ (v−30)(v+20)>0 ⇒ v>30
  - 由来（简短复习）：由“三个二次的关系”：【同乘法】a<0 时两边乘 −1：系数化正，不等号反向；化成 a>0 后：求 Δ 和两根，按三个二次的关系读出解集；例：−x²+x+2>0 ⟺ x²−x−2<0 ⟺ (x−2)(x+1)<0 ⟺ −1<x<2。由“一元二次方程的解法”：【因式分解】(x−x₁)(x−x₂)>0 ⟺ 两个因式同号；⟺ x−x₁、x−x₂ 同正，或同负：两个一元一次不等式组。
- **【公理】实数运算与大小**
  - u>v ⟺ u−v>0；正数×正数=正数
  - 两边同加不变向；乘正数不变向，乘负数变向
  - uv=0 ⟺ u=0 或 v=0
  - 由来（简短复习）：这是课本的定义或约定，直接承认。
- **三个二次的关系**
  - 条件：a>0
  - Δ>0：f(x)>0 ⟺ x<x₁ 或 x>x₂
  - f(x)<0 ⟺ x₁<x<x₂
  - Δ=0：f(x)>0 ⟺ x≠x₁；f(x)<0 无解
  - Δ<0：f(x)>0 对一切 x 成立
  - ≥、≤：把根并进去；Δ=0 时 f(x)≤0 ⟺ x=x₁；Δ<0 时 f(x)≤0 无解
  - 由来（简短复习）：由“零点 ⟺ 根 ⟺ 交点”：【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方；Δ<0：最小值 −Δ/(4a)>0，整条在上方。
- **韦达定理**
  - 条件：Δ≥0
  - x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
  - 两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
  - 由来（简短复习）：由“求根公式与判别式”：【代入】两根相加、相乘：；(−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a。
- **顶点式**
  - f(x) = a(x − h)² + k
  - h = −b/(2a)，k = (4ac−b²)/(4a) = −Δ/(4a)
  - 由来（简短复习）：由“a[(x + b/2a)² − b²/(4a²)] + c”：【展开】−b²/(4a²) 乘 a 后移出括号：a(x + b/2a)² + (4ac−b²)/(4a)；记 h=−b/(2a)，k=(4ac−b²)/(4a)=−Δ/(4a)。由“平移：y = a(x−h)² + k”：【数形结合】一般式配方后得 a(x−h)²+k，正是平移的形式；⇒ 图像 = y=ax² 向右平移 h、向上平移 k：顶点 (h,k)，对称轴 x=h。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **解一元二次不等式 → f(x)/g(x) 与 0 比较**（推导）
   - 【移项通分】把不等式化成 f(x)/g(x) 与 0 比较
2. **f(x)/g(x) 与 0 比较 → 分式不等式化为二次**（推导）
   - 【同乘法】g(x)≠0 时 g(x)²>0，两边乘 g(x)² 方向不变：f/g>0 ⟺ f·g>0
   - ≥0 时 f/g=0 ⟺ f=0 且 g≠0，所以要单独保证 g≠0
3. **【公理】实数运算与大小 → 高次不等式（穿根法）**（推导）
   - 【符号规则】x−xᵢ 在 xᵢ 右边为正、左边为负
   - 乘积的正负由负因式的个数决定：从最右（全为正）往左，每过一个根多一个负因式
4. **三个二次的关系 → 解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是 ax²+bx+c=0 的两根**（推导）
   - 【分类讨论】a<0：解集在两根之外或为全体实数；a=0：一次不等式的解集是半直线、全体实数或空集
   - 所以解集是有界区间 (x₁,x₂) ⇒ a>0，且 x₁、x₂ 是方程的两根
5. **解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是 ax²+bx+c=0 的两根 → 已知解集反求系数**（推导）
   - 「韦达」x₁+x₂=−b/a，x₁x₂=c/a，解出 b、c（用 a 表示）
6. **【公理】实数运算与大小 → 分式不等式化为二次**（提供前提）
   - 【前提】乘正数，不等号方向不变
7. **三个二次的关系 → 高次不等式（穿根法）**（提供前提）
   - 【前提】三个二次的关系是 n=2 的情形
8. **韦达定理 → 已知解集反求系数**（提供前提）
   - 【前提】韦达定理

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### f(x)/g(x) 与 0 比较

#### 分式不等式化为二次
- f(x)/g(x) > 0 ⟺ f(x)·g(x) > 0
- f(x)/g(x) ≥ 0 ⟺ f(x)·g(x) ≥ 0 且 g(x)≠0
- 例：(2x+1)/(x−2) ≥ 1 ⟺ (x+3)/(x−2) ≥ 0 ⟺ x ≤ −3 或 x > 2

#### 高次不等式（穿根法）
- (x−x₁)(x−x₂)…(x−xₙ)>0（x₁<…<xₙ，各因式 x 的系数为正）
- 最右侧全为正，往左每过一个根变一次号；偶次重根不变号
- 例：(x+2)(x+1)(x−1)>0 ⟺ −2<x<−1 或 x>1
- ≥0（≤0）时再并上所有根；偶次重根可能是孤立点，例：(x−1)²(x−3)≥0 ⟺ x≥3 或 x=1

#### 解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是 ax²+bx+c=0 的两根

#### 已知解集反求系数
- ax²+bx+c<0 的解集为 (x₁,x₂) ⇒ a>0，x₁、x₂ 是方程的两根
- ax²+bx+c>0 的解集为 (x₁,x₂) ⇒ a<0（两边乘 −1 化成上一条）；>0 的解集为 x<x₁ 或 x>x₂ ⇒ a>0
- 由韦达：b=−a(x₁+x₂)，c=a·x₁x₂
- 例：x²+bx+c<0 解集 (−3,−1) ⇒ b=4，c=3

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 数轴穿根：(x+2)(x+1)(x−1)，从右上方开始穿线；分母的零点画空心圈。
- 偶次重根：(x−1)²(x−3)≥0，x=1 处不穿过，但它本身满足“=0”，是一个孤立点。

## 着重标注（本集必须突出的地方）
- 不能直接两边乘 x−2：它的正负不知道。
- ≥0 时分母的零点要挖去；并上分子的根。
- 解集是有界区间：<0 ⇒ a>0；>0 ⇒ a<0。

## 解题思维导向（片尾一句话）
分式不等式 → 移项通分，与 0 比较，化成乘积；高次不等式 → 穿根；已知解集 → 端点是方程的根，再用韦达。

## 易错点与边界（必须讲到）
- 移项通分前不能去分母。
- x 的系数为负的因式先化正（乘 −1 变号）。
- 偶次重根不变号，但 ≥0 时它本身要并进去。
