## 第 0 层　地基：函数、二次函数、实数运算与平方非负

### S01 【定义】函数
- 标志：每个 x（定义域内）对应唯一的 y
- 区域：起点
- 类型：起点
- 标签：【定义】
- 是什么：定义域、值域；图像 = 所有点 (x, f(x))
- 注释：起点：函数的定义

### S02 【定义】二次函数
- 标志：y = ax² + bx + c（a≠0）
- 区域：起点
- 类型：起点
- 标签：【定义】
- 是什么：系数含参数时：a=0、b≠0 是一次函数；a=b=0 是常数函数 y=c
- 注释：起点：研究对象的定义（同见不等式大厦〔S05〕）

### S03 【约定】点在图像上
- 标志：点 (x₀, y₀) 在 y=f(x) 的图像上 ⟺ y₀ = f(x₀)
- 区域：起点
- 类型：起点
- 标签：【约定】
- 是什么：点 (x₀, y₀) 在 y=f(x) 的图像上 ⟺ y₀ = f(x₀)
- 注释：起点：数与形互相翻译的依据
- 依赖：
  - 来源：S01
    种类：前提
    步骤：
      1. 【前提】图像 = 所有点 (x, f(x))

### S04 【公理】实数运算与大小

- 注释：起点：同见不等式大厦的地基〔S01、S02〕

### S09 【定义】集合与区间

### 借来的公式（工具箱）

### T01 平方差公式
- 标志：a² − b² = (a+b)(a−b)
- 区域：起点
- 类型：起点
- 标签：【公式】
- 是什么：推出作差恒等式：a[(x₁−h)²−(x₂−h)²] 拆成 a(x₁−x₂)(x₁+x₂−2h)

### T02 完全平方公式
- 标志：(a±b)² = a² ± 2ab + b²
- 区域：起点
- 类型：起点
- 标签：【公式】
- 是什么：配方：一般式化顶点式、方程配成 (x+b/2a)²=Δ/(4a²)

### T03 两点距离公式
- 标志：|PQ| = √((x₁−x₂)²+(y₁−y₂)²)
- 区域：起点
- 类型：起点
- 标签：【公式】
- 是什么：弦长：两点在 y=kx+m 上，化成 √(1+k²)·|x₁−x₂|

### T04 点到直线距离
- 标志：点 (x₀,y₀) 到 Ax+By+C=0：d = |Ax₀+By₀+C| / √(A²+B²)
- 区域：起点
- 类型：起点
- 标签：【公式】
- 是什么：抛物线上的点到直线：绝对值里是二次式，配方求最小值

### T05 求导法则

- 区域：起点
- 类型：起点
- 标签：【公式】
- 是什么：二次、三次函数：f′(x)=2ax+b；三次函数的导数是二次函数; 牛顿法：切线斜率 f′(xₖ)

### T06 指数、对数函数的单调性

- 区域：起点
- 类型：起点
- 标签：【公式】

### T07 同角关系

### T08 对数运算律

### T10 方差

## 第 1 层　图像与一元二次方程

### S10 【定义】虚数单位与复数
- 标志：i² = −1；复数 α+βi（α、β 为实数）
- 区域：起点
- 类型：起点
- 标签：【定义】
- 是什么：四则运算按多项式运算，遇 i² 换成 −1
- 注释：起点：必修四 复数（课本定义）

### R30 y = x² 的图像
- 标志：过原点，开口向上
- 区域：无条件
- 类型：结论
- 重要度：1
- 是什么：关于 y 轴对称；最低点 (0,0)；也是幂函数 y=x^α 中 α=2 的情形：偶函数，在 [0,+∞) 上递增
- 依赖：
  - 来源：S03
    种类：推出
    方法：列表描点
    步骤：
      1. 【列表描点】x=0,±1,±2 代入 y=x²，描点连线
      2. 【代入】(−x)²=x²：(x,y) 在图像上 ⟺ (−x,y) 也在，关于 y 轴对称
  - 来源：S05
    种类：前提
    步骤：
      1. 【前提】x²≥0：图像在 x 轴上方，最低点 (0,0)

### R31 y = ax² 的图像（a≠0）
- 标志：a>0 开口向上，a<0 开口向下
- 区域：无条件
- 类型：结论
- 重要度：1
- 是什么：|a| 越大，开口越小；关于 y 轴对称，顶点 (0,0)（a>0 最低点，a<0 最高点）
- 依赖：
  - 来源：R30
    种类：推出
    方法：伸缩
    步骤：
      1. 【伸缩】同一个 x，纵坐标乘 a
      2. a<0 时翻到 x 轴下方；|a| 越大，同一 x 处离 x 轴越远，开口越窄
      3. x 与 −x 的纵坐标同乘 a 仍相等：对称性不变，顶点仍是 (0,0)

### R32 平移：y = a(x−h)² + k
- 标志：由 y=ax² 向右平移 h、向上平移 k
- 区域：无条件
- 类型：结论
- 重要度：2
- 是什么：顶点 (h, k)，对称轴 x=h；口诀：左加右减（括号里）、上加下减（括号外）；移轴（坐标变换）：令 x′=x−h，y′=y−k，方程化成 y′=ax′²
- 依赖：
  - 来源：R31
    种类：推出
    方法：代换法
    步骤：
      1. 【代换法】(x₀,y₀) 在 y=ax² 上
      2. ⟺ (x₀+h, y₀+k) 在 y=a(x−h)²+k 上
  - 来源：S03
    种类：前提
    步骤：
      1. 【前提】点在图像上 ⟺ 坐标满足解析式

### R33 一元二次方程的解法
- 标志：直接开平方：x²=p（p≥0）⇒ x=±√p
- 区域：无条件
- 类型：结论
- 重要度：1
- 是什么：因式分解：(x−x₁)(x−x₂)=0 ⇒ x=x₁ 或 x₂；配方法：化成 (x+m)²=p 再开平方
- 依赖：
  - 来源：S04
    种类：推出
    方法：因式分解
    步骤：
      1. 【因式分解】乘积为 0 ⟺ 某个因式为 0（uv=0 ⟺ u=0 或 v=0）
      2. 例：x²−5x+6=(x−2)(x−3)=0 ⇒ x=2 或 x=3
      3. 【开平方】x²=p（p≥0）⇒ x=±√p；(x+m)²=p 同理 ⇒ x=−m±√p

### R39 x² + (b/a)x + c/a = 0

### R40 x² + (b/a)x = −c/a
- 标志：x² + (b/a)x = −c/a
- 区域：无条件
- 类型：中间步

### R41 (x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)
- 标志：(x + b/2a)² = (b²−4ac)/(4a²) = Δ/(4a²)
- 区域：无条件
- 类型：中间步
- 是什么：推导过程的中间步骤
- 依赖：
  - 来源：R40
    种类：推出
    方法：配凑
    步骤：
      1. 【配凑】两边加上一次项系数一半的平方 (b/2a)²
      2. 左边凑成完全平方，右边通分：(b²−4ac)/(4a²)

### R34 求根公式与判别式
- 标志：Δ = b²−4ac
- 区域：无条件
- 类型：结论
- 重要度：2
- 是什么：Δ>0：两个不等实根 x = (−b±√Δ)/(2a)；Δ=0：两个相等实根 x=−b/(2a)（解集只有一个元素）；Δ<0：无实根
- 依赖：
  - 来源：R41
    种类：推出
    方法：分类讨论
    步骤：
      1. 【分类讨论】右边分母 4a²>0，正负只看 Δ
      2. Δ<0：右边为负，「平方非负」⇒ 无实根
      3. Δ≥0：【开平方】x+b/2a=±√Δ/(2a) ⇒ x=(−b±√Δ)/(2a)

### P21 韦达定理
- 标志：x₁+x₂ = −b/a，x₁x₂ = c/a（重根算两个）
- 区域：有条件
- 类型：结论
- 重要度：2
- 条件：Δ≥0
- 是什么：两根之差：|x₁ − x₂| = √((x₁+x₂)²−4x₁x₂) = √Δ / |a|；复数范围 Δ<0 时 |a|·|x₁ − x₂| = √(−Δ)
- 注释：同见不等式大厦：工具 ⑫
- 依赖：
  - 来源：R34
    种类：推出
    方法：代入
    步骤：
      1. 【代入】两根相加、相乘：
      2. (−b+√Δ)/(2a) + (−b−√Δ)/(2a) = −b/a，乘积 = c/a
      3. ▼ 加条件：Δ≥0（有实根）

### R42 (a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂
- 标志：(a₁x+c₁)(a₂x+c₂) = a₁a₂x² + (a₁c₂+a₂c₁)x + c₁c₂
- 区域：无条件
- 类型：中间步
- 是什么：推导过程的中间步骤
- 依赖：
  - 来源：R33
    种类：推出
    方法：展开
    步骤：
      1. 【展开】(a₁x+c₁)(a₂x+c₂) 逐项相乘，合并同类项

### R24 十字相乘
- 标志：若 a=a₁a₂，c=c₁c₂，且 a₁c₂+a₂c₁=b，则 ax²+bx+c=(a₁x+c₁)(a₂x+c₂)
- 区域：无条件
- 类型：结论
- 是什么：例：2x²−7x+3=(2x−1)(x−3)
- 依赖：
  - 来源：R42
    种类：推出
    方法：比较系数
    步骤：
      1. 【比较系数】与 ax²+bx+c 对照：a=a₁a₂，c=c₁c₂，b=a₁c₂+a₂c₁
      2. 能找到这样的 a₁、a₂、c₁、c₂ 就能分解；交叉相乘再相加等于 b

### P23 Δ<0 时开平方
- 标志：x + b/2a = ±√(−Δ)·i/(2a)
- 区域：有条件
- 类型：中间步
- 条件：Δ<0（复数范围）
- 是什么：两根 x = (−b ± √(−Δ)·i)/(2a)
- 依赖：
  - 来源：R41
    种类：推出
    方法：开平方
    步骤：
      1. Δ<0：右边为负，实数范围内开不了平方
      2. 「复数」i²=−1 ⇒ Δ/(4a²) = (√(−Δ)·i/(2a))²
      3. 【开平方】x + b/2a = ±√(−Δ)·i/(2a)
      4. ▼ 加条件：Δ<0，在复数范围内求根

### R21 复数范围内的一元二次方程
- 标志：实系数，Δ<0：两个共轭虚根 x = (−b ± √(−Δ)·i)/(2a)
- 区域：有条件
- 类型：结论
- 条件：实系数；Δ<0（复数范围）
- 是什么：根与系数的关系仍成立：x₁+x₂=−b/a，x₁x₂=c/a；例：x²+2x+5=0：x=−1±2i；虚根成对：已知一根 α+βi（β≠0），另一根是 α−βi，再用韦达求系数；例：1+i 是 x²−ax+2=0 的根 ⇒ a=(1+i)+(1−i)=2
- 依赖：
  - 来源：P23
    种类：推出
    方法：代入
    步骤：
      1. 【代入】两根相加：虚部抵消，得 −b/a
      2. 两根相乘：(b² + (−Δ))/(4a²) = 4ac/(4a²) = c/a
  - 来源：S10
    种类：前提
    步骤：
      1. 【前提】i²=−1

### R25 两根的对称式求值
- 标志：x₁²+x₂²=(x₁+x₂)²−2x₁x₂
- 区域：有条件
- 类型：结论
- 重要度：1
- 条件：Δ≥0（实根）
- 是什么：1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)（x₁x₂≠0）；例：x²−3x+1=0：x₁²+x₂²=9−2=7；两交点 P(x₁,y₁)、Q(x₂,y₂) 在 y=kx+m 上：x₁x₂+y₁y₂ 代入直线化成 x₁+x₂、x₁x₂；OP⊥OQ ⟺ x₁x₂+y₁y₂=0（P、Q 不是原点）；非对称式：先用“根满足原方程”降次；例：x₁、x₂ 是 x²+2x−5=0 的两根，x₁²+x₁x₂+2x₁=5+(−5)=0；倒数根：ac≠0 时，cx²+bx+a=0 的两根是 ax²+bx+c=0 两根的倒数
- 依赖：
  - 来源：P21
    种类：推出
    方法：配凑
    步骤：
      1. 【配凑】x₁²+x₂²=(x₁+x₂)²−2x₁x₂，代入韦达
      2. 【通分】1/x₁+1/x₂=(x₁+x₂)/(x₁x₂)

### P24 换元后的方程
- 标志：t 的一元二次方程，t≥0（t=√x 或 t=x²）
- 区域：有条件
- 类型：中间步

### P19 换元解方程（舍根）

## 第 2 层　方程的延伸：判别式法、均值代换、直线与抛物线

### R12 判别式法求值域
- 标志：y = f(x)/g(x) 化为关于 x 的方程 → 二次项系数含 y：为 0 时单独判断；不为 0 时 Δ≥0
- 区域：无条件
- 类型：结论
- 重要度：1
- 是什么：Δ≥0 只给出候选：每个候选 y 都要有 x 满足原定义域、且分母 g(x)≠0，不能只检验端点；定义域是区间时，化为“方程在该区间内有根”，用根的分布；例：y=(x²−x)/(x²−1)：Δ=(2y−1)²≥0 恒成立，但 y=1/2 时根只有 x=1（被排除），y=1 时也只有 x=1，值域是 y≠1 且 y≠1/2
- 注释：同见不等式大厦〔R33〕
- 依赖：
  - 来源：R47
    种类：推出
    方法：检验
    步骤：
      1. 【检验】候选 y 回代：对应的 x 要在定义域内、分母 ≠0

### R13 均值代换
- 标志：两数 x₁、x₂：x₁+x₂=s，x₁x₂=p ⇒
- 区域：无条件
- 类型：结论
- 重要度：1
- 是什么：x₁、x₂ 是 t²−st+p=0 的两根；⇒ s² − 4p ≥ 0；sinα、cosα：sinα+cosα=s ⇒ sinα·cosα=(s²−1)/2，两者是 t²−st+(s²−1)/2=0 的两根，再按 t∈[−1,1] 和象限取舍
- 注释：同见不等式大厦〔R52〕
- 依赖：
  - 来源：P21
    种类：推出
    方法：展开
    步骤：
      1. 【展开】(t−x₁)(t−x₂) = t² − st + p，所以 x₁、x₂ 是 t²−st+p=0 的两根
      2. x₁、x₂ 是实数 ⇒ 判别式 s²−4p = (x₁+x₂)²−4x₁x₂ = (x₁−x₂)² ≥ 0
    条件：借用工具 求根公式与判别式（R34）

### R15 直线与抛物线的交点
- 标志：竖直直线 x=t：恰有一个交点
- 区域：无条件
- 类型：结论
- 是什么：y=kx+m：代入得 ax²+(b−k)x+c−m=0，看 Δ；y=kx+m 时 Δ=0：只有一个公共点，即相切（教材定义）；x=t 虽只有一个交点，但与对称轴平行，不算相切；直线与圆联立：Δ>0、Δ=0、Δ<0 ⟺ d<r、d=r、d>r（d 是圆心到直线的距离）；哪一段抛物线在直线上方：解二次不等式 f(x)−(kx+m)>0；一次、二次方程组：代入消元化成一元二次方程，解出一个未知数，再回代求另一个；两个二次方程的二次项相同时（如两个圆），两式相减消去二次项，得一次方程；与一般圆锥曲线联立：先看二次项系数，为 0 时化成一次方程，至多一个公共点（如双曲线与它的渐近线没有公共点），有也不算相切
- 依赖：
  - 来源：S01
    种类：前提
    步骤：
      1. 【前提】函数定义：每个 x 对应唯一的 y
  - 来源：R34
    种类：推出
    方法：定义
    步骤：
      1. 【定义】函数每个 x 只对应一个 y：竖直直线 x=t 与图像恰有一个交点
      2. 【代入消元】y=kx+m 代入，得关于 x 的二次方程，交点个数 = 实根个数

### R28 两条抛物线的公切线
- 标志：设切线 y=kx+m，分别与两条抛物线联立，两个 Δ 都等于 0
- 区域：无条件
- 类型：结论

  - 来源：R15
    种类：推出

    步骤：

### R16 抛物线的几何定义（选择性必修衔接）
- 标志：定义：到定点 F（焦点）与到定直线 l（准线，F 不在 l 上）距离相等的点的轨迹
- 区域：无条件
- 类型：结论
- 是什么：y = ax² 即 x² = (1/a)y；焦点 (0, 1/(4a))，准线 y = −1/(4a)；焦半径：点 (x₀, y₀) 在 y=ax² 上，到焦点的距离 = 到准线的距离 = |y₀ + 1/(4a)|
- 依赖：
  - 来源：R31
    种类：推出
    方法：距离验证
    步骤：
      1. 【前提】两点距离公式、点到直线的距离（课本）
      2. 【距离验证】令 q=1/(4a)，点 (x,y) 满足 y=ax² 时：
      3. x²+(y−q)² = (y+q)²（两边相减得 x² − 4qy = x² − y/a = 0）
      4. 即到 (0,q) 的距离 = 到直线 y=−q 的距离；反过来展开即得 y=ax²（a<0 时同样成立）

- 是什么：导函数（二次）为正的区间上递增，为负的区间上递减；导函数 Δ>0：两个变号零点，一个极大值点、一个极小值点；导函数 Δ≤0：不变号（重根处为 0 也不变号，如 y=x³），没有极值，单调性不变；F′(x₀)=0 是 x₀ 为极值点的必要不充分条件（F 在 x₀ 处可导）；三次函数（三次项系数为正）有三个零点 ⟺ 导函数 Δ>0，且极大值 >0> 极小值；导函数 = 恒正因子 × 二次式（如 eˣ·(x²−x−2)，或 x>0 时 ((x−1)(x−λ))/x）：单调性只看二次因式的符号，含参时比较两根大小
- 依赖：
  - 来源：R09
    种类：前提
    步骤：
      1. 【前提】二次项系数为负时先化正
  - 来源：R48
    种类：推出
    步骤：
      1. 「三个二次的关系」读出 F′ 的正负区间（3A<0 时先乘 −1 化正）
      2. 【前提】F′>0 的区间递增，F′<0 的区间递减；导数为 0 且左右变号的点是极值点（课本）
  - 来源：P07
    种类：前提
    步骤：
      1. 【前提】三个二次的关系：读出导函数的正负区间

### R29 牛顿法求根
- 标志：从 x₀ 出发，用切线与 x 轴的交点逼近：xₖ₊₁ = xₖ − f(xₖ)/f′(xₖ)
- 区域：无条件
- 类型：结论
- 是什么：例：x²+x−1=0，x₀=1：x₁=2/3，x₂≈0.619，真根 (√5−1)/2≈0.618
- 依赖：
  - 来源：R22
    种类：推出
    方法：切线
    步骤：
      1. 【切线】在 (xₖ, f(xₖ)) 处切线 y=f(xₖ)+f′(xₖ)(x−xₖ)，令 y=0 得 xₖ₊₁
      2. 需 f′(xₖ)≠0
      3. 【前提】导数的几何意义：f′(xₖ) 是切线斜率（选择性必修 6.1.2，由切线的定义得到）

### R36 统计与概率中的二次：方差、最小二乘
- 标志：Q(t)=[(x₁−t)²+(x₂−t)²+…+(xₙ−t)²]/n 展开是 t 的二次函数（二次项系数 1）
- 区域：无条件
- 类型：结论
- 是什么：对称轴 t=(x₁+x₂+…+xₙ)/n：取平均数时偏差平方和最小，Q 的最小值就是方差；配方成顶点式：Q(t) = 方差 + (t − 平均数)²；t=0 得 方差 = 平方的平均数 − 平均数²；分层合并的方差公式也由此得到；已知方差反求某个数据：方差是这个数据的二次函数，列二次方程（可能两解）；例：12、13、15、16、17、14、a 的方差为 4 ⇒ a=11 或 18；随机变量：Σ(xᵢ−t)²pᵢ = D(X) + (t−E(X))²，t=E(X) 时最小；单个数据的范围：(xₖ − 平均数)² ≤ n·方差（其余偏差的平方都 ≥0）；例：10 个整数平均 2、方差 3 ⇒ (xₖ−2)² ≤ 30 ⇒ xₖ ≤ 7；数据和固定且都非负，求方差最大：平均数固定，只看平方和；两数之和 S 固定、x∈[0,S] 时 x²+(S−x)² 开口向上，最大值在端点 x=0 或 S，所以数据往一个上集中；例：a+b+c=600（非负）⇒ a=600、b=c=0 时方差最大 80000；概率：两点分布方差 p(1−p)、二项分布方差 np(1−p)，p=1/2 时最大；A、B 独立，P(A)=p，P(B)=1−p：P(AB)=p(1−p) 最大 1/4；回归直线（斜率记 k，截距记 d）：固定 k，各点竖直偏差的平方和是 d 的二次函数（二次项系数为数据个数 n>0），最小处 d = y 的平均数 − k·x 的平均数，所以回归直线过样本中心点；教材的回归直线记号：斜率、截距的字母上加“^”，表示估计值
- 依赖：
  - 来源：P03
    种类：推出
    方法：配方法
    步骤：
      1. 【配方法】Q(t)=[(x₁−t)²+…+(xₙ−t)²]/n 展开：Q(t)=t² − 2·(平均数)·t + (平方的平均数)
      2. 二次项系数 1>0，对称轴 t=平均数 ⇒ 在平均数处最小
      3. 最小值 = 平方的平均数 − 平均数² = 方差

### R38 相关系数 |r| ≤ 1（判别式）
- 标志：记 uᵢ、vᵢ 为 xᵢ、yᵢ 各自减去平均数：g(t) = Σ(vᵢ − t·uᵢ)² ≥ 0 对一切 t 成立
- 区域：无条件
- 类型：结论
- 是什么：g(t) = (Σuᵢ²)t² − 2(Σuᵢvᵢ)t + Σvᵢ²，二次项系数 >0（x 不全相等；y 也不全相等，r 才有定义）⇒ Δ ≤ 0；⇒ (Σuᵢvᵢ)² ≤ Σuᵢ² · Σvᵢ²，即 |r| ≤ 1；|r| = 1 ⟺ Δ = 0 ⟺ 所有点在一条斜率不为 0 的直线上；g(t) 的顶点 t = (Σuᵢvᵢ)/(Σuᵢ²) 就是回归直线的斜率（最小二乘）；同一证法用于任意实数 aᵢ、bᵢ：aᵢ 不全为 0 时，对 Σ(bᵢ−t·aᵢ)² 用 Δ≤0，得 (Σaᵢbᵢ)² ≤ Σaᵢ² · Σbᵢ²（柯西不等式）；aᵢ 全为 0 时两边都为 0
- 依赖：
  - 来源：P08
    种类：推出
    方法：判别式法
    步骤：
      1. 【判别式法】二次项系数 >0 的二次式对一切 t 恒 ≥0 ⟺ Δ≤0
      2. 4(Σuᵢvᵢ)² − 4Σuᵢ²·Σvᵢ² ≤ 0
  - 来源：R36
    种类：前提
    步骤：
      1. 【前提】偏差平方和、最小二乘
