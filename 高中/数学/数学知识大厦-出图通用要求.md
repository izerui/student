# 数学知识大厦：出图通用要求

适用于任何一个数学主题的推导总图（如不等式、二次函数、数列、三角、向量、导数），以及由总图派生的视频任务书。各主题只在“主题补充”里写自己特有的起点、条件类型和分区，不改动本文的通用要求。

---

## 〇、定位与受众

- **定位**：知识大厦——揭示结论之间如何推出、如何联系，不是考点汇编或公式清单；速查、记忆和解题是应用，不是目的。
- **受众**：高中生（复习、自学；向下衔接初中），不预设看过其他资料。
- **读者看完应能**：顺着箭头独立重建关键推导并说清依据和条件；拿到题从入口反推到结论；分辨每个结论的适用范围。
- **形式**：单张可打印、可编辑的 draw.io 流程图（推导总图），同时作为视频任务书的生成依据。

## 一、数学内容

1. **从起点出发，不跳步**
   - 起点只放直接承认的东西：定义、公理、课本约定（如“a>b 的意思是 a−b 为正数”“函数的定义”“正数乘正数为正数”）。
   - 其余每个结论都要有一条推导线连到它；每条线只靠起点或已推出的结论，不引用“显然”“易知”。
   - 一个结论能由多条路得到时，主干画最基本的一条，其余用浅灰“【前提】”或“⋯ 同源”标注。
2. **结论写全：条件、结论、取等（或边界）三件套**
   - 条件写明限制的是哪些量（如“u,v>0；r,s 不限正负”“a≠0”“x∈[m,n]”）。
   - 取等、端点、能否取到、例外情况要单独写出（如“有零因子时单独判断”“端点不在区间内时最值取不到”）。
   - 写法以最不容易误用为准：能写成乘积式就不写成比值（分母可能为 0）；允许退化情形的要写明（如“允许 k=0”）。
3. **区分“运算能不能做”和“结论成不成立”**
   - 运算有没有意义：分母为 0、负数开偶次方、对数真数 ≤0 等，是运算本身做不了。
   - 结论成不成立：运算能做，但某个性质或比较规则在这里失效（如乘负数后比较方向反过来）。
   - 二者要分开讲，不能把“规则要看条件”讲成“运算被禁止”。
4. **每个加条件的地方都要能举出反例**：去掉条件后结论怎样失效，用具体数值说明；同时说明条件里每一部分是否都必要（不夸大条件的作用，例如不能把“整条链需要 a>0”说成“这一步对负数不成立”）。
5. **总览说法与实际推导一致**：分支的“来源”“用于”要和图上的连线一致，不夸大、不张冠李戴。
6. **数值必须自己算一遍**：图上、例题里、反例里的每个数都要重算；知识上的结论先核对教材或可靠来源，不凭印象判错。格式检查通过不等于内容正确，不说“没有数学错误”这类绝对话。
7. **完整、正确、好懂；不删内容**：发现表述有误时改正，不能删掉了事；内容多时调整层次和位置，不压缩条件。

## 二、关系与结构

1. **关系要有含义**：每条线必须是一种明确的关系，类型固定、样式固定：
   - 推导（实线，越粗越主干）：由前面的结论推出后面的结论；
   - 前提（浅灰线）：引用别处已推出的结论，线上写“【前提】”；
   - 等价转化、特例、推广、同源、配合：用节点内注释或固定标签表示，不画成推导线。
   - 不为了连成网络虚构联系；先后不等于因果，相关不等于推出。
2. **线上写【方法】和具体操作**：如“【代换法】令 x=a−b”“【配方法】提出 a 后补常数”。一条线含多个方法时逐个写出。
3. **不要断头路**：整个主题在一张图里连通；不拆成几块靠编号互相跳转。
4. **正推、反推都能走**
   - 正推（由因导果，综合法）：顺着箭头读。
   - 反推（执果索因，分析法）：题型入口写成“看到什么 → 反推到哪 → 先查什么 → 去这里查〔编号·坐标〕”。
5. **数形结合**：一个对象有几种表示（式子、图像、数轴、几何图形、表格）时，图上要体现表示之间的对应和转化，而不只是罗列公式。
6. **与其他主题的衔接用接口节点**：与另一张总图重合的结论，在本图写成接口节点，标“同见〈主题〉〔编号〕”，两图可以互查；不在两张图里各推一遍不同版本。

## 三、视觉约定

1. **节点颜色（全系列统一）**
   - 紫色：起点（定义、公理、约定，直接承认）；
   - 绿色：对所在的全体对象都成立的结论；白色：同样不加条件的中间一步；
   - 橙色：要加条件才成立的结论，标题旁用橙色标签写明限制哪些量；淡橙：有条件的中间一步；
   - 蓝色：公式与工具（不画线，按编号查）；
   - 青绿虚线框：题型入口。
2. **▼ 加条件**：从哪一步开始要加条件，就在那条线上标 ▼，写“▼ 加条件：……”。只有条件确实是“>0”时才可写“▼ 进入正数域”；含 0、含 ≠0、区间、参数范围一律写“加条件”。
3. **星号与拓展**：★ 越多越重要；超纲或竞赛内容加灰色“拓展”标签。
4. **编号与坐标**：每个节点标〔编号 · 坐标〕，坐标按图边网格（字母列 × 数字行）给出，排版后自动刷新并校验。
5. **线条用曲线**；主干加粗；条件域的分界清楚可见。
6. **左侧导航栏**：图例；条件范围示意（如“正数 ⊂ 非负 ⊂ 实数”，或本主题的条件层级）；公式与工具箱；题型入口目录；方法索引（每种方法的含义和在图上的位置）。
7. **单张、可打印、可编辑**：输出 draw.io 源文件和 PNG；文字在打印尺寸下可读。

## 四、方法

1. 能迁移的方法都要在图上出现，并进入方法索引，标出现次数和位置。
2. 常见方法名统一：作差、作商、代换、配方、配凑、展开、移项、提公因式、因式分解、分类讨论、反证、归纳、构造函数、求导、放缩、数形结合、代入特定值、同乘/同除、取倒数、平方/开方、待定系数等。新主题新增方法时补进索引。

## 五、用语

1. 中文；用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
2. 统一写“【前提】”，不写“【提供前提】”。
3. 同一字母在一张图（一集视频）里只表示一个量；会撞名时换字母并注明。

## 六、版本与审查

1. 只保留最新版本，旧版本清理或移出；不另出同一版本的变体。
2. 先审关系，再审细节；只阻断实质问题（错误事实、错误连接、会导致误判的缺失前提）。用户要求审查时先报告结论，不自动重写；要求修改时只改已确认的问题及其重复引用。
3. 出图前先列节点清单和分区结构给用户确认；按项目规则，生图（generate.js/edit.js）须用户确认后才执行。
4. 命名遵循 `<学科>-速查-<序号>-<简述>`（速查表）；总图文件放在约定位置，路径变动时同步更新所有引用。

## 七、由总图派生视频任务书（需要时）

1. **每集独立完整**：没看过其他集、也没见过总图的学生，能知道每一步为什么成立。用到的已有结论简短复习（写公式、条件、一两句由来），重点仍放在本集。编号、坐标、系列顺序只作元数据，不进讲解。
2. **连贯不跳步**：一步只做一件事；每步讲“为什么想到 → 怎么做 → 得到什么”。
3. **着重标注**：条件用橙框；▼ 处停顿并给去掉条件的反例（反例配叉号，不只靠颜色）；取等单独一行框出；最终结论粗框。
4. **数形结合**：图简单到学生能自己画；先出图再从图中读出结论；讲完说一句“以后遇到什么题可以画这张图”。
5. **结构**：单独成段的片头（标题用结论名）；片尾一句“看到什么 → 想到什么”；明确的结束画面。
6. 配音用默认语速，全系列统一。

## 主题补充（每个主题单独填写）

- **起点**：本主题直接承认的定义和约定。
- **条件类型**：本主题的结论通常受哪些条件限制（如正负、非零、定义域、区间、参数范围、判别式），条件范围示意怎么画。
- **分区**：主干和各分支。
- **接口**：与其他总图重合的结论及其编号。

### 不等式（已完成：数学/不等式大厦/outputs/inequality-tree-v50.drawio）
- 起点：实数大小的定义、正数相乘为正、绝对值定义、函数单调性定义、集合与区间、奇偶性、导数判单调、数学归纳法。
- 条件类型：任意实数 / 非负 / 正数，及“只限制部分量”。
- 分区：地基（实数大小与运算规则）→ 枢纽（平方非负）→ 均值、柯西、绝对值、二次函数、导数、归纳法、排序、函数性质、集合与线性规划、三角与向量等分支。
