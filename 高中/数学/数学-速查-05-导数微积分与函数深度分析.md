Section ① "从极限到导数到积分——微积分阶梯" (top, hero module spanning full width, dark blue header):
The CENTRAL THINKING MODEL — a three-level ascending staircase diagram drawn from left to right, each step higher than the previous, with bidirectional arrows between levels.

Level 1 (leftmost, lowest step, blue background): "极限 (老教材甲种本)"
  lim_{x→x₀} f(x) = L — 直觉: x 无限接近 x₀ 时, f(x) 无限接近 L
  两个重要极限:
    lim_{x→0} sinx/x = 1 (用单位圆夹逼证明)
    lim_{n→∞} (1 + 1/n)ⁿ = e ≈ 2.71828... (自然常数)
  连续性: lim_{x→x₀} f(x) = f(x₀) — 函数在 x₀ 处连续, 即图象不断裂
  ε-δ 语言(严格定义): ∀ε>0, ∃δ>0, 当 0<|x−x₀|<δ 时 |f(x)−L|<ε

Level 2 (middle step, green background): "导数 (新教材核心 + 老教材深化)"
  f'(x₀) = lim_{Δx→0} [f(x₀+Δx) − f(x₀)] / Δx
  几何意义: 曲线 y=f(x) 在点 (x₀, f(x₀)) 处切线的斜率
  物理意义: 位移 s(t) 的导数 = 瞬时速度 v(t); 速度的导数 = 加速度 a(t)
  微分(老教材): dy = f'(x)dx — 用切线段代替曲线弧做线性近似

Level 3 (rightmost, highest step, red background): "积分 (老教材甲种本)"
  不定积分: ∫f(x)dx = F(x) + C, 其中 F'(x) = f(x) (求导的逆运算)
  定积分: ∫_a^b f(x)dx = lim_{n→∞} Σ_{i=1}^{n} f(xᵢ)Δx (黎曼和)
  几何意义: 曲线 y=f(x), x 轴, x=a, x=b 围成区域的有符号面积

Between Level 2 and Level 3, a large bidirectional arrow labeled:
  "牛顿-莱布尼茨公式: ∫_a^b f(x)dx = F(b) − F(a)"
  "微分与积分互为逆运算——微积分基本定理"

Section ② "基本导数公式与积分对照表" (middle-left, medium module, green header):
A three-column table: f(x) | f'(x) 导数 | ∫f(x)dx 积分(老教材)

| f(x)      | f'(x)             | ∫f(x)dx              |
|-----------|-------------------|-----------------------|
| C (常数)   | 0                 | Cx + C₁               |
| xⁿ        | nxⁿ⁻¹            | xⁿ⁺¹/(n+1)+C (n≠−1)  |
| 1/x       | −1/x²            | ln|x| + C              |
| eˣ        | eˣ                | eˣ + C                 |
| aˣ        | aˣ·ln a           | aˣ/ln a + C            |
| ln x      | 1/x               | x·ln x − x + C        |
| log_a x   | 1/(x·ln a)        | (换底后用ln)            |
| sin x     | cos x             | −cos x + C             |
| cos x     | −sin x            | sin x + C              |
| tan x     | 1/cos²x = sec²x  | −ln|cos x| + C         |

Below the table — 求导法则 (Differentiation Rules):
(f ± g)' = f' ± g'  (和差)
(f·g)' = f'g + fg'  (乘积——莱布尼茨法则)
(f/g)' = (f'g − fg')/g²  (商)
[f(g(x))]' = f'(g(x))·g'(x)  (链式法则——复合函数求导)

老教材扩展 — 积分方法:
换元积分法: ∫f(g(x))g'(x)dx = ∫f(u)du (令u=g(x))
分部积分法: ∫u dv = uv − ∫v du (口诀: 反对幂指三——积分优先级)

Sub-area 0 — "高考导数大题·审题导航" (top of this section, highlighted with yellow-green background, magnifying-glass icon):
A comprehensive decision tree — the FIRST thing the student reads when facing a derivative exam problem:

"拿到导数大题 → 先审题: 几问? 每问求什么?"

第(1)问(通常较简单) → 对号入座:
├─ "求单调区间" → f'(x)=0解出临界点 → 列符号表(x, f'(x)正负, f(x)增减) → 写区间(⚠️开闭)
├─ "求极值/最值" → 同上 + 代入临界点和端点 → 比大小
├─ "求切线方程" → 区分两种类型! (→见Section④)
│     "在点P处的切线" → 唯一一条, y−f(x₀)=f'(x₀)(x−x₀)
│     "过点P的切线" → 设切点(t,f(t)), 可能多条
├─ "求参数范围(简单约束)" → 由f'(x₀)=0 或 f(x₀)=某值 解出参数a
└─ "证明f(x)在某区间上单调" → 证f'(x)在该区间上恒正(或恒负)

第(2)问(通常是压轴) → 对号入座:
├─ "证不等式 g(x)≥h(x)"
│    第一步: 构造 F(x)=g(x)−h(x)
│    第二步: 求F'(x), 分析F(x)的单调性
│    第三步: 找F(x)最小值, 证F_min≥0
│    ⚠️ F'(x)=0解不出来? → 放缩法或分段讨论
│    ⚠️ 常用放缩起点: lnx≤x−1, eˣ≥1+x, x/(1+x)<ln(1+x)<x
│
├─ "含参讨论(a的取值影响单调性/极值点)"
│    第一步: 求f'(x), 令f'(x)=0 → 解出x关于a的表达式x₀(a)
│    第二步: 问自己"x₀随a如何变化? 有几个根?"
│    第三步: 对a分类 → 每类画增减表 → 写对应结论
│    ⚠️ 分类标准: f'(x)=0的根的个数和位置随a的变化
│    ⚠️ 别忘验证边界情况(如a=0时f'(x)恒正/恒负)
│
├─ "恒成立/存在性问题"
│    恒成立 f(x)≥a对所有x → 转为 a≤inf f(x); 有最小值m则a≤m; 无最小值但下确界m₀有限则同样a≤m₀
│    存在性 ∃x使f(x)≥a → 有最大值M则a≤M; 无最大值但上确界M₀有限(取不到)则a<M₀; 上方无界则任意a成立
│    ⚠️ 最值须存在才能直接用≤max或≤min; 完整三路判断(无界/有限取到/有限取不到)见密码表06
│    能分离参数 → 分离后转为求另一侧函数的最值(严格不等式保持严格!→见06表)
│    不能分离 → 整体分析F(x)=f(x)−a的零点
│
└─ "零点个数问题"
     第一步: 用导数分析f(x)的单调性和极值 → 画草图
     第二步: 看图象与x轴(或水平线y=k)的交点个数
     第三步: 含参时 → 找临界值(极值恰好=0的参数值) → 分段讨论

Below the navigation tree, the detailed methods follow:

Sub-area A — "导数判断单调性":
f'(x) > 0 on interval (a,b) → f(x) 在 (a,b) 上单调递增 ↗
f'(x) < 0 on interval (a,b) → f(x) 在 (a,b) 上单调递减 ↘
f'(x) = 0 仅在个别点 → 不影响区间单调性 (如 f(x)=x³ 在 x=0 处 f'=0 但仍递增)

Sub-area B — "极值判定流程" (a mini decision tree):
Step ① 求 f'(x) = 0 的根 x₀ (及 f'(x) 不存在但函数连续的点，如尖点)
Step ② 检查 x₀ 两侧 f'(x) 的符号:
  左 + 右 − → x₀ 是极大值点, f(x₀) 是极大值
  左 − 右 + → x₀ 是极小值点, f(x₀) 是极小值
  同号(左+ 右+ 或 左− 右−) → x₀ 不是极值点
Step ③ 闭区间 [a,b] 上最值: 比较所有极值 f(x₀) 与端点值 f(a), f(b), 取最大为最大值, 最小为最小值

Sub-area C — "含参函数分类讨论 (高考压轴策略)":
General method:
① 对 f(x) = (含参数a的表达式) 求导 f'(x)
② 令 f'(x) = 0 → 解出极值点 x 关于 a 的表达式
③ 对参数 a 分类讨论: 不同范围的 a → 极值点位置不同 → 单调区间不同
④ 每种情况列增减表 (x | f'(x)符号 | f(x)增减)

典型框架示例 (compact):
f(x) = x·ln x − ax² → f'(x) = ln x + 1 − 2ax
令 f'(x)=0 → 含 a 的超越方程 → 需分 a 的范围讨论 x 的解的个数和位置

Sub-area D — "构造函数证明不等式 (高考压轴技术)":
Strategy:
要证 g(x) > h(x) → 构造 F(x) = g(x) − h(x) → 证 F(x) > 0 在定义域上恒成立
方法(与06表恒成立分支一致):
  ├─ F下方无界 → F>0不恒成立, 命题不成立
  ├─ F有最小值m → 需 m > 0 (严格! 不能写≥)
  └─ F无最小值但下确界m₀有限 → 需 m₀ ≥ 0 (取不到的下确界≥0即可)
  ⚠️ 详细的界的分类见密码表06恒成立分支

常见构造与基本不等式 (must know):
  ln x ≤ x − 1 (x > 0, 等号当且仅当 x=1) — 证法: F(x)=x−1−lnx, F'(x)=1−1/x, 最小值F(1)=0
  eˣ ≥ 1 + x (等号当且仅当 x=0) — 证法: F(x)=eˣ−1−x, F'(x)=eˣ−1, 最小值F(0)=0
  x − x²/2 < ln(1+x) < x (x > 0) — 用两次构造函数分别证左右
  x/(1+x) < ln(1+x) < x (x > 0)

Section ④ "切线问题分类" (bottom-left, compact module, orange header):
Three types clearly distinguished:

Type 1: "在点P(x₀, f(x₀))处的切线" (at a point ON the curve)
  切线方程: y − f(x₀) = f'(x₀)(x − x₀)
  → 唯一一条

Type 2: "过点P(a, b)的切线" (through a point, P may NOT be on the curve)
  设切点为 (t, f(t)), 则:
  ① 切线斜率 = f'(t)
  ② 切线过 P: b − f(t) = f'(t)(a − t)
  → 解此方程求 t → 可能有 0 条、1 条或多条

Type 3: "两曲线的公切线"
  设切点分别为 (t₁, f(t₁)) 和 (t₂, g(t₂)):
  ① f'(t₁) = g'(t₂) (斜率相同)
  ② 过两切点的直线斜率也等于 f'(t₁)
  → 联立求解
