Section ①b "圆锥曲线求方程导航" (compact sub-module below Section ①, yellow-green header bar labeled "高考第(1)问: 求曲线方程 → 审题导航"):

圆锥曲线第(1)问导航 → 拿到题第一步:
├─ 确定曲线类型: 椭圆/双曲线/抛物线 → 看题目关键词或定义
├─ 确定焦点在哪个轴:
│    ├─ 题目明确说"焦点在x轴" → x²/a² ± y²/b² = 1
│    ├─ 题目明确说"焦点在y轴" → y²/a² ± x²/b² = 1
│    └─ 不确定 → 设 mx²+ny²=1 (m,n待定): m,n同号为正→椭圆; m,n异号→双曲线。关键看解出的系数符号
├─ 列方程(需要两个方程解两个未知数a²和b²):
│    ├─ 已知离心率 e → e=c/a → 得a,b,c之间一个关系
│    ├─ 已知过某点 → 代入方程得一个等式
│    ├─ 已知焦点/顶点坐标 → 直接读出a或c的值
│    ├─ 已知渐近线(双曲线) → b/a=斜率 → 得b与a的比值
│    └─ 已知焦距/通径/准线 → 转化为a,b,c的关系
└─ 联立两个方程 → 解出 a² 和 b² → 写标准方程

⚠️ 审题四大陷阱(red warning box):
① 椭圆要求 a>b>0, 但双曲线只要求 a>0,b>0 (a不一定>b)!
② "焦距为2c" 不是 "焦点坐标为c" — 焦点坐标是(c,0)或(0,c)
③ 离心率 e=c/a, 不要把 e 和 c 搞混
④ 抛物线只有一个参数p → 一个条件就够了, 不需要两个方程

Section ③ "椭圆深度" (bottom-left, medium module, blue header):
Titled "第一定义↔第二定义·参数方程·光学性质"

Sub-block "两个定义的等价性":
  第一定义: |PF₁| + |PF₂| = 2a (焦点定义, 画图用)
  第二定义: |PF|/|PH| = e, 0 < e < 1 (焦点-准线, 求焦半径用)
  等价性: 由第一定义出发, 设焦点F₁(−c,0)和准线x = −a/e = −a²/c,
  经代数推导可证|PF₁| = a + ex₀ = e·(x₀ + a/e) = e·|PH|

Sub-block "焦点三角形":
  P在椭圆上(不在长轴上), ∠F₁PF₂ = θ
  Draw a triangle with vertices F₁, P, F₂. Label the angle θ at P, sides |PF₁|=r₁, |PF₂|=r₂.
  r₁ + r₂ = 2a
  r₁ · r₂ = 2b²/(1 + cos θ) (由余弦定理推得)
  面积 S = ½r₁r₂sin θ = b²·tan(θ/2)
  ⚠️ θ越大 → 面积越大; P在短轴端点(0,±b)时θ取最大值, S_max = bc (此时r₁=r₂=a)

Sub-block "参数方程(老教材·解析几何甲种本)":
  x = a cos t,  y = b sin t  (t ∈ [0, 2π))
  几何意义: 在外接圆x²+y²=a²上取点, y坐标缩放b/a倍
  应用: 求椭圆上点到焦点距离最值, 面积等问题更简洁

Sub-block "光学性质":
  从一个焦点发出的光线, 经椭圆反射后, 必过另一个焦点
  应用: 耳语走廊(椭圆形大厅的声学聚焦)、碎石机(椭圆反射聚焦冲击波)

Section ④ "双曲线深度" (bottom-center, medium module, red header):
Titled "渐近线·等轴·共轭——双曲线的独特性质"

Sub-block "渐近线":
  y = ±(b/a)x: 双曲线无限趋近但永不到达
  Draw a small diagram: hyperbola with dashed asymptote lines, label the angle between asymptote and x-axis as arctan(b/a)
  渐近线方程记忆: 把双曲线方程中"1"换成"0" → x²/a² − y²/b² = 0 → y = ±(b/a)x

Sub-block "双曲线系":
  共渐近线: x²/a² − y²/b² = λ (λ≠0), 所有这些双曲线共享同一对渐近线
  共轭双曲线: x²/a² − y²/b² = 1 与 y²/b² − x²/a² = 1 (互为共轭, 渐近线相同)

Sub-block "等轴双曲线":
  a = b → x² − y² = a² → 渐近线 y = ±x → e = √2
  "最标准"的双曲线, 两条渐近线互相垂直

Sub-block "参数方程(老教材)":
  x = a sec t = a/cos t,  y = b tan t  (t≠π/2+kπ; cos t>0时对应右支, cos t<0时对应左支 → 覆盖两支)
  或用双曲函数: x = a cosh t,  y = b sinh t (只覆盖右支x≥a; 完整双曲线需 x=±a cosh t; 大学预备知识)
