## 参照基准：不等式大厦（一切以它为准）

`数学/不等式大厦/outputs/inequality-tree-v50.drawio` 是唯一样板（节点、连线样式与原 v35 相同；v35 已从目录删除，需要时从 git 历史取回）。除下文“规范映射”写明的恒等式特有差别外，全部照搬：

- **样式**：节点、连线、徽标的 style 串直接从 v35 文件提取（紫 #F3E5F5、绿 #E8F5E9、白 #FAFAFA、橙 #FFE0B2、淡橙 #FFF3E0、蓝 #E3F2FD、入口 #E0F2F1 等），曲线连线，主干加粗，浅灰前提线。
- **版面**：分区背景框（#F7F9FA）+ 深色“▍区名：主线概括”标题条；起点区在最上方，依次往下；上下两边字母列网格（A、B、C…），节点标〔编号 · 坐标〕，排版后自动重算。
- **节点格式**：条件徽标 + 编号徽标 + “拓展”标签 + “★ 标题”；标题居中、多行正文左对齐；“⋯ 配合 / 同源”注释行；公式全部 LaTeX（math=1），分式行上下留距。
- **连线标签**：v35 精简后的写法——“【方法】+ 关键一步”，最易断层处保留 1～2 行完整推理（反证、归纳等）。
- **左侧导航栏**：图例、条件范围示意（本图为三类条件示意：定义域限制、结构前提、符号分支）、公式与工具箱、题型入口目录、方法索引（含次数与〔坐标〕）、正推/反推说明。
- **题型入口**：青绿虚线框，“看到什么 → 反推到哪 → 先查什么 → 去这里查〔编号·坐标〕”。
- **编号**：S 起点、R 无条件、P 有条件。

## 修改规则：只增不删

原有的推导（来路、【方法】、关键一步）、条件与反例、用于与配合、题型入口，只能补充或修正，不能删减。任何删除或改写，先列出原文与改后内容，经用户确认再执行。

## 目标

一张可打印、可编辑的 draw.io 推导总图：从少数起点出发，不跳步推出高中全部恒等式（含灰色“拓展”）。读者能顺着箭头重建每一步、看出每个条件（定义域、结构前提、符号分支）在哪一步出现，并看清“恒等式只来自少数源头，靠少数变形手法反复生成”这一规律。

## 范围

- 全部素材（41 条 + 4 个起点）一张图。
- 对照 B 版教材补齐（已核出处）：诱导公式、半角、积化和差/和差化积、倍角（必修三）；换底（必修二）；复数及三角形式 10.3（必修四）；杨辉三角、二项式系数（选必二）；数学归纳法、Σk²（选必三）；十字相乘（必修一）。辅助角、降幂教材正文未命名，按常用推论处理。
- 拓展（灰色标签）：万能公式（教材未收）、欧拉公式、xⁿ−yⁿ 分解、a³+b³+c³−3abc 分解、拉格朗日恒等式、k·C(n,k)=n·C(n−1,k−1)。

## 组织方式：按起点分树（方案 A）

主干是“源头 → 变形 → 结论”。变形手法写在连线【方法】标签上并进入方法索引，不作为分区。

### 起点（紫）
S1 运算律与等式性质｜S2 乘方与指数幂定义（正整数→零、负、分数指数）｜S3 对数定义｜S4 三角函数单位圆定义｜S5 向量数量积定义｜S6 复数定义 i²=−1｜S7 两个计数原理｜S8 导数定义｜S9 等差/等比数列定义｜S10 数学归纳法

### ① 代数树（S1）
分配律展开 → 平方差、完全平方 → 三数和平方 → 立方和/差、和/差的立方；互换式 a²+b²=(a+b)²−2ab 等三条；因式分解（提公因式、公式法、十字相乘、分组）；配方 → 顶点式 → 韦达定理。拓展：xⁿ−yⁿ、a³+b³+c³−3abc、拉格朗日恒等式。

### ② 指数对数树（S2、S3）
指数运算律 → 分数指数幂；对数恒等式 a^(log_a N)=N；对数运算律（积、商、幂）→ 换底 → log_a b·log_b a=1、log_{aᵐ}bⁿ=(n/m)log_a b。标“指数 ⟷ 对数 互逆”。

### ③ 三角树（S4、S5、S6）
- 勾股恒等式、商数关系 → 1+tan²θ=1/cos²θ；诱导公式（终边关于 x 轴、y 轴、原点、y=x 对称，六组）。sin、cos 的诱导公式对任意实数 α 成立，按无条件结论处理（绿/白），不加象限条件；“把 α 看作锐角定符号”只作记忆口诀写在节点注释里，不作前提。tan 相关的诱导公式只注明实际定义域〔定义域〕（两边的 tan 都有定义）。
- 数量积坐标式（单位正交基 + 分配律）→ cos(α−β) → 其余三个 → tan(α±β)。
- 倍角 → 降幂、半角；积化和差 ⟷ 和差化积；辅助角。
- 解三角形：余弦定理（向量平方展开；A=90° 退化为勾股）、正弦定理、面积公式 S=½ab·sinC。
- 复数：四则运算；iⁿ 周期 4；共轭 z·z̄=|z|²、和/积的共轭；|z₁z₂|=|z₁||z₂|；三角形式乘除（由和差角）→ 棣莫弗。拓展：万能公式、欧拉公式。

### ④ 数列树（S9，借用①）
等差通项（累加）、求和（倒序相加）；等比通项（累乘）、求和（错位相减，q≠1）；下标性质 m+n=p+q；aₙ=Sₙ−Sₙ₋₁（n≥2）；裂项 1/[k(k+1)]；Σk → Σk²（(k+1)³ 展开累加相消）→ Σk³（归纳法）。

### ⑤ 计数树（S7）
排列数 → 组合数 → 对称性、杨辉三角递推 → 二项式定理 → 系数性质（赋值 x=1 得 2ⁿ；x=−1 得奇偶项和相等）。拓展：k·C(n,k)=n·C(n−1,k−1)。

### ⑥ 导数树（S8）
基本初等函数导数；和、差、积、商法则（积 → 商）；简单复合函数求导（链式法则）。
- 互为反函数的是原函数 eˣ 与 ln x（连线连原函数，接 ② 指数对数树）；导数关系另写一条推导：对 ln(eˣ)=x 两边求导，链式法则得 (ln u)′·eˣ=1，令 u=eˣ 得 (ln u)′=1/u（定义域 u>0）。课本直接给出 (ln x)′=1/x，此线作为“由来”标注。

### 跨树连线（标“★ 跨树”）
组合数 → 二项式定理 → 两数和的立方（n=3）；两数和的立方 → Σk²；数量积 → 和差角 → 复数三角形式相乘；xⁿ−1 分解 ⟷ 等比求和；指数 ⟷ 对数（eˣ 与 ln x 互为反函数）→ 经链式法则得 (ln x)′=1/x（x>0）；勾股恒等式 ⟷ 余弦定理（A=90°）。

### 防循环论证
数量积坐标式只由分配律 + 单位正交基推出；余弦定理由向量推出。不使用素材中“余弦定理 → 数量积 → 和差角”的路径。

## 规范映射（恒等式与不等式的差别）

| 颜色 | 恒等式图中的含义 | 例 |
|---|---|---|
| 紫 | 起点 | S1–S10 |
| 绿/白 | 对所有取值成立、无需任何条件 | 完全平方、sin²+cos²=1 |
| 橙/淡橙 | 要加条件才成立，橙标签写明条件**类别**和内容 | 见下表 |

颜色不变，条件标签分三类（标签前缀固定）：

| 条件类别 | 含义 | 例 | 去掉条件会怎样 |
|---|---|---|---|
| 〔定义域〕 | 不满足时某一边没有意义 | 韦达定理、交点式、两根对称式（Δ≥0，实根存在；v3 审查后由〔结构前提〕移入）、tan（cosθ≠0）、对数（M,N>0）、换底（a,c>0 且≠1）、等比求和（q≠1）、万能（α≠π+2kπ）、组合数（0≤k≤n）、aₙ=Sₙ−Sₙ₋₁（n≥2）、(ln x)′（x>0） | 一边无意义，如 q=1 时分母为 0，应改用 Sₙ=na₁ |
| 〔结构前提〕 | 两边都有意义，但只对具有某种结构的对象成立 | 等差通项与求和（{aₙ} 为等差数列）、等比通项与求和（{aₙ} 为等比数列）、下标性质 m+n=p+q（等差/等比）、正弦/余弦定理（a,b,c 为同一三角形的边与对角） | 两边有意义但不相等，如数列 1,2,4,7 不是等差数列：S₄=14，而 n(a₁+aₙ)/2=4×8/2=16 |
| 〔符号分支〕 | 两边都有意义，但根号或角的取值要按象限/范围选定 | 半角公式的 ±（由 α/2 所在象限定）、辅助角 φ 的位置（由 a、b 的正负定）、复数辐角 | 两边有意义但不相等，如 α=300°：α/2=150°，cos150°=−√3/2；而 +√((1+cos300°)/2)=+√3/2，取正号就错了 |

- 蓝色“公式与工具箱”保留（同 v35 左栏）：放查表类内容（如特殊角三角函数值、杨辉三角前几行），具体条目在节点清单中确认。
- ▼ 加条件：标在开始需要条件的那条线上，写成“▼ 加条件〔类别〕：……”。
- 反例按条件类别写：〔定义域〕说明哪一边没有意义；〔结构前提〕〔符号分支〕给出“两边都有意义但不相等”的具体数值。
- ★ 标枢纽：分配律展开、勾股恒等式、和差角、组合数、二项式定理。
- 连线：推导（实线）、前提（浅灰）；同源/互逆/特例/推广写在节点内。
- 接口：不等式大厦 v35（平方差、完全平方、立方和、韦达、二项式→伯努利、裂项、拉格朗日→柯西、辅助角→三角有界）；二次函数大厦（配方、顶点式、韦达）。标“同见〈主题〉〔编号〕”，不重复推导。
- 左侧导航：图例；三类条件示意，各类下并列列出、不画箭头（这些是不同运算各自的条件，互不包含、互不推出）：〔定义域〕并列分出“分式：分母≠0”“对数：真数>0，底数>0 且≠1”“正切：cosθ≠0”“下标与组合数：n≥2、0≤k≤n”；〔结构前提〕并列分出“等差数列”“等比数列”“方程有两根（Δ≥0）”“同一三角形的边与对角”；〔符号分支〕并列分出“半角 ±”“辅助角 φ”“复数辐角”。节点清单的条件标签沿用同一并列结构；题型入口（化简求值、因式分解、三角化简、数列求和、展开式系数等）；方法索引（展开、代换、特例、逆运算、累加相消、错位相减、倒序相加、赋值、归纳等）。

## 三层：工具、方法、题型入口

| 层 | 回答的问题 | 性质 | 图中位置 |
|---|---|---|---|
| 工具 | 能用什么 | 公理、定义、定理、公式，一定能写成一个公式，拿来直接用，如平方差、韦达定理 | 主图每个节点、工具箱；线上“由 工具名〔编号〕”、浅灰线“⇐ 工具” |
| 方法 | 往哪走 | 运算逻辑、变换方式，本身不是公式：把眼前的问题转化成什么样子 | 推导线上的【】；左侧“方法”一栏（14 类，每类写方向、依据、信号、范例、陷阱） |
| 题型入口 | 从哪进 | 看到什么题，走哪个方向、用哪些工具 | 问题节点（“方向”“工具”两行）；左侧“题型入口”一栏 |

一道推导题的过程就是：先用方法定方向，比如“超越式比大小 → 构造函数，转成求最小值”；再用工具完成每一步，比如求导公式、单调性。方法决定能不能想到，工具决定能不能算对。

界定：工具一定能写成一个公式（公式、定理、公理、定义），可以拿来直接用；方法是运算逻辑、公认的运算方式或变换逻辑（换元、同乘、配凑、作差相消、补形等），本身不是公式，是解题的方向和思路。推导线上只写方法；用到的工具写成“⇐ 工具 X”。

写法参照不等式大厦 v47，但线上不加类别名：【】写具体动作（【移项】【开平方】），并把过程写全（从哪个式子出发、怎么变、得到什么）；动作归哪类方法，到“方法”栏查；套用公式写“由 工具名〔编号〕：”；写不成一个公式的流程节点加棕色“解法”标记。题型入口按题型查，“方法”一栏按方法查，是同一张表的两种查法。
