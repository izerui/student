拿到解析几何大题 → 审题三件事(numbered ①②③):

① 确认曲线方程(第(1)问通常考这个):
  ├─ 题目直接给出方程 → 记下备用
  └─ 需要求方程 → 用定义/待定系数法(→详见密码表11导航)

② 第(2)问: 看清要你求/证什么(决定计算方向):
  ├─ 求定值 → 设出变量, 算到最后参数应该全消掉, 若没消完就回头检查
  ├─ 求定点 → 设直线含参数k, 化简后分离k, 要求"对所有k都成立"→各项系数=0
  ├─ 求范围/最值 → 最终化成关于参数的函数, 求值域(注意联立Δ≥0的约束!)
  ├─ 求面积 → S=½|AB|·d 或 S=½|x₁y₂-x₂y₁| (后者当顶点在原点时)
  ├─ 证明某性质 → 按五步法计算, 验证结果为常数或满足条件
  └─ 存在性问题 → 假设存在, 推出条件, 检验是否有解(包括Δ≥0和点在曲线上)

③ 设直线方程 → ⚠️ 最关键的一步, 设法选错全盘皆输:
  ├─ 直线过特殊点(x₀,y₀) → y-y₀=k(x-x₀), 但⚠️必须单独讨论 x=x₀ (k不存在)!
  ├─ 能从条件判断斜率一定存在 → 放心设 y=kx+m
  ├─ 斜率不确定是否存在 → 两种方案:
  │    方案A: 先设 y=kx+m 算出结论, 最后单独验证 x=常数 的情况
  │    方案B: 设 x=my+n (当曲线关于x轴对称时好用, 避免讨论垂直线; ⚠️但改为漏掉水平线y=c, 需单独补查!)
  └─ 焦点弦问题 → 可直接用焦半径/焦点弦公式(→Section③), 不一定需要联立

设完直线 → 进入五步法 ↓ (arrow pointing down to Section ①)

Section ① "设→联→韦→代→化 五步法" (below Section ⓪, hero module, full width, dark blue header):
The CENTRAL THINKING MODEL of this poster — a five-step flowchart drawn as a horizontal pipeline with five large numbered boxes connected by thick arrows (left to right). Each box has a title, content, and warning callouts.

Box 1 "设" (orange background):
  Title: 第一步·设直线方程
  Content:
  过定点(x₀,y₀): y − y₀ = k(x − x₀)  或  x = x₀
  一般设法: y = kx + m
  ⚠️ Warning callout (red border): 必须讨论斜率k是否存在!
    当直线与y轴平行时(x=常数), k不存在, 需单独代入曲线方程验证!

Box 2 "联" (blue background):
  Title: 第二步·联立方程组
  Content:
  将直线方程代入曲线方程, 消去y(或x)
  整理为一元二次: ax² + bx + c = 0
  (其中a,b,c是含k,m的表达式)
  ⚠️ Warning callout (red border): 检查二次项系数a≠0!
    若a=0, 方程降为一次或常数方程, 须另行判断:
    一次方程bx+c=0(b≠0)→有一个解(一个交点);
    常数方程0=c, 若c≠0→无解无交点(如y=x与x²-y²=1联立得0=-1)!
    不可使用韦达定理!

Box 3 "韦" (green background):
  Title: 第三步·韦达定理
  Content:
  设交点 A(x₁,y₁), B(x₂,y₂):
  x₁ + x₂ = −b/a
  x₁ · x₂ = c/a
  前提条件(两步检查):
  ⑴ 消元后二次项系数a≠0 (否则不是二次方程, 不能用韦达!)
  ⑵ 判别式 Δ = b² − 4ac:
     Δ > 0 → 两个不同实交点 → 可用韦达定理
     Δ = 0 → 直线与曲线相切(一个重根/切点) → 单独处理, 韦达仅给x₁=x₂
     Δ < 0 → 无实交点 → 不满足题设
  y₁ + y₂ = k(x₁+x₂) + 2m  (由y=kx+m代入)
  y₁ · y₂ = k²x₁x₂ + km(x₁+x₂) + m²

Box 4 "代" (purple background):
  Title: 第四步·用韦达表达目标量
  Content:
  弦长: |AB| = √(1+k²) · |x₁−x₂| = √(1+k²) · √[(x₁+x₂)²−4x₁x₂]
       = √(1+k²) · √Δ / |a|
  中点: M = ( (x₁+x₂)/2,  (y₁+y₂)/2 )
  面积: S△ = ½|AB|·d   (d = 定点到直线AB的距离)
  向量积: OA⃗·OB⃗ = x₁x₂ + y₁y₂
  斜率积: k_{PA}·k_{PB} = (y₁−yP)(y₂−yP) / [(x₁−xP)(x₂−xP)]

Box 5 "化" (red background):
  Title: 第五步·化简求解
  Content:
  将目标量化简为关于参数(k或m或t)的表达式
  → 求最值: 导数法 或 判别式法
  → 求范围: 联立Δ≥0与其他约束
  → 证定值: 化简后发现结果与参数无关

Section ② "常见题型决策树" (middle, full width, green header):
A decision tree with the root node "题目要求什么?" branching into seven common problem types. Each branch shows the problem type, approach, and key formula.

Branch 1: "求弦长" → 弦长公式 |AB| = √(1+k²)·|x₁−x₂| → 展开用韦达 → 倒推提示: 设y=kx+m即可
Branch 2: "求中点/中点轨迹" → 中点坐标用韦达表示 → 消去参数k或m得轨迹方程 → 倒推提示: 点差法更快(→Section④)
Branch 3: "求面积" → S = ½|AB|·d → 或 S = ½|x₁y₂−x₂y₁| (顶点在原点时) → 倒推提示: 需要同时算弦长和距离
Branch 4: "证过定点" → 将直线方程改写, 分离参数: f(k) ≡ 0 → 对任意k成立 → 各项系数=0, 解出定点 → 倒推提示: 设y=kx+m, 代入后整理出m=g(k), 再回代分离k
Branch 5: "证定值" → 设出表达式, 代入韦达化简 → 发现结果不含参数k/m → 即为定值 → 倒推提示: 一路算别慌, 参数最后会消
Branch 6: "求最值/范围" → 化简为单变量函数g(k) → 导数求极值, 或联立Δ≥0约束k的范围 → 倒推提示: 注意Δ≥0是隐含约束!
Branch 7: "存在性问题" → 假设存在 → 用条件列方程 → 解出参数 → 验证Δ≥0和点在曲线上 → 存在/不存在 → 倒推提示: 设而不求(设存在, 推出矛盾则不存在)

Section ③ "焦点弦问题专题" (bottom-left, medium module, orange header):
Titled "过焦点的弦——特殊性质集"

Sub-block "椭圆焦点弦":
  过焦点F₁的弦AB, A(x₁,y₁), B(x₂,y₂)在椭圆上
  弦长公式(焦半径法): |AB| = |AF₁| + |BF₁| = (a+ex₁) + (a+ex₂) = 2a + e(x₁+x₂)
  → 利用韦达定理代入x₁+x₂, 可化简
  通径(过焦点⊥长轴): |AB| = 2b²/a (最短焦点弦)
  焦半径之积: |AF₁|·|BF₁| = b⁴/(a²sin²α + b²cos²α) (α为弦的倾斜角)

Sub-block "抛物线焦点弦" (highlighted yellow background, key topic):
  过焦点F(p/2, 0)的弦AB, A(x₁,y₁), B(x₂,y₂)在y²=2px上
  |AB| = x₁ + x₂ + p (两焦半径之和)
  设弦倾斜角α: |AB| = 2p/sin²α → 通径α=90°时最短, |AB|_min = 2p
  x₁ · x₂ = p²/4 (将y=k(x−p/2)代入y²=2px, 由韦达得到)
  y₁ · y₂ = −p² (同上推得)
  1/|AF| + 1/|BF| = 2/p (调和性质, 与弦的方向无关!)
  |AF| · |BF| = p²/sin²α (由|AB|=2p/sin²α和1/|AF|+1/|BF|=2/p推得; 通径α=π/2时验证: |AF|=|BF|=p, 乘积=p²=p²/1 ✓)

Sub-block "焦点弦的对称性":
  椭圆: 通径是最短焦点弦, 长轴所在弦是最长焦点弦(=2a)
  抛物线: 通径是最短焦点弦, 无最长(弦长可趋于∞)

Section ④ "中点弦·定点·对称——高级技巧" (bottom-right, medium module, teal header):
Titled "点差法·分离参数·对称变换"

Sub-block "点差法(中点弦问题核心技巧)" (highlighted with blue border):
  设A(x₁,y₁), B(x₂,y₂)都在椭圆x²/a²+y²/b²=1上:
  x₁²/a² + y₁²/b² = 1  ···(i)
  x₂²/a² + y₂²/b² = 1  ···(ii)
  (i)−(ii): (x₁²−x₂²)/a² + (y₁²−y₂²)/b² = 0
  因式分解: (x₁+x₂)(x₁−x₂)/a² + (y₁+y₂)(y₁−y₂)/b² = 0
  设中点M(x₀,y₀), 弦斜率k_AB = (y₁−y₂)/(x₁−x₂):
  → 2x₀/a² + 2y₀ · k_AB/b² = 0
  → k_AB = −b²x₀/(a²y₀)
  ⚠️ y₀=0时分两种情况: ① x₀≠0 → 弦为竖直线 x=x₀; ② x₀=0(中点为原点/中心) → 弦过中心, 方向任意(中心弦), 不能用点差法求斜率, 须从原始联立方程直接处理
  (斜率与中点坐标的直接关系, 无需联立求解!)
  对双曲线同理: k_AB = b²x₀/(a²y₀) (注意符号! 同样须排除y₀=0)

Sub-block "定点问题方法":
  设直线l: y = kx + m (或过定点形式)
  联立曲线方程 → 用韦达定理表达约束条件(如OA⃗·OB⃗=0)
  → 得到k与m的关系: m = f(k)
  → 代回直线方程: y = kx + f(k) = k[x + f(k)/k的化简] + 常数项
  → 分离k: y − 常数 = k(x + 某值) → 对任意k成立 → x = −某值, y = 常数 → 定点!

Sub-block "对称问题":
  点P关于直线y=kx+b的对称点P':
  ① PP'⊥直线: k_{PP'} · k = −1 (⚠️ k=0时PP'为竖直线, 斜率不存在, 须直接用P的x坐标不变、y关于对称轴翻转; P在对称轴上时P'=P)
  ② PP'中点在直线上
  联立两个方程解出P'坐标
  
  曲线关于直线的对称: 求曲线上任意点的对称点的轨迹方程

Sub-block "坐标变换(老教材·解析几何甲种本第三章)":
  平移: x = x' + h, y = y' + k → 消去一次项, 将曲线中心移到原点
  ⚠️ 仅适用于中心曲线(椭圆/双曲线); 抛物线没有中心, 平移只能简化但不能完全消去一次项
  旋转: x = x'cosα − y'sinα, y = x'sinα + y'cosα → 消去交叉项xy
  应用: 一般二次曲线 Ax²+Bxy+Cy²+Dx+Ey+F=0 → 中心曲线可平移消一次项(抛物线须保留轴向一次项) → 旋转消交叉项 → 标准形式
  判别式: B²−4AC < 0 → 椭圆型 | = 0 → 抛物线型 | > 0 → 双曲线型
