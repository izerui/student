## 一、这一层研究什么

- **核心问题**：两个量之间只有两种关系——相等或不等。
  - 相等时：未知数取什么值能让等式成立？→ **方程**
  - 不等时：怎样判断谁大谁小？未知数在什么范围内不等式成立？量能取到的最大、最小值是多少？→ **不等式**
- **为什么需要它**：几乎所有数学问题最后都落到“列一个等式或不等式再求解”。求交点、求零点、求参数范围、求最值、证明结论，都要用到这一层。
- **依赖（下面一层）**：
  - 实数的大小顺序与运算律（A1.3）
  - 式的恒等变形：配方、因式分解（A2）
  - 集合：解写成解集、区间（A3）
  - 逻辑：同解变形就是等价变形（A4）
- **支撑（上面各层）**：
  - 函数：方程的根＝零点；不等式的解集＝图像在 x 轴上方或下方的部分（F4、F5）
  - 导数：证明不等式、求最值（D3）
  - 数列：数列不等式、放缩（S5）
  - 解析几何：联立方程、判别式、韦达定理、弦长（J7）
  - 概率统计：概率的取值范围、期望方差中的最值（P）

## 二、起点：直接承认的东西

| 起点 | 内容 | 说明 |
|---|---|---|
| 实数大小的定义 ★ | a>b ⇔ a−b>0；a=b ⇔ a−b=0；a<b ⇔ a−b<0 | 比较大小归结为判断差的符号 |
| 正负数的运算规则 | 正+正=正；正×正=正；负×负=正；正×负=负 | 一切不等式性质都由它和上一条推出 |
| 等式的基本事实 | 等量加等量、等量乘等量仍相等；不能除以 0 | 【初中衔接】 |
| 平方根、绝对值的定义 | √a（a≥0）表示非负平方根；\|x\| 表示数轴上 x 到原点的距离 | 【初中衔接】 |

## 三、核心概念（要懂什么）

- **恒等式与方程** 〔B版·必修一·Ch2〕【新教材补充】
  - 恒等式：对字母的一切允许值都成立，用来变形，例如 (a+b)²=a²+2ab+b²。
  - 方程：只对部分值成立，任务是求出这些值，全部解组成**解集**。
- **同解变形**：变形前后解集相同。只有同解变形才能保证不多解、不漏解。
  - 两边同乘含未知数的式子、两边平方、去分母，都可能产生增根，必须检验。
  - 两边同除以含未知数的式子，可能失根。
- **不等式的解集**：使不等式成立的全部未知数取值，用集合或区间表示；端点能否取到要单独判断。
- **一元二次方程与判别式**：ax²+bx+c=0（a≠0），Δ=b²−4ac 是配方后才出现的量，它决定根的情况（见六、主线二）。
- **“三个二次”** ★：二次函数 y=ax²+bx+c、一元二次方程 ax²+bx+c=0、一元二次不等式 ax²+bx+c>0，是同一个式子 ax²+bx+c 的三种问法：
  - 函数问“随 x 怎样变”，方程问“何时等于 0”，不等式问“何时大于 0”。
- **最值**：最大（小）值必须**能取到**。只说明 f(x)≥m 还不够，还要找到使 f(x)=m 的 x。
- **恒成立**：对范围内**所有** x 都成立；例如 ax²+bx+c>0 对一切实数 x 成立。

## 四、定理与性质（要知道从哪来）

每条写成：条件 ⇒ 结论｜取等或边界｜由什么推出｜去掉条件的反例。

### 4.1 等式性质 【新教材补充】
- a=b ⇒ a±c=b±c；a=b ⇒ ac=bc；a=b 且 c≠0 ⇒ a/c=b/c。
- 对称性 a=b ⇔ b=a；传递性 a=b，b=c ⇒ a=c。
- 来源：等式的基本事实。

### 4.2 不等式基本性质 ★
| 性质 | 条件 ⇒ 结论 | 可逆吗 | 由什么推出 | 去掉条件的反例 |
|---|---|---|---|---|
| 对称性 | a>b ⇔ b<a | 可逆 | 定义 | — |
| 传递性 | a>b，b>c ⇒ a>c | 不可逆 | a−c=(a−b)+(b−c)，正+正=正 | — |
| 可加性 | a>b ⇔ a+c>b+c | 可逆 | (a+c)−(b+c)=a−b | — |
| 同向可加 | a>b，c>d ⇒ a+c>b+d | 不可逆 | (a−b)+(c−d)>0 | 同向不能相减：3>2，2>0，但 3−2=1<2−0=2；反过来 a+c>b+d 推不出 a>b 且 c>d：3+0>1+1，但 0<1 |
| 可乘性 | a>b，c>0 ⇒ ac>bc；a>b，c<0 ⇒ ac<bc | 不可逆 | ac−bc=(a−b)c，看 c 的符号 | c=0 时 ac=bc，所以乘之前必须先确定符号 |
| 同向正数可乘 【新教材补充】 | a>b>0，c>d>0 ⇒ ac>bd | 不可逆 | ac−bd=a(c−d)+d(a−b)>0 | 去掉“>0”：2>−1，−3>−4，但 2·(−3)<(−1)·(−4) |
| 乘方 | a>b>0 ⇒ aⁿ>bⁿ（n∈N，n≥2） | 不可逆 | 同向正数可乘反复使用 | −1>−2，但 (−1)²<(−2)² |
| 开方 | a>b>0 ⇒ ⁿ√a>ⁿ√b（n∈N，n≥2） | 不可逆 | 反证：若 ⁿ√a≤ⁿ√b，乘方得 a≤b，矛盾 | — |
| 倒数 【新教材补充】 | a>b，ab>0 ⇒ 1/a<1/b | 不可逆 | 1/a−1/b=(b−a)/(ab)<0 | 1>−1，但 1/1>1/(−1) |

- 乘方的推广：a>b>0，n 为任意正实数时也有 aⁿ>bⁿ，因为幂函数 y=xⁿ 在 (0,+∞) 上递增（→ F3）。

### 4.3 平方非负 ★（全层的枢纽）
- 对任意实数 x：x²≥0，当且仅当 x=0 时取等。
- 来源：x>0 时正×正>0；x<0 时负×负>0；x=0 时为 0。

### 4.4 一元二次方程的根 ★
- **判别式定理**：ax²+bx+c=0（a≠0）
  - Δ>0：两个不等实根 x₁,₂=(−b±√Δ)/(2a)
  - Δ=0：两个相等实根 x=−b/(2a)
  - Δ<0：没有实数根；在复数范围内有一对共轭虚根（→ V3）
  - 来源：配方，见六、主线二。
- **韦达定理（根与系数的关系）**：x₁+x₂=−b/a，x₁x₂=c/a。
  - 条件：在实数范围内使用时要求 Δ≥0。
  - 来源：a(x−x₁)(x−x₂) 展开后与 ax²+bx+c 比较系数。
- **根的符号**（由韦达定理推出）：
  - 两正根 ⇔ Δ≥0，x₁+x₂>0，x₁x₂>0
  - 两负根 ⇔ Δ≥0，x₁+x₂<0，x₁x₂>0
  - 一正一负 ⇔ x₁x₂=c/a<0（此时 Δ>0 自动成立）

### 4.5 一元二次不等式的解集 ★（以 a>0 为例）
| | Δ>0 | Δ=0 | Δ<0 |
|---|---|---|---|
| y=ax²+bx+c 的图像 | 与 x 轴交于两点 x₁<x₂ | 与 x 轴相切于 x₀=−b/(2a) | 全在 x 轴上方 |
| ax²+bx+c=0 的根 | x₁、x₂ | x₀（重根） | 无实根 |
| ax²+bx+c>0 的解集 | {x \| x<x₁ 或 x>x₂} | {x \| x≠x₀} | R |
| ax²+bx+c<0 的解集 | {x \| x₁<x<x₂} | ∅ | ∅ |
- 来源：因式分解后用“积的符号”判断，Δ<0 时用平方非负，见六、主线二。表格是推导结果，不需要死记。
- a<0 时：两边同乘 −1 化为 a>0 的情形（不等号方向随之改变）。

### 4.6 恒成立条件
- ax²+bx+c>0 对一切 x∈R 成立 ⇔ a=b=0 且 c>0；或 a>0 且 Δ<0。
- 来源：a≠0 时由 4.5 表中 Δ<0 一列得出；a=0 时退化为一次式或常数。
- 【易错】不能漏掉 a=0 的情况。

### 4.7 根的分布（结论，以 f(x)=ax²+bx+c，a≠0，对称轴 h=−b/(2a) 为例）
| 根的情况 | 充要条件 |
|---|---|
| 一根大于 k，一根小于 k | a·f(k)<0 |
| 两根都大于 k（可以相等） | Δ≥0，h>k，a·f(k)>0 |
| 两根都小于 k | Δ≥0，h<k，a·f(k)>0 |
| 两根都在 (m,n) 内 | Δ≥0，m<h<n，a·f(m)>0，a·f(n)>0 |
| (m,n) 内恰有一根（端点不是根） | f(m)·f(n)<0 |
| (m,n) 内恰有一个重根 | Δ=0，m<h<n |
| m 是根，另一根在 (m,n) 内 | f(m)=0，m<h<(m+n)/2 |
| n 是根，另一根在 (m,n) 内 | f(n)=0，(m+n)/2<h<n |
- 来源：画抛物线，从开口、Δ、对称轴、端点函数值四个角度列条件。用 a·f(端点) 的写法可以免去对 a 的正负讨论。后两行的依据是：另一根＝2h−已知根。
- 【易错】“两根都在 (m,n) 内”不能用 f(m)f(n)>0 代替。反例：f(x)=x²−4，区间 (−1,1)：Δ>0，h=0∈(−1,1)，f(−1)f(1)=9>0，但两根 ±2 都不在区间内。

### 4.8 基本不等式（均值不等式）★
- a,b>0 ⇒ (a+b)/2 ≥ √(ab)，当且仅当 a=b 时取等。
  - 人教B版正文称“均值不等式”，条件是 a,b 都是正数；旁注说明称“基本不等式”时 a,b 还可以为零（取等仍当且仅当 a=b）。
- 来源：由平方非负推出，见六、主线一。
- 几何解释：半圆中，半径 (a+b)/2 不小于半弦 √(ab)（半弦²＝两段乘积，射影定理 → G0）。
- **两个正数的平均数链**（a,b>0）：2/(1/a+1/b) ≤ √(ab) ≤ (a+b)/2 ≤ √((a²+b²)/2)，当且仅当 a=b 时各处取等。依次叫调和平均、几何平均、算术平均、平方平均。

### 4.9 最值定理 ★
- x、y>0，xy=P（定值）⇒ x+y ≥ 2√P，当且仅当 x=y=√P 时取等（**积定和最小**）。
- x、y>0，x+y=S（定值）⇒ xy ≤ S²/4，当且仅当 x=y=S/2 时取等（**和定积最大**）。
- 条件“一正、二定、三相等”缺一不可：各项为正；和或积是定值；等号能取到。

### 4.10 含绝对值的基本不等式 〔B版·必修一·Ch2〕
- 设 a>0：|x|<a ⇔ −a<x<a；|x|>a ⇔ x<−a 或 x>a；|x−m|<a ⇔ m−a<x<m+a。
- 来源：绝对值的几何意义——数轴上到 m 的距离小于 a 的点。

## 六、逻辑主线（要懂的推导链）★

> 读法：每个箭头是一次推导，箭头上的【】是所用方法。能独立走完这三条链，就掌握了这一层的逻辑。

### 主线一：从“大小的定义”到“最值”
```
起点：a>b ⇔ a−b>0　＋　正负数运算规则
  │【作差】例：ac−bc=(a−b)c，按 c 的符号判断
  ▼
不等式基本性质（4.2）：对称、传递、可加、可乘、乘方、开方、倒数
  │【分情况】x>0、x<0、x=0 分别用“正×正”“负×负”
  ▼
平方非负：x²≥0（4.3）
  │【代入】令 x=a−b，【展开】
  ▼
a²+b² ≥ 2ab（一切实数，a=b 时取等）
  │【代换】a→√a，b→√b（要求 a,b>0），两边除以 2
  ▼
均值不等式：(a+b)/2 ≥ √(ab)（4.8）
  │【取定值】积为定值 P 或和为定值 S
  ▼
最值定理：积定和最小、和定积最大（4.9）　──条件：一正、二定、三相等
```

### 主线二：从“配方”到“三个二次”
```
ax²+bx+c（a≠0）
  │【配方】提出 a，补常数
  ▼
ax²+bx+c = a[(x+b/(2a))² − Δ/(4a²)]，Δ=b²−4ac
  │【开平方】(x+b/(2a))² = Δ/(4a²) 有实数解 ⇔ 右边 ≥ 0 ⇔ Δ≥0（平方非负）
  ▼
判别式定理与求根公式（4.4）
  │【因式分解】Δ≥0 时 ax²+bx+c = a(x−x₁)(x−x₂)，【比较系数】
  ▼
韦达定理（4.4）
  │【积的符号】a>0，Δ>0：a(x−x₁)(x−x₂)>0 ⇔ 两因子同号 ⇔ x<x₁ 或 x>x₂
  │【平方非负】Δ=0：a(x−x₀)²>0 ⇔ x≠x₀；Δ<0：方括号内恒正，解集为 R
  ▼
一元二次不等式的解集表（4.5）
  │【数形结合】把上面的代数结论画成抛物线：开口、与 x 轴交点、在 x 轴上方的部分
  ▼
恒成立条件（4.6）、根的分布（4.7）
```

### 主线三：从“等式性质”到“解方程”
```
等式的基本事实
  │【推出】
  ▼
等式性质（4.1）
  │【同解变形】每一步不改变解集；可能产生增根的步骤（乘含未知数的式子、平方、去分母）后必须检验
```

## 七、方法（要会用）

| 方法 | 做法 | 什么时候用 |
|---|---|---|
| 作差法 ★ | 作差 → 变形（因式分解、配方成平方和、凑成恒正或恒负的式子）→ 判号 → 结论 | 比较大小、证明不等式的首选 |
| 作商法 | B>0 时 A/B>1 ⇔ A>B；B<0 时 A/B>1 ⇔ A<B | 两边是乘积、幂、指数式，且同号 |
| 平方作差法 | A、B≥0 时，A>B ⇔ A²>B² | 含根式、绝对值 |
| 配方法 | 提出系数，补常数 | 二次式判号、求最值、推求根公式 |
| 因式分解 | 化成积，用积的符号判断 | 解高次、二次不等式 |
| 同解变形 | 化为等价的、更简单的形式：分式化整式，高次化低次，无理化有理，去绝对值 | 解一切方程、不等式 |
| 分类讨论 | 含参二次不等式分三层：二次项系数是否为 0 → 开口方向 → Δ 的符号与两根大小 | 含参数问题 |
| 数形结合 | 画抛物线读解集；画数轴读绝对值不等式 | 三个二次、根的分布、绝对值 |
| 配凑定值 | 拆项、添项、配系数，使和或积为定值 | 用均值不等式求最值 |
| “1”的代换 | 已知 a+b=1，求 1/a+1/b 的最小值：乘以 (a+b) 后展开 | 条件最值 |
| 同除法 | 分式“谁简单，同除以谁”：x/(x²+1)（x>0）同除以 x 得 1/(x+1/x) | 分式最值 |
| 改用单调性 | 等号取不到时，用函数单调性求最值（→ F2、D3） | 均值不等式“三相等”失败 |
| 建模 | 审题（必要时画示意图）→ 找出常量与变量间的不等关系，在文字、图形、符号间转换 → 求解 → 回到实际意义检验 | 应用题 |

- 解一元二次不等式的步骤：化为二次项系数为正 → 计算 Δ → 求根 → 画草图 → 写解集。
- 等号取不到时改用单调性的例子：
  - x∈[2,+∞) 时求 x+1/x 的最小值：等号要求 x=1，不在范围内；函数在 [1,+∞) 上递增，所以最小值为 f(2)=5/2。
  - sin x + a/sin x（0<sin x≤1，a>1）不能用均值不等式，要用单调性（→ T6）。
- 均值不等式的其他用途：证明不等式（合理配组、反复使用、“1”的妙用）、比较实数大小；与函数、数列、三角、解析几何综合时，先列出目标量的函数关系或方程。

## 八、易错与边界

- 【易错】不等式性质的可逆性：只有对称性、可加性是 ⇔，其余都只是 ⇒。
- 【易错】乘除之前不判断符号就直接变形；c 可能为 0 时“两边同乘 c”也不保持严格不等号。
- 【易错】同解变形中出现增根、失根；端点取舍错误。
- 【易错】含参数时分类标准不清，导致遗漏或重复；恒成立漏掉二次项系数为 0。
- 【易错】x+1/x≥2 必须 x>0：x<0 时 x+1/x≤−2，没有最小值。
- 【易错】忽视“一正、二定、三相等”中的任意一条；连续两次使用均值不等式时，两次的取等条件不一致。
- 【易错】韦达定理在实数范围内使用要先保证 Δ≥0。
- 【易错】根的分布中“两根都在 (m,n) 内”不能用 f(m)f(n)>0 代替（反例见 4.7）。

## 十、学会的标准（合上书能做到）

1. 从 a>b ⇔ a−b>0 出发，推出可乘性，并说清楚为什么乘负数要变号、乘 0 时不再是严格不等式。
2. 从平方非负一路推到均值不等式，说出每一步用了什么、哪一步开始需要 a,b>0。
3. 用配方推出判别式定理和求根公式，不靠背表格。
4. 不看表格，写出 a<0、Δ=0 时 ax²+bx+c≥0 的解集，并说明理由（答：只有 x=−b/(2a) 一个解）。
5. 已知 ax²+bx+c>0 的解集为 (1,3)，反推 a、b、c 应满足的关系（答：a<0，b=−4a，c=3a）。
6. 用均值不等式求最值前，逐条检查“一正、二定、三相等”；等号取不到时，能改用单调性。
7. 对 4.2 表中每条带条件的性质，举出去掉条件后不成立的反例。
8. 判断含参二次不等式时，能按“二次项系数是否为 0 → 开口方向 → Δ 与两根大小”三层分类，不重不漏。

## 拓展（旧教材内容，新课标已删除或不作要求）【旧教材·拓展】

### 拓展 1：一元高次不等式——穿根法（序轴标根法）
- 化正：移项使右边为 0，左边最高次项系数为正。
- 分解：a(x−x₁)^{k₁}(x−x₂)^{k₂}…(x−xₙ)^{kₙ}，其中 x₁>x₂>…>xₙ，kᵢ 是 xᵢ 的重数。
- 标根、穿根：从数轴最右端上方开始画曲线，依次过各根。奇重根穿过数轴，偶重根不穿过（碰到数轴后弹回）。口诀：奇穿偶回。
- 写解集：曲线在数轴上方的区间是“>0”的解集；端点按是否取等决定开闭，偶重根处要单独判断。
- 前提：“从右上开始”必须先把最高次项系数化为正。

### 拓展 2：分式不等式
| 类型 | 同解形式 |
|---|---|
| f(x)/g(x)>0 | f(x)g(x)>0 |
| f(x)/g(x)<0 | f(x)g(x)<0 |
| f(x)/g(x)≥0（≤0） | f(x)g(x)≥0（≤0）且 g(x)≠0 |
| f(x)/g(x)>a（a≠0） | 移项通分：[f(x)−a·g(x)]/g(x)>0，再按上面的方法解 |
- 也可以写成符号组合：f/g>0 ⇔ {f>0 且 g>0} 或 {f<0 且 g<0}。
- 【易错】分母不能直接乘过去，因为符号未知；带等号时漏掉 g(x)≠0。

### 拓展 3：n 个正数的平均数链
- aᵢ>0 时：n/(1/a₁+…+1/aₙ) ≤ ⁿ√(a₁a₂…aₙ) ≤ (a₁+…+aₙ)/n ≤ √((a₁²+…+aₙ²)/n)，当且仅当 a₁=a₂=…=aₙ 时取等。

### 拓展 4：二元一次不等式（组）与简单的线性规划
- 概念：
  - 二元一次不等式 Ax+By+C>0 表示直线 Ax+By+C=0 某一侧所有点组成的平面区域；不含边界画成虚线，带等号含边界画成实线。
  - 约束条件：关于 x、y 的不等式组，都是一次不等式时叫线性约束条件。目标函数 z=f(x,y)，是一次式时叫线性目标函数。
  - 可行解：满足约束条件的 (x,y)；可行域：全部可行解组成的集合；最优解：使目标函数取得最大值或最小值的可行解。
  - 线性规划问题：在线性约束条件下，求线性目标函数的最大值或最小值。
- 画平面区域：画线（带等号用实线，否则用虚线）→ 定侧（代入不在直线上的点，原点常用；或看 B 的符号：B>0 时 Ax+By+C>0 表示直线上方）→ 求交。
- 图解法求最优解：设变量 → 列约束条件 → 写目标函数 → 作可行域 → 平移直线 l₀：ax+by=0，找到最优解对应的点 → 解方程组求最优解和最值。
  - 三种判断：平移目标函数对应的直线；比较可行域各顶点的函数值（“顶点代入”）；比较目标直线与边界直线的斜率。
  - 平移时最先或最后经过的是可行域的顶点或边界上的点。
  - 【易错】z=ax+by 可写成 y=−(a/b)x+z/b：b>0 时纵截距越大 z 越大；b<0 时恰好相反。不能一律认为“直线最后经过的点处 z 最大”。
- 整点最优解：
  - 平移找解法：打网格、描整点，平移目标直线，最先或最后经过的整点就是最优整数解；可行域有限且整点很少时可逐个代入比较。
  - 调整优值法：先求非整点最优解和最优值，再借助不定方程调整，筛选出整点最优解。
- 含参问题：目标函数含参时，参数常与斜率有关，最优解往往已知，用斜率比较转化；约束条件含参时，可行域随参数变动，含参边界直线常过定点，看它绕定点旋转的情形（“过定点，旋转”）。
- 应用与建模：两类典型问题——资源一定，收益最大；任务一定，成本最小。建模三步：用符号表示待定未知量 → 用线性不等式表示全部限制条件 → 用线性函数表示目标。
- 易错：最优点不明显时，把几个候选顶点都算出来比较；数形结合用错方向（b<0 的情形）；最优整数解求错。

### 拓展 5：不等式证明方法
- 比较法：作差（欲证 A>B，只需证 A−B>0）；作商（欲证 A>B（B>0），只需证 A/B>1）；平方作差（两边都非负时比较平方）。变形的目标是能判断符号的形式（积或平方和），判号过程要写清楚。
- 综合法、分析法、反证法（方法本体见 A5.4、A5.5）：综合法由因导果，分析法执果索因（用“要证……只需证……”的格式），两者可以互相转换、联合使用；含“至少”“唯一”或否定词的命题宜用反证法。
- 放缩法：最重要的变形方法之一，要有的放矢，目标从要证的结论中找（见拓展 8）。
- 判别式法：适用于含两个以上字母、一边化为 0、另一边可以看成某个字母的二次式；依据是二次式恒非负 ⇔ 二次项系数>0 且 Δ≤0（系数为 0 时另行讨论）。作差后是关于某个变量的二次式时，可以考虑判别式。
- 导数法（接口 D3）：欲证 x∈(a,b) 时 f(x)>g(x)，令 h=f−g。
  - 若 h′>0，h 在 [a,b) 上递增（h 在 a 处连续），只需 h(a)≥0。
  - 若 h′<0，h 在 (a,b] 上递减（h 在 b 处连续），只需 h(b)≥0。
  - 端点处只需 ≥0：在开区间上严格单调已保证严格不等式。
- 其他：数学归纳法（A5.6、S6）、换元法、函数单调性法、数形结合法（斜率法、向量法）。

### 拓展 6：绝对值不等式
- 定义：|x|=x（x≥0）；|x|=−x（x<0）。几何意义：|x| 是数轴上 x 到原点的距离，|x−a| 是 x 到 a 的距离。
- 三角不等式：||a|−|b|| ≤ |a±b| ≤ |a|+|b|。
  - |a+b|≤|a|+|b|：以 |a+b|、|a|、|b| 为三边，两边之和不小于第三边；当且仅当 ab≥0 时取等。
  - |a−b| ≤ |a−c|+|c−b|：数轴上 a、b 的距离不超过它们各自到 c 的距离之和；当且仅当 c 在 a、b 之间（含端点）时取等。
  - 推广：|a₁+a₂+…+aₙ| ≤ |a₁|+|a₂|+…+|aₙ|。
- 运算性质：|ab|=|a||b|；|a/b|=|a|/|b|（b≠0）。
- 解法：
  - 公式法（m>0）：|x−a|≤m ⇔ a−m≤x≤a+m；|x−a|≥m ⇔ x≥a+m 或 x≤a−m；|ax+b|≤c、|ax+b|≥c 同理。
  - 定义法（零点分段法）：两个以上绝对值相加减时，用零点把数轴分段，分段去掉绝对值；“先交后并”——每段内与分段范围取交集，再把各段结果取并集。
  - 平方法：两边都非负时同时平方。
  - 几何法：|x−a|+|x−b| 的最小值为 |a−b|，在 a、b 之间（含端点）取到。
- 含参数的绝对值不等式要对参数分类。

### 拓展 7：柯西不等式、排序不等式、贝努利不等式
- 柯西不等式：
  - 二维代数形式：(a₁b₁+a₂b₂)² ≤ (a₁²+a₂²)(b₁²+b₂²)，当且仅当 a₁b₂=a₂b₁ 时取等。
  - 向量形式：|α·β| ≤ |α||β|，当且仅当 α、β 共线（β=0 或存在实数 k 使 α=kβ）时取等（→ V2）。【易错】取等条件是共线，不是 α=β。
  - 一般形式：(Σaᵢbᵢ)² ≤ (Σaᵢ²)(Σbᵢ²)，当且仅当 bᵢ=0（对一切 i）或存在 k 使 aᵢ=kbᵢ 时取等。
  - 证明思路：构造关于 t 的二次函数 Σ(aᵢt−bᵢ)²≥0，由 Δ≤0 得证（参数配方法 / 判别式法）。
- 排序不等式：设 a₁≤a₂≤…≤aₙ，b₁≤b₂≤…≤bₙ，c₁,…,cₙ 是 b₁,…,bₙ 的任意排列，则 a₁bₙ+a₂bₙ₋₁+…+aₙb₁ ≤ a₁c₁+…+aₙcₙ ≤ a₁b₁+…+aₙbₙ，即反序和 ≤ 乱序和 ≤ 顺序和；反序和＝顺序和当且仅当 a₁=…=aₙ 或 b₁=…=bₙ。证明可用逐次调整法。
- 贝努利不等式：x>−1，x≠0，n≥2，n∈N 时，(1+x)ⁿ>1+nx，用数学归纳法证明。【易错】严格不等号要求 n≥2：n=1 时两边相等；若写成 ≥，n≥1 也成立。

### 拓展 8：放缩技巧（数列放缩见 S5）
- 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k（k≥2）。
- 1/√k < 2/(√k+√(k−1)) = 2(√k−√(k−1))（k≥1）。
- 1+1/2!+1/3!+…+1/n! ≤ 1+1/2+1/2²+…+1/2ⁿ⁻¹：依据是 k!≥2^(k−1)（k≥3 时严格），所以 n≥3 时为严格不等号，n=1、2 时两边相等。
- 1/(n+1)+1/(n+2)+…+1/(2n) ≤ n/(n+1)：每项不超过 1/(n+1)；n=1 时取等，n≥2 时严格。
- 1/(n+1)+…+1/(2n) ≥ 1/2：每项不小于 1/(2n)；n=1 时取等，n≥2 时严格。
- 1+1/√2+…+1/√n ≥ √n：每项不小于 1/√n；n=1 时取等，n≥2 时严格。
- 【易错】放缩式都带有 k≥2、n≥2、n≥3 等条件，使用时不能省。

### 拓展 9：换元技巧
- 三角换元：x²+y²=1 → x=cosθ，y=sinθ；a≤x²+y²≤b → x=rcosθ，y=rsinθ，a≤r²≤b。
- 均值（增量）换元：a+b=1 → a=1/2+t，b=1/2−t。
- 注意：换元前后变量范围要等价。
- 另有构造技巧：构造函数、向量、几何图形。
