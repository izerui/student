# 数学大厦

从地基一路推到大学的数学全景图：每个知识从哪来、怎么推出来、后来发展到哪、用在哪。后续编辑、修改、生成都在本目录内进行。

## 目录

| 路径 | 内容 |
|---|---|
| `数学大厦-设计.md` | 设计文档：目标、楼层 × 学科柱、节点四项、关系类型、成品（全景网页） |
| `数学大厦-节点清单.md` | **唯一的数据源**，网页上的一切都从这里来。开头是页面设置（标题、区域表）和 5 条主干链；中间按楼层写分组（`###`，77 个，0–8 共 9 层，第 8 层是屋顶）和分组里的知识点（`####`，网页上的卡片，带分组名前缀）；末尾是思想方法。写法见清单里的“怎么读”和项目 skill `knowledge-map-web`。正在从地基往上逐层拆成知识点 |
| `outputs/数学大厦.html` | **成品**：全景网页，单个文件，双击打开。由节点清单生成，不要手改 |
| `数学知识大厦脑图/` | 素材库：12 份按模块整理的知识点脑图，写节点时取材 |
| `工具/checklist.py` | 读取节点清单（分组、知识点、依赖），给检查工具用 |
| `工具/check.py` | 数学大厦自己的规则：字段齐全、依赖方向、无环、主干链依据、思想方法引用、每条依赖都写了“怎么推的” |
| `工具/coverage.py` | 逐节核对人教 B 版必修 4 册＋选择性必修 3 册是否都写到了（每节落在哪个知识、要出现哪些词） |

## 工作流程

1. 只改 `数学大厦-节点清单.md`：分组、知识点、依赖、主干链、讲解、短名和标志公式都在里面。拆一个分组时：在它下面加 `####` 知识点，把分组的“依赖”删掉（拆过的分组没有依赖）；上层引用这个分组的地方改写到具体知识点编号；`工具/check.py` 会指出漏改的地方。
2. 检查（在本目录下运行）：

```bash
python3 工具/check.py          # 数学大厦自己的规则
python3 工具/coverage.py       # 教材每一节是否都写到了
```

3. 生成网页（在仓库根目录运行，只要装了 Node.js，不用安装别的）：

```bash
K=.claude/skills/knowledge-map-web/tools
node $K/build.mjs 数学/数学大厦/数学大厦-节点清单.md 数学/数学大厦/outputs/数学大厦.html   # 生成，双击打开
node $K/serve.mjs 数学/数学大厦/数学大厦-节点清单.md 数学/数学大厦/outputs/数学大厦.html   # 边改边看：保存清单，浏览器自动刷新
```

网页的样式和交互在 skill 的 `template.html` 里改，改完按 skill 的要求回归测试，再重新生成。

全景网页的用法：首页是整栋大楼，F0 地基到 F8 屋顶，一层一条，层内的知识按“同区域靠拢、有推导关系的上下对齐”自动摆放；开场时各层从地面依次升起；同一分组的知识点排在一起、外面套一个框。滚轮平滑放大缩小。鼠标停在一个知识上，画出它直接来自哪些（琥珀色）、直接推出哪些（青色），线上有光点沿推导方向流动。点开一个知识，只留下它的家谱，仍按楼层摆好：下面是它站在上面的知识，上面是站在它上面的知识，没有相关知识的楼层自动收窄；鼠标停在家谱里的某个知识上，描出它和中间这个知识之间的所有路，并提示“这一步怎么推的”。卡片可以拖动，松手会弹回，相连的知识会被一起拽动。选中后用方向键在家谱里走：↓ 往来源、↑ 往后续、←→ 同层换。第二行的主干可以“播放”，一步步从地基走上去，每步说明怎么推出来；思想方法悬停看哪些知识用到。按 `/` 或 ⌘K 打开搜索，`Esc` 回全景；右侧说明栏讲“是什么、从哪来、后来发展到、用在哪、例子”。可点“我学过这个”，进度保存在浏览器里，“现在可以学”标出前置都学过的知识。

## 依赖

- Python 3：检查清单、核对教材覆盖
- Node.js：生成网页（skill 里的 `tools/`，没有依赖）
- 自查网页时可用 Node.js 与 puppeteer 截图（`~/.npm/_npx` 下 mermaid-cli 自带）
