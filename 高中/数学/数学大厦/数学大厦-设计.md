# 数学大厦 · 设计

## 一、要做什么

一套让高中生看懂“自己学的数学从哪来、怎么一步步推上去、将来发展到哪、用在什么地方”的图。从最底层的地基（逻辑、集合、计数、几何公理）出发，经过初中、高中，一直延伸到大学的微积分、线性代数、概率论。

- **受众**：高中生（向下衔接初中，向上展望大学）。
- **读完应该能**：说出一个知识是从前面哪个知识推出来的、用了什么方法；知道它后面会用在哪些知识上、现实中解决什么问题。
- **不是**：考点汇编、公式清单。速查和解题是应用，不是目的。

## 二、整体结构：楼层 × 学科柱

- **楼层（从下往上 9 层）**：0 地基 → 1 数系与度量 → 2 关系（等式与不等式）→ 3 新对象（函数、向量、数列、随机事件、曲线）→ 4 具体的函数、图形与数列 → 5 随机 → 6 变化与累积（极限、导数、积分）→ 7 大学 → 8 屋顶：数学建模与探究（把各柱的模型用回现实）。下层是上层的基础。
- **思想方法**：数形结合、函数与方程、分类讨论、转化与化归、特殊与一般、有限与无限、或然与必然、公理化与演绎。不画成节点，在总图上做成面板，标出它在哪些节点起作用。
- **几何统一在一根柱子里**：平面几何、立体几何、解析几何、向量不分开，都在几何柱中，由几何公理、坐标法、向量连成一体。
- **学科柱（从左到右 5 根）**：地基、代数、函数、几何、随机；屋顶（建模）横跨全楼。每根柱子从地基往上长；跨柱子的依赖就是学科之间的“桥”。
- **主干链（5 条）**：等式与方程、不等式、变化与累积、随机、形状。每条链从地基一路推到大学，链上每一步都在节点清单里有依据（由 `工具/check.py` 检查）。

## 三、节点：分组与知识点

节点清单两级：**分组**（`###`，一类知识，如“导数的应用”）讲整体；**知识点**（`####`，如“导数与单调性”“极值”）是网页上的卡片，粒度按教材小节，名字前显示所属分组名作前缀。只有一个知识点的分组不拆，分组本身就是卡片。知识点写“标志”（卡片第二行的标志公式或定理）、“是什么”、“从哪来”（编号后的括号写这一步怎么推的），可选“要点”“例子”。从地基往上逐层拆，每层先列清单经确认再写入。

### 分组的写法（原“一个节点＝一个具体的知识”）

节点清单中每个节点写四项：

| 项 | 写什么 |
|---|---|
| 是什么 | 一两句大白话，最好带例子 |
| 从哪来 | 依赖哪些节点、用什么方法推出（写编号和关系类型） |
| 解决什么 | 学了它能干什么 |
| 例子 | 最简单的一个 |
| 往上通向（可选） | 后面哪一层会把它严格化、推广或解释（不是依赖） |
| 要点（可选） | 这个知识包含的公式、条文，用“；”分条；只列出来，不展开推导（推导细节放在恒等式、不等式、二次函数等小大厦） |

学段标在节点标题后：〔小学〕〔初中〕〔高中〕〔大学〕，〔高中·拓展〕表示旧教材有、新课标已删。

## 四、关系（箭头）

| 关系 | 含义 | 画法 |
|---|---|---|
| 推出 | 由前面的结论推出 | 深色实线 |
| 用到 | 定义或研究时用到前面的概念 | 灰色细线 |
| 推广 / 特例 | 推广前面的东西，或是它的特殊情形 | 蓝色虚线 |
| 对照 | 同一对象的两种看法，或一一对应 | 橙色点线，双向 |
| 往上通向 | 后面的层把它严格化、推广或解释 | 浅灰点线 |

规则：依赖只能指向更低层、或同层里编号更小的节点；向上的说明一律写进“往上通向”。

## 五、成品：全景网页

数学大厦以**交互网页**为成品，不再出 drawio。成品是本目录 `outputs/` 下的单文件网页 `数学大厦.html`（数据嵌在里面，双击打开），由项目 skill `knowledge-map-web` 从节点清单生成；更新知识只改清单，再生成一次。

- 生成：节点清单是唯一的数据源（短名、标志公式、讲解、每一步“怎么推的”都写在里面），用 skill 的 `tools/build.mjs` 生成 `outputs/数学大厦.html`（`tools/serve.mjs` 开着时保存即自动生成）；md 格式以项目 skill `.claude/skills/knowledge-map-web` 的 `SKILL.md` 为准，页面功能在 skill 的 `template.html` 里改。
- 分工：数学大厦管“全”——覆盖高中全部知识（`工具/coverage.py` 逐节核对教材），每个知识写清从哪来、推出什么、标志公式和要点；每个公式怎么一步步推出来，放在恒等式、不等式、二次函数等小大厦。
- 早期的 drawio 版已删除（需要时可从 git 历史找回）。
