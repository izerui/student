Section ② "辅助角公式详解" (middle-left, medium module, green header):
Core formula in a highlighted box:
  asinx + bcosx = √(a² + b²) · sin(x + φ)  (R=√(a²+b²)>0)
  统一确定φ: cosφ = a/R, sinφ = b/R (由此唯一确定φ的象限)
  ⚠️ 不要只用 tanφ=b/a — 当 a=0 时 tanφ 无意义! 此时 φ=π/2(b>0) 或 φ=-π/2(b<0). a=b=0 时原式恒=0.

Derivation sketch: asinx + bcosx = √(a²+b²)[a/√(a²+b²)·sinx + b/√(a²+b²)·cosx] → let cosφ = a/√(a²+b²), sinφ = b/√(a²+b²) → = √(a²+b²)sin(x+φ)

Worked example:
  y = sinx + √3·cosx → a=1, b=√3 → √(1+3)=2, tanφ=√3/1=√3 → φ=π/3
  ∴ y = 2sin(x + π/3)
  最大值 = 2 (当 x + π/3 = π/2, 即 x = π/6 时取到)
  最小正周期 T = 2π

⚠️ 常见变形: asinx + bcosx 中 a, b 可能为负 → φ 可能在其他象限，统一用 cosφ=a/R, sinφ=b/R (R=√(a²+b²)) 确定 φ 的象限

Section ③ "正弦定理与余弦定理" (middle-right, large module, teal header):
A triangle diagram at the top: triangle ABC with sides a (opposite A), b (opposite B), c (opposite C), circumscribed circle with radius R drawn.

正弦定理 (Sine Rule) in a blue box:
  a/sinA = b/sinB = c/sinC = 2R
  变形: a = 2R·sinA → 边角互化 (将边的关系转化为角的关系或反之)
  适用条件: ① AAS/ASA (两角一边) ② SSA (两边和对角 → ⚠️可能两解!)

余弦定理 (Cosine Rule) in a green box:
  a² = b² + c² − 2bc·cosA
  b² = a² + c² − 2ac·cosB
  c² = a² + b² − 2ab·cosC
  变形: cosA = (b² + c² − a²) / (2bc) → 由三边求角 / 判断角的类型
  适用条件: ① SSS (三边) ② SAS (两边夹角)
  本质: 勾股定理的推广 — 当 A=90° 时 cosA=0, 退化为 a²=b²+c²

面积公式 in an orange box:
  S = ½bc·sinA = ½ac·sinB = ½ab·sinC
  (三角形面积 = 两边之积乘夹角正弦的一半)

⚠️ SSA 两解判定 (warning callout with red border):
  已知 a, b, A (A为已知角对边为a):
  ① 正弦定理求 sinB = b·sinA/a
  ② 若 sinB > 1 → 无解
  ③ 若 sinB = 1 → B = π/2 → 仍须检验 A + B < π:
     A + π/2 < π 即 A < π/2 → 成立则唯一解; A ≥ π/2 → 无解!
     反例: A=120°, a=√3, b=2 → sinB=1, B=90°, 但A+B=210°>180°, 无解
  ④ 若 sinB < 1 → B₁ = arcsin(b·sinA/a), B₂ = π − B₁
     对每个候选B值检验: B + A < π → 满足则该解成立
     两个都满足 → 两解; 一个满足 → 一解; 都不满足 → 无解

Section ④ "解三角形审题导航" (bottom-left, medium-large module, purple header):
A comprehensive navigation flowchart — the student's FIRST action guide when facing a triangle problem.

TOP of this section — "审题第一步" header in bold with a magnifying glass icon:
拿到解三角形题 → 第一步: 数已知条件(几个边? 几个角?)
  Branch 1: "已知两角一边 (AAS/ASA)"
    → 第三角 = π − (已知两角之和)
    → 正弦定理求未知边
    → ✓ 唯一解
  Branch 2: "已知两边一夹角 (SAS)"
    → 余弦定理求第三边
    → 再用正弦定理(或余弦定理)求角
    → ✓ 唯一解
  Branch 3: "已知三边 (SSS)"
    → 余弦定理求最大角(对最长边的角! 先求最大角以判锐/钝)
    → 其余角用正弦定理
    → ✓ 唯一解
  Branch 4: "已知两边和对角 (SSA)" → ⚠️ 红色高亮: "可能两解!"
    → 正弦定理求 sinB = b·sinA/a
    → sinB > 1 → 无解
    → sinB = 1 → B=π/2 → ⚠️仍须检验 A+π/2<π (即A<π/2), 否则无解!
    → sinB < 1 → B₁=arcsin值, B₂=π−B₁ → 逐一检验每个B值是否满足 A+B<π → 可能两解/一解/无解
  Branch 5: "条件不直接属于上述四类"
    → 先挖掘隐含条件:
      a²=b²+c² → 直角三角形!
      面积已知 → S=½absinC → 求出sinC
      边的比例已知 → 正弦定理化为角的关系
    → 化归为上述四类再解

Below the decision tree, a WARNING BOX with red border "⚠️ 解三角形四大陷阱":
  ① SSA两解: 必须逐一检验两个B值是否都使 A+B<π, 漏检=丢解
  ② 最大角判断: 最长边对最大角; 若余弦值<0 → 钝角三角形
  ③ 角的范围: 三角形内角 ∈ (0,π), 用cosA的正负判锐/钝, 不要只用sinA(sinA恒正!)
  ④ 面积公式选择: S=½absinC → 用你已知的两边和它们的夹角, 别选错角!

Section ⑤ "常用结论速查" (bottom-right, compact module, red header):
Bulleted list:
• 射影定理: a = b·cosC + c·cosB (任意三角形成立)
• 三角形内角和性质: A+B+C=π → sin(A+B)=sinC, cos(A+B)=−cosC, tan(A+B)=−tanC
• 三角形中 tanA+tanB+tanC = tanA·tanB·tanC (A+B+C=π 且三角均非π/2, 即非直角三角形, 确保三个正切均存在)
• 中线长公式: m_a = ½√(2b²+2c²−a²) (中线长, m_a 为 a 边上的中线)
• 角平分线长公式: t_a = 2bc·cos(A/2)/(b+c)
• 海伦公式: S = √[p(p−a)(p−b)(p−c)], p = (a+b+c)/2
• 焦点三角形(椭圆): 跨表连接→密码表11
• 外接圆半径 R = a/(2sinA); 内切圆半径 r = S/p (S为面积, p为半周长)
