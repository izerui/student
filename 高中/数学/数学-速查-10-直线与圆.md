  • α = 0°: 水平线, k = 0

Section ② "两直线位置关系" (middle-left, medium module, green header):
Titled "平行·垂直·交角——判定矩阵"

Sub-block "平行判定" with ∥ icon:
  斜率形式: l₁ ∥ l₂ ⟺ k₁ = k₂ 且 b₁ ≠ b₂ (截距不等以排除重合)
  一般式: A₁B₂ − A₂B₁ = 0 且 (A₁C₂ ≠ A₂C₁ 或 B₁C₂ ≠ B₂C₁) → 平行不重合
  ⚠️ 仅用 A₁C₂≠A₂C₁ 不完备: 反例 y=0(0x+1y+0=0)与y=1(0x+1y-1=0), A₁=A₂=0 → A₁C₂=A₂C₁=0, 但 B₁C₂≠B₂C₁
  ⚠️ 两线均无斜率(都垂直于x轴)时也平行，需单独讨论

Sub-block "垂直判定" with ⊥ icon:
  斜率形式: l₁ ⊥ l₂ ⟺ k₁ · k₂ = −1
  一般式: A₁A₂ + B₁B₂ = 0
  ⚠️ 一线斜率为0、另一线无斜率时也垂直，k₁k₂ = −1不适用，需单独判断

Sub-block "交角与到角":
  交角(锐角或直角): tan θ = |(k₁ − k₂) / (1 + k₁k₂)|,  θ ∈ (0, π/2]
  ⚠️ 当 1+k₁k₂=0 时两线垂直, θ=π/2, 不能代入上式(分母为零)
  到角(老教材·有方向): tan(α₂ − α₁) = (k₂ − k₁) / (1 + k₁k₂),  结果可正可负，对应旋转方向

Sub-block "三线共点与三角形":
  三线共点: 解两线交点，验证代入第三条是否成立
  三线围成三角形 ⟺ 任意两线不平行 且 三交点不重合

Section ③ "距离公式" (middle-right, medium module, orange header):
Titled "两点·点线·线线——度量工具箱"

Formula block 1 "两点距离":
  d = √[(x₂ − x₁)² + (y₂ − y₁)²]
  (注: 本质是勾股定理在坐标系中的表达)

Formula block 2 "点到直线距离" (highlighted with yellow background):
  直线 Ax + By + C = 0, 点 P(x₀, y₀):
  d = |Ax₀ + By₀ + C| / √(A² + B²)
  推导要点: 过P作直线的垂线，设垂足H，用向量 PH⃗ 的投影长度推得

Formula block 3 "两平行线距离":
  l₁: Ax + By + C₁ = 0,  l₂: Ax + By + C₂ = 0 (注意A,B系数必须相同!)
  d = |C₁ − C₂| / √(A² + B²)

Formula block 4 "中点与定比分点":
  中点: M = ((x₁+x₂)/2, (y₁+y₂)/2)
  定比分点(老教材): P分AB为 m:n →
  P = ( (nx₁ + mx₂)/(m+n),  (ny₁ + my₂)/(m+n) )
  (m,n同号→内分, 异号→外分)

Section ③b "直线与圆题型导航" (inserted as a compact module between Sections ③ and ④, yellow-green header bar, spanning full width):

直线与圆题型导航 → 拿到题第一步:
├─ 求直线方程 → 看已知条件选形式:
│    已知一点+斜率 → 点斜式 y-y₀=k(x-x₀)
│    已知斜率+截距 → 斜截式 y=kx+b
│    已知两点 → 两点式, 或直接求k再用点斜式
│    已知两截距 → 截距式 x/a+y/b=1
│    ⚠️ 截距式陷阱: 过原点时不能用! 截距为0≠"没有截距", 要单独讨论
│    ⚠️ 斜率不存在时: 别忘 x=常数 这条直线!
├─ 求圆方程 → 三种方法:
│    ├─ 待定系数法: 设标准/一般方程, 代入条件列方程组
│    ├─ 几何法: 圆心在弦的中垂线上, 圆心到切线距离=r
│    └─ 已知直径端点: (x-x₁)(x-x₂)+(y-y₁)(y-y₂)=0
├─ 直线与圆位置关系 → 核心一步: 算圆心到直线距离d, 比较d与r
├─ 切线问题 →
│    ├─ 切点在圆上 → 用切点切线公式(xx₀+yy₀=r² 等)
│    └─ 过圆外一点 → 设切线 y-y₀=k(x-x₀), 用d=r求k (⚠️ 可能有两条! 且要检查斜率不存在的情况)
├─ 弦长问题 → |AB|=2√(r²-d²), d=圆心到直线距离
└─ 两圆问题 → 两方程相减得公共弦/根轴所在直线

Section ④ "圆的方程与性质" (bottom-left, large module, purple header):
Titled "标准·一般·互化——圆的代数描述"

Sub-block "标准方程":
  (x − a)² + (y − b)² = r²
  圆心 (a, b), 半径 r
  特例: 圆心在原点 → x² + y² = r²

Sub-block "一般方程":
  x² + y² + Dx + Ey + F = 0
  配方化标准: 圆心(−D/2, −E/2), 半径 r = ½√(D² + E² − 4F)
  成圆条件: D² + E² − 4F > 0
  D² + E² − 4F = 0 → 退化为一个点
  D² + E² − 4F < 0 → 无图形(空集)

Sub-block "求圆方程三法":
  ① 待定系数法: 设标准/一般方程 → 代入已知条件(过某点/与某线相切/圆心在某线上)
  ② 几何法: 圆心在弦的中垂线上 → 两条中垂线交点即圆心
  ③ 直径端点法: 已知直径AB → (x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0

Sub-block "弦长公式":
  直线与圆相交, 设圆心到直线距离 d, 半径 r:
  弦长 |AB| = 2√(r² − d²)
  (本质: 圆心到弦的距离d、半弦长、半径构成直角三角形)

Section ⑤ "直线与圆/圆与圆位置关系" (bottom-right, medium module, teal header):
Titled "距离判位——位置关系速查"

Sub-block "直线与圆" with a small diagram showing three cases (line outside / tangent / secant to circle):
  设圆心到直线距离 d, 半径 r:
  d > r → 相离 (0个交点)
  d = r → 相切 (1个交点) → 切点即垂足
  d < r → 相交 (2个交点) → 弦长 = 2√(r² − d²)

  切线方程速查:
  过圆x²+y²=r²上点(x₀,y₀)的切线: x·x₀ + y·y₀ = r²
  过圆(x−a)²+(y−b)²=r²上点(x₀,y₀)的切线: (x₀−a)(x−a) + (y₀−b)(y−b) = r²
  过圆外一点的切线: 设切线方程 → 用d=r求k (注意可能有两条!)

Sub-block "圆与圆" with a small diagram showing five cases (external separate / external tangent / intersecting / internal tangent / internal):
  设圆心距 d, 两圆半径 r₁, r₂ (r₁ ≥ r₂):
  d > r₁ + r₂ → 外离 (0个交点, 4条公切线)
  d = r₁ + r₂ → 外切 (1个交点, 3条公切线)
  |r₁ − r₂| < d < r₁ + r₂ → 相交 (2个交点, 2条公切线)
  d = |r₁ − r₂| (≠0) → 内切 (1个交点, 1条公切线)
  d < |r₁ − r₂| → 内含 (0个交点, 0条公切线)
  d = 0 且 r₁ = r₂ → 重合

  公共弦(相交时): 两圆方程相减 → 得到一条直线(公共弦所在直线/相交圆的根轴)
