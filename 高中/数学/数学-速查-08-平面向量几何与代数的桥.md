Section ① "向量运算三阶递进" (top, hero module spanning full width, dark blue header):
The CENTRAL THINKING MODEL of this poster: a three-level ascending staircase diagram (阶梯图), each stair wider and higher than the last, representing increasing abstraction. Each stair is a distinct colored block with content inside.

第一阶 (bottom stair, light blue, labeled "几何运算"):
向量概念: 既有大小又有方向的量, 记作 a⃗ 或 AB⃗(从A指向B)
  零向量 0⃗: 模为0, 方向任意 | 单位向量: 模为1 | 相等向量: 方向相同且模相等 | 相反向量: 方向相反且模相等
加法 (两种法则并排的小示意图):
  三角形法则: a⃗ 的终点接 b⃗ 的起点 → 从a⃗起点到b⃗终点 (首尾相连)
  平行四边形法则: a⃗ 和 b⃗ 共起点 → 对角线为 a⃗+b⃗
减法: a⃗ − b⃗ = a⃗ + (−b⃗), 几何: 共起点时从 b⃗ 终点指向 a⃗ 终点
数乘: λa⃗ — |λ|倍长度; λ>0同向, λ<0反向, λ=0得零向量

第二阶 (middle stair, light green, labeled "基本定理与坐标化"):
向量基本定理: 若 e⃗₁, e⃗₂ 不共线, 则平面上任意向量 a⃗ 可唯一表示为 a⃗ = λ₁e⃗₁ + λ₂e⃗₂
  → 取 e⃗₁=(1,0), e⃗₂=(0,1) 即为标准基底 → 坐标表示: a⃗ = (x₁, y₁)
坐标运算速查:
  a⃗ + b⃗ = (x₁+x₂, y₁+y₂)
  a⃗ − b⃗ = (x₁−x₂, y₁−y₂)
  λa⃗ = (λx₁, λy₁)
  AB⃗ = B − A = (x_B−x_A, y_B−y_A)
  |a⃗| = √(x₁² + y₁²)

第三阶 (top stair, light orange, labeled "数量积"):
定义: a⃗ · b⃗ = |a⃗| |b⃗| cos θ (θ是a⃗与b⃗的夹角, θ∈[0,π])
坐标公式: a⃗ · b⃗ = x₁x₂ + y₁y₂
四大应用 (四个小框):
  求模: |a⃗| = √(a⃗ · a⃗) = √(x₁² + y₁²)
  求夹角: cos θ = (a⃗·b⃗)/(|a⃗||b⃗|) = (x₁x₂+y₁y₂) / (√(x₁²+y₁²) · √(x₂²+y₂²))  (a⃗≠0⃗, b⃗≠0⃗)
  判垂直: a⃗ ⊥ b⃗ ⟺ a⃗·b⃗ = 0 ⟺ x₁x₂+y₁y₂ = 0
  求投影: a⃗在b⃗方向的投影的数量(标量) = (a⃗·b⃗)/|b⃗| = |a⃗|cosθ (b⃗≠0⃗); 向量投影 = [(a⃗·b⃗)/|b⃗|²]·b⃗

Section ② "共线与垂直判定" (middle-left, medium module, green header):
Two parallel judgment boxes side by side:

共线(平行)条件 (blue box):
  几何形式: a⃗ = λb⃗ (存在实数λ, b⃗≠0⃗)
  坐标形式: x₁y₂ − x₂y₁ = 0
  记忆: "交叉相乘相等" — 行列式 |x₁ x₂; y₁ y₂| = 0 (老教材行列式概念: 二阶行列式 = 主对角线乘积 − 副对角线乘积)
  ⚠️ 教材定义: 向量共线 = 向量平行 (同向和反向都算, 包含零向量情形). 区别于"两条直线平行"——直线平行要求不重合, 但向量平行包含共线重合.

垂直条件 (orange box):
  几何形式: a⃗ · b⃗ = 0 (注: 零向量与任何向量都垂直)
  坐标形式: x₁x₂ + y₁y₂ = 0
  记忆: "对应相乘相加为零"

对比总结(底部一行):
共线 → 交叉乘积为零(x₁y₂−x₂y₁=0) | 垂直 → 对应乘积之和为零(x₁x₂+y₁y₂=0)

Section ③ "向量的几何应用" (middle-right, medium module, teal header):
向量法证明几何定理 — 比综合法更系统化、更可靠:

定比分点公式(老教材解析几何):
  P 分 AB 的比为 λ:μ → OP⃗ = (μ·OA⃗ + λ·OB⃗)/(λ+μ)
  中点: M⃗ = (A⃗ + B⃗)/2 (即 λ=μ=1)
  重心: G⃗ = (A⃗ + B⃗ + C⃗)/3

三角形面积(向量叉积的模):
  S△ = ½|AB⃗ × AC⃗| = ½|x₁y₂ − x₂y₁|
  其中 AB⃗=(x₁,y₁), AC⃗=(x₂,y₂)
  老教材深度: 二阶行列式 |x₁ x₂; y₁ y₂| 的绝对值 = 以两向量为邻边的平行四边形面积, ÷2即三角形面积

向量法证余弦定理:
  c⃗ = a⃗ − b⃗ → |c⃗|² = (a⃗−b⃗)·(a⃗−b⃗) = |a⃗|²−2a⃗·b⃗+|b⃗|² = a²+b²−2ab·cosC
  → c² = a² + b² − 2ab·cosC (余弦定理的向量证明, 一步到位)

向量法证中线定理:
  设 M 为 BC 中点, AM⃗ = ½(AB⃗+AC⃗)
  → |AM|² = ¼(|AB|²+2AB⃗·AC⃗+|AC|²) → 4|AM|² = 2|AB|²+2|AC|²−|BC|² (中线长公式)

Section ④ "数量积运算律与公式速查" (bottom, full width, orange header):
A compact reference table with ✓/✗ marks for operation laws:

运算律:
  交换律: a⃗ · b⃗ = b⃗ · a⃗  ✓
  分配律: a⃗ · (b⃗ + c⃗) = a⃗·b⃗ + a⃗·c⃗  ✓
  结合律: (a⃗·b⃗)·c⃗ ≠ a⃗·(b⃗·c⃗)  ✗ ← 左边a⃗·b⃗是标量, 标量·向量=数乘, 与右边含义不同
  数乘结合: (λa⃗)·b⃗ = λ(a⃗·b⃗) = a⃗·(λb⃗)  ✓

重要恒等式(一行排列):
  |a⃗+b⃗|² = |a⃗|² + 2a⃗·b⃗ + |b⃗|²  (向量完全平方)
  |a⃗−b⃗|² = |a⃗|² − 2a⃗·b⃗ + |b⃗|²
  (a⃗+b⃗)·(a⃗−b⃗) = |a⃗|² − |b⃗|²  (平方差)
  |a⃗+b⃗|² + |a⃗−b⃗|² = 2(|a⃗|²+|b⃗|²)  (平行四边形对角线)

⚠️ 常见错误 (red warning strip):
  ① |a⃗·b⃗| ≠ |a⃗|·|b⃗| (除非cosθ=±1)
  ② a⃗·b⃗ = a⃗·c⃗ 不能推出 b⃗=c⃗ — 即使 a⃗≠0⃗ 也不行! 只能推出 a⃗·(b⃗−c⃗)=0, 即 b⃗−c⃗⊥a⃗. 反例: a⃗=(1,0), b⃗=(0,1), c⃗=(0,2), a⃗·b⃗=a⃗·c⃗=0 但 b⃗≠c⃗
  ③ |a⃗+b⃗| ≠ |a⃗|+|b⃗| (三角不等式: |a⃗+b⃗| ≤ |a⃗|+|b⃗|, 等号当a⃗∥b⃗同向时成立)
