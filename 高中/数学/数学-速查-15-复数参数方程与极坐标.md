Section ① "复数代数形式" (top-left, medium module, dark blue header):
Definition in large font: z = a + bi （a为实部Re(z), b为虚部Im(z), i²=−1）

分类判定 decision tree:
  z = a+bi → b=0? → 是 → 实数
                    → 否(b≠0) → 虚数 → a=0? → 是 → 纯虚数
                                              → 否 → 一般虚数

四则运算 (compact table):
  加减: (a+bi) ± (c+di) = (a±c) + (b±d)i
  乘法: (a+bi)(c+di) = (ac−bd) + (ad+bc)i
  除法: (a+bi)/(c+di) = [(a+bi)(c−di)] / (c²+d²)  ← 分母实数化: 乘共轭

i的周期性 (circular diagram with 4 nodes arranged in a square):
  i¹ = i → i² = −1 → i³ = −i → i⁴ = 1 → (回到i¹)
  规律: iⁿ的值只取决于n mod 4
  i¹+i²+i³+i⁴ = i+(−1)+(−i)+1 = 0 （连续四个幂次之和为0; 推广: i¹+i²+⋯+i⁴ⁿ=0）

共轭复数:
  z̄ = a − bi （实部不变，虚部取反）
  z · z̄ = a² + b² = |z|² （模的平方）
  z + z̄ = 2a = 2Re(z)
  z − z̄ = 2bi = 2iIm(z)

LEFT sub-area "三角形式":
  z = r(cosθ + isinθ), where r = |z| ≥ 0, θ = arg(z)
  ⚠️ z=0 时辐角未定义, 只有非零复数才有辐角
  Draw unit circle with point on it showing r and θ relationship to a+bi

  乘法的几何意义 (KEY INSIGHT, highlighted box):
    z₁z₂ = r₁r₂ [cos(θ₁+θ₂) + isin(θ₁+θ₂)]
    "模相乘，辐角相加"
    Geometric meaning: 乘法 = 旋转θ₂角 + 缩放r₂倍
    → 复数乘法统一了旋转和缩放两种几何变换!

  除法:
    z₁/z₂ = (r₁/r₂) [cos(θ₁−θ₂) + isin(θ₁−θ₂)]
    "模相除，辐角相减"

CENTER sub-area "棣莫弗定理":
  Large formula: zⁿ = rⁿ(cos nθ + i sin nθ)
  意义: n次幂 = 模取n次方 + 辐角乘以n

  n次单位根 (draw unit circle with n equally spaced dots):
    zⁿ = 1 的n个解:
    zₖ = cos(2kπ/n) + isin(2kπ/n), k = 0, 1, 2, …, n−1
    Draw a regular pentagon inscribed in the unit circle (n=5 example) with vertices labeled z₀, z₁, z₂, z₃, z₄
    性质: n个n次单位根均匀分布在单位圆上, n≥3时构成正n边形 (n=2时为直径两端点±1)
    z₀+z₁+⋯+zₙ₋₁ = 0 (单位根之和为零, n≥2; n=1时唯一根为1)
    z₀·z₁·⋯·zₙ₋₁ = (−1)ⁿ⁺¹

RIGHT sub-area "欧拉公式" (highlighted golden box):
  Large formula: e^(iθ) = cosθ + isinθ
  Therefore: z = r·e^(iθ) （指数形式——最简洁的表示）

  The most beautiful equation in mathematics (centered, large):
    e^(iπ) + 1 = 0
  "五个最重要的数学常数通过一个等式相连:
   0(加法单位元) · 1(乘法单位元) · i(虚数单位) · π(圆周率) · e(自然常数)"

  Deep connection: 欧拉公式将指数函数、三角函数和复数统一起来
  cosθ = (e^(iθ) + e^(−iθ))/2
  sinθ = (e^(iθ) − e^(−iθ))/(2i)

Section ④ "参数方程" (bottom-left, large module, orange header):
Definition: 曲线C上的点(x,y)的坐标都可以表示为参数t的函数:
  x = f(t), y = g(t) (t为参数)

常见曲线参数方程 (table with 5 rows):
  | 曲线 | 参数方程 | 参数含义 | 普通方程 |
  |------|---------|---------|---------|
  | 直线(过P₀(x₀,y₀)倾斜角α) | x=x₀+tcosα, y=y₀+tsinα | t=从P₀到P的有向距离 | y−y₀=tanα·(x−x₀) (cosα≠0时) |
  | 圆(圆心(a,b)半径r) | x=a+rcosθ, y=b+rsinθ | θ=参数角 | (x−a)²+(y−b)²=r² |
  | 椭圆(标准位置) | x=acosθ, y=bsinθ | θ=离心角(≠真实角) | x²/a²+y²/b²=1 |
  | 抛物线 y²=2px | x=2pt², y=2pt | t=y/(2p)斜率相关 | y²=2px |
  | 摆线(老教材扩展) | x=r(t−sint), y=r(1−cost) | t=滚动角 | (无简洁普通方程) |

消参方法:
  ① 代入消元: 从一个方程解出t, 代入另一个
  ② 三角恒等式: sin²θ+cos²θ=1 → 消去θ
  ③ 平方和/差: 适用于含sin和cos的参数方程

直线参数方程的重要性质 (boxed):
  设直线过定点P₀(x₀,y₀), 倾斜角α:
  x=x₀+tcosα, y=y₀+tsinα
  则: |t| = |P₀P| (参数t的绝对值=P₀到P的距离, t>0沿α方向, t<0沿反方向)
  若P₁, P₂在直线上对应参数t₁, t₂:
  |P₁P₂| = |t₁−t₂|
  P₁P₂中点对应参数 (t₁+t₂)/2
