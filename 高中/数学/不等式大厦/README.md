# 不等式大厦

不等式推导总图的全部文件。后续编辑、修改、生成都在本目录内进行。

当前主稿：`outputs/inequality-tree-v50.drawio`，成图为同名矢量 `.pdf`（任意放大都清晰）。`outputs/` 只保留当前版，旧版本已删除，需要时从 git 历史取回；`生成/` 里各脚本的"用法"记录的是当时的版本号。

v36 起，"看到什么 → 用哪个工具"统一写在左侧"题型入口目录"里，不另设面板：新内容先找相近的入口补进去，不重复、不新增零散块。

## 工作流程

以下命令都在本目录下运行。新版本先复制当前版再改；新版确认后删除上一版（git 历史可取回）。

1. 复制出新版本：

```bash
cp outputs/inequality-tree-v50.drawio outputs/inequality-tree-v51.drawio
```

2. 修改。整图公式转换：

```bash
python3 生成/tex_convert.py "(a+b)/2 ≥ √(ab)"                       # 单条测试
python3 生成/apply.py 输入.drawio outputs/inequality-tree-v51.drawio   # 整图转换，日志写到 /tmp/convlog.txt
```

`refound.py` 里的节点 id、坐标是为 v34 → v35 写死的，不能直接重跑，作为同类改动的参考。`fixrefs.py` 可以反复跑：移动节点或新增引用后运行 `python3 生成/fixrefs.py outputs/inequality-tree-v51.drawio`，全图"编号〔坐标〕"按下面的规则重算。

3. 检查：

```bash
python3 工具/ovl.py outputs/inequality-tree-v50.drawio outputs/inequality-tree-v51.drawio   # 新增重叠
python3 工具/sub.py outputs/inequality-tree-v51.drawio /tmp/局部.drawio 6000 0 9000 1300  # 截局部
/Applications/draw.io.app/Contents/MacOS/draw.io -x -f png -s 0.7 -o /tmp/局部.png /tmp/局部.drawio
```

4. 导出整图（只出矢量 PDF）：

```bash
/Applications/draw.io.app/Contents/MacOS/draw.io -x -f pdf --crop -o outputs/inequality-tree-v51.pdf outputs/inequality-tree-v51.drawio
```

`--crop` 让整张图输出为单页。不要直接导出 PNG：整图只能按 0.4 倍导出（倍数大了会超出渲染显存，出现空白），文字发糊。

## 约定

- 公式写成 `\({LaTeX}\)`，外层大括号防止 MathJax 把一个公式拆成多行；含 `\dfrac` 的公式外包 `<span style="display:inline-block;margin:3px 0;">`，防止相邻行重叠。
- 网格坐标：列 = `'ABCDEFGHJKLMN'[(节点中心x + 80) // 1165]`，行 = `(节点中心y + 80) // 1116 + 1`。
- 三层分工：**工具**＝公理、定义、定理、公式，凡能拿来直接用的，一定能写成一个公式（主图每个节点是本图推出的工具，工具箱是借用的公式）；**方法**＝运算逻辑、变换方式，本身不是公式，是解题的方向和思路，如换元、同乘、配凑（推导线上的【】、左侧“方法”一栏）。写不成一个公式、由几种方法配合工具组成的流程，节点加棕色"解法"标记；**题型入口**＝看到什么想到什么。
- 推导线上【】写**具体做法**（如【同除】【移项】【求导】），每一步都加，过程要写清楚；具体做法归入 12 类方法（比较、配凑、恒等变形、等价变形、代换、构造函数、放缩、消元、数形结合、分类讨论、反证、归纳），归属写在左侧"方法"各块的"线上标签"里，新增做法名要同时加进去。套用公式的步骤写成「工具名」，不带编号。【前提】【公理】【定义】【定理】【研究对象】另有含义。
- 恒等式大厦以本目录的 v35 为样板（见 `../恒等式大厦/恒等式大厦-设计.md`），改动样式时注意两边一致。
