# E26｜拓展：琴生不等式与对数平均（拓展）

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：琴生不等式（拓展）；幂平均不等式（拓展）；对数平均不等式（拓展）

## 这一集要讲明白的一件事
下凸函数“函数值的平均 ≥ 平均处的函数值”；用它可以把平均数链推广成幂平均不等式；对数平均夹在几何平均与算术平均之间。

## 开场问题（不依赖其他集）
下凸函数（f″≥0）有一个性质：几个函数值的平均，不小于平均处的函数值。这是切线不等式的推广。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- 记号：f″ 是 f′ 的导数；f″≥0 说明 f′ 不减，曲线“下凸”（整条曲线在任一切线上方）；f″≤0 叫“上凸”。
- **求导法则**：(t^α)′=αt^(α−1)（如 (√t)′=1/(2√t)）；积、商的求导法则。
- **对数平均化成只含 t**：设 a>b>0，t=a/b>1：a−b=b(t−1)，√(ab)=b√t，(a+b)/2=b(t+1)/2，ln a−ln b=ln t>0；三式同除以 b，再乘以正数 ln t。
- **严格下凸时的切线**：f″>0 时 f′ 严格递增，切线只在切点处与曲线相交，所以琴生不等式取等要求各 xᵢ 全相等。
- **【工具】导数判单调**
  - 在同一个区间 I 内：f′(x) ≥ 0 ⇒ f(x) 递增（不减）；f′(x) ≤ 0 ⇒ f(x) 递减（不增）
  - f′(x) > 0 ⇒ 严格递增；f′(x) < 0 ⇒ 严格递减
  - 不同区间不能连起来用：如 f(x)=−1/x 在 x<0、x>0 上分别递增，但 f(−1) > f(1)
  - 区间端点要算进去时，函数在端点要连续
  - 由来（简短复习）：课本直接使用的工具（严格证明要用拉格朗日中值定理，超出高中）。直观上：导数是切线的斜率，斜率处处 ≥0，图像就不会往下走。
- **切线不等式（切线放缩）**
  - f″(x) ≥ 0（下凸）⇒ f(x) ≥ f(x₀) + f′(x₀)(x−x₀)：图像在切线上方
  - f″(x) ≤ 0（上凸）⇒ 不等号反向：图像在切线下方
  - eˣ ≥ 1+x、eˣ ≥ ex 是下凸的特例；ln x ≤ x−1、ln x ≤ x/e 是上凸的特例
  - 条件：f″ 定号的区间
  - 由来（简短复习）：（f″ 是 f′ 的导数；f″≥0 说明 f′ 不减，曲线下凸。）令 g(x)=f(x)−[f(x₀)+f′(x₀)(x−x₀)]，则 g(x₀)=0，g′(x)=f′(x)−f′(x₀)。f″≥0 时 f′ 不减，所以 x<x₀ 时 g′≤0、x>x₀ 时 g′≥0，g 在 x₀ 取最小值 0，即 g(x)≥0。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【工具】导数判单调 → 对数平均不等式（拓展）**（推导；含 3 个小步骤，逐个展开）
   - 【换元法】不妨 a>b，令 t=a/b>1，化为 2(t−1)/(t+1) < ln t < (t−1)/√t
   - 【构造法】g(t)=ln t − 2(t−1)/(t+1)，h(t)=(t−1)/√t − ln t
   - 【求导】g′=(t−1)²/[t(t+1)²]>0，h′=(√t−1)²/(2t√t)>0，且 g(1)=h(1)=0 ⇒ t>1 时 g,h>0
2. **切线不等式（切线放缩） → 琴生不等式（拓展）**（推导；含 2 个小步骤，逐个展开）
   - 【代入特定值】取 x₀ = 平均值 x̄，对每个 xᵢ 写切线不等式
   - 【逐项相加】f′(x̄)·Σ(xᵢ−x̄) = 0，右边只剩 n·f(x̄)
3. **琴生不等式（拓展） → 幂平均不等式（拓展）**（推导；含 2 个小步骤，逐个展开）
   - 【构造法】0<p<q 时取 f(t) = t^(q/p)（t>0），q/p>1 ⇒ f″ ≥ 0（下凸）
   - 【代入特定值】对 xᵢ = aᵢᵖ 用琴生：(Σaᵢ^q)/n ≥ ((Σaᵢᵖ)/n)^(q/p)，两边开 q 次方
   - p<0 或含 0 的情形同理或取极限（超出高中）

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 琴生不等式（拓展）
- xᵢ 都在同一区间 I 内，f 在 I 上二阶可导且 f″ ≥ 0（下凸）：
- [f(x₁)+…+f(xₙ)]/n ≥ f((x₁+…+xₙ)/n)
- f″ > 0 时：等号 ⟺ xᵢ 全相等
- 只有 f″ ≥ 0 时：等号 ⟺ xᵢ 全相等，或 f 在这些点覆盖的区间 [最小的 xᵢ, 最大的 xᵢ] 上满足 f(x)=kx+b（允许 k=0，即也包括常数函数；如 f(x)=x、f(x)=1 时恒取等）

#### 幂平均不等式（拓展）
- Mₚ = ((a₁ᵖ+…+aₙᵖ)/n)^(1/p)（p≠0），M₀ = ⁿ√(a₁a₂…aₙ)
- p < q ⇒ Mₚ ≤ M_q；等号 ⟺ aᵢ 全相等
- p = −1、0、1、2 就是 调和 ≤ 几何 ≤ 算术 ≤ 平方 平均

#### 对数平均不等式（拓展）
- a,b>0，a≠b：√(ab) < (a−b)/(ln a − ln b) < (a+b)/2
- 用途：极值点偏移（如证 x₁+x₂ > 2x₀ 一类）；先由题设把 x₁、x₂ 对应到 a、b
- ⇐ 工具 ⑮⑯ 对数运算律：ln a − ln b = ln(a/b) = ln t 化成只含 t 的不等式

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑮⑯ 对数运算律（底数 q>0 且 q≠1）；M,N>0：log_q(MN)=log_q M+log_q N；M>0，t∈ℝ：log_q(Mᵗ)=t log_q M

## 易错点与边界（必须讲到）
- f″>0 时等号 ⟺ xᵢ 全相等；只有 f″≥0 时，等号 ⟺ xᵢ 全相等，或 f 在这些点覆盖的区间上满足 f(x)=kx+b（允许 k=0，即也包括常数函数）。
- 不要说成“是一次函数”：高中的一次函数要求 k≠0，会漏掉常数函数。反例：f(x)=1、x₁=0、x₂=2 时两边相等，但 f 不是一次函数。
