# E18｜用函数单调性解不等式：指对、抽象函数、奇偶性

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：指数、对数不等式；用单调性去掉 f；奇偶性 + 单调性解不等式（抽象函数）

## 这一集要讲明白的一件事
单调函数“保持（或反转）大小关系”，所以能把 f 去掉，比较自变量。

## 开场问题（不依赖其他集）
已知 f 是增函数，由 f(2x−1)<f(x+1) 能不能直接得到 2x−1<x+1？什么时候能，什么时候不能？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **例题中的二次不等式**：3x²+2x−1>0 即 (3x−1)(x+1)>0，两个因子同号：同为正得 x>1/3，同为负得 x<−1。
- **非负数平方保序**
  - 0 ≤ a < b ⇒ a² < b²
  - 反过来：a,b ≥ 0 时，a² < b² ⇒ a < b（可两边开平方）
  - 条件：a,b≥0
  - 由来（简短复习）：b²−a²=(b+a)(b−a)；0≤a<b 时，b+a>0、b−a>0，乘积为正，所以 a²<b²。反过来，若 a²<b² 且 a,b≥0，假设 a≥b，就会得到 a²≥b²，矛盾。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】函数单调性 → 指数、对数不等式**（推导）
   - ▼ 加条件：定义域内
   - 【单调性】增函数保持不等号，减函数反转
   - y=aˣ、y=logₐx：a>1 递增，0<a<1 递减
2. **【定义】函数单调性 → 用单调性去掉 f**（推导）
   - 【反证法】设 f(a)<f(b)，假设 a ≥ b：
   - a=b 时 f(a)=f(b)，a>b 时 f(a)>f(b)，都与 f(a)<f(b) 矛盾 ⇒ a<b
3. **【定义】函数奇偶性（定义域关于原点对称） → 奇偶性 + 单调性解不等式（抽象函数）**（推导）
   - 【代换法】偶函数：f(a)=f(|a|)，两边都化到 [0,+∞) 上
   - 奇函数：−f(b)=f(−b)，把负号移进括号
4. **用单调性去掉 f → 奇偶性 + 单调性解不等式（抽象函数）**（推导）
   - 【去掉 f】同在一个单调区间后，按单调性比较自变量
5. **非负数平方保序 → 奇偶性 + 单调性解不等式（抽象函数）**（提供前提）
   - 【前提】|a|<|b| ⟺ a²<b²（两边非负）

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【定义】函数单调性
- 增函数：区间 I 上任取 x₁<x₂，都有 f(x₁)<f(x₂)
- 减函数：区间 I 上任取 x₁<x₂，都有 f(x₁)>f(x₂)
- 起点：这是定义；aˣ、logₐx、幂函数的单调性课本直接给出

#### 指数、对数不等式
- a>1：aᶠ⁽ˣ⁾ > aᵍ⁽ˣ⁾ ⟺ f(x) > g(x)；0<a<1 时不等号反向
- logₐf(x) > logₐg(x)：先保证 f(x)>0、g(x)>0（定义域优先）
- 再按底数 a>1 或 0<a<1 去掉对数
- ⇐ 工具 ⑮⑯ 对数运算律：对数运算律：把两边化为同底再比较

#### 用单调性去掉 f
- f 在区间 I 上递增，a、b∈I：f(a)<f(b) ⟺ a<b
- f 在区间 I 上递减：f(a)<f(b) ⟺ a>b（不等号反向）
- 先查：a、b 都要在定义域内，且在同一个单调区间里

#### 【定义】函数奇偶性（定义域关于原点对称）
- 偶函数：f(−x)=f(x)，图像关于 y 轴对称
- 奇函数：f(−x)=−f(x)，图像关于原点对称
- 起点：这是定义

#### 奇偶性 + 单调性解不等式（抽象函数）
- 偶函数、在 [0,+∞) 上递增：f(a)<f(b) ⟺ |a|<|b|
- 奇函数、在 ℝ 上递增：f(a)+f(b)<0 ⟺ f(a)<f(−b) ⟺ a<−b
- 例：f 为偶函数且在 [0,+∞) 上递增，f(x−1)<f(2x) ⟺ |x−1|<|2x| ⟺ x<−1 或 x>1/3
- 先查：定义域；偶函数先化成 f(|·|) 再比较，别漏掉负的那一半

## 解题思维导向（片尾一句话）
f(□)<f(△) 型 → 先求定义域，再用单调性去掉 f；偶函数先化成比较绝对值。

## 易错点与边界（必须讲到）
- 指对不等式先求定义域，再看底数大于 1 还是小于 1。
- 去掉 f 时两个自变量必须在同一个单调区间里。
