# E14｜绝对值不等式的解法与距离和

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：绝对值不等式的解法（a>0）；绝对值和的最小值

## 这一集要讲明白的一件事
去绝对值靠分类讨论，绝对值的和靠几何意义。

## 开场问题（不依赖其他集）
|x−1|<3 怎么解？|x−1|+|x+2| 最小是多少？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **绝对值的几何意义**：|x−a| 是数轴上 x 到 a 的距离。
- **【定义】绝对值**
  - x≥0 时 |x|=x
  - x<0 时 |x|=−x
  - 由来（简短复习）：这是绝对值的定义，直接承认；几何意义：|x| 是数轴上 x 到原点的距离。
- **三角不等式**
  - |a+b| ≤ |a|+|b|
  - 等号 ⟺ ab ≥ 0
  - 由来（简短复习）：由绝对值的定义，−|a|≤a≤|a|，−|b|≤b≤|b|；两式相加得 −(|a|+|b|)≤a+b≤|a|+|b|，即 |a+b|≤|a|+|b|。a、b 同号（或有一个为 0）时取等。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】绝对值 → 绝对值不等式的解法（a>0）**（推导；含 2 个小步骤，逐个展开）
   - 【分类讨论】按 x≥0、x<0 去掉绝对值，再合并
   - 【数形结合】|x|<a：数轴上到原点的距离小于 a
2. **三角不等式 → 绝对值和的最小值**（推导；含 2 个小步骤，逐个展开）
   - 【代换法】|x−a|+|x−b| = |x−a|+|b−x|
   - ≥ |(x−a)+(b−x)| = |a−b|；等号 ⟺ (x−a)(b−x) ≥ 0
   - 【数形结合】数轴上 x 到 a、b 的距离之和：x 在 a、b 之间时最小

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 绝对值不等式的解法（a>0）
- |x|<a ⟺ −a<x<a；|x|>a ⟺ x<−a 或 x>a
- |f(x)|<g(x) ⟺ −g(x)<f(x)<g(x)
- 多个绝对值：按零点分段讨论
- 例：|x−1|+|x+2| ≥ 5，分 x<−2、−2≤x≤1、x>1 三段 ⇒ x ≤ −3 或 x ≥ 2

#### 绝对值和的最小值
- |x−a|+|x−b| ≥ |a−b|
- 几何意义：数轴上 x 到 a、b 的距离之和
- 等号 ⟺ x 在 a、b 之间（含端点 a、b）；解“距离和 ≥ k”（k>|a−b|）：在两点外侧各找一个边界点

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- |x|<a：数轴上到原点距离小于 a 的点，画成以原点为中心的区间。
- y=|x−a|+|x−b| 的图像是“平底 V”，平底正好是 a、b 之间。

## 着重标注（本集必须突出的地方）
- 分段讨论时，每一段的范围和去掉绝对值后的式子并排写。
- 距离和的最小值在 a、b 之间（含端点）标出。

## 解题思维导向（片尾一句话）
绝对值不等式 → 分段去绝对值，或看成数轴距离；|x−a|+|x−b| → 数轴上到两点的距离和。

## 易错点与边界（必须讲到）
- 多个绝对值按零点分段，每段去掉绝对值后再合并。
- 距离和取最小值时 x 可以取到端点 a、b。
