# E02｜平方非负：整座大厦的第一块砖

- 建议时长：3–4 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：平方非负

## 这一集要讲明白的一件事
任何实数的平方都 ≥0，只有 0 的平方等于 0。a²+b²≥2ab、基本不等式、柯西不等式等许多重要不等式，都从它出发推出。

## 开场问题（不依赖其他集）
一个数自己乘自己，结果会是负数吗？分正数、负数、0 三种情况看一看。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **【公理】实数大小**
  - a>b ⟺ a−b>0（a−b 是正数）
  - 任意两个实数 a、b：a>b、a=b、a<b 恰有一种成立
  - 正数 + 正数 = 正数（由此：a>b、b>c ⇒ a>c）
  - 由来（简短复习）：这是实数大小的规定（公理），直接承认：a>b 的意思就是 a−b 是正数。
- **正数乘法保序**
  - a>b, c>0 ⇒ ac > bc
  - 条件：a,b∈ℝ；c>0
  - 由来（简短复习）：a>b 即 a−b>0；c>0 时，(a−b)c 是两个正数相乘，为正，即 ac−bc>0，所以 ac>bc。
- **负数乘法反序**
  - a>b, c<0 ⇒ ac < bc
  - 条件：a,b∈ℝ；c<0
  - 由来（简短复习）：a−b>0，c<0 则 −c>0；(a−b)(−c) 是两个正数相乘，为正，即 bc−ac>0，所以 ac<bc。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【公理】实数大小 → x=0 ⇒ x²=0**（推导）
   - 【分类讨论】按 x>0、x=0、x<0 三种情况
   - x=0 时 0×0=0（运算规则）
2. **正数乘法保序 → x>0 ⇒ x²>0**（推导）
   - 【代换法】令 a=x, b=0, c=x
3. **负数乘法反序 → x<0 ⇒ x²>0**（推导）
   - 【代换法】令 a=0, b=x, c=x
4. **x>0 ⇒ x²>0 → 平方非负**（推导）
   - 【分类合并】x>0、x<0、x=0 三种情况合起来
   - x² ≥ 0，且只有 x=0 时取等
5. **x<0 ⇒ x²>0 → 平方非负**（推导）
   - 【分类合并】x>0、x<0、x=0 三种情况合起来
   - x² ≥ 0，且只有 x=0 时取等
6. **x=0 ⇒ x²=0 → 平方非负**（推导）
   - 【分类合并】x>0、x<0、x=0 三种情况合起来
   - x² ≥ 0，且只有 x=0 时取等

## 易错点与边界（必须讲到）
- “负 × 负 = 正”不是规定，是推出来的：x<0 时，把 x<0 两边同乘负数 x，不等号反向，得 x·x>0·x=0。
- 等号只在 x=0 时成立；许多不等式的取等条件（如 a=b）都能追到这里。
