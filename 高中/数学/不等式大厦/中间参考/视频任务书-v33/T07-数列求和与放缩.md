# T07｜题型串讲：数列求和与放缩

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 数列求和 / 放缩估计
- 能直接求和：用等差、等比、Σk²、Σk³ 公式
- 不能直接求和：裂项放缩（1/k² < 1/(k−1) − 1/k）、根式裂项、等比放缩、对数放缩（ln(1+1/k) < 1/k）、伯努利
- 先查：每一项放缩方向一致；前几项可单独处理，保证不放过头
- 反推：能直接求和就先求和；求不出就逐项放缩成能求和的形式（裂项、等比、对数、伯努利、n 元均值）
- 去这里查：
- ▸ 等差数列
- ▸ 等比数列
- ▸ 前 n 项平方和
- ▸ 前 n 项立方和
- ▸ 放缩用伯努利 → 伯努利不等式
- ▸ 裂项放缩 → 裂项放缩
- ▸ 等比放缩 → 等比放缩（aₖ>0）
- ▸ 对数放缩 → 对数放缩求和
- ▸ 根式裂项 → 根式裂项
- ▸ 求下界 → 根式裂项（下界）
- ▸ 要证 < 5/3、< 7/4 → 更紧的裂项
- **参考例题（已核对）**：证明 1+1/2²+…+1/n² < 2：n=1 时左边为 1，直接成立；n≥2 时，k≥2 的每一项 1/k² < 1/(k−1) − 1/k，相加后左边 < 1 + (1 − 1/n) < 2。

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **数学归纳法**：先验证 n=1 成立；再由“n=k 时成立”推出“n=k+1 时成立”；于是对所有正整数 n 都成立（像多米诺骨牌一样依次倒下）。
- **伯努利不等式**
  - (1+x)ⁿ ≥ 1+nx
  - x≥−1, n为正整数
  - 等号 ⟺ x=0 或 n=1
  - 条件：x≥−1
  - 由来（简短复习）：数学归纳法：n=1 时两边相等；假设 (1+x)ᵏ≥1+kx，两边乘 1+x≥0（不等号不变）：(1+x)ᵏ⁺¹≥(1+kx)(1+x)=1+(k+1)x+kx²≥1+(k+1)x。
- **裂项放缩**
  - 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k（k≥2）
  - n≥2：1 + 1/2² + … + 1/n² < 2 − 1/n < 2
  - 条件：正整数 k≥2
  - 由来（简短复习）：k≥2 时 k²>k(k−1)>0，取倒数得 1/k²<1/(k(k−1))=1/(k−1)−1/k；从 k=2 加到 n，中间项一对对相消，只剩 1−1/n，再加上第一项 1。
- **等比放缩（aₖ>0）**
  - 若 aₖ₊₁ ≤ q·aₖ（0<q<1）
  - 则 a₁+…+aₙ ≤ a₁(1−qⁿ)/(1−q) < a₁/(1−q)
  - 条件：aₖ>0；0<q<1
  - 由来（简短复习）：由 aₖ₊₁≤q·aₖ 反复使用，得 aₖ≤a₁qᵏ⁻¹；逐项相加，再用等比数列求和公式。
- **对数放缩求和**
  - 1/(k+1) < ln(1+1/k) < 1/k（k 为正整数）
  - 条件：正整数 k
  - 由来（简短复习）：在 ln x≤x−1（x≠1 时严格）中令 x=1+1/k，得 ln(1+1/k)<1/k；在 ln x≥1−1/x 中令 x=1+1/k，得 ln(1+1/k)>1/(k+1)。
- **根式裂项**
  - 1/√k < 2(√k − √(k−1))（k ≥ 1）
  - 条件：正整数 k
  - 由来（简短复习）：√k+√(k−1)<2√k，取倒数：1/(2√k)<1/(√k+√(k−1))=√k−√(k−1)（分母有理化），两边乘 2。
- **根式裂项（下界）**
  - 1/√k > 2(√(k+1) − √k)（k ≥ 1）
  - 条件：正整数 k
  - 由来（简短复习）：√(k+1)+√k>2√k，取倒数得 1/√k=2/(2√k)>2/(√(k+1)+√k)=2(√(k+1)−√k)（分母有理化）；从 k=1 加到 n，中间项相消，剩 2(√(n+1)−1)。
- **更紧的裂项**
  - 1/k² < 1/(k²−1) = ½[1/(k−1) − 1/(k+1)] ⇒ 1 + 1/2² + … + 1/n² < 7/4
  - 1/k² < 4/(4k²−1) = 2[1/(2k−1) − 1/(2k+1)] ⇒ 1 + 1/2² + … + 1/n² < 5/3
  - 两式都从 k=2 起放缩，首项 1 保留不放
  - 条件：正整数 k≥2
  - 由来（简短复习）：k≥2 时 k²>k²−1>0，取倒数得 1/k²<1/(k²−1)=½[1/(k−1)−1/(k+1)]；从 k=2 加到 n 相消后小于 ½(1+½)=3/4，再加首项 1 得 <7/4。换成 k²>k²−1/4，同理得 <5/3。
- **等差数列**
  - aₙ=a₁+(n−1)d
  - Sₙ=n(a₁+aₙ)/2=na₁+n(n−1)d/2
  - 由来（简短复习）：等差数列求和（课本已证）：把 Sₙ 正着写一遍、倒着写一遍相加，每一对都等于 a₁+aₙ，所以 2Sₙ=n(a₁+aₙ)。
- **等比数列（n≥1；q≠0）**
  - aₙ=a₁qⁿ⁻¹；q≠1：Sₙ=a₁(1−qⁿ)/(1−q)
  - q=1：Sₙ=na₁
  - 由来（简短复习）：等比数列求和（课本已证）：Sₙ−qSₙ=a₁−a₁qⁿ（错位相减），q≠1 时两边除以 1−q。
- **前 n 项平方和**
  - Σₖ₌₁ⁿk² = n(n+1)(2n+1)/6
  - 由来（简短复习）：由 (k+1)³−k³=3k²+3k+1，k 从 1 加到 n，左边相消成 (n+1)³−1，再代入 Σk=n(n+1)/2 解出。
- **前 n 项立方和**
  - Σₖ₌₁ⁿk³ = [n(n+1)/2]²
  - 由来（简短复习）：可用数学归纳法验证：n=1 时成立；[k(k+1)/2]²+(k+1)³=[(k+1)(k+2)/2]²。
- **n 元均值不等式**
  - (a₁+…+aₙ)/n ≥ ⁿ√(a₁a₂…aₙ)（ⁿ√ 表示 n 次方根）
  - aᵢ≥0；等号 ⟺ 全相等
  - 条件：aᵢ≥0
  - 由来（简短复习）：先倍增：两两一组用两数的基本不等式，对 2、4、8…个数都成立；n 不是 2 的幂时，补上若干个平均值 A 凑成 2ᵏ 个数，代入后化简回到 n 个数（A=0 时 aᵢ 全为 0，直接成立）。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
