# E01｜地基：实数的大小与运算保序

- 建议时长：4–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：异向不等式可减

## 这一集要讲明白的一件事
比较大小的基本依据是“a>b 就是 a−b 是正数”；加、乘、除对不等号的影响，都能由它和“正数相乘还是正数”推出。同向不等式可以相加，异向不等式可以相减，但同向不等式不能相减。

## 开场问题（不依赖其他集）
说一个数比另一个数“大”，到底是什么意思？先把这句话说清楚：a>b 就是 a−b 是正数。加、乘、除对不等号的影响，都由这一句推出。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【公理】实数大小 → 加法保序**（推导）
   - 【作差法】(a+c)−(b+c) = a−b > 0
   - ⇒ a+c > b+c
2. **【公理】正数相乘 → 正数乘法保序**（推导）
   - 【作差法】a>b ⇒ a−b>0
   - c>0：(a−b)c>0 ⇒ ac>bc
3. **【公理】实数大小 → 正数乘法保序**（提供前提）
   - 【前提】a>b ⟺ a−b>0
4. **【公理】正数相乘 → 负数乘法反序**（推导）
   - 【作差法】a−b>0，c<0 ⇒ −c>0
   - 正×正：(a−b)(−c)>0 ⇒ (a−b)c<0 ⇒ ac<bc
5. **【公理】实数大小 → 负数乘法反序**（提供前提）
   - 【前提】a>b ⟺ a−b>0
6. **【公理】实数大小 → 同向不等式可加**（推导）
   - 【作差法】(a+c)−(b+d) = (a−b)+(c−d) ≥ 0
   - （正数 + 正数 = 正数）
   - 有一项为 0 时，和就等于另一项，仍然 ≥0
7. **加法保序 → 作差判大小**（推导）
   - 【代换法】令 c=−b
8. **正数乘法保序 → 除正数不变向**（推导）
   - 【代换法】令 c=1/d
   - d>0 ⇒ 1/d>0（否则 d·(1/d) ≤ 0，与等于 1 矛盾）
9. **同向不等式可加 → 异向不等式可减**（推导）
   - 【作差法】(a−c)−(b−d) = (a−b)+(d−c)
   - a−b>0，d−c>0，正数 + 正数 = 正数 ⇒ 差 > 0

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【公理】实数大小
- a>b ⟺ a−b>0（a−b 是正数）
- 任意两个实数 a、b：a>b、a=b、a<b 恰有一种成立
- 正数 + 正数 = 正数（由此：a>b、b>c ⇒ a>c）
- 起点：实数的基本规定，所有推导的地基（四则运算、分配律、相反数、倒数直接使用）

#### 【公理】正数相乘
- 正数 × 正数 = 正数
- 起点：实数的基本规定，和“实数大小”的规定一起构成实数大小的公理

#### 加法保序
- a>b ⇒ a+c > b+c

#### 同向不等式可加
- a≥b, c≥d ⇒ a+c ≥ b+d

#### 异向不等式可减
- a>b，c<d ⇒ a−c > b−d
- ⚠ 同向不等式不能相减：5>4，3>0，但 5−3=2 < 4−0=4

#### 作差判大小
- a>b ⟺ a−b > 0

#### 正数乘法保序
- a>b, c>0 ⇒ ac > bc

#### 负数乘法反序
- a>b, c<0 ⇒ ac < bc

#### 除正数不变向
- a>b, d>0 ⇒ a/d > b/d

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 数轴贯穿全片：a>b ⇔ a 在 b 右边 ⇔ a−b 这段箭头指向正方向。
- 加同一个数 = 两点一起平移，左右顺序不变；乘正数 = 以原点为中心伸缩，顺序不变；乘负数 = 翻到原点另一侧，顺序颠倒（把两个点连同箭头一起翻转，让观众看到箭头反向）。
- 同向可加：两段向右的箭头首尾相接，合起来仍向右。
- 异向可减：a−c 与 b−d 的差拆成 (a−b)+(d−c) 两段向右的箭头。

## 解题思维导向（片尾一句话）
看到比大小 → 先作差，和 0 比；要两边同乘或同除 → 先问乘的数是正还是负。

## 易错点与边界（必须讲到）
- 乘以负数要变号：用 3>2，两边乘 −1 得 −3<−2 当场演示。
- 除法只能除以正数才不变向；除以含字母的式子要先判断正负。
- 同向不等式不能相减：5>4，3>0，但 5−3=2<4−0=4。
