# T01｜题型串讲：比大小与解不等式

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 两个式子比大小
- 首选作差：a−b 与 0 比较；含幂、指数的正数式子用作商：a/b 与 1 比较
- 分式加同一个正数：糖水不等式；同一函数的两个值：利用单调性
- 复杂时找中间量（如 0、1），或构造函数用导数判断
- 去这里查：
- ▸ 作差 → 作差判大小
- ▸ 作商 → 作商法（b>0）
- ▸ 糖水 → 糖水不等式
- ▸ 单调性 → 【定义】函数单调性
- ▸ aᵇ 与 bᵃ → 构造 f(x) = ln x / x 比大小（x>0）
- ▸ 作商的例子 → aᵃbᵇ ≥ aᵇbᵃ
- ▸ 两个不等式相减、相除 → 异向可减
- ▸ 异向正数可除
- **参考例题（已核对）**：比较 a²+1 与 2a：作差得 (a−1)² ≥ 0，所以 a²+1 ≥ 2a，a=1 时相等。

## 题型 2：看到 解不等式（求解集）
- 二次：化成二次项系数 >0 → 三个二次的关系；含参按系数、Δ、根的大小分类
- 分式：移项通分 → 化成整式（乘积）→ 穿根法，注意分母 ≠ 0
- 绝对值：|x|<a、|x|>a 公式，或按零点分段；指对：定义域优先，再看底数
- 不等式组：分别解出再取交集；“或”取并集；最后用集合或区间写出解集
- 去这里查：
- ▸ 二次 → 解一元二次不等式
- ▸ 分式 → 分式不等式
- ▸ 高次 → 高次不等式（穿根法）
- ▸ 绝对值 → 绝对值不等式的解法（a>0）
- ▸ 指对 → 指数、对数不等式
- ▸ 根的分布 → 一元二次方程根的分布（a>0）
- ▸ 不等式组、写解集 → 不等式组与解集
- ▸ 根式 → 根式（无理）不等式的解法
- **参考例题（已核对）**：解 x²−x−6<0：(x−3)(x+2)<0，解集 (−2,3)。

## 题型 3：看到 只给性质、不给解析式的不等式，如 f(x−1) < f(2x)
- 反推：去掉 f ← 单调性；偶函数先化成 f(|·|) ← 奇偶性；奇函数先把 −f(b) 化成 f(−b)
- 先查：定义域；是否在同一个单调区间；偶函数要比较绝对值
- 若给的是 f′ 与 f 的关系（如 f′+f>0），改用构造函数
- 去这里查：
- ▸ 去掉 f → 用单调性去掉 f
- ▸ 奇偶性 + 单调性 → 奇偶性 + 单调性解不等式
- ▸ 给的是导数关系 → 构造函数（抽象函数）

## 题型 4：看到 至少 / 至多 / 存在 / 唯一 型结论
- 反推：假设反面成立（如都 <k）→ 同向相加推出矛盾 ← 同向不等式可加
- 适用：直接证明困难、结论是“至少有一个”
- 去这里查：
- ▸ 【反证法】假设结论不成立，各式同向相加推出矛盾 → 同向不等式可加
- **参考例题（已核对）**：已知 a+b+c=3，证明 a、b、c 中至少有一个 ≥1：假设都 <1，相加得 a+b+c<3，矛盾。

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **作差判大小**
  - a>b ⟺ a−b > 0
  - 由来（简短复习）：这就是“a>b”的定义本身：a>b 的意思是 a−b 为正数。
- **作商法（b>0）**
  - a/b > 1 ⟺ a > b
  - 适合含幂、指数、阶乘的式子比大小
  - 条件：b>0
  - 由来（简短复习）：b>0 时，a/b>1 两边乘以正数 b，不等号方向不变，得 a>b；反过来，a>b 两边除以正数 b 得 a/b>1。
- **糖水不等式**
  - b>a>0，m>0 ⇒ (a+m)/(b+m) > a/b（糖水加糖更甜）
  - 反过来：a>b>0 时 (a+m)/(b+m) < a/b
  - 条件：a,b,m>0
  - 由来（简短复习）：作差：(a+m)/(b+m)−a/b=m(b−a)/[b(b+m)]；b>a>0、m>0 时，分子、分母都为正，差为正。
- **【定义】函数单调性**
  - 增函数：区间 I 上任取 x₁<x₂，都有 f(x₁)<f(x₂)
  - 减函数：区间 I 上任取 x₁<x₂，都有 f(x₁)>f(x₂)
  - 由来（简短复习）：这是增函数、减函数的定义，直接承认。
- **构造 f(x) = ln x / x 比大小（x>0）**
  - f′(x) = (1 − ln x)/x²：(0,e) 递增，(e,+∞) 递减
  - 最大值 f(e) = 1/e ⇒ ln x ≤ x/e
  - 例：f(e) > f(π) ⇒ π > e·ln π ⇒ e^π > π^e
  - 条件：x>0
  - 由来（简短复习）：f′(x)=(1−ln x)/x²：0<x<e 时 f′>0，x>e 时 f′<0，所以 x=e 时取最大值 f(e)=1/e。
- **作商比大小：aᵃbᵇ ≥ aᵇbᵃ**
  - a,b>0；等号 ⟺ a=b
  - 两边都是正的乘幂，作商比作差方便
  - 条件：a,b>0
  - 由来（简短复习）：作商：(aᵃbᵇ)/(aᵇbᵃ)=(a/b)^(a−b)。a>b 时底>1、指数>0，商>1；a<b 时底<1、指数<0，商>1；a=b 时商=1。分母为正，所以商 ≥1 就说明 aᵃbᵇ≥aᵇbᵃ。
- **异向不等式可减**
  - a>b，c<d ⇒ a−c > b−d
  - ⚠ 同向不等式不能相减：5>4，3>0，但 5−3=2 < 4−0=4
  - 由来（简短复习）：作差：(a−c)−(b−d)=(a−b)+(d−c)。a>b 给出 a−b>0，c<d 给出 d−c>0，两个正数相加仍为正。
- **异向正数不等式可除**
  - a>b>0，c>d>0 ⇒ a/d > b/c
  - ⚠ 同向正数不等式不能相除：4>3，4>1，但 4/4=1 < 3/1=3
  - 条件：a>b>0；c>d>0
  - 由来（简短复习）：c>d>0 取倒数得 1/d>1/c>0（正数倒数反序）；再与 a>b>0 相乘（同向正数不等式可乘），得 a/d>b/c。
- **解一元二次不等式**
  - ① 化成二次项系数 >0（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写出解集
  - 含参时：依次讨论二次项系数的符号、Δ 的符号、两根的大小
  - 由来（简短复习）：二次项系数为负时，两边乘 −1 化成正（不等号反向）。a>0 时抛物线开口向上：两根之外函数值为正、两根之间为负，所以 >0 的解集在两根之外、<0 的解集在两根之间；Δ<0 时函数值恒为正。
- **分式不等式**
  - f(x)/g(x) > 0 ⟺ f(x)·g(x) > 0
  - f(x)/g(x) ≥ 0 ⟺ f(x)·g(x) ≥ 0 且 g(x) ≠ 0
  - 有理式可化整式后用穿根法；始终保留原定义域禁点
  - 由来（简短复习）：两边乘以 g(x)²（g(x)≠0 时它是正数，不等号不变）：f/g>0 ⟺ f·g>0；“≥0”时还要单独保证分母不为 0。
- **高次不等式（穿根法）**
  - 化为 (x−x₁)(x−x₂)…(x−xₙ) > 0（各因式 x 的系数为正）
  - 无实根的因式（如 x²+x+1）先判断符号，恒正就约去
  - 数轴上标根，从最右边上方开始依次穿线
  - 奇次重根穿过，偶次重根不穿；解 >0 时所有根都不取（偶次根处也要挖去），解 ≥0 时根都取上
  - 由来（简短复习）：每个因式 x−xᵢ 在 xᵢ 右边为正、左边为负；乘积的正负由负因式的个数决定。所以从最右边（全为正）开始，每经过一个根就变一次号；偶次重根相当于变两次号，等于不变。
- **绝对值不等式的解法（a>0）**
  - |x|<a ⟺ −a<x<a；|x|>a ⟺ x<−a 或 x>a
  - |f(x)|<g(x) ⟺ −g(x)<f(x)<g(x)
  - 多个绝对值：按零点分段讨论
  - 例：|x−1|+|x+2| ≥ 5，分 x<−2、−2≤x≤1、x>1 三段 ⇒ x ≤ −3 或 x ≥ 2
  - 由来（简短复习）：|x|<a 表示数轴上到原点距离小于 a 的点，即 −a<x<a；|x|>a 表示距离大于 a，即 x<−a 或 x>a。几个绝对值时，按每个绝对值里式子为 0 的点分段，每段去掉绝对值再解。
- **指数、对数不等式**
  - a>1：aᶠ⁽ˣ⁾ > aᵍ⁽ˣ⁾ ⟺ f(x) > g(x)；0<a<1 时不等号反向
  - logₐf(x) > logₐg(x)：先保证 f(x)>0、g(x)>0（定义域优先）
  - 再按底数 a>1 或 0<a<1 去掉对数
  - 条件：定义域内
  - 由来（简短复习）：a>1 时 y=aˣ、y=logₐx 是增函数，0<a<1 时是减函数；增函数比较函数值就是比较自变量，减函数方向相反。对数还要求真数为正。
- **一元二次方程根的分布（a>0；重根算两个根）**
  - 两根都大于 k ⟺ Δ ≥ 0，−b/(2a) > k，f(k) > 0
  - 一根大于 k、一根小于 k ⟺ f(k) < 0
  - 两根都在 (m,n) 内 ⟺ Δ ≥ 0，m < −b/(2a) < n，f(m) > 0，f(n) > 0
  - 条件：a>0
  - 由来（简短复习）：a>0 时抛物线开口向上。“两根都大于 k”：先要有两根（Δ≥0），对称轴在 k 的右边，且 x=k 处函数值为正（k 在两根外侧）。f(k)<0 说明 x=k 处在 x 轴下方，k 一定在两根之间。
- **不等式组与解集**
  - 不等式组（各式同时成立）：分别解出，再取交集
  - “或”连接（满足其一即可）：取并集
  - 解集写成集合或区间：如 {x | x<−1 或 x>2} = (−∞,−1)∪(2,+∞)
  - 数轴上画出各解集，公共部分就是交集；端点取到画实心点，取不到画空心点
  - 由来（简短复习）：“同时成立”就是属于每一个解集，所以取交集；“满足其一”就是属于某一个解集，所以取并集。
- **根式（无理）不等式的解法**
  - √f(x) > g(x) ⟺ {f(x) ≥ 0 且 g(x) < 0} 或 {g(x) ≥ 0 且 f(x) > g(x)²}
  - √f(x) < g(x) ⟺ f(x) ≥ 0 且 g(x) > 0 且 f(x) < g(x)²
  - 先查定义域 f(x) ≥ 0；只有两边都非负时才能平方
  - （新教材不作要求，老题常见）
  - 条件：定义域内
  - 由来（简短复习）：√f(x)≥0。右边 g(x)<0 时 √f(x)>g(x) 自动成立（只要 f(x)≥0 有意义）；g(x)≥0 时两边都非负，平方不改变方向，化成 f(x)>g(x)²。
- **用单调性去掉 f**
  - f 在区间 I 上递增，a、b∈I：f(a)<f(b) ⟺ a<b
  - f 在区间 I 上递减：f(a)<f(b) ⟺ a>b（不等号反向）
  - 先查：a、b 都要在定义域内，且在同一个单调区间里
  - 条件：同一单调区间
  - 由来（简短复习）：设 f 递增、f(a)<f(b)，假设 a≥b：a=b 时 f(a)=f(b)，a>b 时 f(a)>f(b)，都和 f(a)<f(b) 矛盾，所以 a<b。递减时同理，方向相反。
- **奇偶性 + 单调性解不等式（抽象函数）**
  - 偶函数、在 [0,+∞) 上递增：f(a)<f(b) ⟺ |a|<|b|
  - 奇函数、在 ℝ 上递增：f(a)+f(b)<0 ⟺ f(a)<f(−b) ⟺ a<−b
  - 例：f 为偶函数且在 [0,+∞) 上递增，f(x−1)<f(2x) ⟺ |x−1|<|2x| ⟺ x<−1 或 x>1/3
  - 先查：定义域；偶函数先化成 f(|·|) 再比较，别漏掉负的那一半
  - 条件：f 有奇偶性且单调
  - 由来（简短复习）：偶函数 f(a)=f(|a|)，两边都化到 [0,+∞) 上，再用单调性去掉 f，得 |a|<|b|；奇函数 −f(b)=f(−b)，化成 f(a)<f(−b)，再去掉 f。
- **构造函数（抽象函数；在同一区间内可导）**
  - f′+f>0 ⇒ eˣf(x) 递增；f′−f>0 ⇒ f(x)/eˣ 递增
  - xf′+f>0 ⇒ xf(x) 递增；xf′−f>0（x>0）⇒ f(x)/x 递增
  - 看到 f′ 与 f 的组合，就把它们凑成某个积或商的导数
  - 条件：定义域内
  - 由来（简短复习）：例如 (eˣf(x))′=eˣ(f′(x)+f(x))，eˣ>0，所以 f′+f>0 时导数为正，eˣf(x) 递增；(f(x)/x)′=(xf′−f)/x² 等其余几种同理，都是积、商的求导法则。
- **同向不等式可加**
  - a≥b, c≥d ⇒ a+c ≥ b+d
  - 由来（简短复习）：作差：(a+c)−(b+d)=(a−b)+(c−d)，两项都 ≥0，加起来也 ≥0。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
