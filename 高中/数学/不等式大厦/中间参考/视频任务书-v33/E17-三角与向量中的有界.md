# E17｜三角与向量中的有界：asinθ+bcosθ

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：三角函数有界；向量形式的柯西（任意向量）；向量三角不等式（任意向量）

## 这一集要讲明白的一件事
把 asinθ+bcosθ 看成两个向量的数量积，最大值就是两个向量长度之积。

## 开场问题（不依赖其他集）
3sinθ+4cosθ 最大是多少？sin²θ+cos²θ=1 是一个现成的定值，可以借它求最值。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **向量部分的字母**：向量结论里的 a、b 表示向量（视频中改写成 u、v），θ 表示两向量的夹角（改写成 α），与前面三角函数里的 a、b、θ 无关。
- **向量的模**：u·u=|u|²；u·v=|u||v|cosα，|cosα|≤1。
- **平方后开方**：若 M≥0 且 X²≤M²，则 |X|≤M，即 −M≤X≤M。理由：若 |X|>M≥0，两边都非负，平方得 X²>M²，矛盾。
- **a²+b² ≥ 2ab**
  - 等号 ⟺ a=b
  - 由来（简短复习）：由“平方非负”，(a−b)²≥0；展开得 a²−2ab+b²≥0，移项得 a²+b²≥2ab。等号 ⟺ a−b=0，即 a=b。
- **柯西不等式（二项）**
  - (a²+b²)(c²+d²) ≥ (ac+bd)²
  - 等号 ⟺ ad=bc
  - 由来（简短复习）：由“平方非负”，(ad−bc)²≥0，展开得 a²d²+b²c²≥2abcd；两边同加 a²c²+b²d²：左边是 (a²+b²)(c²+d²)，右边是 (ac+bd)²。等号 ⟺ ad−bc=0。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **a²+b² ≥ 2ab → 三角有界（a²+b²≥2ab 的应用）**（提供前提）
   - 【前提】a²+b² ≥ 2ab
2. **柯西不等式（二项） → 三角有界（柯西应用）**（提供前提）
   - 【前提】柯西不等式（二项）
3. **三角有界（柯西应用） → 三角函数有界**（推导）
   - 【取等】a,b 不全为 0 时，点 (a/√(a²+b²), b/√(a²+b²)) 在单位圆上
   - 取 sinθ、cosθ 等于它（或它的相反数）即达到 ±√(a²+b²)；a=b=0 时恒为 0
4. **正余弦有界 → 三角函数有界**（提供前提）
   - 【前提】|sin(θ+φ)| ≤ 1
5. **正余弦有界 → 向量形式的柯西（任意向量）**（推导；含 2 个小步骤，逐个展开）
   - 【零向量】任一为零时两边为 0
   - 【非零向量】a·b=|a||b|cosθ，|cosθ|≤1
   - 等号 ⇔ |cosθ|=1，即两向量共线；连同零向量的情形，就是对应成比例
6. **向量形式的柯西（任意向量） → 向量三角不等式（任意向量）**（推导）
   - 【展开法】|a+b|² = |a|²+2a·b+|b|² ≤ |a|²+2|a||b|+|b|² = (|a|+|b|)²
   - 下界同理用 a·b ≥ −|a||b|；两边非负，开平方

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 正余弦有界
- −1 ≤ sinθ ≤ 1，−1 ≤ cosθ ≤ 1
- ⇐ 工具 ⑱ 勾股恒等式：sin²θ=1−cos²θ ≤ 1 ⇒ |sinθ|≤1，同理 |cosθ|≤1

#### 三角有界（a²+b²≥2ab 的应用）
- sin²θ+cos²θ ≥ 2sinθcosθ
- 即 1 ≥ sin2θ
- ⇐ 工具 ⑱ 勾股恒等式：【代入消元】sin²θ+cos²θ=1 代入 a²+b²≥2ab
- ⇐ 工具 ㉑ 倍角公式：㉑ 2sinθcosθ = sin2θ

#### 三角有界（柯西应用）
- (sin²θ+cos²θ)(a²+b²) ≥ (asinθ+bcosθ)²
- 即 asinθ+bcosθ ≤ √(a²+b²)
- ⇐ 工具 ⑱ 勾股恒等式：【代入消元】sin²θ+cos²θ=1 代入柯西二项

#### 三角函数有界
- θ 取遍实数时：asinθ+bcosθ 的最大值 = √(a²+b²)，最小值 = −√(a²+b²)
- a,b 不全为 0：最大值在 sinθ=a/√(a²+b²)，cosθ=b/√(a²+b²) 时取到；a=b=0 时恒为 0
- θ 只在某个区间内：最大值不一定取得到，要看端点和导数为 0 的点
- ⇐ 工具 ㉒ 辅助角公式：用㉒化为 √(a²+b²)·sin(θ+φ)，|sin|≤1 得最大值

#### 向量形式的柯西（任意向量）
- |a·b| ≤ |a||b|，等号 ⟺ a、b 共线（含零向量）
- 坐标形式：|x₁x₂+y₁y₂| ≤ √(x₁²+y₁²)·√(x₂²+y₂²)（即二项柯西）
- ⇐ 工具 ㊶ 向量数量积：㊶ 数量积的两种表示

#### 向量三角不等式（任意向量）
- ||a|−|b|| ≤ |a+b| ≤ |a|+|b|
- 右边等号 ⟺ 同向或有零向量；左边等号 ⟺ 反向或有零向量
- 坐标形式（闵可夫斯基）：√(x₁²+y₁²) + √(x₂²+y₂²) ≥ √((x₁+x₂)² + (y₁+y₂)²)

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑱ 勾股恒等式；sin²θ+cos²θ = 1
- ㉑ 倍角公式；sin2α=2sinαcosα；cos2α=cos²α−sin²α=2cos²α−1
- ㉒ 辅助角公式；a,b 不全为 0：asinθ+bcosθ = √(a²+b²)·sin(θ+φ)；其中 cosφ = a/√(a²+b²)，sinφ = b/√(a²+b²)；a=b=0 时原式恒为 0
- ㊶ 向量数量积：a·b=x₁x₂+y₁y₂；两向量非零时：a·b=|a||b|cosθ；有零向量时数量积为 0，不定义夹角

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 单位圆上一点 (sinθ, cosθ) 转动，与固定向量 (a,b) 的数量积随之变化，转到同向时最大、反向时最小。
- 辅助角公式：把 a、b 写成 √(a²+b²)·cosφ、√(a²+b²)·sinφ，合成一个正弦。

## 解题思维导向（片尾一句话）

## 易错点与边界（必须讲到）
- θ 只能在某个区间内取值时，最大值不一定取得到，要看端点。
- a=b=0 时恒为 0。
- 向量三角不等式：右边等号 ⟺ 同向或有零向量；左边等号 ⟺ 反向或有零向量。
