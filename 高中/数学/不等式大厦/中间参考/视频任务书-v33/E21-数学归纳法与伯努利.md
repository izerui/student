# E21｜数学归纳法与伯努利不等式

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：伯努利不等式

## 这一集要讲明白的一件事
归纳法 = 奠基 + 递推；伯努利不等式的递推步里，条件 x≥−1 出现在“乘以 1+x”的那一刻。

## 开场问题（不依赖其他集）
(1+x)ⁿ≥1+nx 对所有正整数 n 都成立吗？n 有无穷多个，一个个验证不完——用数学归纳法。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **乘非负数**：a≥b、c≥0 ⇒ ac−bc=(a−b)c≥0，方向不变。
- **取等条件的由来**：n=1 时两边恒相等；n≥2 时，递推的最后一步丢掉了 kx²，要取等必须 kx²=0，即 x=0。
- **平方非负**
  - x² ≥ 0
  - 等号 ⟺ x=0
  - 由来（简短复习）：x>0 时，x·x 是两个正数相乘，为正；x<0 时，−x>0，x²=(−x)·(−x) 也是两个正数相乘，为正；x=0 时 x²=0。三种情况合起来：x²≥0，只有 x=0 时等号成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【工具】数学归纳法 → n=1：(1+x)¹ = 1+x ≥ 1+x ✓**（推导）
   - 【归纳法·奠基】验证 n=1
2. **n=1：(1+x)¹ = 1+x ≥ 1+x ✓ → 归纳步：(1+x)^{k+1}**（推导）
   - ▼ 加条件：x≥−1
   - 【归纳法·递推】设 n=k 成立，证 n=k+1
3. **平方非负 → 归纳步：(1+x)^{k+1}**（提供前提；含 2 个小步骤，逐个展开）
   - 【前提】kx²≥0（平方非负）
   - 【放缩】去掉 kx² 这一项
4. **归纳步：(1+x)^{k+1} → 伯努利不等式**（推导）
   - 【归纳法】奠基+递推 ⇒ 对所有正整数 n 成立

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【工具】数学归纳法
- P(1)成立 且 P(k)⇒P(k+1)
- 起点：证明原理，由自然数的性质保证

#### n=1：(1+x)¹ = 1+x ≥ 1+x ✓

#### 归纳步：(1+x)^{k+1}
- = (1+x)^k·(1+x)
- ≥ (1+kx)(1+x)   ←归纳假设，且需 1+x≥0（即 x≥−1）
- = 1+(k+1)x+kx²
- ≥ 1+(k+1)x       ←kx²≥0

#### 伯努利不等式
- (1+x)ⁿ ≥ 1+nx
- x≥−1, n为正整数
- 等号 ⟺ x=0 或 n=1
- ⇐ 工具 ⑧ 二项式定理：另一证法（只适用于 x≥0）： (1+x)ⁿ = 1+nx+C(n,2)x²+…+xⁿ 后面各项 ≥0，去掉后 ≥ 1+nx

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑧ 二项式定理（n 为非负整数）；(a+b)ⁿ = Σₖ₌₀ⁿ C(n,k)aⁿ⁻ᵏbᵏ

- 乘以 1+x 那一步停顿，▼ 标出必须 1+x≥0。

## 解题思维导向（片尾一句话）
含正整数 n 的不等式 → 奠基 + 递推。

## 易错点与边界（必须讲到）
- x≥−1 是递推步需要的条件（乘以 1+x 时不变号）；x<−1 时结论不一定成立：x=−4、n=3 时左边 (−3)³=−27，右边 1−12=−11，不成立。
- 取等 ⟺ x=0 或 n=1。
