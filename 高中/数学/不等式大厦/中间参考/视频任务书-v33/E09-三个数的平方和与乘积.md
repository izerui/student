# E09｜三个数：平方和、交叉积与乘积

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：a²+b²+c² ≥ ab+bc+ca；(a+b+c)² ≥ 3(ab+bc+ca)；(a+b)(b+c)(c+a) ≥ 8abc；a³+b³ ≥ ab(a+b)（a+b ≥ 0）；a³ + b³ + c³ ≥ 3abc（a+b+c ≥ 0）

## 这一集要讲明白的一件事
把两数的结论推广到三个数：三组配对相加，或三组相乘；三个立方的和还能因式分解，得到 a³+b³+c³≥3abc。

## 开场问题（不依赖其他集）
三个数 a、b、c：a²+b²+c² 与 ab+bc+ca 谁大？(a+b)(b+c)(c+a) 与 8abc 呢？办法是两两配对。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **乘积取等“至少两个为 0”的由来**：若 a=0，左边=bc(b+c)，右边=0；取等 ⟺ bc(b+c)=0 ⟺ b、c 中至少一个为 0。a,b,c 都为正时，三个基本不等式同时取等 ⟺ a=b=c。
- **(a−b)² ≥ 0**
  - 由来（简短复习）：(a−b)² 是一个实数的平方，由“平方非负”，它 ≥0；当且仅当 a=b 时等于 0。
- **a²+b² ≥ 2ab**
  - 等号 ⟺ a=b
  - 由来（简短复习）：由“平方非负”，(a−b)²≥0；展开得 a²−2ab+b²≥0，移项得 a²+b²≥2ab。等号 ⟺ a−b=0，即 a=b。
- **基本不等式 (AM≥GM)**
  - (a+b)/2 ≥ √(ab)
  - a,b ≥ 0；等号 ⟺ a=b
  - ⚠️ 一正二定三相等：“一正”（各项 ≥0）是定理成立的条件；“二定”（和或积为定值）、“三相等”（等号能取到）是用它求最值时还要查的
  - 条件：a,b≥0
  - 由来（简短复习）：u,v≥0 时，由“平方非负”，(√u−√v)²≥0；展开得 u−2√(uv)+v≥0，即 u+v≥2√(uv)，两边除以 2。把 u、v 记作 a、b 即得。等号 ⟺ √a=√b ⟺ a=b。
- **同向非负不等式可乘**
  - a≥b≥0，c≥d≥0 ⇒ ac≥bd
  - 若 a>b≥0 且 c>d≥0，则 ac>bd
  - 条件：a≥b≥0；c≥d≥0
  - 由来（简短复习）：作差：ac−bd=(a−b)c+b(c−d)。a−b≥0、c≥0，所以 (a−b)c≥0；b≥0、c−d≥0，所以 b(c−d)≥0；两项相加 ≥0。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **(a−b)² ≥ 0 → a³+b³ ≥ ab(a+b)（a+b ≥ 0）**（推导；含 3 个小步骤，逐个展开）
   - ▼ 加条件：a+b≥0
   - 【配凑法】(a+b)²−4ab = (a−b)² ≥ 0 ⇒ (a+b)² ≥ 4ab
   - 【同乘法】两边乘 a+b ≥ 0：(a+b)³ ≥ 4ab(a+b)
   - 【代换法】由⑩：a³+b³ = (a+b)³−3ab(a+b) ≥ ab(a+b)
2. **a²+b² ≥ 2ab → 三组配对，各用 a²+b²≥2ab：**（推导）
   - 【配凑法】分三组
   - (a,b)(b,c)(a,c)
   - 各用 a²+b²≥2ab
3. **三组配对，各用 a²+b²≥2ab： → a²+b²+c² ≥ ab+bc+ca**（推导；含 2 个小步骤，逐个展开）
   - 【逐项相加】三式相加
   - 三组配对求和
   - 2(a²+b²+c²) ≥ 2(ab+bc+ca)
   - 【同除法】两边 ÷2
4. **基本不等式 (AM≥GM) → (a+b)(b+c)(c+a) ≥ 8abc**（推导；含 2 个小步骤，逐个展开）
   - ▼ 进入正数域：要求 a,b,c≥0（三个不等式两边都非负才能相乘）
   - 【分组代入】三对
   - (a,b)(b,c)(c,a)
   - 各用 AM≥GM
   - 三对分别用 AM≥GM：
   - a+b ≥ 2√(ab)
   - b+c ≥ 2√(bc)
   - c+a ≥ 2√(ca)
   - 【逐项相乘】三式相乘
   - 右边 2³·√(a²b²c²)=8abc
5. **同向非负不等式可乘 → (a+b)(b+c)(c+a) ≥ 8abc**（提供前提）
   - 【前提】同向非负不等式可乘：三个同向不等式相乘（允许为 0；有 0 时单独判断等号）
6. **a²+b²+c² ≥ ab+bc+ca → a³ + b³ + c³ ≥ 3abc（a+b+c ≥ 0）**（推导；含 2 个小步骤，逐个展开）
   - ▼ 加条件：a+b+c≥0
   - 【因式分解】a³+b³+c³−3abc = (a+b+c)(a²+b²+c²−ab−bc−ca)
   - 【同号相乘】a+b+c ≥ 0，且 a²+b²+c² ≥ ab+bc+ca ⇒ 乘积 ≥ 0
7. **a²+b²+c² ≥ ab+bc+ca → (a+b+c)² ≥ 3(ab+bc+ca)**（推导；含 2 个小步骤，逐个展开）
   - 【代换法】由⑪：(a+b+c)² = a²+b²+c² + 2(ab+bc+ca)
   - 【放缩法】a²+b²+c² ≥ ab+bc+ca
   - ⇒ (a+b+c)² ≥ 3(ab+bc+ca)

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 三组配对，各用 a²+b²≥2ab：
- a²+b²≥2ab
- b²+c²≥2bc
- a²+c²≥2ac

#### a²+b²+c² ≥ ab+bc+ca
- 等号 ⟺ a=b=c

#### (a+b+c)² ≥ 3(ab+bc+ca)
- 等号 ⟺ a=b=c
- ⇐ 工具 ⑪ a²+b²+c² = (a+b+c)²−2(ab+bc+ca)：⑪ 平方和与交叉积互换

#### (a+b)(b+c)(c+a) ≥ 8abc
- a,b,c ≥ 0；等号 ⟺ a=b=c，或至少两个数为 0

#### a³+b³ ≥ ab(a+b)（a+b ≥ 0）
- 等号 ⟺ a=b 或 a+b=0
- （a,b>0 时最常用）
- ⇐ 工具 ⑩ a³+b³ = (a+b)³−3ab(a+b)：⑩ a³+b³ = (a+b)³−3ab(a+b)
- ⇐ 工具 ③ 立方和公式：另一证法（作差）： a³+b³−ab(a+b) = (a+b)(a²−ab+b²−ab) = (a+b)(a−b)² ≥ 0

#### a³ + b³ + c³ ≥ 3abc（a+b+c ≥ 0）
- 等号 ⟺ a=b=c 或 a+b+c=0
- （a,b,c ≥ 0 时最常用）

## 用到的公式工具（片中写出公式即可，不展开推导）
- ③ 立方和公式；a³+b³ = (a+b)(a²−ab+b²)
- ⑩ a³+b³ = (a+b)³−3ab(a+b)；（立方和与积的互换）
- ⑪ a²+b²+c² = (a+b+c)²−2(ab+bc+ca)；（三元平方和与交叉积的互换）

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 三条边 a、b、c 两两配对的轮换动画：三个 a²+b²≥2ab 依次出现，再竖着相加。
- (a+b)(b+c)(c+a) ≥ 8abc：三个因子各自用基本不等式，再把三个不等式相乘。

## 着重标注（本集必须突出的地方）
- 三组配对用三种颜色区分，相加或相乘时颜色一一对应。
- 相乘前“各式两边非负”标出；取等条件“至少两个为 0”单独标出。

## 解题思维导向（片尾一句话）
三元对称式 → 两两配对，三式相加或相乘。

## 易错点与边界（必须讲到）
- 三式相乘要求各式两边非负；有 0 时取等条件要单独判断（至少两个为 0 也取等）。
- a³+b³ ≥ ab(a+b) 只需 a+b≥0，不必每个都正。
- a³+b³+c³ ≥ 3abc 只需 a+b+c≥0；取等是 a=b=c 或 a+b+c=0，后者别漏。
