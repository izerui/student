# E15｜柯西不等式（二项）与柯西分式

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：柯西不等式（二项）；柯西分式；1/x + 1/y ≥ 4/(x+y)

## 这一集要讲明白的一件事
柯西不等式同样从“平方非负”出发：(ad−bc)² ≥ 0，配凑后就是 (a²+b²)(c²+d²) ≥ (ac+bd)²。

## 开场问题（不依赖其他集）
(a²+b²)(c²+d²) 与 (ac+bd)² 谁大？办法和证明 a²+b²≥2ab 一样：找一个平方。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **a²+b²≥2ab**：(a−b)²≥0，展开得 a²−2ab+b²≥0，移项即得。
- **向量视角（画面要用）**：设向量 u=(a,b)、v=(c,d)，则 u·v=ac+bd=|u||v|cosθ，|u|=√(a²+b²)，|v|=√(c²+d²)；因为 |cosθ|≤1，得 (ac+bd)²≤(a²+b²)(c²+d²)，两向量共线时取等。
- **柯西分式的取等**：由二项柯西的取等 ad=bc：(r/√u)·√v=(s/√v)·√u，两边乘 √u·√v，得 rv=su。
- **平方非负**
  - x² ≥ 0
  - 等号 ⟺ x=0
  - 由来（简短复习）：x>0 时，x·x 是两个正数相乘，为正；x<0 时，−x>0，x²=(−x)·(−x) 也是两个正数相乘，为正；x=0 时 x²=0。三种情况合起来：x²≥0，只有 x=0 时等号成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **平方非负 → (ad−bc)² ≥ 0**（推导）
   - 【代换法】令 x = ad−bc
2. **(ad−bc)² ≥ 0 → a²d²−2abcd+b²c² ≥ 0**（推导）
   - 【展开法】展开平方
3. **a²d²−2abcd+b²c² ≥ 0 → a²d²+b²c²+(ac+bd)²**（推导；含 2 个小步骤，逐个展开）
   - 【移项】两边 +2abcd
   - 【配凑】再两边 +(ac+bd)²
4. **a²d²+b²c²+(ac+bd)² → a²c²+a²d²+b²c²+b²d² ≥ (ac+bd)²**（推导）
   - 【展开法】展开左边新增的平方
   - 左右两边的 +2abcd 相互抵消
5. **a²c²+a²d²+b²c²+b²d² ≥ (ac+bd)² → 柯西不等式（二项）**（推导）
   - 【提公因式】左边提取公因式
   - = (a²+b²)(c²+d²)
6. **柯西不等式（二项） → 柯西分式**（推导；含 3 个小步骤，逐个展开）
   - ▼ 进入正数域：u,v>0；r,s不限正负
   - 【代入特定值】令 a=r/√u, b=s/√v, c=√u, d=√v
   - 【代入消元】代入柯西二项：(r²/u+s²/v)(u+v) ≥ (r+s)²
   - 【同除法】两边 ÷(u+v)
7. **柯西分式 → 1/x + 1/y ≥ 4/(x+y)**（推导）
   - 【代入特定值】令 r=s=1
   - 1²/x+1²/y ≥ (1+1)²/(x+y)

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### (ad−bc)² ≥ 0

#### a²d²−2abcd+b²c² ≥ 0
- ⇐ 工具 ② 完全平方公式：用②展开 (ad−bc)²

#### a²d²+b²c²+(ac+bd)²
- ≥ (ac+bd)²+2abcd
- （两边加 (ac+bd)² 后展开）

#### a²c²+a²d²+b²c²+b²d² ≥ (ac+bd)²

#### 柯西不等式（二项）
- (a²+b²)(c²+d²) ≥ (ac+bd)²
- 等号 ⟺ ad=bc

#### 柯西分式
- r²/u + s²/v ≥ (r+s)²/(u+v)
- u,v>0；等号 ⟺ rv=su

#### 1/x + 1/y ≥ 4/(x+y)
- x,y>0；等号 ⟺ x=y

## 用到的公式工具（片中写出公式即可，不展开推导）
- ② 完全平方公式；(a±b)² = a²±2ab+b²

## 解题思维导向（片尾一句话）
看到“平方和 × 平方和”或“和的平方” → 想柯西；分式和、分母的和固定 → 想柯西分式。

## 易错点与边界（必须讲到）
- 取等写成 ad=bc，不要写成 a/c=b/d（分母可能为 0）。
- 柯西分式要求分母为正，分子可以是任意实数。
