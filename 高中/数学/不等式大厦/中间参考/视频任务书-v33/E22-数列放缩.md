# E22｜数列放缩：裂项、根式裂项、对数放缩、等比放缩

- 建议时长：7–9 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：裂项放缩；更紧的裂项；根式裂项；根式裂项（下界）；对数放缩求和；等比放缩（aₖ>0）

## 这一集要讲明白的一件事
求不出和时，把每一项放大或缩小成能求和（能相消）的形式；放得越少、越晚，界越紧；同一个和也能从下面夹住。

## 开场问题（不依赖其他集）
1+1/2²+1/3²+…+1/n² 求不出和，但能证明它小于 2。办法：把每一项放大成能前后相消的形式。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **求导与单调性**：(ln x)′=1/x；在一个区间上导数为负，函数递减，导数为正，函数递增。
- **根式比较**：0≤k−1<k，所以 √(k−1)<√k，于是 √k+√(k−1)<2√k。
- **同向不等式可加**
  - a≥b, c≥d ⇒ a+c ≥ b+d
  - 由来（简短复习）：作差：(a+c)−(b+d)=(a−b)+(c−d)，两项都 ≥0，加起来也 ≥0。
- **正数乘法保序**
  - a>b, c>0 ⇒ ac > bc
  - 条件：a,b∈ℝ；c>0
  - 由来（简短复习）：a>b 即 a−b>0；c>0 时，(a−b)c 是两个正数相乘，为正，即 ac−bc>0，所以 ac>bc。
- **ln x ≤ x−1（x>0）**
  - 等号 ⟺ x=1
  - 条件：x>0
  - 由来（简短复习）：构造 g(x)=x−1−ln x（x>0），g′(x)=1−1/x：0<x<1 时 g′<0，x>1 时 g′>0，所以 g 在 x=1 取最小值 g(1)=0，即 g(x)≥0。
- **ln x ≥ 1 − 1/x（x>0）**
  - 等号 ⟺ x=1
  - 条件：x>0
  - 由来（简短复习）：在 ln x≤x−1 中把 x 换成 1/x（x>0）：ln(1/x)≤1/x−1，即 −ln x≤1/x−1，所以 ln x≥1−1/x。
- **正数倒数反序**
  - 0<a<b ⇒ 1/a > 1/b
  - （一般地：ab>0 时，a>b ⇒ 1/a < 1/b）
  - 条件：0<a<b；一般式 ab>0
  - 由来（简短复习）：作差：1/a−1/b=(b−a)/(ab)。0<a<b 时分子 b−a>0、分母 ab>0，差为正，所以 1/a>1/b。一般地只要 ab>0（两数同号）同样成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **同向不等式可加 → 等比放缩（aₖ>0）**（推导；含 2 个小步骤，逐个展开）
   - ▼ 进入正数域：要求 aₖ>0、q>0
   - 【递推】aₖ ≤ a₁qᵏ⁻¹（反复用 aₖ₊₁ ≤ q·aₖ）
   - 【逐项相加】再用等比数列求和公式
2. **正数乘法保序 → 等比放缩（aₖ>0）**（提供前提）
   - ▼ 进入正数域：要求 aₖ>0、q>0
   - 【前提】乘以 q>0 不改变方向，递推得 aₖ ≤ a₁qᵏ⁻¹
3. **ln x ≤ x−1（x>0） → 对数放缩求和**（推导；含 2 个小步骤，逐个展开）
   - 【代换法】ln x ≤ x−1 中令 x=1+1/k：ln(1+1/k) < 1/k（x≠1，取不到等号）
   - 【逐项相加】左边 = ln(2/1)+ln(3/2)+…+ln((n+1)/n) = ln(n+1)
4. **ln x ≥ 1 − 1/x（x>0） → 对数放缩求和**（提供前提）
   - 【前提】令 x=1+1/k：ln(1+1/k) > 1 − k/(k+1) = 1/(k+1)
5. **正数倒数反序 → 裂项放缩**（推导；含 2 个小步骤，逐个展开）
   - 【倒数法】k² > k(k−1) > 0 ⇒ 1/k² < 1/(k(k−1))
   - 【裂项】1/(k(k−1)) = 1/(k−1) − 1/k，求和时中间项相消
6. **正数倒数反序 → 根式裂项**（推导；含 3 个小步骤，逐个展开）
   - 【倒数法】√k + √(k−1) < 2√k ⇒ 1/√k = 2/(2√k) < 2/(√k + √(k−1))
   - 【分母有理化】2/(√k + √(k−1)) = 2(√k − √(k−1))；【裂项】求和时中间项相消
7. **正数倒数反序 → 根式裂项（下界）**（推导；含 3 个小步骤，逐个展开）
   - 【倒数法】√(k+1) + √k > 2√k > 0 ⇒ 1/√k = 2/(2√k) > 2/(√(k+1) + √k)
   - 【分母有理化】2/(√(k+1) + √k) = 2(√(k+1) − √k)
   - 【裂项】求和时中间项相消，剩 2(√(n+1) − 1)
8. **裂项放缩 → 更紧的裂项**（推导；含 3 个小步骤，逐个展开）
   - 【放缩法】分母减得越少，放大得越少：k(k−1) < k²−1 < k²−1/4 < k²
   - 【裂项】1/(k²−1) = ½[1/(k−1) − 1/(k+1)]；4/(4k²−1) = 2[1/(2k−1) − 1/(2k+1)]
   - 【保留首项】k=2 起求和：前者 < ½(1 + ½) = 3/4，后者 < 2/3；再加首项 1

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 裂项放缩
- 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k（k≥2）
- n≥2：1 + 1/2² + … + 1/n² < 2 − 1/n < 2

#### 更紧的裂项
- 1/k² < 1/(k²−1) = ½[1/(k−1) − 1/(k+1)] ⇒ 1 + 1/2² + … + 1/n² < 7/4
- 1/k² < 4/(4k²−1) = 2[1/(2k−1) − 1/(2k+1)] ⇒ 1 + 1/2² + … + 1/n² < 5/3
- 两式都从 k=2 起放缩，首项 1 保留不放

#### 根式裂项
- 1/√k < 2(√k − √(k−1))（k ≥ 1）
- ⇐ 工具 ① 平方差公式：① 平方差：(√k + √(k−1))(√k − √(k−1)) = 1

#### 根式裂项（下界）
- 1/√k > 2(√(k+1) − √k)（k ≥ 1）

#### 对数放缩求和
- 1/(k+1) < ln(1+1/k) < 1/k（k 为正整数）
- ⇐ 工具 ⑮⑯ 对数运算律：ln(1+1/k) = ln((k+1)/k) = ln(k+1) − ln k 逐项相加时中间项相消

#### 等比放缩（aₖ>0）
- 若 aₖ₊₁ ≤ q·aₖ（0<q<1）
- 则 a₁+…+aₙ ≤ a₁(1−qⁿ)/(1−q) < a₁/(1−q)
- ⇐ 工具 ㉗㉘ 等比数列：等比数列求和公式

## 用到的公式工具（片中写出公式即可，不展开推导）
- ① 平方差公式；a²−b² = (a+b)(a−b)
- ⑮⑯ 对数运算律（底数 q>0 且 q≠1）；M,N>0：log_q(MN)=log_q M+log_q N；M>0，t∈ℝ：log_q(Mᵗ)=t log_q M
- ㉗㉘ 等比数列（n≥1；q≠0）；aₙ=a₁qⁿ⁻¹；q≠1：Sₙ=a₁(1−qⁿ)/(1−q)；q=1：Sₙ=na₁

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 阶梯面积：1/k² 的柱子都被 1/(k−1)−1/k 的柱子盖住，求和时中间项一对对相消（望远镜动画）。
- 同一个和三次放缩并排：放成 1/(k(k−1)) 得 <2，放成 1/(k²−1) 得 <7/4，放成 4/(4k²−1) 得 <5/3，界越来越紧。
- 等比放缩：每一项都被等比数列的对应项压住。

## 解题思维导向（片尾一句话）
求和放缩 → 裂项相消、等比放缩、对数放缩；注意从第几项开始放，别放过头。

## 易错点与边界（必须讲到）
- 裂项从 k≥2 开始，求和结论要求 n≥2，第一项单独留出。
- 放缩方向必须一致，前几项可以单独计算防止放过头。
- 根式裂项的上界和下界用的是不同的相邻项：上界用 √k 与 √(k−1)，下界用 √(k+1) 与 √k。
