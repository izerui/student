# E06｜基本不等式：(a+b)/2 ≥ √(ab)

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：基本不等式 (AM≥GM)

## 这一集要讲明白的一件事
两个非负数 u、v，把它们写成 (√u)²、(√v)²，由“平方非负” (√u−√v)²≥0 展开，就得到 u+v≥2√(uv)，再除以 2 就是基本不等式。开平方要求 u,v≥0，这是第一次加条件。

## 开场问题（不依赖其他集）
两个非负数 u、v，和的一半 (u+v)/2 与 √(uv) 谁大？关键一步：把 u、v 分别看成 (√u)²、(√v)²，然后用“平方非负”。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **根式运算**：u,v≥0 时 (√u)²=u，√u·√v=√(uv)。
- **平方非负**
  - x² ≥ 0
  - 等号 ⟺ x=0
  - 由来（简短复习）：x>0 时，x·x 是两个正数相乘，为正；x<0 时，−x>0，x²=(−x)·(−x) 也是两个正数相乘，为正；x=0 时 x²=0。三种情况合起来：x²≥0，只有 x=0 时等号成立。
  - 说明：本集直接从 (√u−√v)² ≥ 0 出发，只需要“平方非负”这一条基础

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **平方非负 → 和与几何平均的关系**（推导）
   - ▼ 进入正数域：u,v≥0（要对 u、v 开平方）
   - 【代换法】u,v≥0 时，u=(√u)²，v=(√v)²
   - 【平方非负】(√u−√v)² ≥ 0
   - 【展开】(√u)² − 2√u·√v + (√v)² ≥ 0，即 u − 2√(uv) + v ≥ 0
   - 【移项】u + v ≥ 2√(uv)
2. **和与几何平均的关系 → 基本不等式 (AM≥GM)**（推导）
   - 【同除法】两边 ÷2：(u+v)/2 ≥ √(uv)
   - 把 u、v 改记作 a、b：(a+b)/2 ≥ √(ab)（a,b≥0）
   - 【取等】等号 ⟺ (√a−√b)²=0 ⟺ √a=√b ⟺ a=b

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 和与几何平均的关系
- u+v ≥ 2√(uv)（u,v ≥ 0）

#### 基本不等式 (AM≥GM)
- (a+b)/2 ≥ √(ab)
- a,b ≥ 0；等号 ⟺ a=b
- ⚠️ 一正二定三相等：“一正”（各项 ≥0）是定理成立的条件；“二定”（和或积为定值）、“三相等”（等号能取到）是用它求最值时还要查的

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 半圆模型：直径被分成 a、b 两段，半径 (a+b)/2，分点处的半弦长 √(ab)，半径始终不短于半弦。拖动分点，看两者何时相等（分点在圆心时）。
- 代换动画：a → √u、b → √v，让观众看到为什么 u、v 必须 ≥0（负数开不了平方），▼ 分水岭在这一刻出现。

## 着重标注（本集必须突出的地方）
- 代换 a=√u、b=√v 这一步停顿：▼ 出现，说明为什么 u、v 必须 ≥0。
- “一正二定三相等”分两层写：一正是定理条件，二定三相等是求最值时要查的。

## 解题思维导向（片尾一句话）
看到两个非负数的和与积 → 想基本不等式；用它求最值前，先查一正二定三相等。

## 易错点与边界（必须讲到）
- “一正二定三相等”：一正（各项 ≥0）是定理成立的条件；二定、三相等是用它求最值时才要查的。
- 反例：a=b=−1 时左边 (a+b)/2=−1，右边 √(ab)=1，不等式不成立；a=−1、b=1 时 √(ab) 根本没有意义。所以条件不能丢。
