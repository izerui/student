# T05｜题型串讲：绝对值、几何与三角

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 |a+b| 或绝对值比大小
- 反推：三角不等式 ← −|x|≤x≤|x| 两式相加 ← 绝对值定义
- 差的形式 |a|−|b| 用反三角不等式
- 去这里查：
- ▸ 三角不等式
- ▸ 差的形式 → 反三角不等式
- **参考例题（已核对）**：|a|≤1，|b|≤2，求 |a+b| 的最大值：|a+b| ≤ |a|+|b| ≤ 3，a=1、b=2 时取到。

## 题型 2：看到 斜率型、距离型的式子
- (y−b)/(x−a)：点 (x,y) 与 (a,b) 连线的斜率；√((x−a)²+(y−b)²)：两点间距离
- |x−a|+|x−b|：数轴上到两点的距离和
- 画图后，最值通常在相切或连线与图形相交时取到
- 去这里查：
- ▸ 距离和 → 绝对值和的最小值
- ▸ 距离（三角不等式） → 向量三角不等式（任意向量）
- ▸ 线性目标 ax+by，约束是二元一次不等式组 → 简单线性规划（拓展）
- **参考例题（已核对）**：求 √(x²+1)+√((x−3)²+4) 的最小值：√(x²+1) 是 x 轴上的点 P(x,0) 到 (0,1) 的距离，√((x−3)²+4) 是 P 到 (3,2) 的距离，也等于 P 到其对称点 (3,−2) 的距离；(0,1) 与 (3,−2) 在 x 轴两侧，两点之间线段最短，最小值为 √(3²+3²)=3√2。

## 题型 3：看到 asinθ+bcosθ 求最值
- 反推：三角有界 ← 柯西二项代入 sin²θ+cos²θ=1（或辅助角公式）
- 结论：θ 取遍实数时，最大值 √(a²+b²)，最小值 −√(a²+b²)；a=b=0 时恒为 0
- 先查：θ 的范围；只在某个区间内时，看端点和导数为 0 的点，最值不一定取得到
- 去这里查：
- ▸ 三角函数有界
- **参考例题（已核对）**：3sinθ+4cosθ 的最大值 5、最小值 −5（θ 取遍实数）。

## 题型 4：看到 约束 x²+y²=r²（r≥0），求 ax+by 的最值
- 反推：三角换元 x=rcosθ, y=rsinθ → 化为 r(acosθ+bsinθ) → 三角有界
- 结论：最大值 r·√(a²+b²)（别漏乘 r）；也可直接用柯西：(x²+y²)(a²+b²) ≥ (ax+by)²
- 去这里查：
- ▸ 【三角换元】令 x=rcosθ，y=rsinθ，目标化为 asinθ+bcosθ 型 → 三角函数有界
- **参考例题（已核对）**：x²+y²=4，求 3x+4y 的最大值：令 x=2cosθ、y=2sinθ，得 2(3cosθ+4sinθ)，最大值 2×5=10。

## 题型 5：看到 三角形中求最值 / 范围
- 反推：余弦定理 a²=b²+c²−2bc·cosA → 配合 b²+c² ≥ 2bc 求 bc 或 cosA 的范围
- 或：正弦定理把边化为角 → 化成 asinθ+bcosθ 型 → 三角函数有界
- 先查：角的取值范围（如 0<A<π），等号能否在三角形中取到
- 去这里查：
- ▸ 余弦定理
- ▸ 或 正弦定理 → 正弦定理
- ▸ 再用 b²+c² ≥ 2bc → a²+b² ≥ 2ab
- **参考例题（已核对）**：△ABC 中 A=60°，a=2，求 bc 的最大值：4 = b²+c²−bc ≥ 2bc−bc = bc，b=c=2 时 bc=4。

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **数量积的范围**：a·b=|a||b|cosθ，且 |cosθ|≤1，所以 a·b≤|a||b|。
- **对称点与最短路径**：√((x−3)²+4) 是 x 轴上的点 (x,0) 到 (3,2) 的距离，也等于到它关于 x 轴的对称点 (3,−2) 的距离；(0,1) 和 (3,−2) 在 x 轴两侧，两点之间线段最短。
- **三角不等式**
  - |a+b| ≤ |a|+|b|
  - 等号 ⟺ ab ≥ 0
  - 由来（简短复习）：由绝对值的定义，−|a|≤a≤|a|，−|b|≤b≤|b|；两式相加得 −(|a|+|b|)≤a+b≤|a|+|b|，即 |a+b|≤|a|+|b|。a、b 同号（或有一个为 0）时取等。
- **反三角不等式**
  - ||a|−|b|| ≤ |a−b|
  - 等号 ⟺ ab ≥ 0
  - 由来（简短复习）：|a|=|(a−b)+b|≤|a−b|+|b|，所以 |a|−|b|≤|a−b|；同理 |b|−|a|≤|a−b|。两式合起来就是 ||a|−|b||≤|a−b|。
- **绝对值和的最小值**
  - |x−a|+|x−b| ≥ |a−b|
  - 几何意义：数轴上 x 到 a、b 的距离之和
  - 等号 ⟺ x 在 a、b 之间（含端点 a、b）；解“距离和 ≥ k”（k>|a−b|）：在两点外侧各找一个边界点
  - 由来（简短复习）：由三角不等式：|x−a|+|x−b|=|x−a|+|b−x|≥|(x−a)+(b−x)|=|a−b|；x 在 a、b 之间时两项同号，等号成立。
- **向量三角不等式（任意向量）**
  - ||a|−|b|| ≤ |a+b| ≤ |a|+|b|
  - 右边等号 ⟺ 同向或有零向量；左边等号 ⟺ 反向或有零向量
  - 坐标形式（闵可夫斯基）：√(x₁²+y₁²) + √(x₂²+y₂²) ≥ √((x₁+x₂)² + (y₁+y₂)²)
  - 由来（简短复习）：|a+b|²=|a|²+2a·b+|b|²≤|a|²+2|a||b|+|b|²=(|a|+|b|)²（因为 a·b≤|a||b|），两边都非负，开平方；左边同理用 a·b≥−|a||b|。
- **简单线性规划**
  - 约束条件：二元一次不等式组画出平面区域
  - 目标 z=ax+by（b≠0）：化为 y=−(a/b)x+z/b，在区域内平移这条直线
  - b>0 时直线越往上 z 越大，b<0 时相反；最值一般在区域的顶点处取到
  - 由来（简短复习）：直线 Ax+By+C=0 把平面分成两半：B>0 时，同一个 x 下 y 越大，Ax+By+C 越大，所以直线上方 >0。目标 z=ax+by 可看成一族平行直线，z 变化时直线平移。
- **三角函数有界**
  - θ 取遍实数时：asinθ+bcosθ 的最大值 = √(a²+b²)，最小值 = −√(a²+b²)
  - a,b 不全为 0：最大值在 sinθ=a/√(a²+b²)，cosθ=b/√(a²+b²) 时取到；a=b=0 时恒为 0
  - θ 只在某个区间内：最大值不一定取得到，要看端点和导数为 0 的点
  - 由来（简短复习）：由柯西：(sin²θ+cos²θ)(a²+b²)≥(asinθ+bcosθ)²，而 sin²θ+cos²θ=1，所以 |asinθ+bcosθ|≤√(a²+b²)；a,b 不全为 0 时，取 sinθ=a/√(a²+b²)、cosθ=b/√(a²+b²)（这两个数的平方和为 1，这样的 θ 存在），等号成立。
- **a²+b² ≥ 2ab**
  - 等号 ⟺ a=b
  - 由来（简短复习）：由“平方非负”，(a−b)²≥0；展开得 a²−2ab+b²≥0，移项得 a²+b²≥2ab。等号 ⟺ a−b=0，即 a=b。
- **余弦定理**
  - a² = b²+c²−2bc·cosA
  - （推广勾股定理；a、b、c 与 A 是同一个三角形的边和角）
  - 由来（简短复习）：解三角形的基本定理（课本已证）：在三角形中，边 a 的平方等于另两边平方和减去它们与夹角余弦乘积的 2 倍。
- **正弦定理**
  - a/sinA = b/sinB = c/sinC = 2R
  - （同一个三角形的对应边和角；R 为外接圆半径）
  - 由来（简短复习）：解三角形的基本定理（课本已证）：三角形中各边与对角正弦之比相等，都等于外接圆直径 2R。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
