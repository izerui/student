# E25｜拓展：舒尔不等式与 Nesbitt 不等式（拓展）

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：舒尔不等式（t=1 常用形式，a,b,c≥0）；Nesbitt 不等式

## 这一集要讲明白的一件事
舒尔：先排好大小，再判断每一项的符号；Nesbitt：每项加 1 凑公因式，再用三元均值。

## 开场问题（不依赖其他集）
三个变量的竞赛型不等式怎么证？舒尔不等式靠先排好大小再判断符号，Nesbitt 不等式靠每项加 1 凑出公因式。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **舒尔取等**：a=b=c 时每一项都为 0；两数相等、第三个为 0 时（如 a=b、c=0），代入后左边也为 0。
- **【公理】正数相乘**
  - 正数 × 正数 = 正数
  - 由来（简短复习）：这是实数的基本规定（公理），直接承认：两个正数相乘还是正数。
- **三元 AM≥GM（常用特例）**
  - (a+b+c)/3 ≥ ³√(abc)
  - a,b,c ≥ 0；等号 ⟺ a=b=c
  - 条件：a,b,c≥0
  - 由来（简短复习）：对 x,y,z≥0：x³+y³+z³−3xyz=½(x+y+z)[(x−y)²+(y−z)²+(z−x)²]（把右边展开即可验证），x+y+z≥0、方括号是平方和 ≥0，所以左边 ≥0；令 x=³√a、y=³√b、z=³√c，即得 (a+b+c)/3≥³√(abc)。
- **同向非负不等式可乘**
  - a≥b≥0，c≥d≥0 ⇒ ac≥bd
  - 若 a>b≥0 且 c>d≥0，则 ac>bd
  - 条件：a≥b≥0；c≥d≥0
  - 由来（简短复习）：作差：ac−bd=(a−b)c+b(c−d)。a−b≥0、c≥0，所以 (a−b)c≥0；b≥0、c−d≥0，所以 b(c−d)≥0；两项相加 ≥0。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【公理】正数相乘 → 由对称性不妨设 a≥b≥c≥0，t>0**（推导；含 2 个小步骤，逐个展开）
   - ▼ 进入正数域：a,b,c≥0；t>0
   - 【分类讨论】不妨设 a≥b≥c≥0
   - 【同号相乘】判断各因子符号
2. **由对称性不妨设 a≥b≥c≥0，t>0 → 前两项合并：(a−b)[aᵗ(a−c)−bᵗ(b−c)] ≥ 0**（推导；含 2 个小步骤，逐个展开）
   - 【分组】前两项合并、第三项单独
   - 【同号相乘】按各因子符号判断
3. **前两项合并：(a−b)[aᵗ(a−c)−bᵗ(b−c)] ≥ 0 → 舒尔不等式（t=1 常用形式，a,b,c≥0）**（推导）
   - 【合并整理】两部分都 ≥ 0，相加得证
   - 取 t=1 展开得常用形式
4. **三元 AM≥GM（常用特例） → Nesbitt 不等式**（推导；含 2 个小步骤，逐个展开）
   - ▼ 进入正数域：要求 a,b,c>0（排除负数，分母不能为 0）
   - 【配凑法】每项 +1：a/(b+c)+1 = (a+b+c)/(b+c)，记 S=a+b+c
   - 原式 = S·[1/(b+c)+1/(c+a)+1/(a+b)] − 3
   - 【放缩法】由三元 AM≥GM：(x+y+z)(1/x+1/y+1/z) ≥ 3∛(xyz)·3/∛(xyz) = 9
   - 取 x,y,z 为 b+c、c+a、a+b（和为 2S）⇒ Σ1/(b+c) ≥ 9/(2S)
   - ⇒ 原式 ≥ S·9/(2S) − 3 = 3/2
5. **同向非负不等式可乘 → Nesbitt 不等式**（提供前提）
   - ▼ 进入正数域：要求 a,b,c>0（排除负数，分母不能为 0）
   - 【前提】两个同向正数不等式相乘

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 由对称性不妨设 a≥b≥c≥0，t>0
- aᵗ(a−b)(a−c)+bᵗ(b−a)(b−c)+cᵗ(c−a)(c−b)

#### 前两项合并：(a−b)[aᵗ(a−c)−bᵗ(b−c)] ≥ 0
- （a−b≥0，a−c≥b−c≥0；aᵗ≥bᵗ：幂函数 xᵗ（t>0）在 x≥0 上递增）
- 第三项 cᵗ(c−a)(c−b) ≥ 0（两因子同号）

#### 舒尔不等式（t=1 常用形式，a,b,c≥0）
- a(a−b)(a−c)+b(b−a)(b−c)+c(c−a)(c−b) ≥ 0
- 即 a³+b³+c³+3abc ≥ ab(a+b)+bc(b+c)+ca(c+a)
- 等号 ⟺ a=b=c，或两数相等且第三个为 0

#### Nesbitt 不等式
- a/(b+c)+b/(a+c)+c/(a+b) ≥ 3/2
- a,b,c>0；等号 ⟺ a=b=c

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 舒尔：a≥b≥c 三个点放在数轴上，逐项标出各因子的正负。
- Nesbitt：三个分式各加 1，分子都变成 a+b+c 的动画。

## 解题思维导向（片尾一句话）
三元对称、带分式和 → 先排序或先凑公因式。

## 易错点与边界（必须讲到）
- 舒尔要求 a,b,c≥0；Nesbitt 要求 a,b,c>0。
- Nesbitt 真正要排除的是负数：a=b=1、c=−3 时左边 −1/2−1/2−3/2=−2.5<3/2；取一个 0 时其实仍成立（a=0 得 b/c+c/b ≥ 2），但分母不能为 0。
