# E12｜高次、分式不等式与不等式组

- 建议时长：6–7 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：高次不等式（穿根法）；分式不等式；根式（无理）不等式的解法；不等式组与解集

## 这一集要讲明白的一件事
把乘积的正负和数轴结合起来（穿根法），分式化成整式，根式先保证两边非负再平方；多个不等式取交集或并集。

## 开场问题（不依赖其他集）
(x−1)(x+2)(x−3)>0 怎么解？几个因式相乘，它的正负可以一段一段地判断。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **分母的平方为正**：g≠0 时 g²>0（平方非负，且只有 0 的平方等于 0）。
- **三个二次的关系（a>0）**：Δ>0：两根之外 ax²+bx+c>0，两根之间 <0；Δ=0：除根以外都 >0；Δ<0：恒 >0。理由：开口向上的抛物线与 x 轴的位置关系。
- **解一元二次不等式**
  - ① 化成二次项系数 >0（两边乘 −1，不等号反向）
  - ② 算 Δ、求根；③ 按三个二次的关系写出解集
  - 含参时：依次讨论二次项系数的符号、Δ 的符号、两根的大小
  - 由来（简短复习）：二次项系数为负时，两边乘 −1 化成正（不等号反向）。a>0 时抛物线开口向上：两根之外函数值为正、两根之间为负，所以 >0 的解集在两根之外、<0 的解集在两根之间；Δ<0 时函数值恒为正。
- **非负数平方保序**
  - 0 ≤ a < b ⇒ a² < b²
  - 反过来：a,b ≥ 0 时，a² < b² ⇒ a < b（可两边开平方）
  - 条件：a,b≥0
  - 由来（简短复习）：b²−a²=(b+a)(b−a)；0≤a<b 时，b+a>0、b−a>0，乘积为正，所以 a²<b²。反过来，若 a²<b² 且 a,b≥0，假设 a≥b，就会得到 a²≥b²，矛盾。
- **【公理】正数相乘**
  - 正数 × 正数 = 正数
  - 由来（简短复习）：这是实数的基本规定（公理），直接承认：两个正数相乘还是正数。
- **负数乘法反序**
  - a>b, c<0 ⇒ ac < bc
  - 条件：a,b∈ℝ；c<0
  - 由来（简短复习）：a−b>0，c<0 则 −c>0；(a−b)(−c) 是两个正数相乘，为正，即 bc−ac>0，所以 ac<bc。
- **正数乘法保序**
  - a>b, c>0 ⇒ ac > bc
  - 条件：a,b∈ℝ；c>0
  - 由来（简短复习）：a>b 即 a−b>0；c>0 时，(a−b)c 是两个正数相乘，为正，即 ac−bc>0，所以 ac>bc。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】集合与区间 → 不等式组与解集**（推导）
   - 【定义】同时成立 ⇔ 属于每个解集 ⇔ 属于交集
   - 满足其一 ⇔ 属于并集
2. **解一元二次不等式 → 不等式组与解集**（提供前提）
   - 【前提】每个不等式先单独求出解集
3. **非负数平方保序 → 根式（无理）不等式的解法**（推导；含 2 个小步骤，逐个展开）
   - 【分类讨论】按 g(x) 的正负分情况：g(x)<0 时 √f(x) ≥ 0 > g(x) 自动成立
   - 【平方法】g(x) ≥ 0 时两边都非负，平方不改变方向（非负数平方保序）
4. **【公理】正数相乘 → 高次不等式（穿根法）**（推导；含 2 个小步骤，逐个展开）
   - 【分类讨论】x−xᵢ 在 xᵢ 右侧为正、左侧为负
   - 积的符号由负因式个数的奇偶决定（正×正=正、负×负=正）
   - 【数形结合】在数轴上标出各根，从最右边上方开始穿线，读出正负区间
5. **负数乘法反序 → 高次不等式（穿根法）**（提供前提）
   - 【前提】负 × 负 = 正：两个负因式之积为正
6. **正数乘法保序 → 分式不等式**（推导）
   - 【同乘法】两边乘 g(x)²>0，不等号方向不变
   - f/g · g² = f·g
7. **高次不等式（穿根法） → 分式不等式**（提供前提）
   - 【前提】化成整式后用穿根法求解

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 高次不等式（穿根法）
- 化为 (x−x₁)(x−x₂)…(x−xₙ) > 0（各因式 x 的系数为正）
- 无实根的因式（如 x²+x+1）先判断符号，恒正就约去
- 数轴上标根，从最右边上方开始依次穿线
- 奇次重根穿过，偶次重根不穿；解 >0 时所有根都不取（偶次根处也要挖去），解 ≥0 时根都取上
- ⇐ 工具 ④ 立方差公式：分解因式，如 x³−1 = (x−1)(x²+x+1) x²+x+1 > 0 恒成立，只剩 x−1 一个因式

#### 分式不等式
- f(x)/g(x) > 0 ⟺ f(x)·g(x) > 0
- f(x)/g(x) ≥ 0 ⟺ f(x)·g(x) ≥ 0 且 g(x) ≠ 0
- 有理式可化整式后用穿根法；始终保留原定义域禁点

#### 根式（无理）不等式的解法
- √f(x) > g(x) ⟺ {f(x) ≥ 0 且 g(x) < 0} 或 {g(x) ≥ 0 且 f(x) > g(x)²}
- √f(x) < g(x) ⟺ f(x) ≥ 0 且 g(x) > 0 且 f(x) < g(x)²
- 先查定义域 f(x) ≥ 0；只有两边都非负时才能平方
- （新教材不作要求，老题常见）

#### 【定义】集合与区间
- 交集 A∩B：同时属于 A 和 B；并集 A∪B：属于 A 或属于 B
- 区间：(a,b)、[a,b]、(a,+∞)、(−∞,b] 等；圆括号不含端点，方括号含端点
- 起点：这是定义

#### 不等式组与解集
- 不等式组（各式同时成立）：分别解出，再取交集
- “或”连接（满足其一即可）：取并集
- 解集写成集合或区间：如 {x | x<−1 或 x>2} = (−∞,−1)∪(2,+∞)
- 数轴上画出各解集，公共部分就是交集；端点取到画实心点，取不到画空心点

- ④ 立方差公式；a³−b³ = (a−b)(a²+ab+b²)

## 解题思维导向（片尾一句话）
高次、分式不等式 → 化成因式的乘积 → 数轴穿根；几个不等式联立 → 数轴上画出来取交集，“或”取并集。

## 易错点与边界（必须讲到）
- 解 >0 时所有根都不取；分母为 0 的点永远不取。
- 解 ≤0 或 ≥0 时，偶次根可能成为孤立的解：(x−1)²(x+2)≤0 的解集是 x≤−2 或 x=1，x=1 别漏掉。
- 无实根的因式（如 x²+x+1）先判断符号再约去。
- 根式不等式先求定义域；右边可能为负时不能直接平方，要按右边的正负分类。
