# E16｜柯西不等式（三项、n 项）与权方和

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：柯西不等式（三项）；(a+b+c)² ≤ 3(a²+b²+c²)；柯西不等式（n 项）；权方和不等式（m=1 的情形，即柯西分式的 n 项形式）

## 这一集要讲明白的一件事
把二项柯西推广到三项、n 项；n 项用“构造二次函数 + 判别式”一招证明。

## 开场问题（不依赖其他集）
两项的柯西不等式能推广到三项、n 项吗？三项照搬“平方和非负”的办法，n 项换一招：构造一个二次函数。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- 记号：Σaᵢ² 表示 a₁²+a₂²+…+aₙ²；Σaᵢbᵢ 表示 a₁b₁+…+aₙbₙ。
- **取等条件的由来**：Δ=0 时，二次函数 f(x)=Σ(aᵢx−bᵢ)² 在 x=B/A 处等于 0，而平方和为 0 时每个平方都为 0，即 bᵢ=(B/A)aᵢ。
- **平方非负**
  - x² ≥ 0
  - 等号 ⟺ x=0
  - 由来（简短复习）：x>0 时，x·x 是两个正数相乘，为正；x<0 时，−x>0，x²=(−x)·(−x) 也是两个正数相乘，为正；x=0 时 x²=0。三种情况合起来：x²≥0，只有 x=0 时等号成立。
- **恒非负条件**
  - ax²+bx+c ≥ 0 对所有 x
  - ⟺ Δ ≤ 0（a>0）
  - 条件：x∈ℝ；a>0
  - 由来（简短复习）：a>0 时，由配方，f(x) 的最小值是 −Δ/(4a)；f(x)≥0 对所有 x 成立 ⟺ 最小值 ≥0 ⟺ Δ≤0。
- **柯西分式**
  - r²/u + s²/v ≥ (r+s)²/(u+v)
  - u,v>0；等号 ⟺ rv=su
  - 条件：u,v>0；r,s∈ℝ
  - 由来（简短复习）：在柯西不等式 (x₁²+x₂²)(y₁²+y₂²)≥(x₁y₁+x₂y₂)² 中取 x₁=r/√u、x₂=s/√v、y₁=√u、y₂=√v（u,v>0），得 (r²/u+s²/v)(u+v)≥(r+s)²，两边除以正数 u+v。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **平方非负 → (av−bu)²+(aw−cu)²+(bw−cv)² ≥ 0**（推导）
   - 【代换法】三个平方之和
   - x=av−bu, aw−cu, bw−cv
2. **恒非负条件 → 柯西不等式（n 项）**（推导；含 2 个小步骤，逐个展开）
   - 【构造】A=Σaᵢ²，B=Σaᵢbᵢ，C=Σbᵢ²
   - A=0：aᵢ 全为 0，柯西两边为 0
   - A>0：Σ(aᵢx−bᵢ)²=Ax²−2Bx+C≥0
   - 【判别式】4B²−4AC≤0 ⇒ AC≥B²
   - 取等 ⇔ bᵢ=(B/A)·aᵢ；连同 A=0 的情形，就是对应成比例（含某组全为 0）
3. **(av−bu)²+(aw−cu)²+(bw−cv)² ≥ 0 → 展开三个平方后求和：**（推导）
   - 【展开法】逐个展开三个平方，再相加
4. **展开三个平方后求和： → 柯西不等式（三项）**（推导；含 2 个小步骤，逐个展开）
   - 【配凑法】两边 +(au+bv+cw)²，展开合并，交叉项抵消
   - 【提公因式】左边 = (a²+b²+c²)(u²+v²+w²)
5. **柯西不等式（三项） → 柯西三项取 u=v=w=1：**（推导）
   - 【代入特定值】令 u=v=w=1
6. **柯西三项取 u=v=w=1： → (a+b+c)² ≤ 3(a²+b²+c²)**（推导）
   - 【恒等变形】即 3(a²+b²+c²) ≥ (a+b+c)²，左右互换写成 ≤
7. **柯西分式 → 权方和不等式（m=1 的情形，即柯西分式的 n 项形式）**（推导）
   - 【代换法】在 n 项柯西中取 xᵢ=aᵢ/√bᵢ、yᵢ=√bᵢ（bᵢ>0）：(Σaᵢ²/bᵢ)(Σbᵢ) ≥ (Σaᵢ)²
   - 【同除法】两边除以正数 Σbᵢ
   - 【取等】yᵢ=t·xᵢ ⟺ √bᵢ=t·aᵢ/√bᵢ ⟺ bᵢ=t·aᵢ，即 aᵢ/bᵢ 全相等（aᵢ 全为 0 时也成立）

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### (av−bu)²+(aw−cu)²+(bw−cv)² ≥ 0

#### 展开三个平方后求和：
- a²v²+b²u²+a²w²+c²u²+b²w²+c²v²
- −2(abuv+acuw+bcvw) ≥ 0

#### 柯西不等式（三项）
- (a²+b²+c²)(u²+v²+w²)
- ≥ (au+bv+cw)²
- 等号 ⟺ (a,b,c) 与 (u,v,w) 对应成比例：有常数 t 使 u=ta、v=tb、w=tc，或 a=b=c=0

#### 柯西三项取 u=v=w=1：
- (a²+b²+c²)(1+1+1) ≥ (a+b+c)²
- ⇐ 工具 ⑦ 三数和的平方：用⑦展开右边 (a+b+c)²

#### (a+b+c)² ≤ 3(a²+b²+c²)
- 等号 ⟺ a=b=c

#### 柯西不等式（n 项）
- (a₁²+…+aₙ²)(b₁²+…+bₙ²) ≥ (a₁b₁+…+aₙbₙ)²
- 等号 ⟺ aᵢ 与 bᵢ 对应成比例：有常数 t 使每个 bᵢ=t·aᵢ，或 aᵢ 全为 0

#### 权方和不等式（m=1 的情形，即柯西分式的 n 项形式）
- a₁²/b₁+…+aₙ²/bₙ ≥ (a₁+…+aₙ)²/(b₁+…+bₙ)
- bᵢ>0；等号 ⟺ a₁/b₁=…=aₙ/bₙ

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑦ 三数和的平方；(a+b+c)² = a²+b²+c²+2ab+2ac+2bc

- 先单独处理 aᵢ 全为 0 的情形，再讲 A>0。

## 解题思维导向（片尾一句话）
n 项的平方和与乘积和 → 构造二次函数，用判别式。

## 易错点与边界（必须讲到）
- 取等是两组数对应成比例（有 t 使 bᵢ=t·aᵢ，或 aᵢ 全为 0）。
- 权方和是柯西分式的 n 项形式，分母都要为正。
