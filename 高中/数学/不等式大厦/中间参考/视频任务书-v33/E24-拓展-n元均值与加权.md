# E24｜拓展：n 元均值不等式、三元特例与加权（拓展）

- 建议时长：7–9 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：n 元均值不等式；三元 AM≥GM（常用特例）；加权 AM-GM（wᵢ 为正整数，N=w₁+…+wₙ）；赫尔德不等式（拓展）；n 元平均数不等式链（拓展）

## 这一集要讲明白的一件事
由两个数的均值不等式出发：2→4→8→…→2ᵏ，再补项降回任意 n；加权形式再推出赫尔德不等式，它是柯西不等式的推广。

## 开场问题（不依赖其他集）
两个非负数有 (a+b)/2≥√(ab)；n 个非负数也有类似的结论吗？先倍增到 2、4、8…个，再补项回到任意 n 个。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- 记号：Σaᵢ² 表示 a₁²+a₂²+…+aₙ²；Σaᵢbᵢ 表示 a₁b₁+…+aₙbₙ。
- 记号：∏aᵢ 表示 a₁a₂…aₙ；ⁿ√ 表示 n 次方根。
- **四种平均的定义（a₁,…,aₙ>0）**：平方平均 Q=√((a₁²+…+aₙ²)/n)；算术平均 A=(a₁+…+aₙ)/n；几何平均 G=ⁿ√(a₁…aₙ)；调和平均 H=n/(1/a₁+…+1/aₙ)。
- **正数倒数反序**：0<a<b ⇒ 1/a>1/b：作差 1/a−1/b=(b−a)/(ab)>0。
- **倍增时的取等**：2→4 时，两组内部都要取等（a=b、c=d），两组之间也要取等（√(ab)=√(cd)），合起来四个数全相等；每往上倍增一层同样推理，所以 2ᵏ 个数取等 ⟺ 全相等。补项后 m 个数（含补上的 A）全相等，就是每个 aᵢ=A。
- **补项后平均数不变**：补上 m−n 个 A 后，平均数 (a₁+…+aₙ+(m−n)A)/m=(nA+(m−n)A)/m=A。
- **基本不等式 (AM≥GM)**
  - (a+b)/2 ≥ √(ab)
  - a,b ≥ 0；等号 ⟺ a=b
  - ⚠️ 一正二定三相等：“一正”（各项 ≥0）是定理成立的条件；“二定”（和或积为定值）、“三相等”（等号能取到）是用它求最值时还要查的
  - 条件：a,b≥0
  - 由来（简短复习）：u,v≥0 时，由“平方非负”，(√u−√v)²≥0；展开得 u−2√(uv)+v≥0，即 u+v≥2√(uv)，两边除以 2。把 u、v 记作 a、b 即得。等号 ⟺ √a=√b ⟺ a=b。
- **乘方与开方保序**
  - a>b≥0 ⇒ aⁿ>bⁿ，ⁿ√a > ⁿ√b（n 为正整数）
  - 条件：a>b≥0；n 为正整数
  - 由来（简短复习）：a>b≥0 时，aⁿ−bⁿ=(a−b)(aⁿ⁻¹+aⁿ⁻²b+…+bⁿ⁻¹)，第一个因子为正，第二个因子是非负数之和且含 aⁿ⁻¹>0，所以 aⁿ>bⁿ。开方用反证：若 ⁿ√a≤ⁿ√b，乘方后得 a≤b，矛盾。
- **a³ + b³ + c³ ≥ 3abc（a+b+c ≥ 0）**
  - 等号 ⟺ a=b=c 或 a+b+c=0
  - （a,b,c ≥ 0 时最常用）
  - 条件：a+b+c≥0
  - 由来（简短复习）：因式分解：a³+b³+c³−3abc=(a+b+c)(a²+b²+c²−ab−bc−ca)。a+b+c≥0，第二个因子由 a²+b²+c²≥ab+bc+ca 也 ≥0，乘积 ≥0。
- **柯西不等式（n 项）**
  - (a₁²+…+aₙ²)(b₁²+…+bₙ²) ≥ (a₁b₁+…+aₙbₙ)²
  - 等号 ⟺ aᵢ 与 bᵢ 对应成比例：有常数 t 使每个 bᵢ=t·aᵢ，或 aᵢ 全为 0
  - 由来（简短复习）：构造 f(x)=(a₁x−b₁)²+…+(aₙx−bₙ)²，它是平方和，对一切 x 都 ≥0。若 aᵢ 全为 0，两边都是 0；否则 f(x)=Ax²−2Bx+C（A=Σaᵢ²>0，B=Σaᵢbᵢ，C=Σbᵢ²），开口向上且不低于 x 轴，判别式 4B²−4AC≤0，即 AC≥B²。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **基本不等式 (AM≥GM) → 2、4、8、…、2ᵏ 个数时成立**（推导；含 2 个小步骤，逐个展开）
   - 【分组代入】2→4：分两组各用 AM≥GM，再对两组的几何平均用一次
   - 【重复】同理 4→8→…→2ᵏ
2. **乘方与开方保序 → n 元均值不等式**（提供前提）
   - 【前提】回退时两边开 n 次方不改变方向
3. **2、4、8、…、2ᵏ 个数时成立 → n 元均值不等式**（推导）
   - 【补项】A=Σaᵢ/n，取 m=2ᵏ>n，补 m−n 个 A
   - A=0：由 aᵢ≥0 得全为 0，结论取等
   - A>0：m 元式给 Aᵐ≥(∏aᵢ)Aᵐ⁻ⁿ
   - 约去 Aᵐ⁻ⁿ 后开 n 次方；取等 ⇔ aᵢ 全相等
4. **n 元均值不等式 → 加权 AM-GM（wᵢ 为正整数，N=w₁+…+wₙ）**（推导；含 2 个小步骤，逐个展开）
   - 【配凑法】把 aᵢ 重复 wᵢ 次，共 N=w₁+…+wₙ 个数
   - 【代入消元】对这 N 个数用 n 元 AM≥GM，整理得加权形式
5. **n 元均值不等式 → 三元 AM≥GM（常用特例）**（推导）
   - 【代入特定值】取 n=3
6. **a³ + b³ + c³ ≥ 3abc（a+b+c ≥ 0） → 三元 AM≥GM（常用特例）**（推导）
   - ▼ 进入正数域：x,y,z≥0
   - 【代换法】令 a=∛x，b=∛y，c=∛z（x,y,z ≥ 0，则 a+b+c ≥ 0）
   - x + y + z ≥ 3∛(xyz)，两边 ÷3（另一条路：不用 n 元均值）
7. **n 元均值不等式 → n 元平均数不等式链（拓展）**（提供前提）
   - ▼ 要求 >0（不能取 0）
   - 【前提】G≤A；把 aᵢ 换成 1/aᵢ 再取倒数得 H≤G
8. **柯西不等式（n 项） → n 元平均数不等式链（拓展）**（提供前提）
   - 【前提】取 bᵢ=1：(a₁+…+aₙ)² ≤ n(a₁²+…+aₙ²)，即 A² ≤ Q²
   - ▼ 开方要求两边非负：Q≥0，A>0（由 aᵢ>0 保证）⇒ A≤Q；反例：(−3)²>2²，但 −3>2 不成立
   - 注意：A≤Q 本身对任意实数成立（Q≥|A|≥A），aᵢ>0 是整条链（H 要取倒数、G 要非负）的条件，不要讲成“A≤Q 对负数失效”
9. **加权 AM-GM（wᵢ 为正整数，N=w₁+…+wₙ） → 赫尔德不等式（拓展）**（推导；含 3 个小步骤，逐个展开）
   - 【代入特定值】加权均值取两个数、权 1/p 与 1/q：x^(1/p)·y^(1/q) ≤ x/p + y/q（x,y ≥ 0）
   - 【归一化】记 S=Σaᵢᵖ，T=Σbᵢ^q（S、T 有一个为 0 时两边都是 0；不用 A、B，避免与算术平均 A 混淆）；取 x=aᵢᵖ/S，y=bᵢ^q/T
   - 【逐项相加】Σaᵢbᵢ / (S^(1/p)·T^(1/q)) ≤ 1/p + 1/q = 1
   - p 为有理数时用加权均值即可；一般实数需取极限

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 2、4、8、…、2ᵏ 个数时成立

#### n 元均值不等式
- (a₁+…+aₙ)/n ≥ ⁿ√(a₁a₂…aₙ)（ⁿ√ 表示 n 次方根）
- aᵢ≥0；等号 ⟺ 全相等

#### 三元 AM≥GM（常用特例）
- (a+b+c)/3 ≥ ³√(abc)
- a,b,c ≥ 0；等号 ⟺ a=b=c

#### 加权 AM-GM（wᵢ 为正整数，N=w₁+…+wₙ）
- (w₁a₁+…+wₙaₙ)/N ≥ (a₁^w₁·…·aₙ^wₙ)^(1/N)
- aᵢ≥0；等号 ⟺ aᵢ 全相等
- （权为正有理数可通分化为整数；正实数需取极限，超出高中）

#### 赫尔德不等式（拓展）
- a₁b₁+…+aₙbₙ ≤ (Σaᵢᵖ)^(1/p) · (Σbᵢ^q)^(1/q)
- aᵢ,bᵢ≥0；p,q>1，1/p+1/q=1
- 等号 ⟺ aᵢᵖ 与 bᵢ^q 对应成比例

#### n 元平均数不等式链（拓展）
- aᵢ>0：n/(1/a₁+…+1/aₙ) ≤ ⁿ√(a₁…aₙ) ≤ (a₁+…+aₙ)/n ≤ √((a₁²+…+aₙ²)/n)
- 等号 ⟺ aᵢ 全相等

## 解题思维导向（片尾一句话）
n 个非负数的和与积 → n 元均值不等式。

## 易错点与边界（必须讲到）
- 要求 aᵢ≥0；加权形式要求权为正整数（正有理数可通分）。
- 赫尔德要求 p,q>1 且 1/p+1/q=1；p=q=2 时就是柯西。
