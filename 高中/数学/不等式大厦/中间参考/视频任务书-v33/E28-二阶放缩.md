# E28｜二阶放缩：比切线更贴近的多项式

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：eˣ ≥ 1 + x + x²/2（x≥0）；cos x ≥ 1 − x²/2（x∈ℝ）；sin x ≥ x − x³/6（x≥0）；ln(1+x) ≥ x − x²/2（x≥0）

## 这一集要讲明白的一件事
一阶切线不够精确时，再多带一项（x²/2、x³/6）：构造差函数，它的导数恰好是上一层的不等式，于是一层层推上去。

## 开场问题（不依赖其他集）
x≥0 时 eˣ≥1+x，但这个估计在 x 稍大时差得很远。能不能找一个更贴近 eˣ 的多项式下界？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **求导公式**：(eˣ)′=eˣ，(sin x)′=cos x，(cos x)′=−sin x，(ln(1+x))′=1/(1+x)（x>−1）。
- **偶函数**：f(−x)=f(x) 的函数图像关于 y 轴对称；x≥0 时成立的结论，x<0 时同样成立。
- **【工具】导数判单调**
  - 在同一个区间 I 内：f′(x) ≥ 0 ⇒ f(x) 递增（不减）；f′(x) ≤ 0 ⇒ f(x) 递减（不增）
  - f′(x) > 0 ⇒ 严格递增；f′(x) < 0 ⇒ 严格递减
  - 不同区间不能连起来用：如 f(x)=−1/x 在 x<0、x>0 上分别递增，但 f(−1) > f(1)
  - 区间端点要算进去时，函数在端点要连续
  - 由来（简短复习）：课本直接使用的工具（严格证明要用拉格朗日中值定理，超出高中）。直观上：导数是切线的斜率，斜率处处 ≥0，图像就不会往下走。
- **eˣ ≥ 1+x**
  - 等号 ⟺ x=0
  - 由来（简短复习）：构造 g(x)=eˣ−1−x，g′(x)=eˣ−1：x<0 时 g′<0，x>0 时 g′>0，所以 g 在 x=0 取最小值 g(0)=0，即 g(x)≥0。
- **|sinx| ≤ |x|（x ∈ ℝ）**
  - 等号 ⟺ x=0
  - 由来（简短复习）：x≥0 时，f(x)=x−sin x、g(x)=x+sin x 的导数 1−cos x、1+cos x 都 ≥0，且 f(0)=g(0)=0，所以 −x≤sin x≤x，即 |sin x|≤x；x<0 时用 |sin(−x)|=|sin x| 对称过去。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【工具】导数判单调 → ln(1+x) ≥ x − x²/2（x≥0）**（推导；含 3 个小步骤，逐个展开）
   - 【构造法】令 φ(x) = ln(1+x) − x + x²/2（x>−1）
   - 【求导】φ′(x) = 1/(1+x) − 1 + x = x²/(1+x) ≥ 0
   - 【单调性】φ 在 (−1,+∞) 上递增，φ(0)=0：x≥0 时 φ(x)≥0
2. **eˣ ≥ 1+x → eˣ ≥ 1 + x + x²/2（x≥0）**（推导；含 3 个小步骤，逐个展开）
   - ▼ 加条件：x≥0（x≤0 时反向）
   - 【构造法】令 g(x) = eˣ − 1 − x − x²/2
   - 【求导】g′(x) = eˣ − 1 − x ≥ 0（由 eˣ ≥ 1+x），只在 x=0 处为 0
   - 【单调性】g 在 ℝ 上递增，g(0)=0：x≥0 时 g(x)≥0，x≤0 时 g(x)≤0
3. **|sinx| ≤ |x|（x ∈ ℝ） → cos x ≥ 1 − x²/2（x∈ℝ）**（推导；含 4 个小步骤，逐个展开）
   - 【构造法】令 f(x) = cos x − 1 + x²/2
   - 【求导】f′(x) = x − sin x ≥ 0（x≥0，由 |sin x| ≤ |x|）
   - 【单调性】x≥0 时 f(x) ≥ f(0) = 0
   - 【对称性】f 是偶函数，x<0 时同样成立
4. **cos x ≥ 1 − x²/2（x∈ℝ） → sin x ≥ x − x³/6（x≥0）**（推导；含 3 个小步骤，逐个展开）
   - ▼ 进入正数域：x≥0
   - 【构造法】令 h(x) = sin x − x + x³/6
   - 【求导】h′(x) = cos x − 1 + x²/2 ≥ 0（就是上一条）
   - 【单调性】x≥0 时 h(x) ≥ h(0) = 0

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### eˣ ≥ 1 + x + x²/2（x≥0）
- x≤0 时不等号反向：eˣ ≤ 1 + x + x²/2
- 等号 ⟺ x=0

#### cos x ≥ 1 − x²/2（x∈ℝ）
- 等号 ⟺ x=0

#### sin x ≥ x − x³/6（x≥0）
- 等号 ⟺ x=0

#### ln(1+x) ≥ x − x²/2（x≥0）
- −1<x≤0 时不等号反向；等号 ⟺ x=0

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- y=eˣ、y=1+x、y=1+x+x²/2 三条曲线：x≥0 时二次曲线夹在切线和 eˣ 之间，比切线贴得更近；x<0 时二次曲线跑到 eˣ 上方。
- y=cos x 与抛物线 y=1−x²/2：抛物线始终在下方，只在 x=0 处碰到。
- “导数等于上一层”的阶梯图：eˣ−1−x−x²/2 求导得 eˣ−1−x，再求导得 eˣ−1。

## 解题思维导向（片尾一句话）
一阶切线放缩不够 → 多带一项（x²/2、x³/6），差函数的导数就是上一层不等式。

## 易错点与边界（必须讲到）
- eˣ ≥ 1+x+x²/2 只对 x≥0 成立，x<0 时反向：取 x=−2，e⁻²≈0.135，而 1−2+2=1。
- ln(1+x) ≥ x−x²/2 只对 x≥0 成立；sin x ≥ x−x³/6 要求 x≥0。
