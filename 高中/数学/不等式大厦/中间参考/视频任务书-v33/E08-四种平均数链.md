# E08｜四种平均数：调和 ≤ 几何 ≤ 算术 ≤ 平方

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：平方平均 ≥ 算术平均；几何平均 ≥ 调和平均；四种平均数不等式链（a,b>0）

## 这一集要讲明白的一件事
同一对正数 a、b 的四种平均数，从小到大排成一条链；每一环都能用“平方非负”或“正数取倒数反向”说明。

## 开场问题（不依赖其他集）
两个正数 a、b 有四种常用的“平均”：调和平均、几何平均、算术平均、平方平均。它们谁大谁小？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **绝对值与平方**：|A|²=A²；|x|≥x；a,b≥0 时 a²≤b² ⇒ a≤b（若 a>b≥0，则 a²>b²，矛盾）。
- **a²+b² ≥ 2ab**
  - 等号 ⟺ a=b
  - 由来（简短复习）：由“平方非负”，(a−b)²≥0；展开得 a²−2ab+b²≥0，移项得 a²+b²≥2ab。等号 ⟺ a−b=0，即 a=b。
- **基本不等式 (AM≥GM)**
  - (a+b)/2 ≥ √(ab)
  - a,b ≥ 0；等号 ⟺ a=b
  - ⚠️ 一正二定三相等：“一正”（各项 ≥0）是定理成立的条件；“二定”（和或积为定值）、“三相等”（等号能取到）是用它求最值时还要查的
  - 条件：a,b≥0
  - 由来（简短复习）：u,v≥0 时，由“平方非负”，(√u−√v)²≥0；展开得 u−2√(uv)+v≥0，即 u+v≥2√(uv)，两边除以 2。把 u、v 记作 a、b 即得。等号 ⟺ √a=√b ⟺ a=b。
- **非负数平方保序**
  - 0 ≤ a < b ⇒ a² < b²
  - 反过来：a,b ≥ 0 时，a² < b² ⇒ a < b（可两边开平方）
  - 条件：a,b≥0
  - 由来（简短复习）：b²−a²=(b+a)(b−a)；0≤a<b 时，b+a>0、b−a>0，乘积为正，所以 a²<b²。反过来，若 a²<b² 且 a,b≥0，假设 a≥b，就会得到 a²≥b²，矛盾。
- **正数倒数反序**
  - 0<a<b ⇒ 1/a > 1/b
  - （一般地：ab>0 时，a>b ⇒ 1/a < 1/b）
  - 条件：0<a<b；一般式 ab>0
  - 由来（简短复习）：作差：1/a−1/b=(b−a)/(ab)。0<a<b 时分子 b−a>0、分母 ab>0，差为正，所以 1/a>1/b。一般地只要 ab>0（两数同号）同样成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **a²+b² ≥ 2ab → 平方和与完全平方**（推导）
   - 【配凑法】两边 +a²+b²
2. **平方和与完全平方 → 半平方和不等式**（推导）
   - 【同除法】两边 ÷4
   - (a²+b²)/2 ≥ (a+b)²/4 = ((a+b)/2)²
3. **基本不等式 (AM≥GM) → 倒数的均值**（推导；含 2 个小步骤，逐个展开）
   - ▼ 要求 >0（不能取 0）
   - 【代换法】用 1/a、1/b 代入 AM≥GM
   - 【同乘法】两边 ×2
4. **半平方和不等式 → 平方平均与 |a+b| 的关系**（推导）
   - 【开平方】记 Q=√((a²+b²)/2)，A=(a+b)/2
   - Q²≥A² ⇒ Q≥|A|
5. **非负数平方保序 → 平方平均与 |a+b| 的关系**（提供前提）
   - 【前提】非负数平方保序：两边都非负，开平方不改变方向
6. **倒数的均值 → 几何平均 ≥ 调和平均**（推导；含 2 个小步骤，逐个展开）
   - 【倒数法】两边为正，取倒数不等号反向
   - 【同乘法+通分】两边 ×2，2/(1/a+1/b) = 2ab/(a+b)
7. **正数倒数反序 → 几何平均 ≥ 调和平均**（提供前提）
   - 【前提】正数倒数反序：两边为正，取倒数不等号反向
8. **平方平均与 |a+b| 的关系 → 平方平均 ≥ 算术平均**（推导）
   - 【绝对值界】Q≥|A|≥A
   - 等号 ⇔ a=b 且 A≥0，即 a=b≥0
9. **几何平均 ≥ 调和平均 → 四种平均数不等式链（a,b>0）**（提供前提）
   - 【前提】H≤G
10. **基本不等式 (AM≥GM) → 四种平均数不等式链（a,b>0）**（提供前提）
   - ▼ 要求 >0（不能取 0）
   - 【前提】G≤A
11. **平方平均 ≥ 算术平均 → 四种平均数不等式链（a,b>0）**（提供前提）
   - ▼ 进入正数域：a,b>0
   - 【前提】A≤Q

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 平方和与完全平方
- 2(a²+b²) ≥ (a+b)²
- ⇐ 工具 ⑨ a²+b² = (a+b)²−2ab：用⑨互换 a²+b² 与 (a+b)²

#### 半平方和不等式
- (a²+b²)/2 ≥ ((a+b)/2)²

#### 平方平均与 |a+b| 的关系
- √((a²+b²)/2) ≥ |a+b|/2
- 又 |a+b| ≥ a+b，故对任意实数 ≥ (a+b)/2

#### 平方平均 ≥ 算术平均
- √((a²+b²)/2) ≥ (a+b)/2
- 对任意实数成立；等号 ⟺ a=b ≥ 0

#### 倒数的均值
- 1/a + 1/b ≥ 2/√(ab)（a,b>0）

#### 几何平均 ≥ 调和平均
- √(ab) ≥ 2ab/(a+b)
- a,b>0；等号 ⟺ a=b

#### 四种平均数不等式链（a,b>0）
- H ≤ G ≤ A ≤ Q
- 2ab/(a+b) ≤ √(ab) ≤ (a+b)/2 ≤ √((a²+b²)/2)
- 等号均 ⟺ a=b

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑨ a²+b² = (a+b)²−2ab；（平方和与积的互换）

- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。

- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
