## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **求根公式**：Δ=b²−4ac≥0 时，由配方 (x+b/(2a))²=Δ/(4a²) 得 x=(−b±√Δ)/(2a)；Δ<0 时右边为负，方程没有实根。
- **Δ 的三种情况（a>0）**：Δ>0：抛物线与 x 轴交于两点；Δ=0：相切于一点（重根）；Δ<0：整条抛物线在 x 轴上方。
- **根的分布为什么看这三样（a>0）**：开口向上，f(k)>0 说明 k 在两根之外；再由对称轴在 k 的哪一侧，判断 k 在两根的左边还是右边；Δ≥0 保证确实有根。f(k)<0 说明 k 在两根之间，这时 Δ>0 自然成立。
- **判别式法的一个细节**：二次项系数为负时，两边乘 −1，Δ=b²−4ac 不变，所以同样用 Δ≥0。
- **二次函数最小值**
  - f(x) ≥ −Δ/(4a)
  - 在 x=−b/(2a) 取到
  - 条件：x∈ℝ；a>0
  - 由来（简短复习）：配方：f(x)=a(x+b/(2a))²+(4ac−b²)/(4a)=a(x+b/(2a))²−Δ/(4a)。a>0 时第一项是正数乘一个平方，≥0，所以 f(x)≥−Δ/(4a)，x=−b/(2a) 时取等。
- **负数乘法反序**
  - a>b, c<0 ⇒ ac < bc
  - 条件：a,b∈ℝ；c<0
  - 由来（简短复习）：a−b>0，c<0 则 −c>0；(a−b)(−c) 是两个正数相乘，为正，即 bc−ac>0，所以 ac<bc。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **二次函数最小值 → 判别式法求范围**（推导）
   - 【等价变形】a>0 时：
   - 方程 f(x)=0 有实数解 ⟺ 最小值 −Δ/(4a) ≤ 0 ⟺ Δ≥0
2. **二次函数最小值 → 三个二次的关系（a>0）**（推导；含 3 个小步骤，逐个展开）
   - 【因式分解】Δ>0 时 f(x)=a(x−x₁)(x−x₂)
   - 【分类讨论】两根之外两个因式同号，之间异号
   - 【数形结合】开口向上的抛物线：两根之外在 x 轴上方，之间在下方
3. **三个二次的关系（a>0） → 解一元二次不等式**（推导；含 2 个小步骤，逐个展开）
   - 【等价变形】a<0 时两边乘 −1 化为 a>0
   - 【数形结合】由图像写解集
4. **负数乘法反序 → 解一元二次不等式**（提供前提）
   - 【前提】乘以负数，不等号反向
5. **三个二次的关系（a>0） → 一元二次方程根的分布（a>0；重根算两个根）**（推导）
   - 【数形结合】看三样：判别式、对称轴位置、端点函数值的符号

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 三个二次的关系（a>0）
- Δ>0：方程有两根 x₁<x₂；f(x)>0 ⟺ x<x₁ 或 x>x₂；f(x)<0 ⟺ x₁<x<x₂
- Δ=0：f(x)>0 ⟺ x≠−b/(2a)；f(x)<0 无解
- Δ<0：f(x)>0 对一切 x 成立；f(x)<0 无解
- ⇐ 工具 ⑫ 韦达定理：⑫ 根与系数的关系

#### 解一元二次不等式
- ① 化成二次项系数 >0（两边乘 −1，不等号反向）
- ② 算 Δ、求根；③ 按三个二次的关系写出解集
- 含参时：依次讨论二次项系数的符号、Δ 的符号、两根的大小

#### 一元二次方程根的分布（a>0；重根算两个根）
- 两根都大于 k ⟺ Δ ≥ 0，−b/(2a) > k，f(k) > 0
- 一根大于 k、一根小于 k ⟺ f(k) < 0
- 两根都在 (m,n) 内 ⟺ Δ ≥ 0，m < −b/(2a) < n，f(m) > 0，f(n) > 0

#### 判别式法求范围
- 设 y=f(x)/g(x)，若整理为关于 x 的二次方程 h(x)=0
- x 有实数解 ⇒ Δ≥0，由此得到 y 的取值范围
- 注意：① 二次项系数含 y 时，系数为 0 要单独讨论
- ② 求出的 y 要能对应定义域内的 x（g(x)≠0）

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑫ 韦达定理（根与系数的关系；ax²+bx+c=0，a≠0）；实根 x₁,x₂ 按重数计：x₁+x₂=−b/a，x₁x₂=c/a；在实数范围须 Δ≥0

- 判别式法：把 y 看成参数，方程有实数解 ⟺ Δ≥0。
