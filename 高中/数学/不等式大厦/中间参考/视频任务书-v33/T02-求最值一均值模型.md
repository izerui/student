# T02｜题型串讲：求最值（一）均值模型

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 和固定，求积最大
- 反推：和定积最大 ← (u+v)²≥4uv ← (u−v)²≥0 ← 平方非负
- 先查：u+v 是否为定值；u=v=S/2 能否取到（不要求 u,v 为正）
- 去这里查：
- ▸ 和定积最大（u,v 为任意实数）
- **参考例题（已核对）**：x+y=4（x,y 为实数），xy 的最大值：xy ≤ ((x+y)/2)² = 4，x=y=2 时取到。

## 题型 2：看到 积固定，求和最小
- 反推：积定和最小 ← AM≥GM ← (√u−√v)²≥0
- 先查：u,v>0；u=v=√P 能否取到
- 去这里查：
- ▸ 积定和最小（u,v>0）
- **参考例题（已核对）**：x,y>0，xy=9，x+y 的最小值：x+y ≥ 2√9 = 6，x=y=3 时取到。

## 题型 3：看到 ax+b/x 或 x+k/x
- 反推：对勾函数 ← 积定和最小（ax·b/x=ab 是定值）← AM≥GM
- 先查：a,b,x>0；x=√(b/a) 不在定义域内时改用单调性
- 去这里查：
- ▸ 对勾函数最值
- **参考例题（已核对）**：x>0 时 x+4/x 的最小值为 4（x=2）；若限定 x≥3，函数在 [3,+∞) 上递增，最小值为 3+4/3 = 13/3。

## 题型 4：看到 分式求最值，分子次数 ≥ 分母次数
- 反推：令 t=分母，分离常数 → 化成 At + B + C/t → 对勾函数 / 积定和最小
- 能化成 At+B+C/t 才走这条路（常见：二次式 ÷ 一次式）；只看次数不够，如 (x⁴+1)/(x+1) 就化不成
- 例：(x²+x+1)/(x+1)，x>−1：令 t=x+1>0，原式 = t + 1/t − 1 ≥ 1
- 先查：t≠0；A、C、t 都 >0 才能直接用基本不等式，否则分类讨论或求导；t=√(C/A) 是否在范围内，不在就用单调性
- 去这里查：
- ▸ 对勾函数最值
- ▸ 或 积定和最小 → 积定和最小（u,v>0）

## 题型 5：看到 1/x+1/y 求最值（x,y>0）
- 已知 a,b>0，ax+by=1：乘 1 法 (1/x+1/y)(ax+by) = a+b + by/x + ax/y ≥ a+b+2√(ab)
- 取等：by/x = ax/y；例 x+2y=1 时最小值 3+2√2
- 下式对 x,y>0 恒成立；和固定时便于求最小值： 1/x+1/y ≥ 4/(x+y)
- 反推：1/x+1/y ≥ 4/(x+y) ← 柯西分式取 r=s=1 ← 柯西二项
- 去这里查：
- ▸ x+y 固定时可得常数下界 → 1/x + 1/y ≥ 4/(x+y)
- ▸ 【乘 1 法】展开后 (by/x)·(ax/y)=ab，为定值 ⇒ 积定和最小 → 积定和最小（u,v>0）

## 题型 6：看到 多项乘积，如 (a+b)(b+c)(c+a)
- 反推：每个因子用 AM≥GM 放成 2√(·) 再相乘 ← AM≥GM
- 先查：相乘的各式两边非负（允许为零）；有零因子时单独判等；正因子时查各组等号，必要时尝试调整拆分
- 去这里查：
- ▸ 【待定系数法】设拆分系数，使各组等号能同时取到，再分组用 AM≥GM → 基本不等式 (AM≥GM)
- ▸ n 个数时 → n 元均值 → n 元均值不等式

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **对勾函数的单调性**：f(x)=ax+b/x（a,b>0，x>0）：f′(x)=a−b/x²，x<√(b/a) 时为负，x>√(b/a) 时为正，所以在 (0,√(b/a)] 上递减，在 [√(b/a),+∞) 上递增。
- **乘 1 法为什么能乘**：已知 ax+by=1，乘上它，式子的值不变。
- **和定积最大（u,v 为任意实数）**
  - u+v=S ⇒ uv ≤ S²/4
  - u=v=S/2 时取等
  - 注意：本结论不要求为正，只需和为定值、等号能取到
  - 由来（简短复习）：由“平方非负”，(u−v)²≥0，即 (u+v)²≥4uv，所以 uv≤(u+v)²/4=S²/4；u=v 时取等。对任意实数都成立。
- **积定和最小（u,v>0）**
  - uv=P ⇒ u+v ≥ 2√P
  - u=v=√P 时取等
  - ⚠️ 一正：u,v>0；二定：积 P 固定；三相等：u=v=√P 要能取到（有其他约束时单独检查）
  - 条件：u,v>0
  - 由来（简短复习）：u,v>0 时，(√u−√v)²≥0，展开得 u+v≥2√(uv)=2√P；u=v=√P 时取等。
- **对勾函数最值**
  - f(x) = ax + b/x（a,b>0, x>0）
  - f(x) ≥ 2√(ab)
  - 在 x=√(b/a) 取等
  - 条件：a,b,x>0
  - 由来（简短复习）：a,b,x>0 时，ax 与 b/x 都是正数，乘积 ab 是定值，所以 ax+b/x≥2√(ab)；ax=b/x，即 x=√(b/a) 时取等。
- **1/x + 1/y ≥ 4/(x+y)**
  - x,y>0；等号 ⟺ x=y
  - 条件：x,y>0
  - 由来（简短复习）：展开 (x+y)(1/x+1/y)=2+y/x+x/y，而 y/x+x/y≥2（两个正数，积为 1），所以 ≥4，两边除以 x+y>0。
- **基本不等式 (AM≥GM)**
  - (a+b)/2 ≥ √(ab)
  - a,b ≥ 0；等号 ⟺ a=b
  - ⚠️ 一正二定三相等：“一正”（各项 ≥0）是定理成立的条件；“二定”（和或积为定值）、“三相等”（等号能取到）是用它求最值时还要查的
  - 条件：a,b≥0
  - 由来（简短复习）：u,v≥0 时，由“平方非负”，(√u−√v)²≥0；展开得 u−2√(uv)+v≥0，即 u+v≥2√(uv)，两边除以 2。把 u、v 记作 a、b 即得。等号 ⟺ √a=√b ⟺ a=b。
- **n 元均值不等式**
  - (a₁+…+aₙ)/n ≥ ⁿ√(a₁a₂…aₙ)（ⁿ√ 表示 n 次方根）
  - aᵢ≥0；等号 ⟺ 全相等
  - 条件：aᵢ≥0
  - 由来（简短复习）：先倍增：两两一组用两数的基本不等式，对 2、4、8…个数都成立；n 不是 2 的幂时，补上若干个平均值 A 凑成 2ᵏ 个数，代入后化简回到 n 个数（A=0 时 aᵢ 全为 0，直接成立）。
- **柯西分式**
  - r²/u + s²/v ≥ (r+s)²/(u+v)
  - u,v>0；等号 ⟺ rv=su
  - 条件：u,v>0；r,s∈ℝ
  - 由来（简短复习）：在柯西不等式 (x₁²+x₂²)(y₁²+y₂²)≥(x₁y₁+x₂y₂)² 中取 x₁=r/√u、x₂=s/√v、y₁=√u、y₂=√v（u,v>0），得 (r²/u+s²/v)(u+v)≥(r+s)²，两边除以正数 u+v。
- **柯西不等式（二项）**
  - (a²+b²)(c²+d²) ≥ (ac+bd)²
  - 等号 ⟺ ad=bc
  - 由来（简短复习）：由“平方非负”，(ad−bc)²≥0，展开得 a²d²+b²c²≥2abcd；两边同加 a²c²+b²d²：左边是 (a²+b²)(c²+d²)，右边是 (ac+bd)²。等号 ⟺ ad−bc=0。
- **同向非负不等式可乘**
  - a≥b≥0，c≥d≥0 ⇒ ac≥bd
  - 若 a>b≥0 且 c>d≥0，则 ac>bd
  - 条件：a≥b≥0；c≥d≥0
  - 由来（简短复习）：作差：ac−bd=(a−b)c+b(c−d)。a−b≥0、c≥0，所以 (a−b)c≥0；b≥0、c−d≥0，所以 b(c−d)≥0；两项相加 ≥0。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
