# E05｜a²+b² ≥ 2ab：平方非负的第一个果实

- 建议时长：3–4 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：a²+b² ≥ 2ab

## 这一集要讲明白的一件事
把 (a−b)²≥0 展开，就得到最常用的 a²+b²≥2ab，对任意实数成立。

## 开场问题（不依赖其他集）
a²+b² 和 2ab 谁大？先代几组数试试，再用一个平方说明它对所有实数都成立。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **平方非负**
  - x² ≥ 0
  - 等号 ⟺ x=0
  - 由来（简短复习）：x>0 时，x·x 是两个正数相乘，为正；x<0 时，−x>0，x²=(−x)·(−x) 也是两个正数相乘，为正；x=0 时 x²=0。三种情况合起来：x²≥0，只有 x=0 时等号成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **平方非负 → (a−b)² ≥ 0**（推导）
   - 【代换法】令 x = a−b
2. **(a−b)² ≥ 0 → a²−2ab+b² ≥ 0**（推导）
   - 【展开法】展开完全平方
3. **a²−2ab+b² ≥ 0 → a²+b² ≥ 2ab**（推导）
   - 【配凑法】两边 +2ab
