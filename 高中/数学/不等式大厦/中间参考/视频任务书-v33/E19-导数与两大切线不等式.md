# E19｜导数判单调与两大切线不等式：eˣ ≥ 1+x、ln x ≤ x−1

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：eˣ ≥ 1+x；ln x ≤ x−1（x>0）；eˣ ≥ ex（x∈ℝ）；ln x ≤ x/e（x>0）；ln x ≥ 1 − 1/x（x>0）；x/(1+x) ≤ ln(1+x) ≤ x（x > −1）

## 这一集要讲明白的一件事
构造“两边之差”的函数，用导数找最小值，得到 eˣ≥1+x、ln x≤x−1，再代换出一族变形。

## 开场问题（不依赖其他集）
eˣ 和 1+x 谁大？ln x 和 x−1 呢？代数方法比不出来，换个办法：作差、构造函数、用导数找最小值。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **求导公式**：(eˣ)′=eˣ，(ln x)′=1/x（x>0）。
- **指数、对数的运算**：ln(1/x)=−ln x，ln(x/e)=ln x−1，e·eˣ⁻¹=eˣ；eˣ 递增且 e⁰=1，所以 x<0 时 eˣ<1，x>0 时 eˣ>1。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【工具】导数判单调 → ln x ≤ x−1（x>0）**（推导；含 5 个小步骤，逐个展开）
   - 【构造法】令 h(x)=x−1−ln x（x>0）
   - 【求导】h′(x)=1−1/x=(x−1)/x
   - 【分类讨论】0<x<1 时 h′<0 递减；x>1 时 h′>0 递增
   - 【极值判断】x=1 处取最小值 h(1)=0
   - 【移项法】h(x)≥0 ⇒ ln x ≤ x−1
2. **【工具】导数判单调 → eˣ ≥ 1+x**（推导；含 5 个小步骤，逐个展开）
   - 【构造法】令 g(x)=eˣ−1−x
   - 【求导】g′(x)=eˣ−1
   - 【分类讨论】x<0 时 g′<0 递减；x>0 时 g′>0 递增
   - 【极值判断】x=0 处取最小值 g(0)=0
   - 【移项法】g(x)≥0 ⇒ eˣ ≥ 1+x
3. **ln x ≤ x−1（x>0） → ln x ≥ 1 − 1/x（x>0）**（推导）
   - 【代换法】ln x ≤ x−1 中把 x 换成 1/x
   - −ln x ≤ 1/x − 1，两边乘 −1
4. **ln x ≤ x−1（x>0） → ln x ≤ x/e（x>0）**（推导）
   - 【代换法】ln x ≤ x−1 中把 x 换成 x/e
   - ln x − 1 ≤ x/e − 1
5. **eˣ ≥ 1+x → eˣ ≥ ex（x∈ℝ）**（推导；含 2 个小步骤，逐个展开）
   - 【代换法】eˣ ≥ 1+x 中把 x 换成 x−1：eˣ⁻¹ ≥ x
   - 【同乘法】两边乘 e
6. **ln x ≤ x−1（x>0） → x/(1+x) ≤ ln(1+x) ≤ x（x > −1）**（推导）
   - 【代换法】ln t ≤ t−1 中令 t = 1+x：ln(1+x) ≤ x
7. **ln x ≥ 1 − 1/x（x>0） → x/(1+x) ≤ ln(1+x) ≤ x（x > −1）**（提供前提）
   - 【前提】ln t ≥ 1 − 1/t 中令 t = 1+x：ln(1+x) ≥ x/(1+x)

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【工具】导数判单调
- 在同一个区间 I 内：f′(x) ≥ 0 ⇒ f(x) 递增（不减）；f′(x) ≤ 0 ⇒ f(x) 递减（不增）
- f′(x) > 0 ⇒ 严格递增；f′(x) < 0 ⇒ 严格递减
- 不同区间不能连起来用：如 f(x)=−1/x 在 x<0、x>0 上分别递增，但 f(−1) > f(1)
- 区间端点要算进去时，函数在端点要连续
- 起点：课本直接使用，不需要证明（严格证明要用拉格朗日中值定理，超出高中）

#### eˣ ≥ 1+x
- 等号 ⟺ x=0

#### ln x ≤ x−1（x>0）
- 等号 ⟺ x=1

#### eˣ ≥ ex（x∈ℝ）
- 等号 ⟺ x=1

#### ln x ≤ x/e（x>0）
- 等号 ⟺ x=e

#### ln x ≥ 1 − 1/x（x>0）
- 等号 ⟺ x=1

#### x/(1+x) ≤ ln(1+x) ≤ x（x > −1）
- 等号 ⟺ x=0

## 解题思维导向（片尾一句话）
超越函数与多项式比较 → 构造差函数求最小值；常用 eˣ≥1+x、ln x≤x−1 和它们的变形。

## 易错点与边界（必须讲到）
- 导数判单调只在同一个区间内成立（如 −1/x 的反例）。
- ln 类结论都要求 x>0（ln(1+x) 要求 x>−1）。
