# T04｜题型串讲：柯西、排序与竞赛型

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 (Σaᵢ²)(Σbᵢ²) 或内积结构
- 反推：柯西不等式（二项/三项）← (ad−bc)²≥0 等平方和非负
- 取等：对应成比例（有 t 使 bᵢ=t·aᵢ，或 aᵢ 全为 0）；不要写成 aᵢ/bᵢ 相等，分母可能为 0
- 去这里查：
- ▸ 柯西不等式（二项）
- **参考例题（已核对）**：x²+y²=1，求 x+2y 的最大值：(1²+2²)(x²+y²) ≥ (x+2y)²，最大值 √5，x=1/√5、y=2/√5 时取到。

## 题型 2：看到 分式和求最值，如 u²/x + v²/y
- 反推：分子是平方、分母和为定值 → 柯西分式（权方和）← 柯西二项 ← (ad−bc)²≥0
- 先查：分母为正；取等 u/x = v/y
- 不符合时：齐次化成单变量，再用判别式或导数
- 去这里查：
- ▸ 柯西分式
- **参考例题（已核对）**：x,y>0，x+y=1，求 1/x+4/y 的最小值：1²/x+2²/y ≥ (1+2)²/(x+y) = 9，y=2x 即 x=1/3、y=2/3 时取到。

## 题型 3：看到 两组有序数，求 Σaᵢbᵢ 范围
- 反推：排序不等式 ← (a₂−a₁)(b₂−b₁)≥0（两组同序）
- 结论：同序和最大，逆序和最小
- 去这里查：
- ▸ 排序不等式（两数）
- **参考例题（已核对）**：1,2,3 与 4,5,6 配对：同序和 1·4+2·5+3·6=32 最大，逆序和 1·6+2·5+3·4=28 最小。

## 题型 4：看到 竞赛型对称不等式（三元、分式和、有序乘积）
- 反推：分式和 → 柯西分式 / 权方和 / Nesbitt；三元对称多项式 → 舒尔、立方和
- 有序数组的乘积和 → 排序 / 切比雪夫；带权的平均 → 加权均值
- 先查：变量是否非负；能否齐次化、能否设 a≥b≥c
- 去这里查：
- ▸ 分式和 → 权方和不等式（m=1 的情形，即柯西分式的 n 项形式）
- ▸ Nesbitt → Nesbitt 不等式
- ▸ 三元对称 → 舒尔不等式（t=1 常用形式，a,b,c≥0）
- ▸ 立方和 → a³+b³ ≥ ab(a+b)（a+b ≥ 0）
- ▸ 有序乘积和 → 切比雪夫不等式
- ▸ 带权 → 加权 AM-GM（wᵢ 为正整数，N=w₁+…+wₙ）
- ▸ 三元立方和 → a³+b³+c³ ≥ 3abc
- ▸ 幂次推广 → 幂平均
- ▸ 柯西推广 → 赫尔德
- **参考例题（已核对）**：Nesbitt：a,b,c>0 时 a/(b+c)+b/(c+a)+c/(a+b) ≥ 3/2。思路：每项加 1 得 (a+b+c)/(b+c) 等，记 S=a+b+c，三个分母之和为 2S；由 (x+y+z)(1/x+1/y+1/z) ≥ 9 得 Σ1/(b+c) ≥ 9/(2S)，所以原式 ≥ S·9/(2S) − 3 = 3/2，a=b=c 时取等。

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **柯西分式的字母对照**：题型里的 u²/x+v²/y 对应公式 r²/u+s²/v：r=u、s=v，分母 u、v 换成 x、y，于是取等 rv=su 就是 u·y=v·x，即 u/x=v/y。
- **(x+y+z)(1/x+1/y+1/z)≥9（x,y,z>0）**：展开得 3+(x/y+y/x)+(y/z+z/y)+(z/x+x/z)，每一对两个正数互为倒数，和 ≥2，所以 ≥3+2+2+2=9。
- **柯西不等式（二项）**
  - (a²+b²)(c²+d²) ≥ (ac+bd)²
  - 等号 ⟺ ad=bc
  - 由来（简短复习）：由“平方非负”，(ad−bc)²≥0，展开得 a²d²+b²c²≥2abcd；两边同加 a²c²+b²d²：左边是 (a²+b²)(c²+d²)，右边是 (ac+bd)²。等号 ⟺ ad−bc=0。
- **柯西分式**
  - r²/u + s²/v ≥ (r+s)²/(u+v)
  - u,v>0；等号 ⟺ rv=su
  - 条件：u,v>0；r,s∈ℝ
  - 由来（简短复习）：在柯西不等式 (x₁²+x₂²)(y₁²+y₂²)≥(x₁y₁+x₂y₂)² 中取 x₁=r/√u、x₂=s/√v、y₁=√u、y₂=√v（u,v>0），得 (r²/u+s²/v)(u+v)≥(r+s)²，两边除以正数 u+v。
- **排序不等式（两数）**
  - a₁≤a₂，b₁≤b₂ ⇒ a₁b₁+a₂b₂ ≥ a₁b₂+a₂b₁
  - （同序和 ≥ 逆序和）
  - 等号 ⟺ a₁=a₂ 或 b₁=b₂
  - 由来（简短复习）：作差：(a₁b₁+a₂b₂)−(a₁b₂+a₂b₁)=(a₂−a₁)(b₂−b₁)；两个因子都 ≥0，乘积 ≥0。
- **权方和不等式（m=1 的情形，即柯西分式的 n 项形式）**
  - a₁²/b₁+…+aₙ²/bₙ ≥ (a₁+…+aₙ)²/(b₁+…+bₙ)
  - bᵢ>0；等号 ⟺ a₁/b₁=…=aₙ/bₙ
  - 条件：bᵢ>0；aᵢ∈ℝ
  - 由来（简短复习）：把两项的柯西分式反复使用：先把前两项合成一项，再和第三项合成，……一直到 n 项。
- **Nesbitt 不等式**
  - a/(b+c)+b/(a+c)+c/(a+b) ≥ 3/2
  - a,b,c>0；等号 ⟺ a=b=c
  - 条件：a,b,c>0
  - 由来（简短复习）：每项加 1：a/(b+c)+1=(a+b+c)/(b+c)，记 S=a+b+c，原式=S·[1/(b+c)+1/(c+a)+1/(a+b)]−3。三个分母之和为 2S，由 (x+y+z)(1/x+1/y+1/z)≥9 得括号 ≥9/(2S)，所以原式 ≥9/2−3=3/2。
- **舒尔不等式（t=1 常用形式，a,b,c≥0）**
  - a(a−b)(a−c)+b(b−a)(b−c)+c(c−a)(c−b) ≥ 0
  - 即 a³+b³+c³+3abc ≥ ab(a+b)+bc(b+c)+ca(c+a)
  - 等号 ⟺ a=b=c，或两数相等且第三个为 0
  - 条件：a,b,c≥0
  - 由来（简短复习）：不妨设 a≥b≥c≥0。前两项合并为 (a−b)[a(a−c)−b(b−c)]，其中 a−b≥0，且 a≥b≥0、a−c≥b−c≥0，所以 a(a−c)≥b(b−c)，这一项 ≥0；第三项 c(c−a)(c−b) 的两个因子都 ≤0，乘积 ≥0。
- **a³+b³ ≥ ab(a+b)（a+b ≥ 0）**
  - 等号 ⟺ a=b 或 a+b=0
  - （a,b>0 时最常用）
  - 条件：a,b∈ℝ；a+b≥0
  - 由来（简短复习）：作差：a³+b³−ab(a+b)=(a+b)(a²−ab+b²)−ab(a+b)=(a+b)(a−b)²；a+b≥0、(a−b)²≥0，乘积 ≥0。
- **切比雪夫不等式**
  - a₁≤…≤aₙ, b₁≤…≤bₙ
  - (Σaᵢ)(Σbᵢ)/n ≤ Σaᵢbᵢ
  - 等号 ⟺ 某组全相等
  - 由来（简短复习）：把 b 依次往后挪一位、共挪 n 次，每次由排序不等式：同序和 ≥ 挪动后的和；n 个式子相加，右边恰好是 (Σaᵢ)(Σbᵢ)，再除以 n。
- **加权 AM-GM（wᵢ 为正整数，N=w₁+…+wₙ）**
  - (w₁a₁+…+wₙaₙ)/N ≥ (a₁^w₁·…·aₙ^wₙ)^(1/N)
  - aᵢ≥0；等号 ⟺ aᵢ 全相等
  - （权为正有理数可通分化为整数；正实数需取极限，超出高中）
  - 条件：aᵢ≥0；wᵢ为正整数
  - 由来（简短复习）：把 aᵢ 重复写 wᵢ 次，得到 N 个数，对它们用 n 元均值不等式。
- **a³ + b³ + c³ ≥ 3abc（a+b+c ≥ 0）**
  - 等号 ⟺ a=b=c 或 a+b+c=0
  - （a,b,c ≥ 0 时最常用）
  - 条件：a+b+c≥0
  - 由来（简短复习）：因式分解：a³+b³+c³−3abc=(a+b+c)(a²+b²+c²−ab−bc−ca)。a+b+c≥0，第二个因子由 a²+b²+c²≥ab+bc+ca 也 ≥0，乘积 ≥0。
- **幂平均不等式（拓展）**
  - Mₚ = ((a₁ᵖ+…+aₙᵖ)/n)^(1/p)（p≠0），M₀ = ⁿ√(a₁a₂…aₙ)
  - p < q ⇒ Mₚ ≤ M_q；等号 ⟺ aᵢ 全相等
  - p = −1、0、1、2 就是 调和 ≤ 几何 ≤ 算术 ≤ 平方 平均
  - 条件：aᵢ>0
  - 由来（简短复习）：0<p<q 时 f(t)=t^(q/p) 在 t>0 上下凸（q/p>1），对 xᵢ=aᵢᵖ 用琴生不等式：(Σaᵢ^q)/n≥((Σaᵢᵖ)/n)^(q/p)，两边开 q 次方得 M_q≥Mₚ。
- **赫尔德不等式（拓展）**
  - a₁b₁+…+aₙbₙ ≤ (Σaᵢᵖ)^(1/p) · (Σbᵢ^q)^(1/q)
  - 等号 ⟺ aᵢᵖ 与 bᵢ^q 对应成比例
  - 条件：aᵢ,bᵢ≥0；p,q>1，1/p+1/q=1
  - 由来（简短复习）：加权均值取两个数、权 1/p 与 1/q：x^(1/p)y^(1/q)≤x/p+y/q。取 x=aᵢᵖ/A、y=bᵢ^q/B（A=Σaᵢᵖ，B=Σbᵢ^q），逐项相加，右边和为 1/p+1/q=1。
- **排序不等式（n 个数）**
  - a₁≤a₂≤…≤aₙ，b₁≤b₂≤…≤bₙ
  - 同序和 a₁b₁+…+aₙbₙ ≥ 任意打乱后的和 ≥ 逆序和 a₁bₙ+…+aₙb₁
  - 例：a₁b₁+a₂b₂+a₃b₃ ≥ a₁b₂+a₂b₃+a₃b₁ ≥ a₁b₃+a₂b₂+a₃b₁
  - 取最大值 ⇔ 打乱后仍是同序：aᵢ<aⱼ 时，配给 aⱼ 的 b 不小于配给 aᵢ 的 b；最小值反过来
  - 等号：打乱后的和与同序（或逆序）一样，如 a 值相等的位置互换、某组数全相等
  - 由来（简短复习）：两数时由作差 (a₂−a₁)(b₂−b₁)≥0 得到。n 个数时，任意一种配对里只要有一对是“逆序”的，交换它们，和不会变小；反复交换，直到变成同序。
- **柯西不等式（三项）**
  - (a²+b²+c²)(u²+v²+w²)
  - ≥ (au+bv+cw)²
  - 等号 ⟺ (a,b,c) 与 (u,v,w) 对应成比例：有常数 t 使 u=ta、v=tb、w=tc，或 a=b=c=0
  - 由来（简短复习）：由“平方非负”，(av−bu)²+(aw−cu)²+(bw−cv)²≥0；把三个平方展开再相加，整理后恰好是 (a²+b²+c²)(u²+v²+w²)−(au+bv+cw)²≥0。等号 ⟺ 三个平方都为 0，即两组数对应成比例。
- **n 元均值不等式**
  - (a₁+…+aₙ)/n ≥ ⁿ√(a₁a₂…aₙ)（ⁿ√ 表示 n 次方根）
  - aᵢ≥0；等号 ⟺ 全相等
  - 条件：aᵢ≥0
  - 由来（简短复习）：先倍增：两两一组用两数的基本不等式，对 2、4、8…个数都成立；n 不是 2 的幂时，补上若干个平均值 A 凑成 2ᵏ 个数，代入后化简回到 n 个数（A=0 时 aᵢ 全为 0，直接成立）。

## 解题思维导向（片尾汇总）
- 看到 (Σaᵢ²)(Σbᵢ²) 或内积结构 → 柯西不等式（二项/三项）← (ad−bc)²≥0 等平方和非负
- 看到 分式和求最值，如 u²/x + v²/y → 分子是平方、分母和为定值 → 柯西分式（权方和）← 柯西二项 ← (ad−bc)²≥0

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
