# E13｜绝对值三角不等式

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：三角不等式；反三角不等式

## 这一集要讲明白的一件事
由 −|x| ≤ x ≤ |x| 两式相加，得到 |a+b| ≤ |a|+|b|；再代换出反三角不等式。

## 开场问题（不依赖其他集）
|a+b| 和 |a|+|b| 谁大？把绝对值看成数轴上的距离，答案就清楚了。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **绝对值的两个性质**：|−x|=|x|；c≥0 时，|y|≤c ⟺ −c≤y≤c（到原点的距离不超过 c）。
- **反三角不等式取等的由来**：两边都非负，平方后比较：(|a|−|b|)²=a²−2|ab|+b²，(a−b)²=a²−2ab+b²，相等 ⟺ |ab|=ab ⟺ ab≥0。
- **等号条件 ab≥0 的由来**：a+b≥0 时 |a+b|=a+b，要等于 |a|+|b| 就要 a=|a|、b=|b|，即 a,b≥0；a+b<0 时同理要 a,b≤0；合起来就是 ab≥0。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【定义】绝对值 → −|x| ≤ x ≤ |x|**（推导）
   - 【分类代入】分 x≥0 和 x<0
   - 两种情况代入
2. **−|x| ≤ x ≤ |x| → −|a|≤a≤|a|**（推导）
   - 【逐项代入】分别令 x=a、x=b
3. **−|a|≤a≤|a| → −(|a|+|b|) ≤ a+b ≤ |a|+|b|**（推导）
   - 【逐项相加】对应不等式相加
4. **−(|a|+|b|) ≤ a+b ≤ |a|+|b| → 三角不等式**（推导）
   - 【分类合并】分 a+b≥0 和 <0
   - 合并两种情况
5. **三角不等式 → |a| ≤ |a−b|+|b|**（推导）
   - 【代换法】用 a−b 替换 a
6. **|a| ≤ |a−b|+|b| → |a|−|b| ≤ |a−b|**（推导）
   - 【同减法】两边 −|b|
7. **|a|−|b| ≤ |a−b| → 反三角不等式**（推导）
   - 【对称交换】交换 a,b 得另半
   - 合并用绝对值定义

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【定义】绝对值
- x≥0 时 |x|=x
- x<0 时 |x|=−x
- 起点：这是定义，不是推出来的

#### −|x| ≤ x ≤ |x|

#### −|a|≤a≤|a|
- −|b|≤b≤|b|

#### −(|a|+|b|) ≤ a+b ≤ |a|+|b|

#### 三角不等式
- |a+b| ≤ |a|+|b|
- 等号 ⟺ ab ≥ 0

#### |a| ≤ |a−b|+|b|

#### |a|−|b| ≤ |a−b|

#### 反三角不等式
- ||a|−|b|| ≤ |a−b|
- 等号 ⟺ ab ≥ 0

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 数轴上的距离：|a| 是 a 到原点的距离；两段位移首尾相接，总位移的长度不超过两段长度之和。
- 同号时两段同向（取等），异号时折返（变短）。

## 着重标注（本集必须突出的地方）
- −|x|≤x≤|x| 两式相加那一步，对齐上下两行再相加。
- 等号条件 ab≥0 框出。

## 解题思维导向（片尾一句话）
看到 |a+b| 或 |a|−|b| → 三角不等式；判断等号 → 看两数是否同号。

## 易错点与边界（必须讲到）
- 等号条件：|a+b|=|a|+|b| ⟺ ab≥0。
- 反三角不等式 ||a|−|b|| ≤ |a−b| 同样对任意实数成立。
