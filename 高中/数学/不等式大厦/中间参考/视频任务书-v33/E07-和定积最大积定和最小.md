# E07｜和定积最大、积定和最小、对勾函数、均值代换

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：和定积最大（u,v 为任意实数）；积定和最小（u,v>0）；对勾函数最值；均值代换

## 这一集要讲明白的一件事
同一组不等式，换个角度看就是两类最值模型：和固定时积有最大值，积固定时和有最小值。

## 开场问题（不依赖其他集）
周长固定的长方形，什么时候面积最大？面积固定时，什么时候周长最小？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **y=x+4/x 在 [3,+∞) 上递增**：x₂>x₁≥3 时，f(x₂)−f(x₁)=(x₂−x₁)(1−4/(x₁x₂))，x₂−x₁>0，x₁x₂>9>4，所以差为正。
- **(a−b)² ≥ 0**
  - 由来（简短复习）：(a−b)² 是一个实数的平方，由“平方非负”，它 ≥0；当且仅当 a=b 时等于 0。
- **基本不等式 (AM≥GM)**
  - (a+b)/2 ≥ √(ab)
  - a,b ≥ 0；等号 ⟺ a=b
  - ⚠️ 一正二定三相等：“一正”（各项 ≥0）是定理成立的条件；“二定”（和或积为定值）、“三相等”（等号能取到）是用它求最值时还要查的
  - 条件：a,b≥0
  - 由来（简短复习）：u,v≥0 时，由“平方非负”，(√u−√v)²≥0；展开得 u−2√(uv)+v≥0，即 u+v≥2√(uv)，两边除以 2。把 u、v 记作 a、b 即得。等号 ⟺ √a=√b ⟺ a=b。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **(a−b)² ≥ 0 → 和平方与积的关系**（推导）
   - 【配凑法】(u+v)²−4uv = (u−v)² ≥ 0
   - ⇒ (u+v)² ≥ 4uv（对任意实数成立）
2. **(a−b)² ≥ 0 → 均值代换**（推导）
   - 【代换法】(a−b)² = (a+b)²−4ab = s²−4p ≥ 0
   - ⇒ p ≤ s²/4（对任意实数 a,b 成立）
3. **和平方与积的关系 → 积的上界**（推导）
   - 【同除法】两边 ÷4
4. **积的上界 → 和定积最大（u,v 为任意实数）**（推导）
   - 【代入消元】代入 u+v=S
   - uv ≤ S²/4
5. **基本不等式 (AM≥GM) → 积定和最小（u,v>0）**（推导）
   - ▼ 进入正数域：要求 u,v>0（排除负数：u=v=−1 时 u+v=−2<2）
   - 【代入消元】直接代入 uv=P
   - u+v ≥ 2√P
6. **基本不等式 (AM≥GM) → x+1/x ≥ 2（x>0）**（推导）
   - ▼ 要求 >0（不能取 0）
   - 【代换法】令 u=x, v=1/x
   - uv=1
7. **基本不等式 (AM≥GM) → a/b+b/a ≥ 2（a,b>0）**（推导）
   - ▼ 要求 >0（不能取 0）
   - 【代换法】令 u=a/b, v=b/a
   - uv=1
8. **积定和最小（u,v>0） → 对勾函数最值**（推导）
   - 【代换法】令 u=ax, v=b/x（x>0）
   - uv=ab 为定值 ⇒ u+v ≥ 2√(ab)
   - ax=b/x 即 x=√(b/a) 时取等

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 和平方与积的关系
- (u+v)² ≥ 4uv（u,v 为任意实数）

#### 积的上界
- uv ≤ (u+v)²/4

#### 和定积最大（u,v 为任意实数）
- u+v=S ⇒ uv ≤ S²/4
- u=v=S/2 时取等
- 注意：本结论不要求为正，只需和为定值、等号能取到

#### 积定和最小（u,v>0）
- uv=P ⇒ u+v ≥ 2√P
- u=v=√P 时取等
- ⚠️ 一正：u,v>0；二定：积 P 固定；三相等：u=v=√P 要能取到（有其他约束时单独检查）

#### x+1/x ≥ 2（x>0）
- 等号 ⟺ x=1

#### a/b+b/a ≥ 2（a,b>0）
- 等号 ⟺ a=b

#### 对勾函数最值
- f(x) = ax + b/x（a,b>0, x>0）
- f(x) ≥ 2√(ab)
- 在 x=√(b/a) 取等

#### 均值代换
- 令 a+b=s，ab=p
- 则 a²+b² = s²−2p
- (a−b)² = s²−4p ≥ 0 ⇒ p ≤ s²/4
- 把不等式转化为关于 s,p 的问题
- ⇐ 工具 ⑫ 韦达定理：韦达定理：a、b 是 t²−st+p=0 的两根
- ⇐ 工具 ⑨ a²+b² = (a+b)²−2ab：a²+b²=(a+b)²−2ab，即 s²−2p

## 用到的公式工具（片中写出公式即可，不展开推导）
- ⑨ a²+b² = (a+b)²−2ab；（平方和与积的互换）
- ⑫ 韦达定理（根与系数的关系；ax²+bx+c=0，a≠0）；实根 x₁,x₂ 按重数计：x₁+x₂=−b/a，x₁x₂=c/a；在实数范围须 Δ≥0

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 周长固定的矩形，拖动长宽，面积在正方形时最大；面积固定的矩形，周长在正方形时最小。
- 对勾函数 y=x+4/x（x>0）图像，最低点在 x=2；把定义域截到 [3,+∞)，最低点不在区间里，函数在区间上递增，最小值改在端点 f(3)=13/3。
- 均值代换：a、b 看成方程 t²−st+p=0 的两根，Δ≥0 给出 s²≥4p。

## 解题思维导向（片尾一句话）
和定 → 积有最大值；积定 → 和有最小值；对勾形 ax+b/x → 先凑出积为定值，再查取等点在不在范围里。

## 易错点与边界（必须讲到）
- 和定积最大不要求正数（u、v 任意实数）；积定和最小要求 u,v>0。
- 取等点不在定义域内时，改用单调性，不能硬套。
