# E00｜总览：不等式大厦怎么读

- 系列：不等式推导视频（共 28 集推导 + 7 集题型串讲）
- 位置：系列开篇，建议**最后制作**（等推导片做完，能引用其中的画面和结论）
- 建议时长：4–6 分钟；叙事模型：系统穿行（见 manim-video 的 story-models.md）

## 这一集要讲明白的一件事
本系列从实数的运算和大小规则出发，结合绝对值、函数、导数与归纳等基础，逐步解释这些不等式；拿到一道题，可以从题型入口反推回这座大厦里的某条路径。

## 主线（用一条路径穿过整座大厦）
1. **起点**：a>b 就是 a−b 是正数（紫色起点，E01）。
2. **第一块砖**：平方非负，x² ≥ 0（E02）。
3. **第一个果实**：(a−b)² ≥ 0 展开得 a²+b² ≥ 2ab，对任意实数成立（E05）。
4. **跨进正数域**：由 (√u−√v)² ≥ 0 展开，得到基本不等式 (u+v)/2 ≥ √(uv)（要对 u、v 开平方，必须 u,v ≥ 0）（E06）。这一步线上有 ▼，节点从绿色变成橙色。
5. **主干的顶点**：四种平均数链（a,b>0）：调和 2ab/(a+b) ≤ 几何 √(ab) ≤ 算术 (a+b)/2 ≤ 平方 √((a²+b²)/2)（E08）。理由一句话：调和 ≤ 几何 ⟺ 2√(ab) ≤ a+b；几何 ≤ 算术 ⟺ (√a−√b)² ≥ 0；算术 ≤ 平方 ⟺ (a−b)² ≥ 0。
6. **分支**：平方非负引出二次函数与一元二次不等式（E10–E11）、柯西（E15–E16）等分支；绝对值定义与大小规则引出绝对值不等式（E13–E14）；正负相乘的规则引出高次、分式不等式（E12）；导数长出切线放缩（E19–E20），再多带一项得到更贴近的二阶放缩（E28）；归纳法用于证明伯努利不等式（E21）；倒数比较、对数不等式与递推估计用于数列放缩（E22）。

## 读图规则（片中逐条演示）
- **节点颜色**：紫色是起点（直接承认或定义）；绿色、白色对任意实数成立；橙色要求 ≥0、>0 或其他条件，标题旁的橙色标签写明限制哪些量；淡橙是有条件的中间一步；蓝色是公式工具；青绿虚线框是题型入口。
  - 注意：“乘正数不变向”“乘负数变向”这类运算规则在总图上是白色节点（中间一步），标签写“a,b∈ℝ；c>0”——它们对任意实数 a、b 都成立，c>0 只是规则本身要区分的情况，不是对 a、b 的限制。
- **连线**：深色线是推导，越粗越是主干，线上写【方法】和具体操作；浅灰线是前提，表示引用别处已推出的结论，线上写【前提】。
- **分支块**：地基（实数运算规则 → 平方非负）在最上方；下面每个分支一个虚线框，框顶写分支名。从地基出发的线在地基下方分成几束，每束通向一个分支。
- **▼ 分水岭**：线上出现“▼ 进入正数域：…”或“▼ 加条件：…”，表示从这一步起要加条件。**正数也是实数**，所以橙色节点可以直接使用绿色节点的结论。
- **★**：越多越重要；灰色“拓展”标签是竞赛内容，可以先跳过。
- **〔编号 · 坐标〕**：如〔R36 · C7〕，按图边上的字母（列）和数字（行）找到节点。
- **左侧导航**：除了图例和公式与工具箱（不画线，按编号查），还有三块导航——题型入口目录（看到什么 → 反推到哪 → 先查什么）；取值范围示意（正数 ⊂ 非负 ⊂ 实数）；方法索引（正推 = 综合法，反推 = 分析法；十种方法各用在哪里）。

## 画面建议
- 开场：先只画“a>b ⟺ a−b>0”一个紫色方块，镜头拉远，节点一层层长出来，最后露出整座大厦的轮廓（可用简化的树形示意，不必复刻整张图）。
- 沿主线走一遍：每经过一个节点就点亮它；在基本不等式那条线上停下，▼ 出现，节点由绿变橙。
- 收尾：从一个题型入口（如“看到 积固定，求和最小”）出发，沿反推箭头回到主干，演示“看到题 → 定位 → 往哪走”。

## 易错点与边界（必须讲到）
- 结论的适用范围看节点上的条件标签，不看它在图上的位置。
- 换元以后要重新检查条件：例如把 x²、y² 代入基本不等式，不要求原来的 x、y 非负。
