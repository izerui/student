# E10｜二次函数的最小值与恒非负

- 建议时长：5–6 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：二次函数最小值；恒非负条件

## 这一集要讲明白的一件事
配方把二次函数变成“平方 + 常数”，最小值和恒非负条件一眼可见。

## 开场问题（不依赖其他集）
二次函数 ax²+bx+c 的最小值是多少？什么时候它对所有 x 都 ≥0？配方之后一眼可见。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **平方非负**
  - x² ≥ 0
  - 等号 ⟺ x=0
  - 由来（简短复习）：x>0 时，x·x 是两个正数相乘，为正；x<0 时，−x>0，x²=(−x)·(−x) 也是两个正数相乘，为正；x=0 时 x²=0。三种情况合起来：x²≥0，只有 x=0 时等号成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【研究对象】二次函数 → 配方结果**（推导；含 2 个小步骤，逐个展开）
   - 【配方法】提取 a，括号内配成完全平方
   - 【记号】记 Δ = b²−4ac
2. **配方结果 → 二次函数最小值**（推导）
   - 【平方非负】a>0，平方项 ≥ 0
   - x = −b/(2a) 时平方项为 0，取到最小值
3. **平方非负 → 二次函数最小值**（提供前提）
   - 【前提】平方非负：a(x+b/(2a))² ≥ 0（a>0）
4. **二次函数最小值 → 恒非负条件**（推导）
   - 【等价变形】恒≥0 ⟺ 最小值≥0
   - 即 −Δ/(4a)≥0 ⟺ Δ≤0
5. **二次函数最小值 → 例：a²−3a+3 = (a−3/2)²+3/4**（推导）
   - 【代入特定值】二次项系数 1、一次项系数 −3、常数项 3（自变量用字母 a）
   - 代入配方结果 a(x+b/(2a))²−Δ/(4a)：a²−3a+3 = (a−3/2)² + 3/4
6. **例：a²−3a+3 = (a−3/2)²+3/4 → (a−3/2)²+3/4 ≥ 3/4 > 0**（推导）
   - 【平方非负】平方≥0，再+3/4
7. **(a−3/2)²+3/4 ≥ 3/4 > 0 → ∴ a²+3 > 3a（任意实数 a）**（推导）
   - 【同加法】两边 +3a

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 【研究对象】二次函数
- f(x) = ax²+bx+c（a>0）
- 起点：这是研究对象的定义，不是推出来的

#### 配方结果
- f(x) = a(x + b/(2a))² − Δ/(4a)，其中 Δ = b²−4ac

#### 二次函数最小值
- f(x) ≥ −Δ/(4a)
- 在 x=−b/(2a) 取到

#### 恒非负条件
- ax²+bx+c ≥ 0 对所有 x
- ⟺ Δ ≤ 0（a>0）

#### 例：a²−3a+3 = (a−3/2)²+3/4

#### (a−3/2)²+3/4 ≥ 3/4 > 0

#### ∴ a²+3 > 3a（任意实数 a）

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- 抛物线平移：y=ax² 平移到顶点 (−b/2a, −Δ/4a)，配方式的每一项对应一次平移。
- Δ 的符号对应抛物线与 x 轴交点个数：0 个、1 个、2 个，三种情况连续变化。

## 解题思维导向（片尾一句话）
二次式求最值、证恒正 → 配方，或看判别式 Δ。

## 易错点与边界（必须讲到）
- a>0 才有最小值；a 含参数时先讨论 a 是否为 0。
- 限定区间时顶点可能不在区间内，要看端点。
