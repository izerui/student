# T06｜题型串讲：含参与导数

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 含参不等式：恒成立 / 能成立
- 恒成立：a ≥ g(x) 对所有 x 成立 ⇔ a ≥ g(x) 的最大值；能成立：存在 x 使 a ≥ g(x) ⇔ a ≥ g(x) 的最小值（最值要能取到）
- 最大（小）值取不到时，看端点或极限，等号要单独判断：例 g(x)=x，x∈(0,1)，恒成立 ⇔ a≥1，能成立 ⇔ a>0
- 参数分离：除以含 x 的式子时，要按它的正、负、零分类（不等号可能变向）
- 不能分离：x∈R 上的二次式，二次项系数>0 时 恒 ≥0 ⇔ Δ≤0（系数含参数时先讨论它是否为 0）；区间上改用最值或根的分布
- 双变量（各最值都取得到时）：∀x₁∃x₂ f(x₁)≥g(x₂) ⇔ f 最小值 ≥ g 最小值；∀∀ ⇔ f 最小值 ≥ g 最大值；∃∃ ⇔ f 最大值 ≥ g 最小值；∃x₁∀x₂ ⇔ f 最大值 ≥ g 最大值
- 去这里查：
- ▸ 【参数分离】按除数正负分类后，化为求 g(x) 的最值 → 【工具】导数判单调
- ▸ 或 判别式法 → 判别式法求范围
- ▸ x∈R 上的二次式：Δ≤0 → 恒非负条件

## 题型 2：看到 含参不等式，分离参数很难
- 必要性探路：设 h(x) 为两边之差，要 h(x)≥0 在区间上恒成立；先找一点 x₀，使无论参数取何值都有 h(x₀)=0，这时 x₀ 就是最小值点
- x₀ 是区间内部的点 ⇒ h′(x₀)=0（切线法）；x₀ 是左端点 ⇒ h′(x₀) ≥ 0（端点效应）；右端点 ⇒ h′(x₀) ≤ 0
- 先由此求出参数的候选值，再证明它确实满足（充分性）；前提是 h(x)≥0 恒成立，只有 h(x₀)=0 推不出 h′(x₀)=0
- 例：eˣ ≥ ax+1 对一切实数 x 恒成立，x=0 时两边都等于 1 且为内点 ⇒ a=1；验证：a=1 时就是 eˣ ≥ 1+x
- 去这里查：
- ▸ 求导找候选值 → 【工具】导数判单调
- ▸ 例：a=1 → eˣ ≥ 1+x

## 题型 3：看到 eˣ、ln x、sinx 与多项式比大小 / 求范围
- 反推：ln x≤x−1、eˣ≥1+x ← 构造函数求导找最小值 ← 导数判单调
- 常用变形：x 换成 1/x 得 ln x ≥ 1−1/x；三角：|sinx| ≤ |x|
- 含参如 eˣ ≥ ax+1 对一切实数 x 恒成立：x=0 时两边相等，故 y=ax+1 须是切线 ⇒ a=1（切线法，再验证）
- 去这里查：
- ▸ ln x ≤ x−1（x>0）：【数形结合】y=ln x 在 y=x−1 下方，x=1 处相切
- ▸ 或 eˣ≥1+x → eˣ ≥ 1+x
- ▸ sinx 与 x 比较 → |sinx| ≤ |x|（x ∈ ℝ）
- **参考例题（已核对）**：比较 e^0.1 与 1.1：由 eˣ ≥ 1+x 且 x≠0 时不取等，e^0.1 > 1.1。

## 题型 4：看到 导数压轴：放缩证明、极值点偏移、抽象函数
- 放缩：用切线不等式（eˣ≥1+x、ln x≤x−1 及其变形）把函数换成一次式
- 求和放缩：ln(1+1/k) < 1/k、裂项放缩、等比放缩
- 极值点偏移：先建立题设联系，再考虑对数平均不等式；抽象函数：把 f′ 与 f 凑成积或商的导数
- 去这里查：
- ▸ 切线放缩 → 切线不等式（切线放缩）
- ▸ 求和放缩 → 对数放缩求和
- ▸ 极值点偏移 → 对数平均不等式（拓展）
- ▸ 抽象函数 → 构造函数（抽象函数）
- ▸ ln(1+x) 放缩 → x/(1+x) ≤ ln(1+x) ≤ x（x > −1）
- ▸ 一阶切线不够精确 → 二阶放缩 eˣ ≥ 1+x+x²/2
- ▸ cos x ≥ 1−x²/2
- ▸ ln(1+x) ≥ x−x²/2
- **参考例题（已核对）**：证明 ln(n+1) < 1+1/2+…+1/n：由 ln(1+1/k) < 1/k，k 从 1 到 n 相加，左边相消成 ln(n+1)。

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **恒成立与能成立**：“对每个 x 都成立”⟺ 最不利的那个值也成立，所以看最大值（或最小值）；“存在一个 x 成立”⟺ 最有利的那个值成立即可。双变量时，对两个变量分别这样想（最值都要能取到）。
- **极值点偏移**：f(x₁)=f(x₂)，x₀ 是 f 的极值点，判断 (x₁+x₂)/2 与 x₀ 的大小。
- **切线法与端点效应的由来**：要 h(x)≥0 恒成立且 h(x₀)=0，x₀ 就是最小值点。可导函数在区间内部取最小值时，该点导数为 0（切线法）；在左端点取最小值时，右边的函数值都不比它小，所以 h′(x₀)≥0（端点效应）；右端点时 h′(x₀)≤0。
- **【工具】导数判单调**
  - 在同一个区间 I 内：f′(x) ≥ 0 ⇒ f(x) 递增（不减）；f′(x) ≤ 0 ⇒ f(x) 递减（不增）
  - f′(x) > 0 ⇒ 严格递增；f′(x) < 0 ⇒ 严格递减
  - 不同区间不能连起来用：如 f(x)=−1/x 在 x<0、x>0 上分别递增，但 f(−1) > f(1)
  - 区间端点要算进去时，函数在端点要连续
  - 由来（简短复习）：课本直接使用的工具（严格证明要用拉格朗日中值定理，超出高中）。直观上：导数是切线的斜率，斜率处处 ≥0，图像就不会往下走。
- **判别式法求范围**
  - 设 y=f(x)/g(x)，若整理为关于 x 的二次方程 h(x)=0
  - x 有实数解 ⇒ Δ≥0，由此得到 y 的取值范围
  - 注意：① 二次项系数含 y 时，系数为 0 要单独讨论
  - ② 求出的 y 要能对应定义域内的 x（g(x)≠0）
  - 由来（简短复习）：把 y 看成已知数，整理成关于 x 的二次方程；y 能取到某个值，就是这个方程有实数解，所以判别式 Δ≥0。
- **恒非负条件**
  - ax²+bx+c ≥ 0 对所有 x
  - ⟺ Δ ≤ 0（a>0）
  - 条件：x∈ℝ；a>0
  - 由来（简短复习）：a>0 时，由配方，f(x) 的最小值是 −Δ/(4a)；f(x)≥0 对所有 x 成立 ⟺ 最小值 ≥0 ⟺ Δ≤0。
- **eˣ ≥ 1+x**
  - 等号 ⟺ x=0
  - 由来（简短复习）：构造 g(x)=eˣ−1−x，g′(x)=eˣ−1：x<0 时 g′<0，x>0 时 g′>0，所以 g 在 x=0 取最小值 g(0)=0，即 g(x)≥0。
- **ln x ≤ x−1（x>0）**
  - 等号 ⟺ x=1
  - 条件：x>0
  - 由来（简短复习）：构造 g(x)=x−1−ln x（x>0），g′(x)=1−1/x：0<x<1 时 g′<0，x>1 时 g′>0，所以 g 在 x=1 取最小值 g(1)=0，即 g(x)≥0。
- **|sinx| ≤ |x|（x ∈ ℝ）**
  - 等号 ⟺ x=0
  - 由来（简短复习）：x≥0 时，f(x)=x−sin x、g(x)=x+sin x 的导数 1−cos x、1+cos x 都 ≥0，且 f(0)=g(0)=0，所以 −x≤sin x≤x，即 |sin x|≤x；x<0 时用 |sin(−x)|=|sin x| 对称过去。
- **切线不等式（切线放缩）**
  - f″(x) ≥ 0（下凸）⇒ f(x) ≥ f(x₀) + f′(x₀)(x−x₀)：图像在切线上方
  - f″(x) ≤ 0（上凸）⇒ 不等号反向：图像在切线下方
  - eˣ ≥ 1+x、eˣ ≥ ex 是下凸的特例；ln x ≤ x−1、ln x ≤ x/e 是上凸的特例
  - 条件：f″ 定号的区间
  - 由来（简短复习）：（f″ 是 f′ 的导数；f″≥0 说明 f′ 不减，曲线下凸。）令 g(x)=f(x)−[f(x₀)+f′(x₀)(x−x₀)]，则 g(x₀)=0，g′(x)=f′(x)−f′(x₀)。f″≥0 时 f′ 不减，所以 x<x₀ 时 g′≤0、x>x₀ 时 g′≥0，g 在 x₀ 取最小值 0，即 g(x)≥0。
- **对数放缩求和**
  - 1/(k+1) < ln(1+1/k) < 1/k（k 为正整数）
  - 条件：正整数 k
  - 由来（简短复习）：在 ln x≤x−1（x≠1 时严格）中令 x=1+1/k，得 ln(1+1/k)<1/k；在 ln x≥1−1/x 中令 x=1+1/k，得 ln(1+1/k)>1/(k+1)。
- **对数平均不等式（拓展）**
  - a,b>0，a≠b：√(ab) < (a−b)/(ln a − ln b) < (a+b)/2
  - 用途：极值点偏移（如证 x₁+x₂ > 2x₀ 一类）；先由题设把 x₁、x₂ 对应到 a、b
  - 条件：a,b>0；a≠b
  - 由来（简短复习）：不妨设 a>b>0，令 t=a/b>1，三者同除以 b，不等式等价于 2(t−1)/(t+1) < ln t < (t−1)/√t；分别构造 g(t)=ln t−2(t−1)/(t+1)、h(t)=(t−1)/√t−ln t，求导可知都在 t>1 上递增，且 g(1)=h(1)=0（拓展内容）。
- **构造函数（抽象函数；在同一区间内可导）**
  - f′+f>0 ⇒ eˣf(x) 递增；f′−f>0 ⇒ f(x)/eˣ 递增
  - xf′+f>0 ⇒ xf(x) 递增；xf′−f>0（x>0）⇒ f(x)/x 递增
  - 看到 f′ 与 f 的组合，就把它们凑成某个积或商的导数
  - 条件：定义域内
  - 由来（简短复习）：例如 (eˣf(x))′=eˣ(f′(x)+f(x))，eˣ>0，所以 f′+f>0 时导数为正，eˣf(x) 递增；(f(x)/x)′=(xf′−f)/x² 等其余几种同理，都是积、商的求导法则。
- **x/(1+x) ≤ ln(1+x) ≤ x（x > −1）**
  - 等号 ⟺ x=0
  - 条件：x>−1
  - 由来（简短复习）：在 ln t≤t−1 中令 t=1+x（x>−1）得 ln(1+x)≤x；在 ln t≥1−1/t 中令 t=1+x 得 ln(1+x)≥x/(1+x)。
- **eˣ ≥ 1 + x + x²/2（x≥0）**
  - x≤0 时不等号反向：eˣ ≤ 1 + x + x²/2
  - 等号 ⟺ x=0
  - 条件：x≥0（x≤0 时反向）
  - 由来（简短复习）：构造 g(x)=eˣ−1−x−x²/2，g′(x)=eˣ−1−x≥0（由 eˣ≥1+x），所以 g 在 ℝ 上递增，g(0)=0：x≥0 时 g(x)≥0，x≤0 时 g(x)≤0。
- **cos x ≥ 1 − x²/2（x∈ℝ）**
  - 等号 ⟺ x=0
  - 由来（简短复习）：构造 f(x)=cos x−1+x²/2，f′(x)=x−sin x，x≥0 时 ≥0（由 |sin x|≤|x|），所以 x≥0 时 f(x)≥f(0)=0；f 是偶函数，x<0 时也成立。
- **ln(1+x) ≥ x − x²/2（x≥0）**
  - −1<x≤0 时不等号反向；等号 ⟺ x=0
  - 条件：x≥0（−1<x≤0 时反向）
  - 由来（简短复习）：构造 φ(x)=ln(1+x)−x+x²/2（x>−1），φ′(x)=1/(1+x)−1+x=x²/(1+x)≥0，所以 φ 递增，φ(0)=0：x≥0 时 φ(x)≥0。
- **一元二次方程根的分布（a>0；重根算两个根）**
  - 两根都大于 k ⟺ Δ ≥ 0，−b/(2a) > k，f(k) > 0
  - 一根大于 k、一根小于 k ⟺ f(k) < 0
  - 两根都在 (m,n) 内 ⟺ Δ ≥ 0，m < −b/(2a) < n，f(m) > 0，f(n) > 0
  - 条件：a>0
  - 由来（简短复习）：a>0 时抛物线开口向上。“两根都大于 k”：先要有两根（Δ≥0），对称轴在 k 的右边，且 x=k 处函数值为正（k 在两根外侧）。f(k)<0 说明 x=k 处在 x 轴下方，k 一定在两根之间。
- **裂项放缩**
  - 1/k² < 1/(k(k−1)) = 1/(k−1) − 1/k（k≥2）
  - n≥2：1 + 1/2² + … + 1/n² < 2 − 1/n < 2
  - 条件：正整数 k≥2
  - 由来（简短复习）：k≥2 时 k²>k(k−1)>0，取倒数得 1/k²<1/(k(k−1))=1/(k−1)−1/k；从 k=2 加到 n，中间项一对对相消，只剩 1−1/n，再加上第一项 1。
- **等比放缩（aₖ>0）**
  - 若 aₖ₊₁ ≤ q·aₖ（0<q<1）
  - 则 a₁+…+aₙ ≤ a₁(1−qⁿ)/(1−q) < a₁/(1−q)
  - 条件：aₖ>0；0<q<1
  - 由来（简短复习）：由 aₖ₊₁≤q·aₖ 反复使用，得 aₖ≤a₁qᵏ⁻¹；逐项相加，再用等比数列求和公式。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
