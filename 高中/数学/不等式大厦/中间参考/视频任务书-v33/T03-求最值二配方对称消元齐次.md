# T03｜题型串讲：求最值（二）配方、对称、消元、齐次

- 建议时长：每个题型 1.5–3 分钟，整集 6–10 分钟；叙事模型：问题求解七拍（见 story-models.md）
- 讲法：每个题型都按“看到什么 → 反推到哪 → 先查什么 → 例题演示”的顺序；用到的结论先按下方“本集先补齐的基础”写出公式、条件和理由。

## 题型 1：看到 a²+b² / 平方和结构
- 反推：a²+b²≥2ab ← (a−b)²≥0 ← 平方非负
- 三个数时：a²+b²+c² ≥ ab+bc+ca（三组配对相加）
- 用法：平方和求下界，或积 ab 求上界
- 去这里查：
- ▸ a²+b² ≥ 2ab
- ▸ 三个数时 → a²+b²+c² ≥ ab+bc+ca
- **参考例题（已核对）**：a²+b²=2，求 ab 的最大值：ab ≤ (a²+b²)/2 = 1，a=b=1 或 a=b=−1 时取到。

## 题型 2：看到 对称式 a+b、ab
- 反推：设 s=a+b, p=ab → 均值代换 ← 韦达定理、a²+b²=s²−2p
- 隐含约束：a,b 为实数 ⇒ s²≥4p（来自 (a−b)²≥0）
- 去这里查：
- ▸ 均值代换
- **参考例题（已核对）**：a+b=3，ab=1：a²+b² = 9−2 = 7，a³+b³ = (a+b)³−3ab(a+b) = 27−9 = 18；且 s²=9 ≥ 4p=4，说明 a、b 确实是实数。

## 题型 3：看到 多变量最值，有等式约束
- 消元：由约束解出一个变量代入，化成一元函数再求最值
- 换元：三角换元、均值代换（a+b=s, ab=p）、增量换元（设 a=x+t）
- 主元法：把某个字母看成主变量，其余看成常数；调整法：保持原约束，调整变量使目标更优
- 去这里查：
- ▸ 均值代换 → 均值代换
- ▸ 消元后求导 → 【工具】导数判单调
- ▸ 调整法 → 排序不等式（n 个数）
- **参考例题（已核对）**：x+y=1，x,y≥0，求 x²+y² 的最小值：消元得 2x²−2x+1，x=1/2 时最小值 1/2。

## 题型 4：看到 分式求最值，分子分母同次（齐次式）
- 反推：齐次化——令 t=y/x 化成单变量
- 先查：分子、分母每一项的次数都相同才行（只是最高次相同不够），或已知条件能把比例消掉；x=0 先单独处理
- 再用判别式法（化为关于 t 的二次方程，Δ≥0）或导数求最值；换元后保留原来的取值范围
- 去这里查：
- ▸ 【齐次化】令 t=y/x 化成单变量，再用判别式 → 判别式法求范围
- ▸ 或 求导 → 【工具】导数判单调
- **参考例题（已核对）**：求 (x²+xy+y²)/(x²+y²) 的取值范围：x=0 时值为 1；x≠0 时令 t=y/x，化为 (z−1)t²−t+(z−1)=0，z≠1 时 Δ=1−4(z−1)² ≥ 0，得 1/2 ≤ z ≤ 3/2（t=−1、t=1 时取到端点），范围 [1/2, 3/2]。

## 题型 5：看到 二次函数 ax²+bx+c 求最值
- 反推：二次函数最值 ← 配方 a(x+b/2a)²−Δ/4a ← 平方非负
- 先查 a：a>0 顶点处最小，a<0 顶点处最大；a=0 时不是二次函数，按一次函数或常数处理
- 先查区间：顶点 x=−b/(2a) 不在区间内就看端点；端点不含在内或区间无界（看 x→∞）时，最值可能取不到
- 去这里查：
- ▸ 【配方法】求顶点，【数形结合】看抛物线最低点 → 二次函数最小值
- **参考例题（已核对）**：f(x)=x²−4x+5 在 [0,3] 上：顶点 x=2 在区间内，最小值 f(2)=1；a>0 时离对称轴越远函数值越大，x=0 比 x=3 离对称轴远，所以最大值 f(0)=5（f(3)=2）。

## 本集先补齐的基础（题型里用到的结论：用到时写出公式和条件，一两句话复习由来；重点仍放在解题）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **二次函数的远近规律**：f(x)=a(x−h)²+k（h 是对称轴），a>0 时函数值随 |x−h| 增大而增大：x 离对称轴越远，函数值越大。
- **a²+b² ≥ 2ab**
  - 等号 ⟺ a=b
  - 由来（简短复习）：由“平方非负”，(a−b)²≥0；展开得 a²−2ab+b²≥0，移项得 a²+b²≥2ab。等号 ⟺ a−b=0，即 a=b。
- **a²+b²+c² ≥ ab+bc+ca**
  - 等号 ⟺ a=b=c
  - 由来（简短复习）：三组配对：a²+b²≥2ab、b²+c²≥2bc、c²+a²≥2ca（每一个都由 (x−y)²≥0 得到），三式相加再除以 2。
- **均值代换**
  - 令 a+b=s，ab=p
  - 则 a²+b² = s²−2p
  - (a−b)² = s²−4p ≥ 0 ⇒ p ≤ s²/4
  - 把不等式转化为关于 s,p 的问题
  - 由来（简短复习）：由 (a+b)²=a²+2ab+b² 得 a²+b²=s²−2p；(a−b)²=s²−4p≥0（平方非负）；a、b 就是方程 t²−st+p=0 的两个根。
- **【工具】导数判单调**
  - 在同一个区间 I 内：f′(x) ≥ 0 ⇒ f(x) 递增（不减）；f′(x) ≤ 0 ⇒ f(x) 递减（不增）
  - f′(x) > 0 ⇒ 严格递增；f′(x) < 0 ⇒ 严格递减
  - 不同区间不能连起来用：如 f(x)=−1/x 在 x<0、x>0 上分别递增，但 f(−1) > f(1)
  - 区间端点要算进去时，函数在端点要连续
  - 由来（简短复习）：课本直接使用的工具（严格证明要用拉格朗日中值定理，超出高中）。直观上：导数是切线的斜率，斜率处处 ≥0，图像就不会往下走。
- **排序不等式（n 个数）**
  - a₁≤a₂≤…≤aₙ，b₁≤b₂≤…≤bₙ
  - 同序和 a₁b₁+…+aₙbₙ ≥ 任意打乱后的和 ≥ 逆序和 a₁bₙ+…+aₙb₁
  - 例：a₁b₁+a₂b₂+a₃b₃ ≥ a₁b₂+a₂b₃+a₃b₁ ≥ a₁b₃+a₂b₂+a₃b₁
  - 取最大值 ⇔ 打乱后仍是同序：aᵢ<aⱼ 时，配给 aⱼ 的 b 不小于配给 aᵢ 的 b；最小值反过来
  - 等号：打乱后的和与同序（或逆序）一样，如 a 值相等的位置互换、某组数全相等
  - 由来（简短复习）：两数时由作差 (a₂−a₁)(b₂−b₁)≥0 得到。n 个数时，任意一种配对里只要有一对是“逆序”的，交换它们，和不会变小；反复交换，直到变成同序。
- **判别式法求范围**
  - 设 y=f(x)/g(x)，若整理为关于 x 的二次方程 h(x)=0
  - x 有实数解 ⇒ Δ≥0，由此得到 y 的取值范围
  - 注意：① 二次项系数含 y 时，系数为 0 要单独讨论
  - ② 求出的 y 要能对应定义域内的 x（g(x)≠0）
  - 由来（简短复习）：把 y 看成已知数，整理成关于 x 的二次方程；y 能取到某个值，就是这个方程有实数解，所以判别式 Δ≥0。
- **二次函数最小值**
  - f(x) ≥ −Δ/(4a)
  - 在 x=−b/(2a) 取到
  - 条件：x∈ℝ；a>0
  - 由来（简短复习）：配方：f(x)=a(x+b/(2a))²+(4ac−b²)/(4a)=a(x+b/(2a))²−Δ/(4a)。a>0 时第一项是正数乘一个平方，≥0，所以 f(x)≥−Δ/(4a)，x=−b/(2a) 时取等。

## 制作要求（每集通用）
### 每集独立完整（最重要）
- **验收标准**：一个没看过其他任何一集、也没见过总图的高中生，看完本集，能否知道**每一步为什么成立**。做不到就不算完成。
- 本集用到的每个结论，都按“本集先补齐的基础”在片中**写出公式、写出条件、用一两句话复习由来**，不能用“前面讲过”“上一集学过”代替。复习要短，时间主要给本集的新推导。
- 不要求接上一集、预告下一集；开场用“开场问题”直接进入。编号、坐标、系列顺序只是制作元数据，不进入讲解。
### 连贯、不跳步
- **一步只做一件事**：推导过程里每条线可能含多个【方法】，视频中每个【方法】单独成一步，写出中间式子；“展开得”“整理即得”这类说法必须把中间结果写出来。
- **每一步按“为什么想到 → 怎么做 → 得到什么”讲**：先说动机（我们想要什么、手里有什么、所以试试这个方法），再动手，最后指出得到的式子和目标差在哪里。
### 着重标注（统一规范）
- 条件（≥0、>0、非零、定义域、区间）用橙色框；**▼ 加条件的那一步停顿 1–2 秒**，说明为什么必须加，并给出去掉条件的反例（反例用叉号，不只靠颜色）。
- 区分“运算能不能做”和“比较规则成不成立”：例如负数也能取倒数、相除，只是比较大小的规则要看符号，不能讲成运算禁令。
- 等号成立条件单独一行框出；关键变形（代换、配凑、构造、放缩）用高亮色；最终结论用粗框。
- 屏幕上同时保留的高亮不超过两处，讲完的标注及时淡出。
### 数形结合
- 图要简单到**学生能在草稿纸上自己画出来**（一般不超过三个对象），画面先出图、再从图里“读出”不等式，最后把图和式子一一对应。
- 每个图讲完都说一句“以后遇到什么样的题，可以画这张图”，让学生把它变成自己的工具。
### 解题导向与内容依据
- 片尾用一句话给出“以后看到什么 → 想到什么”（见本集的“解题思维导向”）。
- 用 manim-video 流程制作；本任务书是**内容依据**，讲法、画面由制作方按 skill 的制作指南设计。
- **结论、条件、取等写法以本任务书为准**，不得自行简化或改写条件（如把“a,b≥0”写成“a,b>0”，或省掉“含零向量”）。数值必须自己再算一遍。
- 叙述用高中生听得懂的说法，不用“线性相关、仿射、上下确界”这类超纲术语。
