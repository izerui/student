# E20｜切线放缩、构造函数与比大小

- 建议时长：6–8 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：切线不等式（切线放缩）；构造函数（抽象函数；在同一区间内可导）；构造 f(x) = ln x / x 比大小（x>0）；|sinx| ≤ |x|（x ∈ ℝ）；sin x < x < tan x（0 < x < π/2）

## 这一集要讲明白的一件事
在凹凸性不变的区间内，下凸函数在切线上方，切线给出下界；上凸函数在切线下方，切线给出上界。这是“切线放缩”的两种方向；构造函数把比大小变成单调性问题。

## 开场问题（不依赖其他集）
为什么 eˣ≥1+x（x∈ℝ）、ln x≤x−1（x>0）这类“切线不等式”都成立？关键是凹凸性决定曲线与切线的上下关系：eˣ 下凸，在 x=0 处的切线 y=1+x 上方，切线给出下界；ln x 上凸，在 x=1 处的切线 y=x−1 下方，切线给出上界。

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- 记号：f″ 是 f′ 的导数；f″≥0 说明 f′ 不减，曲线“下凸”（整条曲线在任一切线上方）；f″≤0 叫“上凸”。
- **三角函数的导数**：(sin x)′=cos x，(cos x)′=−sin x；由商的求导法则 (tan x)′=1/cos²x；|cos x|≤1。
- **对数的性质**：ln 是增函数；ln(aᵇ)=b·ln a（a>0）。
- **两个特例的凹凸**：(eˣ)″=eˣ>0，所以 eˣ 下凸；(ln x)″=(1/x)′=−1/x²<0，所以 ln x 上凸。
- **导数只在个别点为 0 也是严格递增**：f′≥0 且只在个别点为 0 时：若 f(x₁)=f(x₂)（x₁<x₂），f 不减，就在 [x₁,x₂] 上是常数，导数在整段上为 0，矛盾。
- **【工具】导数判单调**
  - 在同一个区间 I 内：f′(x) ≥ 0 ⇒ f(x) 递增（不减）；f′(x) ≤ 0 ⇒ f(x) 递减（不增）
  - f′(x) > 0 ⇒ 严格递增；f′(x) < 0 ⇒ 严格递减
  - 不同区间不能连起来用：如 f(x)=−1/x 在 x<0、x>0 上分别递增，但 f(−1) > f(1)
  - 区间端点要算进去时，函数在端点要连续
  - 由来（简短复习）：课本直接使用的工具（严格证明要用拉格朗日中值定理，超出高中）。直观上：导数是切线的斜率，斜率处处 ≥0，图像就不会往下走。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【工具】导数判单调 → 构造函数（抽象函数；在同一区间内可导）**（推导；含 2 个小步骤，逐个展开）
   - 【构造法】(eˣf)′=eˣ(f′+f)，(f/eˣ)′=(f′−f)/eˣ
   - (xf)′=f+xf′，(f/x)′=(xf′−f)/x²
   - 【求导】导数的符号已知 ⇒ 用导数判单调
2. **【工具】导数判单调 → 切线不等式（切线放缩）**（推导；含 3 个小步骤，逐个展开）
   - 【构造法】令 g(x) = f(x) − [f(x₀) + f′(x₀)(x−x₀)]
   - f″≥0 ⇒ f′ 不减 ⇒ g′ = f′(x) − f′(x₀) 在 x₀ 左侧≤0、右侧≥0
   - 【极值判断】g(x) ≥ g(x₀) = 0；f″≤0 时同理反向
   - 【数形结合】f″≥0 时图像下凸，整条曲线在切线上方
3. **【工具】导数判单调 → 构造 f(x) = ln x / x 比大小（x>0）**（推导；含 2 个小步骤，逐个展开）
   - 【构造法】把 aᵇ 与 bᵃ 取对数，化为比较 ln a / a 与 ln b / b
   - 【求导】f′ = (1 − ln x)/x²，按 x 与 e 的大小分类
4. **【工具】导数判单调 → |sinx| ≤ |x|（x ∈ ℝ）**（推导；含 3 个小步骤，逐个展开）
   - 【构造法】令 f(x)=x−sinx，g(x)=x+sinx（x≥0）
   - 【求导】f′=1−cosx≥0，g′=1+cosx≥0，且 f(0)=g(0)=0
   - ⇒ x≥0 时 −x ≤ sinx ≤ x，即 |sinx| ≤ x
   - x>0 时导数只在个别点为 0 ⇒ f(x)>0、g(x)>0：只有 x=0 取等
   - 【对称性】x<0 时用 |sin(−x)|=|sinx|，得 |sinx| ≤ |x|
5. **|sinx| ≤ |x|（x ∈ ℝ） → sin x < x < tan x（0 < x < π/2）**（提供前提）
   - ▼ 加条件：0<x<π/2
   - 【前提】|sin x| ≤ |x|，x>0 时取不到等号 ⇒ sin x < x
6. **【工具】导数判单调 → sin x < x < tan x（0 < x < π/2）**（推导；含 2 个小步骤，逐个展开）
   - 【构造法】令 g(x) = tan x − x
   - 【求导】g′ = 1/cos²x − 1 = tan²x > 0，g(0)=0 ⇒ tan x > x

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 切线不等式（切线放缩）
- f″(x) ≥ 0（下凸）⇒ f(x) ≥ f(x₀) + f′(x₀)(x−x₀)：图像在切线上方
- f″(x) ≤ 0（上凸）⇒ 不等号反向：图像在切线下方
- eˣ ≥ 1+x、eˣ ≥ ex 是下凸的特例；ln x ≤ x−1、ln x ≤ x/e 是上凸的特例

#### 构造函数（抽象函数；在同一区间内可导）
- f′+f>0 ⇒ eˣf(x) 递增；f′−f>0 ⇒ f(x)/eˣ 递增
- xf′+f>0 ⇒ xf(x) 递增；xf′−f>0（x>0）⇒ f(x)/x 递增
- 看到 f′ 与 f 的组合，就把它们凑成某个积或商的导数
- ⇐ 工具 ㊵ 求导法则：㊵ 积、商的求导法则

#### 构造 f(x) = ln x / x 比大小（x>0）
- f′(x) = (1 − ln x)/x²：(0,e) 递增，(e,+∞) 递减
- 最大值 f(e) = 1/e ⇒ ln x ≤ x/e
- 例：f(e) > f(π) ⇒ π > e·ln π ⇒ e^π > π^e

#### |sinx| ≤ |x|（x ∈ ℝ）
- 等号 ⟺ x=0

#### sin x < x < tan x（0 < x < π/2）
- ⇐ 工具 ㉞ 正切与余弦：1/cos²x = 1 + tan²x

## 用到的公式工具（片中写出公式即可，不展开推导）
- ㉞ 正切与余弦；1+tan²θ = 1/cos²θ（cosθ≠0）；（由 sin²+cos²=1 两边÷cos²θ）
- ㊵ 求导法则（u,v 可导；商要求 v≠0）；(uv)′=u′v+uv′；(u/v)′=(u′v−uv′)/v²；(eˣ)′=eˣ；(ln x)′=1/x（x>0）

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）
- f″≥0 时曲线下凸，任意一点的切线都在曲线下方，拖动切点演示。
- f(x)=ln x/x 的图像在 x=e 处最高，用它比较 e^π 与 π^e。
- 单位圆中三块面积：三角形 < 扇形 < 大三角形，对应 sin x < x < tan x。
