# E04｜非负数的平方、乘方与相乘

- 建议时长：4–5 分钟；叙事模型：逐步构建（见 manim-video 的 story-models.md）
- 本集结论：非负数平方保序；同向非负不等式可乘；异向正数不等式可除；乘方与开方保序

## 这一集要讲明白的一件事
两边都非负时，可以放心地平方、开方、相乘，不等号方向不变；异向的正数不等式可以相除。

## 开场问题（不依赖其他集）
a<b 时，能推出 a²<b² 吗？试一下 −3<−2：平方后 9>4，方向反了。什么时候平方、开方、相乘才不改变方向？

## 本集先补齐的基础（开场后简短复习：写出公式和条件，一两句话讲清由来；每条不超过约 20 秒，重点仍放在本集）
- 本集默认使用的基本规则（片头一句话带过，用到时写出）：a>b ⟺ a−b>0；不等式两边同加（减）同一个数方向不变（移项）；两边同乘（除）同一个正数方向不变，乘负数方向反向，乘非负数时“≥”保持；正×正=正，正÷正=正，有一个因子为 0 时乘积为 0；同向不等式可以相加。
- **【公理】正数相乘**
  - 正数 × 正数 = 正数
  - 由来（简短复习）：这是实数的基本规定（公理），直接承认：两个正数相乘还是正数。
- **正数乘法保序**
  - a>b, c>0 ⇒ ac > bc
  - 条件：a,b∈ℝ；c>0
  - 由来（简短复习）：a>b 即 a−b>0；c>0 时，(a−b)c 是两个正数相乘，为正，即 ac−bc>0，所以 ac>bc。
- **正数倒数反序**
  - 0<a<b ⇒ 1/a > 1/b
  - （一般地：ab>0 时，a>b ⇒ 1/a < 1/b）
  - 条件：0<a<b；一般式 ab>0
  - 由来（简短复习）：作差：1/a−1/b=(b−a)/(ab)。0<a<b 时分子 b−a>0、分母 ab>0，差为正，所以 1/a>1/b。一般地只要 ab>0（两数同号）同样成立。

## 推导过程（按顺序讲；每一步讲“为什么想到 → 怎么做 → 得到什么”）
1. **【公理】正数相乘 → 非负数平方保序**（推导；含 2 个小步骤，逐个展开）
   - ▼ 进入正数域：0≤a<b
   - 【作差法】b²−a² = (b+a)(b−a)
   - b+a>0，b−a>0，正×正=正 ⇒ b²−a²>0
   - 【反证法】反过来：若 a,b≥0 且 a²<b²，假设 a≥b，由上式得 a²≥b²，矛盾，所以 a<b
2. **正数乘法保序 → 同向非负不等式可乘**（推导）
   - 【作差法】ac − bd = (a−b)c + b(c−d)
   - a−b ≥ 0、c ≥ 0 ⇒ (a−b)c ≥ 0；b ≥ 0、c−d ≥ 0 ⇒ b(c−d) ≥ 0
   - 两式都严格（a>b，c>d≥0）时 c>0，(a−b)c>0 ⇒ ac>bd
3. **同向非负不等式可乘 → 乘方与开方保序**（推导；含 2 个小步骤，逐个展开）
   - 【归纳法】由 aᵏ>bᵏ≥0 与 a>b≥0 两式相乘，得 aᵏ⁺¹>bᵏ⁺¹
   - 【反证法】开方：若 ⁿ√a ≤ ⁿ√b，乘方后 a ≤ b，矛盾
4. **同向非负不等式可乘 → 异向正数不等式可除**（推导；含 2 个小步骤，逐个展开）
   - 【倒数法】c>d>0 ⇒ 1/d > 1/c > 0
   - 【同向相乘】a>b>0 与 1/d>1/c>0 相乘：a·(1/d) > b·(1/c)
5. **正数倒数反序 → 异向正数不等式可除**（提供前提）
   - 【前提】正数倒数反序：c>d>0 ⇒ 1/d > 1/c

## 本集各结论的完整内容（结论、条件、取等以此为准）
#### 非负数平方保序
- 0 ≤ a < b ⇒ a² < b²
- 反过来：a,b ≥ 0 时，a² < b² ⇒ a < b（可两边开平方）
- ⇐ 工具 ① 平方差公式：用①把 b²−a² 分解为 (b+a)(b−a)

#### 同向非负不等式可乘
- a≥b≥0，c≥d≥0 ⇒ ac≥bd
- 若 a>b≥0 且 c>d≥0，则 ac>bd

#### 异向正数不等式可除
- a>b>0，c>d>0 ⇒ a/d > b/c
- ⚠ 同向正数不等式不能相除：4>3，4>1，但 4/4=1 < 3/1=3

#### 乘方与开方保序
- a>b≥0 ⇒ aⁿ>bⁿ，ⁿ√a > ⁿ√b（n 为正整数）

## 用到的公式工具（片中写出公式即可，不展开推导）
- ① 平方差公式；a²−b² = (a+b)(a−b)

## 画面建议（数形结合：先出图，再从图中读出结论；图要学生能自己画、能套用）

## 解题思维导向（片尾一句话）

## 易错点与边界（必须讲到）
- 有 0 时，严格不等号可能变成等号，要单独判断。
- 本结论要求两边非负：负数开偶次方没有意义；去掉非负时乘方本身会出错（−3<−2，但 9>4）。注意：奇次乘方、奇次方根在全体实数上都保序（如 ∛(−8)=−2<∛(−1)=−1），不要讲成“负数开奇次方不保序”。
- 同向正数不等式不能相除：4>3，4>1，但 4/4=1<3/1=3；相除要先把除数那一式取倒数、变成同向，再相乘。
