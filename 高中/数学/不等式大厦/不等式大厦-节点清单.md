## 第 0 层　地基：公理与定义

### R01 正余弦有界
- 标志：$-1 \le  \sin \theta  \le  1$，$-1 \le  \cos \theta  \le  1$
- 区域：实数域
- 类型：中间步
- 条件：任意实数
- 是什么：由勾股恒等式 $\sin^{2}\theta = 1-\cos^{2}\theta \le 1$
- 依赖：
  - 来源：T12
    种类：用到
    方法：代入消元
    步骤：
      1. 用「勾股恒等式」$\sin^{2}\theta + \cos^{2}\theta = 1$，得 $\sin^{2}\theta = 1 - \cos^{2}\theta \le 1$，即 $|\sin\theta| \le 1$

### S01 实数大小
- 标志：$a\gt b \iff  a-b\gt 0$（$a-b$ 是正数）
- 区域：起点
- 类型：起点
- 标签：【公理】
- 条件：任意实数
- 是什么：任意两个实数 a、b：$a\gt b$、$a=b$、$a\lt b$ 恰有一种成立；正数 + 正数 = 正数（由此得传递性：$a \gt  b$，$b \gt  c \Rightarrow  a \gt  c$）；对称性：$a \gt  b \iff  b \lt  a$（两者都表示 $a - b$ 是正数）；边界：大小只对实数规定；虚数之间不能比较大小

### S02 正数相乘
- 标志：正数 × 正数 = 正数
- 区域：起点
- 类型：起点
- 标签：【公理】
- 条件：任意实数
- 是什么：正数 × 正数 = 正数

### S03 绝对值定义
- 标志：$x\ge 0$ 时 $|x|=x$
- 区域：起点
- 类型：起点
- 标签：【定义】
- 条件：任意实数
- 是什么：$x\lt 0$ 时 $|x|=-x$

### S04 导数判单调
- 标志：$f'(x) \ge 0 \Rightarrow f(x)$ 不减；$f'(x) \le 0 \Rightarrow f(x)$ 不增
- 区域：起点
- 类型：起点
- 标签：【定理】
- 是什么：在同一个区间 I 内：$f'(x) \ge 0 \Rightarrow f(x)$ 递增（不减）；$f'(x) \le 0 \Rightarrow f(x)$ 递减（不增）；$f'(x) \gt 0 \Rightarrow$ 严格递增；$f'(x) \lt 0 \Rightarrow$ 严格递减；不同区间不能连起来用：如 $f(x)=-\dfrac{1}{x}$ 在 $x\lt 0$、$x\gt 0$ 上分别递增，但 $f(-1) \gt f(1)$；区间端点要算进去时，函数在端点要连续

### S05 二次函数
- 标志：$f(x) = ax^{2}+bx+c$（$a\gt 0$）
- 区域：起点
- 类型：起点
- 标签：【研究对象】
- 条件：x∈ℝ；a>0
- 是什么：$f(x) = ax^{2}+bx+c$（$a\gt 0$）

### S06 数学归纳法
- 标志：$P(n_{0})$ 成立，且 $k \ge  n_{0}$ 时 $P(k) \Rightarrow  P(k+1)$
- 区域：起点
- 类型：起点
- 标签：【公理】
- 是什么：⇒ 对所有 $n \ge  n_{0}$ 的正整数 n 成立（$n_{0}$ 不一定是 1，如证 $n \ge  5$ 时 $2^{n} \gt  n^{2}$）

### S07 函数单调性
- 标志：增函数：区间 I 上任取 $x_{1}\lt x_{2}$，都有 $f(x_{1})\lt f(x_{2})$
- 区域：起点
- 类型：起点
- 标签：【定义】
- 条件：任意实数
- 是什么：减函数：区间 I 上任取 $x_{1}\lt x_{2}$，都有 $f(x_{1})\gt f(x_{2})$

### S08 集合与区间
- 标志：交集 A∩B：同时属于 A 和 B；并集 A∪B：属于 A 或属于 B
- 区域：起点
- 类型：起点
- 标签：【定义】
- 是什么：区间：(a,b)、[a,b]、$(a,+\infty)$、$(-\infty ,b]$ 等；圆括号不含端点，方括号含端点

### S09 函数奇偶性（定义域关于原点对称）
- 标志：偶函数：$f(-x)=f(x)$，图像关于 y 轴对称
- 区域：起点
- 类型：起点
- 标签：【定义】
- 是什么：奇函数：$f(-x)=-f(x)$，图像关于原点对称


### T01 平方差公式
- 标志：$a^{2}-b^{2} = (a+b)(a-b)$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：▸ 用在 作差比大小：$b^{2}-a^{2}$ 拆成 $(b+a)(b-a)$，两个因式分别定号 ；▸ 用在 根式裂项：$\left(\sqrt{k}+\sqrt{k-1}\right)\left(\sqrt{k}-\sqrt{k-1}\right) = 1$，分母有理化 ；柯西不等式（二项）

### T02 完全平方公式
- 标志：$(a\pm b)^{2} = a^{2}\pm 2ab+b^{2}$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：▸ 用在 证明的起点：展开 $(a-b)^{2} \ge 0$ 得 $a^{2}+b^{2} \ge 2ab$；柯西推导中展开 $(ad-bc)^{2} \ge 0$ ；▸ 用在 反过来用就是配方：凑成 $(\cdots)^{2} +$ 常数，判正负、求二次函数最值

### T03 立方和公式
- 标志：$a^{3}+b^{3} = (a+b)(a^{2}-ab+b^{2})$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：▸ 用在 作差后分解定号：$a^{3}+b^{3}-ab(a+b) = (a+b)(a-b)^{2}$

### T04 立方差公式
- 标志：$a^{3}-b^{3} = (a-b)(a^{2}+ab+b^{2})$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：▸ 用在 高次不等式先分解：$x^{3}-1 = (x-1)(x^{2}+x+1)$，后一个因式恒正，可约去

### T05 三数和的平方
- 标志：$(a+b+c)^{2} = a^{2}+b^{2}+c^{2}+2ab+2ac+2bc$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：三个数的和的平方等于各项平方和加所有两两乘积的两倍。用在展开 $(a+b+c)^{2}$ 后与 $a^{2}+b^{2}+c^{2}$ 和 $ab+bc+ca$ 互换

### T06 二项式定理（n 为非负整数）
- 标志：$(a+b)^{n} = \sum _{k=0}^{n} C(n,k)a^{n-k}b^{k}$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：n 为非负整数
- 是什么：$(a+b)^{n}$ 展开为 $n+1$ 项的和，每项系数为组合数 $C(n,k)$。用在证明伯努利不等式（$x \ge 0$ 时去掉高次项）、估计 $(1+x)^{n}$ 的大小

### T07 平方和与积的互换
- 标志：$a^{2}+b^{2} = (a+b)^{2}-2ab$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：▸ 用在 已知 $a+b$、ab，求 $a^{2}+b^{2}$：和积代换 s、p ；▸ 用在 比较平方和与和的平方：$2(a^{2}+b^{2}) \ge (a+b)^{2}$ ；（平方和与积的互换）

### T08 立方和与积的互换
- 标志：$a^{3}+b^{3} = (a+b)^{3}-3ab(a+b)$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：$a^{3}+b^{3}$ 可以写成 $(a+b)^{3}-3ab(a+b)$，把立方和与一次式和积联系起来。用在对称不等式中把高次项化为和与积的表达式

### T09 三元平方和与交叉积互换
- 标志：$a^{2}+b^{2}+c^{2} = (a+b+c)^{2}-2(ab+bc+ca)$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：$a^{2}+b^{2}+c^{2} = (a+b+c)^{2}-2(ab+bc+ca)$，在平方和与交叉积之间互换。用在证明 $(a+b+c)^{2} \ge 3(ab+bc+ca)$ 等三元不等式

### T10 韦达定理
- 标志：$ax^{2}+bx+c=0$（$a\ne 0$），实根 $x_{1},x_{2}$ 按重数计：$x_{1}+x_{2}=-\dfrac{b}{a}$，$x_{1}x_{2}=\dfrac{c}{a}$；在实数范围须 $\Delta \ge 0$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：$a \ne 0$；$\Delta \ge 0$（实根）
- 是什么：▸ 用在 已知解集反求系数：解集端点就是两根，用两根之和、之积列方程 ；▸ 用在 对称式 $a+b$、ab：把 a、b 看成 $t^{2}-st+p=0$ 的两根，实根要求 $s^{2} \ge 4p$ ；二次函数最小值——已知两根时，顶点 $x=-\dfrac{b}{2a}=\dfrac{x_{1}+x_{2}}{2}$

### T11 对数运算律
- 标志：$M,N\gt 0$：$\log_{q} (MN)=\log_{q}  M+\log_{q}  N$；$M\gt 0$，$t\in \mathbb{R}$：$\log_{q} (M^{t})=t \log_{q}  M$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：底数 $q \gt 0$ 且 $q \ne 1$；真数 $M, N \gt 0$
- 是什么：▸ 用在 对数放缩求和：$\ln \left(1+\dfrac{1}{k}\right) = \ln (k+1) - \ln k$，逐项相消 ；▸ 用在 对数平均：$\ln a - \ln b = \ln \left(\dfrac{a}{b}\right)$，令 $t = \dfrac{a}{b}$ 化成单变量 ；▸ 用在 指数、对数不等式：先化成同底，再用单调性

### T12 勾股恒等式
- 标志：$\sin^{2} \theta +\cos^{2} \theta  = 1$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：▸ 用在 正余弦有界：$\sin^{2} \theta = 1 - \cos^{2} \theta \le 1$ ；▸ 用在 三角有界：配合柯西或 $a^{2}+b^{2} \ge 2ab$，用 $\sin^{2} \theta +\cos^{2} \theta = 1$ 化成常数

### T13 倍角公式
- 标志：$\sin 2\alpha =2\sin \alpha \cos \alpha$；$\cos 2\alpha =\cos^{2} \alpha -\sin^{2} \alpha =2\cos^{2} \alpha -1$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：$\sin 2\alpha =2\sin \alpha \cos \alpha$；$\cos 2\alpha =\cos^{2} \alpha -\sin^{2} \alpha =2\cos^{2} \alpha -1$

### T14 辅助角公式
- 标志：$a\sin \theta +b\cos \theta  = \sqrt{a^{2}+b^{2}}\cdot \sin (\theta +\varphi)$；其中 $\cos \varphi  = \dfrac{a}{\sqrt{a^{2}+b^{2}}}$，$\sin \varphi  = \dfrac{b}{\sqrt{a^{2}+b^{2}}}$；$a=b=0$ 时原式恒为 0
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：$a, b$ 不全为 0
- 是什么：▸ 用在 求 $a \sin \theta + b \cos \theta$ 的最值或范围：化成 $\sqrt{a^{2}+b^{2}}\cdot \sin (\theta +\varphi)$，再用 $|\sin| \le 1$

### T15 等差数列
- 标志：$a_{n}=a_{1}+(n-1)d$；$S_{n}=\dfrac{n(a_{1}+a_{n})}{2}=na_{1}+\dfrac{n(n-1)d}{2}$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：n 为正整数
- 是什么：通项 $a_{n}=a_{1}+(n-1)d$，前 $n$ 项和 $S_{n}=\dfrac{n(a_{1}+a_{n})}{2}$。用在数列求和、排序不等式中按等差序列配对

### T16 等比数列
- 标志：$a_{n}=a_{1}q^{n-1}$；$q\ne 1$：$S_{n}=\dfrac{a_{1}(1-q^{n})}{1-q}$；$q=1$：$S_{n}=na_{1}$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：$n \ge 1$；$q \ne 0$
- 是什么：通项 $a_{n}=a_{1}q^{n-1}$。$q \ne 1$ 时 $S_{n}=\dfrac{a_{1}(1-q^{n})}{1-q}$；$q=1$ 时 $S_{n}=na_{1}$。用在等比放缩求和、均值不等式的倍增证明（$2 \to 4 \to 8 \to \cdots$）

### T17 正弦定理
- 标志：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：同一三角形的对应边和角；R 为外接圆半径
- 是什么：三角形中 $\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{c}{\sin C}=2R$（$R$ 为外接圆半径）。用在把边化为角、或角化为边，求三角函数有界时将边的条件转化为角的条件

### T18 余弦定理
- 标志：$a^{2} = b^{2}+c^{2}-2bc\cdot \cos A$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：同一三角形的对应边和角
- 是什么：余弦定理：由两边及夹角求第三边，或由三边求任一角的余弦值。$A=90°$ 时退化为勾股定理。用在三角形中求边长范围、结合 $b^{2}+c^{2} \ge 2bc$ 求角的范围

### T19 正切与余弦
- 标志：$1+\tan^{2} \theta  = \dfrac{1}{\cos^{2} \theta }$（$\cos \theta \ne 0$）；（由 $\sin^{2} +\cos^{2} =1$ 两边$\div \cos^{2} \theta$）
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：$\cos\theta \ne 0$
- 是什么：$1+\tan^{2} \theta  = \dfrac{1}{\cos^{2} \theta }$（$\cos \theta \ne 0$）；（由 $\sin^{2} +\cos^{2} =1$ 两边$\div \cos^{2} \theta$）

### T20 前 n 项平方和
- 标志：$\sum _{k=1}^{n}k^{2} = \dfrac{n(n+1)(2n+1)}{6}$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：n 为正整数
- 是什么：$\sum_{k=1}^{n}k^{2} = \dfrac{n(n+1)(2n+1)}{6}$。用在处理 $\sum k \cdot a_{k}$ 型数列求和

### T21 前 n 项立方和
- 标志：$\sum _{k=1}^{n}k^{3} = \left[\dfrac{n(n+1)}{2}\right]^{2}$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：n 为正整数
- 是什么：$\sum _{k=1}^{n}k^{3} = \left[\dfrac{n(n+1)}{2}\right]^{2}$

### T22 求导法则
- 标志：$(uv)'=u'v+uv'$；$\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^{2}}$；$(e^{x})'=e^{x}$；$(\ln  x)'=\dfrac{1}{x}$（$x\gt 0$）；$(x^{n})'=nx^{n-1}$（$n\in \mathbb{R}$，$x\gt 0$；正整数 n 另含 $x\le 0$）；$(\sin  x)' = \cos  x$；$(\cos  x)' = -\sin  x$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：$u, v$ 可导；商要求 $v \ne 0$
- 是什么：▸ 用在 构造函数：看到 $f'+f$ 想 $(e^{x}f)'$，看到 $xf'-f$ 想 $\left(\dfrac{f}{x}\right)'$，凑成积或商的导数 ；▸ 用在 对构造的函数求导，看导数正负判单调、求最值

### T23 向量数量积
- 标志：$a\cdot b=x_{1}x_{2}+y_{1}y_{2}$；两向量非零时：$a\cdot b=|a||b|\cos \theta$
- 区域：起点
- 类型：起点
- 标签：【工具】
- 条件：无额外限制
- 是什么：坐标形式 $\vec{a}\cdot\vec{b}=x_{1}x_{2}+y_{1}y_{2}$；非零向量时 $\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$。用在向量形式的柯西不等式和三角不等式的推导中

## 第 1 层　基本性质

### P01 对数切线不等式
- 标志：$\ln  x \le  x-1$（$x\gt 0$）
- 区域：正数域
- 类型：结论
- 标签：【高考常用】
- 条件：x>0
- 是什么：$y=\ln x$ 在 $x=1$ 处的切线 $y=x-1$ 在曲线上方（$\ln x$ 上凸）；等号 $\iff x=1$
- 依赖：
  - 来源：S04
    种类：推出
    方法：构造函数
    步骤：
      1. 【构造函数】令 $h(x)=x-1-\ln  x$（$x\gt 0$）
      2. 【求导】$h'(x)=1-\dfrac{1}{x}=\dfrac{x-1}{x}$
      3. 「导数判单调」$0\lt x\lt 1$ 时 $h'\lt 0$ 递减
      4. $x\gt 1$ 时 $h'\gt 0$ 递增
      5. 【求最值】$x=1$ 处取最小值 $h(1)=0$
      6. 【移项法】$h(x)\ge 0 \Rightarrow  \ln  x \le  x-1$

### P02 舒尔预备排列
- 标志：$a^{t}(a-b)(a-c)+b^{t}(b-a)(b-c)+c^{t}(c-a)(c-b)$
- 区域：正数域
- 类型：中间步
- 条件：a,b,c≥0；t>0
- 是什么：$a^{t}(a-b)(a-c)+b^{t}(b-a)(b-c)+c^{t}(c-a)(c-b)$
- 依赖：
  - 来源：S02
    种类：推出
    方法：分类讨论
    步骤：
      1. ▼ 条件：$a,b,c \ge 0$，$t \gt 0$
      2. 【分类讨论】不妨设 $a \ge b \ge c \ge 0$（对称性）
      3. 各因子符号：$a-b \ge 0$，$a-c \ge 0$，$b-c \ge 0$
      4. 幂函数 $x^{t}$（$t \gt 0$）在 $x \ge 0$ 上递增，因此 $a^{t} \ge b^{t} \ge c^{t} \ge 0$
      5. 由「正数相乘」判断每项符号：$a^{t}(a-b)(a-c) \ge 0$（三个非负因子之积），类推其余项，为后续分组合并做准备

### P03 非负数平方保序
- 标志：$a,b\ge 0$
- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：a,b≥0
- 是什么：反过来：$a,b \ge  0$ 时，$a^{2} \lt  b^{2} \Rightarrow  a \lt  b$（可两边开平方）
- 依赖：
  - 来源：S02
    种类：推出
    方法：作差法
    步骤：
      1. ▼ 条件：$0 \le a \lt b$
      2. 【作差法】计算 $b^{2}-a^{2}$
      3. 用「平方差公式」分解：$b^{2}-a^{2} = (b+a)(b-a)$
      4. $b+a \gt 0$（因为 $b \gt 0$），$b-a \gt 0$（因为 $b \gt a$）

      8. 因此 $a \lt b$

    种类：用到
    方法：因式分解

### P05 积商导数定号
- 标志：$f'+f\gt 0 \Rightarrow e^{x}f(x)$ 递增
- 区域：正数域
- 类型：结论
- 重要度：1
- 标签：【高考常用】
- 条件：同一区间内可导
- 是什么：$f'+f\gt 0 \Rightarrow e^{x}f(x)$ 递增；$f'-f\gt 0 \Rightarrow \dfrac{f(x)}{e^{x}}$ 递增；$xf'+f\gt 0 \Rightarrow xf(x)$ 递增；$xf'-f\gt 0$（$x\gt 0$）$\Rightarrow \dfrac{f(x)}{x}$ 递增；看到 $f'$ 与 f 的组合，就把它们凑成某个积或商的导数
- 依赖：
  - 来源：S04
    种类：推出
    方法：构造函数
    步骤：
      1. ▼ 条件：同一区间内可导
      2. 【构造函数】看到 $f'+f$，想到构造 $e^{x}f(x)$
      3. 由「求导法则」积的导数 $(uv)' = u'v+uv'$，取 $u = e^{x}$，$v = f$：$(e^{x}f)' = e^{x}f + e^{x}f' = e^{x}(f'+f)$
      4. 因此 $f'+f \gt 0 \Rightarrow (e^{x}f)' \gt 0$
      5. 由「导数判单调」导数 $\gt 0 \Rightarrow e^{x}f(x)$ 递增
      6. 同理：由商的导数 $\left(\dfrac{u}{v}\right)' = \dfrac{u'v-uv'}{v^{2}}$：$\left(\dfrac{f}{e^{x}}\right)' = \dfrac{f'e^{x}-fe^{x}}{e^{2x}} = \dfrac{f'-f}{e^{x}}$，$f'-f \gt 0 \Rightarrow \dfrac{f(x)}{e^{x}}$ 递增
      7. $(xf)' = f+xf'$（积的导数），$xf'+f \gt 0 \Rightarrow xf(x)$ 递增
      8. $\left(\dfrac{f}{x}\right)' = \dfrac{xf'-f}{x^{2}}$（$x \gt 0$），$xf'-f \gt 0 \Rightarrow \dfrac{f(x)}{x}$ 递增
  - 来源：T22
    种类：用到
    方法：求导法
    步骤：
      1. 用「求导法则」积的导数 $(uv)'=u'v+uv'$、商的导数等计算导数

### P07 对数平均不等式（拓展）

      2. 【构造函数】$g(t)=\ln  t - \dfrac{2(t-1)}{t+1}$，$h(t)=\dfrac{t-1}{\sqrt{t}} - \ln  t$

  - 来源：T11
    种类：用到
    方法：代入消元
    步骤：

      5. 坐标形式即 $(a_{1}^{2}+a_{2}^{2})(b_{1}^{2}+b_{2}^{2}) \ge (a_{1}b_{1}+a_{2}b_{2})^{2}$
  - 来源：T23
    种类：用到
    方法：代入消元
    步骤：

### P17 正数倒数反序

### P20 糖水不等式

- 重要度：1

### P09 舒尔前两项合并
- 标志：前两项合并：$(a-b)[a^{t}(a-c)-b^{t}(b-c)] \ge  0$
- 区域：正数域
- 类型：中间步
- 条件：a,b,c≥0；t>0
- 是什么：（$a-b\ge 0$，$a-c\ge b-c\ge 0$；$a^{t}\ge b^{t}$：幂函数 $x^{t}$（$t\gt 0$）在 $x\ge 0$ 上递增）；第三项 $c^{t}(c-a)(c-b) \ge  0$（两因子同号）
- 依赖：
  - 来源：P02
    种类：推出
    方法：分组法
    步骤：
      1. ▼ 条件：不妨设 $a \ge b \ge c \ge 0$
      2. 【分组法】把三项分成两组：前两项合并为 $(a-b)[a^{t}(a-c)-b^{t}(b-c)]$
      3. $a-b \ge 0$
      4. $a \ge b$ 且 $a-c \ge b-c \ge 0$，幂函数递增得 $a^{t} \ge b^{t}$，所以 $a^{t}(a-c) \ge b^{t}(b-c) \ge 0$
      5. 由「正数相乘」非负 $\times$ 非负 $=$ 非负：第一组 $\ge 0$
      6. 第三项 $c^{t}(c-a)(c-b)$：$c-a \le 0$，$c-b \le 0$，两个非正数之积非负，再乘 $c^{t} \ge 0$：第三项 $\ge 0$

### P10 同向非负不等式可乘
- 标志：$a\ge b\ge 0$，$c\ge d\ge 0 \Rightarrow  ac\ge bd$
- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：a≥b≥0；c≥d≥0
- 是什么：若 $a\gt b\ge 0$ 且 $c\gt d\ge 0$，则 $ac\gt bd$
- 依赖：
  - 来源：R05
    种类：推出
    方法：作差法
    步骤：
      1. ▼ 条件：$a \ge b \ge 0$，$c \ge d \ge 0$
      2. 【作差法】$ac - bd = (a-b)c + b(c-d)$
      3. 第一项：$(a-b) \ge 0$，$c \ge 0$，由「正数乘法保序」$(a-b)c \ge 0$
      4. 第二项：$b \ge 0$，$(c-d) \ge 0$，同理 $b(c-d) \ge 0$
      5. 两个非负数之和：$ac - bd \ge 0$，即 $ac \ge bd$
      6. 严格时：$a \gt b \ge 0$ 且 $c \gt d \ge 0 \Rightarrow c \gt 0$，$(a-b)c \gt 0$，因此 $ac \gt bd$

### P11 作商比大小

- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：b>0
- 是什么：$b \gt 0$ 时，$a \gt b \iff \dfrac{a}{b} \gt 1$

  - 来源：R05
    种类：推出
    方法：等价转化
    步骤：
      1. ▼ 条件：$b \gt 0$
      2. 【等价转化】要证 $a \gt b \iff \dfrac{a}{b} \gt 1$

      4. 反向：$\dfrac{a}{b} \gt 1$，由「正数乘法保序」两边同乘 $b \gt 0$：$a \gt b$

### P12 对数切线变形
- 标志：$\ln  x \ge  1 - \dfrac{1}{x}$
- 区域：正数域
- 类型：结论
- 标签：【高考常用】
- 条件：x>0
- 是什么：对数切线不等式中令 $x=\dfrac{1}{x}$ 得到的变形；等号 $\iff x=1$
- 依赖：
  - 来源：P01
    种类：推出
    方法：代换法
    步骤：
      1. 由「对数切线不等式」$\ln t \le t-1$（$t \gt 0$）

### P14 对数切线不等式（切点e）

- 标签：【高考常用】

- 是什么：$y=\ln x$ 在 $x=e$ 处的切线 $y=\dfrac{x}{e}$ 在曲线上方；等号 $\iff x=e$

  - 来源：P01

    方法：代换法

### P15 琴生不等式
- 标志：$\dfrac{f(x_{1})+\cdots +f(x_{n})}{n} \ge  f\left(\dfrac{x_{1}+\cdots +x_{n}}{n}\right)$

- 重要度：1
- 标签：【拓展】

- 是什么：$\dfrac{f(x_{1})+\cdots +f(x_{n})}{n} \ge  f\left(\dfrac{x_{1}+\cdots +x_{n}}{n}\right)$；$f'' \gt  0$ 时：等号 $\iff  x_{i}$ 全相等；只有 $f'' \ge  0$ 时：等号 $\iff  x_{i}$ 全相等，或 f 在这些点覆盖的区间 [最小的 $x_{i}$, 最大的 $x_{i}]$ 上满足 $f(x)=kx+b$（允许 $k=0$，即也包括常数函数；如 $f(x)=x$、$f(x)=1$ 时恒取等）

  - 来源：P06
    种类：推出
    方法：取特值法
    步骤：
      1. 【取特值法】取 $x_{0} =$ 平均值 $\bar{x}$，对每个 $x_{i}$ 写切线不等式
      2. 「同向可加」$f'(\bar{x})\cdot \sum (x_{i}-\bar{x}) = 0$，右边只剩 $n\cdot f(\bar{x})$

### P48 f 有奇偶性且单调
- 标志：$x\gt \dfrac{1}{3}$
- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：f 有奇偶性且单调
- 是什么：奇函数、在 ℝ 上递增：$f(a)+f(b)\lt 0 \iff  f(a)\lt f(-b) \iff  a\lt -b$；例：f 为偶函数且在 $[0,+\infty )$ 上递增，$f(x-1)\lt f(2x) \iff  |x-1|\lt |2x| \iff  x\lt -1$ 或 $x\gt \dfrac{1}{3}$；先查：定义域；偶函数先化成 $f(|\cdot|)$ 再比较，别漏掉负的那一半

  - 来源：S09

    方法：代换法
    步骤：

  - 来源：P03

### P60 同构 + 切线放缩

      2. 【取特值法】分别令 $x = a$：$-|a| \le a \le |a|$
      3. 令 $x = b$：$-|b| \le b \le |b|$

### R24 （展开后移项）
- 标志：$a_{2}b_{2}+a_{1}b_{1} \ge  a_{2}b_{1}+a_{1}b_{2}$
- 区域：实数域
- 类型：中间步
- 条件：任意实数
- 是什么：将预备式展开整理，得到同序积和不小于交叉积和
- 依赖：
  - 来源：R11
    种类：推出
    方法：展开法
    步骤：
      1. 由「排序不等式预备」$(a_{2}-a_{1})(b_{2}-b_{1}) \ge 0$
      2. 【展开法】用乘法分配律展开：$(a_{2}-a_{1})(b_{2}-b_{1}) = a_{2}b_{2} - a_{2}b_{1} - a_{1}b_{2} + a_{1}b_{1}$
      3. 因此 $a_{2}b_{2} + a_{1}b_{1} - a_{2}b_{1} - a_{1}b_{2} \ge 0$

### R25 高次不等式（穿根法）
- 标志：化为 $(x-x_{1})(x-x_{2})\cdots (x-x_{n}) \gt  0$（各因式 x 的系数为正）
- 区域：实数域
- 类型：结论
- 重要度：1
- 标签：【高考常用】
- 条件：任意实数
- 是什么：无实根的因式（如 $x^{2}+x+1$）先判断符号，恒正就约去；数轴上标根，从最右边上方开始依次穿线；奇次重根穿过，偶次重根不穿；解 $\gt 0$ 时所有根都不取（偶次根处也要挖去），解 $\ge 0$ 时根都取上
- 依赖：
  - 来源：S02
    种类：推出
    方法：分类讨论
    步骤：
      1. 【分类讨论】$x-x_{i}$ 在 $x_{i}$ 右侧为正、左侧为负
      2. 积的符号由负因式个数的奇偶决定（正×正=正、负×负=正）
      3. 【数形结合】在数轴上标出各根，从最右边上方开始穿线，经过每个单根时穿越 x 轴
      4. 读出正/负区间即为解集
  - 来源：R06
    种类：推出
    步骤：
      1. 【前提】负 × 负 = 正：两个负因式之积为正

### R26 指数切线不等式（切点1）
- 标志：$e^{x} \ge  ex$（$x\in \mathbb{R}$）
- 区域：实数域
- 类型：结论
- 标签：【高考常用】
- 条件：任意实数
- 是什么：$e^{x} \ge  ex$（$x\in \mathbb{R}$）；等号 $\iff  x=1$
- 依赖：
  - 来源：R10
    种类：推出
    方法：代换法
    步骤：
      1. 由「指数切线不等式」$e^{x} \ge 1+x$（对任意实数 $x$）
      2. 【代换法】把 $x$ 换成 $x-1$：$e^{x-1} \ge 1+(x-1) = x$
      3. 【同乘法】两边乘 $e \gt 0$，不等号不变：$e^{x-1} \cdot e = e^{x} \ge ex$
      4. 等号 $\iff x-1 = 0$，即 $x = 1$

### R27 向量三角不等式（任意向量）
- 标志：$||a|-|b|| \le  |a+b| \le  |a|+|b|$
- 区域：实数域
- 类型：结论
- 重要度：1
- 条件：任意实数
- 是什么：右边等号 ⟺ 同向或有零向量；左边等号 ⟺ 反向或有零向量；复数同理：$||z_{1}|-|z_{2}|| \le  |z_{1} \pm  z_{2}| \le  |z_{1}| + |z_{2}|$；坐标形式（闵可夫斯基）：$\sqrt{x_{1}^{2}+y_{1}^{2}} + \sqrt{x_{2}^{2}+y_{2}^{2}} \ge  \sqrt{(x_{1}+x_{2})^{2} + (y_{1}+y_{2})^{2}}$
- 依赖：
  - 来源：R16
    种类：推出
    方法：展开法
    步骤：
      1. 【展开法】$|a+b|^{2} = |a|^{2}+2a\cdot b+|b|^{2} \le  |a|^{2}+2|a||b|+|b|^{2} = (|a|+|b|)^{2}$
      2. 下界同理用 $a\cdot b \ge  -|a||b|$
      3. 两边非负，【开平方法】得 $|\vec{a}+\vec{b}| \le |\vec{a}|+|\vec{b}|$

### R75 异向不等式可减
- 标志：$a\gt b$，$c\lt d \Rightarrow  a-c \gt  b-d$
- 区域：实数域
- 类型：结论
- 重要度：1
- 条件：任意实数
- 是什么：⚠ 同向不等式不能相减：$5\gt 4$，$3\gt 0$，但 $5-3=2 \lt  4-0=4$
- 依赖：
  - 来源：R07
    种类：推出
    方法：作差法
    步骤：
      1. ▼ 条件：$a \gt b$，$c \lt d$
      2. 即 $a \gt b$ 且 $d \gt c$（将第二个反向）
      3. 【作差法】$(a-c)-(b-d) = (a-b)+(d-c)$
      4. $a-b \gt 0$，$d-c \gt 0$
      5. 由「同向可加」正数之和为正：$(a-b)+(d-c) \gt 0$
      6. 因此 $a-c \gt b-d$

### P24 裂项放缩
- 标志：$\dfrac{1}{k^{2}} \lt  \dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$
- 区域：正数域
- 类型：结论
- 重要度：1
- 标签：【高考常用】
- 条件：正整数 k≥2
- 是什么：$n\ge 2$：$1 + \dfrac{1}{2^{2}} + \cdots  + \dfrac{1}{n^{2}} \lt  2 - \dfrac{1}{n} \lt  2$
- 依赖：
  - 来源：P17
    种类：推出
    方法：取倒数法
    步骤：
      1. ▼ 条件：正整数 $k \ge 2$
      2. $k^{2} \gt k(k-1)$（因为 $k^{2} - k(k-1) = k \gt 0$）
      3. 两边都 $\gt 0$
      4. 由「正数倒数反序」取倒数不等号反向：$\dfrac{1}{k^{2}} \lt \dfrac{1}{k(k-1)}$
      5. 【裂项法】$\dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$（部分分式分解）
      6. 因此 $\dfrac{1}{k^{2}} \lt \dfrac{1}{k-1} - \dfrac{1}{k}$
      7. 对 $k = 2, 3, \ldots, n$ 求和：$\sum_{k=2}^{n}\dfrac{1}{k^{2}} \lt \sum_{k=2}^{n}\left(\dfrac{1}{k-1}-\dfrac{1}{k}\right)$
      8. 右边相消 $= 1 - \dfrac{1}{n}$
      9. 加上首项 $k=1$：$\sum_{k=1}^{n}\dfrac{1}{k^{2}} \lt 1 + 1 - \dfrac{1}{n} = 2 - \dfrac{1}{n} \lt 2$

### P25 正整数 k
- 标志：$\dfrac{1}{\sqrt{k}} \lt  2\left(\sqrt{k} - \sqrt{k-1}\right)$
- 区域：正数域
- 类型：结论
- 重要度：1
- 标签：【高考常用】
- 条件：正整数 k
- 是什么：$\Rightarrow  1 + \dfrac{1}{\sqrt{2}} + \cdots  + \dfrac{1}{\sqrt{n}} \lt  2\sqrt{n}$
- 依赖：
  - 来源：P17
    种类：推出
    方法：取倒数法
    步骤：
      1. 【取倒数法】$\sqrt{k}+\sqrt{k-1} \lt 2\sqrt{k}$，两边为正取倒数反向：$\dfrac{1}{\sqrt{k}} \lt \dfrac{2}{\sqrt{k}+\sqrt{k-1}}$
      2. 【分母有理化】用「平方差公式」$\dfrac{2}{\sqrt{k}+\sqrt{k-1}} = 2(\sqrt{k}-\sqrt{k-1})$
      3. 因此 $\dfrac{1}{\sqrt{k}} \lt 2(\sqrt{k}-\sqrt{k-1})$
      4. $n=1$ 时和为 $1=2\sqrt{1}-1$，取等号
      5. $n \ge 2$ 时，【保留首项】首项 $1$ 不放缩，仅对 $k=2,\ldots,n$ 用严格放缩
      6. $1+\sum_{k=2}^{n}\dfrac{1}{\sqrt{k}} \lt 1+2\sum_{k=2}^{n}(\sqrt{k}-\sqrt{k-1})$
      7. 【裂项法】右边求和相消 $=1+2(\sqrt{n}-1)=2\sqrt{n}-1$
      8. 合并：对所有正整数 $n$，$\sum_{k=1}^{n}\dfrac{1}{\sqrt{k}} \le 2\sqrt{n}-1 \lt 2\sqrt{n}$
  - 来源：T01
    种类：用到
    方法：分母有理化
    步骤：
      1. 用「平方差公式」$(\sqrt{k}+\sqrt{k-1})(\sqrt{k}-\sqrt{k-1}) = k-(k-1) = 1$，分母有理化得 $\dfrac{2}{\sqrt{k}+\sqrt{k-1}} = 2(\sqrt{k}-\sqrt{k-1})$

### P54 正整数 k

### P18 舒尔不等式
- 标志：$a,b,c\ge 0$
- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：a,b,c≥0
- 是什么：即 $a^{3}+b^{3}+c^{3}+3abc \ge  ab(a+b)+bc(b+c)+ca(c+a)$；等号 $\iff  a=b=c$，或两数相等且第三个为 0
- 依赖：
  - 来源：P09
    种类：推出
    方法：合并整理
    步骤：
      1. 由「舒尔前两项合并」前两项合并 $(a-b)[a^{t}(a-c)-b^{t}(b-c)] \ge 0$
      2. 第三项 $c^{t}(c-a)(c-b) \ge 0$（两因子同号）
      3. 【合并整理】两部分都 $\ge 0$，相加得 $\sum a^{t}(a-b)(a-c) \ge 0$
      4. 【取特值法】取 $t=1$ 展开整理得 $a^{3}+b^{3}+c^{3}+3abc \ge ab(a+b)+bc(b+c)+ca(c+a)$

### P19 乘方与开方保序
- 标志：$a\gt b\ge 0 \Rightarrow  a^{n}\gt b^{n}$，$\sqrt[n]{a} \gt  \sqrt[n]{b}$（n 为正整数）
- 区域：正数域
- 类型：结论
- 条件：a>b≥0；奇次幂任意实数
- 是什么：推广：s 为正有理数时 $a^{s} \gt  b^{s}$；奇次幂对任意实数保序：$a \gt  b \iff  a^{3} \gt  b^{3}$
- 依赖：
  - 来源：P10
    种类：推出
    方法：归纳
    步骤：
      1. ▼ 条件：$a \gt b \ge 0$，$n$ 为正整数
      2. 【归纳】$n=1$：$a \gt b$ 显然成立
      3. $n=k \to n=k+1$：由归纳假设 $a^{k} \gt b^{k} \ge 0$
      4. 与 $a \gt b \ge 0$ 配对，由「同向非负不等式可乘」$a^{k} \cdot a \gt b^{k} \cdot b$，即 $a^{k+1} \gt b^{k+1}$
      5. 由数学归纳法对所有正整数 $n$ 成立
      6. 【反证】开方：若 $\sqrt[n]{a} \le \sqrt[n]{b}$，两边 $n$ 次方得 $a \le b$，与 $a \gt b$ 矛盾
      7. 因此 $\sqrt[n]{a} \gt \sqrt[n]{b}$

### P21 正整数 k
- 标志：$\dfrac{1}{k+1} \lt  \ln \left(1+\dfrac{1}{k}\right) \lt  \dfrac{1}{k}$
- 区域：正数域

- 重要度：1
- 标签：【高考常用】
- 条件：正整数 k

- 依赖：
  - 来源：P01
    种类：推出
    方法：代换法
    步骤：
      1. 【代换法】$\ln  x \le  x-1$ 中令 $x=1+\dfrac{1}{k}$：$\ln \left(1+\dfrac{1}{k}\right) \lt  \dfrac{1}{k}$（$x\ne 1$，取不到等号）
      2. 「同向可加」左边 $= \ln \left(\dfrac{2}{1}\right)+\ln \left(\dfrac{3}{2}\right)+\cdots +\ln \left(\dfrac{n+1}{n}\right) = \ln (n+1)$
  - 来源：P12
    种类：推出
    步骤：
      1. 【前提】令 $x=1+\dfrac{1}{k}$：$\ln \left(1+\dfrac{1}{k}\right) \gt  1 - \dfrac{k}{k+1} = \dfrac{1}{k+1}$
  - 来源：T11
    种类：用到
    方法：代入消元
    步骤：
      1. 用「对数运算律」$\ln\left(\dfrac{k+1}{k}\right) = \ln(k+1) - \ln k$，逐项相加时中间项相消得 $\ln(n+1)$

### P22 对数切线变形（1+x）

### P27 排序不等式特例
- 标志：$a^{3}+b^{3} \ge  ab(a+b)$（$a+b \ge  0$）
- 区域：正数域
- 类型：结论
- 重要度：1
- 标签：【高考常用】
- 条件：a,b∈ℝ；a+b≥0

- 依赖：
  - 来源：R37
    种类：推出
    方法：配凑法
    步骤：
      1. ▼ 条件：$a+b \ge 0$
      2. 【配凑法】要证 $a^{3}+b^{3} \ge ab(a+b)$
      3. 由「展开平方差」$(a-b)^{2} \ge 0$，展开得 $(a+b)^{2} - 4ab = (a-b)^{2} \ge 0$，即 $(a+b)^{2} \ge 4ab$

### R51 切比雪夫不等式

- 类型：结论
- 重要度：1
- 条件：任意实数
- 是什么：$\dfrac{\left(\sum a_{i}\right)\left(\sum b_{i}\right)}{n} \le  \sum a_{i}b_{i}$；等号 ⟺ 某组全相等

  - 来源：R41
    种类：推出
    方法：轮换求和

  - 来源：R65

### P39 权方和不等式
- 标志：$\dfrac{a_{1}^{2}}{b_{1}}+\cdots +\dfrac{a_{n}^{2}}{b_{n}} \ge  \dfrac{(a_{1}+\cdots +a_{n})^{2}}{b_{1}+\cdots +b_{n}}$
- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：bᵢ>0；aᵢ∈ℝ
- 是什么：$b_{i}\gt 0$；等号 $\iff  \dfrac{a_{1}}{b_{1}}=\cdots =\dfrac{a_{n}}{b_{n}}$
- 依赖：
  - 来源：P33
    种类：推出
    方法：归纳
    步骤：
      1. ▼ 条件：$b_{i} \gt 0$
      2. 【归纳法】$n=2$：就是「柯西分式」$\dfrac{a_{1}^{2}}{b_{1}}+\dfrac{a_{2}^{2}}{b_{2}} \ge \dfrac{(a_{1}+a_{2})^{2}}{b_{1}+b_{2}}$
      3. $n \to n+1$：先把前 $n$ 项用归纳假设合并为 $\ge \dfrac{(\sum_{i=1}^{n} a_{i})^{2}}{\sum_{i=1}^{n} b_{i}}$

### P41 柯西分式特例
- 标志：$x,y\gt 0$
- 区域：正数域
- 类型：结论
- 标签：【高考常用】

- 是什么：$x,y\gt 0$；等号 $\iff  x=y$
- 依赖：
  - 来源：P33
    种类：推出
    方法：取特值法
    步骤：
      1. ▼ 条件：$x, y \gt 0$

- 标志：$a,b,c\gt 0$
- 区域：正数域
- 类型：结论

      1. ▼ 进入正数域：要求 $a,b,c\gt 0$（排除负数，分母不能为 0）

### P59 赫尔德不等式（拓展）
- 标志：$\dfrac{1}{p}+\dfrac{1}{q}=1$
- 区域：正数域
- 类型：结论
- 重要度：1
- 条件：aᵢ,bᵢ≥0；p,q>1，1/p+1/q=1
- 是什么：等号 $\iff a_{i}^{p}$ 与 $b_{i}^{q}$ 对应成比例；$p = q = 2$ 时就是柯西
- 依赖：
  - 来源：P43
    种类：推出
    方法：取特值法
    步骤：
      1. 【取特值法】加权均值取两个数、权 $\dfrac{1}{p}$ 与 $\dfrac{1}{q}$：$x^{\frac{1}{p}}\cdot y^{\frac{1}{q}} \le  \dfrac{x}{p} + \dfrac{y}{q}$（$x,y \ge  0$）
      2. 【归一化】记 $A=\sum a_{i}^{p}$，$B=\sum b_{i}^{q}$（A、B 有一个为 0 时两边都是 0）
      3. 取 $x=\dfrac{a_{i}^{p}}{A}$，$y=\dfrac{b_{i}^{q}}{B}$
      4. 「同向可加」$\sum \dfrac{a_{i}b_{i}}{A^{\frac{1}{p}}\cdot B^{\frac{1}{q}}} \le  \dfrac{1}{p} + \dfrac{1}{q} = 1$
      5. p 为有理数时用加权均值即可
      6. 任意实数 p：【构造函数】$g(x)=\dfrac{x}{p}+\dfrac{1}{q}-x^{\frac{1}{p}}$（$x\gt 0$），【求导】$g'(x)=\dfrac{1}{p}\left(1-x^{\frac{1}{p}-1}\right)$，$x=1$ 处取最小值 0
      7. 【代换法】令 $x=\dfrac{X}{Y}$（$Y\gt 0$），两边乘 Y 即得上式

- 方向：结论依赖符号或大小 → 分段各自处理；有对称性时只讨论一半
- 信号：含参；绝对值；二次项系数含参；两根大小不定
- 出现在：R43、R15、R36
- 标签：分类讨论；分类代入；分类合并；对称
- 易错：
  - 分类标准统一，不重不漏

### 反证
- 说明：开方保序〔P19 · G2〕、用单调性去掉 f〔P47 · N3〕
- 方向：直接证明困难 → 假设结论不成立，推出矛盾
- 信号：至少、至多、唯一；逆命题已知（如由乘方保序推开方保序）
- 出现在：P19、P47
- 标签：反证
- 易错：
  - 要否定整个结论

### 归纳
- 说明：伯努利不等式〔P26 · K6〕、$2^{k}$ 个数的均值不等式〔P36 · L4〕
- 方向：对所有 n ≥ n₀ 成立 → 奠基 + 递推〔S06 · J5〕
- 信号：含正整数 n 的不等式；能由 k 推到 k+1
- 出现在：S06、P26、P36
- 标签：归纳；奠基；递推；重复
- 易错：
  - 递推那一步必须用上归纳假设

### 恒等变形
- 说明：作差后分解 $a^{3}+b^{3}-ab(a+b)=(a+b)(a-b)^{2}$〔P27 · J3〕、分母有理化〔P25 · L6〕、穿根前分解〔R25 · C3〕
- 方向：把式子换成相等、更好用的样子（用 = 连接）
- 依据：运算律和工具箱里的恒等式
- 信号：要定正负就分解成因式之积；要比较就展开合并；根式和就有理化
- 出现在：P27、P25、R25
- 标签：展开；提公因式；因式分解；通分；合并整理；分母有理化
- 易错：
  - 与等价变形分清：恒等变形变式子（=），等价变形变不等式（⟺）

### 传递消项
- 说明：$a \ge b$ 且 $b \ge c$，消掉中间量 $b$，直接得 $a \ge c$；不等式链 $A \ge B \ge C \ge D$ 中跳过中间步直接取首尾
- 方向：多步推导的中间结果不需要 → 只保留起点和终点的不等关系
- 依据：不等式传递性〔S01 · H1〕
- 信号：连续 $\ge$ 链；两个不等式共享同一个量；多来源推导汇合成一个结论
- 出现在：R05、R07、P13、P24、R46、R71、P26、P27
- 标签：传递消项；不等式链接；消中间量
- 易错：
  - 传递要求方向一致（都是 $\ge$ 或都是 $\le$），混用 $\ge$ 和 $\le$ 先统一方向
  - 严格 $\gt$ 和非严格 $\ge$ 混合时，至少一步严格则首尾严格（$a \gt b \ge c \Rightarrow a \gt c$）

### 端点检验
- 说明：等号成立条件的逆向使用——先从等号 $\iff$ 条件确定极值点，再回到原式构造证明；均值不等式求最值时的"一正二定三相等"中的"三相等"检验
- 方向：猜答案 → 从等号条件反推极值点 → 验证该点确实可取
- 依据：等号条件给出候选集合，再结合约束判断可取性
- 信号：条件最值题；"当且仅当…取等"；"$a=b$ 时等号成立"；约束下求最值
- 出现在：P29、R61、P30、R42、P38、P40、P15
- 标签：端点检验；取等分析；等号条件
- 易错：
  - 等号条件算出的值必须满足原题的所有约束（如正数、定义域）
  - 没有等式约束时等号可能取不到（开区间端点）

### 参数分离
- 说明：含参不等式 $f(x, a) \ge 0$ 对所有 $x$ 恒成立 → 变形为 $a \ge g(x)$（或 $a \le g(x)$），转化为求 $g$ 的最值
- 方向：恒成立问题 → 参数移到一边 → 对另一边求最值
- 依据：$a \ge g(x)$ 对所有 $x$ 成立 $\iff$ $a \ge \sup g(x)$（最大值存在时即 $\max$；端点取不到时用上确界）
- 信号："对所有 $x \in D$ 恒成立，求 $a$ 的范围"；含参不等式的参数取值范围
- 出现在：R30、R44、P01
- 标签：参数分离；分离参数；恒成立转最值
- 易错：
  - 分离时注意乘除的量是否恒正（否则变号）
  - 分离后 $g(x)$ 的定义域要和原题一致
