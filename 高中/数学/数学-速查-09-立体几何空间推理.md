Section ② "空间角与距离" (middle-left, large module, green header):
Four angle types (四种角) each with definition, range, and vector formula:

① 异面直线所成角 θ:
  定义: 平移到共点, 取锐角或直角
  范围: θ ∈ (0, π/2]
  向量法: cos θ = |d⃗₁ · d⃗₂| / (|d⃗₁| · |d⃗₂|)  ← 取绝对值保证锐角

② 线面角 θ:
  定义: 直线与其在平面上射影的夹角
  范围: θ ∈ [0, π/2]
  向量法: sin θ = |d⃗ · n⃗| / (|d⃗| · |n⃗|)  ← sin因为d⃗与n⃗夹角的余角才是线面角

③ 二面角 θ:
  定义: 从棱上一点引两半平面内各一条垂直于棱的射线所成角
  范围: θ ∈ [0, π]
  向量法: cos θ = ±(n⃗₁ · n⃗₂) / (|n⃗₁| · |n⃗₂|)
  ⚠️ 法向量方向决定结果是二面角本身还是补角:
    ①求两个半平面各自的法向量 n⃗₁, n⃗₂
    ②算 cosα = (n⃗₁·n⃗₂)/(|n⃗₁|·|n⃗₂|)
    ③结合图形判断: 两法向量指向二面角同侧(都朝内或都朝外)→所求角=π−α; 指向两侧→所求角=α
    ④实际操作: 算出cosα后, 由题意判断二面角是锐是钝, 选取α或π−α

④ 异面直线的距离(选学):
  向量法: 公垂线长 d = |AB⃗ · n⃗| / |n⃗|, 其中n⃗=d⃗₁×d⃗₂

距离统一方法:
  点到面距离: d = |PA⃗ · n⃗| / |n⃗| (P是点, A是面上任一点, n⃗是法向量)
  线到面距离 = 线上任一点到面的距离(当线∥面时)
  面到面距离 = 一面上任一点到另一面的距离(当面∥面时)
  → 一切距离都化归为"点到面的距离"

Classification tree at top:

体积公式速查表:
| 几何体 | 体积公式 | 侧面积 |
|--------|---------|--------|
| 棱柱/圆柱 | V = Sh | S_侧 = Ch (直棱柱, C为底面周长) / 圆柱: 2πrh |

| 棱台/圆台 | V = ⅓h(S₁+S₂+√(S₁S₂)) | — |
| 球 | V = 4πr³/3 | S = 4πr² |

祖暅原理 (highlighted): 两个几何体被任意平行于底面的平面截得截面积都相等 → 两几何体体积相等
应用: 球的体积推导(半球截面积=圆柱截面积−圆锥截面积) → V_半球 = πR²·R − ⅓πR²·R = πR³ − ⅓πR³ = ⅔πR³ → V_球 = 2 × ⅔πR³ = 4πR³/3

球的组合体:
  球内接长方体: 体对角线 = 2R → √(a²+b²+c²) = 2R
  球内接正方体: 棱长 a = 2R/√3
  球内接正四面体: 棱长 a, R_外 = a√6/4, R_内 = a√6/12 = R_外/3

Section ④ "平面基本事实" (bottom-left, compact module, purple header):
三条公理:
  公理1: 不共线三点确定一个平面
  公理2: 若两点在平面内, 则两点连线上所有点都在该平面内
  公理3: 两个不重合平面有公共点, 则有且仅有一条过该点的公共直线(交线)

三条推论:
  推论1: 一条直线和直线外一点确定一个平面
  推论2: 两条相交直线确定一个平面
  推论3: 两条平行直线确定一个平面
用途: 证点/线/面共面, 证线在面内

Section ⑤ "建系策略与法向量求法" (bottom-center, compact module, teal header):
建系三步:
  Step 1: 找三条两两垂直的线(通常在直三棱柱/正方体/正三/四棱锥的高和底边中)
  Step 2: 以交点为原点, 三条垂直线为坐标轴
  Step 3: 写出各点坐标 → 计算向量

法向量求法:
  设 n⃗ = (x, y, z)
  取面内两个不共线方向向量 d⃗₁, d⃗₂
  解方程组: n⃗ · d⃗₁ = 0 且 n⃗ · d⃗₂ = 0
  → 两个方程三个未知数 → 令一个自由分量=1, 解出另外两个
  ⚠️ 设哪个分量=1须确认该分量确实可以非零; 例如xy平面的法向量只有z分量非零, 不能设x=1或y=1
  ⚠️ 同一平面的法向量有无穷多个(两个相反方向), 选哪个需要在角度计算时注意正负

Section ⑥ "斜二测画法与三视图" (bottom-right, compact module, gray header):
斜二测画法规则:
  ① x轴: 取水平方向, 长度不变(1:1)
  ② y轴: 与x轴成45°, 长度缩为½(1:2)
  ③ z轴: 垂直于x轴, 长度不变(1:1)

三视图:
  正视图(从前往后看) | 侧视图(从右往左看) | 俯视图(从上往下看)
  → 长对正(正视图与俯视图的长度左右对齐) | 高平齐(正视图与侧视图的高度上下对齐) | 宽相等(俯视图的上下宽度=侧视图的左右宽度)
  三视图还原几何体: ① 定轮廓 ② 补线(实线/虚线) ③ 画直观图
