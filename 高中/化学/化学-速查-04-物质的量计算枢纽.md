Section ② "22.4 L/mol 使用陷阱" (middle-left, medium module with red warning border):
Big warning icon ⚠️
Three mandatory conditions (green checkmarks):
✅ 必须是气体（液体、固体不能用！）
✅ 必须是标准状况 STP（0°C, 101 kPa）
✅ 标况(STP)下 Vₘ≈22.4 L/mol；非标况不能直接套用——为什么？气体体积由分子间距决定，分子间距受温度(分子热运动)和压强(外界压缩)控制；温度、压强变了，Vₘ就要按题给条件取值
Common traps (red X marks):
❌ H₂O 在标况下是液体！
❌ SO₃ 在标况下是固体！
❌ CCl₄ 是液体！
❌ 常温常压不能用22.4！
更多N_A易错陷阱 (additional traps):
  ❌ 18g D₂O（重水）的物质的量不是1mol！D₂O的M=20g/mol，所以n=18/20=0.9mol
  ❌ 标况下22.4L HF不是1mol！HF因分子间氢键在标况(0°C)下是液态，不能用22.4L/mol
  ❌ Na₂O₂中阴阳离子个数比是1:2，不是1:1！Na₂O₂含2个Na⁺和1个O₂²⁻（过氧根），不是2个O²⁻
  ❌ 1mol Fe与足量Cl₂反应转移3mol e⁻（生成FeCl₃不是FeCl₂，Cl₂氧化性强把Fe氧化到+3价）
  NO₂/N₂O₄：先查相态→再查2NO₂⇌N₂O₄平衡；混合气体总分子数≠NO₂分子数
Bold rule: "记住：先判断物质状态，再用22.4 L/mol！"

Section ④ "计算题反推导航" (bottom-left, large module, the visual centerpiece of problem-solving):
A REVERSE-REASONING navigation tree. The student starts from "题目要求什么", works backwards to find n, then connects from given conditions. Draw as a flowchart. Each node shows the check to perform and the formula to call.

导航入口: "题目要求什么？" (rightmost node, large, highlighted)
  ↓ 根据所求量选一条路，确定目标物

分支1: 求质量m → m = n(目标物) × M → 需要 n(目标物) 和 M
  M → 查⑤，按化学式算
  n(目标物) → 转到 ★求n★

分支2: 求气体体积V → V = n(目标物) × Vₘ → 需要 n(目标物) 和 Vₘ
  Vₘ → 标况？是 → 22.4 L/mol | 题给其他T、p → 用题给值 | 没说 → 回题找（⚠不能默认22.4）
  n(目标物) → 转到 ★求n★

分支3: 求浓度c → c = n(目标物) / V(溶液) → 需要 n(目标物) 和 V(溶液)
  V(溶液) → 题给 | 或从 ρ 和 m 换算（⚠单位L）
  n(目标物) → 转到 ★求n★

分支4: 求粒子数N → N = n(目标物) × N_A
  ⚠ 先看清问的是什么粒子：1 mol H₂O 含 1 mol 分子、3 mol 原子、10 mol 电子
  n(目标物) → 转到 ★求n★

分支5: 求n本身（如求剩余物质的量、生成物的量、平衡时的量）→ 直接转到 ★求n★
  ⚠ 注意所求n的数量状态：初始量/生成量/消耗量/剩余量/平衡量——这决定了从★求n★返回时取哪个值

★求n★ (central hub, highlighted):
  第一步: 找到题目给了量的物质（记为A），把A的量换算成n(A):
    A的量直接给了n → 直接记录n(A)，保留物质身份A和数量状态（初始/某时刻等）
    A的量给的是质量m → n(A) = m/M
    A的量给的是体积V → ⚠ A在题给条件下是气态吗？
      是气态 → n(A) = V/Vₘ（标况22.4或题给值）
      不是气态 → 题给了A的质量吗？有 → 用质量入口
                  题给了A的密度ρ吗？有 → m = ρV → n(A) = ρV/M
                  都没有 → 信息不足，转到 ⚠出口
    A的量给的是浓度c和体积V → n(A) = cV
    A的量给的是粒子数N → n(A) = N/N_A

  第二步: n(A)的身份和状态是否都匹配所求？需要同时满足两个条件:
    ① A是目标物吗？（物质身份匹配）
    ② n(A)的数量状态（初始/生成/剩余）是所求的那个吗？
    两个都满足 →
      从分支1/2/3/4进来的 → 代入公式得到最终答案
      从分支5进来的（所求就是n）→ 直接输出该n作为最终答案
    任一不满足 → 需要通过反应关系转换 → 转第三步
    (例: 题给了H₂SO₄初始量0.15mol，求反应后剩余酸→身份匹配但状态不匹配→必须进第三步)

  第三步: 建立反应桥梁
    写出涉及A和目标物的化学方程式 → 配平
    ⚠ 确定实际消耗量（按以下顺序逐步检查，命中即止）:
      检查1: 题目是否给了转化率α或实测变化量（如某时刻的浓度变化、质量变化）？
        有 → 实际消耗量 = 初始量 × α（或从实测数据直接算出）→ 跳到"按系数比"
        没有 → 继续检查2
      检查2: 是否有足以判定反应终态及实际消耗量的依据？
        常见依据（不限于特定关键词）:
          题说"完全反应""充分反应至某物耗尽""某反应物已消失" → 限量物耗尽（过量物可能有剩余）
          题说"恰好反应" → 按计量比恰好完全 → 各反应物都耗尽
          题给了终态组成（如反应后某物质量） → 从终态数据求实际消耗量
          (以上都需要比较限量: 把各反应物的n除以各自系数，商小的为限量物)
        ⚠ "足量"只说明该物用量充足，不等于任意时刻反应已完全——须结合题意判断是否问的是最终结果
        没有足够依据 → 继续检查3
      检查3: 该反应是否涉及平衡？
        题给了平衡常数K（Kc或Kp），或明确说"达到平衡" →
          ⚠ 设反应进度为x，列出各物质的平衡量（初始量±按系数比的变化量），代入K的表达式:
            现有独立条件能否确定所求？（即：除了待求的x之外，是否还有其他无法由已知条件确定的参数？）
            能确定（只剩x待求）→ 转10表用平衡计算（本导航到此结束，跨表求解路径尚未在10表中验证）
            不能确定（除x外还有未知参数）→ 信息不足，转到 ⚠出口
        没有 → 信息不足，转到 ⚠出口
    按系数比，从实际消耗量算出各物质的变化量:
      某物的变化量 = 实际消耗量(基准物) × 某物系数/基准物系数
    确定最终所求:
      求生成物的量 → n(目标物) = 生成量（即变化量）
      求反应物的剩余量 → n(目标物) = 初始量 − 消耗量
      求反应后某物的总量 → n(目标物) = 初始量 + 生成量 − 消耗量
    → 从分支1/2/3/4进来的 → 代入公式得到最终答案
    → 从分支5进来的（所求就是n）→ 直接输出对应状态的n作为最终答案

  第四步: 混合物或多步反应（第三步走不通时）
    列方程组 | 用守恒法(见03表电子守恒、13表三大守恒) | 用十字交叉法(见⑥)

  ⚠出口 (red): 条件不足 → 回到题目重新读，看是否漏看了数据、图表或隐含条件（"足量""适量""恰好反应"都是关键信息）

检查清单 (red warning box):
  □ 单位统一了吗？(mL→L, g→kg)
  □ 气体题确认了温度、压强和物态吗？
  □ 溶液体积 ≠ 溶剂体积
  □ "足量"只说明用量充足，不证明反应已完全——须有明确依据才能判定反应终态；终态数据用于求实际消耗量，只有确认某反应物耗尽时才能令其消耗量等于初始量
  □ 最终答案的有效数字和题目一致吗？

实战验证 (small box below, showing each node hit):
  典型题: 将6.5g Zn放入稀H₂SO₄中充分反应至Zn完全消耗，求标况下产生H₂的体积
  → 入口: 求V(气体) → 分支2 → 需要n(H₂)和Vₘ → 标况Vₘ=22.4
  → ★求n★ 第一步: A=Zn，给了质量6.5g → n(Zn)=6.5/65=0.1mol
  → 第二步: ①Zn是目标物H₂吗？不是 → 不匹配 → 转第三步
  → 第三步: 方程式 Zn+H₂SO₄=ZnSO₄+H₂↑
  → 检查1: 无转化率或实测数据 → 继续
  → 检查2: "完全消耗"=完全反应 → 有依据 → Zn为限量物耗尽 → 实际消耗量=0.1mol
  → 求的是生成物H₂ → n(H₂)=0.1×1/1=0.1mol
  → 返回分支2: V=0.1×22.4=2.24L ✓

  剩余量题: 0.15mol H₂SO₄与0.10mol Zn完全反应，求剩余H₂SO₄的物质的量
  → 入口: 求n → 分支5 → 目标物=H₂SO₄，所求状态=剩余量
  → ★求n★ 第一步: A=H₂SO₄，题直接给了n → n(A)=0.15mol，身份=H₂SO₄，状态=初始量
  → 第二步: ①H₂SO₄是目标物？是 ②初始量=所求的剩余量？不匹配 → 转第三步
  → 第三步: 方程式 Zn+H₂SO₄=ZnSO₄+H₂↑ → 系数比1:1
  → 检查1: 无α → 检查2: "完全反应" → 有依据 → 比较限量: 0.10/1<0.15/1 → Zn为限量物
  → H₂SO₄消耗量=0.10×1/1=0.10mol
  → 求剩余量 → n(剩余)=初始−消耗=0.15−0.10=0.05mol
  → 从分支5进来 → 直接输出n=0.05mol ✓

  反例A(有密度): 标况下11.2L H₂O(密度1.0g/mL)含多少个分子？
  → 入口: 求N → 分支4 → 需要n(H₂O) → ★求n★
  → 第一步: A=H₂O，给了体积11.2L → ⚠ 标况下H₂O是气态吗？不是，液态
  → 不是气态 → 题给了质量吗？没有 → 题给了密度吗？有，ρ=1.0g/mL
  → m=ρV=1.0×11200=11200g → n(H₂O)=11200/18≈622mol
  → 第二步: ①H₂O是目标物？是 ②求的就是总量？是 → 匹配 → 直接返回
  → N=622×N_A ✓

  反例B(无密度): 标况下11.2L H₂O含多少个分子？（题目未给密度）
  → 同上走到"不是气态" → 题给了质量？没有 → 题给了密度？没有
  → ⚠信息不足 → 停在出口，回题目找条件
  → 结论: 此题缺少密度或质量信息，无法计算（教学意义：标况+体积≠能用22.4，必须先判物态）

  转化率题: 0.10mol Zn与足量稀H₂SO₄反应，某时刻Zn的转化率为80%，求此时已生成H₂的量
  → 入口: 求n → 分支5 → 目标物=H₂，所求状态=生成量
  → ★求n★ 第一步: A=Zn，题直接给了n → n(A)=0.10mol，身份=Zn，状态=初始量
  → 第二步: ①Zn是目标物H₂吗？不是 → 不匹配 → 转第三步
  → 第三步: 方程式 Zn+H₂SO₄=ZnSO₄+H₂↑
  → 检查1: 题给了转化率α=80% → 命中 → 实际消耗量=0.10×0.80=0.080mol → 跳到系数比
  → 变化量: n(H₂)=0.080×1/1=0.080mol
  → 从分支5进来 → 直接输出n(H₂生成量)=0.080mol ✓

  信息不足题: 0.10mol Zn与足量稀H₂SO₄反应，某时刻已生成H₂的量是多少？（未给转化率）
  → 入口: 求n → 分支5 → 目标物=H₂，所求状态=某时刻的生成量
  → ★求n★ 第一步: A=Zn，题直接给了n → n(A)=0.10mol → 第二步: Zn≠H₂ → 转第三步
  → 检查1: 题给了转化率或实测数据吗？没有 → 继续
  → 检查2: 题说"足量"但不是"完全反应"或"恰好反应" → 无明确完全反应依据 → 继续
  → 检查3: 无K → 信息不足 → ⚠出口
  → 停在这里：无法确定该时刻反应进行到什么程度 ✓

  平衡题A(Δν≠0，给了体积): 在2L密闭容器中充入1mol N₂和4mol H₂，500°C下达到平衡，Kc=0.50，求平衡时NH₃的物质的量
  → 检查3: 有Kc → 设反应进度x mol N₂参与反应 → 平衡时: n(N₂)=1-x, n(H₂)=4-3x, n(NH₃)=2x
  → 代入Kc = [2x/2]² / {[(1-x)/2]·[(4-3x)/2]³} → 已知Kc=0.50, V=2L → 除x外无其他未知参数 → 只剩x待求 → 转10表 ✓

  平衡题B(Δν≠0，缺体积): 同上但未给容器体积
  → 检查3: 设x → Kc = (2x/V)² / {[(1-x)/V]·[(4-3x)/V]³} → Δν=-2 → V不能约掉 → 除x外还有未知参数V → ⚠信息不足 → 停 ✓

  平衡题C(Δν=0，无需体积): 在密闭容器中充入1mol H₂和2mol I₂，某温度下达到平衡，Kc=49，求平衡时HI的物质的量（未给体积）
  → 检查3: 设x mol H₂参与反应 → 平衡时: n(H₂)=1-x, n(I₂)=2-x, n(HI)=2x
  → Kc = (2x/V)² / {[(1-x)/V]·[(2-x)/V]} → Δν=0 → V全部约掉 → Kc = (2x)²/[(1-x)(2-x)] → 只剩x待求 → 转10表 ✓
  → （不会因为"没给体积"误停）

Section ⑥ "溶液稀释与混合计算" (inserted before footer, small module):
  溶液稀释公式: c₁V₁ = c₂V₂ （稀释前后溶质的物质的量不变）——为什么？加水只改变溶液体积不改变溶质量，n=cV恒定
    例：将0.5mol/L的NaOH溶液100mL稀释为0.1mol/L，需加水至V₂ = c₁V₁/c₂ = 0.5×100/0.1 = 500mL
  混合气体平均摩尔质量:
    M̄ = m总/n总 = (M₁n₁ + M₂n₂)/(n₁ + n₂)
    也可以用体积分数：M̄ = M₁φ₁ + M₂φ₂（φ为体积分数/摩尔分数）
    应用：若M̄ < 29 g/mol 则混合气体密度比空气小（可向下排空气法收集）
  十字交叉法 (callout box, light green):
    解混合问题的快速工具。适用于：混合气体的M̄、混合溶液的c或ω、同位素丰度
    方法: 把两个组分的量值写在十字的左上和左下，混合后的值写在交叉点，交叉相减取绝对值→得到两组分相应权重之比（具体见下方）
    例: H₂(M=2)和O₂(M=32)混合，M̄=10。十字交叉：|32-10|=22, |2-10|=8 → n(H₂):n(O₂)=22:8=11:4
    (为什么能用? 本质是加权平均的代数变形: M̄=(M₁n₁+M₂n₂)/(n₁+n₂) → 交叉相减后自动得到 n₁/n₂ 的比)
    ⚠ 交叉相减得到的比的含义取决于加权方式: 平均M → 物质的量(或体积)之比；ω → 溶液质量之比；c → 在体积可加等条件下为体积之比
  质量分数与物质的量浓度的换算:
    c = 1000ρω/M （c: mol/L, ρ: g/mL, ω: 质量分数, M: 溶质摩尔质量 g/mol）
