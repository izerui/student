Section ① "原子结构与能级" (left column, large module, deep blue header):

原子轨道:
- 定义: 由波函数描述的电子运动状态；常用等密度面圈出约90%电子出现概率来表示轨道形状（轨道不是运动路径，是概率分布的数学描述）
- 电子云: 电子在核外空间出现概率的分布图（点的疏密=概率大小）
- 能级→轨道数: s→1(球形)；p→3(px/py/pz，哑铃形)；d→5；f→7
- 每个轨道最多容纳2个电子(自旋相反)——泡利不相容原理

能级顺序(构造原理):
1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d ...
(用斜线图记忆: 按行排列1s / 2s 2p / 3s 3p 3d / 4s 4p 4d 4f / ...沿对角线从右上到左下读取，如2p→3s、3p→4s、3d→4p→5s)

三大规则:
Rule 1 - 构造原理: 基态原子外层电子按上述顺序填充(这是填充顺序，不代表填充后各轨道能级高低)
Rule 2 - 泡利不相容: 每个轨道最多2个电子，自旋方向相反(↑↓)
Rule 3 - 洪特规则: 等价轨道电子先单独占据且自旋平行(↑↑↑)，再配对
排布特例(红色高亮): Cr→d⁵半满；Cu→d¹⁰全满（指定特例，非任意改排规则）
  Cr: [Ar]3d⁵4s¹ (NOT 3d⁴4s²! 为什么? 半满d轨道交换能最大化：5个电子各占一个d轨道，自旋平行时体系总能量最低)
  Cu: [Ar]3d¹⁰4s¹ (NOT 3d⁹4s²! 全满d轨道能量同理更低)

失电子顺序: 先外层ns，再内层(n-1)d → Fe²⁺是[Ar]3d⁶不是3d⁴4s²
  (为什么先失4s? 填充时4s能量低于3d所以先填，但ns和(n-1)d都填有电子后，(n-1)d电子的能量往往更低→成离子时先失去最外层4s电子)

Section ② "元素周期表结构" (right column top, medium module, teal header):

周期表示意图:
- 7个周期: 第1周期为很短周期(2种)，第2、3周期为短周期(各8种)，第4、5周期为长周期(各18种)，第6、7周期为特长周期(各32种)
- 18纵列：现代编号1-18族；旧式标记另列：ⅠA-ⅦA、ⅠB-ⅦB、Ⅷ(三列)、0族
- 核心等式: 原子序数=核电荷数=质子数=核外电子数(中性原子)
- 质量数: A(质量数) = Z(质子数) + N(中子数)
- 同位素: 质子数相同、中子数不同(如¹H/²H(D)/³H(T), ¹²C/¹³C/¹⁴C)

1-20号电子排布(紧凑表):
H(1) He(2) Li(2,1) Be(2,2) B(2,3) C(2,4) N(2,5) O(2,6) F(2,7) Ne(2,8) Na(2,8,1) Mg(2,8,2) Al(2,8,3) Si(2,8,4) P(2,8,5) S(2,8,6) Cl(2,8,7) Ar(2,8,8) K(2,8,8,1) Ca(2,8,8,2)
容量约束: 每层最多2n²个；最外层≤8(第一层≤2)
填充路径: 按能级顺序，不按电子层逐层填满；K/Ca：先填4s，后填3d

Section ③ "同周期/同族递变规律" (middle, large module spanning full width, orange header):

同周期(左→右, 以第3周期Na→Cl为例) 双向箭头+趋势:
| 性质 | 趋势 | 典型对比 |
| 原子半径 | 递减↓ | Na>Mg>Al>Si>P>S>Cl |
(为什么递减? 同周期核电荷Z逐个增加但内层电子屏蔽基本不变→有效核电荷Zeff增大→对外层电子拉力更强→半径缩小)
| 最外层电子 | 递增(1→7) | Na(1)→Cl(7) |
| 金属性/非金属性 | 金属↓非金属↑ | Na强金属→Cl强非金属 |
| 最高正价 | +1→+7 | 主族元素常等于最外层电子数，但O、F通常不按此规律讨论 |
| 最低负价 | -4→-1 | 等于-(8-最外层电子数)(仅非金属) |
| 氧化物水化物 | 碱性↓→两性→酸性↑ | NaOH→Al(OH)₃→HClO₄ |
| 氢化物稳定性 | ↑增强 | SiH₄<PH₃<H₂S<HCl |

同族(上→下): 原子半径↑, 金属性↑, 非金属性↓; ⅠA族例: 最高价氧化物水化物碱性↑(LiOH<NaOH<KOH<CsOH); ⅦA族例: 氢化物稳定性↓(HF>HCl>HBr>HI) (do NOT draw a separate 非金属性 row for ⅠA elements)

Section ④ "判据·电离能·电负性" (bottom, large module, purple header):

金属性强弱判据(3种):
①与水/酸反应剧烈程度(越剧烈→越强) ②最高价氧化物水化物碱性(越强→越强) ③置换反应(活泼金属置换较不活泼金属)

非金属性强弱判据(3种):
①与H₂化合难易+氢化物稳定性(越易/越稳→越强) ②最高价氧化物水化物酸性(越强→越强) ③置换反应(Cl₂+2NaBr→2NaCl+Br₂, Cl>Br)

第一电离能(I₁):
- 定义: 气态基态原子失去一个电子所需最小能量(kJ/mol)
- 同周期: 总体左→右递增, 两处反常:
    ⅡA>ⅢA (为什么? ns²全满亚层特别稳定，打破需额外能量)
    ⅤA>ⅥA (为什么? np³半满稳定——洪特规则的能量体现，半满→全对称交换能最大)
- 同族: 上→下递减
- 逐级电离能应用: I₁<<I₂处发生突变→判断主族族数(如Na的I₁很小I₂突增→+1价)

电负性(鲍林标度):
- 定义: 原子在共价键中吸引共用电子对的能力(F=4.0最大)
- 同周期左→右↑, 同族上→下↓
- 电负性应用矩阵: 差值约1.7→成键类型经验参考(为什么? 电负性差反映原子吸引共用电子对的能力差距→差大则电子严重偏向一方→趋向离子键)；结构相近时差值↑→键极性通常↑；数值约2.0→金属/非金属倾向参考（均非硬分界）

对角线规则: Li~Mg, Be~Al, B~Si (同周期向右↑与同族向下↓抵消→电负性/性质相似)
例: Al与Be都能与NaOH反应; Li与Mg都能与N₂直接化合
