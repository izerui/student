Section ② "硫及其化合物" (top-right, large module):
Transformation chain with arrows:
S →(燃烧，注意只生成SO₂不生成SO₃!) SO₂ →(+O₂, V₂O₅/加热, 可逆: 2SO₂+O₂⇌2SO₃) SO₃ →(+H₂O) H₂SO₄
(为什么只生成SO₂? S→SO₃的活化能远高于S→SO₂，且需要催化剂V₂O₅，空气中燃烧条件不够)
Side reactions:
SO₂ + H₂O ⇌ H₂SO₃ (亚硫酸，弱酸)
SO₂的性质 callout box:
- 酸性氧化物：与NaOH反应 SO₂+2NaOH→Na₂SO₃+H₂O
- 还原性：SO₂+Cl₂+2H₂O→H₂SO₄+2HCl
- 漂白性：使品红褪色（加热恢复！与Cl₂漂白不同）
浓H₂SO₄三大特性: ①吸水性 ②脱水性(使蔗糖变黑) ③强氧化性(与Cu/C反应)
Cu + 2H₂SO₄(浓) →(加热) CuSO₄ + SO₂↑ + 2H₂O

Section ③ "氮及其化合物" (middle, large module spanning full width):
Transformation chain:
N₂ →(放电或高温) NO →(遇空气立即氧化) NO₂ →(+H₂O) HNO₃
Note: The condition for N₂+O₂→NO is 放电(lightning) or 高温, NOT 高温高压. 高温高压 is for the Haber process (N₂+H₂→NH₃), not for NO formation.
Key reactions:
N₂ + O₂ ⇌(放电) 2NO (无色气体，不溶于水)
2NO + O₂ → 2NO₂ (红棕色气体，有刺激性气味)
3NO₂ + H₂O → 2HNO₃ + NO (工业制硝酸; 为什么产NO? NO₂发生歧化：部分N从+4→+5被氧化进入HNO₃，部分N从+4→+2被还原成NO)
HNO₃的性质 box:
- 强酸性
- 不稳定性：4HNO₃ →(光照/加热) 4NO₂↑ + O₂↑ + 2H₂O (所以棕色瓶保存)
- 强氧化性：与Cu反应 3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
  Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
  (浓酸产NO₂、稀酸产NO: 浓酸NO₃⁻浓度高→氧化性更强→产物为高氧化态NO₂(+4); 稀酸氧化性较弱→产物为低氧化态NO(+2))
- 钝化：常温下使Fe/Al钝化（浓HNO₃）
NH₃ side branch: NH₃·H₂O ⇌ NH₄⁺ + OH⁻ (弱碱); NH₃的检验：湿润红色石蕊试纸变蓝
工业合成氨（哈伯法）:
  N₂ + 3H₂ ⇌(高温高压, 催化剂Fe) 2NH₃  （注意：可逆反应，条件是高温高压+催化剂，不是放电!）
  Note: "合成氨是高温高压催化剂；N₂→NO是放电或高温，两者条件完全不同！"
合成氨工业条件选择（哈伯法条件优化，核心考点）:
  温度选择 ~500°C: 正反应放热(ΔH<0)→低温有利于平衡→但温度太低反应速率太慢且催化剂不活化→折中选500°C（动力学与热力学的博弈: 催化剂在此温度活性最高，平衡转化率虽非最大但速率可接受）
  压强选择 10-30MPa: 正反应气体体积减小(4mol→2mol)→高压有利于平衡→但压强太高设备成本太高→折中选中等高压
  铁催化剂: 活性主体Fe；助催化成分K₂O/Al₂O₃等→速率↑，平衡位置不变
  原料气循环利用: 分离出NH₃(液化)后→未反应的N₂和H₂循环回合成塔→提高原料总转化率
  Key note: "工业条件是平衡移动原理+反应速率+经济成本三者折中的结果，不是理论最优！"
氨的催化氧化（工业制硝酸第一步——奥斯特瓦尔德法）:
  4NH₃ + 5O₂ →(催化剂Pt-Rh, 加热) 4NO + 6H₂O
  然后：2NO + O₂ → 2NO₂；3NO₂ + H₂O → 2HNO₃ + NO（两个独立方程式，分两行写；与上方氮的转化链衔接）

Section ④ "硅及其化合物" (bottom-left, medium module):
Key facts:
- Si: 半导体材料，自然界无游离态硅
- SiO₂: SiO₂+4HF→SiF₄+2H₂O（常见酸中特例：HF）
  不与其他酸反应，但与NaOH反应 SiO₂+2NaOH→Na₂SiO₃+H₂O
- Na₂SiO₃: 水溶液俗称水玻璃，是防火剂
- H₂SiO₃: 不溶于水的弱酸，弱于H₂CO₃
  CO₂少量时: Na₂SiO₃+CO₂+H₂O→Na₂CO₃+H₂SiO₃↓ (强酸制弱酸，说明酸性H₂CO₃>H₂SiO₃)
  CO₂过量时: Na₂SiO₃+2CO₂+2H₂O→2NaHCO₃+H₂SiO₃↓

Section ⑥ "碳及其化合物" (inserted before footer, medium module):
Network diagram centered on C:
  C的还原性:
  - 2Fe₂O₃ + 3C →(高温) 4Fe + 3CO₂↑ （炼铁原理之一，C做还原剂）
  - C + H₂O →(高温) CO + H₂ （水煤气反应，吸热反应）
  - SiO₂ + 3C →(高温) SiC + 2CO↑ （制碳化硅）
  CO的性质（无色无味有毒气体）:
  - 还原性：Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂ （工业炼铁的主要反应）
  - 可燃性：2CO + O₂ →(点燃) 2CO₂
  - Note: CO不是酸性氧化物！不与水反应、不与NaOH反应
  CO₂与碱反应——量的关系（重要考点）:
  - CO₂(少量) + 2NaOH → Na₂CO₃ + H₂O （碱过量时生成正盐）
  - CO₂(过量) + NaOH → NaHCO₃ （CO₂过量时生成酸式盐）
  - CO₂(少量) + Ca(OH)₂ → CaCO₃↓ + H₂O
  - 2CO₂(过量) + Ca(OH)₂ → Ca(HCO₃)₂ （沉淀溶解！澄清石灰水先变浑浊后变澄清）
  Key note: "CO₂通入碱液，少量→正盐，过量→酸式盐，这是量变引起质变的典型！"
