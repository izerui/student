Section ① "物质分类决策树" (top, hero module spanning full width, dark blue header):
A complete hierarchical tree diagram — the CENTRAL THINKING MODEL of this poster. Starting from "物质" at the top, each fork is a yes/no decision:

物质 → 是否只含一种组成固定的物质? → 是 → 纯净物
                      → 否 → 混合物

纯净物 → 只含一种元素? → 是 → 单质 (金属: Fe,Cu,Al / 非金属: O₂,S,C,Si)
                        → 否 → 化合物

化合物 branches (常见类别，不穷尽):
  氧化物 (由两种元素组成, 其一为O): 金属氧化物 Fe₂O₃, CuO / 非金属氧化物 CO₂, SO₂
  酸 (水溶液中电离产生的阳离子全部是H⁺): HCl, H₂SO₄, HNO₃, CH₃COOH
  碱 (水溶液中电离产生的阴离子全部是OH⁻): NaOH, Ca(OH)₂, KOH, Ba(OH)₂
  盐 (金属阳离子/NH₄⁺ + 酸根阴离子): NaCl, CaCO₃, Na₂SO₄
  其他化合物 (有机物等): 如CH₃CH₂OH、CH₄（详见14-15表）

混合物 → 是分散系吗？（一种物质分散在另一种中）
  是 → 按分散质粒子直径分:
    <1nm → 溶液 (均一/稳定/透明, 如NaCl水溶液)
    1-100nm → 胶体 (如Fe(OH)₃胶体)
    >100nm → 浊液 (悬浊液/乳浊液, 不稳定)
  其他混合物

Callout attached to 胶体: 三个特性
  ① 丁达尔效应: 光束穿过胶体出现光亮通路(鉴别胶体vs溶液的方法)——原因: 胶体分散质微粒(1-100nm)对可见光(波长400-700nm)发生散射
  ② 聚沉: 加电解质/加热/加相反电荷胶体 → 胶体粒子聚集沉降
  ③ 电泳: 胶体粒子带电, 外加电场中定向移动(如Fe(OH)₃胶体粒子带正电→向阴极移动)

Callout at bottom of tree: 同素异形体
  同一元素形成的不同单质: O₂与O₃, 金刚石与石墨与C₆₀, 红磷(P)与白磷(P₄)
  注意: 同素异形体间的转化属于化学变化

Section ② "电解质判断流程" (middle-left, medium module, green header):
Decision flowchart with diamond nodes:
Start → 是化合物吗?
  → 否 → 不讨论(单质和混合物不属于电解质或非电解质)
  → 是 → 该化合物自身能电离出离子吗?(在水溶液中或熔融态下自身电离, 非与水反应后产物电离)
    → 否 → 非电解质(如CO₂, SO₂, 乙醇)
    → 是 → 电解质 → 能完全电离吗?
      → 是 → 强电解质(强酸/强碱/大多数盐——BaSO₄、CaCO₃虽难溶, 但溶解部分完全电离, 仍是强电解质)。判据是在水溶液中能否完全电离，不由键的极性决定(如HF极性很强，却是弱酸)
      → 否 → 弱电解质(弱酸/弱碱/水)。为什么部分电离？电离产生的离子与对应酸根/碱的亲和力大→易重新结合→电离与结合达动态平衡

⚠️ 易错: CO₂溶于水能导电, 但CO₂是非电解质! 导电离子来自H₂CO₃电离, 非CO₂自身电离。

Section ③ "离子方程式：拆与不拆" (middle-right, medium module, teal header):
Two columns:
✅ 要拆(写成离子):
  强酸: HCl, H₂SO₄, HNO₃
  强碱溶液: NaOH, KOH, Ba(OH)₂
  Ca(OH)₂分支: 澄清石灰水→拆；石灰乳→保留化学式
  可溶性盐: NaCl, KNO₃, BaCl₂
✗ 不拆(保留化学式):
  弱酸: H₂CO₃, CH₃COOH, HF
  弱碱: NH₃·H₂O, Fe(OH)₃
  难溶物: AgCl↓, BaSO₄↓, CaCO₃↓
  氧化物: CuO, SiO₂, Fe₂O₃
  气体: CO₂↑, SO₂↑, NH₃↑
  水: H₂O
  单质: Fe, Cu, O₂

Section ④ "化学键判断" (Row 2 right column, compact module, orange header):
Two-column comparison with visual icons:
活泼金属 + 活泼非金属 → 离子键 (如Na⁺Cl⁻, 阴阳离子间静电作用)
非金属 + 非金属 → 共价键 (如H-O-H, 共用电子对)

Section ⑤ "反应能量与热化学方程式" (Row 3 full width, compact module, red header):
放热反应(ΔH<0): 燃烧/中和/活泼金属+酸或水/大多数化合反应——为什么放热？生成物总能量低于反应物，能量差以热的形式释放(从键能角度: 成新键释放的能量 > 断旧键吸收的能量)
吸热反应(ΔH>0): 大多数分解反应(CaCO₃分解)/Ba(OH)₂·8H₂O+NH₄Cl/C+CO₂→2CO/C+H₂O→CO+H₂——反之: 断旧键吸收的能量 > 成新键释放的能量

热化学方程式书写5规则:
① 标聚集状态: (s)固 (l)液 (g)气 (aq)水溶液
② 标ΔH(kJ/mol): 放热负值, 吸热正值
③ 系数可用分数(表示1mol某物质反应时的ΔH)
④ ΔH与系数成正比: 系数加倍则ΔH加倍
⑤ 正逆反应ΔH数值相等、符号相反
示例: H₂(g) + ½O₂(g) = H₂O(l)  ΔH = -285.8 kJ/mol
