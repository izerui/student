Section ① "弱电解质的电离平衡" (top, hero module, full width):
Core concept: 弱电解质在水中部分电离，存在电离平衡（动态平衡）。
跨表联系 (small label): Ka、Kb、Kw、Ksp 本质上都是化学平衡常数K的具体形式——同一套平衡理论(密码表10)在水溶液中的不同应用
为什么存在平衡: 弱电解质的共价键只部分断裂→电离产生的离子又能重新结合成分子→正逆速率相等时达到动态平衡(区别于强电解质的完全电离)
电离平衡常数（只与温度有关，与浓度无关）:
- CH₃COOH ⇌ CH₃COO⁻ + H⁺, Ka = c(CH₃COO⁻)·c(H⁺)/c(CH₃COOH)
- NH₃·H₂O ⇌ NH₄⁺ + OH⁻, Kb = c(NH₄⁺)·c(OH⁻)/c(NH₃·H₂O)
- 同温、同初始浓度：Ka/Kb↑→通常电离程度↑；浓度不同→另算电离百分数
多元弱酸分步电离: Ka₁ >> Ka₂ >> Ka₃（以第一步为主）
- H₂CO₃ ⇌ H⁺ + HCO₃⁻ (Ka₁ = 4.2×10⁻⁷)
- HCO₃⁻ ⇌ H⁺ + CO₃²⁻ (Ka₂ = 5.6×10⁻¹¹)
影响电离平衡的因素 (callout box with arrows, 以弱酸为例，弱碱类推时H⁺/OH⁻互换):
- 加水稀释 → 平衡正移 → 电离程度增大 → 但弱酸: c(H⁺)降低（稀释效果大于正移效果）；弱碱: c(OH⁻)降低、c(H⁺)升高
- 升温→查电离ΔH：吸热→Ka↑；放热→Ka↓
- 外加同离子（如向CH₃COOH中加CH₃COONa）→ 抑制电离 → 平衡左移
- 加碱中和H⁺(弱酸分支) / 加酸中和OH⁻(弱碱分支) → 促进电离 → 平衡正移

Section ② "水的电离与pH" (middle-left, large module):
水的自耦电离: H₂O + H₂O ⇌ H₃O⁺ + OH⁻ (简写: H₂O ⇌ H⁺ + OH⁻)
离子积常数: Kw = c(H⁺)·c(OH⁻) = 10⁻¹⁴ (25°C)
Note: "Kw只与温度有关。升温→Kw增大（水的电离吸热）。任何水溶液中Kw都成立！"
pH定义: pH = -lg c(H⁺)
| 溶液性质 | c(H⁺)与c(OH⁻)关系 | pH(25°C) |
| 酸性 | c(H⁺) > c(OH⁻) | pH < 7 |
| 中性 | c(H⁺) = c(OH⁻) | pH = 7 |
| 碱性 | c(H⁺) < c(OH⁻) | pH > 7 |
pH计算速查:
强酸: c(H⁺)直接代入。例: 0.01 mol/L HCl → c(H⁺) = 0.01 mol/L → pH = 2
强碱: 先算c(OH⁻) → c(H⁺) = Kw/c(OH⁻)。例: 0.01 mol/L NaOH → c(OH⁻) = 0.01 → c(H⁺) = 10⁻¹² → pH = 12
酸碱混合决策树: 先按物质的量判反应后组成→分流
  强酸+强碱→有剩余：剩余n/V总→c(H⁺)或c(OH⁻)→pH；恰好反应：中性→pH=pKw/2
  含弱酸/弱碱→有剩余：电离/水解平衡；恰好反应：盐类水解→转入③
Warning callout: "先算n，再判组成，最后求平衡；强酸强碱恰好反应时，25°C下pH=7。V总≈V酸+V碱"

Small box "酸碱中和滴定计算" (below the decision tree, compact):
公式: c(待测) = c(标准) × V(标准) / V(待测)（适用于1:1计量比，如HCl+NaOH；其他计量比如H₂SO₄+NaOH需按方程式系数换算：c(H₂SO₄)=c(NaOH)×V(NaOH)/[2×V(H₂SO₄)]）
例: 0.1000 mol/L NaOH 滴定 25.00 mL HCl, 终点消耗 NaOH 23.50 mL
  → c(HCl) = 0.1000 × 23.50 / 25.00 = 0.0940 mol/L
滴定曲线: pH 在化学计量点附近发生突变(突变区)，指示剂的变色范围应落在突变区内
(详见07表滴定操作与误差分析)

Section ③ "盐类水解" (middle-right, large module, coral/red header):
实质: 盐电离出的弱酸根/弱碱阳离子与水电离的H⁺/OH⁻结合，破坏水的电离平衡，促进水的电离。
为什么水解使pH偏离7: 弱离子"消耗"了水电离出的某一种离子(H⁺或OH⁻)→水的电离平衡正向移动→另一种离子过剩→溶液显酸性或碱性
规律口诀 (giant stylized text): "有弱才水解，无弱不水解；谁弱谁水解，谁强显谁性"
水解方程式书写规则:
- 用⇌号（水解程度小，是可逆过程）
- 产物一般不标↑↓（水解程度小，气体/沉淀量极少）
- 多元弱酸根分步水解（以第一步为主）
典型水解方程式:
- Na₂CO₃ (强碱弱酸盐，碱性): CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻
- NH₄Cl (强酸弱碱盐，酸性): NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺
- CH₃COONa (强碱弱酸盐，碱性): CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻
- FeCl₃ (强酸弱碱盐，酸性): Fe³⁺ + 3H₂O ⇌ Fe(OH)₃ + 3H⁺
水解应用 (green box):
- 明矾净水: Al³⁺水解 → Al(OH)₃胶体 → 吸附水中悬浮杂质
- 泡沫灭火器: NaHCO₃溶液与Al₂(SO₄)₃溶液发生相互促进的水解，生成Al(OH)₃和大量CO₂泡沫
- FeCl₃止血: Fe³⁺使血液中的蛋白质凝固并产生收敛作用；不宜简单解释为Fe(OH)₃胶体“聚沉血液”
- 热纯碱去油污: 升温促进水解 → OH⁻浓度增大 → 碱性增强
影响水解因素: 升温→促进; 加水稀释→促进; 加酸→抑制弱碱阳离子水解(促进弱酸根水解); 加碱→反之

Section ④ "溶度积Ksp" (bottom-left, medium module, purple header):
定义: 难溶电解质在水中达到沉淀溶解平衡时，离子浓度幂之积为常数。
为什么Ksp能判断沉淀: Ksp是饱和状态下离子浓度幂积的定值→实际离子积Q超过这个定值→溶液过饱和→多余的离子必须以沉淀形式析出；Q<Ksp→未饱和→沉淀会继续溶解
AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq), Ksp = c(Ag⁺)·c(Cl⁻)
Ag₂CrO₄(s) ⇌ 2Ag⁺ + CrO₄²⁻, Ksp = c²(Ag⁺)·c(CrO₄²⁻)
Ca₃(PO₄)₂(s) ⇌ 3Ca²⁺ + 2PO₄³⁻, Ksp = c³(Ca²⁺)·c²(PO₄³⁻)
Key rules:
- Ksp只与温度有关，与离子浓度无关
- 比溶解度先查组成：同型→可比Ksp；异型→先由Ksp求摩尔溶解度s（同温，排除副反应）
判断沉淀生成/溶解 (decision flowchart):
计算离子积Qc → 与Ksp比较:
Qc > Ksp → 过饱和 → 有沉淀析出
Qc = Ksp → 沉淀溶解平衡（饱和）
Qc < Ksp → 不饱和 → 沉淀溶解 / 不产生沉淀
沉淀转化链: 新沉淀生成→共享离子浓度↓→原沉淀溶解；方向判据：计量关系+Ksp+实际浓度
例: AgCl(白) + KI → AgI(黄) + KCl (Ksp(AgI) << Ksp(AgCl))

Section ⑤ "三大守恒与离子浓度排序" (bottom-right, medium module, orange header):
Three conservation laws with clear definitions and formulas:
为什么三守恒是解题利器: 它们是自然定律的数学表达——电荷守恒源于电中性、物料守恒源于原子守恒、质子守恒可由前两者消元得到（不是额外独立条件）。选取独立守恒关系，结合平衡常数(Ka/Kb/Kw)和已知组成求解；质子守恒可用于简化或校验
电荷守恒: 溶液呈电中性 → 所有阳离子电荷总数 = 所有阴离子电荷总数
物料守恒: 溶质中某元素的总物质的量在各种存在形式中守恒
质子守恒: 水电离出的c(H⁺)总 = 水电离出的c(OH⁻)总（由电荷守恒+物料守恒联立消去得到）

Worked example (yellow highlight box): 0.1 mol/L Na₂CO₃溶液
电荷守恒: c(Na⁺) + c(H⁺) = 2c(CO₃²⁻) + c(HCO₃⁻) + c(OH⁻)
物料守恒: c(Na⁺) = 2[c(CO₃²⁻) + c(HCO₃⁻) + c(H₂CO₃)]
质子守恒: c(OH⁻) = c(H⁺) + c(HCO₃⁻) + 2c(H₂CO₃)
离子浓度排序: c(Na⁺) > c(CO₃²⁻) > c(OH⁻) > c(HCO₃⁻) > c(H⁺)
排序推理: Na⁺最大(完全电离)；CO₃²⁻水解程度小故仍大量存在；水解产生OH⁻使碱性；HCO₃⁻由水解产生但量少；H⁺最小(碱性溶液)

解题思维链 (bottom strip):
"离子浓度排序题" → ①判断溶液酸碱性 → ②写出水解/电离方程式 → ③用三大守恒列等式 → ④根据水解/电离程度比较大小
