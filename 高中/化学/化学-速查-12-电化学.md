Section ① "原电池 vs 电解池 镜像对比" (top, hero module spanning full width, the CENTRAL THINKING MODEL):
A symmetric mirror-image diagram: left side = 原电池, right side = 电解池, sharing a central axis.

Left mirror (原电池 — 化学能→电能, 自发反应, 无需外接电源):
  原理: 自发氧化还原反应中的电子转移被导线分隔→电子被迫走外电路→形成定向电流
  负极 = 发生氧化的电极(失电子) → 电子从负极流出。普通原电池中常为较活泼金属；燃料电池中为燃料电极
    为什么是氧化: 负极是电子流出的一端→该电极上的物质失去电子=被氧化
  正极 = 发生还原的电极(得电子) → 电子流入正极。普通原电池中常为较不活泼金属/碳棒；燃料电池中为氧气电极
  构成4条件: ①两个电极(通常活性不同，燃料电池等可用相同惰性电极) ②具有离子导电能力的电解质介质（溶液、熔融盐、固体电解质、质子交换膜等） ③闭合回路 ④能自发氧化还原反应

Right mirror (电解池 — 电能→化学能, 非自发反应, 需外接直流电源):
  阳极(接电源正极): 氧化反应(失电子)
  阴极(接电源负极): 还原反应(得电子)
  口诀: "阳氧阴还"

Central shared axis — 粒子移动方向:
  原电池外电路: 电子从负极 →(导线)→ 正极
  电解池外电路: 阳极电子 →(导线)→ 电源正极; 电源负极 →(导线)→ 阴极供电子
  内电路(溶液，两种装置相同): 阳离子 → 阴极(原电池正极); 阴离子 → 阳极(原电池负极)

Section ② "放电顺序与应用" (middle-left, medium module, teal header):
阳极氧化顺序(惰性电极、常见水溶液中的经验顺序，实际还受浓度和过电势影响):
  S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根 > F⁻
  为什么有此顺序: 阴离子失电子能力越强(还原性越强)→越优先在阳极放电
  注意: 活泼金属电极自身先溶解!

阴极还原顺序(常见水溶液中的经验顺序，实际还受离子浓度、电极材料和过电势影响):
  Ag⁺>Hg²⁺>Fe³⁺>Cu²⁺>H⁺(酸)>Pb²⁺>Sn²⁺>Fe²⁺>Zn²⁺>H⁺(水)>Al³⁺>Mg²⁺>Na⁺>K⁺

Worked example (电解CuCl₂, 惰性电极):
  阳极: 2Cl⁻ - 2e⁻ = Cl₂↑ | 阴极: Cu²⁺ + 2e⁻ = Cu

应用:
  电镀: 镀件做阴极, 镀层金属做阳极, 含镀层离子的溶液做电镀液
  电精炼: 粗金属做阳极, 纯金属做阴极
  口诀: "镀件阴极粗阳极"

常见二次电池:
  铅蓄电池: Pb + PbO₂ + 2H₂SO₄ ⇌ 2PbSO₄ + 2H₂O (放电→ / ←充电)

新型电池电极反应式书写技巧:
  已知总反应和其中一个电极反应 → 总反应减去已知 = 另一个电极反应
  碱性电解质中不能出现H⁺; 酸性中不能出现OH⁻

Section ③ "金属腐蚀与防护" (middle-right, medium module, red header):
两种腐蚀:
  化学腐蚀: 金属直接与氧化性物质反应(如Fe在干燥Cl₂中)
  电化学腐蚀: 不纯金属在电解质溶液中形成微原电池(更普遍/更快!)
    为什么吸氧比析氢更常见: 自然环境多为中性或弱酸性+有溶解O₂→O₂优先在正极被还原；只有强酸性环境才析氢

电化学腐蚀两种类型:
  吸氧腐蚀(中性/弱酸性/潮湿, 最常见):
    负极(Fe): Fe - 2e⁻ = Fe²⁺
    正极(C等杂质): O₂ + 2H₂O + 4e⁻ = 4OH⁻
    后续: Fe²⁺ → Fe(OH)₂ → Fe(OH)₃ → Fe₂O₃·xH₂O(铁锈)
  析氢腐蚀(强酸性):
    负极(Fe): Fe - 2e⁻ = Fe²⁺
    正极(C等): 2H⁺ + 2e⁻ = H₂↑

三种防护方法:
  ① 牺牲阳极法: 连接更活泼金属(如船体Fe焊Zn块, Zn做负极被腐蚀, Fe被保护)
    原理: 更活泼金属优先失电子(被氧化)→充当原电池负极→被保护金属成为正极不被腐蚀
  ② 外加电流法: 被保护金属接外电源负极(做阴极→外部持续补充电子→不失电子→不氧化)
  ③ 覆盖保护层: 涂油漆/搪瓷/镀层/氧化膜(隔绝水和O₂)

Section ④ "电化学计算" (bottom, wide module, green header):
核心原则: 得失电子守恒

基本公式:
  Q = It (Q电荷量/C, I电流/A, t时间/s)
  n(e⁻) = Q/F = It/F    F = 96500 C/mol(法拉第常数)

串联电路: 各电解池通过各电极的电荷量相等 → 一个电极的数据可推算其他电极产物量

跨表联系 (small label): 电化学的本质是氧化还原反应(密码表03) + 化学能与电能的转化。电池的电动势E与反应的ΔG关系(大学拓展): ΔG = -nFE（n=转移电子mol数，F≈96500 C/mol）→ E>0 自发(原电池)，E<0 非自发(需外加电压=电解)。这也是密码表10中ΔG判据在电化学中的体现

电极增减重:
  阴极增重 = 析出金属质量
  阳极(活泼)减重 = 溶解金属质量
  阳极(惰性)不增不减(产气体)

Worked example:
  惰性电极电解CuSO₄, 阴极增重6.4g
  Cu²⁺+2e⁻=Cu → n(Cu)=6.4/64=0.1mol → n(e⁻)=0.2mol
  阳极: 2H₂O-4e⁻=O₂↑+4H⁺ → n(O₂)=0.05mol → V=1.12L(标况)
