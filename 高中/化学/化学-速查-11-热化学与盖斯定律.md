Section ① "热化学方程式书写规则" (top, hero module, full width):
Six rules listed with numbered icons, each with a specific example:

Rule 1: 必须标注物质的聚集状态 — (s)固体, (l)液体, (g)气体, (aq)水溶液
Rule 2: 必须标注ΔH及其单位 — ΔH的单位为kJ/mol, 放热反应ΔH<0, 吸热反应ΔH>0
Rule 3: 系数表示物质的量, 可以用分数 — 如 H₂(g) + ½O₂(g) = H₂O(l) ΔH = -285.8 kJ/mol
Rule 4: 系数加倍则ΔH加倍 — 2H₂(g) + O₂(g) = 2H₂O(l) ΔH = -571.6 kJ/mol
Rule 5: 正逆反应ΔH数值相等符号相反 — 正反应ΔH = -285.8 → 逆反应ΔH = +285.8 kJ/mol
Rule 6: 状态符号替代↑↓；通常省略点燃/催化剂；温度、压强按题设注明

与普通化学方程式的对比框:
| | 普通化学方程式 | 热化学方程式 |
| 系数含义 | 各物质的化学计量数之比 | 与所写反应进度对应的物质的量比例，可为分数 |
| 状态标注 | 按题目和书写规范标注，常见方程式可用↑↓或状态符号说明 | 必须标(s)(l)(g)(aq) |
| 能量信息 | 无 | 必须标ΔH |
| 条件 | 需标注(点燃/加热/催化剂) | 一般不标点燃/催化剂; 须注明反应温度 |
| ↑↓符号 | 需标 | 不标 |

Worked example:
2H₂(g) + O₂(g) = 2H₂O(l) ΔH = -571.6 kJ/mol
Note: "H₂O写(l)时|ΔH|更大——因为气态水凝结为液态水还额外释放汽化热(约44 kJ/mol per mol H₂O)，总放热更多; H₂O写(g)时ΔH = -483.6 kJ/mol"

Section ② "重要热化学概念" (middle-left, medium module):
Three concept boxes with definitions and key notes:

燃烧热 (拓展·人教版概念，鲁科版教材未单列):
- 定义: 在101 kPa下, 1 mol纯物质完全燃烧生成指定产物时放出的热量
- 指定产物: C→CO₂(g), H→H₂O(l), S→SO₂(g), N→N₂(g)
- 注意: ①燃烧热一定是放热, ΔH<0 ②以1mol可燃物为标准 ③产物必须是最稳定的(CO₂不是CO, H₂O是液态不是气态!)
- 例: C(s)的燃烧热为393.5 kJ/mol, 即C(s)+O₂(g)=CO₂(g) ΔH=-393.5 kJ/mol

中和热 (拓展·人教版概念；鲁科版称“中和反应的反应热”):
- 定义: 在稀溶液中, 强酸与强碱反应生成1 mol H₂O时放出的热量
- 数值: ΔH ≈ -57.3 kJ/mol (强酸强碱稀溶液、且不生成沉淀等其他热效应时近似相同；如稀H₂SO₄+Ba(OH)₂生成BaSO₄会多放热)
- 条件分支: 稀强酸+稀强碱→约-57.3 kJ/mol H₂O；弱酸/弱碱→叠加电离热；浓溶液→叠加稀释热（后两类不直接套值）

反应热的两种理解:
角度1(平均键能近似估算): ΔH ≈ ΣE(反应物中断裂化学键的键能) - ΣE(生成物中形成化学键的键能)
(断旧键吸热, 成新键放热)
角度2(能量): ΔH = E(生成物总能量) - E(反应物总能量)
(生成物能量低于反应物→放热→ΔH<0)
Warning: "两个公式减号方向相反! 键能是'反应物-生成物', 能量是'生成物-反应物'"

Section ③ "盖斯定律" (middle-right, large module, highlighted border):
Core statement in bold:
"化学反应的反应热(ΔH)只与反应的始态和终态有关, 与反应的途径无关"
为什么成立: 焓H是状态函数——只取决于物质的种类、状态和量，与到达该状态的路径无关（类比: 海拔差只由起点和终点决定，与登山路线无关）

Application method:
将已知热化学方程式进行加、减、乘运算 → 得到目标方程式 → ΔH做同样运算

Worked example (complete with solution):
已知:
① C(s) + O₂(g) = CO₂(g)  ΔH₁ = -393.5 kJ/mol
② CO(g) + ½O₂(g) = CO₂(g)  ΔH₂ = -283.0 kJ/mol
求: C(s) + ½O₂(g) = CO(g)  ΔH = ?

解题步骤:
Step 1: 写出目标方程式: C(s) + ½O₂(g) = CO(g)
Step 2: 观察→目标式左边有C(s)(在①左边), 右边有CO(g)(在②左边) → 需要①-②
Step 3: ① - ② → C(s) + O₂(g) - CO(g) - ½O₂(g) = CO₂(g) - CO₂(g)
整理: C(s) + ½O₂(g) = CO(g) ✓
Step 4: ΔH = ΔH₁ - ΔH₂ = -393.5 - (-283.0) = -110.5 kJ/mol

解题口诀: "目标在哪边, 已知就用哪边; 要翻转就变号; 要加倍就乘系数"

Section ④ "键能与反应热计算" (bottom-left, medium module):
Formula in large text:
ΔH ≈ ΣE(反应物中断键所需能量) - ΣE(生成物中成键释放能量)（使用平均键能时为近似值）
为什么是"反应物-生成物": 断旧键需要吸收能量(正值)，成新键释放能量(正值)；ΔH = 吸收总量 - 释放总量。释放>吸收→ΔH<0→放热
记忆: "反应物减生成物" (与能量角度相反!)

Worked example:
H₂(g) + Cl₂(g) = 2HCl(g)
已知键能: E(H-H) = 436 kJ/mol, E(Cl-Cl) = 243 kJ/mol, E(H-Cl) = 431 kJ/mol
ΔH = [1×E(H-H) + 1×E(Cl-Cl)] - [2×E(H-Cl)]
    = [436 + 243] - [2 × 431]
    = 679 - 862
    = -183 kJ/mol (放热反应 ✓)

常见键能参考值 (kJ/mol):
| H-H 436 | O=O 498 | N≡N 946 | C-C 348 | C=C 615 | C≡C 812 |
| H-Cl 431 | H-O 463 | H-N 391 | C-H 413 | C=O 745 | Cl-Cl 243 |

Section ⑤ "能量图与活化能" (bottom-right, medium module):
Description of an energy diagram to be drawn:
- X轴: 反应过程(reaction coordinate)
- Y轴: 能量(Energy)
- 曲线: 反应物能量水平(左侧平台) → 上升到过渡态(最高点) → 下降到生成物能量水平(右侧平台)
- 标注: Eₐ(正) = 正反应活化能 (从反应物到过渡态的能量差)
- 标注: Eₐ(逆) = 逆反应活化能 (从生成物到过渡态的能量差)
- 标注: ΔH = Eₐ(正) - Eₐ(逆)

Key conclusions:
- 放热反应: 反应物能量 > 生成物能量, ΔH < 0, Eₐ(正) < Eₐ(逆)
- 吸热反应: 反应物能量 < 生成物能量, ΔH > 0, Eₐ(正) > Eₐ(逆)
- 催化剂的作用: 降低Eₐ(正)和Eₐ(逆)(过渡态峰值降低), 但ΔH不变(始终态能量不变)
  为什么: 催化剂提供了一条新的、能垒更低的反应路径，但反应物和生成物本身的能量没变→起点终点不变→ΔH不变
  → 催化剂不改变反应热, 只加快反应速率!
- 加虚线曲线: 有催化剂时的能量曲线比无催化剂时的矮, 但起点和终点完全相同

Footer: "能量守恒·始终态定ΔH·途径无关是盖斯"
