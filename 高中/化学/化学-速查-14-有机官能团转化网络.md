Section ① "中心模型：官能团转化网络图" (top, hero module, full width):
Large network diagram with 醇 at the center hub, arrows radiating outward:

  四条核心单向箭头(每条标明条件):
  烷烃 ──(高温催化脱氢)→ 烯烃
  烯烃 ──(+H₂/Ni催化)→ 烷烃
  烯烃 ──(+H₂O/酸催化)→ 【醇】
  醇 ──(连-OH碳的邻位碳有H；酸催化/加热消去)→ 烯烃（乙醇：浓H₂SO₄/170°C）

  醇的氧化(按类别区分):
  伯醇(R-CH₂OH) →(催化氧化Cu/Ag/△)→ 醛(R-CHO) →(继续氧化)→ 羧酸(R-COOH)
    为什么伯→醛: -CH₂OH失去与O和α-C相连的两个H后，C上只剩一个H→形成-CHO(醛基)
  仲醇(R₂CH-OH) →(催化氧化)→ 酮(R-CO-R')
    为什么仲→酮: -CHOH失两个H后，C两侧都连碳→形成>C=O(酮基)
  叔醇(R₃C-OH) → 通常不易被催化氧化(与-OH相连的C上无H可脱)
  酯化(可逆): 羧酸 + 醇 ⇌(浓H₂SO₄/△) 酯 + H₂O (酸脱-OH醇脱-H)
  酸性水解: 酯 + H₂O ⇌(稀酸/△) 羧酸 + 醇 (可逆，需酸催化)
  碱性水解: 酯 + NaOH ──(△)→ 羧酸钠 + 醇 (不可逆——NaOH中和了水解产生的羧酸→产物被持续消耗→平衡完全偏向水解方向)

  卤代烃生成:
  RH + X₂ ──(光照)→ RX + HX (取代，单向；如CH₄+Cl₂→CH₃Cl+HCl)

卤代烃双路径 (关键分叉!):
  卤代烃 →(NaOH水溶液/△)→ 醇 (水解→取代)
  卤代烃 → 连-X碳的邻位碳有H?
    → 有 →(NaOH醇溶液/△)→ 烯烃 (消去)
    → 无 → 不走此消去路径（如CH₃Cl）

"醇是有机转化的枢纽: 伯醇→醛→酸，仲醇→酮，叔醇通常不易氧化 ↓消去到烯 →与羧酸酯化到酯"
为什么醇是枢纽: -OH基团既能被氧化(失去α-H)又能参与取代(脱-OH)又能消去(脱H₂O)→三条反应路径从醇辐射出去，连接了几乎所有官能团

碳四价成键: C有4个价电子→形成4个共价键→可成长链/支链/环; 碳碳单键可旋转/双键不旋转

Right column - 七类常见反应类型:
| 类型 | 定义 | 典型反应 |
| 取代 | 原子/基团被替换 | CH₄+Cl₂→(光照)CH₃Cl+HCl |
| 加成 | 不饱和键断开加原子 | CH₂=CH₂+Br₂→CH₂BrCH₂Br |

| 水解 | 酯+水⇌酸+醇(稀酸/△); 酯+NaOH→盐+醇(碱性不可逆) | CH₃COOC₂H₅+NaOH→CH₃COONa+C₂H₅OH |

Section ③ "重要有机物性质详解" (bottom-left, large module):
乙醇4种反应: ①与Na产H₂(比水缓和) ②催化氧化→醛(Cu/Ag/△) ③消去→烯(浓H₂SO₄/170°C) ④分子间脱水→醚(浓H₂SO₄/140°C)

乙醛: 银镜反应(CH₃CHO+2Ag(NH₃)₂OH →(水浴加热) CH₃COONH₄+2Ag↓+3NH₃+H₂O) + Cu(OH)₂反应(→Cu₂O↓砖红) + 加氢还原→醇
酮vs醛鉴别: 银镜/Cu(OH)₂——醛有反应,酮无! (果糖特例: 碱性下异构化为醛糖→能银镜)

乙酸: 弱酸, 酸性: 盐酸>乙酸>碳酸>苯酚>HCO₃⁻ (重要酸性序!)
乙酸乙酯小试装置链: 大试管缓慢加热→导管口在接收液面上方(防倒吸)→饱和Na₂CO₃接收
试剂作用矩阵: 浓H₂SO₄→催化+吸水；饱和Na₂CO₃→中和乙酸+溶解乙醇+降低酯溶解度

苯酚: 弱酸(比碳酸弱) + FeCl₃显紫色(鉴别) + 浓溴水→白色三溴苯酚↓
  C₆H₅OH+Na₂CO₃→C₆H₅ONa+NaHCO₃(只反应到NaHCO₃!)

苯: 不使溴水/KMnO₄褪色(为什么: 苯环具有芳香性——6个π电子离域产生额外稳定化能→芳香结构较稳定，普通条件下较难加成、较难被酸性KMnO₄氧化→苯优先发生保留芳香环的亲电取代) 但可萃取Br₂; 取代(液溴+FeBr₃/硝化HNO₃+浓H₂SO₄); 加成(+3H₂/Ni，需高温高压+催化剂)

Section ④ "同分异构·鉴别·结构测定" (bottom-right, medium module):
同分异构三类型: 碳链异构(正丁烷/异丁烷) + 位置异构(1-丙醇/2-丙醇) + 官能团异构(乙醇/甲醚)
书写: 主链从长到短→支链从简到繁改位置→最后考虑官能团异构
不饱和度: Ω=(2C+2+N-H)/2 (卤素当H算,O不参与); Ω=4→可能含苯环

鉴别速查:

结构测定三步法(MS→IR→¹H NMR):
①MS: 识别分子离子/准分子离子→定Mr；先排同位素/碎片干扰，勿直接取最大m/z
②IR: 特征峰定官能团(O-H 3200-3650宽强; C=O 1680-1750强尖; C=C 1600-1680)
③¹H NMR: 峰数=H种类数; 面积比=H个数比; 三管齐下定结构
例: Mr=60(MS)+C=O和O-H(IR)+2组峰比3:1(NMR) → CH₃COOH ✓
