## 第 0 层　公理

### A01 基础公理
- 标志：$a + b = b + a$
- 区域：基础
- 类型：起点
- 标签：【公理】
- 条件：无额外限制
- 是什么：加法交换律：两个数相加，交换顺序不影响结果。这是算术和代数的基本公理之一，所有涉及加法化简的推导都以此为前提

### A02 乘法公理
- 标志：$a \cdot b = b \cdot a$
- 区域：基础
- 类型：起点
- 标签：【公理】
- 条件：无额外限制
- 是什么：乘法交换律：两个数相乘，交换顺序不影响结果。与加法交换律一起构成运算的基本规则

## 第 1 层　基本性质

### B01 基本性质
- 标志：$(a + b)^{2} = a^{2} + 2ab + b^{2}$
- 区域：推论
- 类型：结论
- 重要度：1
- 条件：无额外限制
- 是什么：完全平方展开式：和的平方等于各项平方加两倍乘积。用在配方法求最值、判正负、推导均值不等式；反过来用就是配方——把 $a^{2}+2ab+b^{2}$ 收成 $(a+b)^{2}$
- 依赖：
  - 来源：A01
    种类：推出
    方法：展开法
    步骤：
      1. ▼ 条件：$a, b$ 为任意实数
      2. 由「加法交换律」$a+b = b+a$
      3. 【展开法】$(a+b)^{2} = (a+b)(a+b)$
      4. 用「乘法分配律」展开：$= a \cdot a + a \cdot b + b \cdot a + b \cdot b$
      5. 由「乘法交换律」$a \cdot b = b \cdot a$
      6. 合并同类项：$= a^{2} + 2ab + b^{2}$
  - 来源：A02
    种类：推出
    步骤：
      1. 【前提】乘法交换律保证 $ab = ba$，合并为 $2ab$

### B02 差的平方
- 标志：$(a - b)^{2} = a^{2} - 2ab + b^{2}$
- 区域：推论
- 类型：结论
- 重要度：1
- 条件：无额外限制
- 是什么：差的平方展开式：差的平方等于各项平方减两倍乘积。和完全平方对比记忆，符号相反
- 依赖：
  - 来源：B01
    种类：推出
    方法：代换法
    步骤：
      1. ▼ 条件：$a, b$ 为任意实数
      2. 【代换法】在「完全平方展开式」$(a+b)^{2} = a^{2}+2ab+b^{2}$ 中，令 $b$ 换成 $-b$
      3. 代入：$(a+(-b))^{2} = a^{2} + 2a(-b) + (-b)^{2}$
      4. 化简：$(a-b)^{2} = a^{2} - 2ab + b^{2}$

## 第 2 层　核心定理

### C01 核心定理
- 标志：$a^{2} + b^{2} \ge 2ab$
- 区域：推论
- 类型：结论
- 重要度：2
- 条件：无额外限制
- 是什么：任意两个实数的平方和不小于它们积的两倍。这是均值不等式的基础，用在比大小（作差后配方）、求最值（凑定值）、证明更高级的不等式（柯西、排序等）。等号 $\iff a = b$
- 依赖：
  - 来源：B02
    种类：推出
    方法：展开法
    步骤：
      1. 由「差的平方」$(a-b)^{2} = a^{2} - 2ab + b^{2}$
      2. 由「平方非负」$(a-b)^{2} \ge 0$（任意实数的平方都非负）
      3. 因此 $a^{2} - 2ab + b^{2} \ge 0$
      4. 【移项法】两边 $+2ab$：$a^{2} + b^{2} \ge 2ab$
      5. 等号 $\iff a-b = 0$，即 $a = b$

## 思想方法

### 恒等变形
- 说明：展开、因式分解、配方、代换
- 方向：把式子换成相等、更好用的样子（用 = 连接）
- 依据：运算律和恒等式
- 信号：要定正负就分解成因式之积；要比较就展开合并
- 标签：展开；展开法；代换；代换法；移项；移项法
