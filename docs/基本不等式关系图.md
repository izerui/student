一、要做成什么

一张不等式知识大厦图：从最基础的公理出发，逐层推到各类不等式和二级结论。不是公式汇编，而是能看清每个结论"从哪来、怎么来、能推出什么"的关系网。

二、内容范围

1. 起点：实数大小、运算规则、平方非负、绝对值定义等最底层的东西。
2. 不等式：高中范围内的全部，加上常见竞赛结论（排序、切比雪夫、舒尔、Nesbitt 等）。
3. 二级结论：和定积最大、x+1/x≥2、1/x+1/y≥4/(x+y) 这类常用变形，也要作为节点列出来。
4. 支撑公式：乘法公式、对称式、三角、指数对数、数列、排列组合等恒等式也收进来。数学本来相辅相成，这些公式要连到具体用到它的那一步。

三、表达规则

1. 只用一张图，按数学层级往下推，不划小学、初中、高中区域。
2. 节点 = 结果，写清名称、公式、等号条件，以及它是第几级结论。
3. 线条 = 怎么推，写【方法名】加具体操作，比如"两边 ÷2""令 a=√u"。不跳步。
4. 只在一条推导里出现的中间计算写在线上；能独立成立、会被多处复用的结果才做节点。
5. 箭头方向始终是"更基础 → 推出的结论"，不同含义的线要能区分开。

四、使用目标（最核心）

像走迷宫：看到一道求最值或求范围的题，能在图上定位入口，知道往哪走。 顺着箭头是正推，逆着箭头是反推。最终目标是把这座大厦记在脑子里，形成解题思路。所以需要：
- 题型入口：看到什么结构，就去找哪个工具。
- 使用条件检查：比如 AM≥GM 的"一正二定三相等"。
- 常用转化技巧：均值代换、判别式法、齐次化、三角换元等。

五、视觉

节点形状和颜色按类型区分，入口不用菱形。整张图要清晰、不拥挤，便于记忆。你要的内容一个都不能丢，文件要能在 draw.io 里继续编辑。
